Research attempt: A checked certificate model and the statement-translation gap

Represent a propositional clause as a finite set of signed variables. A resolution certificate lists input clauses, then lines of the form: previous clauses $C,D$, pivot $p\in C$ with $\neg p\in D$, and claimed new clause \[ R=(C\setminus\{p\})\cup(D\setminus\{\neg p\}). \] A checker verifies those memberships, the exact set equality, and that indices point to earlier lines. If the final clause is empty, it accepts an unsatisfiability certificate. Soundness is elementary: an assignment satisfying both parents but falsifying every literal of $R$ would have to make $p$ true to satisfy $C$ and false to satisfy $D$, a contradiction. Induction over the ordered lines proves that every model of the input satisfies every derived clause. Since no assignment satisfies the empty clause, acceptance proves unsatisfiability of precisely those input clauses.

For example, start with \[ p\vee q,\quad\neg p\vee q,\quad p\vee\neg q,\quad\neg p\vee\neg q. \] Resolving the first two on $p$ yields $q$, the last two on $p$ yields $\neg q$, and resolving those on $q$ yields the empty clause. A checker using variable bitsets checks a certificate of $L$ lines on $n$ variables with $O(Ln)$ clause-bitset work, plus the costs of parsing and accessing the line indices; this is not a claim that index costs disappear in total bit complexity. Its running time depends on the supplied certificate length; this is not a bound on how quickly a generator finds it.

Where checked generation still fails to certify the requested theorem.
The checker proves a statement only about its exact formal input. Translation can alter that input's meaning without producing an invalid proof. For instance, the natural-number statement $\exists m\,\forall n\;(m>n)$ is false, by taking $n=m$. The statement $\forall n\,\exists m\;(m>n)$ is true, witnessed by $m=n+1$. A generator that reverses these quantifiers can supply a correct proof of the second while failing the first task completely. Kernel acceptance cannot infer that the English quantifiers were translated correctly.

Similarly, if a purported formal proof permits an extra assumption equal to the desired conclusion, the conclusion follows trivially from that assumption. Soundness is conditional on the accepted assumptions, not evidence that they were intended. In a finite dependency DAG, all transitive leaf assumptions can be collected by graph traversal: mark each visited node and visit each predecessor once, yielding $O(V+E)$ work. Comparing these leaves to a specified permitted set detects an unauthorized imported assumption in this model. This does not solve natural-language alignment, foundational soundness, or the handling of all features of a real proof assistant; it identifies concrete obligations beyond a successful proof check.
