For a discrete channel $y_t=\sum_{j=0}^{N-1}h_jx_{t-j}+z_t$, equalization seeks to undo intersymbol interference. An OFDM scheme uses orthogonal subcarriers and FFT-based transforms; a cyclic prefix can convert the relevant convolution into a circular one under stated conditions. Maximum-likelihood sequence detection can have a state count exponential in channel memory, whereas linear equalization solves a different optimization problem.

Research attempt: A long sparse channel need not require exponential-state equalization

Let $x_t$ lie in a known alphabet of size $q$, with known preceding symbols, and observations $y_t=\sum_{j=0}^m h_jx_{t-j}+z_t$ for $1\le t\le T$. For independent equal-variance Gaussian noise, maximizing likelihood is equivalent to minimizing the sum of squared residuals. A dynamic program with state the last $m$ symbols has $q^m$ states; for each new symbol it adds the current residual and shifts the state. The minimum cost for a state is sufficient because all future residuals depend on the past only through those $m$ symbols. There are at most $q^{m+1}$ transitions per time, yielding $O(Tq^{m+1}(m+1))$ arithmetic work if each residual is evaluated directly. Precomputed or incrementally evaluated transition residuals can alter polynomial factors but this displayed generic implementation has exponential state count.

The attempted inference was that channel length alone forces such complexity. Take a sparse channel with only $h_0$ and $h_d$ nonzero, for an arbitrarily large delay $d$. Its objective is \[ \sum_{t=1}^T|y_t-h_0x_t-h_dx_{t-d}|^2. \] Terms couple symbols only in the same residue class modulo $d$. Partition all indices by that residue. The objective is a sum of independent chain objectives, each with a nearest-neighbor interaction and known initial boundary symbol. Each chain is minimized by a $q$-state dynamic program, testing $q^2$ successive-symbol pairs at each position. Across all chains there are $T$ positions, so the exact global minimizer costs $O(Tq^2)$ arithmetic operations, plus initialization of the nonempty chains. Backtracking reconstructs the complete symbol sequence. This is exact discrete sequence estimation, not a linear relaxation.

The sparse support therefore matters through the interaction structure, not only the largest delay. Adding a tap at delay one couples different residue chains and invalidates the decomposition; no general sparse-channel polynomial bound follows. Conversely the generic exponential-state implementation is not a lower bound for all algorithms. Channel-estimation uncertainty and other coding/precoding objectives in the source remain distinct problems.
