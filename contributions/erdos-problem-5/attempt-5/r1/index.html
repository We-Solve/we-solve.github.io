Rescaling Lemma

Let $(a_n)$ be a sequence in $[0,\infty]$ and let $(r_n)$ be positive with $r_n\to 1$. Define $b_n=a_n r_n$. Then $(a_n)$ and $(b_n)$ have the same set of limit points in $[0,\infty]$.

Proof.
If $a_{n_k}\to x<\infty$, then $b_{n_k}=a_{n_k}r_{n_k}\to x$. Conversely, if $b_{n_k}\to x<\infty$, then $a_{n_k}=b_{n_k}/r_{n_k}\to x$. For $\infty$, since $r_n\to 1$, eventually $1/2\le r_n\le 2$, so divergence of one sequence forces divergence of the other. $\square$

Asymptotics of $\log p_n$

Lemma: \[ \lim_{n\to\infty}\frac{\log p_n}{\log n}=1. \]
Proof.
Since $p_n\ge n+1$, we have $\log p_n/\log n\ge \log(n+1)/\log n\to 1$. Explicit bounds of Dusart give \[ p_n\le n(\log n+\log\log n+O(1)), \] hence $\log p_n\le \log n+o(\log n)$, which implies the limsup is at most $1$. $\square$

Equality of Limit--Point Sets

Define \[ g_n=\frac{p_{n+1}-p_n}{\log n},\qquad h_n=\frac{p_{n+1}-p_n}{\log p_n}. \] Let $S$ and $L$ be the respective limit--point sets.

Proposition: $S=L$.
Proof.
We have $g_n=h_n r_n$ with $r_n=\log p_n/\log n\to 1$. By the rescaling lemma, the two sequences have identical limit--point sets. $\square$

Imported theorem: $S$ contains an initial interval $[0,c]$ (ineffective $c>0$)

In the classical normalization, it is known (via Zhang's bounded gaps) that there exists an ineffective constant $c>0$ such that $[0,c]\subseteq S$. Equivalently, every real number in $[0,c]$ is a limit point of normalized prime gaps.

This is strictly stronger than $0\in S$: it gives nonempty interior near $0$.

Definition: the $k$-point difference property

Let $A\subseteq[0,\infty)$. For an integer $k\ge 2$, say that $A$ has property $(P_k)$ if for every real numbers \[ \beta_1\le\beta_2\le\cdots\le\beta_k \] we have \[ A\cap\{\beta_j-\beta_i:1\le i<j\le k\}\neq\emptyset. \] By Merikoski's Theorem 1, $S$ has $(P_4)$; by Banks--Freiberg--Maynard, $S$ has $(P_9)$.

New Lemma: relative-gap constraint from $(P_k)$

Lemma (Relative-gap obstruction): Assume $A\subseteq[0,\infty)$ has $(P_k)$. Let $a>0$ and $b>(k-1)a$. Then $(a,b)\cap A\neq\emptyset$. Equivalently: if $(a,b)\cap A=\emptyset$ with $a>0$, then necessarily $b\le (k-1)a$.
Proof.
Assume for contradiction that $(a,b)\cap A=\emptyset$ with $b>(k-1)a$. Choose $\varepsilon>0$ such that \[ a+\varepsilon<\frac{b}{k-1}, \] which is possible exactly because $b>(k-1)a$.

Define $k$ points by \[ \beta_i:=(i-1)(a+\varepsilon),\qquad i=1,2,\dots,k. \] Then every difference has the form \[ \beta_j-\beta_i=(j-i)(a+\varepsilon)\in\{(a+\varepsilon),2(a+\varepsilon),\dots,(k-1)(a+\varepsilon)\}. \] Each such number lies in $(a,b)$ since $a+\varepsilon>a$ and $(k-1)(a+\varepsilon)<b$. Hence \[ \{\beta_j-\beta_i:1\le i<j\le k\}\subset (a,b), \] so it is disjoint from $A$, contradicting $(P_k)$. $\square$

Corollary: closed + $(P_k)$ forces multiplicative syndeticity

Corollary: If $A\subseteq[0,\infty)$ is closed and has $(P_k)$, then for every $a>0$, \[ A\cap[a,(k-1)a]\neq\emptyset. \] In particular, since $S$ is closed and has $(P_4)$, we have \[ S\cap[a,3a]\neq\emptyset\quad\text{for all }a>0, \] and any open interval $(a,b)$ disjoint from $S$ must satisfy $b\le 3a$.
Proof.
Fix $a>0$ and suppose $A\cap[a,(k-1)a]=\emptyset$. Since $A$ is closed and $[a,(k-1)a]$ is compact, the distance \[ d:=\mathrm{dist}\left(A,\,[a,(k-1)a]\right) \] is strictly positive. Put $\delta:=\min(d/2,a/2)$ so that $a-\delta>0$ and \[ (a-\delta,\,(k-1)a+\delta)\cap A=\emptyset. \] But then \[ (k-1)a+\delta > (k-1)(a-\delta) \] (since the difference is $k\delta>0$), hence the interval $(a-\delta,(k-1)a+\delta)$ has right endpoint $>(k-1)$ times its left endpoint. This contradicts the relative-gap lemma. $\square$

New obstruction example: known structural properties do not imply density

We now show that the package of currently known abstract properties of $S$ is insufficient to deduce density.

Proposition (Strategy-elimination example): Let \[ A:=[0,1]\cup[3,\infty)\subset[0,\infty). \] Then:
  1. $A$ is closed.
  2. $A$ is syndetic (indeed, every interval of length $2$ intersects $A$).
  3. For all $T\ge 0$, $\mu(A\cap[0,T])\ge T/3$.
  4. $A$ has $(P_4)$ and $(P_9)$ (in fact it has $(P_k)$ for every $k\ge 4$).
  5. $A$ is not dense in $[0,\infty)$ (it misses the open interval $(1,3)$).
Proof.
$1$ Closedness is immediate.

$2$ Let $T\ge 0$. If $T\le 1$, then $[T,T+2]$ intersects $[0,1]\subset A$. If $1<T<3$, then $3\in[T,T+2]\cap A$. If $T\ge 3$, then $[T,T+2]\subset[3,\infty)\subset A$. Hence every interval of length $2$ intersects $A$.

$3$ Compute $\mu(A\cap[0,T])$: \[ \mu(A\cap[0,T])= \begin{cases} T, & 0\le T\le 1,\\ 1, & 1<T\le 3,\\ 1+(T-3)=T-2, & T\ge 3. \end{cases} \] For $0\le T\le 1$, we have $T\ge T/3$. For $1<T\le 3$, we have $1\ge T/3$. For $T\ge 3$, we have $T-2\ge T/3$ since $2T/3\ge 2$.

$4$ To prove $(P_4)$, let $\beta_1\le\beta_2\le\beta_3\le\beta_4$. If any consecutive difference satisfies $\beta_{i+1}-\beta_i\le 1$, then that difference lies in $[0,1]\subset A$ and we are done. Otherwise all three consecutive differences exceed $1$, so \[ \beta_4-\beta_1=(\beta_2-\beta_1)+(\beta_3-\beta_2)+(\beta_4-\beta_3)>3, \] hence $\beta_4-\beta_1\in[3,\infty)\subset A$, and we are done. Thus $(P_4)$ holds. The proof for $(P_9)$ is identical: if no consecutive difference is $\le 1$, then $\beta_9-\beta_1>8$, hence belongs to $[3,\infty)\subset A$.

$5$ $A$ is not dense because $(1,3)\cap A=\emptyset$. $\square$

Round--3 consequence: what a counterexample interval for $S$ must look like

Assume (for contradiction) that $S\neq[0,\infty]$. By Round--1 Lemma 1, there exists a nonempty open interval $(a,b)\subset[0,\infty)$ with $(a,b)\cap S=\emptyset$.

Combining:

  • the imported fact that $[0,c]\subseteq S$ for some $c>0$ (ineffective), and
  • the corollary from $(P_4)$ (relative-gap obstruction), and
  • syndeticity of $S$ (bounded additive gaps),
we obtain the following necessary constraints on any such missing interval $(a,b)$:

  1. $a\ge c$ (since $(0,c)$ is fully contained in $S$).
  2. $b\le 3a$ (since $(P_4)$ forbids gaps with multiplicative ratio $>3$).
  3. $b-a\le C_S$ for some absolute (ineffective) syndeticity constant $C_S$ (since $S$ intersects every interval of length $C_S$).

Thus any failure of density must come from a short additive gap occurring above the initial interval $[0,c]$, and with bounded multiplicative ratio.

Crucial meta-point: Proposition above shows these constraints and the known abstract properties are far from sufficient to force density; any genuine proof of Erdős' conjecture must use arithmetic structure beyond closedness + syndeticity + measure bounds + $(P_k)$.

Reminder: $(P_k)$

For $k\ge 2$, a set $A\subseteq[0,\infty)$ has property $(P_k)$ if for every choice of real numbers $\beta_1\le\cdots\le\beta_k$ we have \[ A\cap\{\beta_j-\beta_i:1\le i<j\le k\}\neq\emptyset. \] (As noted in Round--3, $(P_4)$ implies $(P_k)$ for all $k\ge 4$ by restriction to any four points.)

Sharpness construction for $(P_k)$

Theorem (Sharpness of the relative-gap constraint): Fix an integer $k\ge 2$ and reals $0<a<b$ with $b\le (k-1)a$. Define \[ A_{a,b}:=[0,a]\cup[b,\infty)\subset[0,\infty). \] Then:
  1. $A_{a,b}$ is closed and is not dense (it misses the open interval $(a,b)$).
  2. $A_{a,b}$ is syndetic (every closed interval of length $b-a$ meets $A_{a,b}$).
  3. $A_{a,b}$ satisfies $(P_k)$.
  4. For every $T\ge 0$, \[ \mu(A_{a,b}\cap[0,T])\ \ge\ \frac{T}{k-1}. \] In particular, for $k=4$ we have $\mu(A_{a,b}\cap[0,T])\ge T/3$ for all $T\ge 0$.
Proof.
$1$ Closedness is clear since $A_{a,b}$ is a union of closed intervals. Non-density holds since $(a,b)\cap A_{a,b}=\emptyset$.

$2$ Let $C:=b-a$. We claim every closed interval $[x,x+C]$ intersects $A_{a,b}$. If $x\le a$, then $[x,x+C]$ intersects $[0,a]\subset A_{a,b}$. If $x>a$, then $x+C>x+(b-a)>b$, hence $[x,x+C]$ intersects $[b,\infty)\subset A_{a,b}$. Thus $A_{a,b}$ is syndetic.

$3$ Let $\beta_1\le\cdots\le\beta_k$. If some consecutive gap $\beta_{i+1}-\beta_i\le a$, then this difference lies in $[0,a]\subset A_{a,b}$. Otherwise every consecutive gap satisfies $\beta_{i+1}-\beta_i>a$, so \[ \beta_k-\beta_1=\sum_{i=1}^{k-1}(\beta_{i+1}-\beta_i)>(k-1)a\ge b, \] hence $\beta_k-\beta_1\in[b,\infty)\subset A_{a,b}$. In all cases, some pairwise difference lies in $A_{a,b}$, i.e. $(P_k)$ holds.

$4$ We compute $\mu(A_{a,b}\cap[0,T])$ explicitly:

\[ \mu(A_{a,b}\cap[0,T])= \begin{cases} T, & 0\le T\le a,\\ a, & a<T<b,\\ a+(T-b)=T-(b-a), & T\ge b. \end{cases} \]

If $0\le T\le a$, then $\mu=T\ge T/(k-1)$. If $a<T<b$, then $\mu=a\ge b/(k-1)\ge T/(k-1)$ since $T<b\le (k-1)a$. If $T\ge b$, then \[ \mu=T-(b-a)\ \ge\ T-\left(b-\frac{b}{k-1}\right)=\frac{T}{k-1}, \] because $a\ge b/(k-1)$. This proves the measure bound for all $T\ge 0$. $\square$

Corollary (Sharpness at $k=4$): For every $0<a<b\le 3a$, the set $A_{a,b}=[0,a]\cup[b,\infty)$ is closed, syndetic, satisfies $(P_4)$, and obeys $\mu(A_{a,b}\cap[0,T])\ge T/3$ for all $T\ge 0$, yet $(a,b)\cap A_{a,b}=\emptyset$.

Together with the Round--3 relative-gap lemma (necessity of $b\le 3a$ for any set with $(P_4)$), this shows that the multiplicative restriction $b\le 3a$ is optimal: it cannot be improved purely from $(P_4)$.

A strengthened strategy-elimination family: far-out holes + long initial segment

Fix any $L>0$ and any $M>L$ with $M\ge \tfrac12$. Set $a:=M$ and $b:=M+1$ (so $b\le 3a$ holds for $M\ge \tfrac12$) and define \[ A_M := A_{M,M+1}=[0,M]\cup[M+1,\infty)= [0,\infty)\setminus(M,M+1). \] Then:

  • $[0,L]\subseteq A_M$ (indeed, $[0,M]\subseteq A_M$), so $A_M$ contains an arbitrarily long initial interval.
  • $A_M$ is syndetic with constant $1$ (every closed interval of length $1$ meets $A_M$).
  • By Theorem Theorem (Sharpness of the relative-gap constraint) (with $k=4$), $A_M$ satisfies $(P_4)$ and $\mu(A_M\cap[0,T])\ge T/3$ for all $T$.
  • $A_M$ is not dense since it misses the open interval $(M,M+1)$, and this missing interval can be placed arbitrarily far out by taking $M$ large.

Conclusion. Even if one strengthens the abstract hypotheses drastically --- closedness, $(P_4)$, the uniform measure bound $\mu(\cdot)\ge T/3$ for all $T$, syndeticity with tiny constant, and containment of an arbitrarily long initial segment --- density still does not follow. Hence, any proof of Erdős' conjecture for the genuine prime-gap set $S$ must use additional arithmetic structure beyond these global properties.

ADVERSARIAL VERIFICATION

  • Boundary case $b=(k-1)a$. In the $(P_k)$ proof we use $\beta_k-\beta_1>(k-1)a$, hence $\beta_k-\beta_1>b$ even when $b=(k-1)a$, so membership in $[b,\infty)$ is valid.
  • Syndeticity convention (open vs. closed intervals). The proof uses closed intervals $[x,x+C]$. If one uses open intervals $(x,x+C)$, then one should take any $C'>b-a$ instead; this does not affect the strategy-elimination conclusions.
  • Measure bound check in the regime $a<T<b$. The inequality reduces to $a\ge T/(k-1)$ for all $T<b$, which is guaranteed by $b\le (k-1)a$ and is tight at $T=b$ when $b=(k-1)a$.
  • Interaction with Round--3 relative-gap lemma. Our construction matches the Round--3 necessary condition $b\le (k-1)a$, showing it is sharp; there is no contradiction.
  • Relevance to the actual $S$. These sets $A_{a,b}$ are model sets sharing the same abstract properties currently proved for $S$. They do not claim anything about primes, but they rigorously show why these properties alone cannot settle the conjecture.

FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

Round--4 establishes sharpness and a stronger strategy-elimination principle:

  1. The Round--3 multiplicative restriction on missing intervals for sets with $(P_4)$, namely $b\le 3a$, is optimal: any open interval $(a,b)$ with $b\le 3a$ can be removed from a closed syndetic set still satisfying $(P_4)$ and $\mu(\cdot)\ge T/3$ for all $T$.
  2. There exist counter-model sets with arbitrarily long initial intervals and arbitrarily far-out missing intervals, even with syndetic constant $1$ and the full uniform measure lower bound $T/3$.

Thus any proof of Erdős' conjecture for the genuine limit-point set of normalized prime gaps must use substantially more arithmetic information than the currently known global structural properties.
