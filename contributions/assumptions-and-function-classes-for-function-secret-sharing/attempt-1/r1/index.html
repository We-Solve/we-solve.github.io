Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Function secret sharing distributes keys whose local evaluations combine to the output of a function while hiding that function from the prescribed coalitions. A point function is nonzero at one designated input and zero elsewhere.

A cryptographic security requirement compares an efficient adversary's advantage with a negligible function of the security parameter. A negligible function is smaller than every inverse polynomial eventually; computational and information-theoretic security are different requirements.

Research attempt: Perfect-privacy point sharing requires long additive keys

A baseline with exact privacy.
Let the domain have $N$ points, and represent a Boolean function by its truth table $F\in\mathbb F_2^N$. For $m\ge2$, choose independent uniform vectors $K_1,\ldots,K_{m-1}\in\mathbb F_2^N$ and set $K_m=F+\sum_{j<m}K_j$. Party $j$ outputs the requested coordinate of $K_j$. Their sum is $F$ at every point. Every strict coalition sees a uniform tuple independent of $F$: if it omits party $m$, this is immediate; otherwise at least one independent uniform mask is missing, and it makes $K_m$ uniform conditional on all the observed masks. Each key has $N$ bits.
A near-matching lower bound even for point functions.
Now restrict the hidden function to $F=e_i$, the point function at $i\in[N]$, where $N\ge2$. Consider any $m$-party scheme with the following additional hypotheses: local evaluations are deterministic functions of a key and the public input; outputs add in $\mathbb F_2$; correctness holds with probability one simultaneously at all $N$ points; and every strict coalition's key distribution is exactly independent of $i$. Let $V_j\in\mathbb F_2^N$ be the full evaluation vector determined by party $j$'s key.

Fix a party $j$. Let $B=V_j$ and $A=\sum_{\ell\ne j}V_\ell$. The laws of $A$ and of $B$ are each independent of the selected point by the two relevant coalition privacy conditions, and correctness gives $B=e_i+A$. Denote the common law of $A$ by $\mu$. Since the law of $B$ is the same for every $i$, the measure $\mu$ is invariant under translation by every vector $e_i+e_{i'}$. These vectors span the even-parity subspace \[ E=\{v\in\mathbb F_2^N:\sum_i v_i=0\},\qquad |E|=2^{N-1}. \] Indeed $e_1+e_i$ for $i>1$ are linearly independent and span that subspace: the last $N-1$ coordinates determine every even-parity vector.

Translation invariance forces $\mu$ to be uniform within each of the two cosets of $E$. Conditional on its parity, $A$ therefore has entropy $N-1$ bits; hence $H(A)\ge N-1$. The same holds for $B=e_i+A$. Since $B$ is a deterministic function of party $j$'s key, that key must have entropy at least $N-1$: grouping key outcomes by their evaluation vector cannot increase entropy, as follows directly by decomposing entropy into the entropy of the group label plus the nonnegative conditional entropy. In particular, if each key is encoded in at most $\ell$ bits in a fixed-length encoding, $\ell\ge N-1$. The argument holds for every party and every $m\ge2$, including three or more parties.

Why this does not refute succinct computational FSS.
The proof uses equality of distributions to propagate invariance along all translations in a subspace of exponential size. Computational indistinguishability is weaker and does not imply equality or uniformity on those cosets. An unbounded observer could enumerate the truth table and distinguish distributions that efficient observers cannot distinguish. Thus the lower bound applies to the explicitly stronger perfect-privacy model, while the source asks for computational constructions from one-way functions. Nor does it establish that one-way functions are necessary for every useful FSS instance: that would need a separate reduction with the source's exact functionality, security and efficiency parameters.
