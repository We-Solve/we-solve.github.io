Research-attempt provenance

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.

Fix an integer base $b\ge2$. Write the fractional part of $x\in\mathbb R$ as $\sum_{j\ge1}d_jb^{-j}$, where $d_j\in\{0,\ldots,b-1\}$, taking the expansion which is not eventually all $b-1$. A deterministic multitape Turing machine has a fixed finite number of work tapes, finite state and tape alphabets, and at each step reads and writes the scanned symbols and moves each tape head by at most one cell. Its output is in real time when, from a fixed finite initial configuration, it emits these digits in order with at most a fixed constant number of steps before the first digit and between consecutive digits. A real number is algebraic if it is a root of a nonzero polynomial in $\mathbb Z[T]$; otherwise it is transcendental.

Statement recorded in the supplied source.
For every $b\ge2$ and every real $x$ with such a real-time multitape Turing-machine digit expansion, must $x\in\mathbb Q$ or $x$ be transcendental? Equivalently, can no algebraic irrational have such an expansion? [S2]

Short English statement

Can a fixed multitape Turing machine output the digits of an algebraic irrational at a uniformly bounded number of steps per digit?

Research attempt: Real-time output does not imply finite-state behavior

A tempting proof is that bounded work between digits gives only finitely many possible output states, hence an eventually periodic expansion. This conflates finite control with finite tape configurations. Here is a direct counterexample to that intermediate inference.

Use one work tape with a left marker at cell zero and a right marker initially at cell one, and a finite control recording travel direction. On reaching the left marker, emit $1$ and travel right. At every other step emit $0$. At the right marker in position $k$, erase it, move one cell right, write the new right marker at $k+1$, and start traveling left. The initial configuration is finite. The marked endpoint extension and reversal require only a fixed finite number of states; in the usual read-write-move transition convention they are performed in two successive transitions, both emitting a digit. Between successive visits to the left marker there are $2k+2$ transitions, with $k$ the old right endpoint. Thus every transition emits one digit and the gaps between successive $1$'s increase without bound. The expansion is not eventually periodic: a periodic tail with any $1$ has gaps bounded by its period, whereas a tail with no $1$ would contradict the infinitely many returns. Nor is it eventually all $b-1$ in any base $b\ge2$.

For completeness, this expansion is irrational. If a rational number $u/v$ is expanded in base $b$, ordinary long division iterates the remainders $r\mapsto br\bmod v$ in the finite set $\{0,\ldots,v-1\}$. Once a remainder repeats, all subsequent digits repeat, with the usual terminating expansion when zero is reached. Therefore its expansion is eventually periodic, contrary to the constructed digit word. This does not say whether the constructed irrational is algebraic or transcendental, and so does not refute the conjecture. It refutes the proposed finite-configuration proof of it.

A direct opposite attempt is a real-time square-root extractor. For fixed base $b$, let $q_k=\lfloor b^k\sqrt2\rfloor$ and $R_k=2b^{2k}-q_k^2$. If the next digit is $d\in\{0,\ldots,b-1\}$, then \[ q_{k+1}=bq_k+d,\qquad R_{k+1}=b^2R_k-2bq_kd-d^2. \] The correct digit is the largest $d$ leaving the latter nonnegative. This is an exact digit algorithm, but $q_k$ has $\Theta(k)$ digits. A literal implementation that scans its full digit array for these updates uses $\Theta(k)$ work at the $k$th step and quadratic total work. Treating those growing integer operations as unit cost is not allowed. This is a cost analysis of that implementation, not a lower bound against redundant representations, pipelining, or other methods.

Scope and remaining gaps

No exclusion of algebraic irrational outputs is proved, and no bounded-delay multitape algorithm for an algebraic irrational is constructed. The first gaps are, respectively, a genuine arithmetic restriction on unbounded tape behavior or a way to implement growing exact arithmetic with the required bounded delay.
