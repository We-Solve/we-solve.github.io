Verbatim supplied catalogue question

A fully constructive Lipschitz and bounded-noise theorem

Suppose $f:[0,1]\to\mathbb R$ is $L$-Lipschitz, with a known rational $L\ge0$. On a uniform rational grid $t_j=j/M$, $0\le j\le M$, suppose rational observations satisfy $|y_j-f(t_j)|\le\delta$. Let $N$ be their linear interpolant. If $x=(1-u)t_j+ut_{j+1}$, then \[ |N(x)-f(x)|\le\delta+ (1-u)|f(t_j)-f(x)|+u|f(t_{j+1})-f(x)| \le\delta+2u(1-u)L/M\le\delta+L/(2M). \] All inequalities are uniform in $x$. Write $s_j=M(y_{j+1}-y_j)$. The interpolant has the exact rational ReLU realization \[ N(x)=y_0+s_0x+\sum_{j=1}^{M-1}(s_j-s_{j-1})\max(x-t_j,0). \] The slopes telescope on each grid interval, its initial value is $y_0$, and continuity gives equality at every endpoint. On $[0,1]$ the linear term is $s_0\max(x,0)$, so this is one hidden layer of at most $M$ neurons and a rational output bias. It is computable from the finite rational observations. For $L>0$, choosing $M\ge L/\epsilon$ and $\delta\le\epsilon/2$ gives error at most $\epsilon$. For $L=0$, a single noisy constant sample suffices with error at most $\delta$. A dyadic grid can be chosen by rounding $M$ up to a power of two without changing the proof.

The same argument works with a known effective uniform modulus $\omega$: replace $L/(2M)$ by $\omega(1/M)$, using that both endpoints are within $1/M$ of $x$. This statement requires a supplied usable modulus and a noise bound; it does not infer them from the observations.

A finite adaptive sampling algorithm cannot cover all targets

Fix a deterministic algorithm promised to terminate from exact point queries to any computable continuous function and return uniform error less than $1/2$. Run it on the zero function. It makes finitely many queries and returns some network $N$. There is an open interval avoiding every queried point. Choose rational endpoints strictly inside it and a rational midpoint, and define a triangular tent of height one supported on that interval, zero elsewhere. This function $g$ is continuous, computable, piecewise linear with rational data, and Lipschitz with a finite constant, though no common constant was supplied to the algorithm. It gives the same zero answer at every queried point. Induction over adaptive queries therefore gives the same transcript and output $N$. At the tent peak, $f=0$ and $g=1$, so \[ \max\{\|N-f\|_\infty,\|N-g\|_\infty\}\ge1/2. \] This contradicts the promised strict error. The argument is a worst-case deterministic exact-query obstruction; it does not cover a randomized statistical learner under an additional distribution or a class with a known shared modulus. The counterexample is itself exactly represented by a small rational ReLU network, so representation existence is not the missing step.

An irreducible bounded-noise ambiguity

If the supplied error bound is $\delta>0$, the two constant targets $f_+=\delta$ and $f_-=-\delta$ are both consistent with every observation being zero, at every possible query. For any output value $z$, $\max(|z-\delta|,|z+\delta|)\ge\delta$ by the triangle inequality. Thus no algorithm can guarantee uniform error strictly smaller than $\delta$ in this adversarial bounded-noise model, regardless of the number of samples. If computable targets and rational observations are required, choose rational $\delta>0$; this already proves the obstruction.

The ground-truth continuity issue

Exact classification can introduce an additional obstruction. On $[0,1]$ let $f(0)=0$ and $f(x)=1$ for $x>0$. No continuous ReLU network approximates it uniformly with error less than $1/2$: continuity at zero would force its values near zero to approach its value at zero, whereas the two error requirements place them on opposite sides of $1/2$ with a fixed positive gap. A margin restriction changes the task. On the domain $[-1,-\gamma]\cup[\gamma,1]$, $0<\gamma\le1$, the network \[ N_\gamma(x)=\frac{\max(x+\gamma,0)-\max(x-\gamma,0)}{2\gamma} \] returns exactly zero on the negative component and one on the positive component. Its Lipschitz constant is $1/(2\gamma)$, by its three explicit affine pieces. Thus even this basic classification comparison depends on the input-domain promise.
