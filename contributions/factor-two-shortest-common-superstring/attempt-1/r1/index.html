Factor-two shortest common superstring

OpenAI's claim

OpenAI presents the following claims relevant to this question, with manuscript numbers following paper order in Sources. In manuscript 1 (family 128; 2026-09-24), the asserted result is that ordinary shortest common superstring admits one deterministic polynomial-time factor-two algorithm on fully encoded string lists.

Mathematical statement of the claimed result

Manuscript 1.
For any finite explicitly represented collection $\mathcal S$ of ordinary strings, write $\operatorname{OPT}(\mathcal S)$ for the shortest length of a string containing every member as a contiguous substring. The claim supplies a deterministic algorithm, polynomial in total encoded input size, returning a common superstring $T$ with \[ |T|\le2\operatorname{OPT}(\mathcal S). \]
