A representation-independent replay theorem under explicit hypotheses.
Fix a protocol expressed as a finite deterministic state machine. Its state contains abstract group elements, public bytes, and a position in an explicitly specified random tape. Assume each permitted group operation has a fixed semantics; a decoder either rejects or gives one abstract value, a canonical encoder is injective on abstract values, and all public errors have specified conditions and encodings. Suppose two backends implement these semantics exactly and start with equal abstract states and identical public bytes and tapes. Then their public traces and rejection transitions coincide. Proof is by induction on transitions. A deterministic byte operation receives identical bytes. A group operation receives equal abstract arguments, so its semantic result is equal; encoding then produces identical bytes. A random operation consumes the same tape positions and applies the same rule. A branch or rejection predicate consequently has the same truth value. These cases preserve the induction invariant until termination. This is a functional conformance result conditional on the hypotheses; it neither constructs canonical forms nor proves timing behavior or cryptographic security. Without canonical encoding, equal abstract outputs need not have equal byte traces.
There is no uniform distribution on a countably infinite group.
If a countably infinite group $G$ had a uniform probability mass $c$ on each element, then for $c>0$ a finite set of more than $1/c$ elements would have probability greater than one. Thus $c=0$. Countable additivity would then assign $G$ probability zero, contradicting probability one. Therefore an API that promises a uniform random element for every finitely represented infinite group has an impossible specification. A bounded word distribution is a possible different operation, but it depends on generators, length convention, and reduction rules and is not uniform on the group.
Unit tests for the group axioms do not fix the action convention.
A left action must obey $(ab)\cdot x=a\cdot(b\cdot x)$. If a backend represents group elements by matrices but applies them in reversed order, it may effectively implement a right action. Associativity and inverse tests for its group multiplication alone cannot detect this mismatch. For a concrete test over $\mathbb F_5$, put \[ A=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad B=\begin{pmatrix}1&0\\1&1\end{pmatrix},\qquad v=\binom10. \] Both determinants equal one. Direct multiplication gives $AB=\left(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\right)$ and $BA=\left(\begin{smallmatrix}1&1\\1&2\end{smallmatrix}\right)$. Thus $(AB)v=(2,1)^T$ while $B(Av)=(1,1)^T$, which are unequal. A proposed universal adapter that silently identifies the two conventions therefore changes observable protocol computations. The correct contract must specify and test the action law, not only multiplication and inverses.
