Hodge Conjecture

Definitions and mathematical statement

Let $X$ be a smooth projective algebraic variety over ${\mathbb{C}}$ of complex dimension $n$. Its singular cohomology has the Hodge decomposition \[ H^k(X,{\mathbb{C}})=\bigoplus_{r+s=k}H^{r,s}(X),\qquad \overline{H^{r,s}(X)}=H^{s,r}(X), \] and Hodge filtration \[ F^pH^k(X,{\mathbb{C}})=\bigoplus_{r\ge p}H^{r,k-r}(X). \] Here $H^{r,s}(X)$ is the component represented by closed forms of bidegree $(r,s)$, equivalently by harmonic forms of that type after a Kähler metric has been chosen. A rational Hodge class of codimension $p$ is an element of \[ \operatorname{Hdg}^{2p}(X) :=H^{2p}(X,{\mathbb{Q}})\cap H^{p,p}(X) =H^{2p}(X,{\mathbb{Q}})\cap F^pH^{2p}(X,{\mathbb{C}}), \] where rational cohomology is identified with its image in complex cohomology. The equality uses the reality of a rational class. These conventions are those of Deligne's supplied problem description, Section 1.[E1]

If $Z\subset X$ is an algebraic subvariety of complex codimension $p$, its fundamental cycle has Poincaré dual ${\operatorname{cl}}(Z)\in H^{2p}(X,{\mathbb{Z}})$, whose complex image lies in $H^{p,p}(X)$. An algebraic cycle is a finite integral linear combination of such subvarieties. Write ${\operatorname{CH}}^p(X)$ for codimension-$p$ cycles modulo rational equivalence; the cycle-class map factors through this quotient. With ${\operatorname{CH}}^p(X)_{{\mathbb{Q}}}:={\operatorname{CH}}^p(X)\otimes_{{\mathbb{Z}}}{\mathbb{Q}}$, the exact selected assertion is \begin{equation}\label{wsref-0-68-6f-64-67-65-3a-73-74-61-74-65-6d-65-6e-74} \boxed{\quad {\operatorname{cl}}\left({\operatorname{CH}}^p(X)_{{\mathbb{Q}}}\right)=\operatorname{Hdg}^{2p}(X) \quad\text{for every smooth projective }X/{\mathbb{C}}\text{ and }0\le p\le n. \quad} \end{equation} Equivalently, for every rational Hodge class $\alpha$ there are finitely many codimension-$p$ algebraic subvarieties $Z_j$ and coefficients $q_j\in{\mathbb{Q}}$ such that $\alpha=\sum_jq_j{\operatorname{cl}}(Z_j)$. The counterexample requested at the start of the conversation would therefore have to satisfy \begin{equation}\label{wsref-0-68-6f-64-67-65-3a-63-6f-75-6e-74-65-72-65-78-61-6d-70-6c-65} X/{\mathbb{C}}\text{ smooth projective},\qquad \alpha\in\operatorname{Hdg}^{2p}(X),\qquad \alpha\notin{\operatorname{cl}}\left({\operatorname{CH}}^p(X)_{{\mathbb{Q}}}\right). \end{equation} An integral obstruction that disappears after tensoring with ${\mathbb{Q}}$, or a counterexample on a non-projective compact Kähler manifold, does not answer this question. Deligne explicitly discusses both distinctions in Section 2 of the supplied text.[E1]

Formulation and concept references: [S1], [E1]. The uploaded hodge.pdf, rather than a reported solution or a stronger variant, is the authoritative problem statement for this record.

Short English statement

On a smooth complex projective variety, must every rational cohomology class with the Hodge type of an algebraic subvariety be a rational linear combination of classes of actual algebraic subvarieties?

How the standalone .tex preserves the original progress.
The four ZIP archives are also embedded, byte-for-byte in Base64-encoded comment blocks, after this file's \end{document}. They do not affect compilation and require no special LaTeX package. The readable mathematical record above is self-contained; the embedded payload preserves the original code, full Gamma multiplication certificates, all JSON rows, the detailed README arguments, and discovery-era outputs without silently rewriting them. The companion bundle supplies extract_hodge_archives.py to recover those four ZIP files from the single .tex: 
python extract_hodge_archives.py hodge_research_complete.tex recovered_archives
The extractor verifies the recorded SHA-256 digest before writing each file. It never executes the recovered research programs. The following compact standard-library extractor is included here so that archive recovery does not depend on obtaining the companion bundle: 
from pathlib import Path
import base64, hashlib, re, sys

source, dest = Path(sys.argv[1]), Path(sys.argv[2])
dest.mkdir(parents=True, exist_ok=True)
pattern = re.compile(
    r"^% BEGIN_ARCHIVE ([\w.-]+) ([0-9a-f]{64})\n"
    r"((?:% [A-Za-z0-9+/=]+\n)+)% END_ARCHIVE\n", re.M)
for match in pattern.finditer(source.read_text(encoding="utf-8")):
    name, digest, body = match.groups()
    if Path(name).name != name:
        raise ValueError("Unsafe archive name")
    encoded = "".join(line[2:] for line in body.splitlines())
    data = base64.b64decode(encoded, validate=True)
    if hashlib.sha256(data).hexdigest() != digest:
        raise ValueError("Archive checksum mismatch")
    target = dest / name
    if target.exists() and target.read_bytes() != data:
        raise FileExistsError(target)
    target.write_bytes(data)
    print(target)
