A precise finite-range sampling rule.
For an integer $q\ge2$, let $b=\lceil\log_2 q\rceil$. Repeatedly sample $b$ independent fair bits, interpret them as $U\in\{0,\ldots,2^b-1\}$, and accept only when $U<q$. Each trial accepts with probability $p=q/2^b>1/2$ (or $p=1$ when $q$ is a power of two). For any accepted value $a$, its total probability is \[ \sum_{t=0}^{\infty}(1-p)^t2^{-b}=\frac{2^{-b}}p=\frac1q. \] The geometric series also shows termination with probability one and expected trials $1/p=2^b/q<2$. If $q=1$, return zero with no random bits. The often substituted rule $U\bmod q$ is biased unless $q\mid2^b$: writing $2^b=hq+r$, the first $r$ residues have $h+1$ preimages and the others $h$. For example, with $q=3$, two bits give probabilities $1/2,1/4,1/4$. Thus a shared group name and parameter size do not determine the challenge distribution; the exact sampling procedure matters.
Planted witness equality is the wrong validator for many actions.
Let $m\mid q$, let $G=\mathbb Z/q\mathbb Z$ act on $X=\mathbb Z/m\mathbb Z$ by reducing and adding, and fix $x=0$. For public $y\in X$, a valid transporter is any $a\in G$ satisfying $a\equiv y\pmod m$. There are exactly $q/m$ such residues: $y,y+m,\ldots,y+(q/m-1)m$. If a challenge generator samples uniform $a$ and publishes only $y$, every one of these witnesses has the same conditional probability. A solver that always returns the smallest representative solves the mathematical relation with probability one, but a grader insisting on the exact planted $a$ accepts with probability only $m/q$. This discrepancy can be arbitrarily large. It is an exact test fixture, not a security-hard instance; arithmetic in this example is deliberately easy.
What reproducibility would actually establish.
Suppose a specified generator is a deterministic function of an explicitly encoded parameter tuple and a finite random tape. Two executions with the same tuple and tape produce the same output: induction on the transitions shows identical states and identical next consumed tape symbols. This simple claim requires the same algorithm and encoding, including rejection behavior; a seed alone is not an unambiguous tape without a specified expansion rule. It proves reproducibility, not unpredictability. In fact revealing a generation tape may reveal the planted secret, so a public benchmark must distinguish instance-generation replay from the adversary's allowed information. We do not create or release any such challenge in this attempt.
