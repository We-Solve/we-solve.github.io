Subquadratic Approximation for Longest Common Subsequences

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

A common subsequence deletes symbols from each string while preserving order; longest common subsequence maximizes the retained length. An approximation for this maximization problem must preserve the stated fraction of its optimum.

Statement recorded in the supplied source.
Does there exist, for some $\varepsilon>0$, a $1.1$-approximation algorithm for the longest common subsequence of two length-$n$ strings that runs in time $O(n^{2-\varepsilon})$ for every alphabet size? [S2]

Speeding up by aligned blocks can destroy every match

Interpret a factor $1.1$ for this maximization task as producing a common subsequence of length at least $\operatorname{LCS}/1.1$. This is stated for the attempted algorithm, not imposed on every source convention. Divide both length-$n$ strings into the same consecutive blocks of size $b$, where $b\mid n$, solve LCS exactly on each pair of equally positioned blocks, and concatenate these subsequences. Standard dynamic programming on a block costs $O(b^2)$, so the total is $O(nb)$ in a unit-cost symbol-comparison model.
Proposition: Whenever $n$ is even and $b\mid n/2$, this aligned-block algorithm has an instance with true LCS length $n/2$ and output length zero.
Proof: Use $n$ distinct symbols and set \[ X=(1,2,\ldots,n),\qquad Y=(n/2+1,\ldots,n,1,\ldots,n/2). \] In $X$ every symbol of the first half precedes every symbol of the second half; in $Y$ the order of these two groups is reversed. A common subsequence therefore cannot use a symbol from each group. It can use all $n/2$ symbols from either group, so the optimum is exactly $n/2$. Because $b$ divides $n/2$, equally positioned blocks of $X$ and $Y$ lie in different symbol groups and have disjoint alphabets. Their LCS lengths are all zero, and so is their concatenation. The concatenation is always a valid common subsequence for general inputs because block orders agree, but validity supplies no approximation guarantee. ∎
For example $b$ of order $\sqrt n$ gives truly subquadratic running time for the proposed restriction while this family still has zero approximation ratio. Searching more offsets would repair this particular half-rotation, but the proof above does not show that a bounded collection of offsets handles arbitrary alignments.

Verification and remaining gaps

Exact dynamic programming was run on the full strings and aligned blocks for several divisible pairs $(n,b)$, obtaining the predicted $n/2$ versus 0. The alphabet has size $n$, which is permitted by the all-alphabet target, with symbols encoded in $O(\log n)$ bits. The primary small-alphabet approximation paper was read at abstract level and its improvements are not reproduced here.
