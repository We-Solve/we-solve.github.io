Verbatim supplied catalogue question

Let $A_1,\ldots,A_n$ and $B_1,\ldots,B_n$ be $2n$ points in the plane, and define $$f(\theta)=\min_{\pi}\sum_i\|A_i-R(\theta)B_{\pi(i)}\|^2,$$ where $R(\theta)$ is rotation about the origin. How many intervals of $\theta$ can have a constant optimal permutation, and is this number polynomially bounded? How many local minima can $f$ have, and is there a polynomial-time algorithm for finding the best rotation?

Attempt and exact reduction

Write $J(x,y)=(-y,x)$, so $R(\theta)=I\cos\theta+J\sin\theta$. For each permutation $\pi$ define \[ u_\pi=\sum_i A_i\cdot B_{\pi(i)},\qquad v_\pi=\sum_i A_i\cdot J B_{\pi(i)},\qquad z_\pi=(u_\pi,v_\pi), \] and $C=\sum_i\|A_i\|^2+\sum_j\|B_j\|^2$. Direct expansion gives \[ f(\theta)=C-2\max_\pi z_\pi\cdot(\cos\theta,\sin\theta). \] The factor two is retained; the source's informal expansion suppresses a constant factor. Put $P=\operatorname{conv}\{z_\pi\}$. A linear functional has the same maximum on this hull and its generating points, by the defining convex-combination inequality. Thus $f$ is determined by the planar support function of $P$. For every vector $z$, Cauchy--Schwarz gives $\max_\theta z\cdot(\cos\theta,\sin\theta)=\|z\|$, with equality at its direction if nonzero and everywhere if zero. Interchanging two maxima (one over a finite set) therefore yields \[ \min_\theta f(\theta)=C-2\max_\pi\sqrt{u_\pi^2+v_\pi^2}. \] Enumerating permutations and evaluating this formula is an exact finite algorithm, but it still has $n!$ candidates. Linear optimization over $P$ for a supplied direction, which is an assignment problem, does not by itself bound the number of vertices or solve this convex maximization in polynomial time.
What can be said about intervals and local minima without a size bound.
After merging identical $z_\pi$, a full-dimensional polygon with $h$ vertices has $h$ open intervals of directions on which a particular vertex is uniquely exposed. To see this, the normal directions selecting vertex $z$ satisfy $(z-w)\cdot u\ge0$ for all $w\in P$. They form its convex normal cone; in the plane, for a polygon vertex the cone is the closed angular interval between its two incident outward edge normals. The interior exposes only that vertex; the finitely many boundary directions expose edges. These cones cover all directions since every linear functional attains a maximum. For a segment there are two open half-circle intervals and two exceptional perpendicular directions; for a singleton all directions have the same value. Hence the number of these canonical open intervals is at most $n!$. Several permutations can yield the same vector and tie throughout an interval; an arbitrary oscillating tie choice would have no intrinsic interval count. This is why the canonical cost-vector convention is made explicit.

If $\theta_0$ is a local minimum of $f$, every active branch $g_\pi(\theta)=C-2z_\pi\cdot(\cos\theta,\sin\theta)$ is also locally minimized there: $g_\pi\ge f\ge f(\theta_0)=g_\pi(\theta_0)$ nearby. A nonconstant branch has precisely one local minimum per circle, at the direction of $z_\pi$. A strict local minimum cannot have an active constant branch, since that would force $f$ both at most and at least the same constant nearby. Therefore there are at most $n!$ strict local minima, among the nonzero candidate directions. Nonstrict local minima can instead be infinite: if every $A_i=0$, $f$ is constant. This elementary degeneracy does not settle the source's substantive generic-case counting question.

Polynomial interval bound when one point set is collinear.
Suppose $A_i=c+a_i e$ for fixed unit vector $e$. The term $c\cdot R(\theta)\sum_jB_j$ is independent of the permutation. The remaining score is $\sum_i a_i t_{\pi(i)}(\theta)$, where $t_j(\theta)=e\cdot R(\theta)B_j$. Sort the $a_i$ increasingly. If $a_i\le a_j$ but the assigned values satisfy $t_{\pi(i)}>t_{\pi(j)}$, swapping their assignments changes the score by $(a_j-a_i)(t_{\pi(i)}-t_{\pi(j)})\ge0$. Repeatedly removing inversions proves that matching the two sorted lists is optimal. For distinct $B_j,B_l$, the difference $t_j-t_l$ is a nonzero sinusoid and vanishes at two angles per full circle; coincident points have an identical projection and may be tied consistently. Thus all projection orders are fixed between at most $2\binom n2$ event angles. On each such interval the selected optimal permutation and its sinusoidal score are fixed. The best value on its closed interval is attained at an endpoint or at its stationary minimizing direction, so finitely checking these candidates solves this restricted problem. Sorting events and recomputing a sorted matching on each interval gives, conservatively, $O(n^3\log n)$ real-arithmetic operations, including all endpoint/branch checks. Algebraic event-direction comparisons and square roots are charged in this real-arithmetic model; no general bit-complexity theorem is inferred.
