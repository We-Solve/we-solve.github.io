Minimal Assumptions for Additive Randomized Encodings

Definitions and mathematical statement

Shared notation.
Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.

An additive randomized encoding locally maps each party's input into group elements whose aggregate permits decoding the desired output while hiding additional input information. Computational privacy is indistinguishability from a simulator based on the prescribed output.

The source and the checked primary Bitansky--Erabelli--Garg abstract already report ARE constructions from public-key encryption. That is an attributed upper assumption, not a proof of minimality. This attempt asks whether computational hardness could rescue a much simpler model in which every local encoding is deterministic after public setup and there are no hidden coins.

A quantitative public-setup obstruction

Let $R$ be public random setup and let efficient deterministic maps $a_x(R),b_y(R)$ take values in an efficiently represented Abelian group. The visible sum is $S_{xy}(R)=a_x(R)+b_y(R)$, and the decoder sees $(R,S)$. Assume for each input the probability of wrong decoding of AND is at most $\delta$. Suppose each of the two efficiently computable comparison tests \[ (R,S)\longmapsto\mathbf1\{S\ne a_0(R)+b_0(R)\} \] has distinguishing advantage at most $\varepsilon$ between the input pairs $(0,0),(0,1)$ and $(0,0),(1,0)$, respectively. Full computational privacy would in particular bound these tests.
Proposition: Necessarily $2\delta+2\varepsilon\ge1$.
Proof: The test always returns zero on $(0,0)$, so the assumed advantages imply $\Pr_R[S_{01}\ne S_{00}]\le\varepsilon$ and $\Pr_R[S_{10}\ne S_{00}]\le\varepsilon$. With probability at least $1-2\varepsilon$, both equalities hold. Cancellation in the group then gives $b_1=b_0$ and $a_1=a_0$, so $S_{11}=S_{00}$ on this event.

Couple the decoder's internal randomness identically for the $(0,0)$ and $(1,1)$ cases (or use a deterministic decoder). By the union bound, with probability at least $1-2\delta$ both decodings are correct. The intersection of this event and the preceding setup event has probability at least $1-2\varepsilon-2\delta$. But on that intersection the decoder sees the same public setup and sum and uses the same coins, yet must output two different bits. The intersection is empty, proving the inequality. ∎

Thus negligible decoding error and negligible computational privacy error cannot coexist in this all-public-coins deterministic-local model, regardless of a hypothesized hard problem: the distinguishing test is an elementary efficient equality comparison. The attempted shortcut of replacing hidden randomized encodings by deterministic public transforms fails before hardness assumptions become relevant.

Verification and remaining gaps
