Finding distinct marked inputs: verified exclusion and the duplicate-sampling cost

Definitions and mathematical statement

Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

An input is marked when $f(x)=1$. The requested output is m pairwise distinct marked inputs; repeating an earlier output does not count. Query complexity measures calls to f, with the domain size and number of marked inputs affecting the search cost.

Verbatim supplied catalogue question

Find $x,y$ distinct with $f(x) = f(y) = 1$. Consider the case where there are many solutions at low density. How quickly can this be done? Faster than Grover?

More generally, find distinct $x_1,\dots, x_m$ such that $f(x_1) = \dots = f(x_m) = 1$. Can you do better than $m$ preimage searches?

Attempt and results

Assume a Boolean oracle on a domain of size $N$, with a known exact number $K$ of marks, where $1\le K\le N/2$, and request $1\le m\le K$ distinct outputs. These are explicit restrictions absent from the full source. We prove an expected-cost baseline with exclusion and contrast it with repeated search that ignores already found outputs. No matching general lower bound or unknown-count implementation is claimed.
A verified search stage with a uniform success bound.
Suppose $j$ distinct marks have been found. Define a predicate that accepts exactly the marked points outside that stored list, leaving $k=K-j$ marks. Its phase flip can be made by computing the Boolean oracle, checking the classical list reversibly, applying a sign, and uncomputing. This costs two oracle queries per phase flip; comparison-gate cost is separate. Put $\theta=\arcsin\sqrt{k/N}\le\pi/4$. In the span of uniform good and bad states, the uniform initial state has coordinates $(\sin\theta,\cos\theta)$. The phase flip followed by reflection in that initial state has matrix $\left(\begin{smallmatrix}\cos2\theta&\sin2\theta\\-\sin2\theta&\cos2\theta\end{smallmatrix}\right)$. The angle-addition formulas therefore give success probability $\sin^2((2r+1)\theta)$ after $r$ iterations. Choose a nonnegative integer $r$ nearest to $\pi/(4\theta)-1/2$. Then $|(2r+1)\theta-\pi/2|\le\theta$, so success probability is at least $\cos^2\theta\ge1/2$. Also $r\le\pi/(4\theta)\le(\pi/4)\sqrt{N/k}$, since $\arcsin u\ge u$ for $0\le u\le1$ (its derivative is at least one). Measure a candidate and verify with one additional Boolean query; reject an unmarked or previously stored point and restart the stage independently. The number of trials is geometric with mean at most two, and each trial uses $2r+1\le(\pi/2+1)\sqrt{N/k}$ queries. Thus the expected stage cost is at most $C\sqrt{N/k}$ for the explicit constant $C=\pi+2$.
Expected total and one global cutoff.
Linearity of conditional expectation, applied successively to the completed stages, bounds the expected total query count by \[ C\sqrt N\sum_{j=0}^{m-1}(K-j)^{-1/2}. \] No independence between stages is needed, because the bound depends only on the known remaining count. Each summand is at least $1/\sqrt K$, while monotonicity of $x^{-1/2}$ gives \[ \sum_{l=K-m+1}^K l^{-1/2} \le\int_{K-m}^{K}x^{-1/2}\,dx =2(\sqrt K-\sqrt{K-m}) =\frac{2m}{\sqrt K+\sqrt{K-m}} \le\frac{2m}{\sqrt K}. \] The integral at zero is finite when $m=K$. Hence the sum lies between $m/\sqrt K$ and $2m/\sqrt K$, and the algorithm has expected query cost at most $2Cm\sqrt{N/K}$, including $O(\sqrt{NK})$ at $m=K$. For $0<\delta<1$, abort after the ceiling of the proved expectation bound divided by $\delta$. Markov's inequality follows directly from $\mathbb E T\ge a\Pr(T>a)$ for nonnegative $T$ (or by an arbitrarily small limiting adjustment), and gives failure probability at most $\delta$. All outputs retained before success were explicitly verified, so aborting never converts an invalid point into a claimed mark. The memory and comparison-gate costs of exclusion are not included in this query bound.
Why ignoring duplicates can introduce an avoidable logarithm.
If independent successful searches always return uniform points from all $K$ marks, then after $j$ distinct marks the probability of a new one is $(K-j)/K$. The expected number of successful search outputs required for the next distinct mark is therefore $K/(K-j)$, by the geometric-series calculation. Collecting all $K$ requires $K\sum_{l=1}^K1/l$ such outputs in expectation. The harmonic sum is at least $\int_1^{K+1}dx/x=\log(K+1)$, so this version incurs a coupon-collection overhead. Exclusion changes the predicate and avoids those duplicate outputs. This is an improvement over that specific implementation, not a proof of a better asymptotic bound than every strategy for $m$ preimages.

Context, adversarial audit, and gap

The exact original question was read on printed page 3 of the workshop report. The primary Boyer--Brassard--Hoeyer--Tapp abstract discusses unknown-count search, but that algorithm and its proof were not imported into this known-count baseline. The audit checked $m=K$, integral endpoints, verification queries, unknown-count restrictions, and the separation between query and gate costs. An attempted lower bound obtained by multiplying a one-output search lower bound by $m$ would need a direct-product argument for adaptive shared queries; none is proved here, so no optimality conclusion follows from the upper bound. No numerical simulation or quantum implementation was run.
