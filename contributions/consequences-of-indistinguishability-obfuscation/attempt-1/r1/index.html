Indistinguishability obfuscation: conditional canonization and an inversion gap

Verbatim supplied catalogue question

The indistinguishability obfuscation conjecture asserts the feasibility of obfuscating functionally equivalent programs so their obfuscations cannot be distinguished; what are its precise consequences and relations to one-way functions and $P\neq NP$?

Source scope and the attempted implication

The workshop introduction on printed page 3052 remarks that the indistinguishability-obfuscation conjecture does not itself supply one-way functions or a $P\ne NP$ assertion. The catalogue asks broadly for precise consequences rather than stating a single equivalence. We rederive the standard $P=NP$ conditional explanation and examine an elementary attempt to extract a one-way function. No unconditional obfuscator or separation is constructed.

Under P equals NP, circuit canonization is efficient

Fix a standard finite Boolean circuit encoding, with specified input and output arities. For two such circuits, nonequivalence has an NP witness: an input on which their evaluations differ. If $P=NP$, nonequivalence, and hence its complement equivalence, is decidable in polynomial time.

Given a circuit $C$ of size $s$, choose a fixed encoding length $L(s)$ polynomial in $s$, with padding and an explicit end marker, sufficiently large to encode every circuit of size at most $s$ with those arities. Let valid candidate strings describe circuits of size at most $s$ and length $L(s)$. At least one candidate represents $C$. For a candidate prefix $p$, the predicate \[ \exists D\;[D\text{ is a valid candidate beginning with }p \text{ and }D\equiv C] \] is in NP under the assumed polynomial equivalence test: guess the remaining bits and verify validity and equivalence. Thus it too is in P under $P=NP$. Starting with the empty prefix, choose a zero next bit if the predicate remains true, and otherwise choose one. Induction preserves the existence of a completion, and after $L(s)$ steps produces the lexicographically first valid equivalent candidate. The number of calls and each call's input length are polynomial in $s$.

Define the output to be that candidate circuit. It computes precisely the input's function and has size at most $s$. Equivalent circuits with the same size and arities have exactly the same candidate set and therefore identical outputs. Their output distributions have statistical distance zero, even against unbounded distinguishers. Ignoring a security parameter is permissible here, since security is perfect. This proves a deterministic perfect indistinguishability obfuscator conditional on $P=NP$, in the same-size circuit formulation. It does not claim efficient computation of a minimum circuit without that assumption.

Under the same assumption, one-way functions cannot exist

Let $f$ be any deterministic polynomial-time function on binary strings. Given $y=f(x)$ and $1^n$, where $|x|=n$, a prefix $p$ has an extension mapping to $y$ precisely when \[ \exists z\in\{0,1\}^{n-|p|}\quad f(pz)=y. \] This is an NP predicate and hence polynomially decidable under $P=NP$. The same bitwise search finds a length-$n$ preimage for every $y$ in the image of length-$n$ strings. Its time is polynomial in $n+|y|$; the image length is polynomial in $n$. Its inversion success probability on a random length-$n$ input is one. This contradicts any usual one-wayness requirement for $f$.

Together the two arguments give \[ P=NP\quad\Longrightarrow\quad \text{perfect efficient iO exists and no one-way function exists}. \] This is a conditional theorem, not a proof of a model of arithmetic in which $P=NP$ holds, nor an unconditional logical independence result. Indeed an unconditional theorem "iO implies $P\ne NP$," combined with the conditional canonization proof, would itself imply $P\ne NP$ by contradiction. The broad catalogue cannot be declared solved by simply assuming a resolution of that separation.

A concrete failed extraction of a one-way function

Try to encode a secret $s\in\{0,1\}^n$ in a circuit $C_s$ which prints $s$, and publish its obfuscation. Correctness defeats this candidate: evaluating the published circuit on any legal input returns $s$. If obfuscation is randomized and its coins are included in the proposed function's input, this argument recovers the embedded secret, but need not recover coins producing the exact published encoding; hence it is not by itself an inverter for that different function. The precise failure is that this construction cannot hide the secret or justify one-wayness merely through iO. Distinct $C_s$ compute distinct functions, so iO makes no indistinguishability promise between them. With a deterministic obfuscator, including the conditional one above, evaluation recovers a full input preimage and the candidate map is explicitly invertible. A randomized coin-based candidate needs an additional argument which this route does not supply.

Model-assisted audit and remaining scope

The audit checked the two successive uses of $P=NP$, the common size bound needed for canonical outputs, preimage-length input, and the difference between recovering a secret and inverting randomized coins. The conditional implications are known elementary mechanisms, not new cryptographic results. We have not classified iO consequences under other assumptions, built iO unconditionally, or proved a complexity separation. No numerical experiment or theorem prover was used.
