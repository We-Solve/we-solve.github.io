Mixed-integer convex search: exact one-dimensional bisection and a coordinate trap

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Mixed-integer convex optimization minimizes a convex function over a convex feasible set intersected with $\mathbb Z^n\times\mathbb R^d$. In an oracle model, information complexity counts oracle answers needed to obtain the specified additive accuracy, while running time includes the work between queries. The source uses bounded feasible regions, Lipschitz objective control, and a strict-feasibility parameter to state its bounds, with first-order and separation access.

The proposed extension of one-dimensional search

The source distinguishes oracle queries from all computation and specifies radius, Lipschitz control, fiber feasibility and accuracy. We study an elementary one-integer-variable algorithm and then test extending it by coordinatewise minimization. The resulting obstruction satisfies convexity and has a simple feasible region; it is not a lower bound on all methods using general lattice directions or cuts.
Exact discrete convex minimization in one dimension.
Let $g$ be a finite convex real function on $[a,b]$, where $a<b$ are integers, and suppose exact function-value queries and comparisons are available. Put $\delta_k=g(k+1)-g(k)$ for $a\le k<b$. Convexity at the midpoint $k+1$ gives $2g(k+1)\le g(k)+g(k+2)$, hence $\delta_k\le\delta_{k+1}$. Binary search therefore finds the first $k$ with $\delta_k\ge0$ using $O(\log(b-a+1))$ comparisons, each using two value queries. If there is no such index, $g$ strictly decreases at every integer step and $b$ is a minimizer. Otherwise all earlier differences are negative and all later ones nonnegative, so this first $k$ minimizes $g$ on the integer interval. Plateaus and endpoint minima are included; a one-point interval is immediate. The index arithmetic uses $O(\log(|a|+|b|+2))$ bits, so has polynomial cost in the endpoint binary lengths. The statement counts exact oracle access, not a bound on the cost of supplying or comparing arbitrary real oracle answers.
Partial minimization is convex but not automatically cheap.
For a convex feasible set $C\subseteq\mathbb R^{n+d}$ and convex $f$, define $\phi(x)=\inf\{f(x,y):(x,y)\in C\}$, with value $+\infty$ for an empty fiber. Where the infima are finite, $\phi$ is convex. Indeed take points in two fibers with values within $\eta>0$ of their infima. Their convex combination is feasible by convexity of $C$, and convexity of $f$ bounds its value by the same combination of the two values. Taking the infimum in the intermediate fiber and then letting $\eta$ tend to zero proves the inequality. If an infimum is $-\infty$, the same argument uses arbitrarily low fiber values with the appropriate extended-value qualifications. For the bounded promised optimization setting the finite case is the relevant one. This calculation does not give an inexpensive evaluation oracle for $\phi$, or certify all empty fibers. Those operations would require their own algorithms and error budgets.
Coordinatewise integer optimality is insufficient.
Fix $0<\gamma<1$ and minimize \[ f(x_1,x_2,y)=(x_1-x_2)^2-\gamma(x_1+x_2)+y^2 \] on $C=[0,1]^2\times[-1,1]$, with the first two coordinates integer and the last continuous. This is convex: a squared linear form and a square are convex by $(\theta u+(1-\theta)v)^2\le\theta u^2+(1-\theta)v^2$, whose difference is $\theta(1-\theta)(u-v)^2\ge0$; the remaining term is linear. On each integer fiber the best $y$ is zero. The four resulting values are \[ f(0,0,0)=0,\quad f(1,0,0)=f(0,1,0)=1-\gamma>0, \quad f(1,1,0)=-2\gamma<0. \] Thus $(0,0,0)$ is a strict optimum against either individual integer-coordinate change and against all continuous changes, but is not a global mixed-integer optimum. The diagonal move improves it. The region is contained in the radius-one infinity-norm box; every optimal integer fiber contains a continuous interval of radius one; and $y\mapsto y^2$ is Lipschitz with constant two on that interval, since $|y^2-z^2|=|y-z||y+z|\le2|y-z|$. Hence the example is compatible with the corresponding basic source promises rather than exploiting a missing feasibility margin.

Audit and computational gap

The primary oracle model and comparison of query and algorithmic complexity on printed pages 2939--2941 were inspected. The one-dimensional binary search attains logarithmic query count in its stated special model, but independent coordinate searches do not extend its correctness. Computing sufficient directions or effective integer-valid cuts with the desired total cost is precisely missing. We do not replace the source bound by grid enumeration, which can depend polynomially on the numerical radius rather than its logarithm. No numerical oracle experiment or performance benchmark was run, and no general matching running-time bound is established.
