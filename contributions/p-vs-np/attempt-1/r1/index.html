P vs. NP

Definitions and mathematical statement

A decision problem is a language $L\subseteq\{0,1\}^*$ of finite binary strings. Its input size is the string length $|x|$. The class $\mathrm P$ consists of languages decided by a deterministic Turing machine in at most $C(|x|+1)^c$ steps for some fixed constants $C,c$. The machine must halt and answer correctly on every input.

A language belongs to $\mathrm{NP}$ if there are a polynomial $p$ and a deterministic polynomial-time predicate $V$ such that \[ x\in L\quad\Longleftrightarrow\quad \exists y\in\{0,1\}^{\le p(|x|)}\quad V(x,y)=1. \] The string $y$ is a certificate for a yes-instance. Its length and the verification time are bounded by fixed polynomials, uniformly over all inputs. The problem is to decide whether $\mathrm P=\mathrm{NP}$. Since $\mathrm P\subseteq\mathrm{NP}$, inequality means exhibiting a language in $\mathrm{NP}$ with no deterministic polynomial-time decision procedure.

The question uses the ordinary uniform, worst-case bit model of computation. It does not permit a separate uncomputable advice string for each input size or replacement by a quantum algorithm. Efficient verification for no-instances is not part of the definition of $\mathrm{NP}$. Polynomial-time solution of every input, rather than success on a selected distribution of inputs, is required.

Short English statement

Does every decision problem with efficiently checkable yes-certificates also admit an efficient deterministic decision algorithm?

Research attempt

The target is the ordinary uniform worst-case question $\mathrm P=\mathrm{NP}$. This attempt tests a possible lower-bound route: split inputs into two blocks, build a truth-value matrix, and infer a large circuit from exponential matrix rank. The inference fails even on a language with a uniform linear-time algorithm. Establishing that failure does not separate $\mathrm P$ from $\mathrm{NP}$.

For $n\ge1$ define $\operatorname{EQ}_n(x,y)=1$ if $x=y$ and zero otherwise, for $x,y\in\{0,1\}^n$. Let $M_n$ be its $2^n$-by-$2^n$ matrix, with rows indexed by $x$, columns by $y$, in the same order, over the real field.

Proposition: $\operatorname{rank}_{\mathbb R}M_n=2^n$, but $\operatorname{EQ}_n$ has a circuit with at most $6n-1$ gates from $\{\mathrm{AND},\mathrm{OR},\mathrm{NOT}\}$, with the binary gates of fan-in two. The corresponding equality language is in $\mathrm P$.
Proof: $M_n$ is the identity matrix: the entry is one exactly when its row and column labels agree. Its columns are linearly independent, proving the rank assertion. For each coordinate use \[ e_i=(x_i\wedge y_i)\vee(\neg x_i\wedge\neg y_i). \] This uses two NOT gates, two AND gates and one OR gate. Combining all $e_i$ by $n-1$ AND gates gives $5n+n-1$ gates, and evaluates to one precisely when every pair agrees. A deterministic machine can scan the two explicitly delimited strings, compare their lengths and compare the corresponding symbols in polynomial time (linear time with two input heads). Thus the language is uniformly in $\mathrm P$; no uncomputable advice is involved. ∎
What the rank actually lower-bounds.
If a function has a representation $f(x,y)=\sum_{j=1}^r a_j(x)b_j(y)$ over the reals, its matrix has rank at most $r$, because each summand has all columns proportional to one vector and the total column space lies in the span of the $r$ vectors $a_j$. Conversely, if a matrix has rank $r$, choose $r$ basis columns; expressing every column in that basis yields exactly such a sum of $r$ outer products. Therefore matrix rank is precisely a lower bound on this separable-sum representation. It is not a lower bound of comparable magnitude on arbitrary Boolean circuits. The equality circuit combines simple cross-block tests with products; expanding those products into a separable sum can create exponentially many terms.

For contrast, a deterministic one-way communication protocol in which Alice knows $x$, Bob knows $y$, and Alice sends a fixed-length message must send at least $n$ bits for exact equality. If two different $x,x'$ induce the same message, Bob on $y=x$ receives the same information for the accepting pair $(x,x)$ and rejecting pair $(x',x)$, a contradiction. Thus there must be at least $2^n$ messages. This proof identifies another genuinely restricted model. It supplies only a linear communication bound, consistent with the linear circuit, and no superpolynomial time lower bound.

Verification and remaining gaps

The script constructed identity matrices for $n=1,\ldots,8$ and numerically recovered ranks $2,4,\ldots,256$. The algebraic proof already establishes every $n$; these matrix checks are diagnostic only. The gate count was checked at $n=1$, where no final combining gate is needed. The audit separated a uniform machine from circuit families and identified exactly which restricted representation matrix rank controls. To repair this route one would need an invariant that remains bounded for every polynomial-time computation yet grows superpolynomially for a particular NP language; no such invariant or argument is supplied. A large rank alone cannot be that invariant because equality is a counterexample.
