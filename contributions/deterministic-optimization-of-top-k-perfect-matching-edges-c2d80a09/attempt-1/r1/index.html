Top-k perfect matching: extendable subsets and a failed threshold minimax swap

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

A perfect matching is a set of disjoint edges covering every vertex exactly once. If its edge weights in nonincreasing order are $w_1\geq\cdots\geq w_t$, its top-$k$ objective is $\sum_{i=1}^kw_i$, with $0\leq k\leq t$. The input weights are finitely encoded, and polynomial time is measured in their binary length and the graph size.

Statement recorded in the supplied source.
Given a weighted graph and an integer $k$, is there a deterministic polynomial-time algorithm that finds a perfect matching maximizing the total weight of its $k$ heaviest edges? [S2]
Scope qualification.
The question asks for a deterministic algorithm on general graphs, and does not restrict to bipartite graphs. If no perfect matching exists the algorithm must detect infeasibility.

Verbatim supplied catalogue question

Given a weighted graph and an integer $k$, is there a deterministic polynomial-time algorithm that finds a perfect matching maximizing the total weight of its $k$ heaviest edges?

The source graph class and the catalogue target

The primary passage explicitly starts with a bipartite graph, whereas the catalogue asks about weighted graphs generally. The identities and counterexample below apply to either class; the counterexample itself is bipartite. The explicit matching-feasibility routine used for the fixed-$k$ enumeration is justified for bipartite graphs. No unrestricted deterministic algorithm for varying $k$ is claimed.
Exact equivalence with extendable partial matchings.
Suppose a graph has a perfect matching with $t$ edges and $0\le k\le t$. Let $\mathcal R_k$ be the $k$-edge sets contained in some perfect matching. Then \[ \max_M\operatorname{top}_k(M)= \max_{R\in\mathcal R_k}\sum_{e\in R}w_e. \] For any perfect matching, its $k$ heaviest edges belong to $\mathcal R_k$, proving one inequality. Conversely any $R$ in that family extends to a matching $M$, and the sum of the largest $k$ weights in $M$ is at least the sum on that particular $k$-subset, proving the other. Negative weights and ties cause no change to these two comparisons. For $k=0$ both objectives are zero once feasibility is established.

For fixed $k$, enumerate all $k$-subsets of edges, discard those sharing an endpoint, delete the endpoints of each remaining set and test whether the residual graph has a perfect matching. This is exactly the extension test: its union with $R$ is perfect if and only if the residual matching is perfect. In a bipartite graph a maximum matching is found by repeatedly augmenting along alternating paths. Correctness follows because the symmetric difference with any larger matching has an augmenting path component; each search and the at most $|V|/2$ augmentations have polynomial cost. Hence enumeration takes $|E|^{O(k)}$ time and is polynomial for every fixed $k$. It is not a polynomial bound when $k$ is part of the input, since the exponent depends on $k$.

The threshold identity and the tempting illegal exchange.
For real numbers $a_1\ge\cdots\ge a_t$ and $1\le k<t$, \[ \sum_{i=1}^k a_i =\min_{\theta\in\mathbb R} \left(k\theta+\sum_{i=1}^t\max\{a_i-\theta,0\}\right). \] For any $\theta$, each of the first $k$ terms is at most $\theta+\max\{a_i-\theta,0\}$; summing and including the remaining nonnegative terms gives the upper-bound direction. If $a_{k+1}\le\theta\le a_k$, the first $k$ positive parts sum to $\sum_{i\le k}(a_i-\theta)$ and all remaining parts vanish, proving equality. This identity for one matching does not allow interchanging the maximum over matchings with this minimum over thresholds.
An exact bipartite minimax gap.
Take a six-cycle. It has exactly two perfect matchings, its two alternating triples: choosing the edge covering one vertex forces successive choices around the cycle, giving precisely these two. Give one triple weights $(10,0,0)$ and the other $(6,6,6)$, and set $k=2$. Their top-two values are ten and twelve, so the true optimum is twelve. For $0\le\theta\le6$ their threshold objectives are $10+\theta$ and $18-\theta$. The maximum is minimized at $\theta=4$ with value fourteen. For $\theta<0$ the second objective is $18-\theta>18$; for $6\le\theta\le10$ the first is $10+\theta\ge16$; and for $\theta\ge10$ both are $2\theta\ge20$. Consequently \[ \max_M\min_\theta\Phi(M,\theta)=12 \quad\hbox{but}\quad \min_\theta\max_M\Phi(M,\theta)=14. \] The inner maximization at fixed threshold is an ordinary weighted matching objective, but solving that family of objectives optimizes the displayed upper bound, not an equal reformulation of the original problem. This explicit gap blocks that proposed proof of a deterministic solution; it does not exclude other threshold-based algorithms with an additional argument.
