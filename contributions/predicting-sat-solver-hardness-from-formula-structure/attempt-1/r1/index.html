Research attempt: A clause-space calculation and solver-dependent search examples

Constant clause space with unbounded proof length
For $n\geq1$ use the unsatisfiable chain \[ F_n=\{x_1,\ \neg x_1\vee x_2,\ldots,\neg x_{n-1}\vee x_n,\ \neg x_n\}. \] In resolution, a configuration stores clauses; an inference adds a resolvent of two currently stored clauses, and clauses may be erased. Count input-clause downloads and inferences in proof length, and the maximum number of stored clauses in clause space. Starting from the unit $x_1$, download $\neg x_i\vee x_{i+1}$, resolve to $x_{i+1}$, and erase the old unit and binary clause. At most three clauses are stored. Finally download $\neg x_n$ and derive the empty clause, again within space three. This gives a linear-length, constant-space refutation.

Every input clause is essential to unsatisfiability. Removing $x_1$ permits the all-zero assignment; removing $\neg x_n$ permits all ones. Removing the implication $\neg x_i\vee x_{i+1}$ permits $x_1=\cdots=x_i=1$ and $x_{i+1}=\cdots=x_n=0$. Thus any resolution refutation must download all $n+1$ input clauses: otherwise it would refute a satisfiable subset. Resolution soundness used here follows directly because any assignment satisfying both $A\vee x$ and $B\vee\neg x$ satisfies $A\vee B$; induction propagates satisfaction through all inferences. Consequently proof length is at least $n+1$ despite the uniform space-three upper bound.

This is not a difficult SAT family; unit propagation solves it efficiently. Its purpose is to show that clause space alone, without formula size or the proof system, cannot upper-bound even elementary reading/proof length by a constant depending only on that space.

A fixed search order can dominate superficial structure
Consider exhaustive search that tests assignments in lexicographic order with zero before one and stops at the first satisfying assignment. The formulas \[ A_n=\bigwedge_{i=1}^n\neg x_i,\qquad B_n=\bigwedge_{i=1}^n x_i \] have the same numbers of variables, clauses and literal occurrences and the same clause width. They differ only by globally complementing all variables. The specified search checks one assignment for $A_n$ and all $2^n$ assignments for $B_n$, because each has a unique satisfying assignment at the corresponding end of the order. A unit-propagation solver, however, fixes every variable immediately in either formula and uses only linear work in their explicit size. This is an exact comparison for the two stated algorithms, not a claim about modern solver heuristics.
The missing general measure
For unsatisfiable inputs, proof-space lower bounds refer to a chosen proof system and constrain algorithms whose executions yield proofs in that system. Satisfiable inputs instead need a witness search criterion; resolution refutation space is not defined as a finite refutation resource for them. The examples above also show that input size and algorithmic invariances cannot be discarded. To turn the report's proposal into a predictive theorem one must specify the solver, representation, input distribution or worst-case quantifiers, and the relation between memory space and elapsed search. No such universal relation is proved by these elementary families.
