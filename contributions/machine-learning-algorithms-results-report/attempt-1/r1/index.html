A small class can be learned by exhaustive search

The original talk already gives positive examples in machine learning and asks a broad research-program question. We test a restricted explanation for when a theoretically justified learner is efficient. Let $\mathcal H$ be an explicitly enumerable finite family of $M\ge1$ binary functions. Assume the target $h_*$ belongs to this family, training inputs are independent with common distribution $P$, and labels are exactly $h_*(x)$. Choose any hypothesis having zero training error.
Proposition: For $0<\alpha,\delta<1$, if $n\ge(\log M+\log(1/\delta))/\alpha$, every training-consistent hypothesis has true error at most $\alpha$ with probability at least $1-\delta$. Exhaustive search costs at most $nM$ hypothesis evaluations.
Proof: Fix $h\in\mathcal H$ of true error $p>\alpha$. Independence gives probability $(1-p)^n\le e^{-\alpha n}$ that it is consistent with all $n$ labels. Taking the union bound over at most $M$ hypotheses bounds the probability of any bad consistent one by $Me^{-\alpha n}\le\delta$. A consistent hypothesis always exists because $h_*\in\mathcal H$. Testing every hypothesis on every example proves the cost bound. ∎
For a worked case take a uniform two-point input space, target identically zero, and all four binary functions as $\mathcal H$. For $n\ge1$, a hypothesis with positive error remains consistent exactly when at least one input point was never sampled. These two missing-point events are disjoint and have total probability $2^{1-n}$. This can be checked by listing all $2^n$ input sequences. The proposed shortcut from a logarithmic sample dependence on $M$ to a logarithmic running time fails: the proof uses an exhaustive search costing $M$, and supplies no efficient optimization oracle. If $M=2^d$, that cost is exponential in $d$. No general lower bound is claimed; particular classes can have much better algorithms.
