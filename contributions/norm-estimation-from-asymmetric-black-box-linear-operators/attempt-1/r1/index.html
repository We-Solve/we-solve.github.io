Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

For a linear map $A$ between finite-dimensional inner-product spaces, $A^*$ is its adjoint and $\lVert A\rVert=\sup_{\lVert x\rVert_2=1}\lVert Ax\rVert_2$ is the induced operator norm. A black-box query evaluates the supplied map on a chosen vector without exposing its matrix. The first access model supplies $A$ but not $A^*$. In the second, $A$ and $V$ have the same domain and codomain and only evaluations of $A$ and $V^*$ are supplied. Convergence means estimates approach the requested norm as the iteration or query budget grows.

Statement recorded in the supplied source.
Given black-box access to $x\mapsto Ax$ but not to $A^*$, can $\lVert A\rVert$ be estimated by a provably convergent low-memory method? Likewise, can $\lVert A-V\rVert$ be estimated using only black boxes for $A$ and $V^*$? [S2]
Scope qualification.
Low memory is relative to the operator dimensions and the numerical representation in the cited report. No unavailable adjoint or full matrix storage is assumed.

Research attempt: Low-memory random search, Ritz improvement, and missing upper certificates

A finite-dimensional random-plane route using only $A$.
Let $A:\mathbb R^n\to\mathbb R^m$ with $m,n\geq1$, use Euclidean norms, and assume exact oracle products. Maintain a unit vector $v$ and its image $Av$. At step $j$, sample an independent uniform unit vector $x_j$ and query $Ax_j$. Maximize $\|Aw\|^2$ over unit vectors in $\operatorname{span}\{v,x_j\}$ and replace $v$ by a maximizer. If the vectors are dependent this is a one-dimensional problem. Otherwise orthonormalize them, carrying out the same linear combinations on their two known images, and maximize the resulting symmetric $2\times2$ Gram matrix Rayleigh quotient. The eigenvalues are the two roots of its quadratic characteristic polynomial; an associated unit eigenvector gives the required linear combination. This uses a constant number of input/output vectors, $O(n+m)$ real-number memory, and no adjoint oracle or stored matrix.

Let $R_j=\|Av_j\|^2$. The old vector and the new random direction are both candidates, so \[ R_j\geq R_{j-1},\qquad R_j\geq\|Ax_j\|^2,\qquad R_j\leq\|A\|^2. \] For each $\varepsilon>0$, continuity and existence of a maximizing unit vector imply that the set $\{x:\|Ax\|^2>\|A\|^2-\varepsilon\}$ contains a nonempty relatively open part of the sphere, and hence has uniform probability $p_\varepsilon>0$. To see positivity directly, generate the uniform direction by normalizing a standard Gaussian vector: an open ball about a nonzero representative has positive Gaussian density and maps into a sufficiently small spherical neighborhood. Independence gives \[ \Pr\{R_j\leq\|A\|^2-\varepsilon\}\leq(1-p_\varepsilon)^j. \] The event that the nondecreasing sequence never exceeds that threshold has probability zero by taking $j\to\infty$. Intersecting these probability-one statements for $\varepsilon=1,1/2,1/3,\ldots$ proves $R_j\to\|A\|^2$ almost surely. In fact keeping only the largest observed $\|Ax_j\|$ also converges; the Ritz step adds monotonic local improvement. This elementary proof is a convergence statement, not a practical rate theorem: $p_\varepsilon$ may be very small.

The mismatch uses a scalar observable.
Let $V$ have the same dimensions, with only $V^*$ accessible. For independently sampled uniform unit vectors $u_j\in\mathbb R^m$, $v_j\in\mathbb R^n$, compute \[ z_j=\left|u_j^TAv_j-(V^*u_j)^Tv_j\right|, \qquad L_j=\max_{1\leq i\leq j}z_i. \] This needs one product with each available oracle and a constant number of vectors. Put $B=A-V$. By Cauchy--Schwarz, $|u^TBv|\leq\|B\|$. Conversely choose a maximizing unit $v$ and, if $Bv\ne0$, take $u=Bv/\|Bv\|$; if $B=0$ the equality is immediate. Thus the supremum of the scalar observable is exactly $\|B\|$. The same compactness, continuity, positive-open-set probability and independence argument proves $L_j\uparrow\|A-V\|$ almost surely. Neither $A^*$ nor $V$ is applied in this procedure.
Why a convergent lower estimate is not a step-size certificate.
For a deterministic method making $T<n$ forward queries, follow its transcript when $A=0$. Let the query span be $W$; choose a unit vector $w\perp W$ and a unit output vector $u$. For any $K>0$, the operator $A_K=Kuw^T$ gives zero on every query. By induction the adaptive transcript is identical to the zero-operator transcript, yet $\|A_K\|=K$. Thus no finite upper bound valid for all operators can follow from that transcript. The same obstruction applies with the $V^*$ oracle identically zero. This is a worst-case deterministic query obstruction, not a randomized lower bound proved by choosing an operator after seeing private randomness. In particular, substituting a lower estimate for $\|A\|$ in a convergence step-size restriction can choose a step that is too large.

Verification and adversarial audit

The random-plane proof works for $n=1$ (the sphere has two points) and for $A=0$. The mismatch proof handles $B=0$ before division. Memory means real arithmetic storage for a constant number of full vectors, not constant bit storage; numerical roundoff, infinite-dimensional Hilbert spaces, and computable stopping accuracy are outside the proven statement. The transcript argument fixes a deterministic algorithm first and assumes strictly fewer than $n$ forward queries.
