Round-8 Objective

We pursue (A) a proof strategy. Round 7 proved existence of $\delta_{\log}(A)$ under the tail condition \[ \sum_{i=1}^{\infty}\frac1{n_i}<\infty, \] by comparing $A$ with a fixed finite stage $A^{(k)}$ and then controlling the loss by a union bound over later single congruence classes.

The exact remaining weakness of that argument is that it says nothing when the reciprocal series diverges, even if the finite-stage densities themselves already go to zero.

The new objective of this round is to settle that entire branch:

if the stage densities $\delta_k=d(A^{(k)})$ tend to $0$, then $A$ has natural density $0$, hence logarithmic density $0$.
This is a substantial strengthening of the previous rounds, because it removes all auxiliary hypotheses (growth, clique counts, compatibility sparsity, or reciprocal summability) on the whole zero-density branch.

As a concrete consequence, we obtain a complete resolution for the important special case of pairwise coprime moduli: for pairwise coprime $(n_i)$, the logarithmic density always exists and equals \[ \prod_{i\ge 1}\left(1-\frac1{n_i}\right). \] This includes the genuinely new divergent-reciprocal case $n_i=p_i$ (the primes), which was not covered by any earlier round.

Round-7 Foundation Used

We rely on the following vetted results from the previous rounds.
  • Stage sets. For each $k\ge 1$, \[ A^{(k)}:=\{n\in\mathbb N:\ n\not\equiv a_i \pmod{n_i}\ \forall\ 1\le i\le k\}. \]
  • Round 1 activation identity. For $n_k\le n<n_{k+1}$ one has \[ \mathbf 1_A(n)=\mathbf 1_{A^{(k)}}(n). \]
  • Round 2 monotonicity of stage densities. Each $A^{(k)}$ is periodic, so its natural density \[ \delta_k:=d(A^{(k)}) \] exists. Moreover, \[ A^{(k+1)}\subseteq A^{(k)}, \qquad 1\ge \delta_1\ge \delta_2\ge \cdots \ge 0, \] so $\delta_k\to \delta\in[0,1]$.
  • Round 7 fixed-stage comparison principle. For every fixed $k$, the set $A$ is contained in $A^{(k)}$.
  • Periodic-set logarithmic asymptotics. If $B$ is periodic with natural density $d(B)$, then \[ \sum_{\substack{n\le x\\ n\in B}}\frac1n = d(B)\log x+O(1). \] In particular, if a set has natural density $0$, then it has logarithmic density $0$.

New Insight / Tool (Round-8)

The new tool is an lcm-scale periodic majorant.

Let \begin{equation} L_k:=\mathrm{lcm}(n_1,\dots,n_k). \tag{8.1} \end{equation} For any $x$, choose the largest stage $k$ for which the full period $L_k$ already fits below $x$. Since \[ A\subseteq A^{(k)} \] and $A^{(k)}$ is periodic modulo $L_k$, the counting function of $A$ up to $x$ is bounded by the counting function of a genuinely periodic set over at least one whole period. This gives the simple but powerful estimate \[ A(x):=\#\{n\le x:\ n\in A\} \le 2\delta_k x \qquad (L_k\le x), \] with no dependence on local interval bias, compatibility graphs, or discrepancy constants.

Thus, once $\delta_k\to 0$, the set $A$ is automatically $o(x)$-sparse. This settles the entire zero-stage-density branch of the problem.

Attack Plan (Round-8)

Round 7 left open all cases with divergent reciprocal series and/or large compatibility complexity. The precise new gap we attack is:
Can one prove existence of $\delta_{\log}(A)$ whenever the stage densities $\delta_k$ themselves already tend to $0$?

The plan is:

  1. Use Round 2: $\delta_k$ always exists and decreases.
  2. For each $k$, exploit the exact periodic structure of $A^{(k)}$ modulo $L_k$.
  3. If $L_k\le x$, bound $A(x)$ by the number of allowed residues of $A^{(k)}$ in at most one extra period.
  4. Let $k=k(x)$ be maximal with $L_k\le x$. Since $k(x)\to\infty$ and $\delta_{k(x)}\to 0$, deduce $A(x)=o(x)$.
  5. Conclude that $A$ has natural density $0$, hence logarithmic density $0$.
  6. Apply this to pairwise coprime moduli, where $\delta_k$ is explicit by the Chinese remainder theorem.

Work (Round-8)

8.1. A counting lemma at the lcm scale

Define \begin{equation} A(x):=\#\{n\le x:\ n\in A\}. \tag{8.2} \end{equation} For each $k\ge 1$, let $L_k$ be as in $8.1$.
Lemma 8.1.
For every $k\ge 1$, the periodic set $A^{(k)}$ is a union of exactly $\delta_k L_k$ residue classes modulo $L_k$. Consequently, for every real $x\ge 1$, \begin{equation} \#\{n\le x:\ n\in A^{(k)}\} \le \left(\lfloor x/L_k\rfloor+1\right)\,\delta_k L_k. \tag{8.3} \end{equation}

Proof. By definition, $A^{(k)}$ is obtained by avoiding finitely many residue classes modulo $n_1,\dots,n_k$. Hence $A^{(k)}$ is periodic modulo $L_k=\mathrm{lcm}(n_1,\dots,n_k)$. Let $R_k\subseteq\{0,1,\dots,L_k-1\}$ be the set of allowed residues modulo $L_k$. Then \[ |R_k|=\delta_k L_k, \] because the natural density of a periodic set equals the proportion of allowed residues in one full period.

The interval $[1,x]$ intersects at most $\lfloor x/L_k\rfloor+1$ residue blocks of length $L_k$, and each block contains at most $|R_k|=\delta_k L_k$ points of $A^{(k)}$. This proves $8.3$. $\square$

Lemma 8.2.
If $L_k\le x$, then \begin{equation} A(x)\le 2\delta_k x. \tag{8.4} \end{equation}

Proof. Since $A\subseteq A^{(k)}$, Lemma 8.1 gives \[ A(x) \le \left(\lfloor x/L_k\rfloor+1\right)\,\delta_k L_k. \] If $L_k\le x$, then \[ \lfloor x/L_k\rfloor+1\le x/L_k+1\le 2x/L_k, \] so \[ A(x)\le (2x/L_k)\,\delta_k L_k=2\delta_k x. \] This is $8.4$. $\square$

8.2. Zero stage-density limit implies natural density zero

Theorem 8.3.
Assume that \begin{equation} \delta_k\longrightarrow 0. \tag{8.5} \end{equation} Then $A$ has natural density $0$. In particular, \begin{equation} \delta_{\log}(A)=0. \tag{8.6} \end{equation}

Proof. If $n_1=1$, then $A=\varnothing$, so the conclusion is trivial. Assume henceforth that $n_1\ge 2$.

For each sufficiently large $x$, let $k(x)$ be the largest index such that \begin{equation} L_{k(x)}\le x. \tag{8.7} \end{equation} Such an index exists for all large $x$ because $L_k\ge n_k\to\infty$. Also $k(x)\to\infty$ as $x\to\infty$.

Applying Lemma 8.2 with $k=k(x)$, we get \begin{equation} \frac{A(x)}{x}\le 2\delta_{k(x)}. \tag{8.8} \end{equation} Since $k(x)\to\infty$ and $\delta_k\to 0$ by hypothesis, the right-hand side of $8.8$ tends to $0$. Therefore \begin{equation} \frac{A(x)}{x}\longrightarrow 0, \tag{8.9} \end{equation} so $A$ has natural density $0$.

To pass from natural density to logarithmic density, use partial summation: \begin{equation} \sum_{\substack{n\le x\\ n\in A}}\frac1n = \frac{A(x)}{x} + \int_1^x \frac{A(t)}{t^2}\,dt. \tag{8.10} \end{equation} Fix $\varepsilon>0$. By $8.9$, there exists $T=T(\varepsilon)$ such that $A(t)\le \varepsilon t$ for all $t\ge T$. Then for $x\ge T$, \[ \sum_{\substack{n\le x\\ n\in A}}\frac1n \le O_T(1)+\varepsilon\int_T^x \frac{dt}{t} =O_T(1)+\varepsilon\log x. \] Divide by $\log x$ and let $x\to\infty$; since $\varepsilon$ is arbitrary, this proves $8.6$. $\square$

8.3. A complete resolution for pairwise coprime moduli

Corollary 8.4.
Assume that the moduli are pairwise coprime: \begin{equation} \gcd(n_i,n_j)=1\qquad(i\neq j). \tag{8.11} \end{equation} Then the logarithmic density $\delta_{\log}(A)$ exists for every choice of residues $a_i\pmod{n_i}$, and \begin{equation} \delta_{\log}(A) = \lim_{k\to\infty}\delta_k = \prod_{i=1}^{\infty}\left(1-\frac1{n_i}\right). \tag{8.12} \end{equation}

Proof. Under the pairwise coprimeness hypothesis, the Chinese remainder theorem gives \begin{equation} \delta_k= \prod_{i=1}^{k}\left(1-\frac1{n_i}\right), \tag{8.13} \end{equation} independently of the chosen residues.

There are two cases.

Case 1: $\sum_i 1/n_i<\infty$. Then Round 7 (Theorem 7.3) applies directly and yields existence of $\delta_{\log}(A)$, with value $ \lim_k \delta_k $. Using $8.13$, this is exactly the infinite product in $8.12$.

Case 2: $\sum_i 1/n_i=\infty$. Then by $8.13$ and the elementary inequality $\log(1-u)\le -u$ for $0<u<1$, \[ \log \delta_k = \sum_{i=1}^{k}\log\left(1-\frac1{n_i}\right) \le -\sum_{i=1}^{k}\frac1{n_i} \longrightarrow -\infty. \] Hence $\delta_k\to 0$. Theorem 8.3 therefore applies and gives $\delta_{\log}(A)=0$, which is again the value of the infinite product in $8.12$.

Thus $8.12$ holds in all pairwise coprime cases. $\square$

Example 8.5 (prime moduli: a genuinely new divergent-reciprocal case).
Take $n_i=p_i$, the $i$-th prime, with arbitrary residues $a_i\pmod{p_i}$. Then the moduli are pairwise coprime and \[ \sum_{i=1}^{\infty}\frac1{p_i}=\infty, \] so Corollary 8.4 gives \begin{equation} \delta_{\log}(A)=0. \tag{8.14} \end{equation} This case is genuinely outside all previously proved regimes:
  • Round 4 does not apply because $ \mathrm{lcm}(p_1,\dots,p_k)/p_k=\prod_{i<k}p_i\to\infty. $
  • Round 6 does not apply because every finite family of congruences is compatible, so the local clique counts are maximal: $ C_r=2^{r-1}. $
  • Round 7 does not apply because $\sum 1/p_i=\infty$.
Thus Corollary 8.4 is a strict advance into a genuinely new branch of the problem.

Adversarial Verification

We now stress-test the new work.
  • No hidden growth assumptions. Theorem 8.3 uses only the periodicity of $A^{(k)}$, the monotone limit $\delta_k\to 0$, and the trivial containment $A\subseteq A^{(k)}$. No hypotheses on $\sum 1/n_i$, on lcm growth, or on compatibility graphs are used.
  • Choice of the index $k(x)$. Since $L_k\ge n_k$ and $n_k\to\infty$, one has $L_k\to\infty$, so $k(x)$ is well-defined for all sufficiently large $x$ and satisfies $k(x)\to\infty$.
  • Period-counting bound. Inequality $8.3$ is exact up to the harmless final partial block; it does not rely on any averaging or discrepancy estimate.
  • Natural density really follows. From $8.8$, the ratio $A(x)/x$ is bounded by $2\delta_{k(x)}$, which tends to $0$. So this is stronger than a logarithmic-density statement: the set is actually $o(x)$-sparse.
  • Passage to logarithmic density. Equation $8.10$ is the standard partial-summation identity for the counting function $A(x)$. Once $A(x)=o(x)$, it indeed implies the weighted harmonic sum is $o(\log x)$.
  • Pairwise coprime corollary. The only new ingredient there is the Chinese remainder theorem, which gives $8.13$. The divergent-reciprocal case is then handled by Theorem 8.3, while the convergent case is already covered by Round 7.
  • Sharpness of the reduction. Theorem 8.3 shows that any counterexample to the original problem must have \begin{equation} \delta:=\lim_{k\to\infty} d(A^{(k)})>0. \tag{8.15} \end{equation} This is a strictly sharper obstruction than Round 7, which only forced $\sum 1/n_i=\infty$ for a counterexample.

Final

UNRESOLVED (BUT STRICTLY ADVANCED).

The main new theorem is Theorem 8.3:

If the finite-stage densities $\delta_k=d(A^{(k)})$ tend to $0$, then $A$ has natural density $0$, hence logarithmic density $0$.
This is a major structural advance because it completely settles the whole zero-stage-density branch of the problem.

A concrete payoff is Corollary 8.4:

If the moduli $n_i$ are pairwise coprime, then $\delta_{\log}(A)$ always exists and equals \[ \prod_{i\ge 1}\left(1-\frac1{n_i}\right). \]
This includes the prime-modulus case $n_i=p_i$, arbitrary residues, where the logarithmic density is always $0$. That case was not covered by any earlier round.

The unresolved core is now narrower than before: any counterexample must lie in the positive-density stage-limit regime \[ \lim_{k\to\infty} d(A^{(k)})>0, \] so the entire zero-limit branch is eliminated.
