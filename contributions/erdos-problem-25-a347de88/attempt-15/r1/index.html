Round-12 Objective

We pursue (C) obstruction/correction. I do not have a gap-free 100% resolution of Erdős Problem #25 that I can honestly certify. The strongest new result I can certify is an exact structural decomposition of the thresholded set into a thresholdless core plus a one-point-per-stage exceptional set.

This sharpens the current state of the investigation substantially:

all of the threshold phenomenon is concentrated in a single explicit exceptional set.
More precisely, if \[ B:=\{n\in\mathbb N: n\not\equiv a_i\pmod{n_i}\ \forall i\ge 1\} \] is the thresholdless core, then the original set $A$ satisfies an exact disjoint decomposition \[ A = B\ \sqcup\ E, \] where $E$ contains at most one integer from each congruence class and can be written down explicitly. This shows that to solve Problem #25 completely, it is enough to understand two objects separately:
  1. the thresholdless core $B$, and
  2. the exceptional set $E$.
In particular, if one could prove the singleton no-threshold analogue of the Davenport--Erdős theorem for $B$, then Problem #25 would follow immediately.

Round-11 Foundation Used

We rely on the following vetted earlier facts.
  • For each $k\ge 1$, the finite-stage set \[ A^{(k)}:=\{n\in\mathbb N: n\not\equiv a_i\pmod{n_i}\ \forall 1\le i\le k\} \] is periodic, hence has a natural density \[ \delta_k:=d(A^{(k)}). \]
  • The stage densities decrease: \[ 1\ge \delta_1\ge \delta_2\ge \cdots \ge 0, \qquad \delta_k\to \delta\in[0,1]. \]
  • The corrected tail comparison from Round 11 gives the unconditional upper bound \begin{equation} \overline d(A)\le \delta, \qquad \overline\delta_{\log}(A)\le \delta. \tag{12.1} \end{equation}
  • If $P\subseteq\mathbb N$ is periodic with natural density $d(P)$, then \[ \sum_{\substack{n\le x\\ n\in P}}\frac1n = d(P)\log x + O(1). \]

New Insight / Tool (Round-12)

The new tool is an exact partition of the integers according to the first congruence that catches them.

For each $r\ge 1$, define the periodic set \begin{equation} D_r := A^{(r-1)} \cap \{n\in\mathbb N: n\equiv a_r\pmod{n_r}\}. \tag{12.2} \end{equation} Then the $D_r$ are pairwise disjoint and satisfy \[ A^{(r-1)} = A^{(r)} \sqcup D_r, \qquad d(D_r)=\delta_{r-1}-\delta_r. \] Hence \[ \mathbb N \setminus \bigcap_{k\ge 1} A^{(k)} = \bigsqcup_{r\ge 1} D_r. \] The threshold in the definition of $A$ simply puts back one possible small representative from each $D_r$.

That is the exact source of the difficulty.

Attack Plan (Round-12)

The exact gap after Round 11 was that, while we had strong upper bounds and several large positive regimes, we still lacked a clean description of what the threshold condition is actually changing.

We now:

  1. define the thresholdless core $B$;
  2. define the exceptional set $E$ explicitly;
  3. prove the exact disjoint decomposition $A=B\sqcup E$;
  4. derive exact harmonic-sum decompositions;
  5. isolate a sharply formulated remaining obstruction: it is enough to prove that the thresholdless core $B$ has logarithmic density equal to $\delta$.

Work (Round-12)

Let \begin{equation} B := \{n\in\mathbb N: n\not\equiv a_i\pmod{n_i}\ \forall i\ge 1\} = \bigcap_{k\ge 1} A^{(k)}. \tag{12.3} \end{equation} Thus $B$ is the set one gets by removing the activation thresholds entirely.

For each $i\ge 1$, let $r_i\in\{0,1,\dots,n_i-1\}$ be the least nonnegative residue of $a_i\pmod{n_i}$. Define the exceptional set \begin{equation} E := \{r_i: 1\le r_i < n_i\ \text{and}\ r_i\in A^{(i-1)}\}. \tag{12.4} \end{equation} Intuitively, $r_i$ is the unique positive integer below the threshold $n_i$ that would lie in the congruence class $a_i\pmod{n_i}$; if it survives all earlier congruences, then the threshold condition allows it to stay in $A$.

12.1. Distinctness of the exceptional points

Lemma 12.1.
The elements of $E$ are pairwise distinct.

Proof. Suppose $r_i=r_j=:m$ with $i<j$ and $m\in E$. Then by definition of $E$, one has \[ m\in A^{(j-1)}. \] But $m=r_i\equiv a_i\pmod{n_i}$, so $m\notin A^{(j-1)}$ because the $i$-th no-threshold condition is among the first $j-1$ conditions. Contradiction. $\square$

12.2. Exact decomposition of the thresholded set

Theorem 12.2 (exact decomposition).
One has the disjoint union \begin{equation} A = B\ \sqcup\ E. \tag{12.5} \end{equation}

Proof. First, $B\subseteq A$ is immediate: if $n$ avoids every congruence class $a_i\pmod{n_i}$, then it certainly avoids every active one.

Next, let $m\in E$. Then $m=r_i<n_i$ for some $i$, and $m\in A^{(i-1)}$, so $m$ avoids all earlier congruences. Since $m<n_i$, the $i$-th congruence is inactive at $m$, and all later congruences are also inactive because $n_j>n_i>m$ for $j>i$. Hence $m\in A$. Thus \[ B\cup E\subseteq A. \] Also $B\cap E=\varnothing$ because every $m\in E$ satisfies $m\equiv a_i\pmod{n_i}$ for some $i$.

It remains to prove $A\subseteq B\cup E$. Take $n\in A$. If $n\in B$ there is nothing to show. Suppose $n\notin B$. Then there exists at least one index $i$ with \[ n\equiv a_i\pmod{n_i}. \] Let $r$ be the least such index. Then for every $i<r$, one has $n\not\equiv a_i\pmod{n_i}$, so \[ n\in A^{(r-1)}. \] Since $n\in A$ and $n\equiv a_r\pmod{n_r}$, the $r$-th congruence must be inactive at $n$, hence $n<n_r$. But $n$ is a positive integer congruent to $a_r\pmod{n_r}$ and lying in $[1,n_r-1]$, so necessarily \[ n=r_r. \] Therefore $n=r_r\in E$ by definition. This proves $A\subseteq B\cup E$ and finishes the proof. $\square$

12.3. Consequences for harmonic sums

Write \[ S_A(x):=\sum_{\substack{n\le x\\ n\in A}}\frac1n, \qquad S_B(x):=\sum_{\substack{n\le x\\ n\in B}}\frac1n, \qquad S_E(x):=\sum_{\substack{n\le x\\ n\in E}}\frac1n. \] Since the union in (12.5) is disjoint, we obtain the exact identity \begin{equation} S_A(x)=S_B(x)+S_E(x) \qquad (x\ge 1). \tag{12.6} \end{equation} Therefore, for every instance, \begin{equation} \underline\delta_{\log}(A) \ge \underline\delta_{\log}(B)+\underline\delta_{\log}(E), \qquad \overline\delta_{\log}(A) \le \overline\delta_{\log}(B)+\overline\delta_{\log}(E) \tag{12.7} \end{equation} whenever these quantities are interpreted as lower/upper logarithmic densities.

Combined with the unconditional upper bound (12.1), this gives \begin{equation} \overline\delta_{\log}(B)+\overline\delta_{\log}(E) \ \text{need not be}\ \le \delta, \quad\text{but} \quad \overline\delta_{\log}(A)=\overline\delta_{\log}(B\sqcup E)\le \delta. \tag{12.8} \end{equation} Thus any oscillation in $A$ must come from a delicate interaction between the thresholdless core and the exceptional set.

12.4. The thresholdless singleton core is the exact remaining obstruction

The finite-stage sets for $A$ and for the thresholdless core $B$ are the same: \[ B^{(k)}=A^{(k)} \qquad (k\ge 1). \] So both problems have the same stage densities $\delta_k$ and the same limit $\delta$.

This immediately yields the following reduction.

Corollary 12.3.
Assume for a given instance that the thresholdless core $B$ has logarithmic density equal to the stage-density limit: \begin{equation} \delta_{\log}(B)=\delta:=\lim_{k\to\infty}d(A^{(k)}). \tag{12.9} \end{equation} Then the original thresholded set $A$ also has logarithmic density, and in fact \begin{equation} \delta_{\log}(A)=\delta, \qquad \delta_{\log}(E)=0. \tag{12.10} \end{equation}

Proof. Since $B\subseteq A$, identity (12.6) implies \[ \underline\delta_{\log}(A)\ge \delta_{\log}(B)=\delta. \] But Theorem 11.3 gives the unconditional upper bound \[ \overline\delta_{\log}(A)\le \delta. \] Hence $A$ has logarithmic density $\delta$. Subtracting (12.9) from (12.6) shows $S_E(x)=o(\log x)$, i.e. \[ \delta_{\log}(E)=0. \] $\square$

Interpretation.
Corollary 12.3 is the sharpest reduction I can currently certify:
to solve Erdős Problem #25, it is enough to prove the singleton no-threshold analogue of the Davenport--Erdős theorem, namely that the thresholdless core $B$ always has logarithmic density equal to the limit of the finite-stage densities.
Once that is known, the threshold contribution $E$ automatically has logarithmic density $0$ and the original problem follows.

12.5. A corrected reformulation of the remaining gap

Define the thresholdless singleton problem:
Given strictly increasing moduli $1\le n_1<n_2<\cdots$ and residues $a_i\pmod{n_i}$, let \[ B=\{n\in\mathbb N:\ n\not\equiv a_i\pmod{n_i}\ \forall i\ge 1\}. \] Must $B$ have logarithmic density, and is that density always equal to $\lim_k d(A^{(k)})$?
The previous corollary shows that an affirmative answer to this thresholdless singleton problem would solve Erdős Problem #25.

This isolates a single sharply formulated obstruction whose resolution would settle the original problem.

In all previously verified regimes (finite constraints, summable reciprocals, pairwise coprime cases, zero stage-density limit), this reduction is consistent: the thresholdless core already has the expected density, and then $E$ must have logarithmic density $0$ by Corollary 12.3.
