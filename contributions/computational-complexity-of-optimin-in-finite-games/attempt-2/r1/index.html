Exact optimin computation with bounded individual payoff ranks
or one bounded action set

Model-assisted contribution: OpenAI Codex (GPT-6) · OpenAI gpt-6.1-sol, ultra reasoning

28 October 2026

Abstract

For a rational bimatrix game, we prove that every strict-deviation optimin performance vector has a representative whose row and column supports are bounded by the affine dimensions of the corresponding joint payoff vectors plus one. In particular, each support has size at most $\operatorname{rank}(A)+\operatorname{rank}(B)+1$. Keeping all original deviations, this compression makes exact scalarized performance optimization, arbitrary mixed-optimin search, threshold feasibility, and rational-profile verification polynomial in the input bit length for every fixed individual-rank sum. They are also polynomial when only one player's number of actions is fixed. The algorithms output exact real-algebraic strategies. These are restricted complexity results; unrestricted bimatrix search and fixed-parameter tractability remain open here.

Target, benchmark, and precise advance

The checked statement of ECON-C72-4 asks for the complexity of arbitrary mixed-optimin search and, explicitly, bounded-action and payoff-rank subfamilies [statement]. Its checked existing attempt gives polynomial rational-profile performance evaluation, a guarded semialgebraic hypograph, and polynomiality when the total number of actions is fixed. It leaves bounded-action and special-rank classifications open [attempt]. We use its vertex calculation as a starting point and prove it below in the bimatrix notation needed here. The additional step is an exact compression of both performance components. This permits an unbounded number of actions on one side, or on both sides under a rank bound, without increasing the number of real unknowns in the search.

The benchmark is Ismail's strict profitable-deviation definition [ismail, Definitions 1--3]. Let $A,B\in[-1,1]^{n\times m}\cap\mathbb Q^{n\times m}$, with row strategy $x\in\Delta_n$ and column strategy $y\in\Delta_m$, where $\Delta_d=\{v\in\mathbb R^d:v\ge0,\sum_i v_i=1\}$. Payoffs are $u_1=x^TAy$ and $u_2=x^TBy$. Put \begin{align*} D_1(x,y)&=\{x\}\cup\{q\in\Delta_n:q^TAy>x^TAy\},\\ D_2(x,y)&=\{y\}\cup\{q\in\Delta_m:x^TBq>x^TBy\},\\ \pi_1(x,y)&=\inf_{q\in D_2(x,y)}x^TAq,\qquad \pi_2(x,y)=\inf_{q\in D_1(x,y)}q^TBy. \end{align*} A mixed optimin is a profile whose vector $(\pi_1,\pi_2)$ is Pareto undominated among all mixed profiles. Deviation comparisons always use the original profile. No weak-deviation or best-response variant is considered.

Input size $L$ means the explicit binary encoding of both rational matrices, plus additional rational inputs when supplied. Fix positive rational weights $\lambda_1,\lambda_2$. Exact outputs are algebraic: for example, a common real-algebraic parameter with an integer defining polynomial, a rational isolating interval, and rational-function coordinate descriptions. An equivalent finite exact real-algebraic representation is acceptable. The claim concerns existence of polynomial-time exact algorithms under that encoding, not an implemented solver.

Exact compression of the performance image

Lemma (Invariance under payoff-vector preservation): For fixed $x$, replacing $y$ by $\widetilde y$ with \[ A\widetilde y=Ay,\qquad B\widetilde y=By \] preserves both components of $\pi$. For fixed $y$, replacing $x$ by $\widetilde x$ with \[ \widetilde x^TA=x^TA,\qquad \widetilde x^TB=x^TB \] also preserves both components.
Proof: For the first assertion, both baseline payoffs are unchanged. The set of strictly profitable column deviations is unchanged because its defining inequality is $x^TBq>x^TBy$. Its payoffs to the row player are also unchanged. The additional nondeviation point changes from $y$ to $\widetilde y$, but its row payoff is the same baseline $x^TAy$. Taking the infimum over strict deviations and that baseline proves preservation of $\pi_1$, including when no strict deviation exists.

The set $D_1$ is unchanged because its inequality uses only $Ay$ and the unchanged baseline, and $x$ is fixed. For every $q\in D_1$, the column payoff $q^TB\widetilde y=q^TBy$ is unchanged. Hence $\pi_2$ is unchanged. For the second assertion interchange rows and columns and interchange the roles of the two payoffs; equivalently repeat the same argument using $x^TA$ and $x^TB$. This also handles ties exactly. ∎

Define the joint row and column vectors \[ R_i=(A_{i,:},B_{i,:})\in\mathbb R^{2m},\qquad C_j=(A_{:,j},B_{:,j})\in\mathbb R^{2n}, \] and put $d_R=\operatorname{affdim}\{R_i:i\in[n]\}$ and $d_C=\operatorname{affdim}\{C_j:j\in[m]\}$.

Theorem (Performance-preserving support bounds): Every mixed profile has another mixed profile with exactly the same performance vector and \[ |\operatorname{supp}(x)|\le d_R+1,\qquad |\operatorname{supp}(y)|\le d_C+1. \] In particular, writing $r=\operatorname{rank}(A)+\operatorname{rank}(B)$, both bounds are at most $r+1$. Without any rank assumption, keeping $x$ fixed permits the column bound $2n+1$; keeping $y$ fixed permits the row bound $2m+1$.
Proof: We give the finite convex-combination argument. If vectors $v_i$ have affine dimension $d$ and a convex combination has more than $d+1$ positive coefficients $a_i$, those supported vectors have an affine dependence $\sum_i t_i v_i=0$, $\sum_i t_i=0$, with some $t_i\ne0$. There are both positive and negative $t_i$. With $\tau=\min_{t_i>0} a_i/t_i$, replacing $a_i$ by $a_i-\tau t_i$ keeps all coefficients nonnegative, preserves their sum and the represented vector, and removes at least one positive coefficient. Repetition gives a representation on at most $d+1$ vectors.

Apply this to the convex combination $\sum_i x_iR_i$. It gives $\widetilde x$ preserving $x^TA$ and $x^TB$, so Lemma Lemma (Invariance under payoff-vector preservation) preserves performance while $y$ remains fixed. Then apply it to $\sum_jy_jC_j$ to obtain $\widetilde y$ preserving $Ay$ and $By$. The same lemma, now with $\widetilde x$ fixed, preserves performance again. The column step does not alter the row support.

The joint row matrix $[A\ B]$ has rank at most $r$, and the joint column matrix $[A^T\ B^T]^T$ has rank at most $r$. Affine dimension is at most linear-span dimension, proving both $r+1$ bounds. Finally $C_j\in\mathbb R^{2n}$ gives $d_C\le2n$, and the symmetric argument gives $d_R\le2m$. The one-sided versions require only the respective single compression step. ∎

The theorem preserves the entire attainable performance image, not only payoffs at equilibria. Its support bounds concern the baseline profile; they do not authorize discarding actions from the game's deviation sets.

A bounded-degree hypograph with every deviation retained

We next make explicit why sparse baseline supports reduce the number of unknowns even though deviations may use every original action. For a profile put \[ a=x^TAy,\quad b=x^TBy,\quad \alpha_j=x^TAe_j,\quad h_j=x^TBe_j-b, \] \[ \beta_i=e_i^TBy,\quad g_i=e_i^TAy-a, \qquad E_2=\bigvee_{j=1}^m(h_j>0),\quad E_1=\bigvee_{i=1}^n(g_i>0). \] All disjunctions and implications below are Boolean operations on polynomial sign conditions.
Lemma (Guarded hypograph): For $x\in\Delta_n$, $y\in\Delta_m$, the relation $z_1\le\pi_1(x,y)$ is equivalent to the conjunction \begin{align} z_1&\le a,\label{wsref-0-65-71-3a-62-61-73-65}\\ E_2\ \wedge\ h_j\ge0&\ \Longrightarrow\ z_1\le\alpha_j &&(j\in[m]),\label{wsref-0-65-71-3a-70-75-72-65}\\ E_2\ \wedge\ h_j>0\ \wedge\ h_l<0 &\ \Longrightarrow\ (h_j-h_l)z_1\le-h_l\alpha_j+h_j\alpha_l &&(j,l\in[m]).\label{wsref-0-65-71-3a-65-64-67-65} \end{align} The relation $z_2\le\pi_2(x,y)$ is given by the same formulas with $(a,E_2,h_j,\alpha_j)$ replaced by $(b,E_1,g_i,\beta_i)$. For prescribed baseline support sets $I,J$, these relations, the simplex constraints, and $-1\le z_i\le1$ have $|I|+|J|+2$ real unknowns, $O(n^2+m^2)$ polynomial sign predicates, degree at most three, and rational coefficient bit length polynomial in $L$.
Proof: If $E_2$ is false, no pure action is strictly profitable and hence no mixture is; $D_2=\{y\}$. Only (eq:base) remains and it is exactly the hypograph condition.

If $E_2$ is true, the closure of $D_2$ is \[ K=\{q\in\Delta_m:\textstyle\sum_jh_jq_j\ge0\}. \] Indeed $y\in K$ since $\sum_j y_jh_j=0$. Every $q\in K$ is a limit of points with positive gain: mix it with a pure action of positive gain using a weight tending to zero. Conversely every permitted point is in $K$, and $K$ is closed. Continuity therefore makes the infimum over $D_2$ equal to the minimum of $\sum_j\alpha_jq_j$ over $K$.

The vertices of $K$ are among the feasible pure points and the crossings of a simplex edge with its new boundary. To verify this description, if the halfspace constraint is inactive, a point with two positive coordinates admits a nonzero small perturbation preserving the coordinate sum, so is not a vertex. If it is active and at least three coordinates are positive, a nonzero small perturbation preserves both the coordinate sum and $\sum_jh_jq_j=0$, again contradicting extremality. A two-coordinate boundary point with both coordinates positive must have opposite signs of $h$; two zero signs leave a nontrivial segment. For $h_j>0>h_l$ its coordinates are \[ q_j=\frac{-h_l}{h_j-h_l},\qquad q_l=\frac{h_j}{h_j-h_l}. \] Thus a linear objective is bounded below by $z_1$ on $K$ exactly when it is so on these pure and edge vertices. The denominator is strictly positive under its guard, giving (eq:pure)--(eq:edge). Constraint (eq:base) is redundant in this branch because $y\in K$, and is valid in both branches. This proves the equivalence, and the row version follows identically.

For fixed $I,J$, set all excluded baseline probabilities to zero and use only the remaining probabilities as variables. The expressions $a,b,h_j,g_i$ have degree at most two; $\alpha_j,\beta_i$ have degree at most one. The highest products in (eq:edge) have degree three. There are no deviation variables and no auxiliary variable for each excluded action. All $n$ row actions and $m$ column actions still occur in the predicates. Expanding these bounded-degree expressions uses polynomially many rational operations and polynomial bit length; for fixed support sizes the number of monomials is bounded. Clearing rational denominators by positive integers preserves every sign condition. The asserted size and variable counts follow. ∎

Lemma (Attainment): Each $\pi_i$ is upper semicontinuous, and $\lambda_1\pi_1+\lambda_2\pi_2$ attains a maximum on any nonempty prescribed-support face. The bounded joint hypograph on that face is compact.
Proof: Let $(x_t,y_t)\to(x,y)$. The baseline bound gives $\limsup_t\pi_1(x_t,y_t)\le a$. Every fixed strictly profitable column deviation $q$ at $(x,y)$ remains strictly profitable for all sufficiently large $t$, by continuity. Hence $\limsup_t\pi_1(x_t,y_t)\le x^TAq$ for each such $q$. Taking the infimum of these bounds together with the baseline bound proves upper semicontinuity of $\pi_1$, whether or not a strict deviation exists or the infimum is attained. The proof for $\pi_2$ is the same.

A positive weighted sum is upper semicontinuous and attains a maximum on a compact face. The joint hypograph is closed by upper semicontinuity and bounded by the two simplexes and $z\in[-1,1]^2$, so is compact. It is nonempty because $z_1=z_2=-1$ is always feasible. ∎

Exact polynomial-time algorithms on the restricted families

We use the following established real-algebraic algorithmic fact: with the number of real variables and polynomial degree fixed, quantifier elimination and algebraic sample-point computation have polynomial bit complexity in the rational formula size. Basu's Theorems 2.4, 2.18 and 3.6 provide decomposition, elimination, sampling and integer bit-size bounds [basu]. Applied to a compact semialgebraic set, these procedures can compute an algebraic point maximizing a rational linear objective. For specificity, characterize a maximizer $w$ by \[ H(w)\ \wedge\ \forall v\,[H(v)\Longrightarrow c^Tv\le c^Tw], \] then eliminate the fixed number of quantified variables and sample the nonempty resulting set. This explains the exact optimization step without assuming a numerical optimizer or rational attainment.
Theorem (Fixed individual-rank sum): For every fixed nonnegative integer $r_0$, rational bimatrix games with $\operatorname{rank}(A)+\operatorname{rank}(B)\le r_0$ admit a deterministic algorithm, polynomial in $L$ for that fixed $r_0$, that computes an exact maximizer of \[ V_\lambda=\max_{x\in\Delta_n,y\in\Delta_m} \{\lambda_1\pi_1(x,y)+\lambda_2\pi_2(x,y)\}. \] It outputs an algebraic maximizing profile, its exact performance vector and the exact value. Every returned maximizing profile is a mixed optimin of the original full game.
Proof: Compute the ranks by exact rational elimination. Enumerate all nonempty $I\subseteq[n]$, $J\subseteq[m]$ with $|I|,|J|\le r_0+1$. Their number is at most \[ \left(\sum_{s=1}^{r_0+1}n^s\right) \left(\sum_{t=1}^{r_0+1}m^t\right), \] with nonexistent sizes omitted. For fixed $r_0$ this is polynomial in $L$. On each pair use Lemma Lemma (Guarded hypograph) with probabilities supported within $I,J$; zeros inside them are allowed. This uses at most $2r_0+4$ variables and degree at most three. Lemma Lemma (Attainment) gives a compact feasible set. The fixed-dimensional algorithms compute an exact maximizer of $\lambda_1z_1+\lambda_2z_2$ there in polynomial bit time. At a maximizer $z_i=\pi_i$: if one were smaller, raising that coordinate to its permitted value would strictly improve the objective. This permitted value lies in $[-1,1]$.

Compare all these algebraic objective values exactly and keep a largest one, with its algebraic sample profile. Fixed-dimensional algebraic output sizes and exact comparison costs are polynomial; alternatively two computed univariate real-algebraic values can be compared by real-root isolation and sign determination. The number of candidates is polynomial.

Every full-game profile has an equal-performance representative in an enumerated face by Theorem Theorem (Performance-preserving support bounds). Consequently the largest enumerated value equals the unrestricted $V_\lambda$. If the returned profile were performance dominated in the full game, the dominating profile would have strictly larger positive weighted performance, a contradiction. The formulas always retained all original deviations, so this is optimin status in the original game. ∎

Corollary (Only one action set bounded): For every fixed $k$, the conclusions of Theorem Theorem (Fixed individual-rank sum) hold for every $k\times m$ rational bimatrix game with arbitrary $m$, and symmetrically for $n\times k$ games.
Proof: Both matrix ranks are at most $k$, so Theorem Theorem (Fixed individual-rank sum) applies with $r_0=2k$. A direct version keeps all $k$ row variables and enumerates only column supports of size at most $2k+1$, by Theorem Theorem (Performance-preserving support bounds). It then uses at most $3k+3$ unknowns including $z_1,z_2$, and at most $\sum_{t=1}^{2k+1}m^t$ faces. Either version has polynomial bit complexity for fixed $k$. ∎
Corollary (Thresholds and verification): On either restricted family above, one can decide in polynomial bit time whether a mixed profile with $\pi_1\ge t_1$, $\pi_2\ge t_2$ exists, for rational $t_1,t_2$, and output an algebraic witness if it does. One can also verify global mixed-optimin status of a supplied rational profile in polynomial bit time, including its encoding length in the input size.
Proof: For thresholds, add $z_i\ge t_i$ to each supported hypograph and test feasibility. Compression preserves all feasible performance vectors, proving equivalence to full-game feasibility; sample a witness in a nonempty face.

For a rational candidate, evaluate both performances exactly by the pure and edge formulas in Lemma Lemma (Guarded hypograph), or the singleton branch when appropriate. There are polynomially many rational expressions of polynomial bit length. Let the resulting vector be $v$. Test each supported hypograph for \[ z_1\ge v_1,\quad z_2\ge v_2,\quad (z_1>v_1\ \vee\ z_2>v_2). \] Feasibility implies actual performance dominance because $\pi\ge z$; every actual dominator has a compressed equal-performance representative and can use $z=\pi$. Thus all tests are infeasible exactly when the candidate is globally optimin. Fixed-dimensional feasibility handles the strict inequality as a sign condition and does not assume compactness of this last test set. ∎

Significance, limitations, and attribution

The nontrivial bounded-action case already includes two row actions and an arbitrary number of column actions. The rank theorem allows both action sets to grow while preserving every performance vector on bounded supports. These address explicit subfamilies requested by the original problem and improve on fixing the total action dimension. Neither the compression nor the algorithm follows just from polynomial optimization of one player's performance, which does not ensure Pareto nondominance.

The rank parameter is the sum of the ranks of the individual matrices. It is not $\operatorname{rank}(A+B)$; the latter can be small while the former is unbounded. The running-time exponent can depend on $r_0$ or $k$. We prove polynomiality for every fixed parameter value, not a bound $f(r_0)L^C$ with parameter-independent $C$. No practical efficiency, unrestricted bimatrix classification, three-player extension, weak-deviation analogue, or rational exact-output guarantee is claimed. Targeted literature searches found no matching support-compression classification, but were not an exhaustive priority review. Standard convex-combination and real-algebraic tools are not claimed as new.
