Research attempt: A projected Hamiltonian must retain the projection metric

For a smooth auxiliary HJ equation $u_t+H(\nabla_xu)=0$, try the ansatz $u(t,x)=v(t,Px)$ for a fixed linear map $P:\mathbb R^d\to\mathbb R^k$. The chain rule gives the exact reduced equation $v_t+H(P^T\nabla_yv)=0$. For $H(p)=\|p\|^2/2$, its reduced Hamiltonian is $q^TPP^Tq/2$, not generally $\|q\|^2/2$. Thus even a correct ridge ansatz does not permit ignoring the geometry of the projection.

Take $d=2,k=1$, $P(x)=2x_1$ and initial data $u(0,x)=2x_1$. The exact smooth solution is $u(t,x)=2x_1-2t$: its time derivative is $-2$ and gradient norm squared is four. Reusing the unit-metric reduced Hamiltonian would instead give $v(t,y)=y-t/2$, and hence $u(t,x)=2x_1-t/2$, whose HJ residual is $3/2$. This is a fully computed failure of the naive dimensional reduction despite exactly ridge-shaped initial data.

For a state-dependent Hamiltonian $H(x,p)$, closure requires $H(x,P^Tq)$ to depend on $x$ only through $Px$ for every relevant $q$. This is sufficient for the displayed smooth substitution. It is also necessary for a closed rule that works for every affine ridge test: the affine test $v(y)=q\cdot y$ has the same reduced state and gradient on an entire fiber, so the asserted reduced Hamiltonian must take one value there. For instance $H(x,p)=\sin(x_2)p_1$ with $P(x)=x_1$ fails this test at $q=1$.

These chain-rule facts do not prove that arbitrary data become low-dimensional, that viscosity test functions transfer under every map, or that a numerical scheme avoids exponential complexity. Those are separate claims absent from the very short source agenda.
