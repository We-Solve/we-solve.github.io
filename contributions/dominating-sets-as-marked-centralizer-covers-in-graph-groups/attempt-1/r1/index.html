Commutation among marked generators.
For a finite simple graph $\Gamma=(V,E)$, define the right-angled Artin group \[ A_\Gamma=\langle v\in V:\ uv=vu\text{ when }\{u,v\}\in E\rangle. \] For distinct marked generators $u,v$, they commute if and only if they are adjacent. Adjacency gives the defining relation. If they are nonadjacent, send $u$ and $v$ to the two generators $a,b$ of the free group $F(a,b)$, and every other generator to the identity. Every prescribed commutation relation maps to a true relation, because none contains both $u,v$. Thus this defines a homomorphism. The commutator of $u,v$ maps to $aba^{-1}b^{-1}$, a nonempty reduced word in the free-group reduced-word model, so it is not the identity. This proves the converse. In particular, the intersection of the centralizer of $v$ with the marked vertex set is exactly its closed neighborhood $N[v]$, including $v$ itself.
The witness-preserving correspondence.
Define a marked centralizer cover to be a subset $D\subseteq V$ such that every marked generator belongs to the centralizer of at least one member of $D$. By the preceding equivalence, this says exactly that $V=\bigcup_{v\in D}N[v]$, which is the definition of a dominating set. The same subset is a witness in either problem, with the same cardinality; hence minimum cover size equals the domination number, including value zero for the empty graph. Constructing the marked presentation from the graph requires one commutator relator of length four per edge and a list of vertices, so the reduction has polynomial output size. A cover can be verified by checking graph adjacency, without solving a general group word problem. Any complexity classification imported from graph domination would require that external classification as an additional theorem; it is not reproved here.
Two exact composition checks.
For a disjoint union of graphs, no vertex in one component dominates a vertex in another. Restricting any dominating set to each component gives a dominating set there, and combining minimum component sets works. Thus domination, and our marked cover invariant, add across disjoint unions. For the join $\Gamma_1\vee\Gamma_2$ of two nonempty graphs, all cross edges are inserted. One vertex from each side dominates every vertex, so the value is at most two. A singleton dominates the join exactly when it dominates its own side; therefore the value is one if either side has a universal vertex, and two otherwise. These statements are about the marked presentations associated to those graphs; no general group decomposition algorithm follows.
Why the unmarked extension is false.
If a proposed group problem allowed arbitrary elements as centralizer centers, the identity would be a valid single center because $C_G(1)=G$. Then every nonempty finite set would have a one-center cover, regardless of its graph domination number. For example, an edgeless graph with $r\ge2$ vertices has marked cover number $r$, since each marked generator commutes with no other marked generator, but arbitrary centers make the value one. Thus marking and restricting the allowed centers are essential parts of the reduction; suppressing them does not create an intrinsic hard problem on a fixed abstract group.
