Research attempt: A character distinguisher with exact sampler dependence

Let a finite abelian group $G$ act freely and transitively on $\mathcal X$, and fix $E_0$. Assume there is a homomorphism $\chi:G\to\{\pm1\}$ and an available map $L:\mathcal X\to\{\pm1\}$ satisfying $L(gE_0)=\chi(g)$. Given a triple $(A,B,C)$, accept the Diffie--Hellman distribution when \[ L(C)=L(A)L(B). \tag{1} \] If $(A,B,C)=(aE_0,bE_0,(ab)E_0)$, the test always accepts, directly by the homomorphism identity. In the independent distribution, suppose $a,b,c$ are independent draws with character means $\beta_A,\beta_B,\beta_C$. Then the sign $Z=\chi(a)\chi(b)\chi(c)$ has expectation $\beta_A\beta_B\beta_C$ by independence. Since $\mathbf1\{Z=1\}=(1+Z)/2$, the acceptance probability is \[ {1+\beta_A\beta_B\beta_C\over2}, \] and the difference in acceptance probabilities is $(1-\beta_A\beta_B\beta_C)/2$. For a common sampler with mean $\beta$, this is $(1-\beta^3)/2$.

If $\chi$ is nontrivial and the group draws are uniform, multiplication by any element of character $-1$ bijects its two fibers. Thus $\beta=0$, the independent acceptance probability is $1/2$, and equal-prior classification by $1$ has success probability $3/4$. If the sampler is supported on $\ker\chi$, then $\beta=1$ and the same test has no distinguishing advantage at all. If it is supported on the other coset, $\beta=-1$ and the test distinguishes perfectly, because products return to the kernel while the independent third element does not. Hence the ideal-sampling convention can change this particular test from useless to perfect without changing its algebra.

More generally, suppose a readable surjective homomorphism $\varphi:G\to Q$ to a finite group of order $q$ is given. Under uniform independent group elements its images are uniform: each fiber is a coset of the kernel and has the same size. The analogous test $\varphi(c)=\varphi(a)\varphi(b)$ therefore accepts the independent distribution with probability $1/q$ and the DH distribution with probability one. Readability from the public orbit point is the essential computational premise; the mere existence of an abstract quotient supplies no algorithm to evaluate it.

A further boundary blocks an automatic genus-sign argument. If $|G|$ is odd, a homomorphism $G\to\{\pm1\}$ cannot be nontrivial: a nontrivial map would partition $G$ into two equally sized kernel cosets, contradicting odd cardinality. This does not rule out other distinguishers, but it proves that a nontrivial sign character must be justified before applying $1$.
