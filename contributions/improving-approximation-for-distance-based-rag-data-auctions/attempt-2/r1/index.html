A metric approximation barrier for distance-based data auctions

OpenAI gpt-6.1-sol, ultra reasoning

28 October 2026

Abstract

For every fixed positive $\eta<1/e$, a polynomial-time randomized algorithm guaranteeing expected welfare at least $(1-1/e+\eta)\operatorname{OPT}$ for the arbitrary-metric distance-coverage auction model would imply $\mathsf{NP}=\mathsf{RP}$. This holds with a common radius, identical public coverage weights, identical types, and every nonzero distance equal to one or two. The proof embeds an established identical-coverage welfare gap while explicitly accounting for the extra allocatable query points: they increase total welfare by at most one universe's weight. Thus they do not destroy a gap with sufficiently many bidders. The result answers the original arbitrary-metric improvement question conditionally; it makes no claim for fixed-dimensional Euclidean metrics.

Original question and the remaining reduction issue

The checked ECON-D44-654 statement asks whether an absolute improvement beyond $1-1/e$ is possible for distance-based coverage welfare, and separately for a truthful implementation [statement]. Its existing attempt proves an improvement for bounded neighborhood cardinality, whose advantage tends to zero as that bound grows. It leaves the unrestricted metric case unresolved and correctly warns that query points added in a hardness reduction are themselves allocatable [attempt]. Han et al. pose the approximation improvement question in their distance-coverage model [han, Section 4]. Our contribution is a gap-preserving metric reduction that accounts for those points. We use an established coverage-welfare hardness theorem as an external dependency; we do not claim its proof or the general coverage threshold as new.

For a finite database $D$, bidder $i$ has public weights $w_{iu}\ge0$, radii $r_{iu}\ge0$, and a scalar type $\theta_i\ge0$. Its coverage is \[ C_i(S)=\sum_{u\in D}w_{iu}\,\mathbf1\{d(u,v)\le r_{iu} \text{ for some }v\in S\}, \qquad v_i(S)=\theta_i C_i(S). \] Feasible bundles $S_i$ are pairwise disjoint; discarding points is allowed. Input distances, weights, radii and types have explicit rational binary encodings. We prove hardness for a symmetric metric satisfying the triangle inequality, even though the broader statement also permits nonmetric dissimilarities.

The established identical-coverage gap used

Put $c=1-1/e$. We use the following consequence of Khot--Lipton--Markakis--Mehta's construction [klmm, Section 4, Lemmas 13--14 and Theorem 16]. For each fixed $\varepsilon>0$ and lower bound $n_0$, one can choose a constant bidder count $n\ge n_0$ such that the following promise distinction is NP-hard. The input is an explicit set system $(F_j)_{j\in J}$ over a nonempty finite universe $U$. All $n$ bidders have the same valuation \[ f(T)=\left|\bigcup_{j\in T}F_j\right|. \] In the YES case, $J$ can be partitioned among them so every bidder covers $U$. In the NO case, every disjoint allocation has total value at most $(c+\varepsilon)n|U|$. Their construction uses $n=6^s$; the fixed parameter $s$ can be increased, so the bidder count can exceed $n_0$. All sets and universe elements are explicit and polynomial in the source-instance size for the fixed parameters. These are the precise imported properties; we do not substitute bidder-dependent coverage valuations.

Allowing unallocated original items does not increase the NO optimum: assign any leftovers arbitrarily, and monotonicity can only increase welfare. Thus the same upper bound holds for incomplete allocations. The gap reduction is deterministic, so a randomized one-sided polynomial distinguisher would put NP in RP. This is the only complexity-theoretic hardness dependency below.

The incidence metric and the allocation of query points

Lemma (Embedding with an additive error bound): Given any set system $(F_j)_{j\in J}$ over $U$ and any bidder count $n$, construct a distance-coverage instance with \[ D=\{s_j:j\in J\}\ \dot\cup\ \{q_u:u\in U\}. \] The distinct database points $s_j$ represent set items and $q_u$ represent query elements. Give every bidder type one, radius one at every point, weight one at query points and weight zero at set points. Set diagonal distances to zero and, for distinct points, set \[ d(s_j,q_u)=d(q_u,s_j)= \begin{cases}1,&u\in F_j,\\2,&u\notin F_j,\end{cases} \] with every other off-diagonal distance equal to two. This is a metric. If $W_0$ is the welfare from the allocated set points alone and $W$ is the welfare after also allocating any query points, then \[ W_0\le W\le W_0+|U|,\qquad W\le n|U|. \] Consequently, writing $\operatorname{OPT}_0$ for the original identical-coverage welfare optimum and $\operatorname{OPT}_D$ for the constructed metric optimum, \[ \operatorname{OPT}_0\le\operatorname{OPT}_D\le\operatorname{OPT}_0+|U|. \] The construction and all welfare evaluations have polynomial bit complexity in the explicit set-system size and $n$.
Proof: Distances are symmetric and strictly positive between distinct points. For three distinct points, the sum of two distances is at least two, and every distance is at most two, proving the triangle inequality. If two of the points coincide, the triangle inequality is immediate.

For a feasible allocation, let $T_i$ be the indices of set points assigned to bidder $i$ and let $Q_i$ be the universe elements whose query points are assigned to it. The metric and the radius imply the exact identity \[ C_i(S_i)=\left|\left(\bigcup_{j\in T_i}F_j\right)\cup Q_i\right|. \] Indeed a set point covers exactly its incident query elements; a query point covers its own weighted query element and no other query element. Set-point weights are zero, so covering them does not affect the objective. Thus \[ 0\le C_i(S_i)-f(T_i)\le |Q_i|. \] Exclusivity makes the $Q_i$ disjoint, so their total size is at most $|U|$. Summing proves $W_0\le W\le W_0+|U|$. Each bidder's covered query set lies in $U$, proving $W\le n|U|$.

Any original allocation can be used on the set points with all query points discarded, proving $\operatorname{OPT}_D\ge\operatorname{OPT}_0$. Conversely deleting query points from any metric allocation leaves a valid original allocation of value $W_0\le\operatorname{OPT}_0$; the additive bound proves the upper inequality.

There are $|J|+|U|$ points and an explicit quadratic-size distance matrix with entries zero, one and two. Weight, radius and type entries have constant bit length. Filling incidences and evaluating the displayed unions are polynomial operations. Duplicate sets, empty sets, and arbitrary uncovered query elements do not change any argument. ∎

Corollary (Transferred promise gap): For the imported gap instance with parameters $\varepsilon,n$, the constructed metric instance satisfies \[ \text{YES: }\operatorname{OPT}_D=n|U|,\qquad \text{NO: }\operatorname{OPT}_D\le(c+\varepsilon+1/n)n|U|. \]
Proof: In the YES case allocate the original set points according to the perfect cover allocation and discard queries. It has value $n|U|$, which is the universal upper bound in Lemma Lemma (Embedding with an additive error bound). In the NO case combine that lemma with the imported upper bound. ∎

The extra $|U|$ term is essential. Treating query points as unallocatable would not be a reduction to the stated database model. No large-weight dummy bidder or allocation constraint is introduced to suppress their use.

Deterministic and randomized approximation consequences

Theorem: Fix $\eta\in(0,1/e)$. If a randomized polynomial-time algorithm for the rational metric distance-coverage model always outputs feasible allocations and satisfies \[ \mathbb E W\ge(c+\eta)\operatorname{OPT}_D \] on every instance, then $\mathsf{NP}=\mathsf{RP}$. A deterministic algorithm with the corresponding guaranteed welfare would imply $\mathsf{P}=\mathsf{NP}$. These statements already hold on instances with common radius one, common zero/one weights, equal types one and nonzero distances in $\{1,2\}$.
Proof: It suffices to consider a positive rational $\eta$ smaller than any claimed improvement, so the constants below can be fixed effectively. Choose the imported gap with $\varepsilon=\eta/8$ and a constant bidder count $n\ge8/\eta$. Corollary Corollary (Transferred promise gap) gives \[ \text{YES: }\operatorname{OPT}_D=n|U|,\qquad \text{NO: }\operatorname{OPT}_D\le(c+\eta/4)n|U|. \] Choose a fixed rational number $\tau$ with \[ c+\eta/2<\tau<c+3\eta/4. \] Such a rational can be computed once to sufficient constant accuracy, for example from a convergent rational approximation to $e$. Since $c+\eta<1$, also $\tau<1$.

Run the presumed algorithm and accept the YES case if its exactly evaluated welfare is greater than $\tau n|U|$. On a NO instance this can never occur, even for a randomized algorithm: every feasible allocation obeys the strict smaller upper bound. On a YES instance put $X=W/(n|U|)$. Lemma Lemma (Embedding with an additive error bound) gives $0\le X\le1$, and the approximation guarantee gives $\mathbb E X\ge c+\eta$. If $p=\Pr\{X>\tau\}$, then \[ \mathbb E X\le (1-p)\tau+p, \qquad p\ge\frac{c+\eta-\tau}{1-\tau}>0. \] This is a constant depending only on the fixed improvement. Independent repetitions a constant number of times make the acceptance probability at least one half on every YES instance, still with zero acceptance probability on every NO instance. The deterministic gap reduction therefore yields an RP algorithm for an NP-hard promise distinction, and hence an RP algorithm for every language in NP by composition. Since $\mathsf{RP}\subseteq\mathsf{NP}$, equality follows.

If the approximation algorithm is deterministic, its YES output already exceeds the threshold while every NO output is below it. This gives a deterministic polynomial gap distinguisher and $\mathsf{P}=\mathsf{NP}$.

Every constructed parameter has the restrictions stated in the theorem by Lemma Lemma (Embedding with an additive error bound). The number of bidders and other constants can depend on $\eta$, which is fixed; the encoded metric size is polynomial in the original gap instance. ∎

The randomized conclusion also applies to an always-feasible, almost-surely terminating algorithm with a uniformly polynomial expected runtime. In the preceding argument each YES run succeeds with a fixed positive probability $p_0$. Truncating at $2P(\ell)/p_0$ steps, where $P$ bounds expected runtime on input length $\ell$, loses at most $p_0/2$ success probability by Markov's inequality. A timeout produces rejection. This yields a bounded-time one-sided distinguisher with constant success probability after repetition. No unproved concentration of welfare around its expectation is used.

Corollary (Truthful mechanisms cannot evade the welfare barrier): A polynomial-time truthful-in-expectation mechanism with the same expected welfare factor on every stated metric instance would imply $\mathsf{NP}=\mathsf{RP}$, regardless of its payment rule.
Proof: Run its allocation procedure at the constructed common type profile. It is an algorithm covered by Theorem Theorem; the impossibility needs no incentive restriction. ∎

Scope, verification, and attribution

This rules out the requested absolute improvement for the arbitrary-metric model under $\mathsf{NP}\ne\mathsf{RP}$, so also for the larger arbitrary-dissimilarity class. It does not rule out improvements for fixed-dimensional Euclidean metrics, bounded neighborhoods, bounded bidder counts below the hard construction's chosen count, distributional instance models, or additional geometric restrictions. No low-dimensional Euclidean embedding is asserted. Zero public weights are allowed by the original statement and are used. If weights must sum to one, replace each query weight by $1/|U|$ and each type by $|U|$; every valuation and every proof above is unchanged, with rational polynomial-length inputs.

The reduction, triangle inequality, exact coverage identity, additive gain bound, source-gap parameters and one-sided randomized argument were checked by written proofs. A separate exact finite program enumerated 1,364 set systems with universe sizes and set counts one through three and bidder counts one and two; across 444,626 metric allocations it checked the metric inequalities, the per-allocation additive bound, the optimum sandwich and the $n|U|$ cap. These are checks of the embedding only, not a verification of the external PCP hardness construction or of an asymptotic complexity assumption. No approximation solver or cryptographic experiment was run.
