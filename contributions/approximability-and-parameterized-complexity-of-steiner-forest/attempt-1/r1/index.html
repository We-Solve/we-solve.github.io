Steiner forest: the one-group reduction and why it gives no stronger ratio

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Fixed-parameter tractability for parameter $k$ means running time $f(k)N^{O(1)}$, where $N$ is the input length and $f$ is computable. The exponent is independent of $k$.

In Steiner Tree a weighted graph and designated terminals are given, and one minimizes the cost of a connected subgraph containing them. Steiner Forest instead specifies terminal groups or demand pairs that must each be connected, allowing distinct groups to remain disconnected.

Verbatim supplied catalogue question

Give stronger lower bounds on the approximability of the Steiner Forest problem, and characterize its fixed-parameter complexity when the parameter depends on the number of terminal sets.

The parameter route

The report allows pairwise disjoint terminal sets of unrestricted cardinality. The number $m$ of sets is not the total number of terminals and is not the number of demand pairs after expanding a large group. We test an algorithm whose parameter depends only on $m$, and a direct reduction intended to transfer stronger hardness.
An exact set-cover encoding with one terminal group.
Let a set-cover instance have a universe $U$ of $q$ elements, sets $A_1,\ldots,A_t$ whose union is $U$, and optimum cover size $\tau$. Build a graph with a root $r$, a vertex $s_j$ for each set, and a terminal vertex $v_u$ for each element. Join $r$ to every $s_j$, and join $s_j$ to $v_u$ exactly when $u\in A_j$. All edges have cost one. Use the single terminal group $\{r\}\cup\{v_u:u\in U\}$. Then the optimum Steiner-tree cost is exactly $q+\tau$.

To prove the upper bound, choose a minimum cover and its $\tau$ set vertices. Connect each to $r$, and connect each element terminal to one chosen set containing it. These edges form a connected graph with $q+\tau+1$ vertices and $q+\tau$ edges; more directly, each element is a leaf attached to a root-centered star, so it is a tree. For the lower bound, discard any unnecessary components of a feasible forest and remove cycles, which cannot increase cost. The remaining tree contains $r$, all $q$ element terminals, and some $a$ set vertices. Every element has a neighbor among those set vertices, so their sets cover $U$ and $a\ge\tau$. A finite tree on $q+a+1$ vertices has $q+a$ edges: induction removing a leaf proves this identity. Hence its cost is at least $q+\tau$. The construction and decision threshold $q+K$ have polynomial encoding length.

Consequently, an algorithm with time $f(m)N^C$, where $C$ is independent of $m$ and the parameter is bounded for $m=1$, would solve set cover in polynomial time by this exact reduction. The usual consequence "unless $P=NP$" additionally uses the classical NP-hardness of set cover; that external complexity fact is not reproved here. The reduction itself, and the implication to a polynomial set-cover algorithm, are proved completely above. This excludes the most literal group-count-only strategy under that standard complexity assumption, but does not characterize parameters that also include group sizes or other structural data.

Why the same reduction does not transfer a strong ratio.
Suppose an approximation returns a tree of cost at most $\rho(q+\tau)$. It uses at most that cost minus $q$ set vertices, so the cover extracted by the preceding argument obeys only \[ a\le\rho\tau+(\rho-1)q. \] The additive $q$ term can dominate $\tau$. For example a universe of arbitrary size may have a one-set cover. Thus this calculation does not convert a constant-factor Steiner approximation into the same factor for set cover and does not prove the stronger approximability lower bound requested by the report. Removing that additive contribution would require a different gap-preserving construction; setting those edge costs to zero changes the reduction's approximation behavior and needs a separate analysis.
