Research attempt: A rank-metric test of a naive Griesmer transfer

Work over $\mathbb F_q$. For an $\mathbb F_q$-linear subspace $C\subseteq\mathbb F_q^{m\times n}$ of dimension $k$ and minimum nonzero rank $d\geq1$, deleting any $d-1$ rows is injective on $C$. Indeed, a matrix in the kernel is supported on those rows and has rank at most $d-1$, so it must be zero. Thus \[ k\leq (m-d+1)n. \] Deleting columns similarly gives $k\leq m(n-d+1)$. This proves a rank-metric puncturing bound without importing a Hamming residual-code argument.

A direct replacement of Hamming distance by rank distance in the Hamming Griesmer formula is false if "length" means the number of matrix columns. For a concrete example let \[ I=\begin{pmatrix}1&0\\0&1\end{pmatrix},\qquad J=\begin{pmatrix}0&1\\1&1\end{pmatrix},\qquad C=\{aI+bJ:a,b\in\mathbb F_2\}. \] The matrices $I,J$ are linearly independent. The determinant of $aI+bJ$ is $a^2+ab+b^2$, equal to one for each of the three nonzero pairs $(a,b)$. Consequently this is a dimension-two binary linear matrix code, with two columns and minimum rank two. The naive Hamming formula would demand \[ 2\geq \left\lceil2\right\rceil+\left\lceil2/2\right\rceil=3, \] a contradiction. For any positive integer $t$, repeating the same matrix on $t$ diagonal blocks gives a dimension-two code of $2t$ columns and minimum rank $2t$, again violating that substitution ($2t<3t$). The puncturing bound above is attained in the $2\times2$ example: $k=(m-d+1)n=2$.

The failure has a structural explanation. A Hamming coordinate contributes an independent scalar symbol, whereas a rank-metric column here is a vector in $\mathbb F_2^2$. Treating the columns as symbols over $\mathbb F_4$ changes the logarithmic dimension and alphabet parameter. For example, the displayed two-dimensional binary space has only four codewords, not $4^2$. One cannot retain both $q=2,k=2$ and scalar Hamming coordinates while changing the metric and alphabet interpretation. A useful new Griesmer-type statement must first state these choices and its residual or puncturing operation.
