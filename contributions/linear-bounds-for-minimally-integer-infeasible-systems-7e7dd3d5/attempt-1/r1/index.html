Minimal integer infeasibility: a complete parity bound and where determinant information is lost

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

The constraint matrix $A$ is integral, with rows defining the displayed inequalities. Integer-infeasible means $P\cap\mathbb Z^n=\varnothing$; minimally integer-infeasible means deleting any one inequality produces a set containing an integer point. Full-dimensional means that $P$ has nonempty interior in $\mathbb R^n$. The parameter $\Delta$ is the maximum absolute determinant among all square submatrices of $A$.

Verbatim supplied catalogue question

Let $P=\{x\in\mathbb R^n:Ax\leq b\}$ be full-dimensional and minimally integer-infeasible, and let $\Delta$ be the maximum absolute subdeterminant of $A$. Do functions $f$ and $g$ exist such that the number $m$ of inequalities satisfies $m\leq nf(\Delta)+g(\Delta)$?

A witness-expansion route

The target asks for a bound linear in dimension when every minor is bounded. We reconstruct the general exponential parity bound, including the facet-witness construction needed to make the midpoint argument valid, and locate the exact place where it fails to use the determinant promise. This is a rederivation of the classical integer Helly mechanism, not a new linear bound.
Deletion witnesses and an integer-free enlargement.
Write the original inequalities as $a_i\cdot x\le b_i$, with $a_i,b_i$ integral, and suppose deleting any one row admits an integer point $z_i$. Thus $z_i$ satisfies all rows except possibly row $i$. Since the full system has no integer point, $a_i\cdot z_i\ge b_i+1$. Start with enlarged right sides $c_i=b_i+1/2$. The open system $a_i\cdot x<c_i$ for every $i$ still contains no integer point: for an integer point these strict inequalities imply $a_i\cdot x\le b_i$ by integrality. Moreover $z_i$ satisfies all the other enlarged inequalities strictly, since $a_j\cdot z_i\le b_j<c_j$ for $j\ne i$.

Process indices $i=1,\ldots,m$. At its step consider the nonempty set of integer points satisfying all current inequalities other than $i$ strictly. It is nonempty because it contains the original $z_i$: right sides have only increased. Their integer values $a_i\cdot z$ are bounded below by the current $c_i$, since a smaller value would put $z$ in the integer-free open system. Hence these values have a smallest integer $t_i$, attained by some point $y_i$. Replace $c_i$ by $t_i$. This is an enlargement, and it preserves absence of integer points in the open system by the definition of the minimum. The point $y_i$ now lies on boundary $i$ and strictly inside every other current inequality. Later right-side increases preserve those strict inequalities, so in the final system \[ a_i\cdot y_i=c_i, \qquad a_j\cdot y_i<c_j\quad(j\ne i). \] Each step is an existence construction; no efficient search for the minimizing integer point is asserted.

The parity argument, now valid.
If two of the $m$ points $y_i,y_j$ were congruent coordinatewise modulo two, their midpoint $u=(y_i+y_j)/2$ would be integral. For row $i$ one endpoint is on its boundary and the other is strictly below it, so the midpoint satisfies that row strictly. The same holds for row $j$, and every other row is strict at both endpoints. Thus $u$ belongs to the final open system, contradicting integer-freeness. The points occupy distinct classes of $\mathbb Z^n/2\mathbb Z^n$, of which there are $2^n$. Consequently $m\le2^n$. The proof does not actually need full-dimensionality beyond the original setting's promise.
Why directly averaging the original witnesses is invalid.
Original deletion witnesses are outside their own halfspace, rather than on its boundary. For a row $i$, one witness may violate it by more than the slack of another, so their midpoint need not satisfy it. An explicit full-dimensional example with integral data is $3x\le2$ and $-3x\le-1$. The interval $[1/3,2/3]$ is full-dimensional in one dimension, integer-free and minimal. Deletion witnesses can be chosen as $z_1=10$ and $z_2=0$, both even, but their midpoint five still violates the first inequality. Thus parity of arbitrary deletion witnesses alone cannot prove the theorem. The boundary construction is essential.
The determinant gap.
The proof above counts all $2^n$ parity classes and never uses $\Delta$. Merely observing that entries of $A$ lie in $[-\Delta,\Delta]$ gives at best $(2\Delta+1)^n$ possible rows, again exponential. Repeated rows are unnecessary in a minimal system: the weaker of two identical-left-side inequalities is redundant, and equal ones can also be deleted. But deleting duplicates does not turn that exponential row count into the requested linear bound. A useful extension must constrain the possible facet-witness or row configurations using the bounds on all higher minors, not just parity or entry sizes. No such argument is established here.

Audit

The primary question on printed page 2943 was inspected, including integrality of both $A$ and $b$. The audit checked existence and attainment of each integer minimum in the enlargement, strictness of all other facets, preservation under later steps, and the distinction between open enlarged systems and the closed original one. All steps are hand proofs, with no integer-feasibility oracle or finite enumeration used. The requested linear-in-$n$ bound for fixed general $\Delta$ remains unresolved in this attempt.
