Research attempt: A standalone fragment can capture hidden macro context

Use a small expansion language: expressions are literal strings, concatenations, or macro names. An environment maps finitely many names to expressions; its macro-dependency graph is acyclic. The value of a fragment is obtained by recursively expanding names. Let the fragment be the single macro $a$. In one environment $a=b$ and $b$ expands to the string 2; in another $a=b$ and $b$ expands to 3. Copying the fragment and the direct definition of $a$ produces identical copied bytes in both cases, yet the intended output differs. No standalone renderer receiving only that copy can preserve both meanings.

There is an exact repair for this restricted language. Collect every macro reachable from the fragment and copy each definition from its original environment. Expanding the copied fragment then produces the original value. To prove this, order the reachable macros topologically so each dependency precedes its user. Macros with no dependencies contain only literal concatenations and have the same value. Inductively, every referenced macro has the same copied value, so replacing it inside a concatenation preserves the user's value. Finally apply the same structural induction to the fragment itself. Acyclicity ensures termination; the proof does not cover recursive expansion.

Even all copied macro definitions can be captured by an ambient wrapper if duplicate names are resolved in favor of the wrapper. With copied $b=2$ and wrapper $b=3$, the fragment changes meaning. Either isolate the copied environment or rename its macro names injectively and update every reference. Injective consistent renaming preserves the dependency graph and the preceding induction. A wrapper that only makes a file syntactically complete therefore does not establish context independence.
