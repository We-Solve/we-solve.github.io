Problem 50: derivatives of the totient distribution function (Round 2)

1) ROUND-2 OBJECTIVE

Path (C) (obstruction/correction). Round 1 reduced the problem to the limiting distribution function \[ f(c)=\lim_{X\to\infty}\frac1X\#\{n\le X:\varphi(n)<cn\}\qquad(0\le c\le 1) \] (known to exist and to be continuous/strictly increasing), and asked whether there exists $x\in[0,1]$ with $f'(x)$ existing and positive.

In Round 2 we import a deep local-modulus estimate of Tenenbaum--Toulmonde for the standard distribution function \[ G(t):=\lim_{N\to\infty}\frac1N\#\{n\le N:\varphi(n)/n\le t\}\qquad(0\le t\le 1), \] which differs from $f$ only by the strict/weak inequality convention. Using it we prove a new, unconditional theorem: the left derivative of $G$ is $+\infty$ (at arbitrarily small scales) at every point of the value set $\mathcal E:=\{\varphi(n)/n\}$. Consequently, $f'(x)$ cannot exist as a finite positive number at any $x\in\mathcal E$. This gives a strong partial resolution (a dense set of obstructions) and sharply isolates what remains: any hypothetical point with $f'(x)>0$ must lie in $[0,1]\setminus\mathcal E$.

2) ROUND-1 FOUNDATION USED

We rely on the following Round 1 items.

  • Lemma 1 (Round 1). $f$ exists, is nondecreasing and continuous on $[0,1]$; moreover $f'(c)=0$ for almost all $c\in[0,1]$ (pure singularity of the associated measure).
  • Lemma 2 (Round 1). The value $\varphi(n)/n$ depends only on the radical $\mathrm{rad}(n)$.
  • Corollary 3 (Round 1). For every $c>0$, one has $f(c)>0$.

3) NEW INSIGHT / TOOL (ROUND-2)

The new tool is a local description (with power-saving error) of the largest local variations of $G$ at the special points $t\in\mathcal E$. Concretely, Tenenbaum--Toulmonde relate the increment $G(t)-G(t-\varepsilon t)$ (for $t$ in a suitable subset of $\mathcal E$) to the increment near $1$, scaled by an explicit factor \[ K(t):=\sum_{\varphi(n)/n=t}\frac1n. \] Combined with their sharp asymptotic for $G(1)-G(1-\varepsilon)$, this forces blow-up of the left difference quotients at every $t\in\mathcal E$.

4) ATTACK PLAN (ROUND-2)

  1. Identify and compute explicitly the arithmetic scaling factor $K(t)$.
  2. Prove that the value set $\mathcal E$ is dense in $[0,1]$ (to highlight the size of the obstruction).
  3. Import Tenenbaum--Toulmonde's local modulus theorem and their asymptotic at $1$.
  4. Deduce that for every $t\in\mathcal E$ the left derivative of $G$ (hence of $f$) is $+\infty$.
  5. Conclude: the original Erdős question is reduced to points $x\notin\mathcal E$.

5) WORK (ROUND-2)

5.1. The value set $\mathcal E$ is countable and dense

Lemma (Injectivity of the prime-set map): Let $P,Q$ be finite sets of primes. If \[ \prod_{p\in P}\left(1-\frac1p\right)=\prod_{q\in Q}\left(1-\frac1q\right), \] then $P=Q$.
Proof: Rewrite the equality as \[ \prod_{p\in P}\frac{p}{p-1}=\prod_{q\in Q}\frac{q}{q-1}. \] Let $r:=\max(P\cup Q)$ (with the convention $\max\varnothing=-\infty$). Observe that $r$ divides the numerator of $\frac{r}{r-1}$ once, and for any other prime $p<r$ we have $r\nmid p$ and also $r\nmid (p-1)$ because $p-1<r$. Hence the $r$-adic valuation of the left-hand side is $1$ if $r\in P$ and $0$ otherwise; similarly on the right-hand side it is $1$ if $r\in Q$ and $0$ otherwise. Therefore $r\in P$ iff $r\in Q$. Cancel the common factor $\frac{r}{r-1}$ (if present) and iterate on the next-largest prime. This yields $P=Q$. ∎
Corollary: The set \[ \mathcal E:=\left\{\frac{\varphi(n)}{n}:n\ge 1\right\}=\left\{\prod_{p\in P}\left(1-\frac1p\right):\ P\subset\mathbb P\ \text{finite}\right\} \] is countable.
Lemma (Density of $\mathcal E$ in $[0,1]$): The set $\mathcal E$ is dense in $[0,1]$.
Proof: It suffices to approximate any $x\in(0,1)$. Set $y:=-\log x>0$. Use the prime number theorem fact that $\sum_{p}1/p=+\infty$ and that the tail $\sum_{p>N}1/p$ also diverges. Fix $N$ so large that $\sum_{p>N}1/p^2<\eta$ (for a small parameter $\eta>0$ to be chosen later). Choose distinct primes $p_1<p_2<\cdots<p_k$ all $>N$ by the greedy rule: add $p_j$ as long as the partial sum $S_j:=\sum_{i\le j}1/p_i$ stays $\le y$. Since the tail sum diverges while terms $1/p$ can be made arbitrarily small, we can achieve $0\le y-S_k<\delta$ for any prescribed $\delta>0$.

Now use $\log(1-1/p)=-1/p+O(1/p^2)$, uniformly for primes $p$. Therefore \[ \sum_{i=1}^k\log\left(1-\frac1{p_i}\right) =-\sum_{i=1}^k\frac1{p_i}+O\left(\sum_{i=1}^k\frac1{p_i^2}\right) =-S_k+O(\eta). \] Exponentiating gives \[ \prod_{i=1}^k\left(1-\frac1{p_i}\right)=\exp\left(-S_k+O(\eta)\right). \] Since $S_k\in[y-\delta,y]$, we obtain $\exp(-(y+\delta)-O(\eta))\le \prod_{i\le k}(1-1/p_i)\le \exp(-y+O(\eta))$. Choosing $\delta,\eta$ arbitrarily small forces the product to lie arbitrarily close to $e^{-y}=x$. Thus $x$ lies in the closure of $\mathcal E$. Finally, $0$ is a limit point because $\prod_{p\le z}(1-1/p)\to 0$ as $z\to\infty$. ∎

5.2. The scaling factor $K(t)$ is explicit

For $t\in\mathcal E$ define (following Tenenbaum--Toulmonde) \[ K(t):=\sum_{\varphi(n)/n=t}\frac1n. \]

Lemma (Closed form for $K(t)$): Let $t\in\mathcal E$, and write $t=\prod_{p\in P}(1-1/p)$ with $P$ the unique finite set of primes from the injectivity lemma above. Then \[ K(t)=\prod_{p\in P}\frac1{p-1}. \] In particular $0<K(t)\le 1$.
Proof: By Round 1 (Lemma 2), $\varphi(n)/n$ depends only on the set of prime divisors of $n$. By the injectivity lemma, the condition $\varphi(n)/n=t$ is equivalent to: the set of prime divisors of $n$ is exactly $P$. Hence the solutions are precisely the integers of the form $n=\prod_{p\in P}p^{\nu_p}$ with all $\nu_p\ge 1$. Therefore \[ K(t)=\sum_{\nu_p\ge 1}\prod_{p\in P}p^{-\nu_p} =\prod_{p\in P}\left(\sum_{\nu\ge 1}p^{-\nu}\right) =\prod_{p\in P}\frac{1/p}{1-1/p} =\prod_{p\in P}\frac1{p-1}. \] Each factor satisfies $0<1/(p-1)\le 1$, giving $0<K(t)\le 1$. ∎

5.3. Tenenbaum--Toulmonde local modulus estimate at $t\in\mathcal E$

We quote two results from Tenenbaum--Toulmonde.

Theorem (Tenenbaum--Toulmonde: modulus at points of $\mathcal E$): There exists a function $L(u)\to\infty$ as $u\to\infty$ such that, uniformly for $0<\varepsilon<1/3$ and for all $t\in\mathcal A(\varepsilon)$, one has \[ G(t)-G(t-\varepsilon t)=K(t)\,\left(G(1)-G(1-\varepsilon)\right)+O\left(L(1/\varepsilon)^{-1/5}\right), \] where \[ \mathcal A(\varepsilon):=\left\{t\in\mathcal E:\ \exists\,n\le \varepsilon^{-1/8}\ \text{with}\ \varphi(n)/n=t\right\}. \]
Theorem (Tenenbaum--Toulmonde: asymptotic near $1$): As $\varepsilon\to 0^+$, \[ G(1)-G(1-\varepsilon)=\frac{e^{-\gamma}}{\log(1/\varepsilon)}+O\left(\frac1{\log(1/\varepsilon)^3}\right). \]

5.4. New theorem: left derivative is infinite at every $t\in\mathcal E$

Theorem (Round 2 main advance): For every $t\in\mathcal E$, \[ \lim_{h\to 0^+}\frac{G(t)-G(t-h)}{h}=+\infty. \] Equivalently, the left derivative of $G$ at $t$ is $+\infty$. In particular $G'(t)$ (hence $f'(t)$) does not exist as a finite real number for any $t\in\mathcal E$.
Proof: Fix $t\in\mathcal E$. Choose $n_0\ge 1$ with $\varphi(n_0)/n_0=t$. For $0<\varepsilon\le \min(1/3,n_0^{-8})$ we have $n_0\le \varepsilon^{-1/8}$, hence $t\in\mathcal A(\varepsilon)$. Applying the modulus theorem gives \[ G(t)-G(t-\varepsilon t)=K(t)\,\left(G(1)-G(1-\varepsilon)\right)+O\left(L(1/\varepsilon)^{-1/5}\right). \] By the asymptotic near $1$, for $\varepsilon$ sufficiently small we have $G(1)-G(1-\varepsilon)\ge \tfrac12 e^{-\gamma}/\log(1/\varepsilon)$. Also $L(1/\varepsilon)^{-1/5}=o(1/\log(1/\varepsilon))$ as $\varepsilon\to0^+$. Thus, shrinking $\varepsilon$ if needed, \[ G(t)-G(t-\varepsilon t)\ge \frac{K(t)e^{-\gamma}}{4\log(1/\varepsilon)}. \] Divide by $\varepsilon t$: \[ \frac{G(t)-G(t-\varepsilon t)}{\varepsilon t}\ge \frac{K(t)e^{-\gamma}}{4t}\cdot \frac1{\varepsilon\log(1/\varepsilon)}\xrightarrow[\varepsilon\to0^+]{}+\infty. \] Since $h:=\varepsilon t\to 0^+$ with $\varepsilon\to 0^+$, this proves the claimed blow-up of the left derivative. Finally, the strict/weak inequality convention implies $f$ and $G$ coincide at every continuity point; since Round 1 established continuity of $f$, we may identify $f=G$ on $[0,1]$ for derivative questions. ∎
Corollary (Concrete obstruction set): If there exists $x\in[0,1]$ such that $f'(x)$ exists and is positive, then necessarily $x\notin\mathcal E$. Moreover, $\mathcal E$ is a countable dense subset of $[0,1]$ on which $f'$ fails to exist finitely.

6) ADVERSARIAL VERIFICATION

  • Quantifiers in the modulus theorem. We used the theorem only for $t\in\mathcal A(\varepsilon)$. For fixed $t=\varphi(n_0)/n_0$, we ensured $t\in\mathcal A(\varepsilon)$ by requiring $\varepsilon\le n_0^{-8}$. This is legitimate and yields a full $\varepsilon\to0^+$ sequence.
  • Edge case $t=1$. Here $n_0=1$ and $K(1)=1$. The argument gives $\frac{G(1)-G(1-\varepsilon)}{\varepsilon}\to\infty$, consistent with the theorem.
  • Uniqueness of the prime set. The injectivity lemma is crucial for the closed form of $K(t)$. We verified it using the largest prime $r$ and $r$-adic valuations, which cannot be cancelled by any $(p-1)$ with $p<r$.
  • No hidden dependence on unknown constants. The blow-up conclusion uses only that $K(t)>0$ and that $G(1)-G(1-\varepsilon)\asymp 1/\log(1/\varepsilon)$ while the error term is $o(1/\log(1/\varepsilon))$.

7) FINAL (EXACTLY ONE)

UNRESOLVED (BUT STRICTLY ADVANCED).

We proved a strong new theorem: for every rational value $t=\varphi(n)/n$ (a countable dense set), $G$ has infinite left derivative at $t$, hence $f'(t)$ cannot exist as a finite positive number. This removes an entire dense class of candidates and reduces Erdős's question to $x\in[0,1]\setminus\mathcal E$.

Problem 50: derivatives of the totient distribution function (Round 3)

1) ROUND-3 OBJECTIVE

Path (C) (obstruction/correction). Round 2 reduced Problem 50 to the limiting distribution function \[ f(c)=\lim_{X\to\infty}\frac1X\#\{n\le X:\varphi(n)<cn\}\qquad(0\le c\le 1), \] which by continuity may be identified with \[ G(u):=\lim_{X\to\infty}\frac1X\#\left\{n\le X:\frac{\varphi(n)}{n}\le u\right\}\qquad(0\le u\le1). \] Round 2 proved that at every value $t\in\mathcal E:=\{\varphi(n)/n:n\ge1\}$ (a countable dense subset of $[0,1]$), the left derivative exists in the extended sense and equals $+\infty$; so no $t\in\mathcal E$ can be a point where $f'(t)$ exists as a finite positive real number.

New goal in Round 3. We strengthen the Round 2 blow-up statement to a sharp first-order asymptotic at every $t\in\mathcal E$: \[ G(t)-G(t-h)\sim \frac{e^{-\gamma}K(t)}{\log(t/h)}\qquad(h\to0^+), \] with the explicit arithmetic factor $K(t)$. We also record a global modulus theorem (again due to Toulmonde): the supremum of the increments $G(u)-G(u-\varepsilon u)$ is asymptotic to $G(1)-G(1-\varepsilon)$ and is achieved near $u=1/2$. These refinements sharpen the obstruction: any candidate point with a finite positive derivative must lie in $[0,1]\setminus\mathcal E$ and cannot be approached along regimes where the above asymptotic is valid.

2) Round-2 FOUNDATION USED

We use the following Round 2 results as black boxes:

  • (Existence/regularity) $G$ exists, is continuous and strictly increasing on $[0,1]$, and $dG$ is purely singular; hence $G'(x)=0$ for Lebesgue-a.e. $x$.
  • (Value set) $\mathcal E:=\{\varphi(n)/n:n\ge1\}$ is countable and dense in $[0,1]$.
  • (Prime-support injectivity) if $\prod_{p\in P}(1-1/p)=\prod_{q\in Q}(1-1/q)$ for finite prime sets $P,Q$, then $P=Q$.
  • (Closed form for $K$) for $t=\prod_{p\in P}(1-1/p)\in\mathcal E$, \[ K(t):=\sum_{\varphi(m)/m=t}\frac1m=\prod_{p\in P}\frac1{p-1}. \]
  • Round 2: for each $t\in\mathcal E$ the left derivative $G'_-\\!(t)=+\infty$ (extended sense).

3) NEW INSIGHT / TOOL (ROUND-3)

The new input is a published, quantitative version of the Tenenbaum--Toulmonde local modulus relation, namely Toulmonde's Acta Arithmetica paper on the modulus of continuity of $G$. It provides:

  1. an asymptotic for $G(1)-G(1-\varepsilon)$ as $\varepsilon\to0^+$ (first-order term $e^{-\gamma}/\log(1/\varepsilon)$);
  2. a local formula for $G(t)-G(t-\varepsilon t)$ at points $t=\varphi(n)/n$ with a power-saving error term $O(L(1/\varepsilon)^{-1/5})$ for a rapidly growing $L$;
  3. a global theorem identifying $\sup_u\{G(u)-G(u-\varepsilon u)\}$ and locating where the maximum occurs.

By combining $1$ and $2$ we upgrade the Round 2 infinite-derivative statement to an actual limit for the scaled increment, yielding the sharp asymptotic on $\mathcal E$.

4) ATTACK PLAN (ROUND-3)

Round 2 gap addressed. Round 2 used only a lower bound from the local modulus relation, sufficient to force $G'_-(t)=+\infty$ on $\mathcal E$, but not to determine the precise scale of growth.

Plan.

  1. Use Toulmonde's local relation at fixed $t\in\mathcal E$, and check the quantifiers ensuring $t$ belongs to the admissible set $\mathcal A(\varepsilon)$ for all sufficiently small $\varepsilon$.
  2. Combine with the explicit asymptotic at $1$ and show the error is $o(1/\log(1/\varepsilon))$; this gives a limit constant for $(G(t)-G(t-\varepsilon t))\log(1/\varepsilon)$.
  3. Translate from $\varepsilon$ to $h=\varepsilon t$ to obtain $(G(t)-G(t-h))\log(t/h)\to e^{-\gamma}K(t)$, i.e. the sharp local asymptotic.
  4. Record Toulmonde's global maximization theorem for the modulus to complement the local picture.

5) WORK (ROUND-3)

5.1. Toulmonde's published modulus-of-continuity theorems

We use the following (specialized) form of Toulmonde's results.

Theorem (Toulmonde): Let \[ L(x):=\exp\!\left(\sqrt{\log x\,\log\log x}\right)\qquad(x\ge3). \] There exists an absolute constant $c>0$ such that:
  1. (i) As $\varepsilon\to0^+$, \[ G(1)-G(1-\varepsilon)=\frac{e^{-\gamma}}{\log(1/\varepsilon)}+O\!\left(\frac1{(\log(1/\varepsilon))^2}\right). \]
  2. (ii) For $0<\varepsilon<1/3$ and for every \[ t\in\mathcal A(\varepsilon):=\left\{\frac{\varphi(n)}n:\ 1\le n\le \varepsilon^{-1/8}\right\}, \] one has \[ G(t)-G(t-\varepsilon t)=K(t)\left(G(1)-G(1-\varepsilon)\right)+O\!\left(L(1/\varepsilon)^{-1/5}\right). \]
  3. (iii) Uniformly for $0<\varepsilon<1/3$, \[ \sup_{0\le u\le1}\{G(u)-G(u-\varepsilon u)\}=G(1)-G(1-\varepsilon)+O\!\left(L(1/\varepsilon)^{-1/5}\right), \] and any maximizer lies in a fixed interval $\left[\frac{1-\vartheta_0}{2},\frac{1+\vartheta_1}{2}\right]$ for some absolute $\vartheta_0,\vartheta_1\in(0,1)$.

5.2. The $L$--error is negligible at the $1/\log$ scale

Lemma: As $\varepsilon\to0^+$ one has \[ \log(1/\varepsilon)\,L(1/\varepsilon)^{-1/5}\longrightarrow 0. \]
Proof: Write $u:=\log(1/\varepsilon)\to\infty$. Then $L(1/\varepsilon)=\exp(\sqrt{u\log u})$, hence \[ \log(1/\varepsilon)\,L(1/\varepsilon)^{-1/5} =u\exp\!\left(-\frac15\sqrt{u\log u}\right)\xrightarrow[u\to\infty]{}0. \] ∎

5.3. Sharp first-order asymptotic at each $t\in\mathcal E$

Proposition (Limit constant at $t\in\mathcal E$): Fix $t\in\mathcal E$. Then \[ \lim_{\varepsilon\to0^+}\left(G(t)-G(t-\varepsilon t)\right)\,\log(1/\varepsilon)=e^{-\gamma}K(t). \] Equivalently, as $h\to0^+$, \[ \lim_{h\to0^+}\left(G(t)-G(t-h)\right)\,\log(t/h)=e^{-\gamma}K(t), \] and hence \[ G(t)-G(t-h)=\frac{e^{-\gamma}K(t)+o(1)}{\log(t/h)}\qquad(h\to0^+). \]
Proof: Write $t=\varphi(n_0)/n_0$ with fixed $n_0\ge1$. For any $0<\varepsilon\le n_0^{-8}$ we have $n_0\le \varepsilon^{-1/8}$, hence $t\in\mathcal A(\varepsilon)$. By Theorem Theorem (Toulmonde)(ii), \[ G(t)-G(t-\varepsilon t) =K(t)\left(G(1)-G(1-\varepsilon)\right)+O\!\left(L(1/\varepsilon)^{-1/5}\right). \] Insert Theorem Theorem (Toulmonde)(i): \[ G(t)-G(t-\varepsilon t) =K(t)\left(\frac{e^{-\gamma}}{\log(1/\varepsilon)}+O\!\left(\frac1{(\log(1/\varepsilon))^2}\right)\right) +O\!\left(L(1/\varepsilon)^{-1/5}\right). \] Multiply by $\log(1/\varepsilon)$: \[ \left(G(t)-G(t-\varepsilon t)\right)\log(1/\varepsilon) =e^{-\gamma}K(t) +O\!\left(\frac{K(t)}{\log(1/\varepsilon)}\right) +O\!\left(\log(1/\varepsilon)\,L(1/\varepsilon)^{-1/5}\right). \] Both error terms tend to $0$ by Lemma Lemma. This gives the first limit. For the $h$--version, put $h=\varepsilon t$ so that $\log(1/\varepsilon)=\log(t/h)$. ∎
Corollary (Explicit blow-up rate): For every $t\in\mathcal E$, \[ \frac{G(t)-G(t-h)}{h}\sim \frac{e^{-\gamma}K(t)}{h\log(t/h)}\qquad(h\to0^+), \] so $G'_-(t)=+\infty$ (extended sense).
Proof: Divide the asymptotic in Proposition prop:limit-constant by $h$ and use $h\log(t/h)\to0^+$. ∎

5.4. Global modulus: asymptotic size and maximizer location

Corollary (Global relative modulus): As $\varepsilon\to0^+$, \[ \sup_{0\le u\le1}\left(G(u)-G(u-\varepsilon u)\right) =\frac{e^{-\gamma}}{\log(1/\varepsilon)}+O\!\left(\frac1{(\log(1/\varepsilon))^2}\right). \] Moreover, for all sufficiently small $\varepsilon$ the supremum is attained for some $u_\varepsilon\in\left[\frac{1-\vartheta_0}{2},\frac{1+\vartheta_1}{2}\right]$ (absolute $\vartheta_0,\vartheta_1\in(0,1)$).
Proof: By Theorem Theorem (Toulmonde)(iii), \[ \sup_{u}\left(G(u)-G(u-\varepsilon u)\right)=G(1)-G(1-\varepsilon)+O(L(1/\varepsilon)^{-1/5}). \] Insert Theorem Theorem (Toulmonde)(i) and absorb the $O(L^{-1/5})$ term using Lemma Lemma. The location statement is included in Theorem Theorem (Toulmonde)(iii). ∎

6) ADVERSARIAL VERIFICATION

  • Admissibility set $\mathcal A(\varepsilon)$. For fixed $t=\varphi(n_0)/n_0$ we ensured $t\in\mathcal A(\varepsilon)$ by restricting to $\varepsilon\le n_0^{-8}$. This is sufficient to take a full $\varepsilon\to0^+$ limit.
  • Negligibility of the error. The key estimate is Lemma Lemma, which makes the $O(L^{-1/5})$ term $o(1/\log(1/\varepsilon))$.
  • Endpoint case $t=1$. Here $t=\varphi(1)/1$ and $K(1)=1$, so Proposition prop:limit-constant agrees with Theorem Theorem (Toulmonde)(i) after setting $h=\varepsilon$.
  • Change of variables. Since $h=\varepsilon t$ and $t$ is fixed, $\varepsilon\to0^+$ iff $h\to0^+$ and $\log(1/\varepsilon)=\log(t/h)$ exactly.

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 3 strengthens the Round 2 obstruction on the dense value set $\mathcal E$: for every $t\in\mathcal E$ we now have a sharp first-order asymptotic $ G(t)-G(t-h)\sim e^{-\gamma}K(t)/\log(t/h) $ and hence an explicit blow-up rate for the left derivative. We also recorded Toulmonde's global result that the maximal increments $G(u)-G(u-\varepsilon u)$ are asymptotic to $e^{-\gamma}/\log(1/\varepsilon)$ and occur near $u=1/2$. The original question---existence of a point where $f'(x)$ exists and is a finite positive number---remains open only for points $x\notin\mathcal E$, but any future attempt must accommodate these quantitatively described logarithmic spikes on the dense set $\mathcal E$.
