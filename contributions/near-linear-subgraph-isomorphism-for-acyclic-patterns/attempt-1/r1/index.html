Near-Linear Subgraph Isomorphism for Acyclic Patterns

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Subgraph isomorphism for a fixed pattern $H$ asks whether the input graph contains distinct vertices realizing all edges of $H$. Acyclic patterns are forests; near-linear time means input-linear time up to the allowed subpolynomial or logarithmic factors.

The forest direction by an explicit color dynamic program

The source asks for an if-and-only-if classification of fixed-pattern subgraph detection. We establish only the familiar forest direction, for ordinary non-induced subgraphs. Let $H$ be a fixed forest with $k\ge1$ distinctly labeled vertices and let $G$ be a simple input graph with $n$ vertices and $m$ edges. Color each vertex of $G$ independently and uniformly from $[k]$. We seek an embedding mapping pattern vertex $a$ to a host vertex of color $a$.
Proposition: For each coloring, a dynamic program decides existence of such an embedding and supplies a witness in $O(k(n+m))$ time. Repeating independently $\lceil k^k\log(1/\delta)\rceil$ times has false-negative probability at most $\delta$, for $0<\delta<1$, and has no false positives.
Proof: Root each tree component. In order from leaves to root, set $D_a(v)$ true exactly when $v$ has color $a$ and for every child $b$ of $a$ there exists a neighbor $u$ of $v$ with $D_b(u)$ true. For leaves only the color condition remains. Inductively, the condition is equivalent to an embedding of the rooted subtree with $a$ at $v$: any embedding supplies the child witnesses; conversely choose one witness for each child and combine their embeddings. They are disjoint because distinct pattern vertices have distinct prescribed colors, including vertices from different child subtrees. The same observation combines separate components. Thus a full embedding exists exactly when every component root has a true entry. Recording one neighbor witness for each child reconstructs it. Extra host edges are harmless for non-induced detection. For each pattern edge, all needed existence flags can be found by scanning host adjacency lists, costing $O(n+m)$, and leaf/color processing costs $O(kn)$. There are fewer than $k$ pattern edges. For a fixed existing embedding, the probability its $k$ host vertices receive their prescribed labels is exactly $k^{-k}$. Independent repetitions miss it with probability at most $(1-k^{-k})^R\le e^{-Rk^{-k}}\le\delta$. Every reported witness is an actual embedding, so there are no false positives. ∎
The attempted extension to cyclic patterns fails at the gluing step. A spanning-tree embedding need not satisfy a removed cycle edge. For example, a three-vertex path contains the spanning tree of a triangle but no triangle. The forest recurrence stores only the root image, so it cannot enforce compatibility with an additional previously placed endpoint without further state. This identifies the gap, not a lower bound against all possible cyclic-pattern algorithms.

Verification and remaining gaps

Small host graphs and colorings were exhaustively checked against injective embedding enumeration for paths, stars and disconnected forests. Witnesses and the triangle/path obstruction were verified. For fixed $H$ and fixed error tolerance, the running time is linear in the input graph size, but the dependence on $k$ is exponential. Neither the necessity of acyclicity nor a conditional or unconditional lower bound for every cyclic $H$ is established. A known positive half of the question is not original-target completion.
