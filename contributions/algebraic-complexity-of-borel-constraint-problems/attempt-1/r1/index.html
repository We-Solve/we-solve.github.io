The question is about the complexity of the set of Borel-solvable instances, not whether all classically satisfiable instances have Borel solutions. The example below is a concrete obstruction to confusing those two assertions; it is not a counterexample to the requested converse.

Research attempt: A Siggers operation with a measurable-selection obstruction

A template satisfying the identity.
Let $D=\{0,1\}$ with the binary disequality relation. Define $f(x_1,x_2,x_3,x_4)=x_2\mathbin\oplus x_3\mathbin\oplus x_4$, where $\oplus$ is addition modulo two. A related pair of tuples in $D^4$ differs in every coordinate. Complementing all three used inputs complements their XOR, so $f$ preserves disequality and is a homomorphism $D^4\to D$. Moreover \[ f(a,r,e,a)=r\oplus e\oplus a=f(r,a,r,e). \] Finite CSP instances for this template are ordinary bipartiteness problems: assign one vertex color zero in each component and propagate the opposite color across edges; an inconsistency is an odd closed walk and certifies unsatisfiability. On a finite graph this breadth-first procedure terminates in linear time in its vertices and edges, and if it has no inconsistency every edge has opposite endpoint colors.
A product-shift fact with a direct proof.
On $\Omega=\{0,1\}^{\mathbb Z}$ with independent fair-coordinate product measure $\mu$, let $T$ be the coordinate shift. The map $T^2$ is ergodic. Here is the needed proof. Events determined by finitely many coordinates become independent of their $T^{2j}$ translates once the coordinate sets are disjoint. Every measurable event can be approximated in measure by such events: the class of approximable events contains finite-coordinate events, is closed under complements, and is closed under countable unions by first taking a finite union whose difference in measure from the full union is small. This proves the claim for the sigma algebra they generate, and null-set completion does not change it. Approximating two events and using $\mu(E\mathbin\triangle F)$ to bound the error in an intersection proves $\mu(E\cap T^{-2j}E)\to\mu(E)^2$. If $E$ is $T^2$-invariant up to null sets, the left side equals $\mu(E)$; hence $\mu(E)\in\{0,1\}$.
A Borel instance with no measurable solution.
Remove the periodic sequences from $\Omega$. They form a countable null set: for each positive period there are finitely many periodic binary sequences, and each individual sequence has probability zero because specifying $N$ coordinates has probability $2^{-N}$. On the remaining invariant Borel set, join $x$ to $Tx$. Each component is a bi-infinite path. If a measurable proper two-coloring $c$ existed, then $c(Tx)=1-c(x)$ and $c(T^2x)=c(x)$. The event $E=\{c=0\}$ would be $T^2$-invariant, hence have measure zero or one by the proved fact. Shift invariance and the color flip would also give $\mu(E)=1-\mu(E)$, a contradiction. In ordinary set theory with choice the graph is two-colorable by selecting a representative in each orbit and assigning the parity of its shift index. The missing measurable representative is precisely what the finite propagation argument does not furnish.

This example simultaneously has an explicit required algebraic operation, tractable finite instances, and a classically solvable Borel instance without a Borel solution. None of these facts determines whether the set of codes for its Borel-solvable instances is $\boldsymbol\Sigma^1_2$-complete. That descriptive complexity assertion has different quantifiers and requires a reduction or an upper-class theorem, neither supplied here.
