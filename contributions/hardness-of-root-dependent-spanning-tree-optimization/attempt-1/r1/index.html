Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

$T^r$ denotes the directed tree obtained by orienting the chosen undirected spanning tree consistently with root $r$. The objective separately evaluates that rooted orientation using each root's cost vector.

Polynomial time means a number of elementary steps bounded by a polynomial in the encoded input length. A decision problem is in $\mathrm{NP}$ if yes-instances have polynomial-length certificates verifiable in polynomial time; NP-hardness is under polynomial-time reductions.

A spanning tree of a connected finite graph is an acyclic connected subgraph containing every vertex. Its cost is the sum of its edge costs.

An arborescence rooted at $r$ is a directed spanning tree with a unique directed path from $r$ to every other vertex; reversing all arcs gives the inward-rooted convention. The source question fixes the orientation convention.

Statement recorded in the supplied source.
Given an undirected graph $G=(V,E)$ and, for each root $r\in V$, an arc-cost vector $c_r$, prove that it is NP-hard to find a spanning tree $T$ minimizing

$$\sum_{r\in V}c_r(T^r),$$

where $T^r$ is the arborescence rooted at $r$ induced by $T$. [S2]

Scope qualification.
The outward/inward rooting convention and restrictions on arc costs follow the source.

Research attempt: Transferring the satisfiability gadget to root-dependent tree costs

Starting problem and normal form.
Use Boolean formula satisfiability, with variables and binary AND, OR and unary NOT gates. This is the standard NP-complete decision problem just identified. It can be transformed in polynomial time to a conjunction of nonempty clauses of at most three literals while preserving satisfiability. Introduce a new variable $z$ for each gate with input variables $a,b$. For an AND gate use \[ (\neg z\vee a)\wedge(\neg z\vee b)\wedge(z\vee\neg a\vee\neg b). \] If $z=1$, the first two clauses force $a=b=1$; if $z=0$, the last clause forbids $a=b=1$. Thus these clauses are equivalent to $z=a\wedge b$. For OR use \[ (z\vee\neg a)\wedge(z\vee\neg b)\wedge(\neg z\vee a\vee b). \] If $z=0$, the first two force $a=b=0$; if $z=1$, the last requires at least one input to be one. For NOT use $(\neg z\vee\neg a)\wedge(z\vee a)$, which says exactly that $z$ and $a$ differ. Add the unit clause requiring the output variable to be one. Assigning the gates their actual values extends every satisfying original assignment to the clause system; conversely the clauses force all gate values, so every satisfying clause assignment satisfies the original formula. The number of new variables and clauses is linear in the formula size. Delete tautological clauses and repeated literals without changing satisfiability. Each retained clause contains at most one sign of each variable and is nonempty. A detected empty clause can be mapped to a fixed negative target instance; an empty conjunction to a fixed positive one. These trivial cases do not affect hardness. Write the remaining variables as $x_1,\ldots,x_k$ and clauses as $C_1,\ldots,C_m$.
The directed graph and its costs.
Create a root $r$; for each variable create vertices $t_i,f_i,v_i$; and create a clause vertex $q_j$ for each clause. Add arcs \[ r\to t_i,\quad r\to f_i,\quad t_i\to v_i,\quad f_i\to v_i, \quad v_i\to q_j\ \text{when variable }x_i\text{ occurs in }C_j. \] The graph is acyclic, with four layers: root, truth selectors, variable vertices, and clauses. Every nonroot vertex is reachable because clauses are nonempty. An outward spanning arborescence must use both root-selector arcs for every variable, must choose exactly one of $t_i\to v_i,f_i\to v_i$, and must choose exactly one incoming variable arc for each clause. Conversely any such choices give an arborescence: every nonroot vertex has one parent, and following parents strictly decreases the layer until it reaches $r$. This proves reachability and excludes cycles.

Give every non-clause destination the identically zero cost vector. For destination $q_j$, give cost zero to all arcs except that a selector arc into $v_i$ has cost one exactly when its chosen truth value falsifies the literal of $x_i$ in $C_j$. A positive literal therefore makes $f_i\to v_i$ cost one and $t_i\to v_i$ cost zero; a negative literal reverses those costs. For variables absent from $C_j$, both are zero. These are destination-specific vectors with entries in $\{0,1\}$.

Read an assignment from a tree by $x_i=1$ when its parent arc is $t_i\to v_i$, and $x_i=0$ otherwise. If clause $q_j$ chooses parent $v_i$, its unique root path is $r\to t_i\to v_i\to q_j$ or the corresponding path through $f_i$. Its cost under $c^{q_j}$ is exactly one if that literal is false and zero if it is true; the other two arcs have zero cost. Since the available clause parents are precisely its variables, the minimum possible clause cost for a fixed assignment is zero when the clause is satisfied and one when it is not. Choices at distinct clause vertices are independent and never affect any variable parent. Consequently \[ \min_T\sum_{v\ne r}c^v(P^v) =\min_{\text{assignments}}\#\{\text{unsatisfied clauses}\}. \] In particular the optimum is zero if and only if the formula is satisfiable. The graph has $1+3k+m$ vertices and $4k$ plus the number of variable-clause incidences many arcs. Even explicitly listing a cost for every destination and arc takes polynomial space and time. Thus an exact optimizer for the original problem would decide satisfiability in polynomial time. This proves NP-hardness, already on these layered acyclic graphs with nonnegative binary costs.

Transfer to root-dependent costs on one undirected tree.
Forget the orientations of the layered graph just constructed, obtaining a connected undirected graph $G$. Every edge has one distinguished forward direction inherited from the layered directed graph. Let $m$ be the number of clauses and set $M=m+1$. For the distinguished root $r$, assign root-dependent arc cost $d_r(a)=0$ on each forward arc and $M$ on its reverse. For each other root $v$, assign \[ d_v(a)=0\text{ on every forward arc }a,\qquad d_v(\overleftarrow a)=c^v(a) \] on its reverse, using the destination-specific costs already defined. All values are nonnegative integers in $\{0,1,M\}$, and the full list of root-arc costs has polynomial size.

If a tree's outward orientation from $r$ contains any backward arc, its contribution from root $r$ is at least $M$. All other contributions are nonnegative. There exists a tree whose orientation from $r$ uses only forward arcs: choose any assignment and any parent for each nonempty clause. For such a tree, the total objective will be at most $m$, as verified below. Thus no optimizer has a backward arc in its $r$ orientation.

Fix now a tree oriented forward from $r$. For any other root $v$, rerooting reverses exactly the edges of the unique $r$-to-$v$ path. To prove this, remove a tree edge and consider its two components. Its direction points away from the component containing the root. The direction changes between roots $r$ and $v$ exactly when those roots lie in different components, which occurs exactly for edges on their unique connecting path. Every edge outside that path keeps its forward orientation and has $d_v$ cost zero. A path edge with original forward arc $a$ is reversed and contributes $c^v(a)$. Therefore \[ d_v(T^v)=c^v(P^v),\qquad d_r(T^r)=0. \] Summing gives equality of the root-dependent objective and the directed destination-path objective for every permitted tree. In particular a chosen assignment incurs at most one per clause, proving the earlier upper bound $m<M$ and closing the exclusion argument without circularity. It follows that the minimum root-dependent objective equals the minimum number of unsatisfied clauses, and is zero exactly for satisfiable formulas. This proves NP-hardness of the original undirected spanning-tree problem.

If the source uses inward rather than outward rooted orientations, replace each arc-cost vector by its reversal: inward $T^v$ is the reversal of outward $T^v$, so the same numerical objective and the same reduction result. No orientation convention restricts the hardness conclusion.

Verification and adversarial audit

The audit checked that all selector vertices must be spanned, not chosen as optional vertices; the assignment is encoded only by the unique parent of each variable vertex. No clause can select a variable absent from itself. Every root-to-clause path has exactly one cost-bearing selector arc under that clause's own vector. Tautological clauses and duplicate literals are explicitly removed, and the normal-form conversion preserves satisfiability in both directions. The problem asks for an optimization hardness proof, so hardness of distinguishing optimum zero suffices. Finite checks support but do not replace the proof. The rerooting lemma was checked by deleting each tree edge and comparing root components. Backward arcs are excluded by a nonnegative penalty strictly above an explicit feasible upper bound, not by assuming optimal trees already have the intended orientation. The small-instance script enumerated even trees with backward root orientations, so it tests this penalty step as well.
