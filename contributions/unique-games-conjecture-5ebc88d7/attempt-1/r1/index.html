Unique Games Conjecture

Definitions and mathematical statement

Shared notation.
Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.

A Unique Games instance assigns labels from a finite alphabet to graph vertices, with each edge imposing a permutation relation on the endpoint labels. Its value is the largest fraction of satisfiable edges. The standard conjecture asks whether, for every positive tolerance, a sufficiently large alphabet makes distinguishing near-unit value from near-zero value NP-hard.

Statement recorded in the supplied source.
For every $\varepsilon>0$, does there exist an alphabet size $k$ such that it is NP-hard to distinguish Unique-Games instances of value at least $1-\varepsilon$ from instances of value at most $\varepsilon$? [S2]

The basic pairwise marginal relaxation cannot distinguish any instance

This is a repeated Unique Games target; its identity and provenance are retained. We test the basic local-marginal linear relaxation. For a label alphabet of size $k\ge1$, use vertex probabilities $p_v(a)$ and edge joint probabilities $q_{uv}(a,b)$, nonnegative and normalized, with each edge's marginals equal to the endpoint probabilities. Maximize the average probability that an edge permutation constraint is satisfied.
Proposition: For every nonempty-edge Unique Games instance, this relaxation has optimum 1, even when no satisfying labeling exists.
Proof: Set $p_v(a)=1/k$ for every vertex and label. For each oriented constraint $b=\pi_{uv}(a)$, put $q_{uv}(a,b)=1/k$ on its $k$ allowed pairs and zero otherwise. Because $\pi_{uv}$ is a permutation, both marginals are uniform, so the assignment is feasible. Each edge is satisfied with probability 1 in its own local table; hence the relaxation attains 1, which is also the largest possible average probability. For a concrete integrality gap, take a triangle with two identity constraints on the binary alphabet and one flip constraint. The two identity edges would force all three labels equal, contradicting the flip, so no labeling satisfies all three. A constant labeling satisfies two edges, giving true value exactly $2/3$, while the marginal relaxation remains 1. ∎
The local tables cannot be combined into one global joint distribution supported on satisfying labelings in this example. Thus checking pairwise consistency is the exact failed inference. Stronger semidefinite or higher-order relaxations add information absent here, so this does not establish a barrier for all algorithms or settle the conjectured hardness gap.

Verification and remaining gaps

All eight triangle labelings and all local marginal sums were checked exactly; the values are $2/3$ and 1 as stated.
