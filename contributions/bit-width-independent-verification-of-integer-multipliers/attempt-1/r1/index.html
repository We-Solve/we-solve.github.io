Research attempt: Weighted gate identities and the arbitrary-circuit obstruction

A local certificate that telescopes.
Let $A=\sum_{i=0}^{n-1}2^i a_i$ and $B=\sum_{j=0}^{n-1}2^j b_j$, with Boolean input bits. Generate partial-product bits $q_{ij}=a_i b_j$ of weight $2^{i+j}$. Suppose a finite arithmetic network transforms these tokens into output bits using full adders: three same-weight input tokens $u,v,w$ at weight $2^h$ are replaced by a sum bit $s$ at weight $2^h$ and a carry bit $t$ at weight $2^{h+1}$. Each token is consumed once or retained as output, and the final tokens contain one bit $z_h$ at each output position (zero bits may pad missing positions). The local identity is \[ u+v+w=s+2t. \] It is checked by the four possible numbers $0,1,2,3$ of true inputs, taking $s$ as parity and $t$ as majority. A half adder satisfies $u+v=s+2t$ by the analogous three cases.

Multiply each gate identity by its input weight and sum over all gates. Every internal token appears once on each side and cancels. Therefore \[ \sum_h2^h z_h=\sum_{i,j}2^{i+j}q_{ij} =\sum_{i,j}2^{i+j}a_i b_j=AB. \] Equivalently, the output-minus-product polynomial is a linear combination of the gate polynomials and $q_{ij}-a_i b_j$, with explicit constant coefficients $\pm2^h$. This is an exact certificate of degree at most two. If the supplied network has $G$ gates and weights use $O(n)$ bits, the certificate has $O(G+n^2)$ summands with $O(n)$-bit integer coefficients. It does not expand into $2^{2n}$ input assignments. For a truncated output, the same conservation proof establishes the equality modulo $2^w$ after discarding weights divisible by $2^w$; full integer equality and modular equality are distinct specifications.

The structural conditions matter. Unaccounted fan-out, dropped carries, or wrong token weights break the cancellation proof. Local truth-table checks alone cannot establish that an arbitrary arrangement computes multiplication. Signed two's-complement conventions would require their own weighted input and truncation specification and are not silently included.

A reduction for arbitrary candidate multiplier circuits.
Let $\varphi(a_0,\ldots,a_{n-1})$ be any Boolean CNF, represented by a circuit. Construct a circuit $C_\varphi(A,B)$ by taking a correct full multiplier, retaining all output bits except bit zero, and replacing bit zero by its exclusive-or with $\varphi(A)$. The construction adds only the size of $\varphi$ and a constant number of gates. Then \[ C_\varphi(A,B)=AB\text{ for every }A,B \quad\Longleftrightarrow\quad \varphi\text{ is unsatisfiable}. \] If $\varphi$ is always false, the output is unchanged. If it is true on some $A$, the low output bit is flipped for that $A$ and every $B$, so equality fails; one may take $B=0$. Thus a general polynomial-time correctness tester for arbitrary circuits would in particular decide CNF unsatisfiability in polynomial time. This is an explicit reduction, not an unconditional impossibility theorem: no unproved separation such as $\mathrm P\ne\mathrm{NP}$ is being assumed as established.

Likewise, a polynomially checkable proof format guaranteeing polynomial-size correctness certificates for every correct arbitrary circuit would give such certificates for every unsatisfiable CNF via this construction. The simple weighted-gate certificate supplies that guarantee only for networks whose arithmetic structure has already been recognized. General-purpose recognition of that structure, or a proof system efficiently covering arbitrary correct implementations, remains the unresolved step.
