Research attempt: Even fully observed likelihood modality depends on parameterization

For a fully observed finite discrete DAG with unrestricted conditional probability rows, the likelihood factors over rows as $\prod_{i,a,k}\theta_{i,k\mid a}^{n_{i,a,k}}$. Its log is a sum of nonnegative counts times logarithms, so it is concave on the product of row simplices: $\log$ has negative second derivative, and nonnegative sums preserve concavity. A positive-total row is maximized by its empirical frequencies. To prove this including zero counts, write the positive empirical probabilities as $r_k$. The inequality $\log t\le t-1$ gives $\sum r_k\log(\theta_k/r_k)\le\sum_{r_k>0}\theta_k-1\le0$. Equality requires the stated row and zero mass on zero-count cells. A row with no observations is entirely flat. Thus all local maxima in this convex parameter space are global, while uniqueness can fail through flat rows.

This does not yield a graph-only criterion. A graph with a single observed Bernoulli node and no hidden nodes has a unique fitted success probability $p=n_1/N$ for mixed data. Reparameterize it by $p=\theta^2$, $\theta\in[-1,1]$. The same model and data have two distinct parameter maxima $\pm\sqrt{n_1/N}$; the graph and observed-node set have not changed. If one counts modes of observable distributions, both maxima represent one mode; if one counts parameter modes they are distinct. The question must fix which notion it intends.

Even natural unrestricted rows do not ensure a unique maximum for every sample: if a parent configuration is absent, its whole conditional row is unconstrained by the likelihood. Concavity does not remove this nonidentifiability. Therefore a proposed answer based solely on whether all nodes are observed overstates what complete-data factorization proves. Hidden-node placement requires still more information about state sizes, restrictions and sample quantifiers before a precise classification can be attempted.
