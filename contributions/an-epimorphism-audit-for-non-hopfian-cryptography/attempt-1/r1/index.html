Non-Hopfian maps: public lifts invert words and finite images erase kernels

Definitions and mathematical statement

Shared notation.
Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.

A group is nonabelian if some elements do not commute. It is Hopfian if every surjective endomorphism is injective; a non-Hopfian group admits a surjective endomorphism with nontrivial kernel. Using an infinite group computationally requires finite encodings of elements and explicit operations or decision problems.

Attempt and results

The source proposes infinite nonabelian platforms without a particular scheme. We test the tempting implication that a surjective noninjective endomorphism should be hard to invert. Two exact obstructions below explain why that implication needs additional distributions and encoding constraints.
Public generator lifts give an any-preimage algorithm.
Let $G=\langle a_1,\ldots,a_d\rangle$ and let $\phi:G\to G$ be surjective. Assume public words $w_i$ satisfy $\phi(w_i)=a_i$. For an input word $u=a_{i_1}^{\epsilon_1}\cdots a_{i_L}^{\epsilon_L}$, $\epsilon_j\in\{+1,-1\}$, replace each letter by $w_{i_j}^{\epsilon_j}$. The resulting word $v$ satisfies $\phi(v)=u$ by the homomorphism property. If $C=\max_i|w_i|$, its length is at most $CL$, and simple concatenation writes it using at most a constant times that many symbols. Different words representing the same group element may yield different preimages, which is allowed for an any-preimage relation. This does not recover a particular sampled preimage, obey a promised short-output distribution, or discover the lifts when they are unavailable. Surjectivity alone ensures lifts exist, not that their lengths are small or that one can find them efficiently.
Every finite homomorphic observation kills an iterated kernel.
Assume now $G$ is finitely generated and $\phi$ is a surjective endomorphism. For any finite group $Q$, the set $\operatorname{Hom}(G,Q)$ is finite: a homomorphism is determined by images of $d$ generators, so there are at most $|Q|^d$ choices. Precomposition $f\mapsto f\circ\phi$ is injective because $\phi$ is surjective. An injective map of a finite set is surjective. Thus every $f:G\to Q$ has the form $h\circ\phi$, and $f$ kills $\ker\phi$. The same argument applied to the surjective map $\phi^t$ shows that $f$ kills $\ker\phi^t$ for every $t\ge1$. Consequently distinct elements differing by an element of any iterated kernel have identical values under every finite-group homomorphism. If a target group $H$ is residually finite, meaning each nonidentity element has a nonidentity image in some finite group, any homomorphism $G\to H$ also kills these kernels: otherwise composing with a separating finite quotient contradicts the preceding result. In particular a finitely generated residually finite group cannot have a surjective noninjective endomorphism. This is a standard argument, rederived rather than treated as evidence of cryptographic hardness. It limits faithful finite homomorphic encodings; it does not say every finite byte serialization is a homomorphism.
Finite generation is genuinely needed for the finite-image claim.
Let $G=\bigoplus_{j\ge0} S_3$ be the group of finite-support sequences of permutations, with coordinatewise multiplication. It is infinite and nonabelian. The left shift $\phi(g_0,g_1,\ldots)=(g_1,g_2,\ldots)$ is a surjective endomorphism with nontrivial kernel the first $S_3$ factor; inserting an identity at the front is an explicit efficient right inverse in the finite-list encoding. The first-coordinate projection to $S_3$ does not kill that kernel. The group is not finitely generated: any finite set of sequences has support in a finite set of coordinates, as does the subgroup it generates. Thus this example both defeats non-Hopfianity-as-inversion-hardness and checks why the finite-generation hypothesis cannot be omitted above.
