Erdős--Hajnal reciprocal cycle-length sum (Problem 65) --- Round 13

1) ROUND-13 OBJECTIVE

Path chosen: (A) proof-oriented gap closure on the original 1981 conjecture. After the correction in the user's review, the relevant statement is Erdős's 1981 strengthened conjecture: for integers $n\ge 2k$, among all graphs on $n$ vertices and exactly $k(n-k)$ edges, is \[ S(G):=\sum_{\ell\in \mathcal C(G)}\frac1\ell \] minimised by the complete bipartite graph $K_{k,n-k}$?

In this round I do not claim a full proof. Instead I prove a new and quite strong reduction:

assuming the large-$d$ threshold theorem quoted in Montgomery's 2025 survey, the original 1981 conjecture is already true for every $n\ge 2d_0$, where $d_0$ is the threshold from that theorem. Consequently, only finitely many exact parameter pairs $(n,k)$ remain open.

This is the most promising next step because it works with the actual conjecture, not an over-broad reformulation, and it converts the survey's threshold statement into a finite reduction of the original exact-edge problem.

2) Round-12 FOUNDATION USED

I use the following vetted facts.

  • $F1$ For integers $a,b\ge 1$, the complete bipartite graph $K_{a,b}$ has \[ \mathcal C(K_{a,b})=\{4,6,\dots,2\min\{a,b\}\}, \qquad S(K_{a,b})=\frac12\left(H_{\min\{a,b\}}-1\right). \] In particular, \[ S(K_{k,n-k})=\frac12(H_k-1)=\frac12\left(\frac12+\frac13+\cdots+\frac1k\right) \qquad (n\ge 2k). \]

  • $F2$ Round 10 proved the exact $k=2$ line through $n=51$: \[ \min\{S(G): |V(G)|=n,\ |E(G)|=2n-4\}=\frac14 \qquad (7\le n\le 51), \] attained by $K_{2,n-2}$.

  • $F3$ Montgomery's 2025 survey states the following forthcoming theorem: there exists an integer $d_0$ such that for every integer $d\ge d_0$, among the $n$-vertex graphs with at least $d(n-d)$ edges, the quantity $S(G)$ is minimised exactly by the graph $K_{d,n-d}$.

3) NEW INSIGHT / TOOL (ROUND-13)

The new observation is a symmetry reduction which was not exploited in the earlier rounds.

The original 1981 conjecture is parameterised by the smaller part $k$ (since $n\ge 2k$), but Montgomery's threshold theorem is stated for an arbitrary parameter $d$ in the edge count $d(n-d)$. Since \[ k(n-k)=(n-k)k, \] one can apply the survey theorem with \[ d:=n-k, \] that is, with the larger part size.

Because $n\ge 2k$, we have $n-k\ge n/2$. Therefore whenever $n\ge 2d_0$ one gets \[ d=n-k\ge d_0, \] and the survey theorem applies automatically.

So the original conjecture is already settled for all sufficiently large $n$; only finitely many small values of $n$ remain.

4) ATTACK PLAN (ROUND-13)

The exact gap after Round 12 is the actual 1981 conjecture: \[ \text{for }n\ge 2k,\quad \min\{S(G): |V(G)|=n,\ |E(G)|=k(n-k)\}=S(K_{k,n-k})\ ? \]

The Round 13 plan is:

  1. restate Erdős's 1981 conjecture in its original exact-edge form;
  2. derive an exact-edge corollary from the survey's threshold theorem;
  3. apply that corollary with $d=n-k$ rather than $d=k$;
  4. conclude that every case with $n\ge 2d_0$ is solved, leaving only finitely many pairs $(n,k)$ with $n<2d_0$.

5) WORK (ROUND-13)

As before, for a graph $G$ let \[ \mathcal C(G):=\{\ell\ge 3 : \text{$G$ contains a cycle of length $\ell$}\}, \qquad S(G):=\sum_{\ell\in\mathcal C(G)}\frac1\ell. \]

5.1. Erdős's original 1981 strengthened conjecture

The relevant exact-edge statement from Erdős 1981 is:

For $n\ge 2k$, every graph $G(n; k(n-k))$ should satisfy \[ S(G)\ge \frac12\left(\frac12+\frac13+\cdots+\frac1k\right), \] and equality should be attained by the complete bipartite graph with parts of sizes $k$ and $n-k$.
By $F1$, this lower bound is exactly $S(K_{k,n-k})$.

5.2. Exact-edge corollary of the survey theorem

Lemma 5.1. Assume $F3$. Then for every integer $d\ge d_0$ and every integer $n\ge d$, \[ \min\{S(G): |V(G)|=n,\ |E(G)|=d(n-d)\}=S(K_{d,n-d}), \] and the minimiser is unique, namely $K_{d,n-d}$.

Proof. The exact-edge class \[ \{G: |V(G)|=n,\ |E(G)|=d(n-d)\} \] is a subclass of the threshold class \[ \{G: |V(G)|=n,\ |E(G)|\ge d(n-d)\}. \] By $F3$, the minimum of $S(G)$ on the larger class is attained exactly by $K_{d,n-d}$. Therefore the same is true on the smaller exact-edge class. $\square$

5.3. All sufficiently large $n$ are solved

Theorem 5.2. Assume $F3$. Let $n,k$ be integers with \[ n\ge 2k \qquad\text{and}\qquad n\ge 2d_0. \] Then among all $n$-vertex graphs with exactly $k(n-k)$ edges, \[ S(G)\ge S(K_{k,n-k})=\frac12(H_k-1), \] with equality if and only if $G\cong K_{k,n-k}$.

Proof. Fix such $n,k$, and set \[ d:=n-k. \] Since $n\ge 2k$, we have \[ d=n-k\ge n/2\ge d_0. \] Also \[ d(n-d)=(n-k)k=k(n-k). \] Therefore Lemma 5.1 applies with this value of $d$, and gives \[ \min\{S(G): |V(G)|=n,\ |E(G)|=k(n-k)\}=S(K_{d,n-d}). \] But \[ K_{d,n-d}=K_{n-k,k}\cong K_{k,n-k}, \] so the claimed conclusion follows. $\square$

5.4. Finite reduction of the original conjecture

Corollary 5.3. Assume $F3$. Then Erdős's 1981 strengthened conjecture is equivalent to the finite set of cases \[ 1\le k\le n/2 \qquad\text{and}\qquad n<2d_0. \] Equivalently, only finitely many parameter pairs $(n,k)$ remain unresolved.

Proof. By Theorem 5.2, every case with $n\ge 2d_0$ is already true. Hence only cases with $n<2d_0$ remain. For each such $n$, the constraint $n\ge 2k$ means $1\le k\le \lfloor n/2\rfloor$, so there are only finitely many pairs $(n,k)$. Conversely, if those finitely many remaining pairs are verified, then the theorem is proved for all $(n,k)$. $\square$

5.5. Interaction with the earlier $k=2$ line

Remark 5.4. Round 10 already proved the exact $k=2$ line for all $7\le n\le 51$. Combined with Corollary 5.3, this means:

  • the original 1981 conjecture is proved for all $k=2$ with $7\le n\le 51$ by direct argument;
  • it is proved for every $(n,k)$ with $n\ge 2d_0$ by Theorem 5.2;
  • therefore the only unresolved part of the original conjecture is a finite set of small parameter pairs, all lying in the box $n<2d_0$.
This is a strict improvement over the Round 11 status picture, which still described the unsolved regime as if it were an infinite family in $n$.

6) ADVERSARIAL VERIFICATION

  • Original formulation versus over-broad reformulation. Theorem 5.2 applies to Erdős's actual 1981 exact-edge conjecture, namely the case $|E(G)|=k(n-k)$ with $n\ge 2k$. It does not use the over-broad "all exact pairs $(n,m)$" formulation that the user correctly rejected.

  • Legitimacy of using $d=n-k$. The survey theorem is stated for every integer $d\ge d_0$ in the edge count $d(n-d)$. Since \[ k(n-k)=(n-k)k, \] there is no obstruction to applying it with the larger part size $d=n-k$.

  • Threshold to exact-edge passage. Lemma 5.1 is logically valid because the exact-edge class is contained in the threshold class and contains the candidate minimiser itself.

  • Finiteness claim. Corollary 5.3 leaves only pairs with $n<2d_0$ and $1\le k\le n/2$. This set is finite regardless of the (possibly unknown) size of $d_0$.

  • What is still missing. The argument does not give an explicit value of $d_0$, and therefore does not by itself yield a fully explicit finite list of remaining cases. That is the genuine remaining gap.

7) FINAL (EXACTLY ONE)

UNRESOLVED (BUT STRICTLY ADVANCED).

The corrected original 1981 conjecture is not disproved. But Round 13 proves a substantial new reduction: assuming the large-$d$ threshold theorem stated in Montgomery's 2025 survey, the original exact-edge conjecture is already true for every \[ n\ge 2d_0, \] and hence only finitely many parameter pairs $(n,k)$ remain open. So the conjecture has now been reduced from an infinite family of cases to a finite one.
