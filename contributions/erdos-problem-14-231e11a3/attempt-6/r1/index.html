Round-3 Objective

Path pursued: (C) obstruction/correction (sharpening the triangular obstruction).

Round 2 reduced $Q2$ to the existence of an "almost triangular Golomb ruler" family by proving a per-difference multiplicity bound $ |P_d(S;M)|\le E_M+1 $ (Proposition prop:triangular-golomb-obstruction$2$), where $E_M:=|[1,M]\setminus B|$.

In this round I strengthen that obstruction in a way that is strictly sharper and more structural: for each fixed difference $d$, all pairwise sums of starting points in $P_d$ (shifted by $d$) are forced to lie in the bad set. Using a sharp lower bound for restricted sumsets in $\mathbb Z$, this yields an improved multiplicity bound \[ |P_d(S;M)|\le \frac{E_M+3}{2}, \] improving the Round 2 constant by a factor $\approx 2$.

Round-2 Foundation Used

I use the following Round 2 results (as established in 14_v2.tex):
  • Lemma lem:parallelogram (parallelogram collision): if $a,a+d,c,c+d\in S$ with $a<c$ and $2a+d,2c+d\le M$, then $a+c+d\in\mathrm{Bad}(S;M)$.
  • The definitions $P_d(S;M)=\{a\in S: a+d\in S,\ 2a+d\le M\}$ and $E_M=|\mathrm{Bad}(S;M)|$.

New Insight / Tool (Round-3)

The new tool is a clique amplification of Lemma lem:parallelogram: for a fixed $d$, every pair of distinct starting points $a<c$ in $P_d$ generates a bad sum $a+c+d$. Thus the bad set contains a translate of the restricted sumset \[ P_d\oplus P_d:=\{a+c:\ a,c\in P_d,\ a<c\}. \] The key additive-combinatorial input is an elementary sharp bound in $\mathbb Z$: if $X\subset\mathbb Z$ has $|X|=k\ge 2$, then $|X\oplus X|\ge 2k-3$.

Attack Plan (Round-3)

Gap after Round 2. Round 2 gave a per-difference bound $|P_d|\le E_M+1$, obtained by extracting only $|P_d|-1$ bad sums from the difference class $d$.

Round 3 goal. Exploit all pairs in $P_d$:

  1. show $\mathrm{Bad}(S;M)$ contains $(P_d\oplus P_d)+d$ for every $d$;
  2. lower bound $|P_d\oplus P_d|$ sharply by $2|P_d|-3$;
  3. deduce the improved per-difference bound $|P_d|\le (E_M+3)/2$.
This adds a genuinely new, checkable constraint to the "triangular Golomb" reduction.

Work (Round-3)

We keep the Round 2 notation: $M\ge 2$, $S\subseteq[1,M]$, $r_S(n)$ counts unordered representations with $a\le b$, and $\mathrm{Bad}(S;M)=[1,M]\setminus B(S)$.

From a fixed difference class to a translate of a restricted sumset

Lemma (Difference class $d$ forces a translate of $P_d\oplus P_d$ into $\mathrm{Bad}$): Let $M\ge 2$ and $S\subseteq[1,M]$. Fix $d\ge 1$ and define \[ P_d:=P_d(S;M)=\{a\in S: a+d\in S\ \text{and}\ 2a+d\le M\}. \] Then for every pair $a<c$ in $P_d$ one has \[ a+c+d\in\mathrm{Bad}(S;M). \] Equivalently, \begin{equation} \label{wsref-0-65-71-3a-74-72-61-6e-73-6c-61-74-65-2d-6f-70-6c-75-73-2d-73-75-62-73-65-74-2d-62-61-64} (P_d\oplus P_d)+d\ \subseteq\ \mathrm{Bad}(S;M), \end{equation} where $P_d\oplus P_d:=\{a+c:\ a,c\in P_d,\ a<c\}$.
Proof: Let $a<c$ be in $P_d$. Then $a,a+d,c,c+d\in S$ and $2a+d,2c+d\le M$ by definition of $P_d$. Applying Lemma lem:parallelogram (Round 2) gives $a+c+d\in\mathrm{Bad}(S;M)$. This holds for every such pair $a<c$, yielding (eq:translate-oplus-subset-bad). ∎

A sharp lower bound for restricted sumsets in $\mathbb Z$

Lemma (Elementary restricted sumset bound in $\mathbb Z$): Let $X\subseteq\mathbb Z$ be finite with $|X|=k\ge 2$. Define the restricted sumset \[ X\oplus X:=\{x_i+x_j:\ x_i,x_j\in X,\ x_i<x_j\}. \] Then \begin{equation} \label{wsref-0-65-71-3a-72-65-73-74-72-69-63-74-65-64-2d-73-75-6d-73-65-74-2d-6c-62} |X\oplus X|\ge 2k-3. \end{equation}
Proof: Write $X=\{x_1<\cdots<x_k\}$. Consider the $k-1$ sums \[ x_1+x_2 < x_1+x_3 < \cdots < x_1+x_k \] and the $k-2$ sums \[ x_2+x_k < x_3+x_k < \cdots < x_{k-1}+x_k. \] All these $2k-3$ sums belong to $X\oplus X$. They are pairwise distinct: the first chain is strictly increasing; the second chain is strictly increasing; and every sum in the first chain is $\le x_1+x_k < x_2+x_k$, so the two chains are disjoint. Thus $|X\oplus X|\ge 2k-3$. ∎
Remark (On the sharpness of (eq:restricted-sumset-lb)): The bound (eq:restricted-sumset-lb) is sharp (e.g. for arithmetic progressions), but the equality case is not unique in $\mathbb Z$. For instance $X=\{0,1,3,4\}$ has $|X|=4$ and \[ X\oplus X=\{1,3,4,5,7\}, \] so $|X\oplus X|=5=2|X|-3$ even though $X$ is not an arithmetic progression. Accordingly, in this round we use only the lower bound (eq:restricted-sumset-lb).

A sharpened per-difference obstruction

Proposition (Sharpened per-difference bound): Let $M\ge 2$, $S\subseteq[1,M]$, and $E_M:=|\mathrm{Bad}(S;M)|$. For every $d\ge 1$ let $P_d=P_d(S;M)$. Then for all $d\ge 1$, \begin{equation} \label{wsref-0-65-71-3a-69-6d-70-72-6f-76-65-64-2d-70-65-72-2d-64} |P_d|\le \frac{E_M+3}{2}. \end{equation}
Proof: If $|P_d|\le 1$ then (eq:improved-per-d) is trivial. Assume $k:=|P_d|\ge 2$. By Lemma lem:pd-oplus-in-bad, $(P_d\oplus P_d)+d\subseteq\mathrm{Bad}(S;M)$, hence \[ E_M\ge |(P_d\oplus P_d)+d| = |P_d\oplus P_d|. \] Applying Lemma lem:restricted-sumset-2k-3 gives $|P_d\oplus P_d|\ge 2k-3$, so $E_M\ge 2k-3$, i.e. $k\le (E_M+3)/2$. ∎
Remark (Relation to Round 2 bounds): Round 2 obtained $|P_d|\le E_M+1$ from a single anchored family of bad sums. Proposition Proposition (Sharpened per-difference bound) strengthens this to roughly half the allowance by exploiting all pairs $a<c$ in $P_d$ via the translate containment (eq:translate-oplus-subset-bad).

Adversarial Verification

I stress-test the new claims.
  • Boundary $|P_d|=0,1$. Lemma lem:pd-oplus-in-bad is vacuous and Proposition Proposition (Sharpened per-difference bound) gives $|P_d|\le (E_M+3)/2$, automatic.

  • Range of forced bad sums. For $a<c\in P_d$, we used Lemma lem:parallelogram, which already verifies $a+c+d\le M$ under the triangle hypotheses. Here those hypotheses are built into $P_d$, so there is no hidden assumption.

  • Potential collapse of many pairs into few sums. The map $(a,c)\mapsto a+c$ is not injective, so one cannot deduce $|P_d\oplus P_d|=\binom{|P_d|}{2}$. Lemma lem:restricted-sumset-2k-3 is exactly the tool that controls this collapse from below.

  • Compatibility with Round 2. The new bound implies the Round 2 bound (since $(E_M+3)/2\le E_M+1$ for all $E_M\ge 1$), so no contradiction arises.

Final

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 3 strengthens the Round 2 triangular obstruction: for each $d\ge 1$ the bad set contains $(P_d\oplus P_d)+d$, hence \[ E_M\ge |P_d\oplus P_d|\ge 2|P_d|-3, \] so the per-difference multiplicity bound improves from $|P_d|\le E_M+1$ to $|P_d|\le (E_M+3)/2$.

The principal open gap remains: determine whether there exists an infinite nested family $A\subseteq\mathbb N$ for which $E_M=o(\sqrt M)$, equivalently whether the cumulative constraints on all difference classes $P_d(A\cap[1,M];M)$ can be met simultaneously for all large $M$.
