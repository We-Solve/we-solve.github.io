#A.1 Agrawal: A Polynomial Time Algorithm for Testing Primality

The primality testing algorithm we present is based upon the following identity: n is prime if and only if $1 + X$n ≡ 1 + Xn (mod n),

where we consider this congruence as an identity in the polynomial ring $ Z/n Z$[ X]. This easily gives a randomized algorithm which runs in polynomial time: rather than verifying it completely (which would be far too expensive), you verify it modulo a randomly chosen degree log n polynomial Q(X); repeating this sufficiently often, you expect to witness a failure of this congruence to hold fairly quickly if n is composite.

Conjecture. To prove that n is prime, it is enough to let Q(X) run over the set

{X − 1, X 2 − 1,..., X log 2 n − 1}.

We were unable to prove this conjecture, but, instead the modified conjecture, which is then a proposition:

Proposition (Modified conjecture). To prove that n is prime, it is enough to let Q(X) run over the set

R = {$X + a$r − 1: 1 ≤ r ≤ 16(log n)5, 1 ≤ a ≤ 8(log n)7/2},

except when n has a 'small' prime factor ( ≤ (log n)5). [S2]

Recovered target and exact test

The primary lecture distinguishes the initial conjecture, which tests $(1+X)^n=1+X^n$ modulo $(n,X^r-1)$ for all positive periods up to $\log^2n$, from a modified proposition with shifts and a larger range. This attempt studies the former. We do not transfer the latter's proof to it. Let $n>1$ and an integer cutoff $L\ge1$ be fixed; the logarithm convention determines $L$ but is irrelevant to the lemmas below.
Cyclic-binomial criterion and divisor pruning.
Division by the monic polynomial $X^r-1$ gives a unique representative of degree below $r$ over $\mathbb Z/n\mathbb Z$. Since $X^k=X^{k\bmod r}$, the $r$-test is equivalent to the $r$ congruences \[ \sum_{\substack{0\le k\le n\\k\equiv j\pmod r}}\binom nk \equiv {\bf1}_{j=0}+{\bf1}_{j\equiv n\pmod r}\pmod n, \quad 0\le j<r. \] If $d\mid r$, then $X^d-1$ divides $X^r-1$ by the finite geometric series identity, so passing the $r$-test implies passing the $d$-test. Every $d\le L$ has a multiple $r$ in $(L/2,L]$: take $r=d\lfloor L/d\rfloor$; if $d\le L/2$, then $r>L-d\ge L/2$, and if $d>L/2$ use $r=d$. Thus testing all periods through $L$ is exactly equivalent to testing the upper half of this range. This is only a deterministic redundancy reduction; it proves no primality soundness at the logarithmic cutoff.
Why the unquotiented identity is stronger.
For prime $n$, all intermediate binomial coefficients are divisible by $n$, since the numerator $n!$ contains $n$ and neither denominator factorial does. Thus every quotient test passes. Conversely suppose $n$ is composite and $p\mid n$ is prime. Then $p<n$ and $\binom np=(n/p)\binom{n-1}{p-1}$. Modulo $p$, the second factor is $\prod_{i=1}^{p-1}(-i)/i=(-1)^{p-1}=1$, including $p=2$. Therefore its $p$-adic valuation is zero and $v_p(\binom np)=v_p(n)-1$. The coefficient cannot be divisible by $n$, so the identity in the full polynomial ring fails. Quotienting folds this bad coefficient together with others, however; the coefficient argument gives no reason its cyclic sum must remain nonzero at some $r\le\log^2n$. That uncancelled cyclic sum is the missing step.
Low-period tests really can miss a composite.
For odd $n$, reduction modulo $X^2-1$ gives equal even and odd binomial sums $2^{n-1}$, by adding and subtracting $(1+1)^n$ and $(1-1)^n$ over the integers. The two-period test is therefore equivalent to $2^{n-1}\equiv1\pmod n$; the one-period test is the same condition for odd $n$. The composite $341=11\cdot31$ satisfies it: $2^{10}\equiv1\pmod{11}$ and $2^5\equiv1\pmod{31}$, and both exponents divide $340$. The first congruence follows from $2^{10}=1024\equiv1\pmod{11}$; the second from $2^5=32$. Coprimality then gives the modulus $341$. An exact Python cyclic-binomial calculation also found that period three passes, while period four has residual coefficients $(340,340,1,1)$ modulo $341$, in increasing degree order. Thus this number is not a counterexample to the all-period conjecture. The finite calculation illustrates cancellation and is not evidence of soundness for arbitrary integers.

Reduction modulo prime divisors alone loses additional information: for $n=p^a$, repeated characteristic-$p$ binomial expansion gives $(1+X)^n=1+X^n$ modulo $p$, although the preceding coefficient argument shows failure modulo $p^a$ when $a>1$. A proof using only distinct prime residue fields must still recover the prime-power information.
