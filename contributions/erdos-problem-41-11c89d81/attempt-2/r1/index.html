OUTPUT 1) FORMAL RESTATEMENT Definitions/Conventions. - For $N\ge 1$, write $A(N):=|A\cap\{1,\dots,N\}|$. - "Triple sums are all distinct aside from trivial coincidences" is interpreted as the $B_3$ condition: for any $a_1\le a_2\le a_3$ and $b_1\le b_2\le b_3$ in $A$, \[a_1+a_2+a_3=b_1+b_2+b_3 \implies (a_1,a_2,a_3)=(b_1,b_2,b_3).\] Equivalently, the multiset $\{a,b,c\}$ is uniquely determined by its sum $a+b+c$.

Question. If $A\subset\mathbb N$ is infinite and satisfies the above $B_3$ condition, must one have \[\liminf_{N\to\infty} \frac{A(N)}{N^{1/3}}=0?\]

4) WORK Lemma 1 ($B_3$ implies Sidon for infinite sets). Let $A\subset\mathbb N$ be infinite and satisfy the $B_3$ condition above. Then $A$ is a Sidon set (a $B_2$ set): if $a,b,c,d\in A$ with $a\le b$, $c\le d$ and $a+b=c+d$, then $\{a,b\}=\{c,d\}$.

Proof. Assume $a+b=c+d$ with $\{a,b\}\ne\{c,d\}$. Since $A$ is infinite, choose $e\in A$ with $e\notin\{a,b,c,d\}$. Then \[a+b+e=c+d+e.\] Apply the $B_3$ property to the triples $(a,b,e)$ and $(c,d,e)$ (after sorting each nondecreasingly). Because $e$ occurs in both triples and $e\notin\{a,b,c,d\}$, equality of the multisets $\{a,b,e\}=\{c,d,e\}$ forces $\{a,b\}=\{c,d\}$, contradicting the assumption. $\square$

Lemma 2 (Counting bound in $[1,N]$). Let $N\ge 1$, and let $S\subseteq\{1,\dots,N\}$ be a finite set such that all sums $x+y+z$ with $x\le y\le z$ in $S$ are distinct. Writing $k:=|S|$, one has \[\binom{k+2}{3}\le 3N-2,\] and hence $k \ll N^{1/3}$ (e.g. $k\le (18N)^{1/3}+2$).

Proof. The number of multisets of size $3$ chosen from a $k$-element set is $\binom{k+2}{3}$, and these correspond exactly to the triples $x\le y\le z$ in $S$. By assumption, all the sums $x+y+z$ for such triples are distinct integers. Moreover, since $1\le x,y,z\le N$, each such sum lies in the interval $\{3,4,\dots,3N\}$, which has size $3N-2$. Therefore the number of such triples is at most $3N-2$, i.e. $\binom{k+2}{3}\le 3N-2$. The displayed explicit bound on $k$ follows from $\binom{k+2}{3}=\frac{k(k+1)(k+2)}{6}\ge \frac{k^3}{6}$. $\square$
