Erdős Problem #591: the ordinal $\omega^{\omega^2}$

A block gluing theorem and a precise obstruction, 24 September 2026.

Statement and corrected literature status

The question is whether $\alpha\to(\alpha,3)^2$ for $\alpha=\omega^{\omega^2}$, with the red copy required to preserve order type. The older local attempt treated this as open. The current page records the positive solution of Schipperus and Darby. Schipperus's primary abstract states that $\omega^{\omega^\beta}\to(\omega^{\omega^\beta},3)^2$ when $\beta$ is the sum of one or two indecomposable ordinals; here $\beta=2=1+1$ qualifies. We do not substitute this citation for a reconstructed general proof. The work below isolates and proves a block case.

A finite-partition fact

For every countable ordinal $\gamma$, any finite partition of $\omega^\gamma$ has a class of order type $\omega^\gamma$. Here is a transfinite induction. The case $\gamma=0$ is a singleton. For $\gamma=\delta+1$, divide into $\omega$ consecutive blocks of type $\omega^\delta$, apply induction inside each, and take infinitely many blocks selecting the same class. For a nonzero countable limit $\gamma$, choose strictly increasing $\gamma_j$ cofinal in $\gamma$ and divide into blocks of type $\omega^{\gamma_j}$. Again one class occurs on an infinite subsequence; its union has type $\omega^\gamma$, because those exponents are cofinal. The equality of the ordinal sum with $\omega^\gamma$ follows from continuity of ordinal exponentiation and its upper bound by the ambient ordinal. In particular, any proper finite coloring of a blue graph on $\omega^{\omega j}$ has a color class which is a red clique of that entire order type.

A complete block-uniform case

Decompose \[\alpha=\sum_{j=1}^{\infty}\omega^{\omega j} \] into consecutive blocks $I_j$. Suppose the edge coloring has these two extra properties: the blue graph inside each $I_j$ has finite chromatic number (the bound may depend on $j$), and all edges between any fixed pair $I_i,I_j$ have one common color. Assume that there is no blue triangle.

Color the pair $\{i,j\}$ by that common interblock color. This quotient coloring on $\mathbb N$ also has no blue triangle: choosing one vertex from each of three such blocks would otherwise give one upstairs. It therefore has an infinite red set of indices $J$. To justify this last elementary assertion, if a chosen index has infinitely many blue neighbors they form an infinite red clique; otherwise repeatedly remove its finite blue neighborhood and continue in its infinite red neighborhood.

Within each $I_j$, $j\in J$, apply the finite-partition fact to a proper finite blue coloring. Obtain a red clique $R_j$ of type $\omega^{\omega j}$. Every cross edge between these selected cliques is red by the quotient choice. Since $J$ is unbounded in $\mathbb N$, \[\operatorname{otp}\left(\bigcup_{j\in J}R_j\right) =\sum_{j\in J}\omega^{\omega j}=\omega^{\omega^2}. \] This proves the original conclusion for this precise class of colorings, including cases with no uniform finite bound on the chromatic numbers of the individual blocks.

Why separate large red blocks cannot simply be joined

Take two consecutive blocks of any infinite order type $\lambda$. Color within each block red and every cross edge blue. There is no blue triangle, since among three vertices two lie in one block. Both blocks are red copies of $\lambda$, but no red clique meets both. Thus the mere existence of many individually large red pieces is not a gluing argument. The uniform quotient and an infinite red set of indices are what justify the union in the preceding proof. In a general coloring, the cross edges between two blocks need not be uniform. Also, the induced blue graphs inside the blocks can have infinite chromatic number. Neither difficulty is removed by the finite-partition lemma. The old local restriction to an initial segment of type $\omega^\omega$ is valid relative to Chang's theorem, but likewise does not resolve either obstacle.

Outcome and remaining gap

Attempt status: unresolved. The transfinite finite-partition lemma and the stated block gluing theorem are proved. Arbitrary edge colorings on $\alpha$ are not handled; their structural analysis is the substantial missing part of the known solution. No new resolution or local formal verification is claimed.
