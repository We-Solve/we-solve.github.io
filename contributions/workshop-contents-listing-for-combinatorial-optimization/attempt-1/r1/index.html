A source-specific route within the contents listing

The source is a contents list of separate talks. It supplies no single theorem to solve. One listed item concerns balanced independent sets in the Boolean cube; the actual report defines balance as selecting equally many vertices from the two parity classes. The following small exact analysis tests the route of using an ordinary maximum independent set and then balancing it. It does not replace the whole contents listing by a new conjecture. Let $Q_3$ have vertex set $\{0,1\}^3$, with adjacency at Hamming distance one. Its ordinary independence number is four, whereas its largest balanced independent set has size two.
Proof: The even-parity class is an independent set of size four. The four disjoint edges obtained by flipping the first coordinate meet every vertex, and an independent set takes at most one vertex from each edge, proving the upper bound four. Any two distinct even vertices differ in exactly two coordinates. Each has three odd neighbors; they have exactly two common odd neighbors, so the union of their odd neighborhoods has size four, exhausting the odd class. Therefore no independent set can contain two even and any odd vertices. By symmetry the analogous assertion holds with parity reversed. A balanced independent set cannot have two vertices in each class. The antipodal vertices $000$ and $111$ are nonadjacent and have opposite parity, attaining size two. ∎
Balancing the displayed ordinary optimum, which consists entirely of even vertices, by deletion alone leaves only the empty set. Thus an ordinary maximum-independent-set computation followed by this deletion rule loses the entire balanced optimum on this cube.
