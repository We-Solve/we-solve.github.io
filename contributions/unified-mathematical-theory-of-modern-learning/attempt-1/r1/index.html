Testing a function-only dynamical synthesis

A unified theory has no stated acceptance criterion. One concrete route is to treat the represented function, rather than redundant network parameters, as the full state of training. We test whether Euclidean parameter gradient flow descends to an autonomous differential equation on that function alone. Take a scalar two-layer linear network with output $f=wh$, target zero, and loss $L(w,h)=\tfrac12(wh)^2$. The represented function on scalar inputs is $x\mapsto fx$.
Proposition: No function $F$ can describe all these parameter-gradient trajectories by $\dot f=F(f)$ independently of factorization.
Proof: The gradients give $\dot w=-wh^2$ and $\dot h=-w^2h$. Therefore \[ \dot f=\dot w h+w\dot h=-(w^2+h^2)f. \] For every $t>0$, initialization $(w,h)=(t,t^{-1})$ represents exactly $f=1$, but its initial derivative is $-(t^2+t^{-2})$. At $t=1$ this is $-2$, and at $t=2$ it is $-17/4$. A single $F(1)$ cannot equal both. ∎
The difference is not observational disagreement about the initial represented function; it comes from the Euclidean geometry of distinct parameterizations. Augmenting the function state with a tangent metric or other optimization information may remove this obstruction, but doing so and predicting its evolution is additional work.

Verification and remaining gaps
