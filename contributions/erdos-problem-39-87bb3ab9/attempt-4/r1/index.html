3) NEW INSIGHT / TOOL (ROUND-2)

  • Mixed-radix encoding with carry-free addition: represent integers in a base $b_1,b_2,\dots$ where each digit is $<b_j/2$, so that addition of two encoded numbers is digitwise (no carries).
  • Discrete logarithm digit selection: choose digits $x_j(p)$ so that $g_j^{x_j(p)}\equiv p\pmod{q_j}$ for a primitive root $g_j$ mod a prime $q_j$.
  • Deletion-by-largest-element: characterize all possible repeated sums, then remove from the sequence the largest term in each potential collision. If the removed set is thin enough, the counting function is essentially unchanged.

5) WORK (ROUND-2)

5.1. Mixed radix and carry-free addition

Fix integers $b_j\ge 2$. Every $n\in\mathbb N$ has a unique expansion \[ n = x_1 + x_2 b_1 + x_3 b_1 b_2 + \cdots + x_k b_1\cdots b_{k-1} \] with digits $0\le x_j<b_j$ and $x_k\ne 0$. (Proof: repeated Euclidean division; uniqueness by induction.) We write this as the digit string $n=x_k\cdots x_1$.
Lemma (Carry-free digitwise sums): If $0\le u_j,v_j\le b_j-1$ and $u_j+v_j<b_j$ for every $j$, then \[ \sum_{j\ge1} u_j\prod_{t<j} b_t\; +\; \sum_{j\ge1} v_j\prod_{t<j} b_t \] has digit string $(u_j+v_j)_j$. In particular equality of two such sums implies equality digitwise.
Proof: This is immediate from the uniqueness of mixed-radix expansions: no carry occurs in any digit, so the coefficient of $\prod_{t<j}b_t$ in the sum is exactly $u_j+v_j$. ∎

5.2. Choice of primes and the discrete-log digit map

Choose a sequence of primes $(q_j)_{j\ge1}$ such that \begin{equation} \label{wsref-0-65-71-3a-71-6a-2d-67-72-6f-77-74-68} 2^{2j-1}<q_j\le 2^{2j+1}\qquad(j\ge1). \end{equation} Existence is easy, e.g. by Bertrand's postulate applied to $2^{2j-1}$. Set \[ b_j := 4q_j. \] For each $j$, fix a primitive root $g_j$ modulo $q_j$ (exists since $\mathbb F_{q_j}^\times$ is cyclic).

Fix a parameter $c$ with $0<c<\tfrac12$. Partition the prime numbers into blocks \begin{equation} \label{wsref-0-65-71-3a-50-6b-64-65-66} \mathcal P = \bigcup_{k\ge2} P_k,\qquad P_k := \left\{p\text{ prime}: 2^{c(k-1)^2-3}<p\le 2^{ck^2-3}\right\}. \end{equation}

Definition (Digit assignment): For $p\in P_k$ define digits $x_j(p)$ by \begin{equation} \label{wsref-0-65-71-3a-64-69-67-69-74-63-6f-6e-67} g_j^{x_j(p)}\equiv p\pmod{q_j},\qquad q_j+1\le x_j(p)\le 2q_j-1\qquad(1\le j\le k), \end{equation} and set $x_j(p):=0$ for $j>k$. Define the integer \begin{equation} \label{wsref-0-65-71-3a-61-70-64-65-66} a_p := x_1(p) + x_2(p)b_1 + \cdots + x_k(p) b_1\cdots b_{k-1}, \end{equation} i.e. the digit string $a_p=x_k(p)\cdots x_1(p)$ in base $(b_j)$. Let \[ A_{q,c}:=\{a_p: p\in\mathcal P\}. \]
Lemma (Well-defined digits): For each $p\in\mathcal P$ and each $j\ge1$, the digit $x_j(p)$ in (eq:digitcong) exists and is unique. Moreover, for all $j$ and all $p$ we have $0\le x_j(p)\le 2q_j-1<b_j$.
Proof: Fix $j$ and a prime $p\ne q_j$. Since $g_j$ is a primitive root mod $q_j$, there exists an exponent $e$ such that $g_j^e\equiv p\pmod{q_j}$. Replacing $e$ by $e+t(q_j-1)$ does not change $g_j^e\bmod q_j$. The interval $[q_j+1,2q_j-1]$ has length $q_j-1$, so it contains exactly one representative of the congruence class $e\pmod{q_j-1}$. That representative is $x_j(p)$. The stated inequalities are immediate. ∎

5.3. Injectivity and the counting function of $A_{q,c}$

Proposition (Injectivity): The map $p\mapsto a_p$ is injective, so $A_{q,c}$ is an infinite set.
Proof: Suppose $a_p=a_{p'}$. By uniqueness of mixed-radix expansion, $x_j(p)=x_j(p')$ for all $j$. Let $k$ be the largest index with $x_k(p)\ne0$; by construction $p,p'\in P_k$. For each $1\le j\le k$ we have $p\equiv g_j^{x_j(p)}\equiv g_j^{x_j(p')}\equiv p'\pmod{q_j}$. Hence $p\equiv p'\pmod{Q}$ where $Q:=q_1\cdots q_k$. From (eq:qj-growth) we get \[ Q > \prod_{j=1}^k 2^{2j-1} = 2^{\sum_{j=1}^k(2j-1)} = 2^{k^2}. \] Also $|p-p'|<2^{ck^2-3}\le 2^{ck^2}$ (since $p,p'\le 2^{ck^2-3}$), and because $c<1$ we have $2^{ck^2}<2^{k^2}$ for all sufficiently large $k$. Thus the only way to have $Q\mid(p-p')$ is $p-p'=0$, i.e. $p=p'$. ∎
Proposition (Growth of $A_{q,c}$): Let $A_{q,c}(x):=|A_{q,c}\cap[1,x]|$. For any fixed $0<c<\tfrac12$ we have \[ A_{q,c}(x)=x^{c+o(1)}\qquad(x\to\infty). \]
Proof: Let $B_k:=b_1\cdots b_k$. From (eq:qj-growth) we have \[ 2^{2j+1}<b_j\le 2^{2j+3} \quad\Rightarrow\quad 2^{\sum_{j=1}^k(2j+1)}<B_k\le 2^{\sum_{j=1}^k(2j+3)}. \] Since $\sum_{j=1}^k(2j+1)=k^2+2k$ and $\sum_{j=1}^k(2j+3)=k^2+4k$, we get \begin{equation} \label{wsref-0-65-71-3a-42-6b-2d-61-73-79-6d-70} 2^{k^2+2k}<B_k\le 2^{k^2+4k}. \end{equation} Given $x$, choose $k$ such that $B_k<x\le B_{k+1}$. Then (eq:Bk-asymp) implies $k^2=\log_2 x+o(\log x)$.

Lower bound. If $p\le 2^{ck^2-3}$ then $p\in P_\ell$ for some $\ell\le k$, and by construction $a_p< B_k<x$. Hence \[ A_{q,c}(x)\ge \pi(2^{ck^2-3}). \] By the prime number theorem, $\pi(2^{ck^2-3})=2^{ck^2+o(k^2)}=x^{c+o(1)}$.

Upper bound. If $p>2^{c(k+1)^2-3}$ then $p\in P_\ell$ for some $\ell\ge k+2$, and then $a_p\ge B_{\ell-1}\ge B_{k+1}\ge x$. Thus \[ A_{q,c}(x)\le \pi(2^{c(k+2)^2-3})=2^{c(k+2)^2+o(k^2)}=x^{c+o(1)}. \] Combining gives the claim. ∎

5.4. Structure of repeated sums in $A_{q,c}$

The key point is that digitwise addition is carry-free: by Lemma Lemma (Well-defined digits), each digit satisfies $x_j(p)\in\{0\}\cup[q_j+1,2q_j-1]$. So for any two primes $p,p'$, \[ 0\le x_j(p)+x_j(p')\le (2q_j-1)+(2q_j-1)=4q_j-2<b_j. \] Thus Lemma Lemma (Carry-free digitwise sums) applies.
Proposition (Congruence constraints from a repeated sum): Assume we have a nontrivial repeated sum in $A_{q,c}$, i.e. \begin{equation} \label{wsref-0-65-71-3a-72-65-70-73-75-6d} a_{p_1}+a_{p_2}=a_{p_1'}+a_{p_2'},\qquad \{p_1,p_2\}\ne\{p_1',p_2'\}. \end{equation} Reorder the four terms so that $a_{p_1}>a_{p_1'}\ge a_{p_2'}>a_{p_2}$. Then there exist integers $k_1\ge k_2\ge2$ such that
  1. (i) $p_1,p_1'\in P_{k_1}$ and $p_2,p_2'\in P_{k_2}$;
  2. (ii) letting $Q_1:=q_1\cdots q_{k_2}$, we have \[p_1p_2\equiv p_1'p_2'\pmod{Q_1};\]
  3. (iii) if $k_2<k_1$ and $Q_2:=q_{k_2+1}\cdots q_{k_1}$ then \[p_1\equiv p_1'\pmod{Q_2};\]
  4. (iv) the indices satisfy \[ (1-c)k_1^2<k_2^2<\frac{c}{1-c}k_1^2 \] for all sufficiently large $k_1$.
Proof: By Lemma Lemma (Carry-free digitwise sums), (eq:repsum) implies digitwise equality \begin{equation} \label{wsref-0-65-71-3a-64-69-67-69-74-65-71} x_j(p_1)+x_j(p_2)=x_j(p_1')+x_j(p_2')\qquad\text{for all }j\ge1. \end{equation} Define $k_1$ as the largest $j$ with $x_j(p_1)+x_j(p_2)\ge q_j+1$. Since a digit is either $0$ or at least $q_j+1$, the condition "$\ge q_j+1$" means that at least one of $p_1,p_2$ has nonzero $j$th digit. So $k_1$ is the maximum of the block indices of $p_1,p_2$. Similarly define $k_2$ as the largest $j$ with $x_j(p_1)+x_j(p_2)\ge 2q_j+2$. Because $2q_j+2$ is the minimum of a sum of two nonzero digits, this means both primes have nonzero $j$th digit, so $k_2$ is the minimum of the two block indices. Applying the same definitions to the right side of (eq:repsum) and using (eq:digiteq) yields (i).

For (ii), fix $j\le k_2$. Then all four primes lie in blocks $\ge j$, so by definition $g_j^{x_j(p)}\equiv p\pmod{q_j}$ for each of $p=p_1,p_2,p_1',p_2'$. Raising $g_j$ to both sides of (eq:digiteq) gives \[ g_j^{x_j(p_1)+x_j(p_2)}\equiv g_j^{x_j(p_1')+x_j(p_2')}\pmod{q_j} \quad\Rightarrow\quad p_1p_2\equiv p_1'p_2'\pmod{q_j}. \] This holds for every $j\le k_2$, hence modulo $Q_1=q_1\cdots q_{k_2}$.

For (iii), assume $k_2<k_1$ and take $k_2<j\le k_1$. Then $p_2,p_2'$ lie in $P_{k_2}$, so their $j$th digits are $0$, while $p_1,p_1'\in P_{k_1}$ so $g_j^{x_j(p_1)}\equiv p_1$ and $g_j^{x_j(p_1')}\equiv p_1'\pmod{q_j}$. Equation (eq:digiteq) becomes $x_j(p_1)=x_j(p_1')$, so $p_1\equiv p_1'\pmod{q_j}$. Multiplying over $j=k_2+1,\dots,k_1$ gives $p_1\equiv p_1'\pmod{Q_2}$.

For (iv), note first that from (eq:qj-growth) we have \begin{equation} \label{wsref-0-65-71-3a-51-6c-6f-77-65-72} Q_1=q_1\cdots q_{k_2}>2^{k_2^2},\qquad Q_2=q_{k_2+1}\cdots q_{k_1}>2^{k_1^2-k_2^2}. \end{equation} Also, since $p\in P_k$ implies $p\le 2^{ck^2-3}$, we have \[ |p_1p_2-p_1'p_2'|\le p_1p_2+p_1'p_2'\le 2\cdot 2^{c(k_1^2+k_2^2)-6}=2^{c(k_1^2+k_2^2)-5}. \] If the congruence in (ii) is nontrivial then $Q_1\le |p_1p_2-p_1'p_2'|$, so by (eq:Qlower) \[ 2^{k_2^2}<Q_1\le 2^{c(k_1^2+k_2^2)-5}, \] which rearranges to $k_2^2<\frac{c}{1-c}k_1^2+O(1)$.

Similarly, if $k_2<k_1$, the congruence in (iii) is nontrivial (since $p_1\ne p_1'$ by our ordering), so $Q_2\le |p_1-p_1'|\le p_1\le 2^{ck_1^2-3}$. Using (eq:Qlower) again gives \[ 2^{k_1^2-k_2^2}<Q_2\le 2^{ck_1^2-3}, \] which rearranges to $k_2^2>(1-c)k_1^2-O(1)$. For large $k_1$ the additive constants are negligible, giving (iv). ∎

5.5. An explicit Sidon sequence with exponent $\tfrac{3-\sqrt5}{2}$

Proposition Proposition (Congruence constraints from a repeated sum)(iv) is already enough to get a purely explicit Sidon sequence beating $1/3$ without deletions.
Theorem (Cilleruelo's "warm-up" Sidon sequence): Let \[ c_0:=\frac{3-\sqrt5}{2}\approx0.381966. \] Then the set $A_{q,c_0}$ is a Sidon set and $A_{q,c_0}(x)=x^{c_0+o(1)}$.
Proof: By Proposition prop:growth we have the growth statement. If a repeated sum exists, Proposition Proposition (Congruence constraints from a repeated sum)(iv) would give \[ (1-c_0)k_1^2<k_2^2<\frac{c_0}{1-c_0}k_1^2. \] But $c_0$ is exactly the smaller root of $(1-c)^2=c$, so $c_0=(1-c_0)^2$ and therefore $\frac{c_0}{1-c_0}=1-c_0$. Hence the strict inequalities demand an integer $k_2$ lying in an empty open interval, impossible for large $k_1$. So no repeated sums occur and $A_{q,c_0}$ is Sidon. ∎

5.6. Deletion to reach exponent $c=\sqrt2-1$

Now take \[ c:=\sqrt2-1\approx0.414213. \] The set $A_{q,c}$ may have repeated sums, but Proposition Proposition (Congruence constraints from a repeated sum) shows they are highly structured. We now delete the "largest" element from every potential collision.
Definition (Bad primes and the deleted set): For $k\ge2$, call $p\in P_k$ bad if there exist primes $p_2,p_1',p_2'$ such that \begin{equation} \label{wsref-0-65-71-3a-62-61-64} a_p+a_{p_2}=a_{p_1'}+a_{p_2'}, \qquad a_p> a_{p_1'}\ge a_{p_2'}>a_{p_2}. \end{equation} Let $B_k\subseteq P_k$ be the set of bad primes in block $k$. Define the surviving prime set \[ \mathcal P^*:=\bigcup_{k\ge2} (P_k\setminus B_k), \qquad A_{q,c}^*:=\{a_p: p\in\mathcal P^*\}. \]
Lemma (Deletion destroys all repeated sums): $A_{q,c}^*$ is a Sidon set.
Proof: Suppose $A_{q,c}^*$ contains a repeated sum. Choose a representation $a_{p_1}+a_{p_2}=a_{p_1'}+a_{p_2'}$ with $a_{p_1}\ge a_{p_1'}\ge a_{p_2'}\ge a_{p_2}$ and $\{p_1,p_2\}\ne\{p_1',p_2'\}$. If $a_{p_1}=a_{p_1'}$ then injectivity (Proposition Proposition (Injectivity)) forces $p_1=p_1'$, and then equality of sums forces $a_{p_2}=a_{p_2'}$, contradicting nontriviality. Hence we may assume $a_{p_1}>a_{p_1'}\ge a_{p_2'}>a_{p_2}$. But then $p_1$ is bad by Definition Definition (Bad primes and the deleted set), so $p_1\in B_k$ for its block $k$, contradicting $p_1\in\mathcal P^*$. ∎

It remains to show that the deletion does not destroy the density exponent.

5.7. Bounding the number of bad primes

Fix $k_1\ge2$. Let $p_1\in B_{k_1}$ and choose a witness collision as in (eq:bad). By Proposition Proposition (Congruence constraints from a repeated sum) there is some $k_2<k_1$ with \begin{equation} \label{wsref-0-65-71-3a-6b-32-72-61-6e-67-65} k_2^2<\frac{c}{1-c}k_1^2, \end{equation} and writing $Q_1=q_1\cdots q_{k_2}$, $Q_2=q_{k_2+1}\cdots q_{k_1}$ we have \begin{equation} \label{wsref-0-65-71-3a-63-6f-6e-67-2d-51-31-51-32} p_1p_2\equiv p_1'p_2'\pmod{Q_1},\qquad p_1\equiv p_1'\pmod{Q_2}. \end{equation} Thus there exist nonzero integers $s_1,s_2$ such that \begin{equation} \label{wsref-0-65-71-3a-73-31-73-32} p_1p_2-p_1'p_2'=s_1Q_1,\qquad p_1'-p_1=s_2Q_2. \end{equation} From $p\in P_k\Rightarrow p\le 2^{ck^2-3}$ we get \begin{equation} \label{wsref-0-65-71-3a-73-31-62-6f-75-6e-64} |s_1|\le \frac{|p_1p_2-p_1'p_2'|}{Q_1}\le \frac{p_1p_2+p_1'p_2'}{Q_1}\le \frac{2\cdot 2^{c(k_1^2+k_2^2)-6}}{Q_1}=\frac{2^{c(k_1^2+k_2^2)-5}}{Q_1}, \end{equation} and similarly \begin{equation} \label{wsref-0-65-71-3a-73-32-62-6f-75-6e-64} |s_2|\le \frac{|p_1'-p_1|}{Q_2}\le \frac{2^{ck_1^2-3}}{Q_2}. \end{equation} Now rewrite \begin{equation} \label{wsref-0-65-71-3a-64-69-76-69-64-65-73} p_1(p_2-p_2')=(p_1p_2-p_1'p_2')+(p_1'-p_1)p_2'=s_1Q_1+s_2p_2'Q_2. \end{equation} So $p_1$ divides the integer \begin{equation} \label{wsref-0-65-71-3a-73-64-65-66} s:=s_1Q_1+s_2p_2'Q_2. \end{equation}
Definition (The integer sets $S_{k_2,k_1}$): For $k_2<k_1$ define $S_{k_2,k_1}$ to be the set of all nonzero integers of the form (eq:sdef) with parameters satisfying the bounds (eq:s1bound), (eq:s2bound) and with $p_2'\in P_{k_2}$.
Then every $p_1\in B_{k_1}$ divides some nonzero $s\in S_{k_2,k_1}$ for some $k_2$ satisfying (eq:k2range).
Lemma (No $s\ne 0$ has two large prime divisors from $P_{k_1}$): For fixed $k_1$ and $k_2$ as above, any $s\in S_{k_2,k_1}$ is divisible by at most one prime $p\in P_{k_1}$, for all sufficiently large $k_1$.
Proof: If $p,p'\in P_{k_1}$ are distinct then $pp'> (2^{c(k_1-1)^2-3})^2=2^{2c(k_1-1)^2-6}$. On the other hand, using (eq:s1bound)--(eq:s2bound) and $p_2'\le 2^{ck_2^2-3}$, \[ |s|\le |s_1|Q_1+|s_2|p_2'Q_2\le 2^{c(k_1^2+k_2^2)-5}+2^{ck_1^2-3}2^{ck_2^2-3} \le 2\cdot 2^{c(k_1^2+k_2^2)-5}. \] If $k_2$ satisfies (eq:k2range), then for $c<1/2$ we have $k_1^2+k_2^2 \le (1+\frac{c}{1-c})k_1^2=\frac{1}{1-c}k_1^2$, hence $|s|\le 2\cdot 2^{\frac{c}{1-c}k_1^2-5}$. Since $c<1/2$ implies $2c>\frac{c}{1-c}$, we have $2c(k_1-1)^2-6 > \frac{c}{1-c}k_1^2-5$ for all large $k_1$. Thus for large $k_1$, $pp'>2^{2c(k_1-1)^2-6}>|s|$, so $s$ cannot be divisible by two distinct primes from $P_{k_1}$. ∎

Lemma lem:oneprime implies the combinatorial bound \begin{equation} \label{wsref-0-65-71-3a-42-6b-2d-73-75-6d-53-6b} |B_{k_1}|\le \sum_{k_2<\sqrt{\frac{c}{1-c}}\,k_1} |S_{k_2,k_1}|. \end{equation} We now estimate $|S_{k_2,k_1}|$.

Lemma (Size of $S_{k_2,k_1}$): For fixed $k_1>k_2$ we have \[ |S_{k_2,k_1}|\le 4\left(\frac{2^{c(k_1^2+k_2^2)-5}}{Q_1}\right)\left(\frac{2^{ck_1^2-3}}{Q_2}\right)|P_{k_2}|. \]
Proof: By definition, $s$ is determined by the triple $(s_1,s_2,p_2')$. The number of possible $s_1$ is at most $2\cdot \frac{2^{c(k_1^2+k_2^2)-5}}{Q_1}$ (choices for $\pm s_1$), and the number of possible $s_2$ is at most $2\cdot \frac{2^{ck_1^2-3}}{Q_2}$. Finally $p_2'$ can be any prime in $P_{k_2}$. Multiplying gives the bound. ∎

To convert this into a bound on $|B_{k_1}|$, we use the crude estimates \begin{equation} \label{wsref-0-65-71-3a-51-31-32-2d-6c-6f-77-65-72} Q_1Q_2=q_1\cdots q_{k_1}>2^{k_1^2} \end{equation} (from (eq:qj-growth)) and the prime number theorem in the weak form $|P_{k}|\le \pi(2^{ck^2})=2^{ck^2+o(k^2)}$. For the boundary exponent $c=\sqrt2-1$ we keep one more term (a $k^{-2}$ factor) to compare against $|P_{k_1}|$.

Proposition (Bad primes are a strict minority at $c=\sqrt2-1$): Let $c=\sqrt2-1$. Then \[ |B_{k_1}|\le \left(\tfrac12+o(1)\right)|P_{k_1}|\qquad(k_1\to\infty). \] Consequently $|P_{k_1}\setminus B_{k_1}|\gg |P_{k_1}|$.
Proof: Combine (eq:Bk-sumSk) with Lemma lem:Sk-size and (eq:Q12-lower): \[ |B_{k_1}| \le \sum_{k_2<\alpha k_1} 4\cdot \frac{2^{c(k_1^2+k_2^2)-5}}{Q_1}\cdot \frac{2^{ck_1^2-3}}{Q_2}\,|P_{k_2}| \le 2^{-6}\,2^{(2c-1)k_1^2}\sum_{k_2<\alpha k_1} 2^{ck_2^2}\,|P_{k_2}|, \] where $\alpha:=\sqrt{\frac{c}{1-c}}$. Using the standard bound $\pi(x)\le 2x/\log x$ for $x$ large, we have $|P_{k_2}|\le \pi(2^{ck_2^2-3})\le \frac{2\cdot 2^{ck_2^2-3}}{ck_2^2\log 2}$ for large $k_2$. Hence \[ 2^{ck_2^2}|P_{k_2}| \le \frac{2^{-2}}{c\log 2}\,\frac{2^{2ck_2^2}}{k_2^2}. \] Therefore \begin{equation} \label{wsref-0-65-71-3a-42-2d-62-6f-75-6e-64-2d-73-75-6d} |B_{k_1}|\le \frac{2^{-8}}{c\log 2}\,2^{(2c-1)k_1^2} \sum_{k_2<\alpha k_1}\frac{2^{2ck_2^2}}{k_2^2}. \end{equation} The sum is dominated by its largest term because $2^{2ck_2^2}$ grows super-exponentially in $k_2$: for $k_2\le \alpha k_1$ and large $k_1$, the ratio between consecutive terms is at least $2^{2c(2k_2-1)}/4\ge 2^{ck_1}$, so the sum is at most twice the last term. Thus \[ \sum_{k_2<\alpha k_1}\frac{2^{2ck_2^2}}{k_2^2} \le 2\cdot \frac{2^{2c\alpha^2 k_1^2}}{\alpha^2 k_1^2}. \] Insert into (eq:B-bound-sum): \[ |B_{k_1}|\le \frac{2^{-7}}{c\log 2}\,\frac{1}{\alpha^2}\,\frac{2^{\left((2c-1)+2c\alpha^2\right)k_1^2}}{k_1^2}. \] Now $\alpha^2=\frac{c}{1-c}$, so $(2c-1)+2c\alpha^2=(2c-1)+\frac{2c^2}{1-c}=\frac{3c-1}{1-c}$. For $c=\sqrt2-1$ one checks $\frac{3c-1}{1-c}=c$ (equivalently $c^2+2c-1=0$), and also $\alpha^2=\frac{1}{\sqrt2}$. Therefore \begin{equation} \label{wsref-0-65-71-3a-42-2d-61-73-79-6d-70} |B_{k_1}|\le C\,\frac{2^{ck_1^2}}{k_1^2} \end{equation} for an explicit constant $C>0$ (here $C=2^{-7}\sqrt2/(c\log 2)$ works).

On the other hand, by the prime number theorem and the fact that $2^{c(k_1-1)^2}$ is exponentially smaller than $2^{ck_1^2}$, \begin{equation} \label{wsref-0-65-71-3a-50-6b-2d-61-73-79-6d-70} |P_{k_1}|=\pi(2^{ck_1^2-3})-\pi(2^{c(k_1-1)^2-3})=\left(\frac{2^{-3}}{c\log 2}+o(1)\right)\frac{2^{ck_1^2}}{k_1^2}. \end{equation} Comparing (eq:B-asymp) and (eq:Pk-asymp), the ratio $|B_{k_1}|/|P_{k_1}|$ is bounded above by a fixed constant strictly smaller than $1$ (in fact much smaller), for large $k_1$. In particular $|B_{k_1}|\le (\tfrac12+o(1))|P_{k_1}|$. ∎

5.8. Final explicit lower bound exponent $\sqrt2-1$

Theorem (Explicit infinite Sidon set with exponent $\sqrt2-1$): With $c=\sqrt2-1$ and $A_{q,c}^*$ as in Definition Definition (Bad primes and the deleted set), we have:
  1. $A_{q,c}^*$ is a Sidon set;
  2. its counting function satisfies \[ A_{q,c}^*(x)=x^{\sqrt2-1+o(1)}. \]
Proof: Sidonness is Lemma Lemma (Deletion destroys all repeated sums). For the counting function, Proposition prop:growth gives $|P_k|=2^{ck^2+o(k^2)}$ and hence $A_{q,c}(x)=x^{c+o(1)}$. Proposition prop:badminority shows that a positive proportion of each block $P_k$ survives the deletion. Since the block sizes grow like $2^{ck^2}$ and are overwhelmingly dominated by the last contributing block, removing a fixed fraction from each block does not change the exponent $c$. Formally, for $x$ with $B_k<x\le B_{k+1}$ we have \[ A_{q,c}^*(x)\ge \sum_{\ell\le k} |P_\ell\setminus B_\ell| \gg \sum_{\ell\le k}|P_\ell| \asymp |P_k| =2^{ck^2+o(k^2)}=x^{c+o(1)}. \] The matching upper bound $A_{q,c}^*(x)\le A_{q,c}(x)=x^{c+o(1)}$ is immediate. ∎

5.9. What this achieves toward Erdős's conjecture

The original conjecture asks for $A(x)\gg_\varepsilon x^{1/2-\varepsilon}$ for all $\varepsilon>0$. Theorem thm:main gives exponent $\sqrt2-1$. Thus it implies the conjectured bound only for those $\varepsilon$ satisfying \[ \frac12-\varepsilon \le \sqrt2-1\quad\Longleftrightarrow\quad \varepsilon\ge \frac32-\sqrt2\approx 0.085786. \] The remaining gap is to improve the exponent from $\sqrt2-1$ up to $1/2-o(1)$.

6) ADVERSARIAL VERIFICATION

I tried to break the new argument in the following ways:
  • Carry issues: digits satisfy $x_j(p)\le 2q_j-1$ and bases are $b_j=4q_j$, so $x_j(p)+x_j(p')<4q_j=b_j$. Hence Lemma Lemma (Carry-free digitwise sums) applies globally.
  • Uniqueness of digit choice: the interval $[q_j+1,2q_j-1]$ has length exactly $q_j-1$, matching the period of discrete logs in $\mathbb F_{q_j}^\times$.
  • Injectivity: requires $Q=q_1\cdots q_k$ to exceed possible differences $|p-p'|$ inside a block. This holds because $\log_2 Q\ge k^2$ whereas $\log_2|p-p'|\le ck^2+O(1)$ and $c<1$.
  • Repeated-sum classification: the key step is that the thresholds $q_j+1$ and $2q_j+2$ distinguish whether 0, 1, or 2 summands have nonzero $j$th digit. This uses the digit range $\{0\}\cup[q_j+1,2q_j-1]$.
  • Deletion correctness: any repeated sum has a largest element; removing all primes that can be the largest element of a collision eliminates all collisions.
  • Density after deletion: the borderline case $c=\sqrt2-1$ is exactly where the exponent of the bad-set bound matches the block exponent. I checked that Proposition prop:badminority keeps a constant fraction of each block (in fact, the crude constants already make the ratio far below $1/2$).
No hidden quantifier issue was found: all "for large $k$" statements can be made uniform because the inequalities have polynomial/exponential separations in $k$.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 1 established only an explicit lower bound exponent $1/3$. Round 2 constructs an explicit infinite Sidon set $A$ with \[ |A\cap[1,x]|=x^{\sqrt2-1+o(1)}. \] This is a strict and substantial improvement, but still falls short of the conjectured $x^{1/2-o(1)}$.
