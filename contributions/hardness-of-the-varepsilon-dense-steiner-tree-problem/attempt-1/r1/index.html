Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Polynomial time means a number of elementary steps bounded by a polynomial in the encoded input length. A decision problem is in $\mathrm{NP}$ if yes-instances have polynomial-length certificates verifiable in polynomial time; NP-hardness is under polynomial-time reductions.

In Steiner Tree a weighted graph and designated terminals are given, and one minimizes the cost of a connected subgraph containing them. Steiner Forest instead specifies terminal groups or demand pairs that must each be connected, allowing distinct groups to remain disconnected.

Verbatim supplied catalogue question

Prove hardness results for the $\varepsilon$-dense Steiner Tree problem, including whether exact optimization is NP-hard.

Recovered density and the cost-model issue

The report defines density by requiring every terminal to have at least $\varepsilon|V\setminus S|$ neighbors outside the terminal set $S$. It is not density among all vertices or among terminals. The dense paragraph does not repeat a cost convention; its preceding general Steiner discussion permits edge costs, while its cited dense approximation result cannot be transferred to arbitrary costs merely from unweighted neighbor counts. We therefore analyze weighted padding explicitly and then show why it fails in the unit-cost interpretation. No unweighted hardness theorem is inferred from weighted padding.
A precise weighted completion reduction.
Start with a connected finite graph with nonnegative integer edge costs and a nonempty terminal set $S$. Suppose $V\setminus S$ is nonempty; if it is empty, add a new nonterminal joined to one terminal by a cost-$H$ edge, with $H$ defined below. Let $C$ be the sum of the original edge costs and let $H=C+1$. Add every missing edge between a terminal and a nonterminal, giving every added edge cost $H$. Then each terminal is adjacent to every nonterminal, so the resulting graph is $1$-dense under the source's neighbor definition. Its optimum cost is unchanged.

Indeed the connected original graph contains a spanning tree: start from one vertex and repeatedly add an edge to an unreached vertex until all vertices are reached. This is acyclic by construction. Its cost is at most $C$ and it connects all terminals. Any tree using an added edge has cost at least $H>C$, because all costs are nonnegative. An optimal tree therefore uses only original edges, and conversely every original terminal tree is available after completion. The optimum values coincide. The same argument covers the added nonterminal, which is too expensive to occur optimally. The integer $H$ has polynomial bit length: summing $|E|$ encoded costs adds at most $\lceil\log_2|E|\rceil$ bits to their maximum bit length. At most $|S||V\setminus S|$ edges are added.

This is an exact polynomial reduction from weighted Steiner tree to its neighbor-dense weighted version. It transfers whatever exact hardness is established for the starting weighted problem. It does not prove a new source-independent NP-hardness theorem, nor does it preserve a restriction that all edge costs equal one or two.

Unit-cost padding genuinely changes the optimum.
Take a path $v_0v_1\cdots v_L$ of unit edges, with terminals $v_0,v_L$ and $L\ge4$. Its unique terminal-connecting path uses all $L$ edges, so its Steiner optimum is $L$. If one instead adds unit-cost edges from both terminals to every internal vertex, the graph becomes $1$-dense. Any internal vertex now supplies a terminal path of length two, so the new optimum is at most two. It is exactly two because there is no direct terminal-terminal edge and the terminals are distinct. The optimum has changed by a factor $L/2$, unbounded with $L$. Thus replacing expensive completion edges by unit edges destroys the exact reduction and any fixed multiplicative preservation claim.
Why cloning alone does not repair the missing reduction.
If a terminal originally sees $a$ of $b$ nonterminals, making $k$ identical clones of every nonterminal changes those counts to $ka$ and $kb$, leaving the ratio $a/b$ unchanged. Hence uniform cloning does not improve this density condition. Adding many common cheap neighbors does improve it, but introduces the shortcuts seen above. A valid unit-cost construction must reconcile these two effects; this attempt supplies none.
