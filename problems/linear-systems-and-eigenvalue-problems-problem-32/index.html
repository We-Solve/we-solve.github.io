Linear Systems and Eigenvalue Problems — Problem 32

Statement

Definitions and mathematical statement

Let $n\geq 1$ be an integer and let $\lambda=(\lambda_1,\ldots,\lambda_n)\in(0,\infty)^n$. Write $[n]=\{1,\ldots,n\}$ and interpret the source's set of "orthonormal matrices" as the real orthogonal group \[ O(n)=\{V\in{\mathbb{R}}^{n\times n}:V^\top V=I_n\}. \] The source does not explicitly specify the matrix field; this draft uses the real interpretation suggested by its transpose notation. For $V\in O(n)$, put \[ K(V)=V^\top\operatorname{diag}(\lambda_1,\ldots,\lambda_n)V. \] Thus $K(V)$ is positive definite. For an integer $k$ with $1\leq k\leq n$ and a subset $\mathcal I\subseteq[n]$ of cardinality $k$, let $K_{:,\mathcal I}$, $K_{\mathcal I,\mathcal I}$, and $K_{\mathcal I,:}$ denote the corresponding column, principal, and row submatrices. Define the trace error \[ R(K,\mathcal I)=\operatorname{Tr}\!\left(K-K_{:,\mathcal I}K_{\mathcal I,\mathcal I}^{-1}K_{\mathcal I,:}\right). \] The inverse exists because $K$ is positive definite. Define \[ x_k(\lambda)=\max_{V\in O(n)}\ \min_{\substack{\mathcal I\subseteq[n]\\|\mathcal I|=k}}R(K(V),\mathcal I). \] For $0\leq j\leq n$, define the elementary symmetric polynomial by \[ e_j(\lambda)=\sum_{\substack{J\subseteq[n]\\|J|=j}}\prod_{i\in J}\lambda_i, \qquad e_0(\lambda)=1, \] and set $e_{n+1}(\lambda)=0$. For any $K=K(V)$, volume sampling of $k$ indices, denoted $k\text{-}\mathrm{DPP}(K)$, is the probability distribution \[ \Pr(\mathcal I=J)=\frac{\det K_{J,J}}{\displaystyle\sum_{\substack{L\subseteq[n]\\|L|=k}}\det K_{L,L}} =\frac{\det K_{J,J}}{e_k(\lambda)},\qquad |J|=k. \] The supplied record states that the expected trace error depends only on $\lambda$, and gives \[ y_k(\lambda):=\mathbb E_{\mathcal I\sim k\text{-}\mathrm{DPP}(\operatorname{diag}(\lambda))} R(\operatorname{diag}(\lambda),\mathcal I) =(k+1)\frac{e_{k+1}(\lambda)}{e_k(\lambda)}. \] Requested problem. Determine sharp comparison bounds between $x_k(\lambda)$, the worst over orthogonal conjugations of the minimum trace error obtainable by selecting $k$ columns, and $y_k(\lambda)$, the volume-sampling expected trace error, as the positive spectrum $\lambda$, dimension $n$, and subset size $k$ vary.

Unresolved qualifications. The source requests "a tightness bound(s)" without specifying an additive or multiplicative comparison, the permitted dependence of a bound on $n,k,\lambda$, or a precise sharpness criterion. Consequently, it does not determine a unique inequality to prove. The source also omits the range of $k$; the definitions above use the usual nonempty-subset range $1\leq k\leq n$. At $k=n$, both quantities are zero, so a ratio comparison is undefined there; the nontrivial comparison concerns $1\leq k<n$. Inclusion of $k=0$ would require additional empty-matrix conventions not stated in the record.

Short English statement

For a prescribed positive spectrum, compare the largest possible optimal column-selection trace error with the expected trace error from volume sampling. The requested comparison should be sharp, but the source leaves its form and sharpness criterion unspecified. The registry labels this problem open; that label is supplied source data, not an independently verified assessment.
