Kourovka Notebook Problem 15.2

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $G$ be a finite group, and let $\operatorname{Irr}(G)$ denote the set of characters of its irreducible complex representations. An element $x\in G$ is called nonvanishing if \[ \chi(x)\ne 0\qquad\text{for every }\chi\in\operatorname{Irr}(G). \] Write $\mathrm{NV}(G)$ for the set of these elements, and write $F(G)$ for the Fitting subgroup of $G$, the largest nilpotent normal subgroup of $G$. The order of $x$ is denoted by $|x|$.

The source recalls Burnside's theorem that every $\chi\in\operatorname{Irr}(G)$ with $\chi(1)>1$ vanishes at some element of $G$. Thus the irreducible characters that are nonzero everywhere are precisely the linear characters. The questions below concern the dual condition on elements.

  1. (a) Is it true that for every finite solvable group $G$ and every $x\in G$, \[ \left(x\in\mathrm{NV}(G)\ \text{and}\ |x|\equiv 0\pmod 2\right) \quad\Longrightarrow\quad x\in F(G)? \] The source attributes the corresponding assertion for elements of odd order to I. M. Isaacs, G. Navarro, and T. R. Wolf (1999). Consequently, the question is equivalently whether $\mathrm{NV}(G)\subseteq F(G)$ for every finite solvable group $G$.
  2. (b) Determine, up to isomorphism, all finite nonabelian simple groups $S$ for which \[ \exists x\in S\setminus\{1\}\ \forall\chi\in\operatorname{Irr}(S),\qquad \chi(x)\ne 0. \] The source gives $\mathbb{A}_7$, the alternating group on seven letters, as an example having such an element.

The source also attributes to M. Miyamoto (2008) the assertion that every nontrivial abelian normal subgroup of a finite group contains a nonvanishing element. As supplied, this assertion does not require that element to be nonidentity; the identity is always nonvanishing since $\chi(1)$ is a positive integer. No stronger version of this ancillary assertion is assumed here. The registry labels the problem open; that label and the supplied background assertions have not been independently verified.

Short English statement

For a finite group, an element is nonvanishing if every irreducible complex character is nonzero on it. Part (a) asks whether every nonvanishing element of even order in a finite solvable group lies in its Fitting subgroup, extending the supplied odd-order result. Part (b) asks which finite nonabelian simple groups contain a nonidentity nonvanishing element. The source lists $\mathbb{A}_7$ as an example. This is a statement-only draft requiring human mathematical review.
