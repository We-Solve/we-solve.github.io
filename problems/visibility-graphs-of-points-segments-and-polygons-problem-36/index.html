Visibility Graphs of Points, Segments and Polygons — Problem 36

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $P$ be a simple polygon, and let $V(P)$ be its finite set of vertices. Under the usual closed-region visibility convention, distinct vertices $u,v\in V(P)$ are visible to each other if the segment $[u,v]$ is contained in the closed polygonal region bounded by $P$. Its visibility graph is the finite simple undirected graph $G=(V,E)$, where $V=V(P)$ and $\{u,v\}\in E$ exactly when $u$ and $v$ are visible. Let $C$ be the Hamiltonian cycle in $G$ whose cyclic vertex order follows the boundary of $P$.

Under the graph-theoretic interpretation of a hidden set, a set $H\subseteq V$ is hidden if its distinct vertices are pairwise nonadjacent: \[ \forall u,v\in H,\qquad u\ne v\Longrightarrow \{u,v\}\notin E. \] Thus a maximum hidden set is a set $H_{\max}\subseteq V$ satisfying \[ H_{\max}\text{ is hidden},\qquad |H_{\max}|=\max\left\{|H|:H\subseteq V\text{ is hidden}\right\}. \] Problem. Given $G$, promised to be the visibility graph of a simple polygon $P$, together with its specified boundary Hamiltonian cycle $C$, determine a maximum hidden set $H_{\max}$ using the supplied graph and cycle.

Short English statement

Given a polygon visibility graph and the cycle recording its boundary order, find a largest set of mutually nonvisible vertices. This interprets a hidden set as an independent set of the given graph.
