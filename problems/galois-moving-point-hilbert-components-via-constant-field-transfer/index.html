Math-1323

Galois-moving point-Hilbert components via constant-field transfer

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $G_{\mathbb{Q}}=\operatorname{Gal}(\overline{\mathbb{Q}}/{\mathbb{Q}})$. The Hilbert scheme $\operatorname{Hilb}^d({\mathbb{A}}^N_{\mathbb{Q}})$ parametrizes length-$d$ finite subschemes. Its base change to $\overline{\mathbb{Q}}$ has geometric irreducible components on which $G_{\mathbb{Q}}$ acts. The first original question asks for explicit $d,N$ and a geometric component $C$ such that $\sigma(C)\neq C$ for some $\sigma\in G_{\mathbb{Q}}$, or a proof this cannot occur. The second asks the same for the Hilbert schemes $\operatorname{Hilb}^{P}({\mathbb{P}}^3)$ with a curve Hilbert polynomial $P$. The extracted $\operatorname{Gal}({\mathbb{Q}}/{\mathbb{Q}})$ is read with the missing algebraic-closure bar restored.

The supplied existence theorem for the first clause is stronger in its Galois quantifier: \[ \forall\sigma\in G_{\mathbb{Q}}\setminus\{1\}\ \exists d,N\geq1\ \exists C\subset\operatorname{Hilb}^d({\mathbb{A}}^N_{\overline{\mathbb{Q}}}) \text{ a geometric irreducible component}:\quad\sigma(C)\neq C. \] The Hilbert scheme may depend on $\sigma$; no single finite-type Hilbert scheme is claimed to carry a faithful action on its finite set of components. The aid derives this by combining Easton--Vakil's faithful Galois action on surface-moduli components with Jelisiejew's functorial truncation and TNT-frame section--retraction constructions. It reports transfer of nontrivial component constant fields at a generic point, followed by spreading of the frame. If the source surface is canonically embedded in ${\mathbb{P}}^r$, the construction gives $N=2r+8$ and length $d=\dim_k(T/J)$ for the resulting finite frame algebra over its coefficient field $k$. The actual $r,T,J$, field, and numerical $d$ are not supplied. This is a constructive existence route, not the compact fully explicit example requested by the source.

The aid's independent degeneration statement is: every geometric irreducible component in the point-Hilbert schemes above, and in the full projective Hilbert scheme for a fixed polynomial, contains a monomial-ideal point defined over ${\mathbb{Q}}$. Consequently if $C$ is moved, there is one ${\mathbb{Q}}$-rational monomial point $m\in C$ such that \[ m\in\gamma(C)\qquad\text{for every }\gamma\in G_{\mathbb{Q}}. \] Thus all conjugates meet at $m$; when two of them are distinct, $m$ is singular on the ambient Hilbert scheme. This does not assert that $m$ is intrinsically singular on each individual component, or that a rational point forces the component to descend to ${\mathbb{Q}}$.

The reported proof uses monomial degeneration and the fact that a connected torus preserves each irreducible component, followed by the rationality of monomial ideals. For projective curves, the statement concerns the full Hilbert scheme, allowing the scheme-theoretic degenerations with the same polynomial; it is not silently asserted inside an open locus of smooth, integral, or locally Cohen--Macaulay curves that might exclude the monomial limit. The source does not specify which curve convention it intends.

The report found no answer to the second clause in fixed ${\mathbb{P}}^3$. This is a limitation of the supplied work, not a proof of nonexistence or a verified exhaustive literature conclusion. The first-clause existence transfer and the monomial collision condition do not themselves produce a Galois-moved curve component in that fixed projective space.

Short English statement

The supplied construction yields a moved point-Hilbert component for every nontrivial Galois element, but does not provide small numerical parameters or explicit defining data. A separate result says each component contains a rational monomial degeneration, so a moved component meets all its conjugates at an ambient singular point. The fixed-${\mathbb{P}}^3$ curve question is not answered in the report.
