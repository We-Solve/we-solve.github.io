Math-907

Three Structural Problems for Artin Groups

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\Gamma$ be a finite simplicial graph with vertex set $\{1,\ldots,n\}$, and assign an integer $m_{ij}\geq 2$ to each edge $\{i,j\}$. Set $m_{ij}=\infty$ when distinct vertices $i,j$ are not joined by an edge. For letters $a,b$ and a positive integer $m$, let $\operatorname{Alt}_m(a,b)$ denote the alternating word of length $m$ beginning with $a$. The associated Artin group is \[ A_\Gamma=\left\langle s_1,\ldots,s_n\ \middle|\ \operatorname{Alt}_{m_{ij}}(s_i,s_j)=\operatorname{Alt}_{m_{ij}}(s_j,s_i)\text{ whenever }i<j\text{ and }m_{ij}<\infty\right\rangle. \] There is no defining relation for a pair with $m_{ij}=\infty$.

The group $A_\Gamma$ is torsion-free if \[ \forall g\in A_\Gamma\ \forall k\in{\mathbb{Z}}_{\geq 1},\qquad g^k=1\Longrightarrow g=1. \] It has a solvable word problem if there exists an algorithm which, on every finite word in $s_1^{\pm1},\ldots,s_n^{\pm1}$, terminates and decides whether that word represents the identity in $A_\Gamma$. This is an assertion for each fixed $\Gamma$; it does not additionally require a single algorithm taking arbitrary labeled graphs as input.

To specify the conventional meaning of the third property, let \[ W_\Gamma=A_\Gamma/\langle\!\langle s_i^2\mid 1\leq i\leq n\rangle\!\rangle \] be the associated Coxeter group. A subset $T\subseteq\{1,\ldots,n\}$ is spherical if the subgroup of $W_\Gamma$ generated by the images of $s_i$, $i\in T$, is finite. Let $S_\Gamma$ be the standard Salvetti complex associated with this Coxeter system: the usual connected CW complex with one cell of dimension $|T|$ for each spherical subset $T$, with the standard Coxeter--Salvetti attaching maps. Its fundamental group is naturally $A_\Gamma$. The Artin-group $K(\pi,1)$ conjecture for $\Gamma$ asserts that $S_\Gamma$ is a $K(A_\Gamma,1)$, equivalently that its universal cover is contractible, or that \[ \pi_q(S_\Gamma)=0\qquad\text{for every integer }q\geq 2. \] Here the specified standard complex matters: merely asking whether some $K(A_\Gamma,1)$ exists would not express this conjecture.

The supplied reconstructed challenge asks whether, for every finite labeled graph $\Gamma$ as above, all three properties hold. Equivalently, it asks whether each of the following collections of labeled graphs is empty: \[ \begin{aligned} \mathcal F_{\mathrm{tor}}&=\{\Gamma:A_\Gamma\text{ has a nonidentity element of finite order}\},\\ \mathcal F_{\mathrm{word}}&=\{\Gamma:A_\Gamma\text{ has an unsolvable word problem}\},\\ \mathcal F_{K}&=\{\Gamma:S_\Gamma\text{ is not a }K(A_\Gamma,1)\}. \end{aligned} \] If any collection is nonempty, the alternative requested in the supplied statement is a precise characterization of that collection, separately for each property.

This formulation records the supplied reconstructed statement. The supplied original excerpt contains only a general observation about long-standing questions and a damaged Artin presentation; it does not explicitly state these three conjectures or specify the Salvetti formulation. The dated supplied assessment likewise describes the entry as a general warning rather than a single theorem. Thus the intended three-part target and its correspondence with the report require human source review.

Short English statement

For every Artin group defined by a finite labeled graph, the supplied reconstructed challenge asks for torsion-freeness, an algorithm deciding whether a word represents the identity, and asphericity of the standard Salvetti complex. If any property fails, it asks for an exact characterization of the graphs for which it fails. The supplied original excerpt does not explicitly identify these three targets, so this remains a statement-only interpretation requiring review.
