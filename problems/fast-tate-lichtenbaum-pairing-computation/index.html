Math-5682

Fast Tate–Lichtenbaum pairing computation

Status Solved · unsolvedmath.comLLM status Solved from source status

Top Open Problems Not reported cataloguedSolvedSolved

Statement

Definitions and mathematical statement

Develop a fast algorithm computing the Tate--Lichtenbaum pairing $T_n$ on its intended input class. The source does not specify the field, curve/abelian-variety class, input representations, or whether reduced pairing values are requested.

For context, one standard finite-field elliptic-curve version takes an elliptic curve $E/K$, $K=\mathbb F_{q^k}$, an integer $n\geq2$ prime to the characteristic, and $n\mid(|K|-1)$. For $P\in E(K)[n]$ choose a degree-zero divisor $D_P$ representing $P$ and a function with $\operatorname{div}(f_P)=nD_P$. For $[Q]\in E(K)/nE(K)$, using a representative divisor $D_Q$ with disjoint support, the pairing value is \[ T_n(P,[Q])=f_P(D_Q)\pmod{(K^*)^n}\in K^*/(K^*)^n. \] Here evaluation on $D_Q=\sum_R m_R(R)$ is the corresponding product $\prod_R f_P(R)^{m_R}$ where defined. The reduced finite-field value is obtained by the final exponentiation $f_P(D_Q)^{(|K|-1)/n}\in\mu_n$. This explains a common specialization, not a verified restriction of the general source item.

The algorithmic target must state how its cost depends on $n$, field representation/extension degree, and the curve or genus data. The supplied summary reports Miller's algorithm and refinements as resolving the practical computation problem. Its $O(\log n)$ iteration count is not a full bit-complexity bound: iterations include field operations and evaluations, with final exponentiation for the reduced pairing. No universal optimality or machine-independent practical comparison is asserted.

Short English statement

Compute the Tate--Lichtenbaum pairing efficiently, with the pairing variant, input family, and cost model made explicit. The supplied summary reports Miller-based methods and practical refinements as a resolution.
