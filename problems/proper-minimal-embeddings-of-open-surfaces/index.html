Math-4780

Proper Minimal Embeddings of Open Surfaces

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Use the customary convention that an open surface is a connected, noncompact, Hausdorff, second-countable surface without boundary; no orientability assumption is imposed. A smooth structure is understood when discussing a minimal embedding. These conventions are not explicitly specified in the supplied statement and require confirmation against the source context.

An end of $M$ is a Freudenthal end, represented by compatible components outside compact subsets of $M$. An end neighborhood is a connected neighborhood of that end outside a compact subset. An end is nonorientable if every sufficiently small end neighborhood is nonorientable, equivalently if it has no orientable end neighborhood. To make infinite genus at an end precise for both orientable and nonorientable surfaces, use the following convention. For a compact connected subsurface $K$ with $b(K)$ boundary components, put \[ \gamma(K)=2-b(K)-\chi(K). \] This is twice the usual genus when $K$ is orientable and is the nonorientable genus when $K$ is nonorientable. An end has infinite genus if, for every end neighborhood $U$ and every integer $n\geq 1$, there is a compact connected subsurface $K\subset U$ with $\gamma(K)\geq n$. The supplied record does not explicitly define its end and genus terminology; this convention needs human mathematical review.

A smooth bounded domain $D\subset{\mathbb{R}}^3$ is a bounded connected open set with smooth boundary. A complete proper minimal embedding $f\colon M\to D$ is a smooth embedding with vanishing mean curvature whose induced Euclidean metric is complete and for which $f^{-1}(C)$ is compact in $M$ for every compact subset $C\subset D$. Properness is relative to $D$.

With these conventions, the supplied question asks whether, for every open surface $M$, \[ \begin{aligned} &\exists\,D\subset{\mathbb{R}}^3\text{ a smooth bounded domain}\; \exists\,f\colon M\hookrightarrow D \text{ a complete proper minimal embedding} \\[-1mm] &\qquad\Longleftrightarrow\quad \left\{ \begin{array}{l} M\text{ has finitely many nonorientable ends},\\ \text{every end of }M\text{ has infinite genus}. \end{array} \right. \end{aligned} \] The domain may depend on $M$, and finitely many nonorientable ends includes zero. This equivalence is posed as a question, not asserted as a theorem.

Short English statement

Does an open surface admit a complete minimal embedding that is proper inside some smooth bounded domain of ${\mathbb{R}}^3$ exactly when it has only finitely many nonorientable ends and infinite genus at every end? The surface and end conventions above require source confirmation. The supplied registry labels this problem open; that label has not been independently verified.
