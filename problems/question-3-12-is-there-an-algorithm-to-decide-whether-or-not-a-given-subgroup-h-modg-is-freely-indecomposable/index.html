Question 3.12 — Is there an algorithm to decide whether or not a given subgroup H <Modg is freely indecomposable?

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A group $H$ is freely indecomposable if it admits no decomposition $H\cong A*B$ with both factors nontrivial. A nontrivial splitting over ${\mathbb{Z}}$, in the usual Bass--Serre convention, is an amalgamated-product or HNN splitting with infinite cyclic edge group and nontrivial associated tree action, so a presentation with a collapsible edge is not counted merely as a formal splitting.

Question 3.12. Is there an algorithm deciding, for a given subgroup $H<\operatorname{Mod}_g$, whether $H$ is freely indecomposable? Is there an algorithm deciding whether $H$ splits over ${\mathbb{Z}}$? These are two decision questions. In a finite-generator input model, the input would be a list of words in fixed ambient generators whose subgroup is $H$, and each procedure must halt with the correct answer on every valid input in its promised class. A finite-presentation input model or additional subgroup hypotheses could lead to a different problem.

The supplied statement does not specify such an effective encoding, assume finite generation or finite presentability, fix the genus and surface convention, or define the exact allowed cyclic splitting. The finite-generator description above is therefore a possible precise input model, not a silently added hypothesis. The question asks for decision procedures, not just enumeration of candidate splittings or a classification up to abstract isomorphism.

Short English statement

Decide algorithmically whether a specified mapping-class-group subgroup has a nontrivial free-product decomposition, and whether it splits over an infinite cyclic group. The source omits how the subgroup is given and any finiteness promises, which are essential to the algorithmic formulation.
