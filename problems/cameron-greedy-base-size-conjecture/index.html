Cameron Greedy Base-Size Conjecture

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $\Omega$ be a finite nonempty set and let $G\leq\operatorname{Sym}(\Omega)$. The action is primitive if it is transitive and its only $G$-invariant partitions are the partition into singletons and the partition $\{\Omega\}$. For a sequence $(\alpha_1,\ldots,\alpha_k)$ of points, write \[ G_{\alpha_1,\ldots,\alpha_k}=\{g\in G:g\alpha_i=\alpha_i\text{ for every }1\leq i\leq k\}. \] A base is such a sequence with trivial pointwise stabilizer, and $b(G)$ is the minimum length of a base in this action.

The supplied record does not define the greedy procedure or its treatment of ties. To make the intended statement precise, use the following conventional interpretation, which requires confirmation against the cited report. Set $H_0=G$. Whenever $H_i\neq\{1\}$, choose $\alpha_{i+1}\in\Omega$ such that \[ |H_i\alpha_{i+1}|=\max_{\omega\in\Omega}|H_i\omega|, \qquad H_{i+1}=(H_i)_{\alpha_{i+1}}. \] Stop at the first index $k$ for which $H_k=\{1\}$. Define the greedy base size $\gamma(G)$ to be the maximum such length $k$ over all choices permitted by ties. This quantity is denoted $G(G)$ in the supplied record. For the trivial group, take the empty base and set $b(G)=\gamma(G)=0$; this also handles the singleton action.

Cameron's Greedy Conjecture, under the preceding interpretation. There exists a real constant $c>0$, independent of both $\Omega$ and $G$, such that for every finite primitive permutation group $G\leq\operatorname{Sym}(\Omega)$, \[ \gamma(G)\leq c\,b(G). \] Equivalently, every execution of the specified greedy procedure has length at most $c\,b(G)$. The missing source definition of greedy base size, especially the extremum over tie choices, remains a formulation qualification requiring human review.

Short English statement

Cameron's conjecture asks whether the longest base produced by repeatedly choosing a point in a largest orbit of the current pointwise stabilizer is bounded by a universal constant times the shortest possible base, for every finite primitive permutation action. The supplied record leaves the greedy rule and tie convention unstated, so this precise interpretation requires confirmation. Its supplied status is partially solved; that status is not independently verified here.
