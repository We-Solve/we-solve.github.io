Kourovka Notebook Problem 14.68

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For each integer $n>2$, let $R_n={\mathbb{C}}[x_1,\ldots,x_n]$. Write $\operatorname{Aut}_{{\mathbb{C}}}(R_n)$ for the group of ${\mathbb{C}}$-algebra automorphisms, which fix every constant in ${\mathbb{C}}$. A linear automorphism means an automorphism $L$ for which there is a matrix $A=(a_{ij})\in\operatorname{GL}_n({\mathbb{C}})$ satisfying \[ L(x_i)=\sum_{j=1}^{n}a_{ij}x_j\qquad(1\leq i\leq n). \] An automorphism $F$ has order exactly $2$ if $F^2=\operatorname{id}_{R_n}$ and $F\neq\operatorname{id}_{R_n}$.

Under the interpretation that the source means ${\mathbb{C}}$-algebra automorphisms, the question is: for every integer $n>2$ and every $F\in\operatorname{Aut}_{{\mathbb{C}}}(R_n)$ of order exactly $2$, do there exist $G\in\operatorname{Aut}_{{\mathbb{C}}}(R_n)$ and $A=(a_{ij})\in\operatorname{GL}_n({\mathbb{C}})$ such that \[ (G^{-1}\circ F\circ G)(x_i)=\sum_{j=1}^{n}a_{ij}x_j\qquad(1\leq i\leq n)? \] The source says only "automorphism of the polynomial ring" and does not explicitly require constants to be fixed. Consequently, the choice between ring automorphisms and ${\mathbb{C}}$-algebra automorphisms remains a qualification requiring review; the displayed formulation is conditional on the latter interpretation. Here "linear" is interpreted as homogeneous linear substitution.

The supplied source calls this a well-known problem and states that the assertion is true for $n=2$. That boundary-case assertion is retained as supplied background, without independent verification. The registry labels the problem open; this is a supplied status label, not an independently verified mathematical assessment.

Short English statement

Under the ${\mathbb{C}}$-algebra interpretation, must every automorphism of exact order $2$ of ${\mathbb{C}}[x_1,\ldots,x_n]$, for every $n>2$, be conjugate to a linear automorphism? The source states that the answer is yes for $n=2$, but does not explicitly specify whether its automorphisms fix ${\mathbb{C}}$.
