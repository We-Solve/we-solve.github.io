Math-7055

Arc-Smoothness on Closed Fat Sets

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $X\subseteq{\mathbb{R}}^d$ be closed. Interpret fat in its usual topological sense: \[ X=\overline{\operatorname{int}_{{\mathbb{R}}^d}(X)}. \] The supplied record asks for conditions on such sets under which \[ A^\infty(X)=C^\infty(X) \qquad\text{and}\qquad A^M(X)=C^M(X). \] It does not define these four classes or specify the parameter $M$.

Under the conventional real-valued, ambient-extension interpretation, the smooth classes can be defined by \[ C^\infty(X)=\left\{f:X\to{\mathbb{R}}:\ \exists\,U\subseteq{\mathbb{R}}^d\text{ open},\ X\subseteq U,\ \exists\,F\in C^\infty(U),\ F|_X=f\right\} \] and \[ A^\infty(X)=\left\{f:X\to{\mathbb{R}}:\ f\circ c\in C^\infty({\mathbb{R}})\text{ for every }c\in C^\infty({\mathbb{R}},{\mathbb{R}}^d)\text{ with }c({\mathbb{R}})\subseteq X\right\}. \] With these explicitly stated conventions, the smooth question is to characterize the closed fat sets $X$ for which every function passing all these smooth-curve tests extends smoothly to an open neighborhood of $X$. This is a question about conditions on $X$, not an assertion that the equality holds for every closed fat set.

For the ultradifferentiable question, suppose that a parameter $M$ and classes $C^M(U)$ on open sets have first been specified. A possible corresponding interpretation is \[ C^M(X)=\left\{f:X\to{\mathbb{R}}:\ \exists\,U\subseteq{\mathbb{R}}^d\text{ open},\ X\subseteq U,\ \exists\,F\in C^M(U),\ F|_X=f\right\}, \] \[ A^M(X)=\left\{f:X\to{\mathbb{R}}:\ f\circ c\in C^M({\mathbb{R}})\text{ for every }c\in C^M({\mathbb{R}},{\mathbb{R}}^d)\text{ with }c({\mathbb{R}})\subseteq X\right\}, \] where the coordinates of a $C^M$ curve belong to $C^M({\mathbb{R}})$. Under this interpretation, ask which closed fat sets have the indicated equality, for the specified $M$. These definitions are conditional interpretations requiring confirmation: the record does not supply the weight data, growth bounds, Roumieu or Beurling convention, restrictions on $M$, curve-testing convention, or intended extension notion. Consequently, it does not determine a unique precise ultradifferentiable problem.

The statement concerns closed fat sets generally. The background separately refers to a general compact-set question; compactness is not imposed in the displayed source statement.

Short English statement

Determine geometric conditions on a closed fat set under which smoothness, or a specified form of ultradifferentiability, can be detected by composing functions with curves in the set. The smooth formulation above uses an explicit conventional interpretation. The ultradifferentiable formulation remains conditional because the source does not define $M$ or the relevant function classes.
