Kourovka Notebook Problem 8.40

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a group $G$, write $|x|$ for the order of $x\in G$, and use the commutator convention $[a,b]=a^{-1}b^{-1}ab$. An involution is an element of order exactly $2$. A conjugacy class of involutions is a set $D=\{g^{-1}tg:g\in G\}$, where $|t|=2$.

Describe the finite groups $G$, up to isomorphism, for which there exists a conjugacy class $D$ of involutions such that \[ G=\langle D\rangle \qquad\text{and}\qquad \forall a,b\in D,\quad |ab|=4\ \Longrightarrow\ [a,b]\in D. \] For involutions, the specified commutator is $[a,b]=(ab)^2$.

The source additionally asserts that this condition holds when $D$ is a conjugacy class of involutions in a known finite simple group and $\langle C_D(a)\rangle$ is a $2$-group for every $a\in D$. Here the notation is interpreted as \[ C_D(a)=\{d\in D:da=ad\}, \] and a finite $2$-group is a group of order $2^n$ for some integer $n\geq 0$. This assertion is retained as supplied context; the source record does not specify the scope or date of the word "known." It is not an additional hypothesis restricting the requested classification.

Short English statement

Classify the finite groups generated by a single conjugacy class of involutions such that the commutator of any two members whose product has order $4$ also belongs to that class. The supplied record labels the problem open; this draft does not independently verify that status.
