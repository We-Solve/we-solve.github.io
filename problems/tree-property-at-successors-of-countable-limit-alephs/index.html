Math-4244

Tree Property at Successors of Countable Limit Alephs

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For an uncountable cardinal $\kappa$, a $\kappa$-tree is a partially ordered set $(T,<_{T})$ such that the strict predecessors of each node are well ordered by $<_{T}$, the tree has height $\kappa$, and every level has cardinality less than $\kappa$. More explicitly, if $\operatorname{ht}_{T}(t)$ is the order type of the predecessors of $t$, then \[ T_\xi=\{t\in T:\operatorname{ht}_{T}(t)=\xi\},\qquad 0<|T_\xi|<\kappa\quad(\xi<\kappa), \] and there are no nodes of height at least $\kappa$. A cofinal branch is a linearly ordered subset whose node heights are unbounded in $\kappa$. A $\kappa$-Aronszajn tree is a $\kappa$-tree with no cofinal branch. The tree property at $\kappa$, denoted here by $\operatorname{TP}(\kappa)$, asserts that every $\kappa$-tree has a cofinal branch.

Let $\omega_1$ be the first uncountable ordinal and let $\aleph_\beta$ denote the $\beta$-th infinite cardinal, all computed within the same model. Taking a limit ordinal to be nonzero and to have no immediate predecessor, the supplied problem asks whether the following theory is consistent: \[ \mathsf{ZFC}+\left[\forall\alpha<\omega_1\, \left(\alpha\text{ is a nonzero limit ordinal}\ \Longrightarrow\ \operatorname{TP}(\aleph_{\alpha+1})\right)\right]. \] Thus the tree properties are required simultaneously in one model for every countable nonzero limit ordinal. Interpreting consistency over $\mathsf{ZFC}$ is the usual ambient convention; the supplied record does not explicitly specify a base theory or a large-cardinal hypothesis for a relative consistency result. The nonzero convention for limit ordinals is also not explicit in the source record; including $0$ would add the separate requirement $\operatorname{TP}(\aleph_1)$.

Short English statement

Can there consistently be a single model of set theory in which, for every countable nonzero limit ordinal $\alpha$, every tree of height $\aleph_{\alpha+1}$ with levels of size less than $\aleph_{\alpha+1}$ has a cofinal branch? The base theory and the convention excluding zero from limit ordinals require confirmation.
