Definitions and mathematical statement

Let $f_{c,b}|_{{\mathbb{R}}^2}$ denote the real Hénon map referred to in the supplied source. Write $P\subseteq{\mathbb{R}}^2$ for its intended real parameter domain and $H(c,b)=h_{\mathrm{top}}(f_{c,b}|_{{\mathbb{R}}^2})$ for its intended topological entropy. For $\alpha\in[0,\log 2]$, define the isentrope \[ \mathcal E_\alpha=\{(c,b)\in P:H(c,b)=\alpha\}. \] The question attributed in the source to van Strien is whether \[ \forall\alpha\in[0,\log 2],\qquad \mathcal E_\alpha\text{ is connected}. \] Here connectedness is understood in the topology inherited from the real parameter plane. This is a conditional reconstruction: the supplied record does not give the formula for $f_{c,b}$, specify $P$, define $\mathcal E_\alpha$, or state the entropy convention for the noncompact phase space ${\mathbb{R}}^2$. Those choices must be recovered from the source before this becomes a fully specified mathematical statement. The source introduces this connectedness question as a topological formulation of entropy monotonicity; no separate monotonicity assertion or equivalence is established here.

Short English statement

For each entropy value between $0$ and $\log 2$, including both endpoints, must the real Hénon parameters having that entropy form a connected set? The family, parameter domain, and entropy convention require clarification from the source.
