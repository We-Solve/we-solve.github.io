Math-844

Galois Orbits of Finite Planar Trees

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

The supplied problem asks for a description of the orbits of $G=\operatorname{Gal}(\overline{{\mathbb{Q}}}/{\mathbb{Q}})$ on isotopy classes of finite planar trees. Its stated equivalence with Shabat polynomials requires conventions about vertex colours, polynomial equivalence, and allowed critical values that the record does not specify completely.

A precise standard dessin formulation can be given as follows. A bicoloured plane tree is a finite connected acyclic graph with at least one edge, a cyclic ordering of the edges incident to each vertex, and a colouring of its vertices by $0$ and $1$, with adjacent vertices having different colours. Trees are considered up to graph isomorphisms preserving the cyclic orderings and the colours. The cyclic orderings encode an embedding in an oriented plane; no root or vertex labels are imposed.

For each integer $n\geq 1$, set \[ \mathcal S_n=\left\{P\in\overline{{\mathbb{Q}}}[z]:\deg P=n,\quad P'(c)=0\Longrightarrow P(c)\in\{0,1\}\text{ for every }c\in\overline{{\mathbb{Q}}}\right\}. \] Thus the set of finite critical values is required to be contained in $\{0,1\}$. Define $P\sim Q$ if \[ Q(z)=P(az+b)\qquad\text{for some }a\in\overline{{\mathbb{Q}}}^{\times},\ b\in\overline{{\mathbb{Q}}}. \] Under the usual dessin correspondence, the classes in $\mathcal S_n/\!\sim$ correspond to bicoloured plane trees with $n$ edges: the embedded tree is $P^{-1}([0,1])\subset{\mathbb{C}}$, with vertices over $0$ and $1$ carrying their respective colours.

For $P(z)=\sum_{j=0}^n a_jz^j$ and $\sigma\in G$, define \[ P^\sigma(z)=\sum_{j=0}^n\sigma(a_j)z^j, \qquad \sigma\cdot[P]=[P^\sigma]. \] This defines an action on each $\mathcal S_n/\!\sim$, and hence, through the correspondence, on bicoloured plane trees. With these conventions, the problem is to describe completely the orbit partition \[ \mathcal S_n/\!\sim\;=\coprod_{\mathcal O\in G\backslash(\mathcal S_n/\!\sim)}\mathcal O \qquad(n\geq1). \] Equivalently, one seeks a complete characterization of when two associated trees belong to the same orbit; in polynomial terms the relation is \[ [P]\text{ and }[Q]\text{ lie in the same orbit} \quad\Longleftrightarrow\quad \exists\sigma\in G\ \exists a\in\overline{{\mathbb{Q}}}^{\times}\ \exists b\in\overline{{\mathbb{Q}}}\quad Q(z)=P^\sigma(az+b). \]

Unresolved source conventions. If the intended trees have no chosen bipartition colouring, the corresponding polynomial classes must additionally identify $P$ with $1-P$. This involution commutes with the Galois action, so an action also descends to that quotient. The supplied record does not distinguish these two classification problems. Also, "whose only critical values are $0$ and $1$" may require both values to occur, in which case $\mathcal S_n$ must instead require \[ \{P(c):P'(c)=0\}=\{0,1\}. \] The containment convention includes degree-one polynomials and polynomials with just one finite critical value; the equality convention excludes them. A one-vertex tree with no edges is not covered by the nonconstant-polynomial formulation, and its intended inclusion is unspecified. Thus the formulation above states an explicit standard interpretation while leaving these source qualifications unresolved.

Short English statement

Describe all absolute Galois orbits of finite plane trees through their associated Shabat polynomials. A precise version uses bicoloured plane trees and polynomials modulo affine changes of the input variable, with Galois acting on coefficients. The source leaves unresolved whether colours are forgotten, whether both critical values must occur, and whether the tree with no edges is included.
