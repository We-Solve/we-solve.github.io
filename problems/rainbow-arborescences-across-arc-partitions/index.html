Math-7147

Rainbow Arborescences Across Arc Partitions

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For the following formulation, an out-arborescence on a finite vertex set $V$ is a set of arcs whose underlying undirected graph is a tree spanning $V$, with a root $r\in V$ such that every vertex is reachable from $r$ by a directed path. Equivalently, the root has indegree zero and every other vertex has indegree one. The source does not specify the orientation convention for arborescences; using in-arborescences throughout gives the corresponding formulation by reversing every arc.

For every positive integer $k$, let $G=(V,A)$ be a finite directed graph with $|V|=k+1$. Suppose that \[ A=F_1\mathbin{\dot\cup}\cdots\mathbin{\dot\cup}F_k, \] where each $F_i$ is an arborescence on $V$ and $|F_i|=k$. Must there exist an arborescence $F^*\subseteq A$ on $V$ satisfying \[ |F^*\cap F_i|=1\qquad\text{for every }i\in\{1,\ldots,k\}? \] The roots of the given arborescences may differ, and the root of $F^*$ is not prescribed. Thus $F^*$ must select exactly one arc from each part of the partition. The source does not specify whether parallel arcs are permitted; the intended class of directed graphs requires confirmation. The positive-integer range expresses the nonempty family in the source; inclusion of $k=0$ would require conventions for an empty partition and the singleton arborescence.

Short English statement

If the arcs of a directed graph on $k+1$ vertices split into $k$ spanning arborescences, must one be able to select one arc from each to obtain another spanning arborescence? No common or prescribed root is assumed. The supplied record labels the problem partially solved; this draft does not independently verify that assessment.
