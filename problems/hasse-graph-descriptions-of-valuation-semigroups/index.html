Math-15397

Hasse-Graph Descriptions of Valuation Semigroups

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied record refers to a weighted Hasse graph, whose directed edges are cover relations $p\gtrdot q$, with edge weight denoted by $b=b(p,q)$. It also refers to objects $\widehat Y_p$, rational function fields $K(\widehat Y_p)$, functions $f_p$ and $f_{pq}$, and a valuation semigroup $\Gamma_C$. The underlying partially ordered set, the geometric objects, the base field, the permitted weights, the datum $C$, the valuation defining $\Gamma_C$, and the proposed graph-based description of that semigroup are not defined in the supplied record.

Conjecture as recorded, with unresolved notation. The original statement asks whether the description of $\Gamma_C$ using only weighted-Hasse-graph data is valid whenever \[ \text{for every cover relation }p\gtrdot q\text{ of weight }b, \quad \exists\,\eta\in K(\widehat Y_p) \quad\text{such that}\quad \eta^{b}=f_{pq} \quad\text{in }K(\widehat Y_p). \] The existential quantifier is separate for each edge; the supplied wording imposes no additional compatibility condition between these choices.

The supplied clean statement instead writes the edge condition as \[ \text{for every cover relation }p\gtrdot q\text{ of weight }b, \quad \exists\,\eta\in K(\widehat Y_p) \quad\text{such that}\quad \eta^{b}=\frac{f_p}{f_q} \quad\text{in }K(\widehat Y_p). \] The record does not define $f_{pq}$ or identify it with $f_p/f_q$. Nor does it specify how this quotient is interpreted in $K(\widehat Y_p)$, including the necessary nonvanishing of its denominator there. Consequently, these two displayed hypotheses cannot be asserted to be equivalent on the supplied evidence.

The intended conclusion is the validity of the source's weighted-Hasse-graph description of $\Gamma_C$; that description is not supplied as a formula or construction. Thus the record supports this conditional conjecture schema, but does not supply enough definitions or a sufficiently explicit conclusion to state a self-contained semigroup equality. These unresolved qualifications require mathematical review.

Short English statement

For each weighted cover relation, the conjecture assumes that a specified rational function has a root of order equal to the edge weight, and asks whether this ensures the proposed graph description of $\Gamma_C$. The record omits that description and its geometric setup, and uses two right-hand sides without establishing their equality. Its open status and verification labels are supplied curation, not independently verified conclusions.
