Math-7323

Connected Escaping Sets of Postsingularly Finite Entire Functions

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $f\colon{\mathbb{C}}\to{\mathbb{C}}$ be a transcendental entire function, meaning an entire function that is not a polynomial. Write $f^0=\operatorname{id}_{{\mathbb{C}}}$ and $f^{n+1}=f\circ f^n$ for $n\geq 0$. Let $S(f)$ be the closure in ${\mathbb{C}}$ of the set of critical values and finite asymptotic values of $f$. A critical value is a value $f(c)$ with $f'(c)=0$; a finite asymptotic value is a number $a\in{\mathbb{C}}$ for which there is a continuous curve $\gamma\colon[0,\infty)\to{\mathbb{C}}$ such that $|\gamma(t)|\to\infty$ and $f(\gamma(t))\to a$ as $t\to\infty$. Define the postsingular set by \[ P(f)=\overline{\bigcup_{n=0}^{\infty}f^n(S(f))}, \] where the closure is taken in ${\mathbb{C}}$. Let $F(f)$ be the set of points having a neighbourhood on which the family $\{f^n:n\geq0\}$ is normal with respect to the spherical metric, and let $J(f)={\mathbb{C}}\setminus F(f)$ be the Julia set. Define the escaping set by \[ I(f)=\{z\in{\mathbb{C}}:|f^n(z)|\longrightarrow\infty\text{ as }n\to\infty\}. \] Assume that \[ \#P(f)<\infty\qquad\text{and}\qquad P(f)\subseteq J(f). \] Question. Under which additional hypotheses on such a function $f$, if any, is $I(f)$ connected in the topology inherited from ${\mathbb{C}}$? Here connectedness means that $I(f)$ cannot be expressed as the union of two disjoint nonempty relatively open subsets.

Short English statement

For a transcendental entire function with a finite postsingular set contained in its Julia set, ask what further hypotheses ensure that all points whose iterates tend to infinity form a connected subset of ${\mathbb{C}}$. The intended additional hypotheses and the scope of the requested characterization remain unspecified.
