Math-1126

Tree Property with Failure of Singular Cardinal Hypothesis

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Work in $\mathsf{ZFC}$. Put $\kappa=\aleph_\omega$ and $\lambda=\kappa^+=\aleph_{\omega+1}$, so $\operatorname{cf}(\kappa)=\omega$.

A tree is a partially ordered set $(T,<_{T})$ such that the strict predecessors of each node are well ordered by $<_{T}$. The height of a node is the order type of its predecessors, and $T_\alpha$ is the set of nodes of height $\alpha$. A $\lambda$-tree has height $\lambda$ and satisfies $|T_\alpha|<\lambda$ for every $\alpha<\lambda$. A cofinal branch is a linearly ordered subset whose node heights are unbounded in $\lambda$. The tree property at $\lambda$, denoted here by $\operatorname{TP}(\lambda)$, means that every $\lambda$-tree has a cofinal branch.

A cardinal $\kappa$ is strong limit if $2^\mu<\kappa$ for every cardinal $\mu<\kappa$. The strong-limit formulation of the Singular Cardinal Hypothesis asserts that $2^\kappa=\kappa^+$ at every singular strong limit cardinal $\kappa$.

Supplied question. Is it consistent with $\mathsf{ZFC}$ that the tree property holds at $\aleph_{\omega+1}$ while the Singular Cardinal Hypothesis fails at $\aleph_\omega$?

Qualification concerning the intended formulation. The supplied statement does not explicitly say that $\aleph_\omega$ is strong limit or define local failure of the Singular Cardinal Hypothesis. Under the strong-limit reading, the precise consistency question is \[ \operatorname{Con}\!\left(\mathsf{ZFC}+\left[ \operatorname{TP}(\aleph_{\omega+1})\ \land\ (\forall\text{ cardinals }\mu<\aleph_\omega)\;2^\mu<\aleph_\omega\ \land\ 2^{\aleph_\omega}>\aleph_{\omega+1} \right]\right)? \] Here $\operatorname{Con}$ means syntactic consistency, and all cardinal expressions are interpreted within the theory in question. The strong limit condition in this display is an explicit interpretation requiring source confirmation.

Alternatively, a local formulation of SCH at a singular cardinal $\kappa$ is \[ 2^{\operatorname{cf}(\kappa)}<\kappa \quad\Longrightarrow\quad \kappa^{\operatorname{cf}(\kappa)}=\kappa^+. \] With this convention, the question instead becomes \[ \operatorname{Con}\!\left(\mathsf{ZFC}+\left[ \operatorname{TP}(\aleph_{\omega+1})\ \land\ 2^{\aleph_0}<\aleph_\omega\ \land\ (\aleph_\omega)^{\aleph_0}>\aleph_{\omega+1} \right]\right)? \] These readings agree when $\aleph_\omega$ is strong limit; the supplied record does not settle whether that hypothesis is intended. No particular large cardinal assumption or relative consistency strength is specified.

Short English statement

Can a model of set theory have the tree property at $\aleph_{\omega+1}$ together with failure of the Singular Cardinal Hypothesis at $\aleph_\omega$? The source leaves the local meaning of SCH failure implicit, so the draft gives explicit formulations and flags the strong limit hypothesis for review.
