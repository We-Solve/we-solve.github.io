Complexity of Low-Chromatic Compact Free Subshifts

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\Gamma=({\mathbb{Z}}/2{\mathbb{Z}})*({\mathbb{Z}}/2{\mathbb{Z}})*({\mathbb{Z}}/2{\mathbb{Z}})=\langle a,b,c\mid a^2=b^2=c^2=e\rangle$, and give $2^\Gamma=\{0,1\}^\Gamma$ the product topology, with $\{0,1\}$ discrete. Use the left shift action \[ (g\cdot x)(h)=x(g^{-1}h)\qquad(g,h\in\Gamma,\ x\in2^\Gamma). \] A compact subshift is a compact set $X\subseteq2^\Gamma$ invariant under this action. It is free if \[ \forall x\in X\ \forall g\in\Gamma\setminus\{e\},\qquad g\cdot x\ne x. \] For such an $X$, let $G_X$ be the undirected graph on $X$ whose adjacency relation is \[ x\sim_{G_X}y\quad\Longleftrightarrow\quad y=s\cdot x\text{ for some }s\in\{a,b,c\}. \] The condition $\chi_B(G_X)\le3$ means that there is a Borel map $f:X\to\{0,1,2\}$, for the Borel structure inherited from $2^\Gamma$, such that \[ \forall x\in X\ \forall s\in\{a,b,c\},\qquad f(s\cdot x)\ne f(x). \] This uses the natural graph associated with the three free-product generators; the supplied excerpt does not explicitly define its graph convention.

For an explicit parameterization, let $\mathcal K(2^\Gamma)$ be the Vietoris hyperspace of nonempty compact subsets of $2^\Gamma$, and put \[ \mathcal F=\{X\in\mathcal K(2^\Gamma):X\text{ is an invariant free subshift}\},\qquad \mathcal C=\{X\in\mathcal F:\chi_B(G_X)\le3\}. \] The source question is whether $\mathcal C$ is $\boldsymbol\Sigma^1_2$-complete.

To make the complexity terminology explicit, for a Polish space $P$, a set $A\subseteq P$ is $\boldsymbol\Sigma^1_2$ if there is a Borel relation $R\subseteq P\times{\mathbb{N}}^{\mathbb{N}}\times{\mathbb{N}}^{\mathbb{N}}$ such that \[ p\in A\quad\Longleftrightarrow\quad\exists u\in{\mathbb{N}}^{\mathbb{N}}\ \forall v\in{\mathbb{N}}^{\mathbb{N}}\ R(p,u,v). \] Completeness requires membership in this pointclass and an appropriate universal reduction property. Under Borel reductions, that property says that for every standard Borel space $P$ and every $\boldsymbol\Sigma^1_2$ set $A\subseteq P$, there is a Borel map $r:P\to\mathcal K(2^\Gamma)$ with \[ p\in A\quad\Longleftrightarrow\quad r(p)\in\mathcal C. \] Under continuous reductions, one instead requires continuous reducing maps, with the test spaces specified by the chosen completeness convention. A relative formulation with target $\mathcal F$ additionally requires the reducing maps to take values in $\mathcal F$.

Unresolved qualifications. The supplied statement does not specify the reduction convention, the coding space, whether completeness is relative to $\mathcal F$, or whether the empty subshift is allowed. The hyperspace and nonemptiness conventions above give an explicit interpretation, but the intended completeness convention requires confirmation from the full source context. No equivalence between these possible completeness formulations is asserted here.

Short English statement

For the shift action of $({\mathbb{Z}}/2{\mathbb{Z}})*({\mathbb{Z}}/2{\mathbb{Z}})*({\mathbb{Z}}/2{\mathbb{Z}})$ on binary configurations, consider compact invariant sets on which every nonidentity group element acts without fixed points. The question asks whether those whose generator graph admits a Borel proper coloring with at most three colors form a $\boldsymbol\Sigma^1_2$-complete collection. The precise coding and reduction conventions remain unspecified in the supplied excerpt. The registry labels the problem open; this draft does not independently verify that status.
