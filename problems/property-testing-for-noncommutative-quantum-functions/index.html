Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

In the source model a finite-dimensional quantum function $F:X\to A$ assigns positive-semidefinite $d\times d$ measurement operators $M_{a\mid x}$ satisfying $\sum_{a\in A}M_{a\mid x}^2=I$ for each $x$. Sequential query probabilities are $d^{-1}\|M_{a_1\mid x_1}\cdots M_{a_q\mid x_q}\|_{\mathrm F}^2$, with the order interpreted as in the source. The function is commutative if all its measurement operators commute. A property is a class of such functions; a property tester seeks to distinguish membership from being far from the class using few queries.

Verbatim supplied catalogue question

What kinds of noncommutative properties are there? How does one measure a quantum function’s distance to a noncommutative property? What properties of quantum functions can be tested using few queries?

The source question and the attempted metric

The primary report, printed pages 2972--2973, asks for properties, distances and few-query tests, explicitly leaving the distance unspecified. We try a transcript distance and check whether it controls a natural operator-norm notion of commutativity. The answer to that attempted implication is negative. We retain the literal positive-measurement convention $\sum_aM_{a\mid x}^2=I$; no projectivity is assumed except in our concrete example. This does not characterize all testable properties in the source's broad agenda.

An exact operational pseudometric

Assume finite input and output alphabets. For a deterministic adaptive query tree $T$ of depth at most $q$, let $P_F^T$ be its output-transcript distribution when querying $F$, and define \[ d_q(F,G)=\max_T\frac12\sum_\omega |P_F^T(\omega)-P_G^T(\omega)|. \] There are finitely many such trees. The probabilities are valid because summing over the next measurement outcome uses $\sum_aM_{a\mid x}^2=I$ and preserves the prefix probability. The expression is nonnegative and symmetric, vanishes at identical boxes, and obeys the triangle inequality by applying it termwise for each tree and then taking maxima. Ignoring an extra query shows $d_q\le d_{q+1}$. Thus \[ d_{\rm seq}(F,G)=\sum_{q\ge1}2^{-q}d_q(F,G) \] is a well-defined pseudometric bounded by one. It vanishes exactly when all finite adaptive transcript laws agree, since all summands are nonnegative. It need not distinguish operator presentations. For example simultaneous unitary conjugation leaves every product Frobenius norm unchanged. Replacing every $M$ by $M\otimes I_k$ also preserves the normalized squared norm, because both squared Frobenius norm and Hilbert-space dimension multiply by $k$.

Any depth-$q$ tester's acceptance probabilities on two boxes differ by at most $d_q(F,G)$. For a deterministic tree and an acceptance function $a(\omega)\in[0,1]$, the signed difference is $\sum_\omega a(\omega)(P_F^T-P_G^T)(\omega)$, whose absolute value is at most the sum of its positive masses, namely total variation. Randomized trees are convex combinations, so the same bound persists. Conversely, for a maximizing tree, accepting exactly transcripts with positive probability difference attains total variation. This last statement is information-theoretic; it does not say the best tree is efficiently computable.

Small operational distance can hide noncommutativity

For $D\ge1$ form a direct sum of a $D$-dimensional deterministic box and a two-dimensional projective box with two binary queries. For the first query the two-dimensional outcome-zero projector is \[ P=\begin{pmatrix}1&0\\0&0\end{pmatrix}, \] and for the second it is \[ Q=\frac12\begin{pmatrix}1&1\\1&1\end{pmatrix}. \] The other projectors are $I-P,I-Q$. On the first block both queries deterministically output zero. Products remain block diagonal, so every transcript distribution of the combined box $F_D$ is exactly the mixture \[ \frac{D}{D+2}P_{\rm det}^T+\frac2{D+2}P_{P,Q}^T. \] This formula also holds for adaptive trees: the same fixed block is used along each transcript. Hence for the fully deterministic commuting box $G_D$ of dimension $D+2$, \[ d_q(F_D,G_D)\le\frac2{D+2}\quad\hbox{for every }q. \] The bound concerns one sequential run of the box; a newly reset independent copy would sample its block anew.

Nevertheless $F_D$ is a constant distance from commuting operators in the following precise sense. Its two outcome-zero operators are $\widetilde P=I_D\oplus P$ and $\widetilde Q=I_D\oplus Q$, and \[ [P,Q]=\frac12\begin{pmatrix}0&1\\-1&0\end{pmatrix}, \qquad\|[\widetilde P,\widetilde Q]\|_{\rm op}=1/2. \] If commuting positive contractions $P',Q'$ on the same space both approximate these operators within $\delta$ in operator norm, then \[ \|[\widetilde P,\widetilde Q]\|_{\rm op} \le\|[\widetilde P-P',\widetilde Q]\|_{\rm op} +\|[P',\widetilde Q-Q']\|_{\rm op}\le4\delta. \] Thus $\delta\ge1/8$. Positive normalized measurement operators are contractions, since $M_a^2\preceq I$, so the conclusion applies in particular to every commuting measurement family on the same space. It even allows $P',Q'$ to mix the two blocks.

A uniform test that accepts commuting boxes with probability at least $2/3$ and rejects all boxes at this operator-norm distance with probability at least $2/3$ would need an acceptance gap at least $1/3$. For $D>4$ that contradicts the transcript bound, regardless of the length of a single sequential run. Even if a fixed number $q$ of fresh-copy runs were allowed, coupling the block choices gives a total variation bound at most $2q/(D+2)$, by the union bound on ever choosing the small block. Consequently no dimension-independent constant-copy guarantee follows in that model either. This does not preclude tests in normalized Hilbert--Schmidt distance or with a dimension-dependent sample budget.

Audit and the first unresolved step

The attempted passage from operational closeness to uniform operator closeness fails through a low-weight direct-sum sector. The audit checked adaptive transcripts, dimension normalization, operator contractions, possible mixing of sectors by the approximant, and the distinction between one run and fresh copies. A useful general property theory still needs a chosen equivalence and distance, robust positive results, and efficient test constructions. No numerical experiment or theorem prover was used, and the elementary distance construction and obstruction are not claimed as new original-target progress.
