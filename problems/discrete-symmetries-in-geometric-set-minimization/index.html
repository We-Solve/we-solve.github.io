If a group $G$ acts on $X$, a set $E\subseteq X$ is $G$-invariant when \[ gE=E\qquad\text{for every }g\in G, \qquad gE:=\{g\cdot x:x\in E\}. \] If imposing symmetry means requiring each competitor to be invariant, the associated schematic problems would be \[ \inf_{E\in\mathcal A}\mathcal F(E) \qquad\text{and}\qquad \inf_{\substack{E\in\mathcal A\\ gE=E\ \text{for all }g\in G}}\mathcal F(E). \] These expressions illustrate one possible interpretation; the source does not specify that this is the intended meaning of imposing symmetry. In particular, invariance of each competitor and invariance of the objective under a group action are different requirements.
