Verbatim supplied catalogue question

Given a function $f:\{0,1\}^n \to \{0,1,2\}$, find $x\in \{0,1\}^n$ to maximize $f(x)$. Measure average resulting $f(x)$ if, e.g., $f$ has one 1, one 2, and all other values 0. Or consider the function $f:\{0,1\}^n \to \{0,1,2, \dots, 1000\}$. Or consider $f$ which is i.i.d.

Is it possible to do better than Grover search for $x$ such that $f(x) \geq T$ for threshold $T$?

Attempt and results

Use a domain of size $N=2^n$ and a reversible value oracle that writes or unwrites $f(x)$ in an auxiliary register. A threshold phase flip can be implemented by computing the value, applying a sign controlled on the threshold predicate, and uncomputing: two value queries per iteration. We prove a search lower bound for a subfamily and compare two explicit expected-value strategies. We do not claim an optimal solution for all the source's value distributions or query budgets.
The two-dimensional Grover calculation.
Suppose exactly $k$, with $0<k<N$, inputs meet a chosen predicate. Let $|G\rangle$ and $|B\rangle$ be uniform unit vectors on good and bad inputs, and set $\sin\theta=\sqrt{k/N}$, so the initial uniform vector is $|u\rangle=\sin\theta|G\rangle+\cos\theta|B\rangle$. The phase flip is $\operatorname{diag}(-1,1)$ in this basis. Multiplying it by the reflection $2|u\rangle\langle u|-I$ gives the matrix \[ \begin{pmatrix}\cos(2\theta)&\sin(2\theta)\\ -\sin(2\theta)&\cos(2\theta)\end{pmatrix}. \] Applying this matrix to $(\sin a,\cos a)^T$ gives $(\sin(a+2\theta),\cos(a+2\theta))^T$ by the addition formulas. After $r$ iterations the success probability is therefore $\sin^2((2r+1)\theta)$, and conditional on success the output is uniform among the marked inputs. This is the standard Grover calculation, rederived.
A full single-mark query obstruction.
Restrict to functions $f_i$ that are two at one input $i$ and zero elsewhere. Let a $q$-query algorithm's final pure states be $\psi_i$ and $\psi_0$ for $f_i$ and the zero function; deferred measurements and a purified random seed allow this form. Let $p_{t,i}$ be the probability that the query register is $i$ before query $t$ in the zero-oracle run. The difference of the two oracles has norm at most two and vanishes off that query input. Inserting the zero-run state into the two recurrence equations and using unitarity gives inductively $\|\psi_i-\psi_0\|\le2\sum_{t=1}^q\sqrt{p_{t,i}}$. Cauchy--Schwarz and $\sum_i p_{t,i}=1$ imply $\sum_i\|\psi_i-\psi_0\|^2\le4q^2$. For output projectors $Q_i$, the triangle inequality gives $\|Q_i\psi_i\|\le\|Q_i\psi_0\|+\|\psi_i-\psi_0\|$. Taking the Euclidean norm of this list over $i$ yields $\sum_i\|Q_i\psi_i\|^2\le(1+2q)^2$ because $\sum_i\|Q_i\psi_0\|^2\le1$. Thus average probability of finding the unique maximum is at most $(2q+1)^2/N$. Constant success for this family requires $q=\Omega(\sqrt N)$. This does not assert the same constant or optimal utility for a different promise such as one value one and one value two.
The source's two-positive-value example.
Now assume $N\ge3$, exactly one input has value one, exactly one has value two, and all others have value zero. Marking both positive inputs and doing $r$ iterations gives expected output value \[ U_{\ge1}(r)=\frac32\sin^2\left((2r+1)\arcsin\sqrt{2/N}\right), \] since the two marked locations are equiprobable. Marking only the value two gives \[ U_{\ge2}(r)=2\sin^2\left((2r+1)\arcsin(1/\sqrt N)\right) +\frac{\cos^2\left((2r+1)\arcsin(1/\sqrt N)\right)}{N-1}. \] The last term is the value-one location's share of the uniformly distributed unmarked output. Both use the same two value queries per Grover iteration. For each fixed integer $r\ge1$, putting $a=2r+1$ and using $\arcsin z=z+O(z^3)$ and $\sin z=z+O(z^3)$ gives $U_{\ge1}=3a^2/N+O(N^{-2})$ and $U_{\ge2}=(2a^2+1)/N+O(N^{-2})$. These expansions follow by Taylor's theorem at zero with bounded third derivatives on a small fixed interval. Their difference has positive leading coefficient $a^2-1$, so for sufficiently large $N$ the lower threshold gives higher expected value at this fixed budget. Thus always targeting the maximum value is not automatically the best short-budget expected-utility policy. Neither strategy comparison proves optimality among all quantum algorithms. For any integer-valued output $V\in\{0,\ldots,B\}$, the identity $\mathbb E V=\sum_{j=1}^B\Pr(V\ge j)$ follows by summing $V=\sum_j\mathbf1_{V\ge j}$, but optimizing each tail separately need not produce one algorithm simultaneously optimal for their sum.
