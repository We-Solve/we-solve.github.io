Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Let $p$ be prime and $g$ a generator of the cyclic multiplicative group $\mathbb{F}_p^{\times}$, whose order is $p-1$. Unknown exponents $a,b$ are taken modulo $p-1$. The input consists of the binary representations of $p,g,A=g^a\bmod p$ and $B=g^b\bmod p$, and the output is the residue $g^{ab}\bmod p$. The output is independent of the representatives chosen for $a,b$. A uniform efficient algorithm has running time polynomial in the binary input length, hence polynomial in $\log p$. Computing either exponent by a discrete-logarithm algorithm is sufficient to obtain the answer, but recovering either exponent is not part of the required output.

Statement recorded in the supplied source.
Given a prime modulus $p$, a group generator $g$, and the public values $g^a$ and $g^b$ modulo $p$, can the shared value $g^{ab}\bmod p$ be computed efficiently without knowing $a$ or $b$? [S2]

Literature and context check

The original Diffie--Hellman paper, Section III, was consulted. It explicitly separates computing public powers from obtaining the shared exponent product; it does not supply a converse reduction from discrete-logarithm hardness. No current cryptanalytic completeness claim is inferred from this historical source. The following elementary calculations concern classical arithmetic only.

Research attempt: An algebraic shortcut obstruction and a masking reduction

Put $m=p-1$. Consider a deliberately restricted, branch-free program which starts from $g,A=g^a,B=g^b$ and uses multiplication, inversion and exponentiation by publicly fixed integers. Induction on its instructions shows that every intermediate group element is \[ g^{\alpha+\beta a+\gamma b}\qquad(\alpha,\beta,\gamma\in\mathbb Z/m\mathbb Z). \] Multiplication adds triples, inversion negates them, and fixed exponentiation multiplies them by a public scalar. For $m>1$ no such expression equals $g^{ab}$ for all $a,b$. Evaluate at $(0,0),(1,0),(0,1)$ to obtain $\alpha=\beta=\gamma=0$, but $(1,1)$ then requires $0=1\pmod m$. Thus simply combining public powers by these operations cannot implement the missing multiplication of secret exponents. Input-dependent branching, arithmetic on the field representatives, and collision searches are outside this proof; it is emphatically not a classical complexity lower bound.

One possible escape was to solve a convenient fraction of exponent pairs and randomly translate every instance into that fraction. This translation is valid: choose independent uniform $r,s\in\mathbb Z/m\mathbb Z$ and form $A'=Ag^r$, $B'=Bg^s$. If a subroutine returns the correct product for this pair, its answer is \[ C'=g^{(a+r)(b+s)}=g^{ab}A^sB^r g^{rs}. \] All factors after $g^{ab}$ are computable, so division recovers the desired answer. The pair $(a+r,b+s)$ is exactly uniform for each fixed original instance. Consequently a subroutine's average success fraction for a fixed group becomes the same success probability on each target after masking. This algebra is independent of the primality of $m$.

The reduction is conditional on such a useful subroutine; it does not create one. Furthermore an unverified wrong answer remains unverified after removing the mask. Repetition alone does not identify which output is correct. A majority argument would need a success probability greater than one half and an explicit error model; a bare positive fraction or an unrecognizable success set is not enough. Thus the attempted shortcut stops at precisely the unavailable average-case solver or correctness witness, rather than establishing CDH.

For $p=2$, $m=1$ and the group is trivial, so the affine obstruction correctly does not apply and the answer is $1$. Public exponent zero or other easy instances do not contradict a question over all primes and inputs.

Verification and adversarial audit

The masking identity was exhaustively checked for all $22^2=484$ masks for $p=23$, $g=5$, $a=6$, $b=15$. The public values are $8,19$ and every unmasked answer was $2$. The symbolic identity is the proof; this finite test does not establish an algorithm at growing input length. The four-corner argument works for composite group orders as well as prime orders.
