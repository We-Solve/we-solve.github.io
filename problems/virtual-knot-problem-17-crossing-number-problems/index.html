Virtual-knot problem 17 — Crossing number problems

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For a virtual link $K$, let $\mathcal D(K)$ be its diagrams modulo virtual-link equivalence. If $c(D)$ and $v(D)$ count classical and virtual crossings of $D$, respectively, define \[ C(K)=\min_{D\in\mathcal D(K)}c(D),\quad V(K)=\min_{D\in\mathcal D(K)}v(D),\quad T(K)=\min_{D\in\mathcal D(K)}(c(D)+v(D)). \] These minima are taken independently; a diagram minimizing one need not minimize the others.

For a virtual knot, the source describes classical unknotting number by minimizing the number of classical crossing switches needed to reach the unknot, over all diagrams. If such switches cannot unknot it, an infinite/undefined-value convention is needed. The virtual unknotting number instead minimizes the number of classical crossings changed directly into virtual crossings, again allowing any virtual diagram before the changes. This is the operation explicitly described in the source as "direct flattening"; it must not be replaced by a different virtualization move or by merely forgetting over/under information at a flat crossing.

Problem-list item 17 retains the following requests:

  1. Investigate the virtual unknotting number, beyond the source's statement that very little is known.
  2. Relate $V(K)$ to the least genus of a surface representation of $K$. In the usual surface model the latter minimizes genus over representations in thickened oriented surfaces up to the intended stabilization equivalence, but the source gives no exact conventions.
  3. Decide the printed equality $T=V+L$. The source has defined $C,V,T$, while $L$ denotes a link and has not been defined as a numerical invariant. Thus this equality is ill-typed as extracted. If $L$ was intended to mean $C$, the candidate becomes $T(K)=V(K)+C(K)$, asking for simultaneous attainment of the two crossing minima. This is an explicit conditional reading, not a silent correction.
  4. Find an algorithm for $V$ for some class of virtual knots. The class and effective input model are unspecified.
  5. Obtain nontrivial upper and lower bounds from virtual-knot polynomials for the printed list $T,V,L$. The third numerical quantity $L$, the polynomial families and the meaning of nontrivial bounds are not supplied.
The source reports partial work for $T$ in two link classes, one called quasialternating and one unnamed, and mentions classical alternating diagrams; their citation slots are empty. The supplied modern summary reports arrow/writhe-polynomial lower bounds and special virtual-torus-knot unknotting computations, while saying the printed equality and algorithmic $V$ requests remain unresolved. Its scope and references require review.

Short English statement

Study virtual unknotting, compare minimal virtual crossings with surface genus, develop algorithms and polynomial bounds, and clarify the printed crossing-number equality. The extract defines $C,V,T$ but later uses an undefined numerical $L$; this is recorded instead of silently replacing it by $C$. The supplied progress assessment has incomplete citations.
