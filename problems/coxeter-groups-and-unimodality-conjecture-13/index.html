Coxeter Groups and Unimodality — Conjecture 13

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $(W,S)$ be a Coxeter system, and let $\ell:W\to{\mathbb{Z}}_{\geq 0}$ denote its length function. The (strong) Bruhat order is defined by $x\leq y$ if a reduced expression for $y$ contains a subword that is a reduced expression for $x$. For $u\leq v$, the Bruhat interval is the finite ranked poset \[ [u,v]=\{x\in W:u\leq x\leq v\}, \] with rank function $x\mapsto\ell(x)-\ell(u)$. Put $d=\ell(v)-\ell(u)$, and define its rank generating polynomial by \[ R_{u,v}(q)=\sum_{x\in[u,v]}q^{\ell(x)-\ell(u)} =\sum_{i=0}^{d}a_iq^i, \qquad a_i=\left|\{x\in[u,v]:\ell(x)-\ell(u)=i\}\right|. \] The interval is rank log-concave when $a_i^2\geq a_{i-1}a_{i+1}$ for every $1\leq i\leq d-1$.

Conjecture 13 (Brenti, 2024). If $W$ is a Weyl group, then every Bruhat interval in $W$ is rank log-concave. Explicitly, for every $u,v\in W$ with $u\leq v$, \[ \left|\{x\in[u,v]:\ell(x)-\ell(u)=i\}\right|^2 \geq \left|\{x\in[u,v]:\ell(x)-\ell(u)=i-1\}\right| \left|\{x\in[u,v]:\ell(x)-\ell(u)=i+1\}\right| \quad(1\leq i\leq d-1). \] For $d\leq1$, the condition is vacuous.

The source discusses rank generating functions for arbitrary Coxeter systems as background, but states this conjecture for Weyl groups. The usual finite crystallographic interpretation of Weyl group is used here; the supplied excerpt does not specify any broader intended scope. The restriction $u\leq v$ makes explicit the comparability implicit in the source's use of an interval. The supplied registry labels this conjecture open; that label is not an independently verified literature assessment.

Short English statement

Brenti's Conjecture 13 asserts that, for every comparable pair in a Weyl group, the numbers of elements at successive ranks of the Bruhat interval form a log-concave sequence. The draft uses the usual finite crystallographic meaning of Weyl group and requires human mathematical review.
