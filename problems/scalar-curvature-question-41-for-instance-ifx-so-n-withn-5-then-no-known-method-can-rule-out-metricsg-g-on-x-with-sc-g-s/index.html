Scalar Curvature Question [?41]: For instance, ifX =SO(n) withn≥5, then no known method can rule out metricsg ≥g on X with Sc(g) > Sc(g)

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $n\geq5$ and $X=\operatorname{SO}(n)=\{A\in M_n({\mathbb{R}}):A^{\mathsf T}A=I,\ \det A=1\}$. Let $\bar g$ be a bi-invariant Riemannian metric on $X$, meaning invariant under both left and right translations. The bar distinguishes this reference metric from a competing smooth metric $g$; the extraction prints both as $g$, which would otherwise make the strict scalar curvature comparison impossible.

With the usual quadratic-form order on metrics, the question is whether there exists $g$ such that \[ g_x(v,v)\geq\bar g_x(v,v)\quad(x\in X,\ v\in T_xX),\qquad \operatorname{Scal}_g(x)>\operatorname{Scal}_{\bar g}(x)\quad(x\in X). \] Equivalently, can one rule out this simultaneous metric enlargement and everywhere strict scalar curvature improvement? The source says only that no known method rules it out, in its 2017 discussion; that is neither a proof of existence nor a verified statement of present knowledge. The competing metric is not assumed left invariant or bi-invariant.

The bi-invariant reference comes from the supplied summary and the adjacent local record ID 6700037. That context discusses area extremality, whereas the present extracted inequality is $g\geq\bar g$. The displayed formulation uses the usual tensor inequality; whether an area comparison was intended instead needs source checking. The reference metric's normalization is not supplied.

Short English statement

For $\operatorname{SO}(n)$, $n\geq5$, can a metric dominate a bi-invariant reference metric while having strictly larger scalar curvature everywhere? The source describes a gap in available methods rather than asserting that such a metric exists.
