A later attributed result and an independently bounded test case

The primary workshop describes a polynomial loss in deterministic communication condensation and asks whether it is necessary. A later primary preprint by Simon Mackenzie, dated September 2026, claims lossless condensation. Its Theorem1.1 states: for a finite total Boolean matrix of deterministic cost $c\ge4$ and fixed $0<\varepsilon<1$, there is an original $2^k$-by-$2^k$ submatrix with $1\le k\le c-1$, $k\ge(\varepsilon c-4)/3$, and cost at least $(1-\varepsilon)(k+1)$. We read its statement and conventions, not its entire proof. This attributed claimed resolution postdates the preserved catalogue assessment; it is not our new result or an independently certified solution. We use deterministic binary protocols with fixed Boolean outputs at leaves. Let $\mathrm{EQ}_N(i,j)$ be equality on $[N]^2$, $N\ge2$.
Proposition: Its cost lies between $\lceil\log_2N\rceil$ and $\lceil\log_2N\rceil+1$. More generally, on a restriction $A\times B$, put $r=|A\cap B|$. If $r\ge1$, the restricted cost lies between $\lceil\log_2r\rceil$ and $\lceil\log_2(r+1)\rceil+1$; if $r=0$, it is zero.
Proof: Each protocol transcript defines a rectangle: at an Alice node its branch restricts only the row set, and at a Bob node only the column set, so induction from the full rectangle proves the claim. A monochromatic one-rectangle cannot contain two distinct diagonal entries $(i,i),(j,j)$, since it would also contain the zero entry $(i,j)$. Thus there are at least $r$ leaves, and a binary depth-$d$ tree has at most $2^d$ leaves, yielding the lower bound. For the unrestricted upper bound, Alice sends her index using $\lceil\log_2N\rceil$ bits and Bob sends the answer. For the restriction, Alice sends either the index of her element in $A\cap B$ or a special symbol for an element outside that intersection, using $\lceil\log_2(r+1)\rceil$ bits. Bob can then test equality and announce one bit. If the intersection is empty the output is constantly zero. ∎
In particular an $m$-by-$m$ equality square retains cost of order $\log m$. Retaining a constant fraction of $\log N$ needs $m$ polynomial in $N$, which is exponential in the original cost. This is consistent with the source's $2^{O(c)}$ target, not a counterexample. Confusing matrix dimension with its logarithm would give an erroneous obstruction. A basic cover route also shows the remaining step. If the rows are covered by $h$ sets, each supporting a protocol of cost at most $d$ against all columns, Alice can announce the first covering set containing her row and run that protocol. Hence total cost is at most $\lceil\log_2h\rceil+d$. Without a quantitative bound on $h$, cheap restrictions do not give a cheap global protocol. We do not supply the rank-sensitive covering analysis needed by the later preprint.

Verification and remaining gaps

Exact dynamic programming over all nontrivial row/column bipartitions computed protocol depth for small equality matrices and restrictions, checking the stated intervals. The cover protocol was checked directly on finite covers. These auxiliary facts do not independently prove general condensation.
