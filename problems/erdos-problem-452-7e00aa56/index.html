Statement

Let $\omega(n)$ denote the number of distinct prime divisors of the positive integer $n$. Fix a real parameter $x\ge 3$. Define \[ L(x):=\max\Big\{\,\ell\in\mathbb N:\ \exists N\in\mathbb Z\ \text{s.t.}\ x\le N\le 2x-\ell+1\ \text{and}\ \omega(N+j)>\log\log(N+j)\ \forall j\in\{0,\dots,\ell-1\}\Big\}. \] (So $L(x)$ is the length of the longest interval of consecutive integers contained in $[x,2x]$ on which $\omega(n)>\log\log n$ holds throughout.) The problem asks for the order of magnitude / asymptotics of $L(x)$ as $x\to\infty$.
