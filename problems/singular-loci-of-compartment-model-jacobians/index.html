Singular Loci of Compartment Model Jacobians

Definitions and mathematical statement

The supplied record asks for the parameter values at which a Jacobian associated with a linear compartment model loses rank. It does not identify the map being differentiated, so it does not determine a unique mathematical locus.

A conditional formulation is as follows. Fix a linear compartment model, a nonempty parameter domain $\Theta$, a scalar field $K$, and a specified map $F=(F_1,\ldots,F_q):\Theta\to K^q$, with parameter coordinates $\theta=(\theta_1,\ldots,\theta_p)$, for which the coordinate derivatives below are defined. Set \[ J_F(\theta)=\left(\frac{\partial F_i}{\partial\theta_j}(\theta)\right)_{\substack{1\leq i\leq q\\1\leq j\leq p}}, \qquad r_{\max}=\max_{\theta\in\Theta}\operatorname{rank}_{K}J_F(\theta). \] If "drops rank" means rank below the maximal rank on the chosen domain, the problem is to determine exactly \[ \Sigma_F=\{\theta\in\Theta:\operatorname{rank}_{K}J_F(\theta)<r_{\max}\}. \] This is a formulation template, not an identification of the intended Jacobian. The source does not specify whether the Jacobian is that of a parameter-to-coefficient map, another identifiability map, or a different map associated with the model. It also leaves the parameter domain and reference rank unspecified.

The original excerpt includes a figure caption describing a catenary (path) model with $n$ compartments, with an input, output, and leak at compartment $1$. The supplied record does not include the figure, equations, edge directions, admissible values of $n$, or a complete parameter list. It therefore does not establish whether the requested classification concerns this particular family or linear compartment models more generally. Positivity requirements, allowance of zero rates, and boundary parameter values must be specified before the locus above can serve as the intended problem statement.

Short English statement

Determine exactly which admissible parameter values make the intended Jacobian of a linear compartment model have rank below its specified reference rank. The map, parameter domain, and model family remain unresolved; the supplied excerpt mentions a path model with an input, output, and leak at compartment $1$.
