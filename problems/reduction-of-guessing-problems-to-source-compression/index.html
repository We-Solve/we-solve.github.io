Literature and context check

The report, p. 691, asks about general reductions and mentions guessing variants for which direct compression arguments do not suffice. It does not define a single universal reduction model. The selected attempt tests the narrower route of using only optimal expected prefix-code length to recover ordinary expected guessing cost.

Research attempt: Optimal expected code length alone does not determine optimal guessing cost

For a finite distribution, asking singleton guesses in decreasing probability order minimizes expected guess count. If probabilities $p_a>p_b$ are placed at positions $j>i$, swapping them changes the expected count by $-(j-i)(p_a-p_b)<0$. Repeatedly removing inversions proves the claim, with ties harmless.

For a binary prefix code on three positive-probability symbols, the optimal expected length is $2-p_{\max}$. At most one codeword can have length one when there are three codewords: the two one-bit words would otherwise exhaust both branches and allow no third prefix-free word. If there is one length-one word, the other lengths are at least two, giving expected length at least $2-p_a\ge2-p_{\max}$. If there is none, every length is at least two. Assigning 0 to a most probable symbol and 10,11 to the others attains $2-p_{\max}$.

Now take $p=(1/2,3/10,1/5)$ and $q=(1/2,2/5,1/10)$. Both have optimal expected prefix length $3/2$. Their optimal expected guess counts are respectively \[ \tfrac12+2\cdot\tfrac3{10}+3\cdot\tfrac15=\tfrac{17}{10},\qquad \tfrac12+2\cdot\tfrac25+3\cdot\tfrac1{10}=\tfrac85. \] Consequently the scalar optimal expected compression length is insufficient to determine the scalar optimal guessing cost. This does not preclude a reduction that uses the original distribution, a different compression objective, or an entire optimized code.

A precise related inequality shows why a different coding objective can matter. Order a binary prefix code's symbols by increasing codeword length. A symbol of length $\ell$ has guessing rank at most $2^\ell$: extend all codewords of length at most $\ell$ to binary strings of length $\ell$; prefix-freeness makes their sets of extensions disjoint, and each uses at least one of the $2^\ell$ strings. Thus for $\rho>0$, this guessing rule satisfies $E G^\rho\le E2^{\rho\ell(X)}$. This is an exponential length moment, not the expected length alone. It is a proved one-direction relation, not an optimality equivalence for all guessing variants.

Verification and adversarial audit

Both distributions are strictly positive, their probability orders are explicit, and the three-symbol prefix-code optimum is proved without invoking a coding algorithm.
