Statement

For every $\epsilon>0$, every $N\ge 1$, and every Sidon set $A\subseteq [N]$, does there exist an integer $M\ge N$ and a set $B\subseteq \{N+1,\dots,M\}$ such that $A\cup B$ is Sidon and \[ |A\cup B|\ge (1-\epsilon)\sqrt{M}? \] (Here Sidon is in $\mathbb{Z}$, i.e. $x_1+x_2=x_3+x_4$ with $x_i\in A\cup B$ implies the corresponding multisets of summands are equal.)

Erdős Problem #44 --- Round 4

1) ROUND-4 OBJECTIVE

Path (A): proof. Given the Round-3 status, the most promising direction is not to restart the global problem, but to close the cutoff-quantifier gap left by Round 2 and Round 3. Round 2 proved that every finite Sidon set extends to a Sidon superset of density $(1/\sqrt2-o(1))$ for some cutoff $M$, and Round 3 upgraded this to an infinite perfect-difference completion with the same limsup density. In this round I prove a strictly stronger finite theorem: \[ \textit{for every sufficiently large } M, \textit{ not merely for some } M, \] there is a Sidon extension of size at least $(1/\sqrt2-\varepsilon)\sqrt M$. This does not settle the original constant-$1$ target, but it eliminates the remaining "sporadic $M$" weakness in the Round-2 construction.

2) ROUND-3 FOUNDATION USED

I use the following previously established ingredient, which Round 3 explicitly preserved as valid progress from Round 2.

Round-2 block-extension construction. Fix a finite Sidon set $A\subset [N]$ and a prime power $q$. Put \[ L:=q^2+q+1. \] Whenever $L>N$, the Round-2 Singer-block + forbidden-difference pruning + sum-range separation argument produces a set \[ B\subset [N+L+1,\,N+2L] \] such that $A\cup B$ is Sidon and \[ |A\cup B|\ge q-N+2. \] I use this construction as a black box; I do not re-prove it here.

The unresolved issue after Round 3 was therefore not how to build one dense block, but how to choose the block order $q$ so that the resulting cutoff lands at a prescribed large $M$.

3) NEW INSIGHT / TOOL (ROUND-4)

The new ingredient is a prime-near-target selection lemma. By the prime number theorem, for every fixed $\delta>0$, every sufficiently large interval \[ [(1-\delta)x,\,x] \] contains a prime. Since a prime is a prime power, this lets us choose the Singer parameter $q$ very close to the target value \[ \sqrt{\frac{M-N}{2}}, \] so that the Round-2 block occupies almost exactly half of $[1,M]$. This upgrades "there exists some $M$" to "every sufficiently large $M$" without changing the constant $1/\sqrt2$.

4) ATTACK PLAN (ROUND-4)

Exact gap left after Round 3. Round 3 supplied infinitely many dense cutoffs, but not a theorem for a given large $M$.

Precise claim to prove now. For every finite Sidon set $A\subset [N]$ and every $\varepsilon>0$, there exists $M_0=M_0(A,\varepsilon)$ such that for every $M\ge M_0$ there exists \[ B\subset \{N+1,\dots,M\} \] with $A\cup B\subset [M]$ Sidon and \[ |A\cup B|\ge \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \]

Why this plan works. The Round-2 construction already gives the right density once $q$ is chosen. The only missing step is to ensure simultaneously that \[ q^2+q+1\le \frac{M-N}{2} \] and \[ q=(1-o(1))\sqrt{\frac M2}. \] A prime in a short relative interval does exactly this.

5) WORK (ROUND-4)

5.1\; Prime near a prescribed target

Lemma (Prime in a short relative interval): For every $\delta\in(0,1)$ there exists $x_0=x_0(\delta)$ such that every real $x\ge x_0$ admits a prime $q$ with \[ (1-\delta)x\le q\le x. \]
Proof: By the prime number theorem, \[ \pi(x)\sim \frac{x}{\log x} \qquad (x\to\infty). \] Hence for fixed $\delta\in(0,1)$, \[ \pi(x)-\pi((1-\delta)x) \sim \frac{x}{\log x}-\frac{(1-\delta)x}{\log((1-\delta)x)} \sim \frac{\delta x}{\log x}>0. \] Therefore $\pi(x)-\pi((1-\delta)x)\ge 1$ for all sufficiently large $x$, which means that the interval $[(1-\delta)x,x]$ contains a prime. ∎

5.2\; Main theorem: every sufficiently large cutoff is admissible

Theorem (Cofinite-cutoff extension at constant $1/\sqrt2$): Let $N\ge 1$ and let $A\subset [N]$ be a Sidon set. Then for every $\varepsilon>0$ there exists $M_0=M_0(A,\varepsilon)$ such that for every integer $M\ge M_0$ there exists a set \[ B\subset \{N+1,\dots,M\} \] for which $A\cup B\subset [M]$ is Sidon and \[ |A\cup B|\ge \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \]
Proof: If $\varepsilon\ge 1/\sqrt2$, then the target lower bound is nonpositive and the statement is trivial. So assume \[ 0<\varepsilon<\frac1{\sqrt2}. \] Choose $\delta\in(0,1/2)$ so small that \begin{equation} \label{wsref-0-65-71-3a-64-65-6c-74-61-2d-63-68-6f-69-63-65} \frac{1-\delta}{\sqrt2}>\frac1{\sqrt2}-\frac\varepsilon2. \end{equation} Apply Lemma Lemma (Prime in a short relative interval) with this $\delta$, and let $x_0=x_0(\delta)$ be the corresponding threshold.

For $M>N$, define \[ X(M):=\sqrt{\frac{M-N}{2}}-1. \] Then \[ \frac{X(M)}{\sqrt M}\longrightarrow \frac1{\sqrt2} \qquad (M\to\infty), \] so by (eq:delta-choice), \[ \frac{(1-\delta)X(M)-N+2}{\sqrt M}\longrightarrow \frac{1-\delta}{\sqrt2}>\frac1{\sqrt2}-\frac\varepsilon2. \] Hence there exists $M_1$ such that for every $M\ge M_1$, \begin{equation} \label{wsref-0-65-71-3a-73-69-7a-65-2d-74-61-72-67-65-74} (1-\delta)X(M)-N+2\ge \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \end{equation} Choose also $M_2$ so large that for every $M\ge M_2$, \begin{equation} \label{wsref-0-65-71-3a-61-75-78-2d-74-68-72-65-73-68-6f-6c-64-73} X(M)\ge x_0, \qquad (1-\delta)X(M)\ge N, \qquad M\ge N+2. \end{equation} Set \[ M_0:=\max\{M_1,M_2\}. \] Now fix any integer $M\ge M_0$. By (eq:aux-thresholds) and Lemma Lemma (Prime in a short relative interval), there exists a prime $q$ such that \[ (1-\delta)X(M)\le q\le X(M). \] In particular $q\ge N$, so with \[ L:=q^2+q+1 \] we have $L>N$.

We next check that the Round-2 block fits inside $[M]$. Since $q\le X(M)$ and $X(M)=\sqrt{(M-N)/2}-1$, writing $Y:=\sqrt{(M-N)/2}$ gives $q\le Y-1$, and therefore \[ L=q^2+q+1\le (Y-1)^2+(Y-1)+1=Y^2-Y+1. \] Because $M\ge N+2$, one has $Y\ge 1$, so $Y^2-Y+1\le Y^2=(M-N)/2$. Hence \[ L\le \frac{M-N}{2}, \qquad\text{so}\qquad N+2L\le M. \]

Now invoke the Round-2 block-extension construction with this prime power $q$. It yields a set \[ B\subset [N+L+1,\,N+2L]\subset [N+1,\,M] \] such that $A\cup B$ is Sidon and \[ |A\cup B|\ge q-N+2. \] Finally, \[ |A\cup B|\ge q-N+2\ge (1-\delta)X(M)-N+2 \] and so by (eq:size-target), \[ |A\cup B|\ge \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \] This proves the theorem. ∎

5.3\; Reformulation of the advance

Theorem thm:cofinite-M strictly strengthens the Round-2 theorem. Round 2 gave, for fixed $(A,\varepsilon)$, existence of at least one suitable cutoff $M$. Round 4 gives every sufficiently large cutoff $M$. Thus the remaining gap to Erdős Problem #44 is no longer a quantifier problem about which $M$ are reachable; it is purely the density constant $1$ versus $1/\sqrt2$.

6) ADVERSARIAL VERIFICATION

  • Did I accidentally use more than Round 2 proved? No. The only imported fact is the explicit Round-2 construction: for each prime power $q$ with $L=q^2+q+1>N$, it produces a block $B\subset [N+L+1,N+2L]$ and the lower bound $|A\cup B|\ge q-N+2$.

  • Does the block really lie inside the prescribed ambient interval $[M]$? Yes. The estimate $L\le (M-N)/2$ gives $N+2L\le M$, so the entire Round-2 block sits inside $[N+1,M]$.

  • Could $q$ be too small, invalidating the Round-2 separation argument? No. By construction $q\ge N$, hence $L=q^2+q+1>N$.

  • Is the prime-selection lemma strong enough? Yes. We only need a prime in a fixed relative interval $[(1-\delta)x,x]$, and the prime number theorem implies this for all sufficiently large $x$.

  • Boundary cases. If $\varepsilon\ge 1/\sqrt2$, the theorem is trivial. If $A=\varnothing$, the same proof works verbatim with any $N\ge 1$ such that $A\subset [N]$.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED). This round does not settle the original constant-$1$ conjecture. However, it proves a genuinely stronger theorem than any previous round: \[ \textit{for every finite Sidon set }A\subset [N]\textit{ and every }\varepsilon>0,\textit{ every sufficiently large }M \] admits a Sidon extension inside $[M]$ of size at least \[ \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \] So the Round-2 / Round-3 constant $1/\sqrt2$ is now available with the correct cofinite quantifier in $M$; the only unresolved issue is whether the constant can be pushed all the way from $1/\sqrt2$ to $1$.

Erdős Problem #44: independent continuation

Date: 23 September 2026. Source versions read in full: 44.tex in gpt_pro_5.4.

1) OBJECTIVE AND SOURCE AUDIT

Given a finite Sidon set $A\subset[1,N]$, the original problem asks for an extension of size $(1-\varepsilon)\sqrt M$ for some $M$. The supplied argument upgrades a previously asserted block construction to every sufficiently large cutoff, at constant $1/\sqrt2$. I audit that construction instead of assuming the missing earlier round. The following lemma also replaces a loss depending on $N$ by one depending on $|A|$.

2) WORK: EXPLICIT COMPATIBILITY PRUNING

Write $k=|A|$, assume $L\ge N$, and let $S\subset[1,L]$ be any Sidon set of size $s$. There is a subset $S'\subset S$ of size at least $s-\binom{k}{2}$ such that \[ A\cup(N+L+S')\quad\hbox{is Sidon}. \] For each positive difference in $A-A$, delete one endpoint of the pair in $S$ realizing that difference, if such a pair exists. Each difference has at most one such pair because $S$ is Sidon. The set of forbidden positive differences has size $\binom{k}{2}$, so at most that many points are deleted. Now $(S'-S')\cap(A-A)\subseteq\{0\}$.

Put $B=N+L+S'$. The three types of sums lie in disjoint intervals: \[ A+A\subset[2,2N],\quad A+B\subset[N+L+2,2N+2L],\quad B+B\subset[2N+2L+2,2N+4L], \] provided $L\ge N$. Sums of the first and third type are unique as unordered pairs by the individual Sidon hypotheses. An equality $a+b=a'+b'$ in the middle type would give $a-a'=b'-b$, hence $a=a'$ and $b=b'$. This proves the lemma, including sums with repeated summands.

In particular, whenever a Singer-type block of length $L=q^2+q+1$ and size $q+1$ is supplied with $L\ge N$, this gives \[ |A\cup B|\ge q+1+k-\binom{k}{2},\qquad A\cup B\subset[1,N+2L]. \] The bound is uniform over the locations of the old points. Using the standard prime-near-target selection from the supplied attempt yields $(1/\sqrt2-o(1))\sqrt M$ at every sufficiently large $M$, now with a completely explicit compatibility proof. This corollary is conditional only on the stated classical block input; the pruning lemma needs no finite-field theorem.

3) VERIFICATION AND REMAINING GAP

The factor $2L$ is essential to this particular proof: moving the new block down can make mixed sums overlap new--new sums. Avoiding old differences alone does not exclude these new collisions. Thus improved deletion costs do not turn $1/\sqrt2$ into $1$; the principal asymptotic gap is untouched. The all-large-$M$ conclusion is already in the source, not a new result here.

7) FINAL AND REFERENCE

UNRESOLVED. A self-contained block-compatibility lemma and a better finite loss are established; no constant-$1$ extension has been found. Official target checked through the indexed primary page: https://www.erdosproblems.com/44.

Erdős Problem #44 --- Round 2

1) ROUND-2 OBJECTIVE

Path (A): proof. Round 1 isolated the key gap: Lemma 1 and Lemma 2 only add $O(\log M)$ new elements, whereas the target size is $\asymp \sqrt{M}$. In this round I push the block extension idea (Round-1 "next move" $2$) to obtain an unconditional constant-density extension. Specifically, I prove a gap-free theorem showing that every Sidon $A\subset [N]$ can be extended to a Sidon subset of some $[M]$ of size at least $(1/\sqrt2-\varepsilon)\sqrt M$. This does not settle the original $(1-\varepsilon)\sqrt M$ target, but it is a strict quantitative advance.

2) ROUND-1 FOUNDATION USED

I use the Round-1 formal restatement of the problem and the Round-1 identification of the main gap ("need $\Theta(\sqrt M)$ new elements without $M$ exponential"). I do not reuse Lemma 1 or Lemma 2 directly; instead I replace the exponential-growth tail with a dense block.

3) NEW INSIGHT / TOOL (ROUND-2)

New ingredients beyond Round 1:
  • Sum-range separation. Place the new set $B$ inside a top interval of $[M]$ so that \[A+A \;<\; A+B \;<\; B+B\] (as sets of integers). This deletes the hardest mixed collisions (e.g. $a+b=b_1+b_2$) by sheer range separation.
  • Forbidden-difference pruning lemma. Starting from any Sidon set $T$, delete at most $|F|$ elements to ensure that the remaining subset has no pairwise differences lying in a prescribed finite forbidden set $F$.
  • Dense Sidon blocks from finite geometry. Use Singer's construction of a perfect difference set (hence Sidon set) of size $q+1$ inside $[q^2+q+1]$ for every prime power $q$.

4) ATTACK PLAN (ROUND-2)

Gap from Round 1. We need a mechanism to add many elements in $\{N+1,\dots,M\}$ while preserving Sidon-ness.

Plan. Fix $A\subset [N]$ Sidon and choose a large length $L$ and an interval \[I:=[N+L+1,\,N+2L]\subset [M],\qquad M:=N+2L. \] We will place $B\subset I$ so that:

  1. $B$ itself is Sidon;
  2. no nonzero difference of two elements of $B$ equals a difference of two elements of $A$;
  3. because $I$ sits far above $[N]$, the sum-ranges $A+A$, $A+B$, $B+B$ are disjoint.
Then $A\cup B$ is Sidon by a direct case analysis. Choosing $L\approx q^2$ with $q$ large yields $|B|\approx \sqrt L$ and hence $|A\cup B|\approx \sqrt{M/2}=(1/\sqrt2)\sqrt M$.

5) WORK (ROUND-2)

5.1\; A Sidon set has unique differences

Lemma (Differences are unique in a Sidon set): Let $S\subset \mathbb Z$ be Sidon. If $x_1-x_2=x_3-x_4\neq 0$ with $x_i\in S$, then $(x_1,x_2)=(x_3,x_4)$. Equivalently, for each nonzero integer $d$ there is at most one ordered pair $(x,y)\in S^2$ with $x-y=d$.
Proof: From $x_1-x_2=x_3-x_4$ we obtain $x_1+x_4=x_3+x_2$. By Sidon-ness of $S$, the unordered multisets of summands are equal: \[\{x_1,x_4\}=\{x_3,x_2\}. \] If $x_1=x_2$ then the difference is $0$, excluded, so $x_1\neq x_2$. Thus the only way the multisets can coincide is $x_1=x_3$ and $x_4=x_2$, which forces $x_2=x_4$. Hence $(x_1,x_2)=(x_3,x_4)$. ∎

5.2\; Deleting a small set to avoid forbidden differences

Lemma (Forbidden-difference pruning): Let $S\subset \mathbb Z$ be a finite Sidon set and let $F\subset \mathbb N$ be any finite set. Then there exists a subset $S'\subseteq S$ such that
  1. for all distinct $u,v\in S'$ we have $|u-v|\notin F$; and
  2. $|S'|\ge |S|-|F|$.
Proof: Form a (simple) graph $G$ with vertex set $S$, joining two distinct vertices $u,v$ by an edge if $|u-v|\in F$. Fix $d\in F$. By Lemma Lemma (Differences are unique in a Sidon set), there is at most one unordered pair $\{u,v\}\subset S$ with $|u-v|=d$. Hence for each $d\in F$ there is at most one edge of $G$ labelled by $d$, and therefore \[|E(G)|\le |F|. \] Now pick a set $C\subseteq S$ by selecting, for each edge of $G$, one of its endpoints, and taking the union over edges. Then $C$ is a vertex cover of $G$ and $|C|\le |E(G)|\le |F|$. Let $S':=S\setminus C$. By construction $S'$ spans no edges in $G$, hence has no forbidden differences. Also $|S'|=|S|-|C|\ge |S|-|F|$. ∎

5.3\; A dense Sidon block (Singer)

Theorem (Singer): For every prime power $q$ there exists a set $D\subset \mathbb Z/(q^2+q+1)\mathbb Z$ of size $q+1$ such that every nonzero residue class has a unique representation as a difference of two elements of $D$. In particular, $D$ is a Sidon set in the cyclic group $\mathbb Z/(q^2+q+1)\mathbb Z$. Choosing representatives in $\{0,1,\dots,q^2+q\}$ gives a Sidon set of integers of size $q+1$ contained in $[0,q^2+q]$.
Proof[Comment]: This is Singer's construction of a perfect difference set; we use only its existence. The implication "perfect difference set $\Rightarrow$ Sidon" follows from rewriting $a+b=c+d$ as $a-c=d-b$ and invoking uniqueness of differences. If a set is Sidon in $\mathbb Z/m\mathbb Z$, then it is Sidon as a set of integers when represented in $\{0,\dots,m-1\}$, because an integer equality implies the same congruence mod $m$. ∎

5.4\; Main theorem: a universal $1/\sqrt2$-density extension

Theorem (Uniform extension with constant $1/\sqrt2$): Let $N\ge 1$ and let $A\subset [N]$ be Sidon. Then for every $\varepsilon>0$ there exist $M\ge N$ and $B\subset\{N+1,\dots,M\}$ such that $A\cup B\subset [M]$ is Sidon and \[ |A\cup B|\ge \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M. \]
Proof: We may assume $0<\varepsilon<1/\sqrt2$ (otherwise the lower bound is nonpositive and the claim is trivial).

Step 1: choose a dense Sidon block length. Let $q$ be a prime power satisfying \begin{equation} \label{wsref-0-65-71-3a-71-63-68-6f-69-63-65} q\ge \max\left\{\frac N2,\ \frac{N-1}{\sqrt2\,\varepsilon}-1\right\}. \end{equation} (Such $q$ exists, e.g. take $q=2^m$ for $m$ large.) Set \[L:=q^2+q+1,\qquad M:=N+2L. \] By Theorem Theorem (Singer) there exists a Sidon set $T\subset [L]$ of size $|T|=q+1$.

Step 2: forbid the differences coming from $A$. Define the forbidden absolute difference set \[F_A:=\{ |a-a'| : a,a'\in A,\ a\neq a'\}\subset \{1,2,\dots,N-1\}. \] In particular $|F_A|\le N-1$. Apply Lemma Lemma (Forbidden-difference pruning) to $S=T$ and $F=F_A$ to obtain $T'\subseteq T$ such that:

  1. for all distinct $u,v\in T'$ we have $|u-v|\notin F_A$; and
  2. $|T'|\ge |T|-|F_A|\ge (q+1)-(N-1)=q-N+2$.

Step 3: place the block in the top half of $[M]$. Define \[B:=\{t+(N+L):\ t\in T'\} \subset [N+L+1,\,N+2L]=[N+L+1,\,M]. \] Then $B\subset\{N+1,\dots,M\}$, and $B$ is Sidon because it is a translate of the Sidon set $T'$.

Step 4: verify $A\cup B$ is Sidon (sum-range separation + cross-sum injectivity). Write $S:=A\cup B$. We compare the ranges of the three kinds of sums: \begin{align*} A+A &\subset [2,\,2N],\\ A+B &\subset [\min(A)+\min(B),\ \max(A)+\max(B)]\subset [1+(N+L+1),\ N+(N+2L)]\\ &\subset [N+L+2,\ 2N+2L],\\ B+B &\subset [2\min(B),\ 2\max(B)]\subset [2(N+L+1),\ 2(N+2L)]\\ &= [2N+2L+2,\ 2N+4L]. \end{align*} Since $L> N$ (indeed $L=q^2+q+1> N$ since $q\ge N/2$), these three intervals are pairwise disjoint and ordered as \[A+A\;<\;A+B\;<\;B+B. \] Therefore, any solution of $x_1+x_2=x_3+x_4$ with $x_i\in S$ must lie entirely within one category. The $A+A$ and $B+B$ categories are trivial because $A$ and $B$ are Sidon. It remains to check $A+B$ sums are distinct.

Suppose $a_1+b_1=a_2+b_2$ with $a_i\in A$ and $b_i\in B$. Rearranging gives $b_2-b_1=a_1-a_2$. If $a_1\neq a_2$, then $|a_1-a_2|\in F_A$; taking absolute values gives \[|b_2-b_1|=|a_1-a_2|\in F_A. \] But $b_i$ are translates of elements of $T'$, and $T'$ was constructed to avoid all differences in $F_A$. Hence this is impossible. Therefore $a_1=a_2$, and then the equality forces $b_1=b_2$. So all $A+B$ sums are distinct, completing the Sidon verification.

Step 5: size lower bound. We have $|A\cup B|=|A|+|B|\ge |B|=|T'|\ge q-N+2$. Also, using $N\le 2q$ from (eq:qchoice), \[ M=N+2(q^2+q+1)=2q^2+2q+(N+2)\le 2q^2+4q+2=2(q+1)^2, \] so $\sqrt M\le \sqrt2\,(q+1)$. Thus \[ \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt M \le \left(\frac1{\sqrt2}-\varepsilon\right)\sqrt2\,(q+1)=(1-\sqrt2\,\varepsilon)(q+1). \] Therefore it suffices to prove $q-N+2\ge (1-\sqrt2\,\varepsilon)(q+1)$. But this inequality is equivalent to \[\sqrt2\,\varepsilon\,(q+1)\ge N-1, \] which holds by the choice of $q$ in (eq:qchoice). This proves the theorem. ∎

6) ADVERSARIAL VERIFICATION

  • Repeated summands. The Sidon definition allows $x_1=x_2$. In the range separation check, $2b\in B+B$ is still $\ge 2(N+L+1)=2N+2L+2$, strictly larger than any $a+b\le 2N+2L$, so no hidden overlap.
  • Cross-sums among themselves. The only way $a_1+b_1=a_2+b_2$ could fail to force $a_1=a_2$ is if $b_1-b_2$ equals a nonzero difference of $A$. This is exactly what Lemma Lemma (Forbidden-difference pruning) eliminates.
  • Cardinality of $F_A$. We used only $F_A\subset\{1,\dots,N-1\}$, hence $|F_A|\le N-1$ (no bound on $|A|$ is needed).
  • Quantifiers/dependence. The construction chooses $M$ and $B$ depending on $(N,A,\varepsilon)$, as allowed.
  • Extremal small-$N$ cases. When $N=1$, $F_A=\varnothing$ and the construction works verbatim. If $A=\varnothing$, then $F_A=\varnothing$ and we simply place a dense Sidon block $B$ in the top interval.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED). The original problem asks for extension to size $(1-\varepsilon)\sqrt M$. In Round 2 we proved the following unconditional quantitative extension theorem: for every Sidon $A\subset [N]$ and every $\varepsilon>0$ there exist $M$ and $B\subset\{N+1,\dots,M\}$ such that $A\cup B$ is Sidon and \[|A\cup B|\ge \left(\tfrac1{\sqrt2}-\varepsilon\right)\sqrt M.\] The structural reason for the $1/\sqrt2$ loss is that we enforced $A+B$ and $B+B$ to lie in disjoint ranges; improving the constant beyond $1/\sqrt2$ requires handling those mixed collisions rather than separating them.
