Math-1577

Rank-one subgroups as Diophantine congruence limits

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $E/{\mathbb{Q}}$ be an elliptic curve and $G=E({\mathbb{Q}})$. Its Mordell--Weil rank is $\dim_{\mathbb{Q}}(G\otimes_{\mathbb{Z}}{\mathbb{Q}})$; assume this rank is two, so $G\cong{\mathbb{Z}}^2\oplus F$ for a finite abelian torsion group $F$. A subgroup $H\le G$ has rank one if $\dim_{\mathbb{Q}}(H\otimes_{\mathbb{Z}}{\mathbb{Q}})=1$. Interpreting definability in the field ${\mathbb{Q}}$ with its ring language, rational parameters, and an algebraic coordinate coding of $E({\mathbb{Q}})$, Shlapentokh's Question 20 asks \[ \forall E/{\mathbb{Q}}\text{ of rank }2\quad \exists H\le E({\mathbb{Q}})\text{ of rank }1 \quad H\text{ is existentially definable over }{\mathbb{Q}}. \] Over ${\mathbb{Q}}$, inequations can be converted to existential equations by inverses; finite coordinate charts and the identity point must be included when coding the projective curve. The short source does not itself specify a language or parameter convention; the ring-language interpretation is the one used by the aid.

Fix an infinite-order $P\in G$ and write $H_P=\langle P\rangle$. For each fixed positive integer $m$, define the congruence tube \[ T_m=H_P+[m]G =\bigcup_{r=0}^{m-1}\left([r]P+[m]G\right). \] Thus membership in $T_m$ is expressed by the finite disjunction \[ X\in G\quad\wedge\quad \bigvee_{r=0}^{m-1}\exists Q\in G\ (X=[r]P+[m]Q). \] Using the algebraic group law, each fixed tube is positive-existentially definable over ${\mathbb{Q}}$, with $P$ fixed. This means one finite formula for each fixed $m$, not an asserted single Diophantine formula with a variable integer multiplication index.

The supplied aid asserts the exact limit description \[ H_P=\bigcap_{N\ge1}\left(H_P+[N!]G\right),\qquad H_P+[(N+1)!]G\subseteq H_P+[N!]G. \] The finite-generation hypothesis matters here: $G/H_P$ is finitely generated, and its intersection of factorial multiples is zero, including its finite torsion part. This infinite conjunction is not a first-order existential definition. Moreover, if a nonempty finite expression is built from tubes $T_{m_1},\ldots,T_{m_s}$ using only intersections and unions, it contains $[L]G$, where $L=\operatorname{lcm}(m_1,\ldots,m_s)$. Hence it contains a rank-two subgroup and cannot itself be a rank-one subgroup. This obstruction concerns those finite positive combinations, not arbitrary field-language formulas.

The independent pure-group obstruction reported by the aid is: for $G\cong{\mathbb{Z}}^2\oplus F$, no subgroup of rank one is definable in one free group variable by a positive-existential formula in $\{0,+,-\}$, even with parameters from $G$. Such formulas use existential quantifiers, conjunctions, and disjunctions of group equations, not arbitrary negations or field arithmetic. The assertion does not cover the intended ring-language problem, whose quantified witnesses can range over rational field coordinates. Thus the aid's negative pure-group result and factorial-limit description leave the original existential field-arithmetic question open.

Short English statement

Does every rank-two rational elliptic curve have an existentially definable rank-one subgroup? The aid describes a cyclic subgroup as an infinite intersection of individually Diophantine congruence tubes, while ruling out finite positive tube combinations and positive-existential definitions using only the abstract group language.
