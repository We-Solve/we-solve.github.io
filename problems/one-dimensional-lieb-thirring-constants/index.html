One-Dimensional Lieb-Thirring Constants

OpenAI's claim

The linked manuscripts present the following claims by OpenAI: All equality cases of that matrix inequality are claimed to be channels in a constant unitary basis, each either zero or a scalar single-state soliton; The scalar one-dimensional Lieb--Thirring optimal constant is claimed to be the one-bound-state value for every $1/2<\gamma<3/2$; The same sharp constant is claimed for Hermitian positive matrix potentials of every finite size, even when values at different points fail to commute. Together they give a claimed affirmative answer in the matching scope.

Mathematical statement of the claimed result

Result 1.
Fix a finite matrix size $m\ge1$, $1/2<\gamma<3/2$, and $p=\gamma+1/2$. For measurable Hermitian $W(x)\ge0$ with $\int_{\mathbb R}\operatorname{tr}(W^p)<\infty$, form $H_W=-d^2/dx^2-W$ by its $H^1$ quadratic form. The source claims \[ \sum_{\lambda_j(H_W)<0}|\lambda_j|^\gamma \le C_\gamma\int_{\mathbb R}\operatorname{tr}(W^p),\quad C_\gamma=\left(\frac{\gamma-1/2}{\gamma+1/2}\right)^{\gamma-1/2} \frac{\Gamma(\gamma+1)}{\sqrt\pi\Gamma(\gamma+3/2)}. \] Writing $r=(\gamma-1/2)^{-1}$, equality occurs exactly for a constant unitary $U$, $0\le k\le m$, $a_j>0$, $x_j\in\mathbb R$, and \[ W(x)=U\operatorname{diag}(w_1(x),\ldots,w_k(x),0,\ldots,0)U^*,\quad w_j(x)=(r+1)a_j^2\operatorname{sech}^2(ra_j(x-x_j)) \] almost everywhere. Each nonzero channel has just the negative eigenvalue $-a_j^2$, and $k=0$ means the zero potential.
Result 2.
For $1/2<\gamma<3/2$ and $W\ge0$ in $L^{\gamma+1/2}(\mathbb R)$, put $H_{-W}=-d^2/dx^2-W$. Counting negative eigenvalues with multiplicity, the source claims \[ \sum_{\lambda_j<0}|\lambda_j|^\gamma\le C_\gamma\int_{\mathbb R}W^{\gamma+1/2},\quad C_\gamma=\left(\frac{\gamma-1/2}{\gamma+1/2}\right)^{\gamma-1/2} \frac{\Gamma(\gamma+1)}{\sqrt\pi\Gamma(\gamma+3/2)}. \] This constant is optimal. An equality potential is $W(x)=(r+1)\operatorname{sech}^2(rx)$, $r=(\gamma-1/2)^{-1}$.
Result 3.
Let $m\ge1$ be finite, $1/2<\gamma<3/2$, and $W:\mathbb R\to\mathbb C^{m\times m}$ be measurable, Hermitian, and positive semidefinite, with $\int\operatorname{tr}(W^{\gamma+1/2})<\infty$. For the form-defined operator $H_W=-d^2/dx^2-W$, the claim is \[ \sum_{\lambda_j(H_W)<0}|\lambda_j|^\gamma\le C_\gamma\int_{\mathbb R}\operatorname{tr}(W^{\gamma+1/2}),\quad C_\gamma=\left(\frac{\gamma-1/2}{\gamma+1/2}\right)^{\gamma-1/2} \frac{\Gamma(\gamma+1)}{\sqrt\pi\Gamma(\gamma+3/2)}. \] The constant is sharp for each $m$, witnessed by $W(x)=\operatorname{diag}((r+1)\operatorname{sech}^2(rx),0,\ldots,0)$, $r=(\gamma-1/2)^{-1}$.

Outline of the argument

The action estimate is refined to keep each convexity and trace defect. Vanishing defects force pointwise matrix relations and fixed invariant channels, after which the scalar differential equations identify the independent soliton scales and centers.

A finite-interval action inequality is obtained through a regularized matrix field and a rank-one comparison. Matrix paths with prescribed endpoints bound the action, which is integrated into the full negative-eigenvalue moment inequality; scalar solitons provide sharpness.

An integrated trace inequality controls a regularized matrix path without simultaneous diagonalization. The endpoint action estimate gives the complete negative-spectrum moment bound, and embedding a scalar one-bound-state channel shows the dimension-independent constant cannot improve.
