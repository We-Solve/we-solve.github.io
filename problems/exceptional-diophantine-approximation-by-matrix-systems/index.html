Exceptional Diophantine Approximation by Matrix Systems

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied record concerns a real matrix $L\in M_{\ell,m}({\mathbb{R}})$, where $M_{\ell,m}({\mathbb{R}})$ denotes the space of real $\ell$-by-$m$ matrices. For a vector $x=(x_1,\ldots,x_r)$ with a positive number of coordinates, write $\|x\|_\infty=\max_{1\leq i\leq r}|x_i|$. The record does not specify the admissible dimensions $\ell,m$ or the domain of the parameter $k$.

The supplied approximation function is \[ \psi_L(k)=\inf_{\substack{q\in{\mathbb{Z}}^m,\ p\in{\mathbb{Z}}^\ell\\ \|q\|_\infty\leq k}}\|Lq-p\|_\infty. \] There is an unresolved defect in this formulation: whenever $k\geq0$, the displayed admissible set includes $q=0$ and $p=0$, so the formula as written gives $\psi_L(k)=0$ for every $L$. A restriction excluding $q=0$ could change this, but no such restriction is present in the supplied record, and it is not inserted here.

The source asks which exceptional behaviors of $\psi_L$, relative to the generic case, are possible and how large the corresponding sets of matrices are. It does not define the generic case, the properties constituting exceptional behavior, or the notion of size of an exceptional set. Thus this is a broad classification question whose intended nontrivial formulation remains unresolved, rather than a fully specified quantified conjecture.

Short English statement

The question asks how matrix Diophantine approximation can differ from typical behavior and how large the exceptional sets are. The supplied formula permits the zero approximation and therefore vanishes for nonnegative $k$. The intended admissibility restriction, meaning of typical behavior, and notion of exceptional-set size require clarification.
