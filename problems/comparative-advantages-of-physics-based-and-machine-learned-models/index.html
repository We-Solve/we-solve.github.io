Verbatim supplied catalogue question

Is a physics-based model always advantageous when the underlying system obeys physical laws, and which modelling or controller-design problems can be solved better with machine learning?

The original comparison and this attempted formalization

The original workshop discussion, printed page 1211, asks which modelling and controller-design tasks machine learning handles better and calls for a benchmark library. It does not specify a loss, information budget, noise class, or permitted physical-model error. Consequently there is no universal numerical comparison to prove. We attempt a common-loss comparison on a fully specified one-step dynamical system. Its exact bias/variance calculation shows which missing assumptions change the answer; it is not a replacement solution of the broad source agenda.

Exact scalar control calculation

Fix $\lambda>0$ and the physical law \[ x_+=a x+u,\qquad J_a(x,u)=(a x+u)^2+\lambda u^2. \] Completing the square gives \[ J_a(x,u)=\frac{\lambda a^2x^2}{1+\lambda} +(1+\lambda)\left(u+\frac{a x}{1+\lambda}\right)^2. \] Thus, when the parameter $a$ is known exactly, the unique optimal action is $u_a=-a x/(1+\lambda)$. A plug-in model using $b$ incurs exactly the regret \[ J_a(x,u_b)-J_a(x,u_a)=\frac{x^2(a-b)^2}{1+\lambda}. \] This identity includes the equilibrium $x=0$, where every plug-in action is zero and the regret vanishes. It provides a common criterion for the following comparison, evaluated at $x=1$.

Suppose $N\ge1$ independent reset experiments start at $x=1$, apply $u=0$, and return $Y_i=a+\eta_i$, where $\mathbb E\eta_i=0$, $\mathbb E\eta_i^2=\sigma^2<\infty$. Use $\widehat a=N^{-1}\sum_iY_i$. Independence gives $\mathbb E(\widehat a-a)^2=\sigma^2/N=:v$. A nominal physical parameter $a_0$ instead has squared error $b^2=(a-a_0)^2$. Therefore the expected regrets are respectively \[ \frac{v}{1+\lambda},\qquad \frac{b^2}{1+\lambda}. \] The data estimate is better exactly when $v<b^2$, worse when $v>b^2$, and tied when they are equal. This is an estimation comparison, not evidence that a particular neural-network architecture outperforms traditional system identification. If the true parameter is supplied, the physical controller has zero regret and no method can improve on it for this loss.

A hybrid and its information requirement

For a fixed real $w$ consider $\widetilde a=w\widehat a+(1-w)a_0$. Its mean squared error is \[ w^2v+(1-w)^2b^2. \] The cross term vanishes because $\widehat a-a$ is centered. When $b^2+v>0$, completing the square yields its optimum at $w_*=b^2/(b^2+v)$ with value $b^2v/(b^2+v)$. When both are zero every choice has zero error. The oracle weight uses unknown $b^2$ and cannot be advertised as an implementable advantage without extra information.

If instead a certified parameter-error bound $|a-a_0|\le B$ is supplied and $v$ is known, the worst-case risk among these fixed-weight rules is $w^2v+(1-w)^2B^2$. Indeed the coefficient of $b^2$ is nonnegative and the endpoints attain the bound. Its minimizing weight is $B^2/(B^2+v)$ when the denominator is positive, and its worst-case regret is \[ \frac{B^2v}{(B^2+v)(1+\lambda)}. \] This is a complete minimax statement only within the displayed family of fixed linear shrinkage estimators. It does not assert minimax optimality among every data-dependent controller.

Failure of learning without informative experiments

The successful comparison used excitation at $x=1$. Suppose all available experiments instead reset to $x=0$. Use a common parameter-independent noise law in the two parameter cases below, and an algorithmic random seed independent of the parameter. Even if actions are selected adaptively, observations $Y_i=u_i+\eta_i$ have a joint distribution independent of $a$: induction on observations and the controller's random seed proves this transcript claim. Consider two possible laws $a=A$ and $a=-A$, with $A>0$, and a subsequent control task at $x=1$. Any learned action $U$ has the same law in the two cases. The average of its two expected regrets is \[ \frac12\mathbb E\left[(1+\lambda) \left(U+\frac{A}{1+\lambda}\right)^2 +(1+\lambda)\left(U-\frac{A}{1+\lambda}\right)^2\right] =(1+\lambda)\mathbb E U^2+\frac{A^2}{1+\lambda} \ge\frac{A^2}{1+\lambda}. \] Infinite second moment only makes the conclusion stronger. Thus at least one physical law has regret at least this amount, regardless of the number of uninformative observations or the expressiveness of the learning algorithm. The constant action zero attains this minimax value for the two-point parameter class. This lower bound is restricted to the specified experiment protocol; allowing nonzero state excitation changes it.

Audit, attempted inference, and remaining scope

The attempted inference that the mere existence of a physical law favours either modelling method fails because exact knowledge, misspecification, observation noise, and experimental excitation produce different comparisons on the same system and loss. The calculations also show why physics and learning are not disjoint mathematical classes: a learned parameter can be inserted into the physical controller, and the hybrid uses both sources. The audit checked the zero-noise and zero-bias cases, the unknown oracle shrinkage weight, adaptive transcript independence, and the restriction of the minimax family. These are complete elementary auxiliary results, with no novelty claim, simulation, or theorem prover. A general source-level advantage criterion is not obtained.
