Math-1196

Ryser–Brualdi–Stein Near-Transversal Conjecture

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $n\geq 1$ be an integer and write $[n]=\{1,\ldots,n\}$. A Latin square of order $n$ is a function $L:[n]\times[n]\to[n]$ such that each symbol occurs exactly once in each row and exactly once in each column. A partial transversal is a set $T\subseteq[n]\times[n]$ such that, for distinct $(i,j),(i',j')\in T$, one has $i\neq i'$, $j\neq j'$, and $L(i,j)\neq L(i',j')$. Its length is $|T|$. A full transversal has length $n$.

Near-transversal conjecture (Ryser--Brualdi--Stein, as attributed in the supplied record). For every integer $n\geq1$ and every Latin square $L$ of order $n$, there exists a partial transversal $T$ satisfying \[ |T|=n-1. \] For $n=1$, the empty set is permitted. Equivalently, every Latin square of order $n$ has a partial transversal of length at least $n-1$, since entries can be discarded from a longer partial transversal.

Source qualifications. The original excerpt uses the phrase "a transversal which uses all but at most one symbol"; the supplied clean statement interprets this as a partial transversal of length at least $n-1$. The dated literature assessment also discusses a full-transversal assertion for odd orders. That assertion would require $|T|=n$ whenever $n$ is odd, and is a separate, stronger requirement than the near-transversal statement formulated here. The record labels the problem partially solved and labels its statement corrected_verified; these are supplied curation labels, not independent verification in this draft.

Short English statement

Does every Latin square of positive order $n$ contain $n-1$ entries in distinct rows and distinct columns, all carrying different symbols? The supplied dated assessment reports results for sufficiently large orders; this draft preserves the universal conjecture and requires human mathematical review.
