Performance Gains from Robust Mean–Variance Portfolios

Definitions and mathematical statement

For a real-valued portfolio return $X$ under a probability law $P$, when $\mathbb E_P[X^2]<\infty$, its mean and variance are \[ \mu_P(X)=\mathbb E_P[X],\qquad \operatorname{Var}_P(X)=\mathbb E_P\!\left[(X-\mu_P(X))^2\right]. \] These definitions explain the mean--variance terminology; the source does not specify a return variable, investment horizon, probability law, or moment assumptions. Robust portfolio selection considers uncertainty in the inputs or models used to select a portfolio. Here the uncertainty explicitly includes volatility, correlation, and model specification, but the source does not define an uncertainty set or a particular robustness criterion.

Source question. How much can robust mean--variance portfolio strategies improve investor performance under uncertainty in volatility, correlation, and model specification?

A quantitative comparison can be expressed schematically as follows. Once an admissible strategy class $\mathcal A$, a set $\Theta$ of possible models, a real-valued performance criterion $J:\mathcal A\times\Theta\to{\mathbb{R}}$ oriented so that larger values are preferred, a robust strategy $a_{\mathrm{rob}}\in\mathcal A$, and a benchmark strategy $a_{\mathrm{base}}\in\mathcal A$ have been specified, define \[ \Delta(\theta)=J(a_{\mathrm{rob}},\theta)-J(a_{\mathrm{base}},\theta),\qquad \theta\in\Theta. \] The question then concerns the magnitude and circumstances of performance improvement. Short English statement

The problem asks how much robust mean--variance portfolio selection can improve investor performance when volatility, correlations, and the model itself are uncertain. A precise quantitative claim requires an investment model, uncertainty set, portfolio constraints, benchmark, and performance measure. These are absent from the supplied record, so the question remains a research objective requiring further specification.
