Definitions and mathematical statement

A Euclidean convex body conventionally means a compact convex set $K\subset{\mathbb{R}}^n$ with nonempty interior. The supplied record does not specify the dimension $n$, boundary regularity, or the precise class of billiard trajectories under consideration.

To describe the intended minimization problem schematically, let $D$ be a billiard domain in an ambient space $M$, and let $\mathcal B(D)$ denote a specified class of admissible billiard trajectories in $D$. For a trajectory $\gamma$, let $L(\gamma)$ denote its length in the ambient geometry. A shortest trajectory in this class would be an element $\gamma_*\in\mathcal B(D)$ satisfying \[ L(\gamma_*)=\inf_{\gamma\in\mathcal B(D)}L(\gamma). \] This notation is only a framework: the source does not define $\mathcal B(D)$, assert attainment of the infimum, or specify whether trajectories must be nonconstant, closed, or periodic.
