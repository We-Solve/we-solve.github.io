Math-3633

Existential Completeness in Triangle-Free Graphs

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a simple undirected graph $G=(V,E)$, write $x\sim_G y$ when $\{x,y\}\in E$. The graph is triangle-free if there are no three distinct pairwise adjacent vertices. A set $A\subseteq V$ is independent if no two distinct vertices of $A$ are adjacent. The simple undirected graph convention is used here to express the statement; the supplied record does not explicitly specify graph conventions or whether graphs must be finite.

For an integer $k\geq 0$, define the extension property stated literally in the supplied record by \[ P_k(G)\;\Longleftrightarrow\; \forall A,B\subseteq V,\quad \left[ \begin{gathered} A\text{ is independent},\qquad A\cap B=\varnothing,\\ |A|+|B|\leq k \end{gathered} \right] \Longrightarrow \left[ \exists x\in V\quad (\forall a\in A,\ x\sim_G a) \ \land\ (\forall b\in B,\ x\not\sim_G b) \right]. \] Here $B$ is arbitrary subject to the displayed conditions; it need not be independent. Empty sets $A$ and $B$ are allowed, so $P_k(G)$ requires a vertex even when both sets are empty. The record calls a triangle-free graph with this property $k$-existentially complete.

Question, with unresolved scope. Let $\mathcal C$ denote the intended class of triangle-free graphs. Does there exist a positive integer $r$, independent of $G$, such that \[ \forall G\in\mathcal C,\qquad \neg P_r(G)? \] The supplied record leaves the class $\mathcal C$ unspecified with respect to finiteness. It also does not explicitly require the witnessing vertex $x$ to lie outside $A\cup B$. If a fresh vertex is intended, the existential quantifier in the definition must instead read $\exists x\in V\setminus(A\cup B)$. These qualifications must be resolved before this draft can be treated as a precise statement of the intended conjecture.

Short English statement

The question asks whether a fixed positive integer $r$ prevents every triangle-free graph in the intended class from realizing all adjacency patterns prescribed by an independent set $A$ and a disjoint set $B$, with $|A|+|B|\leq r$. The source leaves graph finiteness and the requirement that the realizing vertex be outside $A\cup B$ unresolved.
