Kourovka Notebook Problem 12.28

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $G$ be a group with identity $1_G$. A function $f\colon G\to{\mathbb{C}}$ is called normed if $f(1_G)=1$, central if \[ f(gh)=f(hg)\qquad(g,h\in G), \] and positive-definite if, for every integer $n\geq1$, every $g_1,\ldots,g_n\in G$, and every $c_1,\ldots,c_n\in{\mathbb{C}}$, \[ \sum_{k=1}^{n}\sum_{l=1}^{n} f(g_k^{-1}g_l)\overline{c_k}c_l\in{\mathbb{R}}_{\geq0}. \] A group is locally finite if each subgroup generated by finitely many elements is finite, and simple if it is nontrivial and its only normal subgroups are $\{1_G\}$ and $G$.

The supplied classification question is: classify the infinite simple locally finite groups $G$ admitting a normed, central, positive-definite function $f\colon G\to{\mathbb{C}}$.

Unresolved qualification. These three conditions alone do not express the intended distinction: on every group, both the constant function $f(g)=1$ and the function \[ \delta_{1_G}(g)=\begin{cases}1,&g=1_G,\\0,&g\neq1_G\end{cases} \] satisfy them. The supplied source nevertheless asserts that simple Chevalley groups have no such functions, whereas locally matrix (or stable) classical groups over finite fields possess such functions. These are supplied source assertions, and the nonexistence assertion is incompatible with the displayed conditions alone. An additional restriction on the admissible functions appears to be missing; the record does not specify it. Consequently, a precise formulation of the intended classification remains unresolved, and no additional restriction is imposed here.

The source describes the question as motivated by the theory of $C^*$-algebras and identifies the references below as motivation and partial results. Its status label is open; this is supplied registry metadata, not an independently verified assessment.

Short English statement

The source asks which infinite simple locally finite groups admit normalized, central, positive-definite complex functions. Its stated nonexistence claim conflicts with the given definition, since the constant function and the identity indicator always qualify. A missing restriction must be recovered before the intended classification can be stated precisely.
