O29 — NP-hardness of exact shortest vector

Status Solved · unsolvedmath.comLLM status Solved from source status

Top Open Problems Not reported cataloguedSolvedSolved

Statement

Definitions and mathematical statement

The exact Euclidean shortest vector problem takes a nonsingular integer matrix $B\in{\mathbb{Z}}^{n\times n}$, encoded in binary, defining the full rank lattice \[ L(B)=\{Bz:z\in{\mathbb{Z}}^n\}\subset{\mathbb{R}}^n. \] Its output is a vector $v\in L(B)\setminus\{0\}$ with \[ \|v\|_2=\lambda_1(L(B)):=\min\{\|w\|_2:w\in L(B)\setminus\{0\}\}. \] The dimension $n$ is part of the input, and the requested answer is exact, not an approximation within a factor. The source asks whether this search problem is NP-hard.

A corresponding decision task, useful for specifying hardness reductions, takes a nonnegative rational threshold $t$ and asks whether $\lambda_1(L(B))^2\leq t$. An exact shortest-vector output determines this answer. The source does not specify the reduction type intended by NP-hardness of its search task.

The registry reports that Euclidean exact SVP is NP-hard under randomized reductions, attributing this to Ajtai (STOC 1998). That qualification is essential: it is not an assertion here of deterministic many-one NP-hardness. The precise randomized reduction and success/error convention are not supplied. The summary's additional $\ell_\infty$ result concerns a different norm and is recorded only as related context.

Short English statement

Is finding an exactly shortest nonzero vector in a variable-dimensional full rank integer lattice NP-hard for Euclidean norm? The supplied resolution uses randomized reductions, whose precise convention is not specified.
