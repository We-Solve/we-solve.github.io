Math-3404

Analytic Preorders from Colored Countable Linear Orders

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

To match the coloring space in the source, regard $P=({\mathbb{N}},\le_P)$ as a countable quasi-order (or fix an enumeration of its label set). A quasi-order is reflexive and transitive. It is a well-quasi-order if every sequence $(p_i)_{i\in{\mathbb{N}}}$ has $i<j$ with $p_i\le_Pp_j$. A standard definition of better-quasi-order is that for every infinite $A\subseteq{\mathbb{N}}$ and every continuous map $F:[A]^\omega\to P$, with $P$ discrete and $[A]^\omega$ given its increasing-sequence topology, some $X\in[A]^\omega$ satisfies \[ F(X)\le_P F(X\setminus\{\min X\}). \] Assume $P$ is well-quasi-ordered but not better-quasi-ordered.

Let $LO$ be the standard Borel space of linear orders on ${\mathbb{N}}$, coded as subsets of ${\mathbb{N}}\times{\mathbb{N}}$. For $(\sqsubseteq,\varphi),(\sqsubseteq',\varphi')\in LO\times{\mathbb{N}}^{{\mathbb{N}}}$, define \[ (\sqsubseteq,\varphi)\preccurlyeq_P(\sqsubseteq',\varphi') \] if and only if there is an injective $g:{\mathbb{N}}\to{\mathbb{N}}$ such that for every $i,j\in{\mathbb{N}}$, \[ i\sqsubseteq j\ \Longleftrightarrow\ g(i)\sqsubseteq'g(j), \qquad \varphi(i)\le_P\varphi'(g(i)). \] Thus the embedding preserves the linear order and allows labels to increase in $P$, rather than requiring equality of colors. With the countable coding above this is an analytic preorder.

Classify $\preccurlyeq_P$ for well-quasi-orders $P$ that are not better-quasi-orders. A natural descriptive-set-theoretic interpretation is classification under Borel reducibility: for preorders $R,S$ on standard Borel spaces, $R\le_B S$ means that a Borel map $h$ satisfies $xRy$ if and only if $h(x)Sh(y)$. However, the source does not explicitly say whether it asks for exact Borel-reducibility degrees, Borel versus non-Borel complexity, universality, or classification by another comparison. That target and any dependence on the particular non-better well-quasi-order remain unresolved.

The supplied assessment discusses established behavior for labels that are not well-quasi-ordered and for better-quasi-ordered labels. Those are contextual cases, not replacements for the intermediate class requested here.

Short English statement

The problem studies embeddability of countable linear orders with labels that may increase along a fixed well-quasi-order. It asks for the descriptive complexity when that label order fails to be a better-quasi-order, with the exact classification standard still to be specified.
