Kirby Problem 2.40

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $S$ be an infinite-type surface in the source's marked conformal-surface setting, and let $\varphi$ be a mapping class, an isotopy class of homeomorphisms of $S$. Use the full space $\operatorname{Teich}(S)$ of marked conformal structures discussed in the source, rather than silently restricting to a single base-structure quasiconformal component. Its precise equivalence, topology, orientation, and boundary conventions are referred to [BC24a] and [Tap23] but not specified in this record.

Assume $\varphi$ has a quasiconformal self-homeomorphism representative for some marked structure $\Sigma$, and let $T$ be the component containing $\Sigma$. For $\sigma\in T$, put \[K_T(\sigma)=\min\{K(f):f:\sigma\to\sigma\text{ is quasiconformal and represents }\varphi\},\qquad \kappa_T=\inf_{\sigma\in T}K_T(\sigma),\] where $K(f)\geq1$ is maximal quasiconformal dilatation, the essential supremum of the infinitesimal major-to-minor stretching ratio in conformal coordinates. The source reports attainment of the first, fixed-structure minimum by compactness of normalized bounded-dilatation maps. This is distinct from attainment of $\kappa_T$ while varying the structure. The function is used only on components where the class has the required quasiconformal realizations; the source explicitly says it may not be defined on every component.

Following the source's terminology, $\varphi$ is elliptic for $T$ if $K_T$ takes the value $1$, parabolic if $\kappa_T$ is not attained, and hyperbolic if $\kappa_T>1$ is attained. In particular, its definition of parabolic is nonattainment, not an unstated assumption $\kappa_T=1$. A value $1$ means a conformal representative, described in the source as an isometry for the associated conformal structure.

  • (a) If $\kappa_T>1$ is attained, is the minimizing quasiconformal representative unique, and what is its structure? The source moves between minimizers at a fixed structure and minimizers over structures; the intended equivalence under markings, isotopy, and conformal conjugacy must be specified to make uniqueness precise.
  • (b) If the class is parabolic for $T$, must a sequence $\sigma_j\in T$ with $K_T(\sigma_j)\to\kappa_T$ degenerate by pinching a sequence or system of essential simple closed curves? Is the system unique, and can it depend on $T$? Essential here has its usual non-nullhomotopic, nonperipheral meaning. The record supplies no precise metric normalization, degeneration topology, quantifier on varying curves, or equivalence of systems; these are part of the formulation to clarify.
  • (c) If $\varphi$ preserves two distinct components $T,T'$ setwise, can its types differ? In particular, can it be parabolic for $T$ and hyperbolic for $T'$? Preserving a component is different from fixing each of its points.
The background reports contractible components and infinitely many components for infinite-type $S$ [Bas97, BK08]. It distinguishes classes preserving no components, some but not all, or all components. It attributes to Basmajian--Chandran an announced result that the subgroup preserving every component is the compactly supported subgroup, and announced examples quasiconformal on some components but not others. These announced results are retained as such, not independently upgraded. Finite-type Teichmüller uniqueness is background motivation; fixed marked structures and usual scope conventions are needed before comparing it with the global uniqueness question here.

The source also gives a highly reducible non-realizable example on an infinite ladder of twice-punctured tori $T_n$, $n\in{\mathbb{Z}}$, applying $\alpha^n$ on $T_n$ for a fixed pseudo-Anosov class $\alpha$. Its point is unbounded required distortion across the pieces for every structure, so no global quasiconformal representative exists; the stated numerical comparison with $|n|$ times a minimum dilatation should be checked for dilatation versus logarithmic-dilatation conventions. The source asks for a straightforward irreducible example as additional context. It notes a version of this problem in the 2021 Nearly Carbon Neutral Geometric Topology list [CPV21]. The triage checked 2026-08-17 labels the global questions partially solved / PARTIAL-PROGRESS, distinguishing fixed-structure attainment from unresolved componentwise minimizer, degeneration, and type classification; the registry is open.

Short English statement

For an infinite-type mapping class, study the least quasiconformal distortion as the marked conformal structure varies within each preserved Teichmüller component. The source asks about uniqueness of attained minimizers, curve pinching for unattained infima, and different types on different components, while retaining partial results and several convention gaps.
