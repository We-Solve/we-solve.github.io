Math-1154

Embedding Locally Countable Orders into Turing Degrees

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\mathfrak c=2^{\aleph_0}=|\mathcal P({\mathbb{N}})|$. A partial order $(P,\leq_P)$ is a set equipped with a reflexive, antisymmetric, transitive relation. Interpret locally countable to mean that every principal lower set is at most countable: \[ \forall p\in P,\qquad |\{q\in P:q\leq_P p\}|\leq\aleph_0. \] The supplied statement does not explicitly define this term; this lower-set convention requires confirmation against the source.

For $A,B\subseteq{\mathbb{N}}$, write $A\leq_T B$ if an oracle Turing machine with oracle $B$ computes the characteristic function of $A$. Write $A\equiv_T B$ if both $A\leq_T B$ and $B\leq_T A$. The set of Turing degrees is \[ \mathcal D_T=\mathcal P({\mathbb{N}})/{\equiv_T}, \] ordered by $[A]_T\leq_T[B]_T$ if $A\leq_T B$. An order embedding $f:P\to\mathcal D_T$ is an injective map satisfying \[ \forall p,q\in P,\qquad p\leq_P q\ \Longleftrightarrow\ f(p)\leq_T f(q). \]

Question (attributed to Sacks in the supplied curation). Does the following assertion hold in ZFC? \[ \begin{gathered} \text{For every partial order }(P,\leq_P)\text{ with }|P|=\mathfrak c \text{ and }\forall p\in P\; |\{q\in P:q\leq_P p\}|\leq\aleph_0,\\ \text{there exists an order embedding }f:(P,\leq_P)\longrightarrow(\mathcal D_T,\leq_T). \end{gathered} \] No height restriction or additional set-theoretic axiom is imposed in this question. The supplied dated assessment labels the question open in ZFC and reports positive results under the continuum hypothesis, under Martin's axiom, and for restricted heights. These are supplied literature qualifications, not independently verified conclusions; the record does not specify the precise hypotheses or height bounds of those positive results.

Short English statement

Can every partial order of cardinality continuum, in which each element has at most countably many predecessors, be represented by Turing degrees so that the representation preserves and reflects the order? The interpretation of local countability uses lower sets. The supplied curation attributes the question to Sacks and labels it open; this statement-only draft requires human mathematical and source review.
