Math-4344

Quantitative Thin-Set Descriptions of Reducible Specializations

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $f(t,x)\in{\mathbb{Q}}[t,x]$ be irreducible, as in the supplied record. The parameter domain and the treatment of exceptional specializations are not specified there. The following gives a conditional formulation over rational parameters, with these unresolved choices made explicit.

Suppose $n=\deg_x f\geq 1$, and write \[ f(t,x)=\sum_{j=0}^{n}a_j(t)x^j,\qquad a_n(t)\neq 0. \] Define the set of parameters preserving the degree in $x$ by \[ U_f=\{u\in{\mathbb{Q}}:a_n(u)\neq 0\}. \] For these parameters, define \[ \operatorname{Red}^{\mathrm{reg}}_f =\left\{u\in U_f: \begin{array}{l} f(u,x)=g(x)h(x)\text{ for some }g,h\in{\mathbb{Q}}[x],\\ \deg g\geq 1\text{ and }\deg h\geq 1 \end{array}\right\}. \] This definition concerns reducibility over ${\mathbb{Q}}$. It does not determine whether the source's $\operatorname{Red}_f$ includes parameters at which the degree drops or the specialization is zero or constant. The hypothesis $\deg_x f\geq1$ and the rational parameter domain are natural conventions for this formulation, but they are not explicit hypotheses of the supplied statement.

One conventional meaning of a thin-set presentation of a set $S\subseteq{\mathbb{Q}}$ is a finite covering \[ S\subseteq E\cup\bigcup_{i=1}^{r}\varphi_i\left(C_i({\mathbb{Q}})\right), \] where $r\in{\mathbb{Z}}_{\geq0}$, $E\subseteq{\mathbb{Q}}$ is finite, each $C_i$ is an integral algebraic curve over ${\mathbb{Q}}$, and each $\varphi_i:C_i\to\mathbb A^1_{{\mathbb{Q}}}$ is a dominant generically finite morphism defined over ${\mathbb{Q}}$, with \[ d_i=\deg\varphi_i=[{\mathbb{Q}}(C_i):{\mathbb{Q}}(t)]\geq2. \] The source does not specify whether this class of maps is intended, whether the curves must be rational, or whether the displayed containment must instead be equality, possibly outside a finite exceptional set. These alternatives must be resolved before a unique quantitative problem is obtained.

For a specified specialization set $S\subseteq{\mathbb{Q}}$, define its symmetric integer counting function by \[ N_S(B)=\#\{u\in S\cap{\mathbb{Z}}:|u|\leq B\},\qquad B\in{\mathbb{R}},\ B\geq1. \] Problem, conditional on the conventions above. For a given irreducible $f$, determine how many maps $\varphi_i$ are required to describe its reducible-specialization set, which degree lists $(d_1,\ldots,d_r)$ are required or possible, and how such presentation data constrain the growth of $N_{\operatorname{Red}_f}(B)$ as $B\to\infty$. The supplied background also identifies the finiteness of $\operatorname{Red}_f\cap{\mathbb{Z}}$ as part of the unresolved inquiry. The source gives no proposed bound, asymptotic formula, criterion for finiteness, or specified dependence on invariants of $f$. It also does not specify whether the number of maps is to be minimized; arbitrary presentations have no intrinsic number of components.

Short English statement

For an irreducible polynomial over ${\mathbb{Q}}$, describe the rational parameters giving reducible specializations by finitely many value maps, and relate the number and degrees of those maps to the growth and possible finiteness of the integer specialization set. The parameter domain, exceptional specializations, permitted maps, and precise meaning of a presentation remain unspecified in the source. This is a statement-only draft requiring mathematical review.
