The Lyapin's Notebook — Problem 7

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

A semigroup is a nonempty set with an associative binary operation. A semigroup variety is a class of semigroups defined by identities. For a class $\mathcal G$ of semigroups, let $\operatorname{Var}(\mathcal G)$ denote the smallest semigroup variety containing $\mathcal G$. A semigroup $S$ is regular if \[ \forall a\in S\;\exists b\in S\qquad aba=a. \] A semigroup is periodic if every element generates a finite cyclic subsemigroup; equivalently, \[ \forall a\in S\;\exists m,n\in{\mathbb{N}}\qquad 1\leq m<n\quad\text{and}\quad a^m=a^n. \] A variety is periodic if every semigroup belonging to it is periodic.

Problem (S. Kublanovsky). Characterize the periodic semigroup varieties $\mathcal V$ for which there exists a class $\mathcal G$ of regular semigroups such that \[ \mathcal V=\operatorname{Var}(\mathcal G). \] The requirement concerns the generating semigroups; it does not assert that every member of $\mathcal V$ is regular. The source does not specify a required form of the characterization.

The supplied source states that the corresponding description for periodic varieties generated by completely $0$-simple semigroups was obtained in reference [Kubl4]. Here a semigroup $S$ with zero is completely $0$-simple if $S\neq\{0\}$, $S^2\neq\{0\}$, its only ideals are $\{0\}$ and $S$, and it contains a primitive nonzero idempotent. A nonzero idempotent $e$ is primitive if every nonzero idempotent $f$ satisfying $ef=fe=f$ equals $e$. The bibliographic entry for [Kubl4] is absent from the supplied record, so this background attribution remains unverified.

Short English statement

Describe exactly which periodic varieties of semigroups can be generated by regular semigroups. The source attributes the problem to S. Kublanovsky and reports an existing description for the special case of completely $0$-simple generators, citing [Kubl4] without supplying its bibliographic entry.
