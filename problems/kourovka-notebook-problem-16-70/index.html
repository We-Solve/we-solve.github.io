Kourovka Notebook Problem 16.70

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $A$ be an ordered abelian group, with a translation-invariant total order. An $A$-tree is a nonempty $A$-valued metric space in which each pair of points is joined by a unique geodesic segment isometric to an interval in $A$, and every geodesic triangle is a tripod. An action on such a tree is understood to be by isometries. We use the standard convention that a free action has trivial point stabilizers and has no inversions: no group element interchanges the endpoints of a nondegenerate segment that it preserves.

For $n\geq 1$, equip ${\mathbb{Z}}^n$ with lexicographic order: for distinct vectors $u,v$, one has $u<v$ if the first nonzero coordinate of $v-u$ is positive. The supplied record does not explicitly specify the order on ${\mathbb{Z}}^n$, or its convention concerning inversions; the formulation below uses these standard conventions and requires confirmation against the source.

Question. For every ordered abelian group $A$ and every finitely generated group $G$, does the following implication hold? \[ \begin{gathered} G\text{ admits a free isometric action on an }A\text{-tree} \\[2pt] \Longrightarrow \\[2pt] \exists n\in{\mathbb{Z}}_{\geq 1}\quad G\text{ admits a free isometric action on a lexicographically ordered }{\mathbb{Z}}^n\text{-tree}. \end{gathered} \] The integer $n$ is not required to be uniform over the groups in the question.

Supplied 2013 qualification. The record reports that every finitely presented group acting freely on an $A$-tree acts freely on an ${\mathbb{R}}^n$-tree for some suitable $n$, citing O. Kharlampovich, A. Myasnikov, and D. Serbin. Its accompanying order description literally refers to ${\mathbb{R}}$ as having lexicographic order; the likely intended reference is lexicographic order on ${\mathbb{R}}^n$, but that wording requires source confirmation. This reported result concerns finitely presented groups and an ${\mathbb{R}}^n$-tree target, whereas the question concerns finitely generated groups and a ${\mathbb{Z}}^n$-tree target. The report is supplied background, not an independently verified theorem or resolution of the question.

Short English statement

Must every finitely generated group that acts freely on a tree with distances in some ordered abelian group also act freely on a tree with distances in lexicographically ordered ${\mathbb{Z}}^n$, for some positive integer $n$? The supplied record labels the problem open. Its 2013 comment reports a related result for finitely presented groups with an ${\mathbb{R}}^n$-tree target; that report and the order conventions require source review.
