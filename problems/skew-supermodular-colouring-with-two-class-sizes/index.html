Math-5567

Skew-supermodular colouring with two class sizes

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $S$ be finite. In the standard all-pairs convention an integer-valued set function $p:2^S\to\mathbb Z$ is skew-supermodular when, for every $X,Z\subseteq S$, \[ p(X)+p(Z)\leq\max\{p(X\cap Z)+p(X\cup Z),\ p(X\setminus Z)+p(Z\setminus X)\}. \] The source does not give its convention, so any restriction to crossing or positive-demand pairs must be checked rather than silently substituted.

Decision problem. Given two integer skew-supermodular functions $p_1,p_2$ satisfying \[ \max\{p_1(X),p_2(X)\}\leq\min\{|X|,k\}\qquad(X\subseteq S), \] and positive integers $m_1,m_2,n_1,n_2$ with $m_1n_1+m_2n_2=|S|$, decide whether there is a partition $\mathcal P$ of $S$ having $m_1$ classes of size $n_1$ and $m_2$ classes of size $n_2$, such that \[ \big|\{Y\in\mathcal P:Y\cap X\ne\varnothing\}\big| \geq\max\{p_1(X),p_2(X)\}\qquad(X\subseteq S). \] Can this decision be made in polynomial time? A partition has pairwise disjoint nonempty classes whose union is $S$; if $n_1=n_2$, the requirement is simply $m_1+m_2$ classes of that size, since the source does not require distinct sizes.

The source uses $k$ without defining it or explicitly identifying it with $m_1+m_2$. It may be treated as an additional parameter pending that clarification. More importantly, polynomial time requires an input model for the set functions: explicit tables and value-oracle access have very different sizes and complexity measures. Neither is supplied. The summary reports no published polynomial algorithm or characterization found for the two-size variant; this is a search assessment, not a hardness result.

Short English statement

Decide whether two skew-supermodular demands can be met by a partition with prescribed counts of two class sizes. The exact function-access model and the parameter $k$ need clarification before polynomial time has a definite meaning.
