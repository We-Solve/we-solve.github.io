Several Complex Variables Problem List — Problem 24

Statement

Definitions and mathematical statement

Let $D\subset{\mathbb{C}}^n$ be a domain, meaning a connected open set. Under the usual $C^2$-boundary convention, strong pseudoconvexity means that near each boundary point there is a real-valued defining function $\rho$, with $D=\{\rho<0\}$ locally and ${\,\mathrm{d}}\rho\ne0$ on the boundary, such that \[ \sum_{j,k=1}^{n}\frac{\partial^2\rho}{\partial z_j\partial\overline z_k}(q)v_j\overline v_k>0 \] for every boundary point $q$ in that neighborhood and every nonzero complex tangent vector $v$ satisfying $\sum_{j=1}^{n}\frac{\partial\rho}{\partial z_j}(q)v_j=0$. This explains a standard convention; the supplied source does not specify boundary regularity or boundedness.

For a holomorphic function $f$ on $D$, define its underlying zero set by \[ Z_D(f)=\{z\in D:f(z)=0\}. \] Write $H^p(D)$ for the holomorphic Hardy space on $D$, once the exponent $p$ and the boundary norm convention have been fixed. For such fixed choices, define \[ \mathcal Z_p(D)=\left\{Z_D(f): f\in H^p(D),\ f\not\equiv0\right\}. \] Problem. Give necessary and sufficient geometric conditions on a subset $E\subset D$ for \[ E\in\mathcal Z_p(D), \] when $D$ is strongly pseudoconvex.

This is a formulation of the request using underlying zero sets of nonzero functions. The supplied statement does not specify the exponent or range of exponents, ambient dimension, boundedness, boundary regularity, Hardy-space convention, or whether zero multiplicities must be retained. If zero divisors are intended, the target must instead retain the vanishing multiplicities along their components. The exclusion of the identically zero function is also a convention requiring confirmation. Consequently, the displayed formulation leaves these source qualifications unresolved.

Short English statement

Characterize geometrically which sets in a strongly pseudoconvex domain occur as zero sets of holomorphic Hardy-space functions. The supplied statement leaves the exponent, domain hypotheses, Hardy-space convention, and treatment of multiplicities unspecified.
