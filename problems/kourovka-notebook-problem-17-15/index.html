Math-13802

Kourovka Notebook Problem 17.15

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $R_n={\mathbb{Z}}[x_1,\ldots,x_n]$ be the polynomial ring in the finitely many indeterminates appearing in the input specification. Under the interpretation that $\operatorname{Aut}(R_n)$ denotes the group of unital ring automorphisms, these automorphisms fix ${\mathbb{Z}}$ pointwise. For $f\in R_n$, define its stabilizer by \[ G_f=\{\sigma\in\operatorname{Aut}(R_n):\sigma(f)=f\}. \] This is the unique largest subgroup all of whose elements fix $f$. Here the source's phrase "maximal subgroup" is interpreted in this sense; it does not impose the additional condition that $G_f$ be a maximal proper subgroup of $\operatorname{Aut}(R_n)$.

Requested algorithm. Construct an algorithm which, given $f\in{\mathbb{Z}}[x_1,\ldots,x_n]$, terminates and explicitly describes generators $S_f\subseteq\operatorname{Aut}(R_n)$ such that \[ \langle S_f\rangle=G_f. \] An explicit individual generator can be specified by its polynomial images of $x_1,\ldots,x_n$. The source does not specify whether the required output is a finite list of generators or whether an effectively described infinite generating family is permitted. Consequently, the required representation of $S_f$, and hence the precise algorithmic output requirement, remains unresolved.

The source relates this question to describing the integer solution set \[ V_{{\mathbb{Z}}}(f)=\{(a_1,\ldots,a_n)\in{\mathbb{Z}}^n:f(a_1,\ldots,a_n)=0\}. \] It does not state a separate requirement that the algorithm describe this solution set.

Short English statement

Given an integer polynomial, find explicit generators for the group of polynomial ring automorphisms that fix it. The source leaves unclear whether finitely many generators must be returned or an effective description of an infinite family is allowed. The supplied registry labels the problem open; that label has not been independently verified.
