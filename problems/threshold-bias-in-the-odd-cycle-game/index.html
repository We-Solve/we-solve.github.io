Math-7139

Threshold Bias in the Odd-Cycle Game

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For each integer $n\geq 3$, let $K_n$ be the complete simple graph on vertex set $\{1,\ldots,n\}$. An odd cycle is a simple cycle of length $2k+1$, where $k\geq 1$. Define the family of winning edge sets by \[ OC_n=\left\{A\subseteq E(K_n): A\text{ contains every edge of some odd cycle}\right\}. \] In a biased Maker--Breaker odd-cycle game, Maker and Breaker claim previously unclaimed edges of $K_n$; Maker wins by obtaining an edge set in $OC_n$, and Breaker wins if Maker never does so.

The supplied record does not specify the move order, the treatment of an incomplete final move, or the exact threshold convention. An explicit conventional interpretation is the following: Maker moves first and claims one edge per turn; Breaker then claims $b$ edges per turn, or all remaining edges if fewer than $b$ remain. For this interpretation, allow $b\in{\mathbb{Z}}_{\geq 0}$, with $b=0$ an auxiliary convention under which Breaker claims no edges, and define \[ b_{\mathrm{MB}}(OC_n)=\max\left\{b\in{\mathbb{Z}}_{\geq 0}:\text{Maker has a strategy guaranteeing an odd cycle}\right\}. \] These conventions require confirmation against the cited source; they are not explicitly supplied by the registry record.

With $b_{\mathrm{MB}}(OC_n)$ understood as the intended source threshold, the question is whether \[ b_{\mathrm{MB}}(OC_n)=\left(\frac12+o(1)\right)n \qquad\text{as }n\to\infty. \] Equivalently, is it true that for every real $\varepsilon>0$ there exists an integer $N\geq 3$ such that every integer $n\geq N$ satisfies \[ \left|\frac{b_{\mathrm{MB}}(OC_n)}{n}-\frac12\right|<\varepsilon? \] The record labels this problem open; that label is supplied curation rather than an independently verified assertion.

Short English statement

Maker tries to claim all edges of an odd cycle in the complete graph, while Breaker claims $b$ edges for each edge claimed by Maker. The question asks whether the largest bias allowing Maker a guaranteed win is asymptotic to $n/2$. The source's precise play and threshold conventions require confirmation.
