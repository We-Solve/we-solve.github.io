Simultaneous Exact Tests for Contingency Tables

Status Open · unsolvedmath.comLLM status Open unverified

Definitions and mathematical statement

A contingency table with two rows and $c$ columns is an array $N=(N_{ij})_{1\leq i\leq 2,\,1\leq j\leq c}$ of nonnegative integer cell counts. The supplied question emphasizes $c=2$ and $c=3$, without restricting attention to those sizes. Simultaneous testing refers here to analyzing a collection of such tables and making multiple testing decisions; the record does not specify the collection, its sampling law, or the hypotheses to be tested.

The retained source question is: How can many contingency tables, especially $2$ by $2$ and $2$ by $3$ tables, be analyzed simultaneously using exact tests and suitable multiple-testing methods?

Short English statement

The record asks how to combine exact tests for many contingency tables, particularly $2\times2$ and $2\times3$ tables, with multiple-testing methods. Its supplied curation identifies this as a description of methods rather than a definite open conjecture. The testing model and intended guarantee remain unspecified.
