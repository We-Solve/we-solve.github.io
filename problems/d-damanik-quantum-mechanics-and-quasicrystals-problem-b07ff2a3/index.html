D. Damanik: Quantum Mechanics and Quasicrystals — Problem

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $(V,E)$ be the graph associated with a Penrose tiling, with undirected nearest-neighbor edges and counting measure on $V$. Write \[ \ell^2(V)=\left\{\psi:V\to\mathbb C:\sum_{v\in V}|\psi(v)|^2<\infty\right\}. \] Define the graph operator \[ (H\psi)(v)=\sum_{w:\{v,w\}\in E}(\psi(w)-\psi(v)). \] The graph has uniformly bounded degree, so this is a bounded self-adjoint operator on all of $\ell^2(V)$. Its sign convention is adjacency minus degree, the negative of the nonnegative combinatorial Laplacian.

Determine its spectrum \[ \sigma(H)=\{\lambda\in\mathbb C:H-\lambda I\text{ has no bounded inverse on }\ell^2(V)\}. \] The spectrum is real by self-adjointness; no candidate spectral set is supplied. The graph convention needs to be fixed: using tiling vertices joined by tile sides is a usual interpretation, but different Penrose graph models need not define the same operator.

The supplied summary reports infinitely many finitely supported eigenfunctions and corresponding integrated-density-of-states jumps for Penrose graph models, citing arXiv:2209.01443, while leaving a complete spectral description unresolved. Infinitely many such eigenfunctions does not itself assert infinitely many distinct eigenvalues. The summary also mentions four mutually-locally-derivable Penrose graph models and the Ammann--Beenker setting; those are related models, not silently identified with the one operator in this question.

Short English statement

Determine the spectrum of the Penrose-tiling graph operator that sums neighboring value differences. Preserve its negative-Laplacian sign convention and distinguish the intended graph from related tiling models.
