Math-4659

Wandering Domains, Hyperbolicity, and Thurston Algorithms

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a transcendental entire map $f$, its Fatou set is the normality locus of the iterates. A wandering domain is a Fatou component whose successive forward Fatou components are distinct. Limit functions of $\{f^n|_U\}$ mean subsequential locally uniform limits in the intended, usually spherical, topology. The postsingular set is conventionally \[ P(f)=\overline{\bigcup_{m\geq0}f^m(S(f))}, \] where $S(f)$ is the closed set of finite critical and asymptotic values. Nonrecurrence of a critical point ordinarily means that it does not belong to the omega-limit set of its forward orbit; the source's full nonrecurrence hypotheses are not supplied.

The record bundles these questions:

  1. If $f$ has a wandering domain $U$, can its limit functions there be bounded? It is unspecified whether bounded means individually bounded, finite rather than infinite, or uniformly bounded as a collection.
  2. If $P(f)$ is bounded, can $f$ have wandering domains? Ask also for the stated variant in which all critical points are nonrecurrent; no assumption excluding asymptotic values is added.
  3. For $f_{\lambda,k}(z)=\lambda z e^z+k$, with $\lambda=e^{2\pi i\theta}$ and the required nonrecurrence assumptions, can $f_{\lambda,k}$ have a Siegel disk, that is, a maximal domain on which an iterate is conformally an irrational rotation? The assumptions are referred to but not actually stated, and the parameter ranges are incomplete.
  4. Is the complement of the hyperbolicity locus precompact in $\operatorname{Rat}_d$ modulo Möbius conjugacy? Here $\operatorname{Rat}_d$ denotes degree-$d$ rational maps; under the usual degree-$d\geq2$ convention hyperbolicity means that every critical orbit converges to an attracting cycle. Precompactness asks for compact closure in the intended moduli space, not automatically in an added compactification.
  5. For $f_\lambda(z)=\lambda e^z$, characterize parameters for which the nonescaping set is connected, and separately those for which that set together with $\{\infty\}$ is connected. Under the usual convention the escaping set is $I(f)=\{z:|f^m(z)|\to\infty\}$, and nonescaping is its complement, not necessarily the bounded-orbit set. The second topology is that of the Riemann sphere.
  6. Can Thurston's algorithm be implemented in \[ O\left((\deg(f)+|\Omega_f|)^n\right) \] iterations, producing either a point sufficiently close to a fixed point of the pullback map or a Thurston obstruction? The input class, $\Omega_f$, exponent parameter $n$, closeness tolerance, metric, and meaning of algorithmic cost are unspecified. The printed iteration bound is retained without replacing it by a newly chosen complexity model.
The bundle is not one fully defined proposition; each clause retains its own missing hypotheses.

Short English statement

The source groups questions about wandering domains, bounded postsingular sets, Siegel disks in an explicit entire family, rational-map moduli, exponential connectivity and the complexity of Thurston's algorithm. Every clause is retained with its source-specific gaps.
