A finite-domain witness-encryption table, and its size obstruction

The report's witness-PRF must evaluate publicly with a valid witness while keeping its value pseudorandom at false instances even given its public evaluation key and permitted function queries. Its known construction uses multilinear maps; the requested generic witness-encryption implication is broader. We test an exhaustive-table construction under ordinary witness-encryption correctness and false-instance message indistinguishability. Let $X$ be an explicitly listed domain of size $D$ polynomial in the security parameter, let $R(x,w)$ be the witness relation, and choose independent uniform $\ell$-bit strings $r_x$. Store their table in a secret key. Define $F(x)=r_x$ and publish $c_x=\operatorname{WE.Enc}(x,r_x)$ for every $x\in X$. On input $(x,w)$, first verify $R(x,w)$, returning $\bot$ if invalid; otherwise decrypt $c_x$ with $w$.
Proposition: This construction has witness-evaluation correctness. For a fixed false challenge instance $x_*\in X$, its value is computationally indistinguishable from an independent uniform string, even with the public table and adaptive value queries at points other than $x_*$, assuming false-instance security of witness encryption. This is a selective, single-challenge assertion.
Proof: On a valid witness, witness-encryption correctness returns $r_x=F(x)$; invalid witnesses are rejected explicitly. For security, choose independent uniform strings $u,v$ and submit them as the two messages in a witness-encryption challenge for the fixed false instance $x_*$. Insert the challenge ciphertext as $c_{x_*}$, generate every other table entry honestly, and give $u$ as the function-value challenge. Queries at other points can be answered from their stored strings. If the ciphertext encrypts $u$, the joint distribution is exactly that of the true function value at $x_*$. If it encrypts $v$, the public table encrypts an independent uniform true value while the announced challenge $u$ is independent uniform. All other table entries and query answers agree in distribution. Thus any distinguisher for these two experiments gives one with the same advantage against witness encryption. The simulation is polynomial because $D$ is polynomial and all other operations are efficient by the primitive's hypotheses. ∎

Verification and remaining gaps

The independent-message hybrid was checked by enumerating all 16 ordered pairs of two-bit strings, including collisions. Table storage for the full $n$-bit domain has at least $2^n\ell$ secret bits, and that growth was evaluated for several $n$. The failed step in extending this construction is not correctness but efficiency: enumerating the entire ordinary domain $\{0,1\}^n$ is exponential in $n$. The proof also supplies only the stated selective single-point security game, not a proof for an unrestricted adaptively chosen challenge. No compression of the table, generic full-domain implication, or weaker-assumption witness-PRF construction is established. The 2014 primary construction is attributed, not independently reproduced.
