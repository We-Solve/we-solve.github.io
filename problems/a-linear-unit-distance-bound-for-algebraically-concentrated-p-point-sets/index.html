Math-1377

A linear unit-distance bound for algebraically concentrated p-point sets

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $p$ be prime and, for $z=(z_1,z_2)\in{\mathbb{F}}_p^2$, write $Q(z)=z_1^2+z_2^2$. For $S\subset{\mathbb{F}}_p^2$ with $|S|=p$, define the ordered unit-pair count \[ U(S)=|\{(u,v)\in S^2:Q(u-v)=1\}|. \] T. Tao's source problem asks for the largest possible $U(S)$. This notation resolves the extracted coordinate ambiguity without treating a quadratic form over a finite field as a positive real metric. Self-pairs never contribute; unordered pair counts are half the ordered count. The original remark gives an upper bound of order $p^{3/2}$ and a lower example of order $p$; constants and pair convention are not specified, so these are retained as asymptotic orders.

The supplied aid's structural theorem assumes $p$ odd. If $S$ is contained in a geometrically irreducible plane curve $C$, defined over ${\mathbb{F}}_p$, of degree $d\ge1$, it reports \[ U(S)\le2dp, \] or at most $dp$ unordered unit pairs. The stated input is a uniform Bézout intersection argument with unit circles. Geometric irreducibility is a hypothesis, not merely irreducibility over ${\mathbb{F}}_p$. Consequently a family with $U(S)/p\to\infty$ cannot be contained in geometrically irreducible curves of any uniformly bounded degree. This is not an improved bound for arbitrary sets or all reducible algebraic supports.

For a full affine line $S=a+{\mathbb{F}}_pv$, $v\ne0$, the aid reports the exact classification \[ U(S)=\begin{cases} 2p,&Q(v)\text{ is a nonzero square in }{\mathbb{F}}_p,\\ 0,&Q(v)=0\text{ or is a nonsquare}. \end{cases} \] The line contains exactly $p$ points, so this is a sharp instance of the degree-one structural bound.

For the ambient unit-distance graph on ${\mathbb{F}}_p^2$, let $\chi$ be the quadratic character with $\chi(0)=0$. The aid reports degree $p-\chi(-1)$. For distinct vertices $u,v$, set $t=Q(u-v)$. Their number of common unit neighbors is reported as \[ \begin{cases} 0,&t=0,\\ 1+\chi(t(4-t)),&t\ne0. \end{cases} \] The $t=0$ case includes distinct isotropically separated vertices when such vectors exist. These formulas and the algebraic-support theorem use odd characteristic; the source does not exclude $p=2$, which remains outside the aid's stated partial results. The aid explicitly does not improve the $O(p^{3/2})$ general bound.

Short English statement

The source asks for the maximum number of unit-distance pairs among $p$ points in ${\mathbb{F}}_p^2$. The supplied aid gives exact line and common-neighbor formulas and a linear bound for points on a geometrically irreducible bounded-degree curve, while leaving arbitrary configurations unresolved.
