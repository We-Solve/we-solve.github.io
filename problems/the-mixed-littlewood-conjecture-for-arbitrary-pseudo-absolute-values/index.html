The Mixed Littlewood Conjecture for Arbitrary Pseudo-Absolute Values

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

The supplied record calls this the mixed Littlewood conjecture for arbitrary pseudo-absolute values. Its formula requires conventions that are not explicit in the record: the entries of the sequence must have a specified domain, the range of the limiting variable must be specified, and the defining minimum needs an initial product. The following precise formulation uses the intended-looking integer interpretation; these conventions require mathematical review against the cited source.

Let $D=(d_i)_{i\geq 1}$ be any sequence of integers with $d_i\geq 2$. Set \[ D_0=1,\qquad D_n=\prod_{i=1}^{n}d_i\quad(n\geq 1). \] For each nonzero integer $a$, define \[ |a|_D=\min\{D_n^{-1}:n\in{\mathbb{Z}}_{\geq 0},\ a\in D_n{\mathbb{Z}}\}. \] This minimum exists because the set of eligible indices contains $0$ and is finite. For $t\in{\mathbb{R}}$, write \[ \|t\|=\min_{m\in{\mathbb{Z}}}|t-m| \] for the distance to the nearest integer.

Under these explicitly stated conventions, the question is whether, for every such sequence $D$ and every $x\in{\mathbb{R}}$, \[ \liminf_{\substack{q\to\infty\\q\in{\mathbb{Z}}_{\geq 1}}}q\,|q|_D\,\|qx\|=0. \] Equivalently, is it true that for every such $D$, every $x\in{\mathbb{R}}$, every $\varepsilon>0$, and every integer $Q\geq 1$, there exists an integer $q\geq Q$ satisfying \[ q\,|q|_D\,\|qx\|<\varepsilon? \] No boundedness assumption on the sequence $(d_i)$ is imposed. The supplied definition does not give a minimum at $a=0$; no value there is needed for this formulation. The integer domain, the convention $D_0=1$, and the positive-integer range of $q$ are explicit interpretive additions, not verified quotations from the source.

Short English statement

Under the explicitly stated integer and indexing conventions, the conjecture asks whether every real number admits arbitrarily large positive integers $q$ for which the product of $q$, its $D$-pseudo-absolute value, and the distance of $qx$ to the nearest integer is arbitrarily small. The source labels the problem open; that label and the formulation require independent review.
