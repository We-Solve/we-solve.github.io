Bárány–Larman Colored Tverberg Conjecture

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Fix integers $d\geq 1$ and $r\geq 2$. For a positive integer $n$, let $\Delta^{n-1}$ be the simplex with vertex set $V$, where $|V|=n$. A coloring is a partition \[ V=C_1\sqcup\cdots\sqcup C_{d+1}. \] A nonempty face $\sigma$ is rainbow if its vertex set contains at most one vertex from each $C_i$. Faces are pairwise disjoint when their vertex sets are pairwise disjoint. The required intersection property is the existence of nonempty, pairwise disjoint rainbow faces $\sigma_1,\ldots,\sigma_r$ such that \[ \bigcap_{j=1}^{r}f(\sigma_j)\neq\varnothing. \] Here $f:\Delta^{n-1}\to{\mathbb{R}}^d$ is affine; no general-position or injectivity assumption is supplied.

For $n\geq(d+1)r$, let $P_{d,r}(n)$ mean that for every partition of $V$ into $d+1$ color classes satisfying $|C_i|\geq r$ for every $i$, and every affine map $f:\Delta^{n-1}\to{\mathbb{R}}^d$, the required intersection property holds. Define the feasible version of the supplied minimum by \[ n_{\mathrm{feas}}(d,r)=\min\{n\in{\mathbb{Z}}:n\geq(d+1)r\text{ and }P_{d,r}(n)\}, \] provided this set is nonempty. The first requested determination is this minimum, with conjectured value \[ n_{\mathrm{feas}}(d,r)=(d+1)r. \] Unresolved qualification: the source writes $n(d,r)$ without explicitly restricting the minimum to feasible values of $n$. For $n<(d+1)r$, no prescribed partition exists, so the literal universal assertion is vacuous. The notation $n_{\mathrm{feas}}$ makes this qualification explicit rather than silently identifying it with the source's undefined minimum.

For a positive integer $t$, let $Q_{d,r}(t)$ mean that for every partition of the vertices of $\Delta^{(d+1)t-1}$ into exactly $d+1$ color classes of size $t$, and every affine map \[ f:\Delta^{(d+1)t-1}\to{\mathbb{R}}^d, \] the required intersection property holds. Define \[ t(d,r)=\min\{t\in{\mathbb{Z}}:t\geq1\text{ and }Q_{d,r}(t)\}, \] provided this set is nonempty. The alternative requested determination is $t(d,r)$, with conjectured value \[ t(d,r)=r. \] The supplied record calls this equivalent to the Bárány--Larman equality. At the proposed minimum $n=(d+1)r$, the condition $|C_i|\geq r$ forces every color class to have size exactly $r$, so the two proposed assertions have the same intersection requirement there. The feasibility qualification for the first minimum remains necessary.

Short English statement

For every $d\geq1$ and $r\geq2$, determine the smallest feasible number of colored vertices that guarantees $r$ vertex-disjoint rainbow faces with intersecting affine images in ${\mathbb{R}}^d$. The proposed value is $(d+1)r$. With exactly $d+1$ equally sized color classes, determine the smallest class size; the proposed value is $r$. The source's first minimum requires an explicit feasibility restriction to avoid vacuous cases.
