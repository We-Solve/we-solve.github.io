Math-3891

Algebraicity of Labelled Well-Quasi-Ordered Permutation Classes

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For each integer $n\geq 0$, let $S_n$ be the set of permutations of $\{1,\ldots,n\}$, with $S_0$ consisting of the empty permutation. For $\sigma\in S_k$ and $\pi\in S_n$, write $\sigma\leq\pi$ if there are indices $1\leq i_1<\cdots<i_k\leq n$ such that, for all $a,b\in\{1,\ldots,k\}$, \[ \sigma(a)<\sigma(b)\quad\Longleftrightarrow\quad\pi(i_a)<\pi(i_b). \] A permutation class is a subset $\mathcal C\subseteq\bigcup_{n\geq0}S_n$ closed downward under this containment relation.

A quasi-order $(L,\preceq_L)$ is well-quasi-ordered if every infinite sequence $\ell_1,\ell_2,\ldots$ in $L$ has indices $r<s$ with $\ell_r\preceq_L\ell_s$. An $L$-labelled permutation is a pair $(\pi,\lambda)$, where $\pi\in S_n$ and $\lambda:\{1,\ldots,n\}\to L$. Define \[ (\sigma,\mu)\leq_L(\pi,\lambda) \] if there is a pattern-containment embedding $i_1<\cdots<i_k$ as above such that $\mu(a)\preceq_L\lambda(i_a)$ for every $1\leq a\leq k$. Call $\mathcal C$ labelled well-quasi-ordered if, for every well-quasi-ordered label quasi-order $L$, the collection of all $L$-labelled permutations whose underlying permutations belong to $\mathcal C$ is well-quasi-ordered under $\leq_L$.

For a permutation class $\mathcal C$, define its ordinary generating function by \[ F_{\mathcal C}(x)=\sum_{n\geq0}|\mathcal C\cap S_n|x^n\in{\mathbb{Q}}[[x]]. \] Here the coefficients count underlying permutations, without additional labels. Say that this generating function is algebraic if there exists a nonzero polynomial $P(X,Y)\in{\mathbb{Q}}[X,Y]$ such that $P(x,F_{\mathcal C}(x))=0$ as a formal power series.

Question. Is it true that, for every permutation class $\mathcal C$, \[ \mathcal C\text{ is labelled well-quasi-ordered} \quad\Longrightarrow\quad \exists\,0\neq P(X,Y)\in{\mathbb{Q}}[X,Y]\text{ with }P(x,F_{\mathcal C}(x))=0? \]

The supplied excerpt does not explicitly define labelled well-quasi-ordering or specify the generating-function convention; the formulation above uses the standard interpretation with every well-quasi-ordered label quasi-order and ordinary enumeration by permutation length. Including or excluding the empty permutation changes the series only by a constant and does not change its algebraicity. The excerpt presents this question as a possible rescue of one direction of its "False Conjecture 1" by strengthening the hypothesis to labelled well-quasi-ordering, and attributes the question to Brignall and Vatter, reference [7] in the report. The text of that conjecture and the full reference [7] are not supplied here.

Short English statement

Does every permutation class that remains well-quasi-ordered when its entries receive labels from any well-quasi-ordered set have an algebraic ordinary generating function counting its underlying permutations by length? The supplied record labels this question open; this draft does not independently verify that status.
