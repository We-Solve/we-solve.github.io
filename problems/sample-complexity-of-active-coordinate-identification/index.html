Sample Complexity of Active Coordinate Identification

Definitions and mathematical statement

Shared notation.
Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.

An active coordinate is a variable on which the target function depends. Nonadaptive sampling chooses all observation points before seeing any observed function values.

In recovering an approximately low-dimensional function of $N$ variables from samples, how many non-adaptive sample points are required to identify the active coordinates? [S2]

Determine the sample count needed to identify variables used by an approximately low-dimensional function.
