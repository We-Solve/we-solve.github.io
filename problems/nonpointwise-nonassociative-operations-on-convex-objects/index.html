Nonpointwise, Nonassociative Operations on Convex Objects

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A subset $K$ of a real vector space $V$ is convex if $(1-t)x+ty\in K$ for all $x,y\in K$ and $t\in[0,1]$. A real-valued function $f:D\to{\mathbb{R}}$ on a convex domain $D\subseteq V$ is convex if \[ f((1-t)x+ty)\leq (1-t)f(x)+tf(y) \qquad(x,y\in D,\ t\in[0,1]). \] These definitions provide terminology; the source does not specify an ambient space, a domain, or whether functions must be real-valued rather than extended-real-valued.

If binary operations on a class $\mathcal X$ are intended, such an operation is a map $\star:\mathcal X\times\mathcal X\to\mathcal X$. It is associative if \[ (A\star B)\star C=A\star(B\star C) \qquad\text{for all }A,B,C\in\mathcal X. \] For a class $\mathcal F$ of real-valued functions on a common domain $D$, one possible meaning of a pointwise operation is that there exists a single map $\Phi:{\mathbb{R}}^2\to{\mathbb{R}}$ such that \[ (f\star g)(x)=\Phi(f(x),g(x)) \qquad\text{for all }f,g\in\mathcal F\text{ and }x\in D. \] This is a conditional interpretation, not a definition supplied by the record. In particular, the record does not define pointwise operations on convex sets or specify a representation through which that term should be interpreted.

Source problem. Find classification results for operations on convex functions or convex sets that are neither necessarily pointwise nor associative.

Short English statement

The problem asks for classification results about operations on convex functions or convex sets without necessarily assuming pointwise behavior or associativity.
