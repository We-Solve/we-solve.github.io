Math-6815

Generating-Function Field for Separable Permutation Subclasses

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For each integer $n\geq 0$, let $S_n$ be the set of permutations of $\{1,\ldots,n\}$, with $S_0$ consisting of the empty permutation. A permutation $\sigma\in S_k$ is a pattern of $\pi\in S_n$ if there exist indices $1\leq i_1<\cdots<i_k\leq n$ such that $\pi(i_a)<\pi(i_b)$ if and only if $\sigma(a)<\sigma(b)$ for all $a,b$. A permutation avoids $\sigma$ if it does not contain this pattern. For a set $B$ of permutations, write $\operatorname{Av}(B)$ for the set of finite permutations avoiding every member of $B$.

A permutation class is a set of finite permutations closed under taking patterns. Define the class of separable permutations by \[ \operatorname{Sep}=\operatorname{Av}(2413,3142). \] A proper subclass means a permutation class $\mathcal C\subsetneq\operatorname{Sep}$. Its ordinary generating function, counted by permutation length, is \[ F_{\mathcal C}(z)=\sum_{n\geq0}|\mathcal C\cap S_n|z^n\in{\mathbb{Q}}[[z]]. \] Let $u,v\in{\mathbb{Q}}[[z]]$ be the unique series satisfying \[ u^2=1-4z,\qquad v^2=1-6z+5z^2,\qquad u(0)=v(0)=1, \] and regard $K={\mathbb{Q}}(z,u,v)$ as a subfield of the formal Laurent series field ${\mathbb{Q}}((z))$.

Question. Is it true that \[ \forall\,\mathcal C\subsetneq\operatorname{Sep}\text{ that is a permutation class},\qquad F_{\mathcal C}(z)\in{\mathbb{Q}}\!\left(z,\sqrt{1-4z},\sqrt{1-6z+5z^2}\right)=K? \] Equivalently, does every such generating function admit a rational expression in $z,u,v$ with rational coefficients?

The supplied excerpt gives the contextual example \[ \mathcal D=\operatorname{Av}(2143,2413,3142),\qquad F_{\mathcal D}(z)=\frac{2}{1+z+\sqrt{1-6z+5z^2}}, \] and identifies its enumeration with OEIS sequence A033321. The supplied dated assessment describes this example as refuting the smaller field ${\mathbb{Q}}(z,\sqrt{1-4z})$, while leaving the displayed two-radical question unresolved. These are supplied source claims, not independently verified conclusions of this draft. The excerpt's suggested recursive explanation for the example is heuristic; its assertion of a smallest class lacks explicit initial conditions and is not an additional hypothesis of the question. The empty-permutation convention above is explicit; changing only the constant term does not affect membership in $K$.

Short English statement

Does every pattern-closed proper subclass of the separable permutations have its ordinary length-generating function in ${\mathbb{Q}}(z,\sqrt{1-4z},\sqrt{1-6z+5z^2})$? The supplied example motivates the second radical. The record labels the enlarged question open; this statement-only draft does not independently verify that status.
