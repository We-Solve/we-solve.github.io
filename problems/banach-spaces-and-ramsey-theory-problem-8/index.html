Banach Spaces and Ramsey Theory — Problem 8

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $X$ be a separable Banach space. All subspaces and linear maps are understood over the scalar field of $X$; the supplied record does not specify whether this field is ${\mathbb{R}}$ or ${\mathbb{C}}$. Let $(r_i)$ be independent random variables taking the values $-1$ and $1$, each with probability $1/2$.

For $1\le p\le2$, say that $X$ has Rademacher type $p$ if there exists $T<\infty$ such that, for every positive integer $n$ and every $x_1,\ldots,x_n\in X$, \[ \left({\mathbb{E}}\left\|\sum_{i=1}^n r_i x_i\right\|^2\right)^{1/2} \le T\left(\sum_{i=1}^n\|x_i\|^p\right)^{1/p}. \] For $2\le q<\infty$, say that $X$ has Rademacher cotype $q$ if there exists $C<\infty$ such that, for every such finite sequence, \[ \left(\sum_{i=1}^n\|x_i\|^q\right)^{1/q} \le C\left({\mathbb{E}}\left\|\sum_{i=1}^n r_i x_i\right\|^2\right)^{1/2}. \] Two Banach spaces are isomorphic if there is a bounded linear bijection between them with bounded inverse.

Extraction qualification. The supplied statement has a missing symbol after both $2-$ and $2+$, and before $>0$. The following question uses the natural but unverified reconstruction of these expressions as $2-\varepsilon$, $2+\varepsilon$, and $\varepsilon>0$. In the type alternative, only parameters for which the exponent belongs to the conventional type range are used. This range restriction is not explicit in the supplied statement. Subspaces are interpreted as closed linear subspaces, as usual for Banach subspaces; closedness is also not explicit in the extraction.

Question under this reconstruction. Suppose that \[ \left(\exists\varepsilon\in(0,1]\; X\text{ fails to have type }2-\varepsilon\right) \quad\text{or}\quad \left(\exists\varepsilon>0\; X\text{ fails to have cotype }2+\varepsilon\right). \] Must there exist a family $(Y_t)_{t\in{\mathbb{R}}}$ of closed linear subspaces of $X$ such that $Y_s$ and $Y_t$ are not isomorphic whenever $s\ne t$? Thus the requested family has cardinality $2^{\aleph_0}$. The hypothesis is existential in the parameter in each alternative; it does not require failure for every positive parameter. Confirmation against the original source is required before treating this reconstruction as an exact formulation.

Short English statement

Under an explicitly qualified reconstruction of the damaged exponents, the question asks whether a separable Banach space that fails some type exponent below $2$, or some finite cotype exponent above $2$, must contain continuum many pairwise non-isomorphic closed subspaces.
