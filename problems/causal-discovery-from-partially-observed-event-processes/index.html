Causal Discovery from Partially Observed Event Processes

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $X=(X^v)_{v\in V}$ denote a multivariate event process, with coordinate index set $V$, and let $O\subseteq V$ be the set of observed coordinates. Write $X^O=(X^v)_{v\in O}$. The source does not specify the time domain, the class of event processes, or the precise definition of local independence.

To express the identification question without supplying these missing assumptions, let $\mathcal M$ denote an admissible class of underlying process models, to be specified. For $M\in\mathcal M$, let $\mathcal L_O(M)$ denote the local-independence model induced by observing only $X^O$, and let $\mathcal C(M)$ denote its underlying causal structure. Both the construction of $\mathcal L_O$ and the meaning of $\mathcal C$ require specification. Define \[ M\sim_O M'\quad\Longleftrightarrow\quad \mathcal L_O(M)=\mathcal L_O(M'). \] For a given induced model $L$, define its compatible causal structures by \[ \mathfrak C_O(L) =\{\mathcal C(M):M\in\mathcal M,\ \mathcal L_O(M)=L\}. \] A feature $f$ of the causal structure is identifiable from $L$, relative to $\mathcal M$, if \[ \forall M,M'\in\mathcal M,\qquad \mathcal L_O(M)=\mathcal L_O(M')=L \ \Longrightarrow\ f(\mathcal C(M))=f(\mathcal C(M')). \] Problem. When only some coordinates of a multivariate event process are observed, characterize the aspects of the causal structure that are identifiable from the induced local-independence model. In the notation above, this asks for a characterization of $\mathfrak C_O(L)$ and of the causal features shared by every member of this set.

This is a conditional formalization of the supplied identification question. It does not select an admissible model class, impose faithfulness or causal sufficiency, identify a graph with a causal structure, or assume a particular rule for marginalization. Those choices are absent from the source record and are needed for a fully specified mathematical problem.

Short English statement

Given the local-independence information available from the observed coordinates of an event process, determine which features of the underlying causal structure must agree across all compatible models. The source leaves the process assumptions, the definition of local independence, and the intended causal representation unspecified.
