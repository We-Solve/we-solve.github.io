Dynamical Comparison for Amenable Minimal Nonamenable-Group Actions

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

The supplied record conjectures dynamical comparison for every amenable minimal action of a nonamenable group on a compact metric space. It does not specify the topology or countability of the group, or define amenability and dynamical comparison. The following is a precise conditional formulation using discrete groups, topological amenability, and the open-set comparison convention stated below. These interpretations require source review.

Let $G$ be a discrete group and let $X$ be a nonempty compact metric space. An action $G\curvearrowright X$ is an action by homeomorphisms, written $(g,x)\mapsto gx$. It is minimal if $\overline{Gx}=X$ for every $x\in X$. The group is nonamenable if there is no left-translation-invariant mean on $\ell^\infty(G;{\mathbb{R}})$.

Write \[ \operatorname{Prob}(G)=\left\{p\in\ell^1(G;{\mathbb{R}}):p(h)\geq 0\text{ for all }h\in G,\quad \sum_{h\in G}p(h)=1\right\}, \qquad (g\cdot p)(h)=p(g^{-1}h). \] The action is topologically amenable if there is a net of norm-continuous maps $m_i:X\to\operatorname{Prob}(G)$ such that, for every $g\in G$, \[ \lim_i\sup_{x\in X}\left\|m_i(gx)-g\cdot m_i(x)\right\|_1=0. \] Let $M_G(X)$ be the set of $G$-invariant Borel probability measures on $X$; thus $\mu(gA)=\mu(A)$ for every Borel set $A\subseteq X$ and every $g\in G$.

For nonempty open sets $U,V\subseteq X$, write $U\prec V$ if, for every closed set $F\subseteq U$, there exist finitely many open sets $W_1,\ldots,W_n\subseteq X$ and elements $g_1,\ldots,g_n\in G$ such that \[ F\subseteq\bigcup_{j=1}^{n}W_j,\qquad g_jW_j\subseteq V\quad(1\leq j\leq n),\qquad g_jW_j\cap g_kW_k=\varnothing\quad(j\neq k). \] The empty family is allowed when $F=\varnothing$. Under the convention used here, the action has dynamical comparison if, for every pair of nonempty open sets $U,V\subseteq X$, \[ \left[\mu(U)<\mu(V)\text{ for every }\mu\in M_G(X)\right]\ \Longrightarrow\ U\prec V. \] If $M_G(X)=\varnothing$, the bracketed condition is vacuous, so this definition requires $U\prec V$ for every pair of nonempty open sets. No existence of an invariant probability measure is assumed.

Conjecture, conditional on these conventions. For every nonamenable discrete group $G$, every nonempty compact metric space $X$, and every topologically amenable minimal action $G\curvearrowright X$, the action has dynamical comparison.

The supplied text imposes no freeness, finite-dimensionality, or countability hypothesis. None is added here. Whether a countable discrete group or another additional hypothesis is intended remains unresolved. The original wording places "amenable" in parentheses, whereas the supplied reconstructed statement explicitly requires amenability; the formulation above follows the reconstructed statement.

Short English statement

The conjecture says that every topologically amenable minimal action of a nonamenable group on a compact metric space has dynamical comparison: whenever all invariant probability measures assign an open set $U$ less mass than a nonempty open set $V$, each closed subset of $U$ can be covered by finitely many open pieces whose group translates lie disjointly inside $V$. The discrete-group setting and the precise comparison convention used here require confirmation from the source. The supplied status is partially solved, not an independently verified conclusion.
