Math-5519

Research Problems in Function Theory — Problem 2.40

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a nonconstant entire function $f$, define \[ M(r,f)=\max_{|z|=r}|f(z)|,\qquad E(c)=\{z\in\mathbb C:|f(z)|>c\}, \] and let $m_2$ be planar Lebesgue measure. Assume $m_2(E(c))<\infty$ for some real threshold $c$.

Growth question. Determine the minimum possible growth of $f$ under this hypothesis. Hayman's proposed necessary and best-possible condition is \[ \int_R^{\infty}\frac{r\,dr}{\log\log M(r,f)}<\infty, \] where $R$ is sufficiently large that $M(r,f)>e$ for all $r\geq R$. This tail-integral formulation makes sense of the source's formal lower limit $0$, since $\log\log M(r,f)$ need not be positive or defined near the origin. Finiteness does not depend on which sufficiently large $R$ is used. The phrase best possible is retained, but the source gives no explicit converse construction or admissible growth-envelope class defining its sharpness.

Threshold question (P. Erdős). If $m_2(E(c))<\infty$, must $m_2(E(c'))<\infty$ also hold for smaller thresholds $c'<c$? The substantive positive-threshold version asks this for every $0<c'<c$. The source does not explicitly state that restriction; nonpositive thresholds introduce a separate degeneracy because a nonconstant entire function has only a discrete zero set and $E(c')$ then has infinite area. This missing qualification is not silently ignored.

The supplied summary labels the problem open as of Hayman's 2018 edition and reports no recent resolution located, without an independently verified current result.

Short English statement

How fast must an entire function grow if the region where its modulus exceeds one threshold has finite area? Test the proposed integral condition and ask whether finite area persists at every smaller positive threshold.
