Better-Than-Two Approximation for Multiplicative Connectivity Augmentation

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

In $\alpha$-multiplicative connectivity augmentation the input is a $k$-edge-connected graph and a set of candidate links with nonnegative costs. One selects minimum-cost links so that the augmented graph is at least $\lceil\alpha k\rceil$-edge-connected. Edge connectivity is the minimum number of edges in a nontrivial cut. An approximation factor below two means a polynomial-time algorithm with cost at most $\rho$ times optimum for some $\rho<2$.

Statement recorded in the supplied source.

Scope qualification.
The improvement may depend on fixed $\alpha$ but must be uniform over the input instances. Feasibility assumes enough available links to achieve the target.

Duplicate scope

This fragment repeats the augmentation problem retained as 30004907. The original paragraph on printed page 2945 supplies the base connectivity, weighted candidate links and rounded target. We examine a simple base class where the deficient cuts can be characterized exactly, then test extending the rule of covering only the original minimum cuts. This is a separate attempted route on the same underlying question, not a new independent conjecture.
An exact unit-cost star augmentation.
Let $G$ be a star with $h\ge2$ leaves. Its edge connectivity is one. Suppose every pair of leaves is available as a unit-cost link, and $1<\alpha\le2$, so the target is $\lceil\alpha\rceil=2$. A selected set of links is feasible exactly when each leaf is incident to at least one link. To prove this, represent any cut by its side not containing the center; that side is a nonempty leaf subset $S$. Its original cut size is $|S|$. If $|S|\ge2$, the target is already met. If $S$ is a singleton, it needs exactly one crossing link, equivalent to that leaf's having positive link degree. This proves necessity and sufficiency for every cut.

The optimum number of links is $\lceil h/2\rceil$. Every link covers at most two leaves, giving this lower bound. For even $h$, pair all leaves and take the resulting $h/2$ links. For odd $h\ge3$, pair $h-1$ leaves and connect the remaining leaf to any paired leaf; this uses $(h+1)/2$ links and covers every leaf. The construction is polynomial and exact, but uses the complete candidate-link set, unit costs and the target two. It does not solve arbitrary weighted augmentation.

Original minimum cuts need not be the only deficient cuts.
Keep a star with four leaves, but now take $\alpha=3$, so the target is three. Select two parallel links between leaves one and two, and two between leaves three and four. Each singleton leaf cut increases from one to three, so all original minimum cuts meet the target. The cut with side consisting of leaves one and two still has only its two star edges: none of the selected links crosses it. Its capacity is two, below target. Thus covering every original minimum cut to its required new size is not sufficient for general multiplicative augmentation. All originally sub-target cuts matter, including those that were not minimum cuts. The source allows candidate links as a multiset, so the parallel links in this countercheck respect that model.

This example uses $\alpha=3$, outside the source's proposed initial polygon range $\alpha\le6/5$. It tests the full "any constant greater than one" goal, not an impossibility claim for that smaller range. Conversely the exact target-two star construction lies within the smaller range when $\alpha\le6/5$ because the ceiling is still two. Neither observation transfers its algorithm to arbitrary large base connectivity.

The primary augmentation paragraph and the duplicate link were inspected. The audit checked the ceiling at base connectivity one, both sides of every star cut, the odd-leaf construction and the scope of the parallel-link example. All proofs are by explicit cut counts, with no optimization solver used. The missing step is an algorithm coordinating all deficient cuts with arbitrary costs and base graph structure while achieving a uniform factor below two. This remains unresolved under the repeated source record.

Verbatim supplied catalogue question

For every fixed $\alpha>1$, does $\alpha$-multiplicative connectivity augmentation admit an approximation factor strictly below $2$?

The cut-cover route

Put $t=\lceil\alpha k\rceil$. For a nontrivial vertex set $S$, let $d_G(S)=|\delta_G(S)|$ and $b(S)=\max\{0,t-d_G(S)\}$. A selected multiset $F$ of available links is feasible exactly when \[ |F\cap\delta_L(S)|\ge b(S)\quad\hbox{for every nontrivial }S. \] Indeed each selected crossing link adds one to that cut, so its new size is $d_G(S)+|F\cap\delta_L(S)|$. Requiring this to be at least $t$ is exactly the displayed inequality. This uses the source's cut definition of edge connectivity, without an additional disjoint-path theorem. Only cuts with $d_G(S)<t$ matter. Since this cut size is integral, $d_G(S)<t$ implies $d_G(S)<\alpha k$, including when $\alpha k$ is an integer. This explains the relevance of a representation of near-minimum cuts. It does not solve their simultaneous weighted covering problem.
A feasible optimum fractional solution missed by thresholding.
Take $G=K_{k+1}$ for $k\ge1$. A cut with $s$ vertices on one side has $d_G(S)=s(k+1-s)\ge k$, so its edge connectivity is $k$. Let $r=t-k>0$. Provide $q$ parallel candidate copies of every original edge, each of unit cost, where $q$ is chosen so large that $r/(qk)<1/2$. Give every candidate fractional value $x_e=r/(qk)$. For any cut the added fractional capacity is $(r/k)d_G(S)$, and hence the total is $(t/k)d_G(S)\ge t$. Thus all cut constraints hold and all variables lie strictly below one half.

This fractional solution is optimal for the cut relaxation. Each singleton cut needs $r$ added capacity. Summing the $k+1$ singleton constraints counts each link twice, so every feasible fractional solution has cost at least $(k+1)r/2$. The displayed solution has exactly that cost, since there are $qk(k+1)/2$ links. Rounding by retaining only values at least one half selects no link and fails every deficient singleton cut. This example does not claim that the fractional point is an extreme point. An iterative-rounding theorem about extreme optima cannot be refuted by an arbitrary optimum, and this distinction is essential.

Why repeating a one-unit algorithm needs amortization.
Suppose one has a factor-$\rho$ routine for increasing the current connectivity by one. A naive analysis applies it $r=t-k$ times and compares each round's optimum with the cost $C^*$ of one final optimal augmentation. That comparison is valid: at any round, adding the final optimum's as-yet unselected links would attain at least $t$, so in particular attains the next target. Its additional cost is at most $C^*$. But summing these bounds yields only $r\rho C^*$, not $\rho C^*$. For fixed $\alpha>1$, $r$ grows with $k$, so this argument alone does not even give a uniform constant factor. Some stronger charging argument or coordinated multilevel algorithm would be required. This is a failure of the proposed analysis, not a constructed lower bound on every repeated-augmentation routine.

Audit

The primary augmentation problem on printed page 2945 was inspected, including the weighted multiset of links. The audit retained the ceiling, all deficient cuts, and the fact that compactly representing constraints does not automatically yield stronger rounding. The fractional example uses a simple base graph and only the explicitly permitted parallel candidate links. No LP solver or augmentation experiment was run. A factor uniformly below two for the full original class remains unproved here.
