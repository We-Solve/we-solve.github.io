Statement

Let $(\epsilon_k)_{k\ge 0}$ be independent random variables with \[\mathbb P(\epsilon_k=1)=\mathbb P(\epsilon_k=-1)=\tfrac12. \] For each $n\ge 0$ define the random degree-$n$ polynomial \[f_n(z)=\sum_{k=0}^n \epsilon_k z^k. \] Let $R_n$ be the number of real roots of $f_n$ (counted with multiplicity). Question: Is it true that, with probability $1$, \[\lim_{n\to\infty} \frac{R_n}{\log n} = \frac{2}{\pi}\ ?\] (Here $\log$ is the natural logarithm; the limit is interpreted for integers $n\to\infty$.)

Round-(round_no-1) FOUNDATION USED

If $D_n$ denotes the event that $f_n$ has a real multiple root, then \[ \sum_{n=1}^{\infty}\mathbb P(D_n)<\infty. \] Hence, almost surely, every real root of $f_n$ is simple for all sufficiently large $n$. Therefore asymptotic statements for distinct real-root counts and multiplicity-counting real-root counts are equivalent.

For the distinct-root counts $N_n(I)$, the previous round established \[ \mathbb E N_n([0,1]) =\mathbb E N_n([-1,0]) =\mathbb E N_n([1,\infty)) =\mathbb E N_n((-\infty,-1]) =\frac{1}{2\pi}\log n+o(\log n), \] and also \[ \mathbb E N_n(\mathbb R)=\frac{2}{\pi}\log n+O(1). \]

The new theorem below is denser in a different direction.

NEW INSIGHT / TOOL (ROUND-2)

The new tool is a harmonic-weighted Borel--Cantelli argument.

The available concentration estimate has the form \[ \mathbb P\left(\left|N_n(I)-\mathbb E N_n(I)\right|\ge \varepsilon\log n\right) \le C_{\varepsilon,I}e^{-c_{\varepsilon,I}\sqrt{\log n}}, \] for the relevant intervals $I$. For an interval $I\subseteq\mathbb R$, let $N_n(I)$ denote the number of distinct real roots of $f_n$ in $I$. Let \[ \mathcal I:=\{\mathbb R,[0,1],[-1,0],[1,\infty),(-\infty,-1]\}. \] For $I\in\mathcal I$, define \[ c_I:= \begin{cases} \dfrac{2}{\pi},& I=\mathbb R,\\[6pt] \dfrac{1}{2\pi},& I\in\{[0,1],[-1,0],[1,\infty),(-\infty,-1]\}. \end{cases} \] By the previous round, for every $I\in\mathcal I$, \begin{equation}\label{wsref-0-65-71-3a-65-78-70-65-63-74-2d-61-73-79} \mathbb E N_n(I)=c_I\log n+o(\log n). \end{equation}

Lemma 1 (weighted tail summability)

For every $c>0$, \[ \sum_{n=3}^{\infty}\frac{1}{n}e^{-c\sqrt{\log n}}<\infty. \]
Proof.
By the integral test it suffices to show that \[ \int_3^{\infty}\frac{1}{x}e^{-c\sqrt{\log x}}\,dx<\infty. \] Set $u=\sqrt{\log x}$. Then $x=e^{u^2}$ and $dx/x=2u\,du$, so \[ \int_3^{\infty}\frac{1}{x}e^{-c\sqrt{\log x}}\,dx = \int_{\sqrt{\log 3}}^{\infty}2u e^{-cu}\,du<\infty. \] This proves the claim. $\square$

Lemma 2 (Tonelli weighted Borel--Cantelli)

Let $(E_n)_{n\ge1}$ be events. If \[ \sum_{n=1}^{\infty}\frac{\mathbb P(E_n)}{n}<\infty, \] then almost surely \[ \sum_{n=1}^{\infty}\frac{\mathbf 1_{E_n}}{n}<\infty. \]
Proof.
Define the nonnegative random variable \[ X:=\sum_{n=1}^{\infty}\frac{\mathbf 1_{E_n}}{n}. \] By Tonelli's theorem, \[ \mathbb E X = \sum_{n=1}^{\infty}\frac{\mathbb E\mathbf 1_{E_n}}{n} = \sum_{n=1}^{\infty}\frac{\mathbb P(E_n)}{n}<\infty. \] A nonnegative random variable with finite expectation is finite almost surely. Hence $X<\infty$ almost surely. $\square$

Lemma 3 (weighted concentration around the asymptotic constant)

Fix $I\in\mathcal I$ and $\varepsilon>0$. Then there exist constants $C=C(I,\varepsilon)>0$, $c=c(I,\varepsilon)>0$, and $n_0=n_0(I,\varepsilon)$ such that for all $n\ge n_0$, \[ \mathbb P\left(\left|\frac{N_n(I)}{\log n}-c_I\right|>\varepsilon\right) \le C e^{-c\sqrt{\log n}}. \]
Proof.
Fix $I$ and $\varepsilon$. By (eq:expect-asy), there exists $n_0$ such that for all $n\ge n_0$, \[ \left|\mathbb E N_n(I)-c_I\log n\right|\le \frac{\varepsilon}{2}\log n. \] Hence for $n\ge n_0$, \[ \left\{\left|\frac{N_n(I)}{\log n}-c_I\right|>\varepsilon\right\} \subseteq \left\{\left|N_n(I)-\mathbb E N_n(I)\right|>\frac{\varepsilon}{2}\log n\right\}. \] Can--Nguyen's concentration theorem, in the form quoted in Do's paper and already used in the previous round, gives constants $C,c>0$ such that \[ \mathbb P\left(\left|N_n(I)-\mathbb E N_n(I)\right|>\frac{\varepsilon}{2}\log n\right) \le C e^{-c\sqrt{\log n}} \qquad(n\ge2). \] Combining the two displays proves the lemma. $\square$

Theorem 4 (harmonic-summable exceptional set for a fixed interval)

Fix $I\in\mathcal I$ and $\varepsilon>0$. Then almost surely, \begin{equation}\label{wsref-0-65-71-3a-68-61-72-6d-6f-6e-69-63-2d-62-61-64} \sum_{n=3}^{\infty}\frac{1}{n} \mathbf 1_{\left\{\left|N_n(I)/\log n-c_I\right|>\varepsilon\right\}}<\infty. \end{equation}
Proof.
Let \[ E_n:=\left\{\left|\frac{N_n(I)}{\log n}-c_I\right|>\varepsilon\right\}. \] By Lemma 3, there exist $C,c>0$ and $n_0$ such that for all $n\ge n_0$, \[ \mathbb P(E_n)\le C e^{-c\sqrt{\log n}}. \] Therefore, by Lemma 1, \[ \sum_{n=3}^{\infty}\frac{\mathbb P(E_n)}{n}<\infty. \] Lemma 2 now implies (eq:harmonic-bad). $\square$

Corollary 5 (endpoint-root degrees are harmonic-summable)

Almost surely, \[ \sum_{n=3}^{\infty}\frac{\mathbf 1_{\{f_n(1)=0\}}}{n}<\infty, \qquad \sum_{n=3}^{\infty}\frac{\mathbf 1_{\{f_n(-1)=0\}}}{n}<\infty. \]
Proof.
By the exact endpoint formula from the previous round, \[ \mathbb P(f_n(\pm1)=0)=O(n^{-1/2}). \] Hence \[ \sum_{n=3}^{\infty}\frac{\mathbb P(f_n(\pm1)=0)}{n}<\infty. \] Apply Lemma 2. $\square$

Theorem 6 (logarithmic-density-one convergence for distinct root counts)

Fix $I\in\mathcal I$. Then almost surely there exists a set $G_I\subseteq\{3,4,\dots\}$ such that \begin{equation}\label{wsref-0-65-71-3a-68-61-72-6d-6f-6e-69-63-2d-67-6f-6f-64} \sum_{n\notin G_I}\frac1n<\infty, \end{equation} and \begin{equation}\label{wsref-0-65-71-3a-47-49-2d-6c-69-6d-69-74} \frac{N_n(I)}{\log n}\to c_I \qquad\text{as }n\to\infty\text{ with }n\in G_I. \end{equation}
Proof.
For each integer $m\ge1$, define the bad set \[ B_m:=\left\{n\ge3:\left|\frac{N_n(I)}{\log n}-c_I\right|>\frac1m\right\}. \] By Theorem 4 with $\varepsilon=1/m$, almost surely \[ \sum_{n\in B_m}\frac1n<\infty \qquad\text{for every }m\ge1. \] Work on an outcome $\omega$ for which these convergences hold for all $m$.

Choose integers \[ 3\le M_1<M_2<\cdots \] such that for each $m\ge1$, \[ \sum_{\substack{n\in B_m(\omega)\\ n\ge M_m}}\frac1n<2^{-m}. \] Now define \[ G_I(\omega):= \bigcup_{m=1}^{\infty} \left([M_m,M_{m+1})\cap B_m(\omega)^c\right). \] If $n\in G_I(\omega)$ and $n\in[M_m,M_{m+1})$, then \[ \left|\frac{N_n(I)(\omega)}{\log n}-c_I\right|\le \frac1m. \] Hence (eq:GI-limit) holds.

It remains to prove (eq:harmonic-good). If $n\notin G_I(\omega)$ and $n\in[M_m,M_{m+1})$, then $n\in B_m(\omega)$. Therefore \[ \sum_{\substack{n\ge3\\ n\notin G_I(\omega)}}\frac1n \le \sum_{m=1}^{\infty} \sum_{\substack{n\in B_m(\omega)\\ n\ge M_m}}\frac1n <\sum_{m=1}^{\infty}2^{-m}=1. \] This proves (eq:harmonic-good). $\square$

Corollary 7 (simultaneous convergence on a set of full logarithmic density)

Almost surely there exists a single set $G\subseteq\{3,4,\dots\}$ such that \[ \sum_{n\notin G}\frac1n<\infty, \] and, as $n\to\infty$ with $n\in G$, \[ \frac{N_n([0,1])}{\log n}\to\frac{1}{2\pi}, \qquad \frac{N_n([-1,0])}{\log n}\to\frac{1}{2\pi}, \qquad \frac{N_n([1,\infty))}{\log n}\to\frac{1}{2\pi}, \qquad \frac{N_n((-\infty,-1])}{\log n}\to\frac{1}{2\pi}, \] and consequently \[ \frac{N_n((-\infty,-1]\cup[1,\infty))}{\log n}\to\frac{1}{\pi}, \qquad \frac{N_n(\mathbb R)}{\log n}\to\frac{2}{\pi}. \]
Proof.
Apply Theorem 6 to the four intervals \[ [0,1],\ [-1,0],\ [1,\infty),\ (-\infty,-1]. \] This gives random sets $G_{[0,1]}$, $G_{[-1,0]}$, $G_{[1,\infty)}$, and $G_{(-\infty,-1]}$, each with complement of finite harmonic sum. By Corollary 5, the set of degrees on which $f_n(1)=0$ or $f_n(-1)=0$ also has finite harmonic sum. Let $G_{\mathrm{ep}}$ denote its complement. Set \[ G:=G_{[0,1]}\cap G_{[-1,0]}\cap G_{[1,\infty)}\cap G_{(-\infty,-1]}\cap G_{\mathrm{ep}}. \] Then \[ \sum_{n\notin G}\frac1n<\infty. \] Along $n\in G$, the four individual convergences hold simultaneously, and by construction $f_n(1)\neq0$, $f_n(-1)\neq0$, while $f_n(0)\neq0$ identically. Therefore on the root set of $f_n$ the four intervals \[ [0,1],\ [-1,0],\ [1,\infty),\ (-\infty,-1] \] are disjoint. Thus for every $n\in G$, \[ N_n((-\infty,-1]\cup[1,\infty)) = N_n([1,\infty))+N_n((-\infty,-1]), \] and \[ N_n(\mathbb R) = N_n([0,1])+N_n([-1,0])+N_n([1,\infty))+N_n((-\infty,-1]). \] Dividing by $\log n$ and using the four individual limits yields the two stated consequences. $\square$

Corollary 8 (the original multiplicity-counting problem holds on a set of full logarithmic density)

Almost surely there exists a set $G\subseteq\{3,4,\dots\}$ such that \[ \sum_{n\notin G}\frac1n<\infty, \] and, as $n\to\infty$ with $n\in G$, \[ \frac{R_n}{\log n}\to\frac{2}{\pi}, \qquad \frac{R_n((-\infty,-1]\cup[1,\infty))}{\log n}\to\frac{1}{\pi}, \qquad \frac{R_n([1,\infty))}{\log n}\to\frac{1}{2\pi}, \qquad \frac{R_n((-\infty,-1])}{\log n}\to\frac{1}{2\pi}. \]
Proof.
By the previous round's multiple-root lemma, almost surely there exists $n_0(\omega)$ such that every real root of $f_n$ is simple for all $n\ge n_0(\omega)$. Let $G$ be the set from Corollary 7 and replace it by $G\cap\{n\ge n_0(\omega)\}$. This removes only finitely many integers, so the complement still has finite harmonic sum. Along this modified set, distinct-root counts and multiplicity-counting root counts agree, and the displayed limits follow from Corollary 7. $\square$

Corollary 9 (bad degrees have logarithmic density $0$)

Fix $I\in\mathcal I$ and $\varepsilon>0$. Then almost surely, \[ \sum_{\substack{n\ge3\\ |N_n(I)/\log n-c_I|>\varepsilon}}\frac1n<\infty. \] In particular, \[ \frac{1}{\log N} \sum_{\substack{n\le N\\ |N_n(I)/\log n-c_I|>\varepsilon}}\frac1n \to0 \qquad(N\to\infty) \] almost surely.
Proof.
The first statement is Theorem 4. The second follows because the numerator converges to a finite limit while the denominator $\log N$ diverges. $\square$

  1. Did I really advance beyond the previous round? Yes. The previous round gave deterministic dense-subsequence laws. The present round gives a much denser random set $G$ with \[ \sum_{n\notin G}\frac1n<\infty, \] along which the conjectured asymptotics hold. This is stronger in density and is not implied by the previous subsequence theorem.

  2. Did I accidentally use full-sequence convergence anywhere? No. Every proof uses only the previous round's expectation asymptotics, endpoint formula, multiple-root lemma, and the known one-point concentration estimate.

  3. Is there any hidden independence assumption across $n$? No. Lemma 2 uses only Tonelli's theorem. No independence between the events $E_n$ is required.

  4. What about the overlap of closed intervals at $\pm1$? This is handled explicitly in Corollary 7 by intersecting with $G_{\mathrm{ep}}$, the set on which $f_n(1)\neq0$ and $f_n(-1)\neq0$. Since the exceptional endpoint degrees have finite harmonic sum almost surely, removing them preserves the theorem.

  5. What about multiplicities? They are harmless because the previous round proved that real multiple roots occur only finitely often almost surely. Corollary 8 uses this explicitly.

  6. Does finite harmonic sum really imply the announced density statement? Yes. If $A\subseteq\mathbb N$ satisfies $\sum_{n\in A}1/n<\infty$, then automatically \[ \frac{1}{\log N}\sum_{\substack{n\le N\\ n\in A}}\frac1n\to0. \] This is exactly the logarithmic-density-zero conclusion for the bad degrees.

I do not see a gap in the new argument.

5.1. Obstruction: one-point concentration is not enough for the full sequence

Lemma 5.1. Let $c>0$. Then \[ \sum_{n=3}^\infty e^{-c\sqrt{\log n}}=\infty. \] Consequently, the presently available one-point concentration bound \[ \mathbb P\left(|N_n(I)-\mathbb E N_n(I)|\ge \varepsilon\log n\right) \le C_\varepsilon e^{-c_\varepsilon\sqrt{\log n}} \] cannot by itself yield the full-sequence almost sure convergence via Borel--Cantelli.

Proof. Consider the integral \[ \int_3^\infty e^{-c\sqrt{\log x}}\,dx. \] Make the substitution $u=\sqrt{\log x}$, so that $x=e^{u^2}$ and $dx=2u e^{u^2}\,du$. Then \[ \int_3^\infty e^{-c\sqrt{\log x}}\,dx =\int_{\sqrt{\log 3}}^\infty 2u\,e^{u^2-cu}\,du. \] Since $u^2-cu\to\infty$ as $u\to\infty$, the integrand $2u e^{u^2-cu}$ tends to $\infty$ and in particular is eventually bounded below by $1$. Hence the integral diverges. By the integral test, \[ \sum_{n=3}^\infty e^{-c\sqrt{\log n}}=\infty. \] The final claim is immediate: the first Borel--Cantelli lemma requires summability of the probabilities along the full sequence, and Lemma 5.1 shows that the current one-point upper bound does not provide this. Therefore any proof of the original full-sequence almost sure law must use more than one-point concentration; specifically, one needs some maximal inequality or other mechanism controlling correlations between nearby degrees. $\square$

The following lemma is the main new technical device of this round.

Lemma 5.2 (summable-tail subsequence principle). Let $(X_n)_{n\ge2}$ be random variables and $(a_n)_{n\ge2}$ deterministic real numbers. Let $(b_n)_{n\ge2}$ be positive deterministic numbers with $b_n\to\infty$. Assume that for every integer $m\ge1$ there is a sequence $(p_{n,m})_{n\ge2}$ such that \[ \mathbb P\left(|X_n-a_n|\ge m^{-1}b_n\right)\le p_{n,m} \qquad(n\ge2). \] Let $(n_k)_{k\ge1}$ be an increasing sequence of integers such that for every $m\ge1$, \[ \sum_{k=1}^\infty p_{n_k,m}<\infty. \] Then \[ \frac{X_{n_k}-a_{n_k}}{b_{n_k}}\to0 \qquad\text{almost surely as }k\to\infty. \]

Proof. Fix $m\ge1$. Define \[ E_{k,m}:=\left\{|X_{n_k}-a_{n_k}|\ge m^{-1}b_{n_k}\right\}. \] By hypothesis, \[ \sum_{k=1}^\infty \mathbb P(E_{k,m})\le \sum_{k=1}^\infty p_{n_k,m}<\infty. \] The first Borel--Cantelli lemma implies \[ \mathbb P(E_{k,m}\ \text{i.o.})=0. \] Therefore, for almost every outcome $\omega$, there exists $K_m(\omega)$ such that for all $k\ge K_m(\omega)$, \[ |X_{n_k}(\omega)-a_{n_k}|<m^{-1}b_{n_k}. \] Now intersect over all $m\in\mathbb N$. Since this is a countable intersection of probability-one events, it still has probability one. On that event, for every $m\ge1$ the ratio $|X_{n_k}-a_{n_k}|/b_{n_k}$ is eventually at most $1/m$. Hence the ratio tends to $0$. $\square$

5.3. The relevant concentration input

We now record the specific concentration estimate that will be plugged into Lemma 5.2.

Lemma 5.3. For each fixed $\varepsilon>0$ and each interval \[ I\in\{\mathbb R,[0,1],[1,\infty),[-1,0],(-\infty,-1]\}, \] there exist constants $c_{\varepsilon,I},C_{\varepsilon,I}>0$ such that for all $n\ge2$, \[ \mathbb P\left(|N_n(I)-\mathbb E N_n(I)|\ge \varepsilon\log n\right) \le C_{\varepsilon,I}e^{-c_{\varepsilon,I}\sqrt{\log n}}. \]

Justification. This is precisely the consequence of Can--Nguyen's Theorems 1.4 and 1.5 recorded by Do in the proof of his Lemma 2.3. $\square$

5.4. Expectation constants for the four fundamental intervals

We next determine the asymptotic expectations on the intervals $[0,1]$, $[-1,0]$, $[1,\infty)$, and $(-\infty,-1]$.

Lemma 5.4. As $n\to\infty$, \[ \mathbb E N_n([0,1]) =\mathbb E N_n([-1,0]) =\mathbb E N_n([1,\infty)) =\mathbb E N_n((-\infty,-1]) =\frac{1}{2\pi}\log n+o(\log n). \]

Proof. We proceed in three steps.

Step 1: positive and negative roots inside $[-1,1]$ have the same expectation. Consider the polynomial \[ g_n(x):=f_n(-x)=\sum_{k=0}^n \epsilon_k(-1)^k x^k. \] The coefficient sequence $((-1)^k\epsilon_k)_{0\le k\le n}$ has the same joint distribution as $(\epsilon_k)_{0\le k\le n}$, because multiplying each coordinate by the deterministic sign $(-1)^k$ preserves the i.i.d. Rademacher law. Hence $g_n$ has the same distribution as $f_n$.

A real number $x\in[0,1]$ is a root of $g_n$ if and only if $-x\in[-1,0]$ is a root of $f_n$, with the same multiplicity. Therefore the random variables $N_n([0,1])$ and $N_n([-1,0])$ have the same distribution, hence \[ \mathbb E N_n([0,1])=\mathbb E N_n([-1,0]). \]

Step 2: inside and outside expectations agree on each sign side. By the Round-1 reciprocal symmetry, \[ \mathbb E N_n(0,1)=\mathbb E N_n(1,\infty). \] Adding the same endpoint contribution $\mathbb P(f_n(1)=0)$ to both sides gives \[ \mathbb E N_n([0,1])=\mathbb E N_n([1,\infty)). \] Similarly, \[ \mathbb E N_n([-1,0])=\mathbb E N_n((-\infty,-1]). \]

Step 3: evaluate the common asymptotic. Do records the classical expectation asymptotic \[ \mathbb E N_n([-1,1])=\frac{1}{\pi}\log n+o(\log n). \] Since $0$ is never a root of $f_n$ (because $f_n(0)=\epsilon_0\in\{\pm1\}$), the intervals $[-1,0]$ and $[0,1]$ split $[-1,1]$ without overlap on roots, and therefore \[ \mathbb E N_n([-1,1])=\mathbb E N_n([-1,0])+\mathbb E N_n([0,1]). \] By Step 1 the two summands are equal, so each equals \[ \frac12\,\mathbb E N_n([-1,1]) =\frac{1}{2\pi}\log n+o(\log n). \] Then Step 2 transfers the same asymptotic to $[1,\infty)$ and $(-\infty,-1]$. $\square$

5.5. Dense-subsequence strong laws

We can now combine Lemma 5.2 and Lemma 5.3 with the expectation asymptotics above.

Theorem 5.5 (dense-subsequence strong law on the four fundamental intervals and on $\mathbb R$). Let $(n_k)_{k\ge1}$ be an increasing sequence of integers such that \[ \frac{\sqrt{\log n_k}}{\log k}\to\infty. \] Then the following almost sure convergences hold: \[ \frac{N_{n_k}(\mathbb R)}{\log n_k}\to\frac{2}{\pi}, \] and for each interval \[ I\in\{[0,1],[-1,0],[1,\infty),(-\infty,-1]\} \] one has \[ \frac{N_{n_k}(I)}{\log n_k}\to\frac{1}{2\pi} \qquad\text{almost surely.} \] Consequently, \[ \frac{N_{n_k}((-\infty,-1]\cup[1,\infty))}{\log n_k}\to\frac{1}{\pi} \qquad\text{almost surely.} \]

Proof. We first prove the statement for a fixed interval $I$ among \[ \mathbb R,[0,1],[-1,0],[1,\infty),(-\infty,-1]. \] For each integer $m\ge1$, apply Lemma 5.3 with $\varepsilon=1/m$. Then there exist constants $c_{m,I},C_{m,I}>0$ such that \[ \mathbb P\left(\left|N_n(I)-\mathbb E N_n(I)\right|\ge m^{-1}\log n\right) \le C_{m,I}e^{-c_{m,I}\sqrt{\log n}} \qquad(n\ge2). \] Because \[ \frac{\sqrt{\log n_k}}{\log k}\to\infty, \] for each fixed $m$ there exists $K_m$ such that for all $k\ge K_m$, \[ c_{m,I}\sqrt{\log n_k}\ge 3\log k. \] Therefore, for all large $k$, \[ C_{m,I}e^{-c_{m,I}\sqrt{\log n_k}} \le C_{m,I}k^{-3}. \] Hence \[ \sum_{k=1}^\infty \mathbb P\left(\left|N_{n_k}(I)-\mathbb E N_{n_k}(I)\right|\ge m^{-1}\log n_k\right)<\infty. \] Lemma 5.2 now yields \[ \frac{N_{n_k}(I)-\mathbb E N_{n_k}(I)}{\log n_k}\to0 \qquad\text{almost surely.} \]

It remains to identify the deterministic limit of $\mathbb E N_{n_k}(I)/\log n_k$.

  • For $I=\mathbb R$, Round 1 already used the expectation asymptotic of Do--Nguyen--Vu: \[ \mathbb E N_n(\mathbb R)=\frac{2}{\pi}\log n + C + o(1). \] Hence \[ \frac{\mathbb E N_{n_k}(\mathbb R)}{\log n_k}\to \frac{2}{\pi}. \] Combining with the previous display gives \[ \frac{N_{n_k}(\mathbb R)}{\log n_k}\to\frac{2}{\pi} \qquad\text{almost surely.} \]

  • For $I\in\{[0,1],[-1,0],[1,\infty),(-\infty,-1]\}$, Lemma 5.4 gives \[ \frac{\mathbb E N_{n_k}(I)}{\log n_k}\to \frac{1}{2\pi}. \] Therefore \[ \frac{N_{n_k}(I)}{\log n_k}\to\frac{1}{2\pi} \qquad\text{almost surely.} \]

Finally, the intervals $[1,\infty)$ and $(-\infty,-1]$ are disjoint, so their counts add exactly. Hence \[ N_{n_k}((-\infty,-1]\cup[1,\infty)) = N_{n_k}((-\infty,-1]) + N_{n_k}([1,\infty)), \] and dividing by $\log n_k$ yields the outside-root limit $1/\pi$. $\square$

Corollary 5.6 (explicit non-lacunary subsequence with ratio tending to $1$). Define, for $k\ge3$, \[ \nu_k:=\exp\left((\log k)^3\right) \qquad\text{and}\qquad n_k:=\lfloor \nu_k\rfloor. \] After discarding finitely many initial terms, $(n_k)$ is strictly increasing and satisfies \[ \frac{n_{k+1}}{n_k}\to1. \] Hence Theorem 5.5 applies to this explicit non-lacunary subsequence. In particular, \[ \frac{N_{n_k}(\mathbb R)}{\log n_k}\to\frac{2}{\pi} \qquad\text{and}\qquad \frac{N_{n_k}((-\infty,-1]\cup[1,\infty))}{\log n_k}\to\frac{1}{\pi} \] almost surely.

Proof. We first verify the growth condition in Theorem 5.5. Since \[ \log n_k=(\log k)^3+o(1), \] we obtain \[ \frac{\sqrt{\log n_k}}{\log k} \sim \frac{(\log k)^{3/2}}{\log k} =(\log k)^{1/2}\to\infty. \] So Theorem 5.5 applies once $(n_k)$ is strictly increasing.

It remains to show $n_{k+1}/n_k\to1$. Because \[ \log \nu_k=(\log k)^3, \] we have \[ \log \frac{\nu_{k+1}}{\nu_k} =(\log(k+1))^3-(\log k)^3. \] By the mean value theorem applied to $\phi(x)=(\log x)^3$, there exists $\xi_k\in(k,k+1)$ such that \[ (\log(k+1))^3-(\log k)^3 =\phi'(\xi_k) =\frac{3(\log \xi_k)^2}{\xi_k}\to0. \] Hence $\nu_{k+1}/\nu_k\to 1$. Since $n_k/\nu_k\to1$, the same limit holds for $n_{k+1}/n_k$. Also, \[ \nu_{k+1}-\nu_k\sim \nu_k\cdot \frac{3(\log k)^2}{k}\to\infty, \] so after removing finitely many initial indices the floors $n_k$ are strictly increasing. $\square$

Corollary 5.7 (full-sequence liminf/limsup constraints). Almost surely, \[ \liminf_{n\to\infty}\frac{R_n}{\log n}\ge \frac{1}{\pi} \qquad\text{and}\qquad \limsup_{n\to\infty}\frac{R_n}{\log n}\ge \frac{2}{\pi}. \]

Proof. Since $R_n\ge N_n([-1,1])$ for every $n$, Do's strong law on $[-1,1]$ gives \[ \liminf_{n\to\infty}\frac{R_n}{\log n} \ge \lim_{n\to\infty}\frac{N_n([-1,1])}{\log n} =\frac{1}{\pi} \qquad\text{almost surely.} \] For the limsup, apply Theorem 5.5 to the explicit sequence from Corollary 5.6 (or alternatively use the Round-1 lacunary theorem): along that subsequence, \[ \frac{R_{n_k}}{\log n_k}\to \frac{2}{\pi} \qquad\text{almost surely,} \] so the full-sequence limsup is at least $2/\pi$ almost surely. $\square$

ADVERSARIAL VERIFICATION

I now check the new arguments against the main failure modes.

  • Did I really go beyond Round 1? Yes. Round 1 proved only a lacunary almost sure law on $\mathbb R$. Theorem 5.5 replaces this by a much denser subsequence theorem, valid whenever $\sqrt{\log n_k}/\log k\to\infty$, and gives exact outside-half-line laws that were absent in Round 1.

  • Was lacunarity accidentally used anywhere? No. The proof of Theorem 5.5 uses only the summability of \[ e^{-c_{m,I}\sqrt{\log n_k}}, \] which follows from $\sqrt{\log n_k}/\log k\to\infty$. No ratio lower bound $n_{k+1}/n_k\ge q>1$ is used.

  • Is the condition $\sqrt{\log n_k}/\log k\to\infty$ strong enough for all rational error tolerances? Yes. For each fixed $m$, the constant $c_{m,I}>0$ is fixed. Hence eventually \[ c_{m,I}\sqrt{\log n_k}\ge 3\log k, \] which makes the $m$th error event summable in $k$. Countably many $m$ are handled by a countable intersection of probability-one events.

  • Did endpoint roots at $\pm1$ create double-counting issues? They do not invalidate any asymptotic. In Lemma 5.4, the equality \[ \mathbb E N_n([0,1])=\mathbb E N_n([1,\infty)) \] is exact because both closed intervals differ from their open counterparts by the same endpoint event $\{f_n(1)=0\}$. Likewise on the negative side.

  • Did multiplicities matter? The concentration theorems and expectation asymptotics are stated for distinct roots. By the Round-1 multiple-root lemma, real multiple roots occur only finitely often almost surely. Therefore every asymptotic statement in Theorem 5.5 and its corollaries remains valid for the original multiplicity-counting quantities $R_n(I)$.

  • Any hidden use of unproved expectation asymptotics on $[1,\infty)$ or $(-\infty,-1]$? No. These were derived in Lemma 5.4 from (i) the classical expectation on $[-1,1]$, (ii) the sign symmetry $x\mapsto -x$, and (iii) the Round-1 reciprocal expectation symmetry.

  • Does Corollary 5.6 really give a non-lacunary sequence? Yes. The ratio $n_{k+1}/n_k\to1$, so there is no fixed $q>1$ with $n_{k+1}\ge q n_k$ for all large $k$. Hence the sequence is genuinely non-lacunary.

No contradiction or gap was found in the new arguments.

FINAL

UNRESOLVED (BUT STRICTLY ADVANCED)

The original full-sequence statement remains unresolved. However, this round proves the following new theorems beyond Round 1.

  1. Rigorous obstruction. The current one-point concentration estimate is non-summable along the full sequence, so Borel--Cantelli alone cannot prove the original almost sure law; a maximal inequality or other inter-degree control is genuinely necessary.

  2. Dense-subsequence global law. If $(n_k)$ is any deterministic increasing sequence with \[ \frac{\sqrt{\log n_k}}{\log k}\to\infty, \] then \[ \frac{R_{n_k}}{\log n_k}\to\frac{2}{\pi} \qquad\text{almost surely.} \] This is strictly stronger than the Round-1 lacunary theorem.

  3. Dense-subsequence law on the outside half-lines. Along the same class of subsequences, \[ \frac{R_{n_k}([1,\infty))}{\log n_k}\to\frac{1}{2\pi}, \qquad \frac{R_{n_k}((-\infty,-1])}{\log n_k}\to\frac{1}{2\pi}, \] and therefore \[ \frac{R_{n_k}((-\infty,-1]\cup[1,\infty))}{\log n_k}\to\frac{1}{\pi} \qquad\text{almost surely.} \]

  4. Explicit non-lacunary subsequence. The same conclusions hold along the explicit deterministic sequence \[ n_k=\lfloor\exp\left((\log k)^3\right)\rfloor \] (after removing finitely many initial terms), for which $n_{k+1}/n_k\to1$.

Thus the remaining gap is now sharply localized: the unresolved issue is not one-point concentration, but the absence of a method that propagates these dense-subsequence laws across the residual windows between nearby degrees.

1) TARGET AND SOURCE AUDIT

For the coupled random polynomials $f_n(x)=\sum_{j=0}^n\epsilon_jx^j$ with independent random signs, does the real-root count satisfy $R_n/\log n\to2/\pi$ almost surely along every degree?

All supplied versions considered: 521.tex, 521_v2.tex. Version 1 proves a deterministic subsequence consequence of one-point concentration. Version 2 proves convergence outside a random set of finite reciprocal sum, but labels the result only as logarithmic-density-one. In fact it implies ordinary density-one convergence; I prove that upgrade and its limit.

2) WORK

A deterministic strengthening.
If $B\subseteq\mathbb N$ and $\sum_{n\in B}1/n<\infty$, then $B$ has natural density zero. For fixed $M<N$, \[ {|B\cap[1,N]|\over N}\le {M\over N}+\sum_{\substack{n\in B\\n>M}}{1\over n}. \] First let $N\to\infty$ and then $M\to\infty$. This proves the claim. Thus the conclusion of version 2 already implies: almost surely there is a random set $G$ of natural density one along which all its stated normalized root counts converge. Each fixed-tolerance exceptional set has natural density zero, so this is also almost sure statistical convergence in the ordinary counting sense.

For completeness, the supplied concentration hypothesis $\mathbb P(|R_n/\log n-2/\pi|>\epsilon)\le C_\epsilon e^{-c_\epsilon\sqrt{\log n}}$ implies finite exceptional reciprocal sum by Tonelli, since substitution $u=\sqrt{\log x}$ gives $\int_3^\infty e^{-c\sqrt{\log x}}dx/x=\int_{\sqrt{\log3}}^\infty2ue^{-cu}du<\infty$. A diagonal choice of cutoffs for tolerances $1/j$ gives a single $G$: choose each tail reciprocal mass below $2^{-j}$, omit the corresponding bad points in successive cutoff blocks, and also allow the finitely many initial points. The initial finite set was omitted from one displayed estimate in version 2, but it has no effect on finiteness.

This still cannot give convergence at every degree: a deterministic sequence equal to $c+1$ at $n=2^j$ and $c$ otherwise has a harmonic-summable exceptional set and fails to converge.

3) ADVERSARIAL VERIFICATION

No independence between degrees is used by Tonelli. The statistical statement is a consequence of the supplied concentration input, not a new proof of that input. Root counts are not monotone in degree, so density-one convergence cannot be interpolated to all degrees. Reciprocal symmetry gives equal marginal laws, not equality of the coupled stochastic processes.

4) FINAL

UNRESOLVED. The full almost sure limit still requires control across exceptional degrees, especially outside $[-1,1]$. The stronger density interpretation narrows no such pathwise oscillation by itself.
