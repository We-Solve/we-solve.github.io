Math-6784

Low-Rank Splitting Error Analysis for Discretized PDEs

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied problem asks for an extension of the error analysis of the dynamical low-rank splitting scheme to spatial discretizations of partial differential equations.

For notation only, let $h$ index a spatial discretization. If $u_h(t)$ denotes a reference evolution and $Y_h^n$ denotes the low-rank splitting approximation at time $t_n$, an error quantity could be written as \[ e_h^n=\lVert u_h(t_n)-Y_h^n\rVert_h, \] provided that both states belong to a common space equipped with a specified norm $\lVert\cdot\rVert_h$. This notation does not specify a PDE class, a discretization, a rank constraint, a splitting algorithm, or a reference solution; these are absent from the supplied record.

Requested mathematical task. Establish an error analysis for the intended dynamical low-rank splitting scheme when applied to spatially discretized PDEs, addressing the obstruction described in the supplied curation: the existing estimate depends on a Lipschitz constant and does not apply to these spatial discretizations.

Unresolved qualifications. The record supplies neither the existing estimate nor its hypotheses. It does not specify whether the desired error is relative to the semidiscrete PDE evolution, an exact low-rank evolution, or the original PDE solution. Nor does it specify an error rate, a time interval, admissible initial or boundary conditions, or the required dependence on spatial resolution and rank. Thus no fully quantified error theorem can be extracted without additional source information. In particular, a bound uniform in spatial resolution is a possible interpretation of the intended extension, not an explicit requirement stated in the record.

Short English statement

Develop an error analysis for the intended dynamical low-rank splitting method applied to spatially discretized PDEs, overcoming the reported limitation involving a Lipschitz constant. The PDE class, numerical scheme, assumptions, error norm, and desired estimate remain unspecified, so the supplied record determines a research task rather than a fully quantified conjecture.
