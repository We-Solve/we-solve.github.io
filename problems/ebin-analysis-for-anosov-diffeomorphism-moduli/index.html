Ebin Analysis for Anosov Diffeomorphism Moduli

Definitions and mathematical statement

A conventional framework for interpreting the supplied questions is the following; the source record does not specify that this is the intended full set of hypotheses. Let $M$ be a closed smooth manifold, let $\operatorname{Diff}^{\infty}(M)$ denote its group of smooth diffeomorphisms, and fix an auxiliary Riemannian norm on $TM$. A diffeomorphism $f\in\operatorname{Diff}^{\infty}(M)$ is Anosov if there exist a continuous $Df$-invariant splitting $TM=E^s\oplus E^u$, a constant $C\geq 1$, and $0<\lambda<1$ such that, for every $x\in M$, every integer $n\geq0$, and all $v^s\in E_x^s$, $v^u\in E_x^u$, \[ \|D(f^n)_xv^s\|\leq C\lambda^n\|v^s\|, \qquad \|D(f^{-n})_xv^u\|\leq C\lambda^n\|v^u\|. \] Write $\mathcal A^{\infty}(M)$ for the set of such diffeomorphisms. Two elements $f,g\in\mathcal A^{\infty}(M)$ are smoothly conjugate if there is $h\in\operatorname{Diff}^{\infty}(M)$ with $g=h\circ f\circ h^{-1}$. Define the smooth-conjugacy class and the corresponding set of equivalence classes by \[ \mathcal O^{\infty}(f)=\{h\circ f\circ h^{-1}:h\in\operatorname{Diff}^{\infty}(M)\}, \qquad \mathcal M_A^{\infty}(M)=\mathcal A^{\infty}(M)/{\sim}, \] where $\sim$ is smooth conjugacy.

For a metric space $(X,d)$ and $S\subseteq X$, define, for $s>0$, \[ \mathcal H_d^s(S)=\lim_{\delta\downarrow0}\inf\left\{ \sum_{i=1}^{\infty}(\operatorname{diam}_d U_i)^s: S\subseteq\bigcup_{i=1}^{\infty}U_i,\quad \operatorname{diam}_d U_i\leq\delta \right\}, \qquad \dim_{H,d}S=\inf\{s>0:\mathcal H_d^s(S)=0\}, \] with $\inf\varnothing=+\infty$.

Questions recorded by the source. Can a smooth-conjugacy class of Anosov diffeomorphisms have Hausdorff dimension greater than $2$? Can Ebin's infinite-dimensional analysis of Riemannian metrics modulo diffeomorphisms be adapted to Anosov diffeomorphisms and their moduli spaces?

Short English statement

The supplied record asks whether a smooth-conjugacy class of Anosov diffeomorphisms can have Hausdorff dimension greater than $2$, and whether Ebin's methods for Riemannian metrics modulo diffeomorphisms extend to this setting. A precise statement requires the intended metric, underlying manifolds, regularity, and analytical goals. The record labels the problem open; that label is supplied curation and has not been independently verified.
