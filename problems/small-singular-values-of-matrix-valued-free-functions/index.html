Small Singular Values of Matrix-Valued Free Functions

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For notation only, if an evaluation of a matrix-valued function is a finite matrix \[ A=F(X_1,\ldots,X_m)\in\mathbb K^{r\times s},\qquad \mathbb K\in\{{\mathbb{R}},{\mathbb{C}}\}, \] write $q=\min\{r,s\}$. Its singular values $\sigma_1(A)\ge\cdots\ge\sigma_q(A)\ge0$ are the square roots of the $q$ largest eigenvalues of $A^*A$, counted with multiplicity, where $A^*$ denotes the conjugate transpose. Here "small singular values" refers to singular values near zero; the smallest singular value is $\sigma_q(A)$. This notation does not impose a domain or matrix shape on the source problem.

Source question. Can the small singular values of general matrix-valued functions $F(X_1,\ldots,X_m)$ be controlled?

Short English statement

The problem asks for control of singular values near zero for evaluations $F(X_1,\ldots,X_m)$.
