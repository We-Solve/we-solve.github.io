Escaping Boundary Points of Baker Domains

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied record does not specify the class of maps $f$. Consequently, its intended domain of quantification remains unresolved. The following makes the question precise under an explicitly conditional interpretation in which $f\colon{\mathbb{C}}\to{\mathbb{C}}$ is transcendental entire; this hypothesis must be confirmed against the source before accepting the formulation.

Under this interpretation, let $f^0=\operatorname{id}_{{\mathbb{C}}}$ and $f^{n+1}=f\circ f^n$. Define the escaping set by \[ I(f)=\{z\in{\mathbb{C}}: |f^n(z)|\longrightarrow\infty\text{ as }n\to\infty\}. \] The Fatou set $F(f)$ consists of points having a neighborhood on which $\{f^n:n\geq0\}$ is normal, with convergence measured in the spherical metric. A Fatou component is a connected component of $F(f)$. Here a periodic escaping Fatou component, called a Baker domain in the supplied record, means a Fatou component $U$ for which some integer $p\geq1$ satisfies $f^p(U)\subseteq U$ and every $z\in U$ belongs to $I(f)$.

The source question, under these hypotheses, is whether \[ \forall f\colon{\mathbb{C}}\to{\mathbb{C}}\text{ transcendental entire},\quad \forall U\text{ a periodic escaping Fatou component of }f,\quad \partial_{{\mathbb{C}}}U\cap I(f)\neq\varnothing. \] Thus the boundary point sought is a finite complex point. If the intended class includes meromorphic maps or maps on another domain, the definitions and quantifiers require further specification.

The supplied literature assessment uses the wording that a Baker domain "can have" an escaping boundary point. Read literally, this is an existence question, whereas the displayed source statement asks whether every such component must have one. The formulation above follows the explicit original and clean statements; the assessment does not resolve this difference.

Short English statement

Must every periodic escaping Fatou component have an escaping point on its boundary? The displayed formulation uses an explicitly conditional transcendental entire setting because the supplied record does not specify the class of maps. The supplied open status is dated curation, not an independently verified conclusion.
