Math-5035

Subgraph Query Complexity for Fixed Pattern Graphs

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Fix a graph $H$. The supplied clean statement concerns adaptive queries in a hidden countably infinite Erdős--Rényi graph. Under the conventional interpretation that $H$ is a finite simple undirected graph and that copies are not required to be induced, the model and question can be formulated as follows. These conventions require confirmation from the cited report, since the supplied record does not explicitly specify them.

For $0<p<1$, let $G({\mathbb{N}},p)$ be the random simple graph with vertex set ${\mathbb{N}}$, in which each unordered pair of distinct vertices is an edge independently with probability $p$. An adjacency query selects such a pair and reveals whether it is an edge. A strategy may choose each query using the answers to earlier queries. A copy of $H$ is revealed when there is an injective map $\phi:V(H)\to{\mathbb{N}}$ such that, for every $uv\in E(H)$, the pair $\{\phi(u),\phi(v)\}$ has been queried and answered positively. No condition is imposed on pairs corresponding to nonedges of $H$.

Interpreting the number of queries as a fixed upper bound on the queries used, define \[ f(H,p)=\min\left\{q\in{\mathbb{Z}}_{\geq0}:\text{some adaptive strategy using at most }q\text{ queries reveals a copy of }H\text{ with probability at least }\tfrac12\right\}. \] The strategy may depend on $H$ and $p$. If strategies use internal randomness, the probability includes that randomness as well as the random graph. The supplied record does not explicitly distinguish a fixed query budget from an expected query cost; the displayed definition uses a fixed budget.

Question. Determine the asymptotic growth of $f(H,p)$ as $p\to0^+$, for each fixed $H$. The supplied clean statement additionally asks which graphs $H$ admit a constant $c=c(H)$ for which \[ f(H,p)=\Theta\!\left(p^{-c}\right)\qquad(p\to0^+). \] Here the latter condition means that there exist $a_H,b_H,p_H>0$, independent of $p$, such that \[ a_Hp^{-c}\leq f(H,p)\leq b_Hp^{-c}\qquad(0<p<p_H). \] Any treatment of edgeless targets must specify the convention for revealing vertices without querying edges; under the convention above they can be revealed with zero queries.

Unresolved source qualifications. The original extracted text contains only the growth-rate question for $f(H,p)$, followed by an apparently separate question attributed to Robertson (2010) and Plummer and Zha (2012), asking for a structural characterization of graphs in an undefined class $\mathcal G$. It also records a conjecture attributed to Plummer and Zha (2012) that all graphs in $\mathcal G$ are $3$-colorable, and reports that Maria Chudnovsky and Paul Seymour proved that conjecture during the workshop. The supplied record does not define $\mathcal G$ or establish a connection to the query problem. These fragments therefore cannot be incorporated into its hypotheses or treated as a solution of it. The definition of the query model and the pure-power classification request come from the supplied clean statement; their agreement with the report is asserted by the registry but is not independently verified here.

Short English statement

For a fixed graph $H$, determine how many adaptive adjacency queries are needed to reveal a copy of $H$ in $G({\mathbb{N}},p)$ with probability at least $1/2$ as $p\to0^+$, and identify when this number has pure-power order. The draft uses explicitly stated conventional graph and query-budget interpretations. The registry labels the problem open, but the source extraction contains unrelated-looking material and requires human mathematical review.
