Math-984

First Root Conjecture for Real Exponential Polynomials

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $n\geq 1$ be an integer. An integer-coefficient real exponential polynomial in $n$ variables is a function $f:{\mathbb{R}}^n\to{\mathbb{R}}$ given by a finite polynomial presentation \[ P\in{\mathbb{Z}}[X_1,\ldots,X_n,Y_1,\ldots,Y_n],\qquad f(x)=P(x_1,\ldots,x_n,e^{x_1},\ldots,e^{x_n}), \] where $e^t$ is the usual real exponential function. Thus the notation ${\mathbb{Z}}[x_1,\ldots,x_n,e^{x_1},\ldots,e^{x_n}]$ denotes these functions, supplied by such finite presentations. Write \[ Z(f)=\{x\in{\mathbb{R}}^n:f(x)=0\},\qquad \|x\|_2=\left(\sum_{i=1}^n x_i^2\right)^{1/2}. \] First Root Conjecture. There is a single algorithm which, on every input consisting of $n\geq1$ and a finite polynomial presentation $P$ as above, halts and returns a positive integer $M(n,P)$ such that \[ Z(f)\neq\varnothing \quad\Longrightarrow\quad \exists\alpha\in{\mathbb{R}}^n\; \left(f(\alpha)=0\ \land\ \|\alpha\|_2<M(n,P)\right). \] The algorithm must halt also when $Z(f)=\varnothing$; in that case the displayed implication imposes no further condition on its output. Only the existence of one zero within the bound is required, and the bound need not contain every zero.

Interpretive qualifications. The supplied statement asks to effectively find $\eta(n,f)$, without specifying its output type or encoding. The formulation above uses the usual uniform algorithmic interpretation with integer bounds and finite polynomial inputs. A positive integer bound is equivalent to a positive rational bound or a computably specified finite real bound that can effectively be enlarged to an integer. No canonical presentation of the function $f$ is required. The source also leaves the norm unspecified; the Euclidean norm is used here as an explicit convention. Using the maximum norm yields an equivalent effective bounding problem, by \[ \|x\|_\infty\leq\|x\|_2\leq\sqrt n\,\|x\|_\infty. \] These conventions require confirmation against the intended source formulation.

Short English statement

The First Root Conjecture asks for a uniform algorithm producing a finite radius from an integer-coefficient exponential polynomial. Whenever the polynomial has any real zero, at least one zero must lie strictly inside that radius. The supplied record labels the problem open; this draft does not independently verify that status.
