An optimization problem minimizes a specified objective $f(x)$ over a feasible set $K$. A set is convex if $tx+(1-t)y\in K$ for $x,y\in K$ and $0\leq t\leq1$; a convex objective satisfies $f(tx+(1-t)y)\leq tf(x)+(1-t)f(y)$ on that domain. Linear algebra studies vector spaces and linear maps. Algebraic geometry studies polynomial equation sets and their algebraic invariants. Polynomial optimization uses polynomial objectives and constraints. These definitions identify the fields compared, without specifying a universal replacement algorithm.

Research attempt

The DARPA agenda does not define an optimization class or an efficiency target. To test one precise algebraic route, this attempt solves the real polynomial family \[ f_a(x,y)=(xy-1)^2+a(x^2+y^2),\qquad a\in\mathbb R, \] and tests the proposal "solve the gradient equations and enumerate isolated stationary points." This is an explicitly chosen model, not a formal replacement of the source agenda.
Proposition: For $a<0$, $\inf_{\mathbb R^2}f_a=-\infty$. For $a=0$, the minimum is zero on precisely the hyperbola $xy=1$. For $0<a<1$, the minimum is $2a-a^2$, attained precisely at $(\sqrt{1-a},\sqrt{1-a})$ and its negative. For $a\ge1$, the unique minimum is $1$, attained at $(0,0)$.
Proof: If $a<0$, take $x=0$ and let $|y|$ grow. If $a=0$, the square vanishes exactly when $xy=1$. For $a>0$, set $t=xy$. Since $(|x|-|y|)^2\ge0$, we have \[ f_a(x,y)\ge (t-1)^2+2a|t|=:q_a(t). \] For $t<0$, $q_a'(t)=2(t-1)-2a<0$, so this half-line has infimum $q_a(0)=1$. For $t\ge0$, completing the square gives \[ q_a(t)=(t-(1-a))^2+2a-a^2. \] Its minimizer on this half-line is $t=\max\{1-a,0\}$. Equality in the original inequality requires $|x|=|y|$. If $0<a<1$, the positive product forces the two stated points. If $a\ge1$, product zero and equal magnitudes force $x=y=0$. These points attain the stated values. ∎
Audit of stationary-point enumeration.
The gradient equations are \[ y(xy-1)+ax=0,\qquad x(xy-1)+ay=0. \] At $a=0$ their solution set is the entire hyperbola $xy=1$ together with $(0,0)$, so a method enumerating only isolated critical points returns the point with value $1$ and misses every global minimizer with value $0$. This is a concrete failure of that restricted algebraic procedure, not a failure of all algebraic-geometric methods. At $a>0$, multiplying the two equations by $x$ and $y$ and subtracting gives $a(x^2-y^2)=0$. The branch $x=-y$ gives $x(x^2+1+a)=0$, hence only zero; the branch $x=y$ gives $x(x^2-1+a)=0$. These recover the stationary points above. The Hessian at the origin is \[ \begin{pmatrix}2a&-2\\-2&2a\end{pmatrix}, \] with eigenvalues $2(a-1)$ and $2(a+1)$. Hence no parameter-uniform positive Hessian gap survives as $a\to1$. A critical-point solver that presumes a uniformly isolated nondegenerate solution has an additional unjustified hypothesis even in this small family.
