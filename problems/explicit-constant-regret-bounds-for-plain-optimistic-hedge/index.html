Statement

Explicit constant-regret bounds for plain Optimistic Hedge

Status checked: 17 October 2026

Status

This is a literature-motivated quantitative problem. Existence of some dimension-dependent constants is already claimed by a preprint; this proposal concerns effective bounds for the specified update.

Game, feedback, and regret

Fix integers $N\geq 2$ and $K\geq 2$. A game has labelled players $i\in\{1,\ldots,N\}$, action sets $A_i=\{1,\ldots,m_i\}$ with $1\leq m_i\leq K$, and payoffs $u_i:\prod_j A_j\to[0,1]$. Payoffs extend multilinearly to $\Sigma=\prod_i\Delta(A_i)$. At round $t\geq1$, all players choose mixed strategies simultaneously. After play, player $i$ receives its own exact vector $v_i^t(a)=u_i(a,x_{-i}^t)$ for every $a\in A_i$. An uncoupled update uses its own past vectors, its state, its own label and the public dimensions, without access to any player's payoff table or to precomputed equilibria. All logarithms are natural. Set \[ R_i(T)=\max_{a\in A_i}\sum_{t=1}^T \left(v_i^t(a)-\langle x_i^t,v_i^t\rangle\right), \qquad [r]_+=\max\{r,0\}. \] The comparator is one fixed action. A horizon-uniform bound concerns $\sup_T R_i(T)$, rather than $\sup_T|R_i(T)|$ or a comparator that changes actions each round. This is expected-payoff feedback and mixed-payoff regret, rather than realized regret after action sampling.

The fixed algorithm

Initialize $x_{ia}^1=1/m_i$ and $v_i^0=0$. For a common constant step size $\eta>0$, use exactly \[ x_{ia}^{t+1}=\frac{x_{ia}^{t}\exp(\eta(2v_{ia}^{t}-v_{ia}^{t-1}))} {\sum_{b\in A_i}x_{ib}^{t}\exp(\eta(2v_{ib}^{t}-v_{ib}^{t-1}))}. \] The payoff form agrees with the loss form under $\ell_i=1-v_i$; action-independent factors cancel in normalization, including the first step with zero initial feedback.

Question R2

Find explicit computable functions $\eta(N,K)>0$ and $B(N,K)<\infty$ such that for every allowed action-count vector, every game, every player, and every horizon, the simultaneous iterates satisfy \[ R_i(T)\leq B(N,K). \] A precise quantitative subquestion is whether there are absolute constants $c,p,q>0$ and an explicit such step-size rule with \[ B(N,K)\leq cN^p(1+\log K)^q \quad(N,K\geq2). \] A negative answer to that polynomial question must concern every step-size rule for the displayed algorithm, rather than one unsuitable choice of $\eta$. A useful first step is any fully effective finite bound. Matching the $O(\sqrt N\log K)$ scale known for a different algorithm is a stronger comparison, not a premise.

Known claim and unresolved quantitative issue

Ha reports that for each action-count vector there exist $\eta_\star>0$ and $C_\star<\infty$, independent of the payoff table and horizon, such that for $0<\eta\leq\eta_\star$ \[ R_i(T)\leq\frac{\log m_i}{\eta}+C_\star\eta. \] The text after Corollary 4.2 and the conclusion explicitly leave dimension-explicit constants for future work [ha, Theorem 4.1]. The proposed $B$ would have to be uniform over all action counts at most $K$; there are finitely many such vectors for fixed $N,K$. The source statement was checked; its full proof has not been independently audited here.

Duplicate and scope checks

No exact we-solve target for effective plain-Optimistic-Hedge constants was found. ECON-C73-63 permits a larger learner class but imposes additional adversarial and computation restrictions; this proposal is not claimed to settle it. The algorithm above is plain Optimistic Hedge, not a modified higher-order or regret-matching rule. The model does not include sampled utilities, floating-point rounding, or last-iterate Nash convergence.
