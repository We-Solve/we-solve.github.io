Definitions and mathematical statement

Let $\Omega$ denote the local complex domain intended in the source; its dimension, geometry, and boundary assumptions are not specified in the supplied excerpt. A plurisubharmonic function on $\Omega$ is an upper semicontinuous function with values in $[-\infty,\infty)$ whose restriction to every complex line is subharmonic or identically $-\infty$ on each connected component of the intersection. Write $\operatorname{PSH}(\Omega)$ for this class, subject to the source's unspecified convention concerning functions identically $-\infty$ on a connected component.

Question 42 (attributed to Guedj). In the local setting and with the complex Monge--Ampère flow referred to in the source, can one run that flow from every initial function \[ u_0\in\operatorname{PSH}(\Omega), \] without requiring $u_0$ to be bounded?

The supplied context states that the flows under discussion include a local version of the Kähler--Ricci flow as a particular case and can be run from bounded plurisubharmonic initial data. It motivates the question by the corresponding global results cited there as [GZ13, DiNL14b].
