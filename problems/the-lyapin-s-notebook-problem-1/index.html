The Lyapin's Notebook — Problem 1

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A semigroup is a nonempty set with an associative binary operation. An extension of a semigroup $S$ is a semigroup $T$ equipped with an injective homomorphism $\iota:S\hookrightarrow T$. An equation with constants from $S$ is an equality between nonempty words in variables and named elements of $S$. A solution in an extension assigns elements of $T$ to the variables, interprets each constant $c\in S$ as $\iota(c)$, and makes every equation hold simultaneously.

Source problem (S. Kublanovsky and M. Sapir). Describe the types of equations or systems of equations for which an algorithm can decide, for every choice of the constants in the original semigroup, whether the equation or system has a solution in some finite extension of that semigroup.

The following expresses the decision target conditionally, without resolving missing source conventions. For a finite system template with variables $x_1,\ldots,x_n$, constant slots $c_1,\ldots,c_r$, and equations \[ \Sigma(\mathbf x;\mathbf c)=\{u_j(\mathbf x,\mathbf c)=v_j(\mathbf x,\mathbf c):1\leq j\leq m\}, \] let $\mathcal E_{\mathrm{fin}}(S)$ denote the extensions admitted by the intended, but unspecified, meaning of "finite extension." For each $\mathbf c\in S^r$, the required decision is whether \[ \exists (T,\iota)\in\mathcal E_{\mathrm{fin}}(S)\;\exists\mathbf t\in T^n\;\bigwedge_{j=1}^{m} u_j(\mathbf t,\iota(\mathbf c))=v_j(\mathbf t,\iota(\mathbf c)). \] Here $\iota(\mathbf c)$ means applying $\iota$ to each constant. The requested classification concerns the equation or system types for which this decision can be made by an algorithm that halts on every admissible input.

Unresolved qualifications. The source does not define "finite extension," specify the original semigroup or its effective presentation, or determine whether the algorithm is uniform over original semigroups, system templates, or both. It also does not explicitly restrict systems to finite systems; the displayed finite-template formulation is therefore a conditional clarification, not an additional source hypothesis. If "finite extension" means that $T$ itself is finite, injectivity forces $S$ to be finite. These choices must be settled before a unique algorithmic classification problem is specified.

Short English statement

Classify the equation and system types for which one can decide, for every assignment of constants from the original semigroup, whether a solution exists in some finite extension. The meaning of finite extension, the effective input model, and the required algorithmic uniformity remain unspecified in the supplied source.
