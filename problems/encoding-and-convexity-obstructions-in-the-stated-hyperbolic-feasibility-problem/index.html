Math-5353

Encoding and convexity obstructions in the stated hyperbolic-feasibility problem

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a homogeneous polynomial $p:{\mathbb{R}}^d\to{\mathbb{R}}$, hyperbolicity with respect to $e$ means $p(e)>0$ and that $t\mapsto p(x-te)$ has only real roots for every $x$. Its closed hyperbolicity cone $\Lambda_+(p,e)$ is the closure of the connected component of $\{p>0\}$ containing $e$. A linear matrix inequality (LMI) has the form $A_0+\sum_j y_jA_j\succeq0$, with specified real symmetric matrices.

The literal source defines a hyperbolic feasibility problem by polynomials $p_1,\ldots,p_m$ and raw inequalities $p_i(x)\ge0$, without choosing hyperbolicity components. Given an ellipsoid $E_0\subseteq{\mathbb{R}}^d$ of volume $R>1$ and $\varepsilon\in(0,1)$, its proposed task is to output either \[ x\in E_0\cap\bigcap_{i=1}^m\{p_i\ge0\}, \] or the correct assertion that this intersection contains no Euclidean ball of volume at least $\varepsilon$. The second output is a weak infeasibility certificate and does not say the feasible set is empty. The proposed size is \[ s=\max\{m,\log(1/\varepsilon),\log R\}. \] Open Problem 1.10.3 asks whether every such problem can be explicitly converted to an LMI, solvable to the stated accuracy in $\operatorname{poly}(s)$ Blum--Shub--Smale real operations, whose solution supplies the required original output. This is the source's stated reduction requirement, despite its use of the word "equivalent." The OCR control character is interpreted as $\varepsilon$; a displayed $\operatorname{size}(\mathrm{HLP})$ appears to be a typographical variant of the HFP size.

The aid identifies two separate defects. First, $s$ omits $d$, the polynomial representation, and the ellipsoid data. Under a convention charging explicit coordinate output, a fixed-$(m,R,\varepsilon)$ family with unbounded $d$ requires $\Omega(d)$ output while $s$ is constant. One can take the linear hyperbolic constraint $p(x)=x_1$ and a ball $E_0$ of fixed volume $R$, translated wholly into $\{x_1>0\}$. Its feasible set contains that ball, so the no-ball output is false for fixed $\varepsilon<R$. This obstruction depends on the stated explicit-output cost convention and refutes that size bound, not every repaired reduction question.

Second, raw hyperbolic inequalities need not define a convex set. For $p(x,y)=xy$, hyperbolic with respect to $(1,1)$, the set $\{xy\ge0\}$ is nonconvex. Every projection of a spectrahedron is convex. Hence this literal set cannot be exactly such a projection. This does not rule out an arbitrary computational reduction that does not preserve the entire feasible set.

The supplied conditional repair includes complete input encoding, chosen cone directions, appropriate conditioning and accuracy data, and explicit spectrahedral lifts \[ \Lambda_+(p_i,e_i)=\{x:\exists z_i\ L_i(x,z_i)\succeq0\} \] whose total encoded size is polynomial in the repaired input size. If the encoded ellipsoid is $E_0=\{x:\|B(x-c)\|_2\le1\}$, its LMI is \[ L_E(x)=\begin{pmatrix}1&(B(x-c))^{\mathsf T}\\ B(x-c)&I_d\end{pmatrix}\succeq0. \] Then \[ \operatorname{diag}(L_1(x,z_1),\ldots,L_m(x,z_m),L_E(x))\succeq0 \] projects exactly onto $E_0\cap\bigcap_i\Lambda_+(p_i,e_i)$, with polynomial total size under the supplied-lift assumption. This is an exact representation conditional on having those lifts. It neither establishes their existence for every hyperbolicity cone nor, by itself, proves the source's volume-sensitive accuracy and running-time guarantee: conditioning and recovery of a suitable approximate solution require separate quantitative control. The final extracted phrase "A problem analogous to" is truncated and is not completed here.

Short English statement

The printed feasibility problem omits essential input size and cone choices. The aid separates an explicit-output size obstruction from a nonconvexity obstruction to exact LMI projections. A block LMI represents the repaired cone intersection only when polynomial-size lifts and the needed numerical data are supplied.
