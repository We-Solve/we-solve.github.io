Research Problems in Function Theory — Problem 2.6

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For an entire function $f$, define $M(r,f)=\max_{|z|=r}|f(z)|$. A path to infinity means a continuous map $\gamma:[0,\infty)\to{\mathbb{C}}$ with $|\gamma(t)|\to\infty$. The source attributes to Boas the existence of one such path satisfying \[ \forall n\in{\mathbb{Z}}_{\ge0},\qquad \lim_{t\to\infty}\frac{|f(\gamma(t))|}{|\gamma(t)|^n}=\infty. \] The same path must work for every fixed $n$; this is not a choice of a different path for each power.

The extract says only that $f$ is entire. This literal scope includes polynomials, for which the displayed growth beyond every polynomial power cannot hold. Thus a transcendental-entire restriction, or another exclusion of polynomial functions, is missing from the stated base result. That necessary qualification is flagged explicitly rather than silently inserted into the attributed theorem. The refinement question is naturally read in the intended nonpolynomial setting, pending source confirmation.

The open request is whether quantitative information on the lower growth of $M(r,f)$ can strengthen the growth guaranteed on such a path. The extract specifies neither a class of lower-growth bounds nor a particular proposed stronger conclusion. For context, ordinary order and lower order in the transcendental setting are \[ \rho(f)=\limsup_{r\to\infty}\frac{\log\log M(r,f)}{\log r},\qquad \lambda(f)=\liminf_{r\to\infty}\frac{\log\log M(r,f)}{\log r}. \] But "lower growth" need not mean only the single parameter $\lambda(f)$; it could prescribe a more detailed lower bound. No such interpretation or optimal rate is imposed here.

The source also attributes to Hayman entire functions of infinite order, described as growing arbitrarily rapidly, such that every path $\gamma$ to infinity on which $|f(\gamma(t))|\to\infty$ satisfies \[ \log\log|f(\gamma(t))|=O(\log|\gamma(t)|)\qquad(t\to\infty). \] The implicit bound may depend on the path; the source gives no uniform constant. This is its stated obstruction to transferring rapid maximum-modulus growth directly to a path. The phrase "arbitrarily rapidly" is not quantified, so no eventual pointwise lower bound against every prescribed growth function is invented. The supplied summary calls the Boas existence result classical and the quantitative refinement open, but no proof or independent source verification is supplied here.

Short English statement

Can lower bounds for an entire function's maximum modulus force faster growth along one path than growth beyond every fixed polynomial power? The base path statement needs a missing nonpolynomial hypothesis. The source also reports very rapidly growing infinite-order examples whose growth along every path tending to infinity in value still has finite order, so the exact lower-growth assumption and desired improvement matter.
