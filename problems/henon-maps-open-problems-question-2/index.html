Henon Maps: Open Problems — Question 2

Statement

Definitions and mathematical statement

Let $\{H_\lambda\}_{\lambda\in\Lambda}$ denote the two-dimensional Hénon family intended in the supplied source. The record does not specify a normal form, the admissible parameter set $\Lambda$, or an exact convention for an attractor; these remain qualifications of the formulation below.

For a parameter $\lambda$, an invariant Borel probability measure $\mu$ satisfies \[ \mu(H_\lambda^{-1}(B))=\mu(B) \qquad\text{for every Borel set }B \] in the phase space. Following the source's stated description, the SRB property means that the conditional measures along unstable curves are absolutely continuous with respect to length on those curves. More explicitly, for an appropriate measurable partition into local unstable curves $\gamma$, its conditional measures satisfy \[ \mu_\gamma\ll m_\gamma \qquad\text{for almost every partition element }\gamma, \] where $m_\gamma$ denotes induced length. The existence and precise meaning of these unstable curves must be understood in the intended dynamical setting.

Question 2. Give a short proof that there exist a parameter $\lambda\in\Lambda$, an attractor $A$ for $H_\lambda$, and an invariant Borel probability measure $\mu$ such that \[ \mu(A)=1, \qquad \mu_\gamma\ll m_\gamma \quad\text{along unstable curves as above}. \] Here "short" expresses the source's request for a quick proof; the source gives no formal bound on proof length or complexity. The requested advance concerns the proof: the supplied text already reports existence for a positive-measure set of parameters, with difficult and lengthy proofs attributed to references labeled [BC], [Berger], [Ta], and [WY]. Neither the parameter region nor the reference parameter measure is specified in this record.

Background and unresolved qualifications. The source motivates the question by asserting that, for $q_c(x)=x^2+c$ with $c\in{\mathbb{R}}$, an absolutely continuous measure is easy to obtain by choosing a parameter whose post-critical orbit is "finite but not periodic." A finite forward orbit is eventually periodic, so this wording requires clarification, plausibly referring to strict preperiodicity rather than absence of eventual periodicity. This background assertion is retained as supplied context, not as a separately verified theorem. The question occurs in a discussion of stochastic attractors, but the record does not explicitly state positive-Lyapunov-exponent, nontriviality, or dissipation hypotheses. These omissions matter for distinguishing the intended SRB attractor from any interpretation involving attracting periodic orbits.

Short English statement

Find a quick proof that some Hénon map has an attractor carrying an invariant SRB probability measure, whose conditional measures on unstable curves are absolutely continuous. The supplied source reports that existence for a positive-measure set of parameters is already known through lengthy proofs. The intended parameter range, attractor convention, and nontriviality requirements need clarification.
