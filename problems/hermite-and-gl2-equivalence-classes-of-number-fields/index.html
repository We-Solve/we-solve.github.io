Hermite and GL2 Equivalence Classes of Number Fields

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $K$ be a number field, that is, a finite extension of ${\mathbb{Q}}$, and put $n=[K:{\mathbb{Q}}]$. The supplied question concerns a set denoted by $\operatorname{PI}(K)$, with Hermite equivalence and $\operatorname{GL}_2({\mathbb{Z}})$-equivalence. The record does not define this set or either equivalence relation. Consequently, these are unresolved source-dependent notions, and the formulation below is conditional on their intended definitions.

For $R\in\{{\mathbb{Z}},{\mathbb{Q}}\}$, let $\operatorname{GL}_2(R)$ denote the group of invertible $2\times2$ matrices over $R$. Specifying this group does not specify the action or equivalence relation intended in the source. Write $\sim_H$ for the intended Hermite equivalence and $\sim_{{\mathbb{Z}}}$ for the intended $\operatorname{GL}_2({\mathbb{Z}})$-equivalence on $\operatorname{PI}(K)$. The wording of the question presupposes that each Hermite-equivalence class is a union of $\sim_{{\mathbb{Z}}}$-classes; the missing definitions must establish this compatibility.

Subject to these qualifications, define \[ \mathcal S(K)=\left\{H\in\operatorname{PI}(K)/{\sim_H}:\ \exists f,g\in H\text{ with }f\not\sim_{{\mathbb{Z}}}g\right\}. \] The intended question is whether \[ \text{for every number field }K,\qquad |\mathcal S(K)|<\infty. \] Thus, for each fixed $K$, are there only finitely many Hermite-equivalence classes containing more than one $\operatorname{GL}_2({\mathbb{Z}})$-equivalence class? The proposed finiteness is for each field separately; no bound uniform in $K$ is supplied.

The original record also supplies the following contextual assertions, which are retained as source assertions rather than independently verified theorems:

  • Theorem 2, attributed there to reference [4]: for every integer $n\geq4$, $\operatorname{PI}(n)$ contains infinitely many Hermite-equivalence classes that are unions of at least two $\operatorname{GL}_2({\mathbb{Z}})$-equivalence classes. Neither $\operatorname{PI}(n)$ nor reference [4] is identified in the supplied record. Its relationship to the fixed-field set $\operatorname{PI}(K)$ is therefore unresolved.
  • Theorem 3: if $K$ has degree $n\geq5$ and its Galois closure has Galois group $S_n$, then the Hermite-equivalence classes in $\operatorname{PI}(K)$ that split into more than one $\operatorname{GL}_2({\mathbb{Z}})$-equivalence class lie in finitely many $\operatorname{GL}_2({\mathbb{Q}})$-equivalence classes. Here $S_n$ is the symmetric group on $n$ letters. The intended rational equivalence relation is also undefined in the record. This supplied assertion concerns finiteness of rational equivalence classes, which does not by itself state the requested finiteness of Hermite-equivalence classes.

Short English statement

For each fixed number field $K$, ask whether only finitely many Hermite-equivalence classes in $\operatorname{PI}(K)$ split into multiple $\operatorname{GL}_2({\mathbb{Z}})$-equivalence classes. The supplied record omits the definitions of $\operatorname{PI}(K)$ and the equivalence relations, so this is a conditional statement-only draft requiring those definitions and human mathematical review.
