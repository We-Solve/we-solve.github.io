Statement

Definitions and mathematical statement

Let $n$ denote the matrix dimension and let $\delta$ denote the requested backward-error tolerance. The supplied source does not specify the input field, the admissible matrix class, the range of $\delta$, or the norm and normalization used to measure backward error. These choices must be supplied before the problem becomes a fully quantified algorithmic statement.

Backward-error diagonalization ordinarily means computing an invertible matrix $V$ and a diagonal matrix $D$ such that \[ A+E=VDV^{-1} \] for a perturbation $E$ satisfying the prescribed backward-error bound. Backward-error Schur decomposition ordinarily means computing factors satisfying \[ A+E=QTQ^*,\qquad Q^*Q=I, \] where $Q^*$ denotes the conjugate transpose. In a complex Schur formulation, $T$ is upper triangular; in a real Schur formulation, $Q$ is real orthogonal and $T$ is upper quasi-triangular, with diagonal blocks of sizes $1$ and $2$. The source does not select between these formulations or specify the output field for diagonalization. These identities describe the usual intended factorizations; the source does not specify how rounding of the output factors is incorporated into the backward-error guarantee. It also does not say whether the perturbation bound is absolute, such as $\lVert E\rVert\leq\delta$, or relative, such as $\lVert E\rVert\leq\delta\lVert A\rVert$.

Requested algorithmic statement (with unresolved specifications). Give a provable randomized algorithm for backward-error diagonalization or Schur form with running time \[ O\!\left(n^3\log^c(n/\delta)\right) \] for some fixed constant $c$, using only \[ O\!\left(\log(n/\delta)\right) \] bits of precision. The admissible inputs, backward-error guarantee, success probability, computational cost model, and meaning of precision remain unspecified in the supplied formulation; the displayed bounds must therefore be read as the requested targets rather than as a complete formal specification.

The source presents this problem as seeking an improvement over [Banks-et-al-23] for diagonalization and [banks2022global] for Schur form. Its stated motivation is that the best provable algorithms then known require substantially more precision than the numerical-analysis target of $\log(1/\delta)+c\log n$ bits. The source states that this target has been achieved for Hermitian diagonalization in [shah2025hermitian]. These are supplied literature assessments, not independently verified claims here.

Short English statement

Find a provably correct randomized algorithm for backward-error diagonalization or Schur form with $O(n^3\log^c(n/\delta))$ running time and $O(\log(n/\delta))$ bits of precision. The source leaves the input domain, error convention, probability guarantee, and computational model unresolved.
