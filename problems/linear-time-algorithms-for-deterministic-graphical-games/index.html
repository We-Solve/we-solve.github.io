Linear-Time Algorithms for Deterministic Graphical Games

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A finite-state deterministic graphical game of perfect information is described by a finite directed graph $G=(V,E)$, together with additional game data. Vertices represent states, edges represent permitted transitions, and all players observe the current state and the preceding play. Determinism means that a selected move determines its successor state, without a random transition. The supplied record does not specify the number of players, who chooses moves at each state, the outcomes or payoffs, or how finite and infinite plays are evaluated.

Source question. Can finite-state deterministic graphical games of perfect information, given explicitly as graphs, be solved in linear time by a comparison-based algorithm?

The intended algorithmic quantifiers are whether there exists a single comparison-based algorithm that correctly solves every explicitly represented game in the intended class, using time linear in the relevant input size. However, the supplied record does not define the required output of "solving" a game, the permitted comparisons, or the input-size and operation-cost conventions. Consequently, this question cannot yet be made into a fully specified algorithmic proposition. In particular, a bound of $O(|V|+|E|)$ requires conventions about the representation and cost of any additional game data; those conventions are not supplied. Terminal states, states with no outgoing edges, cycles, and infinite plays also require explicit treatment before the intended class and correctness criterion are determined.

Short English statement

The question asks for one comparison-based algorithm that solves every finite deterministic perfect-information game supplied as an explicit graph in linear time. The record leaves the game objectives, required solution, treatment of infinite play, and computational cost model unspecified, so the precise algorithmic target requires clarification from the cited source.
