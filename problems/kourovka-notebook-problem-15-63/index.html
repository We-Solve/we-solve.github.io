Kourovka Notebook Problem 15.63

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $F_n=F(x_1,\ldots,x_n)$ be the free group of finite rank $n$ with the displayed free basis. Define the semigroup \[ S_n=\{x_{i_1}\cdots x_{i_k}:k\geq 1,\ 1\leq i_j\leq n\}. \] An element $u\in F_n$ is positive if $u\in S_n$, and is potentially positive if \[ P_n(u)\quad\Longleftrightarrow\quad \exists\alpha\in\operatorname{Aut}(F_n)\;\alpha(u)\in S_n. \] Here the semigroup convention uses nonempty positive words, so the identity is excluded. The source does not explicitly discuss the empty-word convention or rank zero.

Part (a): algorithmic recognition. Is potential positivity decidable? For a fixed finite rank $n$, this asks whether there exists an algorithm which, on every input word in $x_1^{\pm1},\ldots,x_n^{\pm1}$, halts and correctly decides whether its represented element satisfies $P_n$. The source does not specify whether it requires a separate algorithm for each rank or one uniform algorithm taking both the rank and the word as input. This distinction remains unresolved in this draft.

The supplied comment dated 2013 reports that R. Goldstein answered part (a) affirmatively for $n=2$, citing the 2006 reference listed below. This is a supplied literature report, not an independently verified assertion here.

Part (b): archived question. For $m\geq n$, identify $F_n$ with the subgroup generated by $x_1,\ldots,x_n$ in $F_m=F(x_1,\ldots,x_m)$, and write $\iota_{n,m}:F_n\hookrightarrow F_m$ for this inclusion. This standard free-factor inclusion makes explicit the source's implicit interpretation of an element of $F_n$ as an element of $F_m$. Define stable potential positivity by \[ \operatorname{SP}_n(u)\quad\Longleftrightarrow\quad \exists m\geq n\;\exists\beta\in\operatorname{Aut}(F_m)\; \beta(\iota_{n,m}(u))\in S_m. \] The archived question asks whether there exist a finite rank $n$ and an element $u\in F_n$ such that \[ \operatorname{SP}_n(u)\ \land\ \neg P_n(u). \] The supplied archive reports a negative answer, attributed to A. Clark and R. Goldstein (2005); equivalently, it reports that stable potential positivity implies potential positivity in the original rank. This archival resolution is recorded as supplied attribution and is not independently verified here. The local record labels the overall problem partially solved, retains part (a) in the main section, and places part (b) in the solved archive.

Short English statement

An element of a finitely generated free group is potentially positive if some automorphism turns it into a nonempty word using only the chosen generators, without inverses. Part (a) asks for an algorithm deciding this property; the supplied 2013 comment reports a positive answer in rank two. Part (b) asks whether adding free generators can make an element potentially positive when it was not so originally; the supplied archive reports that this cannot happen.
