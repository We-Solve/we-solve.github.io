Math-3554

Abelian Galois Groups of Imaginary Quadratic Fields

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

An imaginary quadratic field is a degree-two extension $K/{\mathbb{Q}}$ having no real embedding, considered up to ${\mathbb{Q}}$-isomorphism. Write $D_K<0$ for its fundamental discriminant and $h_K=|\operatorname{Cl}(\mathcal O_K)|$ for its ideal class number. Here prime class number means that $h_K$ is a positive rational prime, so class number $1$ is excluded. Let $K^{\mathrm{ab}}$ be the maximal abelian extension of $K$ inside a fixed algebraic closure, and set \[ G_K^{\mathrm{ab}}=\operatorname{Gal}(K^{\mathrm{ab}}/K), \] with its Krull topology. Define \[ \widehat{{\mathbb{Z}}}=\varprojlim_{m\geq 1}{\mathbb{Z}}/m{\mathbb{Z}}, \qquad A_0=\widehat{{\mathbb{Z}}}^{\times}\times\prod_{n\geq 1}{\mathbb{Z}}/n{\mathbb{Z}}, \] where the inverse limit is over divisibility, $\widehat{{\mathbb{Z}}}^{\times}$ has its profinite topology, and the second factor has the product topology with each finite cyclic group discrete.

The supplied conjecture asks whether $G_K^{\mathrm{ab}}$ is isomorphic to $A_0$ for density one of the imaginary quadratic fields whose class number is prime. The natural profinite interpretation of isomorphism is a continuous group isomorphism with continuous inverse; the record does not explicitly specify this category.

For precision, a discriminant-ordered interpretation can be written as follows. For real $X>0$, put \[ \mathcal F(X)=\{K/{\mathbb{Q}}\text{ imaginary quadratic up to isomorphism}: |D_K|\leq X,\ h_K\text{ prime}\}. \] Under this ordering convention, the requested assertion is \[ \lim_{X\to\infty} \frac{\#\{K\in\mathcal F(X):G_K^{\mathrm{ab}}\cong_{\mathrm{top}}A_0\}} {\#\mathcal F(X)}=1, \] with the quotient taken where its denominator is nonzero. This is relative density within the prime-class-number family. The source record does not specify an ordering or density convention, so this displayed limit is an explicit possible interpretation requiring source confirmation. The record also does not establish that the prime-class-number family is infinite; no such infinitude is asserted here.

Short English statement

The supplied conjecture predicts that almost all imaginary quadratic fields with prime ideal class number have the same absolute abelian Galois group, namely $A_0$. A precise possible reading uses relative density ordered by absolute discriminant and isomorphisms of profinite groups. These conventions require confirmation from the source.
