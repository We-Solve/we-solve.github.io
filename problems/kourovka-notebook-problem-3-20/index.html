Statement

Definitions and mathematical statement

Let $\mathcal O$ and $\mathcal P$ denote, respectively, the classes called orderable groups and pro-orderable groups in the supplied source. The record does not define these terms and refers to Problem 1.35, whose text is not supplied. In particular, the intended definition of pro-orderability cannot be recovered from this record alone.

Under the interpretation that "axiomatizable" means axiomatizable by a set of first-order sentences in the language of groups $L_{\mathrm{grp}}=\{\cdot,{}^{-1},1\}$, define \[ \operatorname{Th}(\mathcal P)=\{\varphi:\varphi\text{ is an }L_{\mathrm{grp}}\text{-sentence and }H\models\varphi\text{ for every }H\in\mathcal P\}, \] and \[ \mathcal E(\mathcal P)=\{G:G\text{ is a group and }G\models\operatorname{Th}(\mathcal P)\}. \] Thus $\mathcal E(\mathcal P)$ is the smallest first-order axiomatizable class of groups containing $\mathcal P$, with smallest understood with respect to inclusion.

Question (A. I. Kokorin, 1969; Kourovka Notebook Problem 3.20). With the source's intended definitions, is \[ \mathcal O=\mathcal E(\mathcal P)? \] Equivalently, under the stated first-order interpretation, is it true for every group $G$ that \[ G\in\mathcal O\quad\Longleftrightarrow\quad G\models\operatorname{Th}(\mathcal P)? \] Unresolved qualifications. This is a conditional formalization: the supplied record does not specify the order-invariance convention for orderable groups, the meaning of pro-orderable groups, or the logical meaning of axiomatizability. The missing reference to Problem 1.35 must be checked before these placeholders can be replaced by complete intrinsic definitions.

Short English statement

Kokorin asks whether the orderable groups are exactly the groups in the smallest axiomatizable class containing all pro-orderable groups. Under a first-order interpretation, this asks whether orderability is equivalent to satisfying every group-language sentence true in every pro-orderable group. The supplied record omits the relevant definitions and the referenced Problem 1.35, so the formulation remains conditional.
