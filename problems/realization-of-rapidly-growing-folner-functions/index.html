Math-4635

Realization of Rapidly Growing Følner Functions

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $f:{\mathbb{Z}}_{\geq1}\to{\mathbb{Z}}_{\geq1}$ be nondecreasing and satisfy $f(n)\geq\exp(n)$ for every $n\geq1$. For a finitely generated group $G$ and a finite symmetric generating set $S$, define the outer boundary $\partial_S A=SA\setminus A$ of a finite subset $A\subseteq G$, and use the convention \[\operatorname{Fol}_{G,S}(n)=\min\{|A|:0<|A|<\infty,\ |\partial_S A|\leq |A|/n\}.\] Set the minimum to $+\infty$ if no admissible set exists. Having finite values for all $n$ is the Følner amenability condition in this convention. The source asks whether every such $f$ is realized by some finitely generated group: \[\operatorname{Fol}_G(n)\asymp f(n).\] No smoothness, doubling, regularity, or computability condition is imposed on the prescribed function beyond monotonicity and the exponential lower bound. Any realizing group would have finite Følner values and thus be amenable; a finite group could not realize the required unbounded growth. The source suppresses the generating set and does not define $\asymp$. Its usual pointwise comparison meaning would be $cf(n)\leq\operatorname{Fol}_{G,S}(n)\leq Cf(n)$ for all sufficiently large $n$ and constants $c,C>0$. In group geometry one also uses the weaker comparison permitting rescaling of the argument, for example $F(n)\leq C f(\lceil Cn\rceil)$ and the reverse inequality with the roles exchanged. These versions need not agree for arbitrary rapidly growing or irregular $f$, and the latter is the usual setting for independence of generating-set choices. The requested realization cannot be assigned one of these meanings silently. The boundary convention is similarly explicit in this draft, not claimed as the report's only convention. The supplied 2026-08-21 triage labels the question open and reports broad constructions and characterizations with extra regularity, without a realization theorem for every function in the stated class.

Short English statement

Can every nondecreasing function bounded below by $e^n$ occur as a finitely generated group's Følner function? The comparison relation and generating-set/boundary conventions matter, especially because no regularity of the prescribed function is assumed.
