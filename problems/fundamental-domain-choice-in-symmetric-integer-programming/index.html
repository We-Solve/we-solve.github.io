Literature and context check

The primary report, printed pages 2261--2262, explains that a fundamental-domain ordering changes symmetry-based fixing and can interact with integer-programming branching choices. It already recommends aligning variable ordering with application structure. The attempt below proves the invariant objective statement and computes a small example under an explicitly fixed branching protocol; it is not a solver-independent performance theorem.

Research attempt: Objective preservation and a branch-dependent domain example

What every valid representative domain preserves
Let a finite group $G$ preserve an integer feasible set $S$ and an objective $f$, so $f(gx)=f(x)$. Let $D$ meet every orbit in exactly one point. If a minimum exists on $S$, its orbit representative belongs to $S\cap D$ and has the same objective. Since $S\cap D\subseteq S$, the two minimum values are equal. The same argument applies to maxima and to domains that retain more than one representative but never lose an orbit. Thus differing valid domains cannot change the correct optimal objective in an invariant problem. Without objective invariance this assertion fails: for $S=\{(1,0),(0,1)\}$ and objective $x_1$, the swap symmetry of $S$ does not preserve the objective, and choosing the wrong singleton representative changes its maximum.
A concrete interaction with a fixed branching choice
Consider binary $x_1,x_2$ with relaxation \[ 0\leq x_i\leq1,\qquad x_1+x_2\leq3/2, \qquad\max(x_1+x_2). \] Swap of the variables preserves both problem and objective. The representative domains $D_1:\ x_1\leq x_2$ and $D_2:\ x_2\leq x_1$ each retain one point from the nontrivial binary orbit. Both root relaxations have bound $3/2$, and both integer optima equal one. Suppose an incumbent of value one is known and a fixed protocol branches on $x_1\in\{0,1\}$ before $x_2$, pruning only infeasible nodes or nodes with relaxation bound at most the incumbent.

In $D_1$, the branch $x_1=0$ has bound one and is pruned. The branch $x_1=1$ forces $x_2\geq1$ and violates the sum constraint, so it is infeasible. These two children finish the search. In $D_2$, the branch $x_1=0$ forces $x_2=0$ and is pruned, but $x_1=1$ leaves $0\leq x_2\leq1/2$ and bound $3/2$. The stated protocol therefore branches again: $x_2=0$ gives value one and $x_2=1$ is infeasible. It processes two additional children. Every relaxation and pruning decision follows from the displayed inequalities.

This protocol deliberately fixes the variable order; it may branch on a variable integral in a chosen root relaxation optimum. A solver choosing the fractional variable in $D_2$ would instead select $x_2$ and avoid this difference. Thus the example proves dependence on the domain together with the branching protocol, rather than an inherent superiority of one symmetric domain under all algorithms.

The failed universal-selection inference
The two domains are mapped to one another by the original symmetry. If the whole branching procedure, tie breaking and variable selection are transported by that same relabeling, their search trees correspond exactly: map each node's fixed-coordinate constraints and each feasible relaxation point by the swap. Objective bounds and pruning tests are unchanged. A claimed intrinsic performance ranking from the representative set alone therefore cannot follow from this example. Any general efficiency criterion must also specify how the algorithm treats the coordinates and how domain constraints are represented.
