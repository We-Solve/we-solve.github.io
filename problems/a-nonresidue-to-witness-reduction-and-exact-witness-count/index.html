Verbatim supplied catalogue question

Question 12. Let p be prime, write p − 1 = 2 `m where m is odd, and assume

` ≥ 3. Find in deterministic polynomial time x ∈ Fp such that x2`−1

+ 1 is not a 2 `−1th power. (Kedlaya)

Attempt and supplied-data condition

Write $p-1=2^\ell m=2km$, with $m$ odd, $\ell\ge3$ and $k=2^{\ell-1}$. The target is $x$ for which $x^k+1$ is not a $k$th power, including zero among the powers. We prove a deterministic construction if one quadratic nonresidue $z$ is supplied. Producing that supplied nonresidue for arbitrary $p$ remains a separate step, so the conditional construction is not the original unconditional algorithm.
The power subgroup and its membership test.
The multiplicative group of a finite field is cyclic. Here is the needed elementary proof. In any finite abelian group one can construct an element whose order is the exponent (the least common multiple of all element orders): for each prime choose an element containing the maximal prime-power order, raise it to remove its other primary parts, and multiply these commuting elements of coprime orders. In a finite subgroup of a field, if this exponent is $e$, all group elements are roots of $X^e-1$, so their number is at most $e$. The constructed element gives $e$ distinct elements, hence it generates the group. Thus $H=(\mathbb F_p^*)^k$ has size $2m$, equals the roots of $u^{2m}=1$, and contains $-1$. Each $h\in H$ has exactly $k$ preimages under $x\mapsto x^k$, as is immediate from exponents of a generator. Let $H_0=H\cup\{0\}$. Membership in $H_0$ is tested by equality to zero or by the displayed power test. Since $k$ is even, $H$ consists of squares, and a quadratic nonresidue is outside $H_0$.
Nonmonotone bisection finds an additive boundary.
Represent the supplied nonresidue $z$ as an integer in $[1,p-1]$. Maintain integers $a<b$ with $a\in H_0$ and $b\notin H_0$, starting at $a=0,b=z$. Test the integer midpoint: if it is in $H_0$, replace $a$ by it; otherwise replace $b$. Each step preserves the opposite endpoint labels and halves the interval length up to rounding, so after $O(\log p)$ tests we have $b=a+1$. No monotonicity of the subgroup labels is assumed. Since one belongs to $H_0$, the final $a$ cannot be zero. Set $h=a\in H$; then $h+1\notin H_0$.
An explicit $k$th root of the boundary value.
If $m>1$, choose an integer $e$ with $ke\equiv1\pmod m$ by the integer Euclidean algorithm; this is possible since $k$ is a power of two and $m$ is odd. For $m=1$ set $e=0$. In either case $ke=1+tm$ with $t$ odd, since $ke$ is even and $m$ is odd. For $h\in H$, $h^m$ equals $1$ or $-1$, so \[ (h^e)^k=h(h^m)^t=h h^m. \] A nonresidue $z$ has $z^{(p-1)/2}=-1$, by the cyclic-group criterion for squares. Therefore $c=z^m$ satisfies $c^k=-1$. If $h^m=1$, take $x=h^e$; if $h^m=-1$, take $x=h^e c$. The displayed equations prove $x^k=h$ in both cases. Consequently $x^k+1=h+1$ is not a $k$th power, as required. The membership tests and exponentiations use exponents with $O(\log p)$ bits; binary powering uses $O(\log p)$ field multiplications per test. Together with the Euclidean algorithm and $O(\log p)$ bisections this is polynomial in the binary length of $p$, conditional on the supplied nonresidue.
Existence alone does not locate a witness efficiently.
The proper set $H_0$ contains zero and one. Taking the least positive integer outside it gives an additive boundary as above, so such a boundary exists without any algorithmic assumption. Each boundary $h\in H$ has $k$ distinct $k$th roots, giving at least $k$ witnesses. This bound can be exact: for $p=17$, $m=1$, $k=8$ and $H=\{1,-1\}$. Only $h=1$ has $h+1$ outside $H_0$, since $1+1=2\notin\{0,1,-1\}$ while $-1+1=0$; $x=0$ also fails. There are exactly eight witnesses. An existence proof or a brute-force scan over $p$ values is not a deterministic bound polynomial in $\log p$.
