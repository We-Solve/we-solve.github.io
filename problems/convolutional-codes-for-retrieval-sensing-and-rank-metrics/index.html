A sliding-window inverse needs a boundary anchor

The source lists retrieval, compressed sensing and rank-metric coding as separate directions. We test a basic convolutional recovery step that might be used in a sliding-window construction. In a real-valued model, suppose \[ y_t=u_t+u_{t-1},\qquad 1\le t\le L, \] where $L\ge1$. This is a scalar finite-memory filter, not by itself a private-retrieval or compressed-sensing scheme.
Proposition: If $u_0$ is known, the window is uniquely recoverable by \[ u_t=(-1)^tu_0+\sum_{j=1}^t(-1)^{t-j}y_j. \] If each observed $y_j$ has additive error of magnitude at most $\eta$, the worst possible error in $u_t$ is exactly $t\eta$. If $u_0$ is unknown, the window measurements alone do not determine the input sequence.
Proof: The recursion $u_t=y_t-u_{t-1}$ proves the inverse formula by induction. With an exact initial anchor, the error equals $\sum_{j=1}^t(-1)^{t-j}e_j$, whose magnitude is at most $t\eta$. Taking $e_j=(-1)^j\eta$ makes all summands have the same sign for every fixed $t$ and attains that bound. If the boundary anchor is unknown, add $\delta u_t=(-1)^t a$ for any nonzero real $a$ and every $0\le t\le L$. Then $\delta u_t+\delta u_{t-1}=0$, so all measurements stay unchanged while the input changes. ∎

Verification and remaining gaps

Exact rational inversions were checked for several windows, along with alternating perturbations attaining the $t\eta$ error and the unknown-boundary null direction. Thus an overlapping-window recovery argument must account both for carried state and for accumulated noise; local invertibility alone supplies no uniform stability bound independent of window length. There are $L$ measurements for $L$ unknown inputs once the anchor is fixed, so this calculation gives no compression advantage. It also supplies no privacy guarantee or rank-metric distance construction. Those separate source goals remain unaddressed beyond this concrete recovery prerequisite, and no full-target progress is claimed.
