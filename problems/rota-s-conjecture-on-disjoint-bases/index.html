Math-1899

Rota's conjecture on disjoint bases

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $M=(S,\mathcal I)$ be a finite matroid of rank $n\ge1$. Its independent sets are closed under taking subsets and satisfy exchange: an independent set of smaller size can be enlarged using an element of a larger independent set. Bases are independent sets of size $n$.

Suppose $S$ is partitioned into $n$ bases $B_1,\ldots,B_n$. Rota's basis conjecture asks whether $S$ can also be partitioned into bases $C_1,\ldots,C_n$ with \[ |B_i\cap C_j|=1 \quad(1\le i,j\le n). \] Equivalently, write the given bases as the rows of an $n\times n$ array and permute entries within each row so that every column is also a basis.

The new bases must be pairwise disjoint, so each of the $n^2$ ground elements is used exactly once. Finding one transversal basis is weaker than constructing the complete partition. The assertion is for arbitrary matroids; a representation over a particular field is not assumed. In a represented example, ground elements remain separately labelled even when their representing vectors agree or are parallel. The row partition is part of the hypothesis and may not be replaced by arbitrary $n$-element sets, which need not themselves be bases.

Short English statement

Can an array whose rows are disjoint matroid bases always be reordered within rows so that every column is also a basis?
