The Unique Games Conjecture

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For $[k]=\{1,\ldots,k\}$, a unique game has a nonempty finite edge set and a permutation $\pi_e$ of $[k]$ on each directed edge $e=(v,w)$. Its optimum is \[ \operatorname{val}(G)=\max_{L:V\to[k]}\frac{\#\{e=(v,w):\pi_e(L(v))=L(w)\}}{|E|}. \] For every fixed $\varepsilon,\delta>0$ with $\varepsilon+\delta<1$, some fixed $k$ makes distinguishing $\operatorname{val}(G)\ge1-\varepsilon$ from $\operatorname{val}(G)\le\delta$ NP-hard under deterministic polynomial-time many-one reductions. Intermediate values lie outside the promise. The alphabet size depends on the accuracy parameters, not on the growing input graph.

Formulation and concept references: [S1].

Short English statement

Is it computationally intractable to distinguish almost satisfiable permutation constraints from ones where almost none can be satisfied?

The basic pairwise marginal relaxation cannot distinguish any instance

This is a repeated Unique Games target; its identity and provenance are retained. We test the basic local-marginal linear relaxation. For a label alphabet of size $k\ge1$, use vertex probabilities $p_v(a)$ and edge joint probabilities $q_{uv}(a,b)$, nonnegative and normalized, with each edge's marginals equal to the endpoint probabilities. Maximize the average probability that an edge permutation constraint is satisfied.
Proposition: For every nonempty-edge Unique Games instance, this relaxation has optimum 1, even when no satisfying labeling exists.
Proof: Set $p_v(a)=1/k$ for every vertex and label. For each oriented constraint $b=\pi_{uv}(a)$, put $q_{uv}(a,b)=1/k$ on its $k$ allowed pairs and zero otherwise. Because $\pi_{uv}$ is a permutation, both marginals are uniform, so the assignment is feasible. Each edge is satisfied with probability 1 in its own local table; hence the relaxation attains 1, which is also the largest possible average probability. For a concrete integrality gap, take a triangle with two identity constraints on the binary alphabet and one flip constraint. The two identity edges would force all three labels equal, contradicting the flip, so no labeling satisfies all three. A constant labeling satisfies two edges, giving true value exactly $2/3$, while the marginal relaxation remains 1. ∎
The local tables cannot be combined into one global joint distribution supported on satisfying labelings in this example. Thus checking pairwise consistency is the exact failed inference. Stronger semidefinite or higher-order relaxations add information absent here, so this does not establish a barrier for all algorithms or settle the conjectured hardness gap.

Verification and remaining gaps

All eight triangle labelings and all local marginal sums were checked exactly; the values are $2/3$ and 1 as stated. The primary report discusses later progress on related label-cover gaps, but this attempt proves no new complexity reduction. Exact consistency does not solve the near-perfect gap

The source surveys the Unique Games Conjecture and semidefinite approaches. We test an elementary propagation route. Consider a finite graph with alphabet $[q]$, $q\ge1$, and each oriented edge $uv$ carrying a permutation $\pi_{uv}$, with the reverse constraint its inverse. A labeling satisfies this edge when $\ell(v)=\pi_{uv}(\ell(u))$.
Proposition: Whether all edges can be satisfied is decidable in $O(q(|V|+|E|))$ permutation evaluations. However, this exact test rejects instances whose optimum satisfied fraction tends to one.
Proof: In each connected component choose a root and a spanning tree. For every possible root label, propagate labels along tree edges using their permutations or inverses, then check every edge. Every fully satisfying labeling is uniquely determined by its root label along that tree, so the procedure succeeds exactly when a fully satisfying labeling exists. The claimed cost follows by trying $q$ labels in each component and summing their sizes. For the second assertion take a cycle of length $L\ge3$ with alphabet $\{0,1\}$. Give $L-1$ edges identity constraints and the remaining edge the flip $b\mapsto1-b$. Satisfying all edges would propagate a label around the cycle to its complement, an impossibility. The constant-zero labeling satisfies all identity edges, so the optimum is exactly $(L-1)/L$. ∎
The attempted inference "efficient exact consistency testing refutes the conjecture" therefore fails. For every fixed $\eta>0$, a cycle with $L>1/\eta$ is a near-perfect instance, yet the exact test rejects it. A promise distinction between value at least $1-\eta$ and value at most a small constant is a different task; the cycle example alone gives neither an algorithm nor a hardness proof for that distinction.

All binary labelings of the frustrated cycles with $3\le L\le10$ were enumerated, obtaining optimum $L-1$ satisfied edges. Research attempt: Exact-consistency propagation and the gap to promise hardness

Deciding whether every edge can be satisfied
Let an undirected graph have alphabet $[q]$, with each oriented edge $uv$ carrying a permutation $\pi_{uv}$ and the reverse edge its inverse. Satisfaction means $\ell(v)=\pi_{uv}(\ell(u))$. For each connected component choose a root and a spanning tree. For each of the $q$ possible root labels, propagate labels uniquely along that tree and check every remaining edge. This finds a completely satisfying assignment if one exists: any such assignment has one of the tried root labels and is forced along the tree. Conversely every assignment accepted by the checks satisfies every edge. The work is $O(q(|V|+|E|))$ permutation evaluations and comparisons with explicitly represented permutations. Components are handled independently, so one does not enumerate combinations of their root choices.

Every forest is satisfiable by this construction. A connected graph with $m\geq1$ edges and $n$ vertices has an assignment satisfying at least its $n-1$ tree edges, hence value at least $(n-1)/m$. An isolated vertex is automatically satisfiable and requires no ratio. This is useful near a tree but need not be useful in dense graphs.

Unsatisfiable instances can have value arbitrarily near one
On a cycle of length $m\geq3$ with binary alphabet, put equality constraints on all but one edge and inequality on the last. Full consistency is impossible because traversing the cycle would both preserve and flip the root label. Assigning all vertices the same label violates just the inequality edge, so the optimum value is exactly $(m-1)/m$. Thus the exact-consistency algorithm cannot settle the conjectured promise distinction between near-one and near-zero values: rejecting perfect satisfaction is consistent with values tending to one.
Elementary existence of low-value instances
Fix $0<\beta<1$ and choose $q$ with $\log2<\tfrac12\beta\log q$. On the complete graph on $n$ vertices, choose edge permutations independently and uniformly, using one orientation per edge. For a fixed labeling each edge is satisfied with probability $1/q$, independently. If at least $\beta m$ edges are satisfied, some set of $\lceil\beta m\rceil$ edges are all satisfied. A union bound over edge subsets and all $q^n$ labelings gives \[ \Pr(\exists\text{ labeling of value at least }\beta) \leq q^n2^m q^{-\lceil\beta m\rceil} \leq\exp\left(n\log q+m\log2-\beta m\log q\right). \] For $m=n(n-1)/2>2n/\beta$, this is strictly less than one. Hence there exist instances of value below $\beta$. All permutations can in principle be enumerated to find one, but this argument gives no efficient explicit construction or reduction from an NP-complete problem.

The high-value and low-value families prove that the two promise regimes are mathematically nonempty. Producing both kinds separately does not establish computational difficulty of distinguishing them. A polynomial reduction with both completeness and soundness parameters, for the conjecture's full tolerance quantifiers, remains the missing step.

Verification and adversarial audit

The propagation algorithm tries all root labels and checks non-tree edges, rather than assuming local consistency implies global consistency. The odd parity around a cycle gives exactly one necessary unsatisfied edge. The random low-value proof uses independence across edges for a fixed labeling and a subsequent union bound over labelings; it does not incorrectly assume different labelings' events are independent.
Audit corrections.
Separated perfect-consistency testing from near-perfect promise approximation and distinguished existence of hard-looking instances from a hardness reduction.
