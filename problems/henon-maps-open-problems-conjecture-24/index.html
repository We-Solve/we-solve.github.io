Statement

Definitions and mathematical statement

The supplied excerpt omits the defining formula for the family $f_{c,b}$, beginning instead with a reference to parameters $(c,b)\in{\mathbb{C}}^2$. Consequently, the following formulation is conditional on recovering the intended family; it does not identify a specific family from the excerpt alone.

For the intended complex Hénon interpretation, suppose that, for $b\ne0$, the missing specification gives an invertible map $f_{c,b}:{\mathbb{C}}^2\to{\mathbb{C}}^2$. Define \[ K^+_{c,b}=\{z\in{\mathbb{C}}^2:(f_{c,b}^{\,n}(z))_{n\ge0}\text{ is bounded}\}, \qquad K^-_{c,b}=\{z\in{\mathbb{C}}^2:(f_{c,b}^{-n}(z))_{n\ge0}\text{ is bounded}\}, \] and \[ J_{c,b}=\partial K^+_{c,b}\cap\partial K^-_{c,b}, \] where boundedness and boundaries are taken in the usual Euclidean structure on ${\mathbb{C}}^2$. The phase space and invertibility required here must be confirmed from the omitted family definition.

The source explicitly includes $b=0$ to simplify the presentation and defines that case separately: for $p_c:{\mathbb{C}}\to{\mathbb{C}}$, $p_c(z)=z^2+c$, let \[ K(p_c)=\{z\in{\mathbb{C}}:(p_c^{\,n}(z))_{n\ge0}\text{ is bounded}\}, \qquad J_{c,0}=\partial K(p_c). \] Thus the definition at $b=0$ uses the one-variable Julia set and does not require backward iteration of $f_{c,0}$.

Define the connectedness locus \[ \mathcal M=\{(c,b)\in{\mathbb{C}}^2:J_{c,b}\text{ is connected}\}. \] The target of Conjecture 24, attributed in the supplied record to Berger and Bedford (2023), is that $\mathcal M$ is disconnected in the usual topology of the parameter space ${\mathbb{C}}^2$. Equivalently, there exist disjoint, nonempty subsets $U,V\subseteq\mathcal M$, both open relative to $\mathcal M$, such that $\mathcal M=U\cup V$. This remains an incompletely specified conjecture until the defining formula for $f_{c,b}$ is recovered.

Short English statement

Conjecture 24 asserts that the set of complex parameter pairs for which the intended Hénon Julia set is connected is itself disconnected. The slice $b=0$ is included using the Julia set of $z\mapsto z^2+c$. The supplied excerpt omits the Hénon family formula, so the statement requires that missing specification.
