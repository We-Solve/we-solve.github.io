Math-6940

Vertex Sets Meeting Every Edge Color

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $r\in{\mathbb{Z}}$ with $r\geq3$, and let $R,G,B\in{\mathbb{Z}}_{\geq0}$. Under the usual finite simple hypergraph interpretation, let $H=(V,E)$, where $V$ is finite and $E\subseteq\binom{V}{r-1}$. A three-coloring is a map $c:E\to\{\mathrm{red},\mathrm{green},\mathrm{blue}\}$, so each edge receives exactly one color. Write $E_{\mathrm{red}},E_{\mathrm{green}},E_{\mathrm{blue}}$ for the three color classes, and require \[ |E_{\mathrm{red}}|=R,\qquad |E_{\mathrm{green}}|=G,\qquad |E_{\mathrm{blue}}|=B. \] For $S\subseteq V$, the induced colored hypergraph $H[S]$ has edge set $\{e\in E:e\subseteq S\}$, with colors inherited from $c$. Define \[ N_r(H,c)=\left|\left\{S\in\binom{V}{r}:\ \text{for every }a\in\{\mathrm{red},\mathrm{green},\mathrm{blue}\}\text{ there exists }e\in E_a\text{ with }e\subseteq S\right\}\right|. \] The problem is to determine, for every such $r,R,G,B$, the extremal quantity \[ M_r(R,G,B)=\max_{(H,c)}N_r(H,c), \] where the maximum ranges over colored hypergraphs satisfying the preceding requirements, with no prescribed number of vertices. The finite simple hypergraph convention is an explicit interpretation: the supplied statement does not separately specify finiteness, simplicity, or whether zero-sized color classes are permitted.

The original excerpt additionally asserts that the answer is monotonically non-decreasing in $r$; with the edge counts held fixed, this reads $M_{r+1}(R,G,B)\geq M_r(R,G,B)$. This is recorded as a supplied contextual assertion, not independently verified here.

The supplied literature assessment reports an upper bound $6\sqrt{RGB}$ for the count and a sharp upper bound $2\sqrt{RGB}$ when $r=3$. It also describes a conjectured bound for general $r$ as unresolved, but does not explicitly state that conjecture. These are supplied dated literature claims, not independently verified results of this draft. In particular, the precise general conjecture cannot be recovered unambiguously from the assessment alone.

Short English statement

For each integer $r\geq3$ and prescribed edge counts $R,G,B$, determine the largest possible number of $r$-element vertex sets containing a red edge, a green edge, and a blue edge of a three-colored $(r-1)$-uniform hypergraph. The formulation uses an explicitly stated finite simple hypergraph convention. The supplied record labels the problem open; its literature claims and verification labels require independent review.
