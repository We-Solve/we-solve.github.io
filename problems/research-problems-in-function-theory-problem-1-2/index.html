Research Problems in Function Theory — Problem 1.2

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

In the usual meromorphic interpretation, let $f$ be a nonconstant meromorphic function on ${\mathbb{C}}$. Write $T(r,f)$ for its Nevanlinna characteristic and $N(r,a)$ for the integrated counting function of $a$-points, counted with multiplicity, with poles used when $a=\infty$. Concretely, $T(r,f)=m(r,f)+N(r,\infty)$, where \[ m(r,f)=\frac1{2\pi}\int_0^{2\pi}\log^+|f(re^{it})|\,dt. \] For $a\in\widehat{\mathbb{C}}$, the Valiron deficiency is conventionally \[ \Delta(a,f)=1-\liminf_{r\to\infty}\frac{N(r,a)}{T(r,f)}, \qquad E_V(f)=\{a:\Delta(a,f)>0\}. \] This uses a liminf, in contrast to the usual Nevanlinna deficiency's limsup. The supplied phrase "set of Valiron deficiencies" is interpreted as the set of deficient values; the source's preceding definitions are not reproduced and must be checked.

Hayman's Problem 1.2 asks how large $E_V(f)$ can be for functions in the plane, and whether the stated estimate can be sharpened. The supplied statement records the known estimate \[ N(r,a)=T(r,f)+O\!\left(T(r,f)^{1/2+\varepsilon}\right) \qquad(r\to\infty) \] for all $a$ outside a set of capacity zero. In the customary formulation $\varepsilon>0$ is fixed, capacity is logarithmic capacity, and the implied constant may depend on $f,a,\varepsilon$; uniformity in $a$ is not stated. These conventions require checking against the full source.

The record says that in the finite-radius case $R<\infty$ this is "more or less best-possible," but in the plane an example of Valiron is only reported to show that the corresponding exceptional set can be uncountable. It also refers to possible sharpening of source label 1.3, whose target is not reproduced or unambiguously identified. Neither a finite-radius hypothesis nor its sharpness claim is transferred to the plane. The precise size invariant sought, the identification of the exceptional set in the estimate with $E_V(f)$, and the intended sharpened estimate remain to be checked. The supplied summary reports the problem open as of the 2018 edition and no verified later resolution.

Short English statement

The problem asks how large the set of Valiron-deficient values of a plane meromorphic function can be, beyond its reported capacity-zero restriction and uncountable examples, and whether a counting-function estimate can be improved. The exact exceptional-set and missing-label conventions need the full source.
