A bounded-drift comparison route with an explicit model gap

The original report explicitly omits the stochastic system for lack of space. Consequently the bank-specific optimization problem cannot be reconstructed from that report alone. We test one restricted mathematical model, not asserted to be the omitted system. After subtracting a threshold, let \[ X_t^a=x+\int_0^t a_s\,ds+\sigma W_t, \qquad x>0,\ \sigma>0, \] where $W$ is standard Brownian motion and admissible adapted measurable drifts satisfy $|a_s|\le M$ almost everywhere, with a fixed $M\ge0$. The constant drift $a_s=M$ is allowed. Define $\tau_a=\inf\{t\ge0:X_t^a<0\}$, with infinity if the set is empty.
Proposition: On a common Brownian path, $\tau_a\le\tau_M$ for every admissible drift. Nevertheless every admissible drift has positive probability of threshold crossing by any fixed time $T>0$; specifically \[ \Pr(\tau_a\le T)\ge \Phi_{\rm N}\!\left(-\frac{x+MT}{\sigma\sqrt T}\right)>0, \] where $\Phi_{\rm N}$ is the standard normal distribution function.
Proof: The drift bound gives $\int_0^t a_sds\le Mt$ for every $t$ outside a single probability-zero exceptional set, so $X_t^a\le X_t^M$ simultaneously by continuity. Each time with $X_t^M<0$ also has $X_t^a<0$; taking infima proves the crossing-time order. Thus $M$ maximizes every survival probability and every bounded increasing function of the crossing time in this model. In particular it is a genuine pathwise optimum, even though an unbounded expected-time objective could be infinite and uninformative. The event $x+MT+\sigma W_T<0$ implies $X_T^a<0$ and hence $\tau_a\le T$. Since $W_T/\sqrt T$ is standard normal, this event has exactly the displayed probability. The Gaussian density is positive everywhere, so its probability is strictly positive for every finite argument. ∎
The comparison requires that control affect only an additively ordered drift with a common fixed diffusion. It can fail as a design argument if the actual control changes volatility, constraints, other state variables, or the set of feasible drifts. The attempted step from this ordered model to the source model stops at precisely those absent equations and admissibility conditions.

Verification and remaining gaps

For the illustrative values $x=\sigma=M=T=1$, the Gaussian lower bound is $\Phi_{\rm N}(-2)\approx0.0227501$. No real capital ratio, regulation or financial policy is assessed. Positive crossing probability is not probability-one eventual crossing; the duplicate source fragment's stronger implication is separately examined in record 30000199. The original bank-specific avoidance and optimal-delay targets remain unresolved.
