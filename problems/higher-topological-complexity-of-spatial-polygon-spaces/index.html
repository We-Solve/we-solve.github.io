Higher Topological Complexity of Spatial Polygon Spaces

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $n\geq 1$ be an integer and fix a vector $\ell=(\ell_1,\ldots,\ell_n)\in(0,\infty)^n$. Write $S^2=\{v\in{\mathbb{R}}^3:\|v\|=1\}$, and define \[ P_\ell=\left\{(v_1,\ldots,v_n)\in(S^2)^n:\sum_{i=1}^n\ell_i v_i=0\right\},\qquad N_\ell=P_\ell/SO(3). \] Here $SO(3)$ acts diagonally by $g\cdot(v_1,\ldots,v_n)=(gv_1,\ldots,gv_n)$, and $N_\ell$ carries the quotient topology. Thus configurations differing by a common rotation represent the same point.

To specify the numerical convention for higher topological complexity, let $X$ be a nonempty path-connected space and let $r\geq2$ be an integer. Give $PX=C([0,1],X)$ the compact-open topology and define \[ e_r:PX\longrightarrow X^r,\qquad e_r(\gamma)=\left(\gamma(0),\gamma\!\left(\frac1{r-1}\right),\ldots,\gamma(1)\right). \] The unreduced sequential topological complexity $\operatorname{TC}^{\mathrm{unred}}_r(X)$ is the least positive integer $k$ for which $X^r$ has an open cover $U_1,\ldots,U_k$, each admitting a continuous map $s_j:U_j\to PX$ satisfying $e_r\circ s_j=\operatorname{id}_{U_j}$. Set this value to $\infty$ if no finite such cover exists. The reduced convention counts one fewer open set: for finite values, \[ \operatorname{TC}^{\mathrm{red}}_r(X)=\operatorname{TC}^{\mathrm{unred}}_r(X)-1. \]

Problem as supplied. For the fixed positive length vector $\ell$, compute $\operatorname{TC}_n(N_\ell)$.

Unresolved qualifications. The source record does not specify reduced versus unreduced normalization. It also uses $n$ both for the number of lengths and for the sequential-complexity index. Read literally, the requested index equals the number of lengths; whether the intended question instead asks for $\operatorname{TC}_r(N_\ell)$ for every $r\geq2$, independently of $n$, remains unresolved. No lower bound $n\geq2$, genericity hypothesis on $\ell$, nonemptiness hypothesis, or path-connectedness hypothesis is supplied. Consequently, the definition above specifies the invariant when its stated hypotheses hold, but does not silently impose those hypotheses on the source problem or settle conventions for empty spaces or index $1$. Degenerate length vectors are not excluded by the supplied formulation.

Short English statement

For a fixed vector of positive side lengths, form the space of closed spatial polygon configurations modulo simultaneous rotations and compute its higher topological complexity. The draft preserves the source's request $\operatorname{TC}_n(N_\ell)$, while flagging the unspecified normalization, possible index ambiguity, and missing hypotheses on the polygon space. The supplied record labels the problem partially solved; this is a dated curation assessment requiring independent review.
