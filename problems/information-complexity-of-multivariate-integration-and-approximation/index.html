Information Complexity of Multivariate Integration and Approximation

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $d\geq 1$ be an integer, let $D_d\subset{\mathbb{R}}^d$ be a bounded domain, and let $F$ be a class of functions on $D_d$. The permitted information consists of point evaluations $f(x_i)$, with $x_i\in D_d$. The source asks about two target operators: integration, denoted by $\operatorname{INT}$, and approximation of the input function, denoted by $\operatorname{APP}(f)=f$. The integration measure, function range, integrability assumptions, and approximation output space are not specified.

A conditional formulation of the information-complexity question is as follows. Fix a target $S\in\{\operatorname{INT},\operatorname{APP}\}$, an admissible algorithm model $\mathcal M$, and an error criterion $e$. Let $\mathcal A_n(\mathcal M)$ denote the algorithms permitted by that model that use at most $n$ point evaluations, with the meaning of this evaluation bound specified as part of the model. Define \[ n(\varepsilon;S,F,\mathcal M,e) :=\inf\left\{n\in{\mathbb{Z}}_{\geq0}:\exists A\in\mathcal A_n(\mathcal M)\text{ such that }e(A,S;F)\leq\varepsilon\right\}, \qquad \inf\varnothing:=+\infty. \] For $\varepsilon>0$, determine the number of function values needed to achieve error at most $\varepsilon$, for integration or approximation, as a function of the dimension and the specified problem data.

This formula makes the missing parameters explicit; it is a template for the source question, not a uniquely specified complexity problem. The record does not select $F$, a family of domains as $d$ varies, an integration measure or normalization, a norm or other error criterion, absolute versus relative error, or an algorithm model. In particular, whether sampling is adaptive or randomized and whether the guarantee is uniform over $F$, average-case, or probabilistic remain unresolved. No boundary conditions are supplied.

Short English statement

How many sampled values of a function are needed to approximate its integral or the function itself within tolerance $\varepsilon$? The supplied record leaves the function class, integration setup, error criterion, and sampling model unspecified, so it describes a family of information-complexity questions rather than one precise conjecture.
