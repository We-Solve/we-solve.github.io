Math-1197

Bollobás–Erdős–Tuza Independent-Set Hitting Conjecture

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For the intended graph-theoretic formulation, interpret a graph as a finite simple undirected graph; this convention is not explicitly specified in the supplied record and requires confirmation. For a nonempty graph $G=(V,E)$, put $n=|V|$. A set $I\subseteq V$ is independent if no two distinct vertices of $I$ are adjacent. Define \[ \alpha(G)=\max\{|I|:I\subseteq V\text{ is independent}\}, \qquad \mathcal I_{\max}(G)=\{I\subseteq V:I\text{ is independent and }|I|=\alpha(G)\}. \] The minimum size of a vertex set meeting every maximum independent set is \[ h(G)=\min\{|S|:S\subseteq V,\ S\cap I\ne\varnothing\text{ for every }I\in\mathcal I_{\max}(G)\}. \] Equivalently, $h(G)=\min\{|S|:\alpha(G-S)<\alpha(G)\}$, where $G-S$ is the induced graph on $V\setminus S$ and $\alpha(\varnothing)=0$. Let $\chi(G)$ denote the minimum number of colors in a proper vertex coloring.

Conjecture attributed in the supplied record to Bollobás, Erdős and Tuza (1991). For every sequence $(G_j)_{j\ge1}$ with $n_j=|V(G_j)|\to\infty$, if there exist constants $c>0$ and $j_0$ such that \[ \alpha(G_j)\ge c n_j\qquad(j\ge j_0), \] then \[ \lim_{j\to\infty}\frac{h(G_j)}{n_j}=0. \] Thus the implicit constant in $\alpha(G_j)=\Omega(n_j)$ is independent of $j$. The condition $n_j\to\infty$ makes explicit the asymptotic interpretation of the supplied statement.

Supplied relaxed conjecture. For every fixed positive integer $k$, every sequence $(G_j)$ with $n_j\to\infty$ and $\chi(G_j)\le k$ for all sufficiently large $j$ satisfies $h(G_j)/n_j\to0$. The supplied report text describes this as open even for $\chi(G)=3$; this is a source assertion, not an independently verified current status.

Qualifications concerning the supplied remarks. The source attributes to Hajnal (1965) the assertion that $\alpha(G)>n/2$ implies $h(G)=1$. It also transcribes the existence of a family $G_n$ with \[ \alpha(G_n)>n/4,\qquad \chi(G_n)\le8,\qquad h(G_n)>n/2. \] If this refers to unbounded orders, it contradicts both conjectures above. Detached square-root symbols occur in the extracted text, so this displayed transcription must not be accepted as a reliable bound or silently repaired.

A further supplied assertion describes graphs of unbounded order with \[ \alpha(G_n)=\left(\tfrac12-o(1)\right)n, \qquad h(G_n)>(\log n)^{0.999}. \] The source says that its constructions settle questions of Friedgut, Kalai and Kindler, and of Dong and Wu; the questions and the assignment of these conclusions to individual constructions are not specified.

For regular graphs, the source transcribes the hypothesis $\alpha(G)>0.250001n$ and the bound $h(G)\le O(n\log n)$, followed by the statement that this applies in particular to regular $3$-colorable graphs. A detached square-root symbol makes the intended upper bound uncertain. Neither its placement nor a corrected bound is determined here. These background claims require checking against the report before mathematical use.

The record also contains an interleaved passage entitled "Beyond Hadwiger in $F$-free graphs." Its clique-minor questions are distinct from the independent-set hitting target and are not incorporated into this conjecture.

Short English statement

The conjecture asks whether every graph sequence whose maximum independent sets contain a fixed positive proportion of the vertices admits a set of $o(n)$ vertices meeting every maximum independent set. The supplied weaker version assumes bounded chromatic number. Some extracted background bounds are corrupted or incompatible with the stated conjectures, so this is a statement-only draft requiring mathematical and source review.
