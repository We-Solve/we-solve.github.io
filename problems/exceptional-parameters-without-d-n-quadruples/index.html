Math-4098

Exceptional parameters without D(n)-quadruples

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.

For $n\in\mathbb Z$, a $D(n)$-$m$-tuple is a set $A=\{a_1,\ldots,a_m\}\subset\mathbb N$ of distinct positive integers such that $a_i a_j+n$ is the square of an integer for every $i<j$.

Statement recorded in the supplied source.
Is it true that no $D(n)$-quadruple exists for each $n\in\{-3,3,5,8,12,20\}$? [S2]

Short English statement

For each of these six exceptional parameters, rule out or exhibit a set of four positive integers having the required pairwise square property.
