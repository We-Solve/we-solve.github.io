CS-6 · Math-141

One-way functions exist

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems openaigpt 6 astra progpt 6 astra ultra Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A nonnegative function $\eta(n)$ is negligible if for every $c>0$ it is at most $n^{-c}$ for all sufficiently large $n$. The sought function family is uniformly computable in deterministic polynomial time and satisfies, for every probabilistic polynomial-time $A$, \[ \Pr_{x\leftarrow\{0,1\}^n,\,A}\!\left[A(1^n,f_n(x))\in f_n^{-1}(f_n(x))\right] \le \eta_A(n) \] for some negligible $\eta_A$. An output of the wrong input length is a failed inversion. The probability includes both a uniformly random input and the inverter's internal randomness. The inverter only has to find some preimage; recovering the originally sampled input is unnecessary.

Formulation and concept references: [S1].

Short English statement

Is there an efficiently computable function whose outputs no efficient randomized algorithm can usually reverse, even when any preimage counts?
