Math-1530

Transverse invariants via negative-stabilization coequalizers

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

The source reports Ko Honda's joint results with Etnyre that some knot types are not transversally simple, obtained indirectly, and Eliashberg's request for an invariant distinguishing transverse knots. In a cooriented contact three-manifold, a positively transverse knot has tangent positively transverse to the contact planes. In the standard $(S^3,\xi_{\mathrm{std}})$ setting used by the aid, a smooth oriented knot type is transversally simple if its positive transverse isotopy classes are determined by self-linking number. The general source does not specify an ambient manifold or ask for a complete invariant.

The aid reports that the invariant-existence interpretation has positive answers through Khovanov, Floer, monopole and transverse-DGA constructions, while a complete transverse classification does not follow. It supplies the following abstract descent criterion in a setting where the Legendrian-approximation/negative-stabilization theorem applies. Let $\mathcal L$ be Legendrian isotopy classes, $S_-$ negative stabilization, and $I:\mathcal L\to A$ an invariant satisfying \[ I(S_-L)=f(I(L)) \] for a fixed map $f:A\to A$. Let $A/{\sim}$ be the quotient by the smallest equivalence relation identifying $a$ with $f(a)$. Positive transverse push-off $T_+(L)$ then has the well-defined invariant \[ \overline I(T_+(L))=[I(L)]\in A/{\sim}. \] This uses the theorem that two Legendrian approximations give the same transverse class exactly when some negative stabilizations are Legendrian isotopic. The resulting invariant is complete precisely when \[ [I(L)]=[I(L')] \quad\Longrightarrow\quad S_-^mL\simeq S_-^{m'}L' \text{ for some }m,m'\geq0. \] The reverse implication is automatic. A quotient construction alone therefore provides descent, not completeness.

For classical Legendrian values $(t,r)=(\operatorname{tb},\operatorname{rot})$, use \[ S_-:(t,r)\mapsto(t-1,r-1),\qquad \operatorname{sl}(T_+(L))=\operatorname{tb}(L)-\operatorname{rot}(L). \] On the formal value lattice ${\mathbb{Z}}^2$, the coequalizer is exactly $t-r$; realizability restricts its image for a given knot type. The aid cites Etnyre--Honda representatives labelled $L_+$ and $S_+K_+$ in the $(2,3)$-cable of the positive trefoil. Their positive transverse push-offs both have self-linking $3$ but are not negative-stably Legendrian equivalent. Consequently any descended invariant factoring only through classical Legendrian data and the fixed smooth knot type fails to distinguish this pair. The individual representatives and cable convention require the original reference; no unstated $\operatorname{tb}$ or rotation values are invented. This is an incompleteness certificate, not a claim that every cited modern invariant distinguishes that pair.

Short English statement

The source asks for invariants detecting transverse non-simplicity. The aid reports several existing theories and gives a stabilization-quotient test for descent and completeness. Classical Legendrian data descend only to self-linking, which cannot distinguish the cited Etnyre--Honda pair with self-linking $3$.
