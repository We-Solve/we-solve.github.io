Verbatim supplied catalogue question

Given a parity-check matrix $H$, find the hidden Goppa code in $H$. How quickly can we decode $H$, assuming Goppa decoder for $H$ exists?

Attempt and results

We distinguish the public code, a hidden presentation, and a requested decoder. The source fixes neither a decoding radius nor equivalence of presentations. The following calculations test a presentation-recovery route and an exhaustive public decoding baseline, without claiming a new Goppa attack.
An explicit family of equivalent presentations.
Let $K$ be a finite extension of $\mathbb F_q$, let $L=(\alpha_1,\ldots,\alpha_n)$ have distinct entries in $K$, and let $g\in K[z]$ be monic of degree $d\ge1$ with $g(\alpha_i)\ne0$. Define the Goppa code here by \[ \Gamma_q(L,g)=\left\{c\in\mathbb F_q^n: \sum_i\frac{c_i}{z-\alpha_i}=0\pmod g\right\}. \] Inverses exist modulo $g$ because none of its roots is a locator. Let $D(z)=\prod_i(z-\alpha_i)$ and $F_c(z)=\sum_i c_i\prod_{j\ne i}(z-\alpha_j)$. Since $D$ is invertible modulo $g$, membership is equivalent to $g\mid F_c$. For any $a\in K^*$ and $b\in K$, set $\alpha'_i=a\alpha_i+b$ and $g'(z)=a^d g((z-b)/a)$, which is again monic and avoids the new locators. The corresponding numerator satisfies $F'_c(z)=a^{n-1}F_c((z-b)/a)$. Substitution is an invertible change of polynomial variable and all scalar factors are nonzero, so $g'\mid F'_c$ if and only if $g\mid F_c$. Thus these aligned, coordinate-preserving presentations define exactly the same code. Distinct parameter tuples in this family can therefore produce the same public code; recovering the planted tuple verbatim is not an intrinsically identifiable task without a normalization or equivalence rule. The calculation does not say that every equivalent presentation arises this way.
Unique bounded decoding is a property of the public code.
For any linear code $C=\ker H\subseteq\mathbb F_q^n$ and integer $t\ge0$, two errors $e,e'$ of Hamming weight at most $t$ with the same syndrome have $e-e'\in C$ and weight at most $2t$. Hence if every nonzero codeword has weight greater than $2t$, there is at most one such error per syndrome. Conversely, a nonzero $c\in C$ of weight at most $2t$ can have its support partitioned into sets $A,B$ of sizes at most $t$. Set $e=c$ on $A$ and zero elsewhere, and $e'=-c$ on $B$ and zero elsewhere. Then $e-e'=c$, so these distinct errors have the same syndrome. This proves the exact equivalence between uniform uniqueness up to radius $t$ and minimum distance greater than $2t$, with the zero code having infinite minimum distance. The partial map assigning the unique small error, where one exists, is thus determined by $H,t$ alone, independently of which hidden presentation supplies an efficient method of evaluating it.
A complete but exponential baseline and its first missing step.
Enumerate supports of size $j\le\min(t,n)$ and all nonzero values on each. There are $\sum_{j=0}^{\min(t,n)}\binom nj(q-1)^j$ candidates; test $He=s$ for each. This finds a small error or certifies none by exhaustion. It is polynomial for fixed $t$ and fixed $q$, but not an efficient arbitrary-radius algorithm. Given any aligned Goppa presentation and a correct decoder promised for that presentation and radius, applying that decoder to the corresponding code solves the public decoding problem. The missing implication is obtaining such a presentation or decoder from the mere promise of its existence. The affine ambiguity additionally shows why demanding one designated secret tuple is stronger than producing any valid aligned trapdoor.
