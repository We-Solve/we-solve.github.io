Exact Recovery by Lagrangian-Dual Binary Tomography

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\mathcal X$ denote the admissible class of binary images and let $\mathcal T$ denote the tomographic forward map for a given instance. For noiseless data $p$, define the feasible set by \[ \mathcal S(\mathcal T,p)=\{x\in\mathcal X:\mathcal T(x)=p\}. \] The instance has a unique binary solution if $\mathcal S(\mathcal T,p)=\{x_\ast\}$ for some $x_\ast\in\mathcal X$.

The supplied question asks whether, for every instance in the intended class, uniqueness of the binary solution guarantees that the proposed Lagrangian-dual approach retrieves $x_\ast$. If that approach defines a reconstruction map $\mathcal D$, the requested implication is schematically \[ \mathcal S(\mathcal T,p)=\{x_\ast\} \quad\Longrightarrow\quad \mathcal D(\mathcal T,p)=x_\ast. \] Here $\mathcal X$, $\mathcal T$, and $\mathcal D$ are placeholders for the intended image class, forward model, and reconstruction procedure; their definitions are not supplied. In particular, the record does not specify the binary values, image domain, acquisition geometry, boundary conditions, admissible operators, dual optimization problem, or reconstruction rule. Thus the displayed implication records the intended recovery question but is not a fully specified conjecture.

The supplied statement-verification note classifies this record as unrecoverable and describes it as a partial duplicate of the binary-tomography recovery conjecture retained under source code OWR-16766-003. It explicitly declines to promote a separate clean statement for this record. That related conjecture is not supplied here and cannot be substituted for this question.

Short English statement

For noiseless binary tomography, does a unique feasible binary image necessarily coincide with the reconstruction produced by the proposed Lagrangian-dual method? The method and its admissible instances are unspecified. The supplied registry retains this record for provenance as a partial duplicate, so this is a schematic statement requiring human mathematical review.
