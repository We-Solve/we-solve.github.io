$S^*$ is the set of finite concatenations of words from $S$, including the empty word. A factor is a contiguous substring; $\operatorname{Fact}(S^*)$ collects all such substrings and $\Sigma^*$ all finite alphabet words.

Statement recorded in the supplied source.
For a finite set $S$ of words over an alphabet $\Sigma$, where $\operatorname{Fact}(S^*)$ is the set of factors of $S^*$, is it decidable whether $\operatorname{Fact}(S^*)=\Sigma^*$, and what is the computational complexity of testing this equality? [S2]

Literature and context check

The original report on printed page 2224 describes decidability via automata and leaves the exact finite-word factor-universality complexity open at that time. A later primary check found Mika and Szykula's paper, arXiv:1902.06702v5 (JACM 2021), whose abstract explicitly states that this exact finite-set problem is PSPACE-complete. Only that abstract was consulted for the later classification, not its full hardness construction. The work below rederives a complete elementary upper-bound algorithm and a witness bound; it is not a new resolution or a reproof of the published lower bound.

Research attempt: A factor automaton and a polynomial-space decision procedure

An automaton that recognizes factors directly
Let $S$ be a finite list of words over a finite alphabet $\Sigma$. Discard empty words, which do not change $S^*$. Make a base state $q_0$; for each nonempty word of length $\ell$, attach a directed path labeled by that word from $q_0$ back to $q_0$, using $\ell-1$ new internal states unique to the word. A length-one word gives a loop. There are \[ N=1+\sum_{w\in S,\ |w|>0}(|w|-1) \] states. Paths from $q_0$ back to $q_0$ read exactly the concatenations in $S^*$. Now declare every state initial and every state accepting. The resulting nondeterministic automaton reads exactly $\operatorname{Fact}(S^*)$.

To prove the last assertion, a factor of a base-to-base path is a subpath between arbitrary states. Conversely every finite path between arbitrary states can be extended on its left and right to a base-to-base path, because every state lies on one of the word loops. The resulting label is a word of $S^*$ containing the original label as a factor. For $S$ empty, the lone base state and no labeled edges recognize only the empty word, as required. The empty alphabet is also allowed and makes its sole word, the empty word, accepted.

Subset reachability decides universality
A deterministic subset state records all possible current automaton states. Start at the full $N$-state set and, for a letter, take the union of its outgoing neighbors from those states. A word is a factor exactly when its resulting subset is nonempty. Thus universality is equivalent to the empty subset being unreachable. Breadth-first search on at most $2^N$ subsets is a finite decision algorithm. If a missing word exists, a shortest path to the empty subset has no repeated subset, because deleting the intervening cycle would give a shorter missing word. Therefore there is a missing word of length at most $2^N-1$.
A deterministic polynomial-space implementation
The exponential-size graph need not be stored. Subsets occupy $N$ bits and one-step adjacency can be computed from the given automaton. Define $R(U,V,j)$ to mean that there is a path of length at most $2^j$ from $U$ to $V$. At $j=0$ test equality or a single transition. For $j>0$, enumerate all $N$-bit subsets $W$ and accept exactly when some one satisfies both $R(U,W,j-1)$ and $R(W,V,j-1)$. The recurrence is valid by cutting a path at its midpoint; paths shorter than the allowance are covered because zero-length paths are allowed. Recursive calls are evaluated sequentially and their storage reused.

Calling this with $j=N$ covers every reachable vertex in the $2^N$-vertex graph. The recursion depth is $N$, and each stack frame stores a constant number of $N$-bit subsets, the enumeration counter, and its recursion index. Thus it uses $O(N^2)$ working bits, in addition to input and polynomial-size bookkeeping for transitions. Negating the reachability answer uses the same space. This proves membership in PSPACE directly, without assuming nondeterministic polynomial space equals deterministic polynomial space. The time bound of this particular recursive algorithm is not polynomial.

Boundary examples and the lower-bound gap
For $S=\{a,b\}$ over $\{a,b\}$, all words are factors. For $S=\{ab,ba\}$, all two-letter words occur, but $aaa$ does not: within a word the letters differ and an equal-letter run can cross only one word boundary, so it has length at most two. The all-states start condition is essential: a factor may begin in the middle of a dictionary word, and ordinary prefix universality is a different problem.

A PSPACE-hardness result for unrestricted NFAs cannot simply be transferred to these automata. Their edges are organized as internally disjoint word loops around one state. A reduction must realize the necessary behavior by a polynomial-size finite word list, preserving this representation constraint. That is the missing lower-bound construction in this attempted automaton route; the later paper reports a construction using set rewriting systems, but it is not reproduced here.

Verification and adversarial audit

The automaton proof treats factors beginning and ending inside words, ignores harmless empty words, and includes the empty dictionary and empty alphabet. The witness bound follows from deterministic subset-state nonrepetition. The space recursion permits zero-length paths and reuses memory between its two recursive tests. No exponential-state enumeration is mislabeled polynomial time.
