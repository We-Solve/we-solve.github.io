Kourovka Notebook Problem 20.95

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

A group $G$ is periodic if every element has finite order. An involution is an element of order $2$. The condition on subgroups of order $4$ is \[ \forall V\leq G,\qquad |V|=4\ \Longrightarrow\ V\text{ is cyclic}. \] A finite group $F$ is a finite Frobenius group if it has a nontrivial proper subgroup $C$ such that \[ C\cap x^{-1}Cx=\{1\}\qquad\text{for every }x\in F\setminus C. \] Using the usual subgroup-containment interpretation, $G$ is saturated with finite Frobenius groups if every finite subgroup $H\leq G$ is contained in a finite subgroup $F\leq G$ that is a Frobenius group. The supplied record does not explicitly define saturation.

The source asks: if $G$ is a periodic group saturated with finite Frobenius groups, contains an involution, and has no noncyclic subgroup of order $4$, must $G$ be a Frobenius group in the sense of Kourovka Notebook Problem 6.53?

The referenced definition in Problem 6.53 is not supplied. Under the convention that an arbitrary group is Frobenius when it contains a nontrivial proper malnormal subgroup, the precise conclusion would be \[ \exists C\leq G:\quad \{1\}\subsetneq C\subsetneq G \quad\text{and}\quad \forall g\in G\setminus C,\quad C\cap g^{-1}Cg=\{1\}. \] Thus the conditional formulation asks whether every group satisfying the stated hypotheses has such a subgroup $C$. This convention must be checked against Problem 6.53 before treating it as the source's exact intended conclusion. No finiteness or local finiteness assumption on $G$ is added.

Short English statement

Must every periodic group that is saturated with finite Frobenius groups, contains an involution, and has only cyclic subgroups of order $4$ be a Frobenius group? The source refers to Problem 6.53 for the intended meaning of Frobenius group; that definition is absent, so the explicit malnormal-subgroup formulation remains conditional.
