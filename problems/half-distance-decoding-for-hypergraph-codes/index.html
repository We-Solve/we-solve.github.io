Half-Distance Decoding for Hypergraph Codes

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

In the LOCAL model vertices communicate synchronously along graph edges; messages and local computation are unrestricted and complexity is the number of rounds. After $t$ rounds a vertex can depend only on its radius-$t$ neighborhood and any supplied identifiers or randomness.

A $k$-uniform hypergraph has edges that are $k$-element vertex subsets. A matching is a collection of pairwise disjoint edges. Its minimum $(k-1)$-codegree is the minimum number of edges containing a given $(k-1)$-subset.

A code $C\subseteq\Sigma^N$ is a set of permitted length-$N$ words. Its Hamming minimum distance is the minimum number of unequal coordinates of two distinct words. For a linear $[N,K,D]_q$ code, rate is $K/N$ and relative distance is $D/N$; decoding recovers a codeword from corrupted observations.

Statement recorded in the supplied source.
For the $t$-partite, $t$-uniform hypergraph codes defined from a local binary code and a regular expanding hypergraph, can one construct an efficient low-complexity decoder that corrects errors up to half the designed minimum distance for each fixed $t$? [S2]

Verbatim supplied catalogue question

For the $t$-partite, $t$-uniform hypergraph codes defined from a local binary code and a regular expanding hypergraph, can one construct an efficient low-complexity decoder that corrects errors up to half the designed minimum distance for each fixed $t$?

Source scope and attempted route

The report uses binary linear local codes $A\subseteq\{0,1\}^{\Delta}$ of minimum distance $d_0$, on regular $t$-partite, $t$-uniform hypergraphs. Its requested error radius is global, approximately one half of $N\delta_0^{t/(t-1)}$ after the expansion error term. We try the relaxation that keeps every local codeword convex hull. The following sufficient condition is proved for arbitrary such hypergraphs; it is more restrictive than the target.
Local inequalities and a complete sufficient decoding certificate.
Let $E(v)$ denote the $\Delta$ coordinates at vertex $v$, and define \[ P=\{z\in[0,1]^E:z_{E(v)}\in\operatorname{conv}(A)\text{ for all }v\}. \] Assume $d_0\ge1$. For every $e\in E(v)$ and every $z\in P$, \[ (d_0-1)z_e\le\sum_{f\in E(v)\setminus\{e\}}z_f. \] Indeed for a local codeword with coordinate $e=1$ its nonzero weight is at least $d_0$; for coordinate $e=0$ the inequality is automatic. Convex combinations preserve it. For an error set $F$, put $q_v=|F\cap E(v)|$. Summing this inequality over $e\in F\cap E(v)$ yields \[ d_0\sum_{e\in F\cap E(v)}z_e\le q_v\sum_{e\in E(v)}z_e. \] If every $q_v\le q<d_0/2$, sum over all vertices. Each coordinate belongs to exactly $t$ local constraints, so $\sum_{e\in F}z_e\le(q/d_0)\sum_ez_e$. If the transmitted codeword is zero and the received bits have support $F$, minimizing their relaxed Hamming distance amounts, up to a constant, to minimizing $L(z)=\sum_{e\notin F}z_e-\sum_{e\in F}z_e$ over $P$. Every nonzero feasible $z$ has \[ L(z)\ge(1-2q/d_0)\sum_ez_e>0=L(0). \] Thus zero is the unique optimum. For any transmitted codeword $c$, complement coordinate $e$ when $c_e=1$. On each local hull this affine transformation permutes its codeword vertices, because $A$ is linear and $c_{E(v)}\in A$. It preserves $P$ and transforms the objective into the zero-word instance. Hence the same condition certifies unique correct decoding for every $c$.
What the relaxation costs and why the certificate stops early.
An explicit extended formulation uses variables $\lambda_{v,a}\ge0$, $\sum_{a\in A}\lambda_{v,a}=1$, and $z_e=\sum_{a\in A}\lambda_{v,a}a_e$ in each local ordering. It has $O(|V||A|+tN)$ variables/constraints and coefficients of bounded size. For fixed $\Delta$ this is a linear-size rational linear program; a running-time claim for solving it uses the standard polynomial-time rational LP theorem, not a new algorithm proved here. If $\Delta$ varies, explicit enumeration of $A$ may be exponential in $\Delta$ and this must be charged. Even a globally small error set can have more than $d_0/2$ errors at one vertex. Once $N$ is large, an error set of constant size concentrated there can lie well below the requested global radius but fail this certificate. This shows that the proved implication is insufficient; it does not show that the LP fails on that set. Exploiting the report's expansion to certify all globally small sets, including these concentrated ones, is the missing step.
Why arbitrary local correction is not globally monotone.
Take the local repetition code $A=\{0^{\Delta},1^{\Delta}\}$, with $\Delta\ge3$, and a connected incidence structure. The global code is repetition: local equality propagates through incidence paths, so all edge bits agree. Put $q=\lfloor\Delta/2\rfloor+1<\Delta$ errors among the edges of a single vertex, and suppose $N>2\Delta$. The global word is within $N/2$ of zero. Nearest-local-codeword correction at that vertex chooses $1^{\Delta}$ uniquely and increases global distance to zero from $q$ to $\Delta$. The inequalities are direct since $\Delta-q<q$ and all coordinates changed lie at that vertex. No expansion claim for this example is required or asserted. It refutes only the proposed proof that each nearest-local update must decrease the unknown global error count. An actual iterative decoder needs a selection rule or a different potential and its expansion analysis.

Adversarial audit and gap

Both proofs use strict half-distance inequalities, avoiding ambiguity at a tie. The LP certificate assumes local error bounds; the source asks for a global bound. The local repetition example diagnoses a failed invariant, not an impossibility result for the expanding families. The numerical radii printed in the source were read as context and were not recomputed or asserted here as new theorems. The fixed-$t$ half-designed-distance question remains unresolved.
