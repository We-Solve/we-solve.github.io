Kourovka Notebook Problem 14.64

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For a group $G$, define its lower central series by $\gamma_1(G)=G$ and \[ \gamma_{i+1}(G)=[\gamma_i(G),G]\qquad(i\geq 1), \] where $[H,G]$ is the subgroup generated by $h^{-1}g^{-1}hg$ for $h\in H$ and $g\in G$. A nontrivial nilpotent group has nilpotency class $c$ if $\gamma_c(G)\neq\{1\}$ and $\gamma_{c+1}(G)=\{1\}$. Using the conventional definition, a finite $5$-group $G$ of order $5^n$, with $n\geq 2$, has maximal class when its nilpotency class is $n-1$.

Classification problem (M. F. Newman, as attributed in the statement). Classify, up to group isomorphism, all finite $5$-groups of maximal class. Equivalently, describe all isomorphism classes of groups $G$ satisfying \[ |G|=5^n,\qquad \gamma_{n-1}(G)\neq\{1\},\qquad \gamma_n(G)=\{1\},\qquad n\geq 2. \] Here classification is interpreted as classification up to isomorphism. The stated convention includes groups of order $25$; the source does not specify a lower-order cutoff.

The source says that computer calculations suggest some conjectures and refers to Newman's 1990 contribution, but it does not state those conjectures. They cannot be formulated separately from the supplied record. Newman's supplied comment of 2025 points to related work by Cant, Dietrich, Eick, and Moede (2022), without asserting that this classification problem is resolved. The registry labels the problem open; this is a supplied status, not an independently verified assessment. The registry proposer attribution to A. Moretó conflicts with the attribution to M. F. Newman in the statement.

Short English statement

Describe every finite group of order $5^n$ and nilpotency class $n-1$, up to isomorphism, using the convention $n\geq 2$. The source mentions computational conjectures and related work without specifying those conjectures or claiming a complete classification. Its proposer attributions conflict.
