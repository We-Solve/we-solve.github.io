Kourovka Notebook Problem 12.27

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

A group is locally finite if every subgroup generated by finitely many elements is finite. Let $G$ be a simple locally finite group. A permutation representation of $G$ on a set $\Omega$ is a homomorphism \[ \rho:G\longrightarrow\operatorname{Sym}(\Omega). \] Here a nontrivial permutation representation is interpreted as one for which $\rho(G)\ne\{\operatorname{id}_{\Omega}\}$. For a finite subgroup $H\le G$ and a point $\omega\in\Omega$, define \[ H_{\omega}=\{h\in H:\rho(h)(\omega)=\omega\}. \] The orbit $H\omega$ is regular if $H_{\omega}=\{1\}$, equivalently if $|H\omega|=|H|$.

Following the supplied source, $G$ is a group of finite type if there exist a set $\Omega$, a nontrivial permutation representation $\rho:G\to\operatorname{Sym}(\Omega)$, and a finite subgroup $H\le G$ such that \[ \forall\omega\in\Omega,\qquad H_{\omega}\ne\{1\}. \] Thus the restriction of the action to $H$ has no regular orbit.

Problem (Kourovka Notebook 12.27). Investigate and, if possible, classify the simple locally finite groups of finite type.

The source states an investigation and possible classification problem, rather than a specific conjectured classification. It imposes neither transitivity of the permutation action nor an explicit infinitude condition on $G$. It does not specify whether its convention for simple groups excludes cyclic groups of prime order; that convention requires review against the original source.

Short English statement

Investigate, and if possible classify, simple locally finite groups admitting a nontrivial permutation action in which some finite subgroup has a nontrivial stabilizer at every point. The source supplies no proposed classification and labels the problem open; that status is not independently verified.
