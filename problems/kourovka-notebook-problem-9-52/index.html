Kourovka Notebook Problem 9.52

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A group $G$ is soluble if its derived series, defined by $G^{(0)}=G$ and $G^{(i+1)}=[G^{(i)},G^{(i)}]$, satisfies $G^{(d)}=\{1\}$ for some integer $d\geq 0$. It is finitely presented if it admits a presentation $G=\langle X\mid R\rangle$ with both $X$ and $R$ finite. Interpret finite rank in the usual Prüfer sense: there is an integer $r\geq 0$ such that every finitely generated subgroup of $G$ can be generated by at most $r$ elements. The supplied record does not explicitly define its rank convention.

For a fixed finite presentation of $G$, the conjugacy problem is decidable if there exists an algorithm which, on every pair of words $u,v$ in the generators and their inverses, halts and decides whether \[ \exists x\in G\qquad x^{-1}\overline{u}x=\overline{v}, \] where $\overline{u},\overline{v}$ are the elements represented by the words.

Question. Does every finitely presented soluble group of finite rank have a decidable conjugacy problem? Here "soluble conjugacy problem" is read as algorithmic decidability. The formulation asks for an algorithm for each such group; the supplied record does not specify a uniform algorithm taking arbitrary presentations as additional input.

Supplied qualification. The source adds that there is an algorithm to decide conjugacy to a given element of the group. Read as a fixed-target assertion, this says that for each fixed $g\in G$, there exists an algorithm deciding, for every input word $u$, whether $\overline{u}$ is conjugate to $g$. The record does not specify effective uniformity in $g$; its note must therefore be distinguished from an algorithm receiving both elements as inputs.

Short English statement

Must every finitely presented soluble group of finite Prüfer rank admit an algorithm deciding whether any two input words represent conjugate elements? The supplied note asserts decidability for a fixed target element, without specifying uniformity in that target. The rank convention and algorithmic interpretation require human review.
