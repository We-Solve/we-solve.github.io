Similarity Metrics for Stochastic Processes

Definitions and mathematical statement

A stochastic process is a family $X=(X_t)_{t\in T}$ of random variables on a probability space, taking values in a measurable state space. The supplied record does not specify the index set $T$, state space, probability spaces, or any path regularity assumptions; these are placeholders, not recovered hypotheses.

For a specified set $\mathcal S$ of stochastic processes or their chosen representations, a metric is a function \[ d:\mathcal S\times\mathcal S\longrightarrow[0,\infty) \] satisfying, for every $X,Y,Z\in\mathcal S$, \[ \begin{gathered} d(X,Y)=0\iff X=Y,\qquad d(X,Y)=d(Y,X),\\ d(X,Z)\le d(X,Y)+d(Y,Z). \end{gathered} \] Here equality depends on the chosen objects: equality of representations, equality in law, and a behavioral equivalence such as bisimulation are different possibilities. If distinct representations may have distance zero, the corresponding construction is a pseudometric on representations and can be a metric on a suitable quotient.
