Math-1925

Unbounded outer-billiard orbits for almost every polygon

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $P\subset{\mathbb{R}}^2$ be a compact convex polygon with nonempty interior. For a point $x$ outside $P$ in the regular domain, choose a supporting tangent line with a fixed orientation convention and tangency vertex $v$. The outer-billiard map sends $x$ to $T_P(x)=2v-x$. Points on singular supporting rays, where the tangency choice is not unique, must be excluded or assigned a specified convention.

A forward orbit is defined if $T_P^k(x)$ avoids these singularities for every integer $k\geq0$. It is unbounded if \[ \sup_{k\geq0}\|T_P^k(x)\|_2=+\infty. \] The source conjecture says that for almost every convex polygon $P$ there exists such an unbounded orbit. This quantifier is existential in $x$; it does not assert that almost every orbit is unbounded.

A standard possible parameter convention fixes a number $n\geq3$ of vertices and uses Lebesgue measure on the open set of labelled, cyclically ordered strictly convex $n$-gons in $({\mathbb{R}}^2)^n$. With that convention, the target for an admissible $n$ would be that the polygons possessing an unbounded nonsingular orbit form a full-measure subset. The source does not specify the intended values of $n$ or a measure on polygon space. There is no canonical single Lebesgue measure on polygons of all numbers of vertices, so this convention and any exceptional polygon classes must be settled before a precise almost-everywhere statement can be asserted. Whether "orbit" means forward or two-sided is also not specified; the display above makes the forward interpretation explicit.

Short English statement

Does a typical convex polygon admit at least one unbounded outer-billiard orbit? The number of sides, measure on polygon space, and singular-orbit conventions need to be specified.
