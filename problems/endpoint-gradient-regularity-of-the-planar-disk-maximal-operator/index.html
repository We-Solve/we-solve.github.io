Endpoint gradient regularity of the planar disk maximal operator

OpenAI's claim

Endpoint gradient of disk maxima: The paper claims that the centered disk maximal function of a real $W^{1,1}(\mathbb R^2)$ function has an integrable weak gradient controlled by the original gradient. Local Sobolev membership of the maximal output is also included.

Mathematical statement of the claimed result

Mathematical claim 1.
For the centered disk maximal operator $Mf(x)=\sup_{r>0}(\pi r^2)^{-1}\int_{B(x,r)}|f(y)|\,dy$, every real $f\in W^{1,1}(\mathbb R^2)$ is claimed to satisfy $Mf\in W^{1,1}_{\mathrm{loc}}(\mathbb R^2)$ and \[\int_{\mathbb R^2}|\nabla Mf|\le C\int_{\mathbb R^2}|\nabla f|\] with an absolute constant. The distributional gradient is globally integrable; global $L^1$ integrability of $Mf$ is not claimed.

Outline of the argument

Endpoint gradient of disk maxima: Scalar cancellation is arranged across dyadic cells using common nonnegative prices with a total variation budget. A different path measure represents vector gradient masses and charges changes of direction in both space and scale. Averaging over direction histories assembles the radius bands while canceling the differentiated weight terms.
