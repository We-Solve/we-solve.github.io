Kourovka Notebook Problem 17.34

Statement

Definitions and mathematical statement

For a positive integer nilpotency-class bound $c$, let $N_c$ denote the class of torsion-free nilpotent groups of class at most $c$, called a quasivariety in the source. Explicitly, torsion-freeness means that $x^n=1$, for $n\geq 1$, implies $x=1$. Define the lower central series by $\gamma_1(G)=G$ and $\gamma_{i+1}(G)=[\gamma_i(G),G]$, where $[a,b]=a^{-1}b^{-1}ab$; the class bound means $\gamma_{c+1}(G)=\{1\}$. A subgroup $D\leq G$ is divisible if \[ \forall d\in D\;\forall n\in{\mathbb{Z}}_{\geq1}\;\exists e\in D:\quad e^n=d. \] Using the standard relative dominion definition, set \[ \operatorname{Dom}^{N_c}_G(D)= \left\{g\in G:\ \forall K\in N_c\;\forall\text{ group homomorphisms }f,h:G\to K,\quad f|_D=h|_D\Longrightarrow f(g)=h(g)\right\}. \] The question attributed to A. I. Budkin is whether, for every such $c$, every $G\in N_c$, and every divisible subgroup $D\leq G$, \[ \operatorname{Dom}^{N_c}_G(D)=D. \] Equivalently, must every $g\in G\setminus D$ admit a group $K\in N_c$ and homomorphisms $f,h:G\to K$ agreeing on $D$ but satisfying $f(g)\neq h(g)$?

The source leaves the integer range of $c$ implicit; the formulation above uses positive integers. If class zero is permitted, its additional case concerns only the trivial group. The source refers to Problem 16.20 for the dominion definition, but that definition is not included in the supplied record, so the standard definition used here requires comparison with that reference. The supplied registry labels this problem open and separately records an explicitly unverified AI claim of an affirmative solution; neither label establishes a mathematical conclusion.

Short English statement

Must every divisible subgroup of a torsion-free nilpotent group equal its dominion within the same nilpotency-class bound? In other words, can every element outside the subgroup be distinguished by two homomorphisms into another group in that class that agree on the subgroup? The supplied affirmative solution claim is explicitly unverified.
