Research attempt: The state requirement for independently toggled knowls

Model $n\ge1$ independently toggled panels. A state is the subset $S\subseteq\{1,\ldots,n\}$ of currently open panels; the observable output identifies exactly that subset. Toggling panel $i$ replaces $S$ by its symmetric difference with $\{i\}$. Starting from the empty subset, any subset is reachable by toggling each of its elements once. There are therefore $2^n$ reachable, observably distinct states.

Any deterministic emulator preserving these observations requires at least $2^n$ distinguishable internal states. Otherwise two distinct reachable subsets $S,T$ would correspond to the same emulator state by the pigeonhole principle. The emulator's current observable output is a function of its state and would be equal for those two histories, contradicting the required different visible subsets. If state is stored in $b$ binary bits with no other varying memory, it has at most $2^b$ possible values, so $2^b\ge2^n$ and $b\ge n$. An $n$-bit indicator vector achieves the bound: flip bit $i$ on action $i$ and display exactly the set of one bits.

A static fallback that opens every panel preserves the union of panel contents but not this interaction behavior. For $n=1$ it already merges the closed and open states, losing one observable distinction. A collection of static pages could represent all $2^n$ subsets, but then it pays for that many separate state representations; navigation semantics and link availability still need implementation. The lower bound is about the selected state model, not a claim that an EPUB file must literally contain exponentially many pages or that a scripting runtime cannot encode states compactly.
