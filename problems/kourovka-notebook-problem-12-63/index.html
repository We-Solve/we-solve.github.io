Kourovka Notebook Problem 12.63

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\Omega$ be an infinite set and let $G\leq\operatorname{Sym}(\Omega)$ be a permutation group, acting faithfully on $\Omega$. Define $G^{(0)}=G$ and $G^{(i+1)}=[G^{(i)},G^{(i)}]$, where $[H,H]$ denotes the subgroup generated by all commutators of elements of $H$. The group $G$ is soluble if $G^{(d)}=\{1\}$ for some finite integer $d\geq 0$.

For an integer $k\geq 1$, put \[ \Omega^{\langle k\rangle}=\{(\omega_1,\ldots,\omega_k)\in\Omega^k:\omega_i\neq\omega_j\text{ whenever }i\neq j\}. \] The diagonal action is \[ g\cdot(\omega_1,\ldots,\omega_k)=(g\omega_1,\ldots,g\omega_k). \] Write $G\backslash\Omega^{\langle k\rangle}$ for its set of orbits.

Problem (P. M. Neumann, 1992). Does there exist an infinite set $\Omega$ and a soluble subgroup $G\leq\operatorname{Sym}(\Omega)$ such that \[ \left|G\backslash\Omega^{\langle 3\rangle}\right|<\infty? \] Supplied conjecture. No such group exists; equivalently, every soluble permutation group on an infinite set has infinitely many orbits on triples. No countability, transitivity, or fixed bound on the derived length is assumed.

Qualification concerning triples. The supplied wording does not specify whether triples are ordered, unordered, or allowed to have repeated entries. We use ordered triples of distinct points. On an infinite set, finiteness of the number of orbits is equivalent for these three conventions, so this choice does not change the existence question.

Supplied comment of 2001. The record reports that D. Macpherson proved that every infinite soluble permutation group has infinitely many orbits on quadruples, citing the 1997 reference below. This is retained as a source-reported result, without independent verification; it does not settle the stated triples question.

Short English statement

Can a soluble group act faithfully on an infinite set with only finitely many orbits on triples of points? P. M. Neumann conjectured that the answer is no. The supplied record labels the problem open and includes a 2001 comment reporting an analogous result for quadruples.
