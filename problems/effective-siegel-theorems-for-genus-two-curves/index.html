Math-964

Effective Siegel Theorems for Genus-Two Curves

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The record leaves the curve model, the set $S$, and the convention for integrality implicit. Under the usual interpretation, let $k$ be a number field, let $C/k$ be a smooth, projective, geometrically integral curve of genus $2$, let $\phi\in k(C)\setminus k$, and let $S$ be a finite set of places of $k$ containing all archimedean places. These conventions make the intended question precise but require confirmation against the original source.

Define the ring of $S$-integers by \[ \mathcal O_{k,S}=\{a\in k: v(a)\geq 0\text{ for every nonarchimedean place }v\notin S\}. \] Let $D_\infty$ be the pole divisor of $\phi$, and interpret the points that are $S$-integral with respect to $\phi$ as \[ I(C,\phi,k,S)=\{P\in C(k)\setminus\operatorname{Supp}(D_\infty):\phi(P)\in\mathcal O_{k,S}\}. \] In particular, poles of $\phi$ are excluded, and the points considered are $k$-rational points.

Effectivity question. Is there a single algorithm which, for every such input $(k,C,\phi,S)$ given by effective finite descriptions, terminates and outputs exactly the set $I(C,\phi,k,S)$? The source also asks for an explicit bound for all these points. A precise height-bound version asks whether, given additionally an effectively specified projective embedding $\iota:C\hookrightarrow{\mathbb{P}}^N_k$, one can compute a finite bound $B$ from the input such that \[ h_{\iota}(P)\leq B\qquad\text{for every }P\in I(C,\phi,k,S), \] where $h_{\iota}$ is the absolute logarithmic projective Weil height induced by $\iota$. The source does not specify a height, an input representation, or a required form of the bound; this height formulation is an explicit interpretation of its alternative request, not a separately supplied formulation.

Short English statement

For every genus-two curve over a number field, nonconstant rational function, and finite set of allowed places, ask for an effective procedure to list all rational points where the function is finite and takes an $S$-integer value, or for a computable height bound on those points. The curve-model and integrality conventions above require source confirmation. The supplied record labels the problem open; this draft does not independently verify that status.
