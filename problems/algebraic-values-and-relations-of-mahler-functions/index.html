Algebraic Values and Relations of Mahler Functions

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For an integer $q\geq 2$ and a coefficient field $K\subseteq{\mathbb{C}}$, a convergent power-series germ $g$ at $0$ is called a $q$-Mahler function over $K$ if it satisfies an identity \[ \sum_{j=0}^{r}a_j(z)g(z^{q^j})=0, \qquad a_j(z)\in K(z), \] with the coefficients not all zero. A usual system presentation for a vector $F=(f_1,\ldots,f_m)^{\mathsf T}$ is \[ F(z)=A(z)F(z^q),\qquad A(z)\in\operatorname{GL}_m(K(z)). \] The supplied record does not specify $K$, the analytic hypotheses, or this precise system convention. These definitions provide a conditional framework, rather than additional hypotheses attributed to the source.

For this system convention, one usual meaning of a regular point $\beta$ is that neither $A$ nor $A^{-1}$ has a pole at any point $\beta^{q^k}$, for every integer $k\geq0$. Let $S$ be the set of algebraic points $\beta$ satisfying $|\beta|<1$, at which the specified function values exist and which are nonsingular in the intended sense. The record does not establish whether nonsingularity means this entire-orbit condition or only regularity at $\beta$. The boundary $|\beta|=1$ is excluded. The record does not exclude $\beta=0$, so zero must remain eligible whenever the chosen hypotheses permit it.

Requested determination, subject to these unresolved specifications. Given the vector of $q$-Mahler functions and an algebraic point $\alpha\in S$, determine, for a specified transcendental Mahler function $g$, the set \[ E(g;S)=\{\beta\in S:g(\beta)\in\overline{{\mathbb{Q}}}\}. \] Here the function $g$, its relationship to the given vector, and the base field relative to which it is transcendental must be specified; transcendence over $K(z)$ means that no nonzero polynomial in $K(z)[X]$ vanishes at $g$.

If the requested "value relations" mean polynomial relations with algebraic coefficients among the entries of $F(\alpha)$, their precise object is the ideal \[ I_{\alpha}(F)=\{P\in\overline{{\mathbb{Q}}}[X_1,\ldots,X_m]: P(f_1(\alpha),\ldots,f_m(\alpha))=0\}. \] If instead the target is to locate points realizing a specified relation $P$, the corresponding set is \[ Z_P(F;S)=\{\beta\in S:P(f_1(\beta),\ldots,f_m(\beta))=0\}. \] These are explicit possible meanings of the requested generalization. The source does not select between them, specify the allowed relations, or define what constitutes a determination procedure. Thus it does not supply a unique fully specified mathematical problem beyond this qualified formulation.

Short English statement

Determine which algebraic points strictly inside the unit disk give algebraic values of a transcendental Mahler function, subject to the intended nonsingularity condition, and determine the associated value relations. The coefficient field, the role of the given point $\alpha$, the meaning of nonsingularity, and the precise relation problem remain unspecified. The displayed sets and ideal express conditional interpretations requiring human mathematical review.
