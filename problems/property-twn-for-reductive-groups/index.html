Property (TWN+) for Reductive Groups

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

A number field is a finite field extension $F/{\mathbb{Q}}$. For each number field $F$, let $\mathcal R_F$ denote the class of reductive algebraic groups over $F$ intended by the cited source. Write $\operatorname{TWN}^{+}(G/F)$ for the assertion that $G$ satisfies the source's property $(\mathrm{TWN}+ )$; this notation names that property and does not define it.

Conjecture (as supplied). For every number field $F$ and every $G\in\mathcal R_F$, the group $G$ satisfies property $(\mathrm{TWN}+ )$. Symbolically, \[ \forall F\text{ a number field},\qquad \forall G\in\mathcal R_F,\qquad \operatorname{TWN}^{+}(G/F). \]

Unresolved formulation qualifications. The supplied record does not define property $(\mathrm{TWN}+ )$, its analytic objects, or its required estimates and quantifiers. It also does not specify the connectedness convention for reductive groups. Consequently, the display preserves the source's universally quantified conjecture but is not a self-contained formulation of its analytic content. The precise definition and group conventions require checking in the supplied references; no replacement definition is asserted here.

Short English statement

The conjecture asks whether every reductive group over every number field has property $(\mathrm{TWN}+ )$. The supplied record omits the definition of that property, so its precise analytic requirements remain unresolved. The record labels the problem partially solved; that label and the accompanying literature assessment are supplied curation, not independently verified conclusions.
