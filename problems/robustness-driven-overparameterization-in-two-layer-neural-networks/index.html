Robustness-Driven Overparameterization in Two-Layer Neural Networks

Statement

Definitions and mathematical statement

Shared notation.
Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.

For scalar output, a two-layer network has the form $f(x)=b_0+\sum_{j=1}^m a_j\sigma(w_j^{\mathsf T}x+b_j)$ for a chosen activation $\sigma$. Interpolation of data $(x_i,y_i)$ means $f(x_i)=y_i$ for every $i$. On a specified domain $D$, with specified input and output norms, $\operatorname{Lip}(f)=\sup_{x,y\in D,\,x\ne y}\|f(x)-f(y)\|/\|x-y\|$. A bound $\operatorname{Lip}(f)\le L$ controls output changes by $L$ times the input perturbation; any robustness conclusion must state these norms and the dataset assumptions.

Record scope and qualifications.
The catalogue title is retained as metadata. Named certificates, contracts, bounds or frameworks in that title are not asserted as results of the original source extract. Source-record limitation: The primary Bubeck--Li--Nagaraj result concerns most datasets and a neuron-count regime. The missing hypotheses are not supplied by the source extraction.
Statement recorded in the supplied source.
Does interpolation by a two-layer neural network with few parameters necessarily force the represented function to have a large Lipschitz constant, thereby making overparameterization necessary for robustness? [S2]

Ask whether fitting the training labels with a small two-layer network forces strong sensitivity to input perturbations.
