The cyclic group $\mathbb Z/n\mathbb Z$ uses addition modulo $n$. For a subset $A$, its sumset is $A+A=\{a+a':a,a'\in A\}$; summands need not be distinct. The decision input consists of $n$ and an encoding of $B\subseteq\mathbb Z/n\mathbb Z$. A positive instance has a subset $A$ whose sumset equals $B$ exactly, rather than merely containing it.

Statement recorded in the supplied source.
Given $B\subseteq\mathbb Z/n\mathbb Z$, is there an efficient algorithm that decides whether some $A\subseteq\mathbb Z/n\mathbb Z$ satisfies $B=A+A$? [S2]
Scope qualification.
The complexity depends on the source encoding of $B$ and $n$; explicit membership arrays and sparse binary-encoded lists have different input lengths. No encoding-independent polynomial-time claim is inserted.

Research attempt: Integer-to-cyclic recognition reduction with encoding control

Decision problems and encodings.
Let $q\geq1$ be an integer and let $B\subseteq\mathbb Z/q\mathbb Z$. The question is whether $B=A+A$ for some subset $A$, with addition modulo $q$. Consider either (i) $q$ in binary and the distinct canonical residues of $B$ in a binary list, or (ii) a membership array of length $q$. We prove NP-completeness under either encoding, using the stated external integer theorem. Thus a polynomial-time decision algorithm exists if and only if $\mathrm P=\mathrm{NP}$. This conclusion does not assert an unconditional separation of those classes.
Membership in NP.
The empty input set has the empty root. For a nonempty root choose $a_0\in A$. The injection $a\mapsto a+a_0$ maps $A$ into $B$, so $|A|\leq |B|$. A witness list therefore uses $O(|B|\log(q+1))$ bits. Computing all at most $|B|^2$ pair sums, reducing modulo $q$, removing repetitions and comparing with $B$ verifies the witness in polynomial time in either specified input length. This also covers $q=1$; there is no hidden demand for a witness of size $q$ under sparse encoding.
Normalization of integer instances.
Given a finite nonempty set $S\subseteq\mathbb Z$, put $s_0=\min S$. If $S=C+C$, then $s_0=2\min C$. Thus odd $s_0$ implies a NO instance. For even $s_0$ define $B=S-s_0$ and $M=\max B$. Then \[ S=C+C\quad\Longleftrightarrow\quad B=(C-s_0/2)+(C-s_0/2). \] Conversely any integer root $D$ of $B$ yields the root $D+s_0/2$ of $S$. Here $0\in B\subseteq[0,M]\cap\mathbb Z$ and $M\geq0$. An empty $S$ is mapped to a fixed YES instance, for example $(q,B)=(3,\varnothing)$. An odd minimum is mapped to the fixed NO instance $(3,\{0,1\})$. To verify the latter, a root has at most two elements by the injection just proved. A singleton has a singleton sumset. For two distinct residues $a,b$ modulo $3$, the three sums $2a,a+b,2b$ are distinct: equality of either adjacent pair implies $a=b$, and $2a=2b$ does also because $2$ is invertible modulo $3$. Hence its sumset has three elements.
The no-wrap lemma.
For a normalized input set use the odd modulus \[ q=2M+3. \] We claim that $B$ has an integer sumset root if and only if it has a root modulo $q$. The forward implication follows just by reducing an integer equality modulo $q$; distinct elements of $B\subseteq[0,M]$ remain distinct. For the reverse implication suppose $B=A+A$ modulo $q$. Because $0\in B$, choose $a,b\in A$ with $a+b=0$ modulo $q$. Let $r,s\in[0,q-1]$ be the canonical residues of $2a,2b$. Both belong to $B$, so $0\leq r,s\leq M$. Moreover $r+s=0$ modulo $q$ and $0\leq r+s\leq2M<q$. Therefore $r=s=0$. Since $q$ is odd, multiplication by $2$ is injective, and $a=b=0$ modulo $q$. We have proved $0\in A$. It follows that every canonical representative of $A$ is in $B$, using $a=0+a\in A+A$. All representatives of $A$ thus lie in $[0,M]$. Their ordinary pair sums lie in $[0,2M]\subset[0,q-1]$, so none wraps modulo $q$. The modular equality is consequently the ordinary integer equality $A+A=B$. This proves both directions.
Polynomial encoding bounds.
Subtracting $s_0$ and forming $q=2M+3$ increases the binary length of each integer by at most an additive constant relative to the largest input magnitude. The number of elements of $B$ is $|S|$ and the exceptional instances have constant size. The map is thus a polynomial-time many-one reduction for sparse binary lists. For membership arrays, arbitrary huge binary integer inputs would not give a polynomial-size output array. Instead compose directly with the external 3-SAT reduction whose integer interval has size $O(N^4)$. After normalization $M=O(N^4)$ and hence $q=O(N^4)$, so the whole membership array can be produced in polynomial time. The same theorem consequently proves NP-hardness for both encodings. Together with membership in NP this establishes the claimed classification, even with hardness restricted to odd $q$.
An exact algorithm and the failed shortcut.
For completeness there is an elementary exponential search with candidate set \[ H=\{a\in\mathbb Z/q\mathbb Z:2a\in B\}. \] Every root lies in $H$, since every self-sum must belong to $B$. For each $b\in B$, the congruence $2a=b\pmod q$ has at most two solutions, computable by the Euclidean algorithm (one for odd $q$). Thus $|H|\leq2|B|$. Enumerating subsets of $H$ and checking pair sums is a finite exact algorithm. The necessary condition $A\subseteq H$ does not itself identify the root, and checking $H+H=B$ is not a correct recognition algorithm: for $q=7$ and $B=\{0,1,2\}$ the root $A=\{0,1\}$ works, but $H=\{0,1,4\}$ contains $4$ and $H+H$ contains $4\notin B$. The hardness classification concerns arbitrary inputs, not the termination of this exponential algorithm or the possibility of useful special-case algorithms.

Verification and adversarial audit

The reverse implication was checked at its two essential points: $0\in B$ alone does not imply $0\in A$ in a general cyclic group, and an arbitrarily large modulus alone does not prevent a modular root from having large representatives. The doubled-residue argument proves both claims using oddness and $2M<q$. For example the use of oddness cannot simply be erased: modulo $2$, the set $A=\{1\}$ has $A+A=\{0\}$ without containing $0$. The cases $S=\varnothing$, $M=0$, odd negative minima, $q=1$ in the verification problem, singleton roots and sparse witness size were separated explicitly. The dense encoding proof uses the external polynomial-interval theorem, not an unjustified expansion of arbitrary binary integers into an array.
