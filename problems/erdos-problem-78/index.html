Statement

For $k\ge 2$, let $R(k)$ be the diagonal Ramsey number as in Problem #77. The task asks:

Find a constant $C>1$ and give a constructive (explicit) proof that $R(k)>C^k$ for all sufficiently large $k$ (or for all $k$).

Ambiguity: "constructive" can mean at least three inequivalent things:

  • (Explicit family) A closed-form description of a graph $G_k$ on at least $C^k$ vertices with $\omega(G_k),\alpha(G_k)<k$.
  • (Polynomial-time algorithm) A deterministic algorithm that on input $k$ outputs such a graph in time poly$(|V(G_k)|)$.
  • (Brute-force constructible) Any deterministic finite procedure (possibly exponential time) that outputs such a graph.
The problem text's "equivalently" phrasing indicates the first or second meaning: an explicit construction of a Ramsey graph on $n$ vertices with both clique number and independence number $O(\log n)$.

Restatement from Math-5482-A3 r1, with the source manuscript’s qualifications.

Erdős Problem 78 --- Round 2

1) ROUND-2 OBJECTIVE

I pursue path (C): isolate and prove the fatal obstruction in the wording of Problem #78. Round 1 already identified the undefined word "constructive" as the main gap. In this round I will prove two precise claims:

  1. the optional strengthening "for all $k$" is actually false for every constant $C>1$;
  2. if "constructive" is interpreted in the weakest natural uniform sense ("there exists a deterministic algorithm which eventually outputs a witness graph"), then the "for all sufficiently large $k$" version is already trivial.
Thus the original wording does not isolate the intended open problem. The correct nontrivial version must explicitly forbid brute-force search, for example by asking for an explicit family or an output-size-polynomial-time deterministic algorithm.

2) Round-1 FOUNDATION USED

I use the following specific Round-1 results.

  1. Round-1 Lemma 78.1: for every $n,k$, one has $R(k)>n$ if and only if there exists a graph on $n$ vertices with both $\omega(G)<k$ and $\alpha(G)<k$.
  2. Round-1 Lemma 78.2: there is an explicit graph on $(k-1)^2$ vertices with $\omega(G)=\alpha(G)=k-1$, hence $R(k)>(k-1)^2$.
  3. Round-1 Lemma 77.2: for every $k\ge 9$, one has $R(k)>2^{k/2}$.
  4. Round-1 computation: explicit small witnesses such as $C_5$ and $3K_3$ were verified.
I will not re-prove any of these; I only use them.

3) NEW INSIGHT / TOOL (ROUND-2)

The new insight is a logical one, but it has concrete mathematical content.

  • A single fixed constant, for example \[ C=\frac54, \] combined with Round-1 Lemmas 77.2 and 78.1, already gives a deterministic exhaustive-search algorithm that outputs a witness graph on at least $C^k$ vertices for every $k\ge 9$.
  • Therefore the phrase "constructive proof" cannot be allowed to mean merely "some deterministic finite search procedure", because under that interpretation the problem is already solved.
  • On the other hand, the stronger wording "for all $k$" is impossible because the case $k=2$ blocks every $C>1$.

So Round 2 turns the Round-1 ambiguity into a theorem: the original wording is simultaneously too strong in one place (the all-$k$ variant is false) and too weak in another (the weak constructive reading is vacuous).

4) ATTACK PLAN (ROUND-2)

The exact unresolved issue after Round 1 was this: the phrase "constructive proof" had been listed as ambiguous, but no rigorous consequence of that ambiguity had been proved.

I now prove the following precise claims.

  1. Claim A. No constant $C>1$ can satisfy the demand "for all $k$".
  2. Claim B. Under the weakest uniform interpretation of "constructive", the "for all sufficiently large $k$" version is already settled affirmatively.
  3. Claim C. Hence the original statement is not well-posed: to obtain a meaningful problem one must replace "constructive" by a stronger requirement (explicit closed-form family, or deterministic algorithm running in time polynomial in the output size), and one must keep the quantifier "for all sufficiently large $k$" rather than "for all $k$".

This overcomes the Round-1 obstacle because it converts the informal ambiguity into a rigorous obstruction/correction theorem.

5) WORK (ROUND-2)

Fast reality check (deterministic search on a toy case). I implemented the lexicographic exhaustive search over all graphs on $n$ vertices and checked the condition $\omega(G),\alpha(G)<3$. The exact outcomes are:

  • on $n=4$ vertices there are exactly $18$ such graphs; the lexicographically first one has edge set \[ \{03,12\}; \]
  • on $n=5$ vertices there are exactly $12$ such graphs; the lexicographically first one has edge set \[ \{03,04,12,14,23\}. \]
So the brute-force search branch below is not merely formal: on tiny inputs it behaves exactly as expected.

Definition 78.3 (weak constructive interpretation). For the purposes of this round, call a statement of the form

"there is a constructive proof that for all sufficiently large $k$ there exists a graph $G_k$ with property $P(k)$"
weakly constructive if it only means:
there exists a deterministic algorithm $A$ such that, for every sufficiently large $k$, the algorithm halts and outputs a graph $G_k$ satisfying $P(k)$.
No complexity bound is imposed.

Lemma 78.3 (the "for all $k$" variant is false). There is no constant $C>1$ such that, for every $k\ge 2$, there exists a graph on at least $C^k$ vertices with both $\omega(G)<k$ and $\alpha(G)<k$.

Proof. Assume for contradiction that such a constant $C>1$ exists. Apply the claim at $k=2$. Then there should exist a graph $G$ on at least $C^2$ vertices with \[ \omega(G)<2\qquad\text{and}\qquad \alpha(G)<2. \] Since $C>1$, we have $C^2>1$, so any graph on at least $C^2$ vertices must have at least $2$ vertices. Pick two distinct vertices $u,v$ of $G$. Exactly one of the following holds:

  • $uv\in E(G)$, in which case $\{u,v\}$ is a clique of size $2$, contradicting $\omega(G)<2$;
  • $uv\notin E(G)$, in which case $\{u,v\}$ is an independent set of size $2$, contradicting $\alpha(G)<2$.
Both alternatives are impossible. Therefore no such constant $C>1$ exists. $\square$

Lemma 78.4 (Round-1 bounds force witnesses at size $\lceil(5/4)^k\rceil$ for $k\ge 9$). For every integer $k\ge 9$, \[ \left\lceil\left(\frac54\right)^k\right\rceil < R(k). \] Equivalently, for every $k\ge 9$ there exists a graph on \[ N_k:=\left\lceil\left(\frac54\right)^k\right\rceil \] vertices with $\omega(G)<k$ and $\alpha(G)<k$.

Proof. By Round-1 Lemma 77.2, \[ R(k)>2^{k/2}\qquad (k\ge 9). \] So it is enough to show that \[ \left\lceil\left(\frac54\right)^k\right\rceil < 2^{k/2} \qquad (k\ge 9). \] Since $\lceil x\rceil\le x+1$ for every real $x$, it suffices to prove \[ \left(\frac54\right)^k+1<2^{k/2}. \] Now \[ \frac{2^{k/2}}{(5/4)^k}=\left(\frac{4\sqrt2}{5}\right)^k. \] Because $\sqrt2>11/8$, we have \[ \frac{4\sqrt2}{5}>\frac{4\cdot(11/8)}{5}=\frac{11}{10}. \] Hence for every $k\ge 9$, \[ \frac{2^{k/2}}{(5/4)^k}>\left(\frac{11}{10}\right)^k\ge \left(\frac{11}{10}\right)^9 =\frac{2357947691}{10^9}>2. \] Therefore \[ 2^{k/2}>2\left(\frac54\right)^k\ge \left(\frac54\right)^k+1, \] because $(5/4)^k\ge 1$. So indeed \[ \left\lceil\left(\frac54\right)^k\right\rceil \le \left(\frac54\right)^k+1 < 2^{k/2} < R(k). \] The existence of a graph on $N_k$ vertices with $\omega,\alpha<k$ then follows from Round-1 Lemma 78.1. $\square$

Theorem 78.5 (under the weak constructive interpretation, the sufficiently-large-$k$ statement is already solved). Under Definition 78.3, Problem #78 has an affirmative answer. More precisely, for all $k\ge 9$ there is a deterministic algorithm which outputs a graph $G_k$ on at least $(5/4)^k$ vertices with \[ \omega(G_k)<k\qquad\text{and}\qquad \alpha(G_k)<k. \]

Proof. Fix $k\ge 9$ and set \[ N_k:=\left\lceil\left(\frac54\right)^k\right\rceil. \] Consider the following deterministic algorithm.

  1. Enumerate all simple graphs on vertex set $[N_k]=\{1,2,\dots,N_k\}$ in lexicographic order of their edge-indicator bitstrings.
  2. For each graph $H$ in that order, test whether $H$ contains a clique of size $k$ or an independent set of size $k$.
  3. Output the first graph for which both tests fail.
The algorithm is finite because there are only \[ 2^{\binom{N_k}{2}} \] graphs on the vertex set $[N_k]$, and for each graph there are only finitely many $k$-subsets to test.

By Lemma 78.4 we have $N_k<R(k)$. Therefore, by Round-1 Lemma 78.1, some graph on $N_k$ vertices satisfies \[ \omega(H)<k\qquad\text{and}\qquad \alpha(H)<k. \] Since the search scans every graph on $[N_k]$, it must eventually encounter such a graph and halt. The output graph $G_k$ has exactly $N_k$ vertices, hence at least $(5/4)^k$ vertices, and it satisfies $\omega(G_k),\alpha(G_k)<k$.

Thus, with the weak interpretation of "constructive", the problem is already solved with the explicit constant $C=5/4$. $\square$

Corollary 78.6 (fatal obstruction and corrected statement). Problem #78, as written in Round 1, is not mathematically well-posed. Indeed:

  1. if one reads it with the optional strengthening "for all $k$", it is false by Lemma 78.3;
  2. if one reads "constructive" in the weak sense of Definition 78.3, then the "for all sufficiently large $k$" version is already trivial by Theorem 78.5.
A clean corrected version is therefore:
Find a constant $C>1$ and a deterministic algorithm running in time polynomial in the output size which, for every sufficiently large $k$, outputs the adjacency matrix of a graph $G_k$ on at least $C^k$ vertices with $\omega(G_k),\alpha(G_k)<k$.
An equivalent strong formulation is to require a genuinely explicit closed-form family $G_k$ rather than an arbitrary exhaustive search.

Proof. The two bullets follow immediately from Lemma 78.3 and Theorem 78.5. The quoted corrected statement removes both defects simultaneously:

  • it keeps the only viable quantifier, namely "for every sufficiently large $k$";
  • it forbids the vacuous exhaustive-search interpretation by imposing an output-size complexity bound (or, equivalently in spirit, by demanding a genuinely explicit family).
So this corrected version captures the intended nontrivial content of the problem. $\square$

6) ADVERSARIAL VERIFICATION

I now try to break the new round-2 argument.

(a) Quantifier trap: did I accidentally prove something only for infinitely many $k$ rather than all sufficiently large $k$? No. Lemma 78.4 is proved for every integer $k\ge 9$, and Theorem 78.5 uses exactly that threshold. So the weak constructive statement holds uniformly for all sufficiently large $k$.

(b) Integer-size issue: is "at least $C^k$ vertices" compatible with taking $N_k=\lceil C^k\rceil$? Yes. The output graph has exactly $N_k$ vertices, and by definition $N_k\ge C^k$. The proof of Lemma 78.4 explicitly handles the ceiling.

(c) Hidden use of an oracle: does the algorithm need to know $R(k)$? No. The algorithm never computes $R(k)$. It only uses the a priori theorem $N_k<R(k)$ to justify that a witness graph exists somewhere in the finite search space. The actual procedure is a fully explicit deterministic enumeration.

(d) Dependence on Round-1: did I use any unproved external theorem? No. The only nontrivial existence input is Round-1 Lemma 77.2, which was already proved in the previous round. The translation from Ramsey colourings to graphs is Round-1 Lemma 78.1.

(e) Is the corrected statement really the minimal correction? Strictly speaking there is no unique canonical formalization of "constructive." What has been proved is the necessary content of any meaningful correction:

  • the phrase "for all $k$" must be dropped (or at least the statement must start at $k\ge 3$);
  • brute-force exhaustive search must be excluded by requiring either explicit closed-form structure or a genuine resource bound such as polynomial time in the output size.
So while the exact formalization is not unique, the obstruction itself is sharp and rigorous.

(f) Could the toy computation conceal a pathology? No. The computation is not used in any proof. It only confirms that the exhaustive-search construction behaves as stated in tiny cases.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED)

Round 2 establishes a genuine obstruction/correction theorem for Problem #78:

  1. the variant "for all $k$" is false for every $C>1$ (Lemma 78.3);
  2. the variant "for all sufficiently large $k$" is already trivial if "constructive" means merely "deterministic finite search" (Theorem 78.5);
  3. therefore the problem is not well-posed as stated, and the meaningful corrected version must demand an explicit family or an output-size-polynomial-time deterministic construction.

What remains unresolved is precisely that corrected strong version.

Erdős Problem #78: independent continuation

Date: 2026-09-23. Research attempt; no claim of a new published result.

1) TARGET AND SOURCE AUDIT

Find an explicit exponential lower-bound construction for diagonal Ramsey numbers: for some $C>1$ and all sufficiently large $k$, construct a graph with at least $C^k$ vertices and no clique or independent set of size $k$.

All supplied versions considered: 78.tex. The source correctly separates unbounded exhaustive search from efficient construction, but calling the intended problem ill-posed does not solve it. Polynomial-time output and a closed formula are not equivalent formal requirements. I improve its exhaustive search to a standard conditional-expectation algorithm, while making the remaining complexity gap explicit.

2) WORK

Let $n=\lfloor2^{k/3}\rfloor$, and let $X$ count homogeneous $k$-subsets of a uniformly random graph. Then \[ \mathbb E X=2\binom nk2^{-\binom k2}\le2^{1-k^2/6+k/2}<1\qquad(k\ge6). \] Expose edges one at a time. Given any partial assignment, the conditional expectation is computable by summing over all $k$-subsets: a subset already containing both an edge and a nonedge contributes zero; a monochromatically assigned subset contributes the appropriate probability $2^{-u}$ for its $u$ unassigned internal edges; a completely unassigned subset contributes $2^{1-\binom k2}$. Of the two possible values of the next edge, at least one has conditional expectation at most the current one, since their average equals the current expectation. Choose that value. At the end $X$ is a nonnegative integer below one, so $X=0$.

The naive implementation takes $O(n^2\binom nk k^2)$ rational-arithmetic operations, with $O(k^2)$-bit probability denominators (and polynomially bounded total bit lengths). Since $k=\Theta(\log n)$ this is $\exp(O((\log n)^2))$, much smaller than enumerating $2^{\binom n2}$ graphs. Also $n\ge2^{k/4}$ for $k\ge12$, so the output has the desired exponential size.

3) ADVERSARIAL VERIFICATION

The final algorithm is deterministic and terminates, but its displayed running time is quasipolynomial, not polynomial in $n$. Choosing a low-expectation branch does not magically make the sum over all $k$-sets cheap. The construction is a standard derandomization, not a new Ramsey theorem.

4) FINAL

UNRESOLVED. An efficient explicit exponential construction in the intended strong sense remains unproved. The exact remaining algorithmic obstacle here is evaluating a suitable pessimistic estimator in polynomial time.

5) SOURCES CHECKED

Full source 78.tex read; Attempted retrieval of the formal-conjectures ErdosProblems/78.lean statement URL on 2026-09-23 failed; no external fact is attributed to that unavailable page. The probabilistic and algorithmic argument is proved above without importing a Ramsey bound.

Ambiguity: "constructive" can mean at least three inequivalent things:

The problem text's "equivalently" phrasing indicates the first or second meaning: an explicit construction of a Ramsey graph on $n$ vertices with both clique number and independence number $O(\log n)$.

I also include a computational sanity check on small instances.

4) WORK.

Fast reality check (tiny $k$ explicit examples).

  • For $k=3$, the cycle $C_5$ on $5$ vertices has $\omega(C_5)=2$ and $\alpha(C_5)=2$, so it avoids both a triangle and an independent triple. A script confirms $\omega=\alpha=2$.
  • For $k=4$, the disjoint union of three triangles ($3K_3$) has $n=9$ and $\omega=\alpha=3$ (verified by script).

Lemma 78.1 (Graphs vs. 2-colourings; equivalence of formulations). Let $n,k\in\mathbb{N}$ with $k\ge 2$.

  • If there exists a red/blue colouring of $E(K_n)$ with no monochromatic $K_k$, then there exists a graph $G$ on $n$ vertices with $\omega(G)<k$ and $\alpha(G)<k$.
  • Conversely, if there exists a graph $G$ on $n$ vertices with $\omega(G)<k$ and $\alpha(G)<k$, then there exists a red/blue colouring of $E(K_n)$ with no monochromatic $K_k$.
In particular, $R(k)>n$ if and only if there exists a graph on $n$ vertices with $\omega,\alpha<k$.

Proof. Given a 2-colouring of $E(K_n)$, define $G$ to be the graph on the same vertex set whose edges are exactly the red edges. Then a red $K_k$ in the colouring is precisely a clique of size $k$ in $G$. A blue $K_k$ in the colouring means that all edges among some $k$-set are blue, i.e. those $k$ vertices form an independent set of size $k$ in $G$ (since none of the edges among them are red).

Thus, "no monochromatic $K_k$" is equivalent to "$G$ has no clique of size $k$ and no independent set of size $k$", i.e. $\omega(G)<k$ and $\alpha(G)<k$. The converse direction is the same implication read backwards (colour edges of $G$ red and non-edges blue). $\square$

Lemma 78.2 (Explicit polynomial lower bound $R(k)>(k-1)^2$). For every integer $k\ge 2$ there is an explicit graph on $(k-1)^2$ vertices with \[ \omega(G)=k-1\quad\text{and}\quad \alpha(G)=k-1. \] Consequently, \[ R(k)>(k-1)^2\qquad (k\ge 2). \]

Proof. Let $s:=k-1$ and form $G$ as the disjoint union of $s$ copies of the clique $K_s$. Then $|V(G)|=s\cdot s=s^2=(k-1)^2$.

Any clique in $G$ lies entirely within one component (different components have no edges between them), so $\omega(G)=s=k-1$.

Any independent set in $G$ contains at most one vertex from each clique component (because within a clique all vertices are adjacent), so $\alpha(G)=s=k-1$ (achieved by choosing one vertex from each component).

Therefore $G$ contains neither a clique nor an independent set of size $k$. By Lemma 78.1 this implies there exists a 2-colouring of $K_{(k-1)^2}$ with no monochromatic $K_k$, so $R(k)>(k-1)^2$. $\square$

5) VERIFICATION.

  • The equivalence in Lemma 78.1 is exact and uses only the definitions of clique/independent set and colouring.
  • Lemma 78.2 construction was sanity-checked computationally for $k=3,4,5$: $C_5$ has $(\omega,\alpha)=(2,2)$; $3K_3$ has $(3,3)$; $4K_4$ has $(4,4)$.
  • The lemma yields only a polynomial bound; it does not approach $C^k$.

6) FINAL.

UNRESOLVED

(i) Strongest proved partial result: An explicit construction gives $R(k)>(k-1)^2$ for all $k\ge 2$ (Lemma 78.2). Also, the exact equivalence between the Ramsey formulation and explicit Ramsey graphs is proved (Lemma 78.1).

(ii) First gap (crisp): Produce, for some constant $C>1$, an explicit family $G_k$ with $|V(G_k)|\ge C^k$ and $\omega(G_k),\alpha(G_k)<k$ (or any explicit algorithm with that guarantee).

(iii) Top 3 next moves (concrete):

  1. Try to derandomize the probabilistic method from Problem #77 to yield a deterministic polynomial-time construction; a concrete target lemma is: "there exists an explicit $\varepsilon$-biased (or $t$-wise independent) distribution on edge-colourings such that the union bound still works for $k$-cliques."
  2. Search for an algebraic graph family where one can prove $\omega,\alpha\le c\log n$ using only elementary estimates (e.g. spectral/eigenvalue methods plus explicit eigenvalue bounds).
  3. Computation: for small $k$ (say $k\le 6$), attempt to algorithmically construct near-Ramsey graphs and look for structural patterns that might suggest a scalable deterministic rule.

(iv) Minimal counterexample structure (to the desired constructive statement): a "barrier" would be that every explicit candidate family $G_k$ of size $\exp(\Theta(k))$ necessarily has either a clique or independent set of size $\Omega(k)$, i.e. fails pseudorandomness at the $\log n$ scale. Any such barrier would likely manifest via an efficiently checkable structural property forced by explicitness (e.g. low description complexity) that can be exploited to find large homogeneous sets.
