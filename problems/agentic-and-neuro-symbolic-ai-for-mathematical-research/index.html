Research attempt: A complete bounded Horn research loop with explicit certificates

Let $U$ be a finite set of $N$ propositional atoms, $F\subseteq U$ initial facts, and a finite set of Horn rules $P\to a$ with $P\subseteq U$, $a\in U$. Empty premises are allowed. Form a closure by starting with $C=F$ and repeatedly adding the head of any rule whose premises are all in $C$. Each effective addition increases $|C|$, so there are at most $N$ additions. At termination every rule with all premises in $C$ has its head in $C$.

The final set is independent of the order and exactly characterizes entailment of atomic goals. Every model of the facts and rules contains each newly added atom, by induction over additions. Conversely, the truth assignment making exactly $C$ true satisfies the facts and every rule: if its premises are true they lie in $C$, and closure places the head in $C$. Thus a goal $a$ is entailed if and only if $a\in C$. If it is, recording the rule and previously recorded premises at the first insertion gives an acyclic readable proof. If it is not, the assignment $C$ is an explicit countermodel.

A queue implementation is linear in the input incidence size. For each rule store a counter of premises not yet true and, for each atom, a list of rules containing it. Insert facts once, decrement a counter when its previously false premise first becomes true, and enqueue the head when the counter reaches zero. Each atom is inserted at most once, every premise incidence is processed at most once, and every rule is activated at most once. Initialization includes all rules and atoms, so the bound is \[ O\left(N+\#\text{rules}+\sum_{P\to a}|P|\right). \] Duplicate premises are removed in the set representation. Empty-premise rules are activated at initialization.

Role and limit of a learned proposer.
An untrusted learned component may prioritize enabled rules or propose short derived lemmas, provided every insertion is verified against already accepted facts. Soundness remains the induction above. Completeness additionally requires the queue to process every enabled rule eventually; a heuristic that indefinitely revisits an unproductive rule need not find an existing derivation. A fallback queue provides this guarantee in the finite fragment.

For example, rules $p\to q$ and $q\to p$ with no facts do not prove either atom. A purported circular derivation citing each as the other's support is invalid; the closure is empty and its all-false assignment is a model. With fact $p$, the rule $p\to q$ gives a valid one-step proof of $q$. This example shows why merely assembling mutually supportive generated lemmas is not a proof certificate. The finite rule/atom universe makes termination possible here; a mathematical research system generating new definitions and conjectures need not remain in such a bounded closure.
