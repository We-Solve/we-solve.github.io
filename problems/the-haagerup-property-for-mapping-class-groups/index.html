Math-4815

The Haagerup Property for Mapping Class Groups

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a surface $S$, a mapping class group is a group of homeomorphisms of $S$ modulo isotopy, with the same prescribed orientation, boundary, and marked-point conditions imposed on homeomorphisms and isotopies. Write this group as $\operatorname{Mod}(S)$ once those conditions have been specified. The supplied record does not specify the class of surfaces or these conditions.

For a countable discrete group $G$, the Haagerup property means that there exist a real Hilbert space $\mathcal H$, an orthogonal representation $\pi:G\to O(\mathcal H)$, and a map $b:G\to\mathcal H$ satisfying \[ b(gh)=b(g)+\pi(g)b(h)\qquad(g,h\in G), \] such that \[ \#\{g\in G:\|b(g)\|\le R\}<\infty \qquad\text{for every }R\ge0. \] Equivalently, $G$ admits a metrically proper affine isometric action on a real Hilbert space, given by $g\cdot v=\pi(g)v+b(g)$.

Source question. To what extent do mapping class groups have the Haagerup property? Under the countable discrete interpretation just defined, the mathematical task is to determine for which intended surfaces $S$ and mapping class group conventions such a pair $(\pi,b)$ exists for $G=\operatorname{Mod}(S)$. This is a classification question, not an assertion that every mapping class group has the property. A fully quantified surface classification cannot be extracted from the supplied record: the surface class, boundary and marked-point conventions, and intended scope of "to what extent" remain unspecified. The countable discrete interpretation is explicitly a convention for this draft, not a hypothesis stated in the source.

Short English statement

Determine which mapping class groups admit a metrically proper affine isometric action on a Hilbert space. The supplied question leaves the surfaces and mapping class group conventions unspecified, so its precise classification scope requires review. The supplied registry labels the problem open; this draft does not independently verify that status.
