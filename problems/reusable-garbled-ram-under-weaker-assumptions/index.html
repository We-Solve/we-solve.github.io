Reusing a mask leaks a persistent-state transition

The source asks for reusable garbled RAM and persistent databases under weaker assumptions. We test a restricted proposed implementation: encrypt one persistent bit by XOR with the same one-time pad at every update. This is not claimed to be a full garbled-RAM construction. Start with memory $m_0=0$, choose a uniform secret bit $K$, and expose $c_0=m_0\oplus K$. Compare two one-write histories, both accessing the same address and returning the same public output 0: one writes $m_1=0$, the other writes $m_1=1$. Expose $c_1=m_1\oplus K$.
Proposition: The exposed ciphertext histories distinguish these two cases perfectly. With independent fresh uniform pads for the two exposures, the ciphertext pair alone has the same distribution for both histories.
Proof: For the reused pad, $c_0\oplus c_1=m_0\oplus m_1=m_1$. Equivalently, equality of the two exposed bits occurs with probability 1 in the first history and 0 in the second. For independent pads $K_0,K_1$, any fixed pair $(c_0,c_1)$ arises from exactly one pad pair $(m_0\oplus c_0,m_1\oplus c_1)$, whose probability is $1/4$ irrespective of $m_1$. Thus both ciphertext-pair distributions are uniform. ∎
The first observation blocks a direct reuse-of-one-time-randomness route even when the address pattern and public output reveal no difference. The second identifies a local repair but does not make it a reusable garbling: maintaining pad updates, permitting authorized computation, enforcing state consistency, and controlling access-pattern leakage are separate obligations.

Verification and remaining gaps

All two reused-pad outcomes and all four fresh-pad outcomes were enumerated for both histories. This is an exact information leak in an auxiliary XOR-masking model, not an attack on the source's obfuscation-based constructions. No reusable garbled-RAM scheme, persistent-state security proof, or reduction to weaker cryptographic assumptions is obtained.
