Small graph diameter does not bound every improving pivot path

A tempting geometric explanation is that a polytope with small graph diameter must force short simplex runs. We test that inference with an explicit deformed cube. Fix $0<\eta<1/2$ and let \[ P_d=\{x:0\le x_1\le1,\quad \eta x_{i-1}\le x_i\le1-\eta x_{i-1}\ (2\le i\le d)\}. \] Maximize $x_d$. The parameter and objective define an auxiliary family, not a distribution of real-world linear programs.
Proposition: The graph of $P_d$ is the $d$-cube and has diameter $d$, but it has a strictly improving edge path for $x_d$ visiting all $2^d$ vertices.
Proof: Induction on coordinates shows $0\le x_i\le1$. Hence each pair of lower and upper bounds has strictly positive separation, at least $1-2\eta$, and cannot both be tight. For each bit vector $b\in\{0,1\}^d$, select one tight bound in each pair, giving the unique point \[ x_1=b_1,\qquad x_i=b_i+(1-2b_i)\eta x_{i-1}. \] It is feasible and its $d$ active constraints have a triangular, invertible coefficient matrix. It is therefore a vertex. Conversely a vertex must have $d$ independent active constraints; at most one can come from each of the $d$ pairs, so every vertex has this form. Fixing all but one of the selected pairs leaves a one-dimensional face between the two bit choices: the free coordinate ranges between its two distinct bounds, and later fixed coordinates depend affinely on it and stay feasible. Thus bit strings differing in one coordinate are adjacent. Each vertex has exactly $d$ active independent constraints and hence $d$ incident edges, so these are all edges. The graph is the cube, with distances equal to Hamming distances and diameter $d$. Construct the improving Hamilton path inductively. For $d=1$ traverse 0 then 1. For dimension $d$, first follow the previous path with last bit 0. Along it $x_d=\eta x_{d-1}$ strictly increases from 0 to $\eta$. At its endpoint change the last bit to 1, increasing $x_d$ from $\eta$ to $1-\eta$. Then traverse the previous path in reverse with last bit 1; now $x_d=1-\eta x_{d-1}$ strictly increases to 1. Consecutive bit strings differ in one coordinate, so every step is an edge, and the path visits all vertices exactly once. The middle increase uses $\eta<1/2$. ∎

Verification and remaining gaps

For $\eta=1/10$ and $1\le d\le8$, all reflected-Gray-code vertices were evaluated with exact rational arithmetic; consecutive objective values strictly increase and consecutive bit labels differ in one position. There are $2^d-1$ pivots despite graph diameter $d$. This disproves only the assertion that small undirected diameter controls every improving rule. It does not preclude a different polynomial pivot rule, does not establish a lower bound for all rules, and does not explain observed practical performance. A rule-specific geometric or probabilistic argument is still needed.
