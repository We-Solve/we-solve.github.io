Complexity in Enumerative Combinatorics — Conjecture 3

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Fix an integer $k\ge 1$. The supplied record does not specify whether graphs are simple, undirected, or allowed to have loops or multiple edges. Under the provisional convention of finite simple undirected graphs, let \[ a_{k,n}=\left|\left\{G:\ |V(G)|=n,\ \deg_G(v)=k\text{ for every }v\in V(G)\right\}/\cong\right|, \qquad n\ge 1, \] where $\cong$ denotes graph isomorphism. Thus each isomorphism class is counted once, independently of vertex labels. Under this convention, $a_{k,n}=0$ whenever $k\ge n$ or $kn$ is odd.

Conjecture 3 (Pak, 2018), provisional precise formulation. For every fixed integer $k\ge 1$, there exist a deterministic algorithm $A_k$, a constant $C_k>0$, and an integer $d_k\ge 0$ such that, for every integer $n\ge 1$, the algorithm $A_k$, given $n$, outputs the exact integer $a_{k,n}$ in binary using at most \[ C_k(n+1)^{d_k} \] bit operations. The algorithm and polynomial bound may depend on $k$; no bound uniform in variable $k$ is asserted. Computing all terms through index $n$ is an equivalent polynomial-in-$n$ formulation for fixed $k$.

The graph convention and the deterministic bit-operation interpretation above are explicit provisional interpretations, not hypotheses or computational conventions established by the supplied excerpt. The record does not specify the index-zero term. Source review is required before treating this as a fully resolved formulation.

The supplied background reports that reference [Ges] establishes similar polynomial recurrences for the numbers of labeled $k$-regular graphs for every fixed $k\ge 1$. This background assertion is distinct from the conjecture about unlabeled graphs; the conjecture does not explicitly demand such a recurrence.

Short English statement

For each fixed degree $k\ge 1$, Pak conjectures that the number of unlabeled $k$-regular graphs on $n$ vertices can be computed exactly in time polynomial in $n$. The displayed formulation provisionally uses simple undirected graphs and bit complexity; these conventions require source review. The registry labels the problem open, but that status has not been independently verified.
