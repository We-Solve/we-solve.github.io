Math-13155

Martingale for practical purposes

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $(\Omega,\mathcal F,\Pr,(\mathcal F_i)_{i=0}^n)$ be a filtered probability space, and let $X_0,\ldots,X_n$ be an adapted integrable real process. A stopping time $T$ takes values in $\{0,\ldots,n\}$ with $\{T\leq i\}\in\mathcal F_i$. A martingale satisfies ${\mathbb{E}}[X_{i+1}\mid\mathcal F_i]=X_i$ almost surely, and finite-horizon optional stopping gives ${\mathbb{E}} X_T={\mathbb{E}} X_0$ for every such $T$.

Aldous asks for a mathematically useful definition of being a "martingale for practical purposes" with the following operational implication: if a process fails the definition, it should be practical to find a stopping time $T$ such that \[ {\mathbb{E}} X_T\ne{\mathbb{E}} X_0. \] The inequality may have either sign; no positivity, payoff threshold, or tolerance is stipulated. The aim is effective discovery of a stopping rule, not merely abstract existence.

For a discrete process $X_0,\ldots,X_n$, the related question is whether a natural polynomial-size collection of stopping-time constraints, of the form ${\mathbb{E}} X_T={\mathbb{E}} X_0$, can define a tractable class with this practical interpretation. The underlying information filtration, encoding or access model for the process law, size parameter for the polynomial, computational resources and required numerical accuracy are not specified. A polynomial number of constraints does not by itself ensure that their expectations can be computed or a violated constraint found efficiently. Likewise a nonzero but arbitrarily tiny bias need not be practically detectable; the source does not provide a quantitative replacement for its exact inequality.

This is a definitional and algorithmic programme. It does not prescribe an existing approximate-martingale class, a finite list of tests, or an error bound to adopt.

Short English statement

Define a useful practical analogue of a martingale whose failure enables a feasible stopping rule to change expected value. For a finite process, ask whether polynomially many natural stopping-time tests can yield such a tractable class.
