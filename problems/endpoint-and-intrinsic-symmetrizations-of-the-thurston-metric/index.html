Math-5449

Endpoint and intrinsic symmetrizations of the Thurston metric

Statement

Definitions and mathematical statement

A. Papadopoulos asks for a good symmetrization of the Thurston metric; the source notes that Sorvali's length-spectrum metric is one. In the usual finite-type Teichmüller space with nonzero dimension, fix the normalization \[ d_{\mathrm{Th}}(X,Y)=\log\sup_{\alpha}\frac{\ell_Y(\alpha)}{\ell_X(\alpha)},\qquad d_{\mathrm{ls}}(X,Y)=\max\{d_{\mathrm{Th}}(X,Y),d_{\mathrm{Th}}(Y,X)\}. \] Thus $d_{\mathrm{ls}}=\sup_\alpha|\log\ell_Y(\alpha)-\log\ell_X(\alpha)|$, with no factor $1/2$ in this convention. The curve set consists of essential simple closed classes. For a basepoint $X_0$, the normalized log-length map \[ \Phi(X)=\left(\log\frac{\ell_X(\alpha)}{\ell_{X_0}(\alpha)}\right)_\alpha\in\ell^\infty(\mathcal C(S)) \] realizes $d_{\mathrm{ls}}$ as the ambient chord metric $\|\Phi(X)-\Phi(Y)\|_\infty$.

The aid contrasts this with infinitesimal symmetrization. Let \[ F_X(v)=\sup_\alpha{\,\mathrm{d}}(\log\ell_\alpha)_X(v),\qquad F_X^\vee(v)=\max\{F_X(v),F_X(-v)\} =\sup_\alpha|{\,\mathrm{d}}(\log\ell_\alpha)_X(v)|. \] Its intrinsic path metric is \[ \delta_\vee(X,Y)=\inf_{\gamma:X\to Y}\int F_{\gamma(t)}^\vee(\dot\gamma(t))\,{\,\mathrm{d}} t, \] using piecewise smooth, or the corresponding absolutely continuous, paths. The aid asserts that this is the intrinsic length metric of the log-length image, is reversible, mapping-class invariant, complete, topology-compatible and geodesic, and satisfies \[ d_{\mathrm{ls}}(X,Y)\leq\delta_\vee(X,Y). \] The surface class and analytic hypotheses for these metric properties need the full source argument; they are not extended here to arbitrary infinite-type spaces.

For a forward-dominant pair, meaning $D=d_{\mathrm{Th}}(X,Y)\geq d_{\mathrm{Th}}(Y,X)$, the aid's calibrated criterion is \[ \delta_\vee(X,Y)=d_{\mathrm{ls}}(X,Y)=D \] if and only if there exists a forward Thurston geodesic $\gamma$ from $X$ to $Y$ such that \[ F_{\gamma(t)}(\dot\gamma(t))\geq F_{\gamma(t)}(-\dot\gamma(t)) \quad\text{for almost every }t. \] The path is a minimizing $\delta_\vee$ path as well; arclength reparametrization is allowed. If every forward Thurston geodesic between the pair violates this inequality on a positive-measure set, then $\delta_\vee(X,Y)>d_{\mathrm{ls}}(X,Y)$. The reverse-dominant case is handled by reversing the ordered pair. This is a pairwise conditional test, not an exhibited strict pair or a proof of equality for all pairs. "Good" is not given a unique optimization criterion in the original problem, so these constructions and comparisons do not select a universally preferred symmetrization.

Short English statement

Compare the usual endpoint length-spectrum symmetrization with the intrinsic metric obtained by symmetrizing Thurston's infinitesimal norm. The supplied aid gives their inequality and an exact geodesic sign condition for equality, rather than claiming they always coincide.
