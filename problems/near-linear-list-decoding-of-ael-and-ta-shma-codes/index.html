Statement

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

List decoding returns all codewords within the allowed distance. Capacity refers to the source's optimal rate-versus-error tradeoff; the Johnson bound is the standard distance-derived list-decoding radius. Near-linear time allows the stated logarithmic factors in block length.

A code $C\subseteq\Sigma^N$ is a set of permitted length-$N$ words. Its Hamming minimum distance is the minimum number of unequal coordinates of two distinct words. For a linear $[N,K,D]_q$ code, rate is $K/N$ and relative distance is $D/N$; decoding recovers a codeword from corrupted observations.

List decoding returns every codeword within a prescribed distance of the received word, allowing several answers. Efficient list decoding requires polynomial runtime and a controlled output-list size; the intended capacity and alphabet are those in the source.

Statement recorded in the supplied source.
Can Alon–Edmonds–Luby codes be list-decoded up to capacity in linear time? Can Ta-Shma codes be list-decoded up to a radius approaching one half, or up to the Johnson bound, in near-linear time? [S2]
Scope qualification.
The rates, alphabets, capacity conventions, and dependence on gap-to-capacity are source-specific; exact linear and near-linear runtimes are separate requirements.

Short English statement

Meet the stated optimal decoding radii in linear or near-linear time for both named code families.
