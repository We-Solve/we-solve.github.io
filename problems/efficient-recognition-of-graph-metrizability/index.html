Math-6938

Efficient Recognition of Graph Metrizability

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

The supplied record does not define graph metrizability or consistent path systems. The following gives a conventional interpretation for review; the source's intended graph class and weight conventions remain unconfirmed.

Let $G=(V,E)$ be a finite simple undirected graph. Under a componentwise convention, a path system $\mathcal P$ assigns a simple path $P_{uv}$ to every unordered pair of distinct vertices $u,v$ in the same connected component. It is consistent if, whenever distinct vertices $x,y$ lie on $P_{uv}$, the subpath of $P_{uv}$ between $x$ and $y$ is $P_{xy}$. For positive edge weights $w:E\to{\mathbb{R}}_{>0}$, put \[ \ell_w(Q)=\sum_{e\in E(Q)}w(e). \] Call $\mathcal P$ metrizable if \[ \exists w:E\to{\mathbb{R}}_{>0}\quad \forall \{u,v\}\subseteq V\text{ in one component}\quad \forall\text{ simple }u\text{--}v\text{ paths }Q, \qquad \ell_w(P_{uv})\leq\ell_w(Q). \] Call it strictly metrizable if such weights can be chosen with strict inequality whenever $Q\ne P_{uv}$. Under this interpretation, $G$ is metrizable if every consistent path system on $G$ is metrizable; it is strictly metrizable if every such system is strictly metrizable. In particular, the weights may depend on the path system: \[ \forall\mathcal P\text{ consistent on }G\quad\exists w:E\to{\mathbb{R}}_{>0} \quad\text{realizing the specified shortest paths.} \] These conventions are provisional definitions, not definitions verified from the cited report. The record does not say whether graphs must be connected, simple, or undirected, or whether the edge weights must be positive.

Recognition problem, conditional on these conventions. Construct an algorithm $A$ which, for every input graph $G$, decides whether $G$ is metrizable and has running time polynomial in the length $L(G)$ of a standard explicit graph encoding: \[ A(G)=\mathrm{YES}\ \Longleftrightarrow\ G\text{ is metrizable}, \qquad T_A(G)\leq p(L(G)) \] for some fixed polynomial $p$. The requested additional goal is practical complexity, described in the original excerpt as a truly efficient algorithm. No running-time bound, computational model, or practical performance criterion is supplied. Thus the intended improvement over existing polynomial-time recognition cannot be expressed as a precise performance requirement from this record alone.

Surrounding source qualifications. The original excerpt states that all outerplanar graphs are metrizable and that every $2$-connected metrizable graph with at least $11$ vertices can be made outerplanar by deleting at most one vertex. Here outerplanar means admitting a plane embedding with every vertex on the boundary of the unbounded face; $2$-connected means having at least three vertices and remaining connected after deletion of any one vertex. These are supplied background assertions, not conclusions established in this draft.

The excerpt also conjectures the existence of a specified family $\mathcal F$ of six graphs, each with at most eight vertices, such that \[ G\text{ is not strictly metrizable} \quad\Longleftrightarrow\quad \exists H\in\mathcal F\text{ such that }H\text{ is a minor of }G. \] A graph minor is obtained by vertex deletions, edge deletions, and edge contractions. The six graphs are not supplied, so this conjecture cannot be fully instantiated here. It concerns strict metrizability, which must be distinguished from metrizability.

Finally, the excerpt asks how large $\Delta(\mathcal P)$ can be for a consistent $n$-point path system $\mathcal P$. Neither $\Delta$ nor the underlying notion of an $n$-point path system is defined in the supplied record, so no precise extremal statement is asserted. The excerpt's caption refers to an example of a non-metric consistent path system, but the figure is not supplied.

Short English statement

The main request is a practically efficient algorithm deciding whether a finite graph is metrizable. Under the explicitly provisional definitions above, this means that every consistent choice of paths can be realized as shortest paths by suitable positive edge weights. The supplied dated assessment says polynomial-time recognition already exists, so the requested practical improvement remains unspecified. The source also includes a strict-metrizability minor conjecture and a question about an undefined quantity $\Delta(\mathcal P)$; both require further source information.
