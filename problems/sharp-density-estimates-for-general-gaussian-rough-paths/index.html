Sharp Density Estimates for General Gaussian Rough Paths

Definitions and mathematical statement

A Gaussian process is a family of random variables whose every finite subfamily has a joint Gaussian distribution; vector-valued versions are defined by requiring all finite collections of scalar coordinates to be jointly Gaussian. For terminology, a standard real fractional Brownian motion with Hurst parameter $H\in(0,1)$ is a centered Gaussian process $(B_t^H)_{t\geq0}$ with covariance \[ {\mathbb{E}}[B_s^H B_t^H]=\frac12\left(s^{2H}+t^{2H}-|t-s|^{2H}\right),\qquad s,t\geq0. \] This definition fixes terminology only: the supplied record specifies neither a Hurst-parameter range for the intended estimates nor the dimension or normalization of the driving process. For an ${\mathbb{R}}^d$-valued random variable $Y$, a Lebesgue density is a measurable function $p:{\mathbb{R}}^d\to[0,\infty)$ satisfying \[ \mathbb P(Y\in A)=\int_A p(y)\,{\,\mathrm{d}} y \quad\text{for every Borel set }A\subseteq{\mathbb{R}}^d. \] The record does not identify the random variable whose density is to be estimated.
