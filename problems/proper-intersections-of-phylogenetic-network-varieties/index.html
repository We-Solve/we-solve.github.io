Proper Intersections of Phylogenetic Network Varieties

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For a fixed leaf number $n$, consider two distinct $n$-leaf phylogenetic networks $N_1$ and $N_2$. The source does not specify the admissible network class, the equivalence relation determining distinctness, or whether leaf labels must agree. These choices must be fixed before the problem has a fully specified domain.

For each network $N$, write $M_N$ for the associated model set, called the model variety in the supplied record, and put \[ V_N=\overline{M_N}^{\mathrm{Zar}}. \] This notation requires a choice of model, ground field, and ambient algebraic space. For the following intersection to be meaningful, the two model sets must be interpreted in a common ambient space $X$, with compatible coordinates. These are prerequisites for the formulation, not specifications supplied by the source.

Problem. With those choices fixed, characterize the pairs of distinct $n$-leaf phylogenetic networks $(N_1,N_2)$ for which \[ V_{N_1}\cap V_{N_2}\subsetneq V_{N_1} \qquad\text{and}\qquad V_{N_1}\cap V_{N_2}\subsetneq V_{N_2}. \] Here $\subsetneq$ means strict set inclusion; the intersection has the induced Zariski-closed structure. The requested conditions concern properness in both varieties. The source does not specify whether an empty intersection is permitted as a proper subvariety, whether irreducibility is assumed, or whether a stronger dimension condition is intended. No expected-dimension or transversality condition is imposed in this draft.

The supplied record labels the problem partially solved and reports generic distinguishability for important large-cycle and level-one network classes, while stating that proper intersections for arbitrary network varieties remain incompletely characterized. This is supplied dated curation, not an independently verified mathematical or literature assessment.

Short English statement

Characterize when the model varieties of two distinct phylogenetic networks with the same number of leaves intersect in a strictly smaller closed subset of each. A precise instance requires specifying the network class, statistical model, ground field, and common ambient coordinates; the supplied record leaves these choices unresolved.
