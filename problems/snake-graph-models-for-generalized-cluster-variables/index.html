Snake-Graph Models for Generalized Cluster Variables

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $\mathcal A$ denote the particular generalized cluster algebra of type $C_n$ intended by the source, let $\mathcal X(\mathcal A)$ denote its set of cluster variables, and let $G$ denote the associated generalized snake graph referred to there. These are placeholders for the source-specific construction: the supplied record does not specify the initial seed, coefficient system, generalized exchange polynomials, admissible values of $n$, or construction of $G$. A subgraph $H\subseteq G$ is connected if every pair of its vertices can be joined by a path in $H$.

Question as supplied. For every $x\in\mathcal X(\mathcal A)$, does there exist a connected subgraph $H\subseteq G$ that represents $x$ in the intended generalized snake-graph construction? Do analogous representations exist for every cluster variable of each affine type covered by that same construction?

Unresolved qualifications. The record does not define what it means for a connected subgraph to represent a cluster variable. Its background describes the target as a perfect-matching conjecture for particular generalized type-$C$ exchange polynomials, but supplies neither those polynomials nor a matching formula, edge weights, normalization, or correspondence. A perfect matching of a graph is a set of edges incident to each vertex exactly once; this definition alone does not determine the intended cluster-variable formula. The affine types and their constructions are also unspecified. Consequently, the question above records the intended quantifiers but is not a fully specified, independently testable conjecture. It must not be interpreted as a claim for arbitrary generalized exchange polynomials, or as merely asserting the existence of some connected subgraph without a prescribed representation of $x$.

Short English statement

The supplied question asks whether every cluster variable in a particular generalized type-$C_n$ cluster algebra has a representation by a connected part of its generalized snake graph, and whether the same construction extends to the intended affine types. The exchange polynomials, graph construction, representation rule, and affine types are missing, so a precise standalone formulation requires further source information. The supplied open status and literature assessment are dated curation, not independently verified conclusions.
