Math-3601

Positive Weighted Graph Homomorphism Densities

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A finite graph is called positive if all its real edge-weighted homomorphism densities are nonnegative. The supplied record asks for a characterization of these graphs, but does not explicitly specify graph simplicity, target loops, or vertex-weight conventions.

For an explicit candidate formulation, take $H=(V(H),E(H))$ to be a finite simple undirected graph. Represent a weighted target by a nonempty finite vertex set $[n]=\{1,\ldots,n\}$ and a symmetric matrix $W=(w_{ij})_{i,j=1}^{n}\in{\mathbb{R}}^{n\times n}$. Entries are arbitrary real edge weights; zero entries represent absent edges. Under the convention allowing diagonal target weights and assigning equal weight to each target vertex, define \[ t(H,W)=\frac{1}{n^{|V(H)|}}\sum_{\phi:V(H)\to[n]}\prod_{\{u,v\}\in E(H)}w_{\phi(u),\phi(v)}. \] The maps $\phi$ need not be injective. Empty products equal $1$, so isolated vertices impose no edge factors and the graph with no vertices has density $1$.

Under these explicit conventions, the requested problem is to characterize the class \[ \mathcal P=\left\{H:\ H\text{ is finite, simple, and undirected, and }\forall n\geq1\ \forall W\in{\mathbb{R}}^{n\times n},\quad W=W^{\mathsf T}\Longrightarrow t(H,W)\geq0\right\}. \] The characterization must give necessary and sufficient conditions on $H$. This is a conditional precise rendering of the supplied question: the source record does not establish whether its intended weighted targets allow diagonal weights or additional vertex weights, nor whether all source graphs are simple. Those conventions require confirmation before accepting this formulation as canonical.

Short English statement

Characterize the finite graphs whose homomorphism density is nonnegative in every target graph with arbitrary real edge weights. The displayed formulation uses simple undirected source graphs and symmetric real target matrices with unrestricted diagonal entries; these conventions require source confirmation. The supplied record labels the problem open, but that status has not been independently verified.
