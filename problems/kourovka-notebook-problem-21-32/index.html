Kourovka Notebook Problem 21.32

Statement

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.

For a group $H$, its derived subgroup $H'=[H,H]$ is generated by all commutators $x^{-1}y^{-1}xy$. A finite group $G$ is integrable if there exists a finite group $H$ with $H'\cong G$. A finite multiplication table is one explicit encoding of the input group; any proposed complexity bound must specify its chosen encoding and size parameter.

Statement recorded in the supplied source.
Is there an algorithm that, on every input finite group $G$, terminates and correctly decides whether some finite group $H$ satisfies $H'\cong G$? If such a decision algorithm exists, determine the complexity of this decision problem, with the input representation and size measure made explicit. [S2] [S3]

Short English statement

Decide whether a finite group occurs as the commutator subgroup of a finite group, and determine the computational complexity of doing so.
