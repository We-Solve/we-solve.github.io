Visibility Graphs of Points, Segments and Polygons — Problem 8

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For a finite simple undirected graph $G=(V,E)$, an obstacle representation places the vertices at distinct points $p_v\in{\mathbb{R}}^2$ and uses a finite collection of obstacles avoiding those points, with $uv\in E$ exactly when the segment joining $p_u$ and $p_v$ is not blocked by the obstacles. The supplied excerpt does not define admissible obstacles or the precise blocking convention. Accordingly, let $\mathcal M$ denote a fixed choice of these conventions, and let $\operatorname{obs}_{\mathcal M}(G)$ be the minimum number of obstacles in such a representation, with value $+\infty$ if none exists. This parameterized definition records the missing conventions rather than selecting them implicitly. Set \[ F_{\mathcal M}(n)=\max\{\operatorname{obs}_{\mathcal M}(G):G\text{ is a finite simple undirected graph with }|V(G)|=n\}. \] The source asks for an improvement of the lower bound for the obstacle number of an $n$-vertex graph. However, it writes the purported lower bounds using $O$: first $O(\sqrt{\log n})$, attributed to Alpet et al. [akl-ong-2010], then $O(n/(\log n)^2)$, attributed to Mukkamala et al. [mps-glon-2010]. It also gives $O(n/\log n)$ when obstacles are restricted to convex polygons. These are transcriptions of the supplied claims, not verified bounds. Big-$O$ does not express the stated lower-bound direction, and the intended notation requires confirmation.

If the intended benchmark is $F_{\mathcal M}(n)=\Omega(n/(\log n)^2)$, a precise formulation of an asymptotic improvement would be: find a function $f:{\mathbb{N}}\to(0,\infty)$, a constant $c>0$, and an integer $n_0\geq 3$ such that \[ \lim_{n\to\infty}\frac{f(n)(\log n)^2}{n}=+\infty \] and \[ \forall n\geq n_0\ \exists G\quad \left(|V(G)|=n\ \text{ and }\ \operatorname{obs}_{\mathcal M}(G)\geq c f(n)\right). \] Here $\log$ may be taken as the natural logarithm; any fixed base greater than one gives the same asymptotic comparison. This is a conditional reconstruction of the requested improvement. The obstacle model, the intended replacement of $O$ by lower-bound notation, and the intended strength and quantifier range of the improvement remain unresolved. The convex-polygon bound is supplied background; the final request does not explicitly restrict obstacles to convex polygons.

Short English statement

The apparent request is to improve the worst-case lower bound for the number of obstacles needed to represent an $n$-vertex graph by visibility in the plane. The excerpt calls its bounds lower bounds but writes them using $O$, and it omits the obstacle conventions. The displayed target therefore gives a conditional interpretation requiring human review. The registry labels this problem open; that label has not been independently verified.
