Research attempt: A minimal extraction closure and its provenance limitation

Model a book by a finite directed graph $(V,E)$, with an edge $u\to v$ meaning that retaining $u$ requires retaining $v$. These are mandatory conjunctive dependencies, not optional alternatives. For selected worksheets $S\subseteq V$, initialize $C_0=S$ and set $C_{k+1}=C_k\cup\{v:\exists u\in C_k,(u,v)\in E\}$. After at most $|V|$ strict additions this stabilizes at $C$. It contains every node reachable from $S$: induction on path length proves inclusion. Conversely every added node has a path from $S$, by induction on the insertion stage. Hence $C$ is precisely the reachable set and is the smallest dependency-closed superset of $S$. A queue implementation visits every retained node and outgoing edge once, giving $O(|V|+|E|)$ time for explicit adjacency lists.

Selecting only worksheet-tagged nodes fails on the three-node instance $w\to m\to b$: the worksheet $w$ uses a macro $m$ whose expansion depends on a bibliography object $b$. Retaining $w,m$ but not $b$ is still insufficient. This tests transitive rather than merely direct closure.

Closure alone does not preserve provenance. Suppose editions $v_1,v_2$ both have a worksheet with local identifier $w$, but different statements. An extraction retaining only $w$ and a mutable latest-edition URL has the same stored provenance for the two different origins. No resolver using only those fields can recover both origins correctly: identical input forces identical output. A provenance record must distinguish the edition and original item, for example the triple $(\text{publication},\text{edition},\text{id})$, and any actual link must be checked against that edition's manifest. This additional datum does not follow from dependency reachability.

The closure proof deliberately excludes alternatives, conditional imports, and dynamically generated references. With an either-or dependency, requiring both endpoints can cease to be minimal; those cases need a different model.
