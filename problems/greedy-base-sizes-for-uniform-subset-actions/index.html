Greedy Base Sizes for Uniform-Subset Actions

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $X$ be a finite set of size $n$, and let $r$ be an integer with $0\le r\le n$. Write \[ \Omega=\binom{X}{r}=\{A\subseteq X:|A|=r\}. \] A permutation group $G\le\operatorname{Sym}(X)$ induces an action on $\Omega$ by $g(A)=\{g(x):x\in A\}$. Let $H\le\operatorname{Sym}(\Omega)$ be the image of this action. For $B\subseteq\Omega$, its pointwise stabilizer is \[ H_{(B)}=\{h\in H:h(A)=A\text{ for every }A\in B\}. \] A base for $H$ is a set $B$ with $H_{(B)}=1$. Passing to the induced image makes this definition faithful; whether the intended source action is assumed faithful must be checked.

For a precise reference convention, a greedy base construction starts with $H_0=H$. Whenever $H_{i-1}\ne1$, choose $A_i\in\Omega$ whose $H_{i-1}$-orbit has maximum cardinality, and put \[ H_i=(H_{i-1})_{A_i}. \] Stop at the first index $k$ with $H_k=1$. Define \[ g_{\max}(H)=\max\{k:k\text{ is the length of such a greedy construction}\}, \] where the maximum includes all choices among tied largest orbits, and the empty construction has length zero when $H=1$. This supplies an explicit possible convention for greedy base size; the extraction does not specify its convention or its treatment of ties.

Extracted problem, with unresolved scope. Determine the greedy base size for the intended standard primitive actions on $\binom{X}{r}$ in the range \[ n<4r^2. \] Under the reference convention above, this would mean determining $g_{\max}(H)$ for the intended family. An action is primitive if it is transitive and its only invariant equivalence relations are equality and the universal relation. The extraction does not identify the acting groups, state unambiguously which action is required to be primitive, or specify the additional restrictions on $n$ and $r$. The elementary conditions $0\le r\le n$ merely make the subset notation meaningful; they do not establish that every such pair is intended. Boundary cases, including singleton subset spaces and complementary subset sizes, remain unspecified.

The retained report passage says that a similar bound is known in most standard uniform-subset cases and that the problem remains open below the displayed threshold. Neither that bound nor the conjecture announced at the end of the passage is supplied. Thus the request to determine an exact value, the reference convention above, and the full family of actions cannot be confirmed from the excerpt. No unique fully quantified conjecture can be recovered from this record alone. The threshold is strictly $n<4r^2$; the equality case is not included in the extracted range.

Short English statement

The record asks for greedy base sizes in certain standard primitive actions on $r$-element subsets of an $n$-element set when $n<4r^2$. It omits the precise group family, the earlier bound, and the announced conjecture. The definitions above provide an explicit reference convention, but the intended numerical statement requires source clarification and human mathematical review.
