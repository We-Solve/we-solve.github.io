Algebraic Invariants of Yang–Baxter Map Order

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied question is: Is there an algebraic invariant that determines the order of the Yang--Baxter map $r$? The record does not specify the domain of $r$, the class of Yang--Baxter maps under consideration, or what qualifies as an algebraic invariant.

For purposes of interpreting the word order, if $r\colon S\to S$ is a bijection of a set $S$, define \[ \operatorname{ord}(r)= \begin{cases} \min\{n\in{\mathbb{Z}}_{\geq 1}:r^n=\operatorname{id}_S\},&\text{if this set is nonempty},\\ \infty,&\text{otherwise}. \end{cases} \] Here $r^n$ denotes composition of $r$ with itself $n$ times. Bijectivity is a condition for this permutation-order interpretation; it is not explicitly supplied in the record.

One possible setting is a set-theoretic solution in the braid convention: a set $X$ and a bijection $r\colon X\times X\to X\times X$ satisfying \[ (r\times\operatorname{id}_X)\circ(\operatorname{id}_X\times r)\circ(r\times\operatorname{id}_X) = (\operatorname{id}_X\times r)\circ(r\times\operatorname{id}_X)\circ(\operatorname{id}_X\times r) \quad\text{on }X^3. \] This is an illustrative interpretation, not a hypothesis established by the supplied source record. The intended convention for the Yang--Baxter equation must be confirmed, together with any finiteness, nondegeneracy, or involutivity assumptions.

Once an intended class $\mathcal C$ and an equivalence relation on its objects have been specified, an invariant would be an assignment $I\colon\mathcal C\to A$ constant on equivalent objects. To say that it determines the order means \[ \forall u,v\in\mathcal C,\qquad I(u)=I(v)\ \Longrightarrow\ \operatorname{ord}(r_u)=\operatorname{ord}(r_v), \] where $r_u$ is the Yang--Baxter map belonging to $u$. This gives a conditional meaning to "determines"; neither $\mathcal C$, the equivalence relation, nor the permitted algebraic construction of $I$ is supplied. In particular, permitting the order itself as the invariant would make the question tautological. A precise substantive existence problem therefore requires additional restrictions on the intended invariant. The supplied question is retained with these qualifications unresolved.

Short English statement

The question asks whether algebraic data associated with a Yang--Baxter map determine its order under iteration. The intended maps, hypotheses, and permitted invariants are unspecified, so the displayed formulation is conditional and requires mathematical review. The supplied record labels the problem open; this status has not been independently verified.
