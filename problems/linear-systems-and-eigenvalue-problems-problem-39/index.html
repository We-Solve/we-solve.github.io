Math-2545

Linear Systems and Eigenvalue Problems — Problem 39

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $T=(V,E)$ be a specified tree tensor network with $|V|=m$ nodes, physical index dimensions $d_1,\ldots,d_n$, and prescribed internal edge dimensions $r_e$ for $e\in E$. The ambient tensor space is $\mathcal H={\mathbb{R}}^{d_1\times\cdots\times d_n}$. A tensor is representable by this network if it is obtained by contracting real core tensors along all internal edges, each contracted index having its prescribed dimension. Write $S\subseteq\mathcal H$ for the set of representable tensors. Under this usual core-dimension interpretation, the actual ranks of a represented tensor may be smaller than the prescribed dimensions; the source does not explicitly distinguish this interpretation from requiring exact ranks.

For $\mathcal B\in\mathcal H$, define the squared Frobenius norm by \[ \|\mathcal B\|_F^2=\sum_{i_1=1}^{d_1}\cdots\sum_{i_n=1}^{d_n}B_{i_1,\ldots,i_n}^{\,2}. \] When the indicated minimum exists, put \[ \operatorname{OPT}_S(\mathcal A)=\min_{\mathcal Y\in S}\|\mathcal Y-\mathcal A\|_F^2. \] The source uses a minimum; its existence must be justified for the intended interpretation of $S$.

Requested statement, retaining the source's unresolved qualifications. For every choice of an $m$-node tree tensor network, including tensor train or Tucker networks, and prescribed edge dimensions, find a polynomial-time algorithm which, for every input $\mathcal A\in\mathcal H$, returns $\mathcal X\in S$ satisfying \[ \|\mathcal X-\mathcal A\|_F^2<(m-1)\operatorname{OPT}_S(\mathcal A), \] or establish, under suitable complexity-theoretic assumptions, that an $(m-1)$-approximation is optimal. The displayed factor applies to the squared Frobenius error.

Unresolved formulation issues. The strict inequality cannot hold when $\mathcal A\in S$, since then the minimum is zero and the left-hand side is nonnegative. No exclusion of such inputs is supplied. For $m=2$, the strict inequality also requires an error strictly below the minimum; for $m=1$, its right-hand side is zero whenever the minimum is defined. The source supplies no lower restriction on $m$. Consequently, the universal strict requirement needs correction or qualification before it can express the intended approximation problem. No correction is selected here. The source also leaves unspecified the computational model for arbitrary real inputs, the required numerical accuracy, which network parameters contribute to input size, whether one uniform algorithm is required across all networks and ranks, and the assumptions and precise lower-bound quantifiers intended by optimality of the factor. Its output notation $\mathbb S$ is undefined; the displayed formulation provisionally reads it as the previously defined set $S$.

Short English statement

For any prescribed tree tensor network with $m$ nodes and chosen edge dimensions, the source asks for a polynomial-time approximation whose squared Frobenius error is strictly less than $(m-1)$ times the best representable error, or a conditional proof that this factor is optimal. The strict inequality, rank convention, computational model, and intended hardness claim require clarification. This is a statement-only draft; the supplied registry labels the problem open.
