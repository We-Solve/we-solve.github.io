A long-wave failure visible in a dispersion relation.
In a constant-coefficient quasigeostrophic test model the linear equation $\partial_t(\Delta\psi-L_D^{-2}\psi)+\beta\partial_x\psi=0$ has plane-wave frequency \[ \omega(k,l)=-\frac{\beta k}{k^2+l^2+L_D^{-2}}, \] obtained by substituting $e^{i(kx+ly-\omega t)}$. Put $K^2=k^2+l^2$ and $a=L_D^{-2}>0$. The short-wave expansion is $\omega=-(\beta k/K^2)\sum_{n\geq0}(-a/K^2)^n$, which converges only when $K^2>a$.
Quantifying the leading error.
With $\omega_0=-\beta k/K^2$ and $\beta k\ne0$, the relative frequency error is exactly $|\omega_0-\omega|/|\omega|=a/K^2$. It becomes large for the longest waves. Retaining $a$ in the denominator is a simple uniform repair for this test equation; it recovers the finite long-wave form $\omega\sim-\beta k/a$. At $\beta k=0$ with $K>0$, both frequencies vanish, so relative error is undefined and one must use absolute error. At $K=0$, the exact frequency is zero but the short-wave expression itself is undefined.
Source limitation.
This is not the report's global short-wave equatorial model, and the constant-coefficient approximation omits equatorial trapping and meridional mode structure. It therefore diagnoses a generic nonuniform denominator expansion rather than explaining the source discrepancy. The first gap is locating the corresponding discarded balance in the actual model and deriving a matched approximation with a norm and wavelength range. Its longest-wave errors remain unresolved by the illustrative calculation.
