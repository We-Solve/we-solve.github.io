Statement

Definitions and mathematical statement

The supplied Question 1 asks whether a Hénon map of some degree admits a wild attractor, described there as a Cantor set attracting a set of positive Lebesgue measure and strictly contained in a transitive set. The excerpt does not specify the ambient field, the class of Hénon maps, or the convention for transitivity, so it does not determine a unique fully specified existence statement.

A conditional formulation is as follows. Fix an ambient Euclidean phase space $X$, its metric $d$ and Lebesgue measure $m_X$, and an intended class $\mathcal H(X)$ of Hénon maps. A Cantor set means a nonempty compact, perfect, totally disconnected subset of $X$. For a map $F\colon X\to X$ and a Cantor set $K\subseteq X$, define its basin of attraction by \[ B_F(K)=\left\{z\in X:\lim_{n\to\infty}\operatorname{dist}(F^n(z),K)=0\right\}, \qquad \operatorname{dist}(z,K)=\inf_{w\in K}d(z,w). \] Under the convention that an attractor is invariant and a transitive set is an invariant set on which the restriction is topologically transitive, the question becomes: do there exist $F\in\mathcal H(X)$, of some degree, and sets $K,T\subseteq X$ such that \[ \begin{gathered} K\text{ is a Cantor set},\qquad F(K)=K,\qquad m_X(B_F(K))>0,\\ K\subsetneq T,\qquad F(T)=T, \end{gathered} \] and, for every pair of nonempty relatively open subsets $U,V\subseteq T$, there exists an integer $n\geq 0$ such that \[ F^n(U)\cap V\neq\varnothing? \] Here the choices of $X$ and $\mathcal H(X)$ remain unresolved. The basin, invariance, and topological-transitivity conventions above make one reading explicit; they require confirmation against the complete source context. The excerpt also does not state whether $T$ must be closed or compact, or whether further conditions on the attractor or its basin are intended.

Short English statement

Berger and Bedford ask whether some Hénon map, with degree unrestricted in the excerpt, has an invariant Cantor set attracting a set of positive Lebesgue measure while lying strictly inside a transitive invariant set. The ambient space, admissible map class, and precise dynamical conventions require source clarification. The registry labels the problem open; this is a supplied status, not an independently verified assessment.
