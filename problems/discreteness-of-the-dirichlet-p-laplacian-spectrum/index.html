Discreteness of the Dirichlet $p$-Laplacian Spectrum

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a conventional formulation, let $n\geq 1$, let $\Omega\subset{\mathbb{R}}^n$ be a nonempty bounded connected open set, and let $1<p<\infty$. These parameter ranges and the connectedness convention are not specified explicitly in the supplied record; any additional intended hypotheses on $\Omega$ require verification. Write $W^{1,p}_0(\Omega)$ for the closure of $C_c^\infty(\Omega)$ in $W^{1,p}(\Omega)$. The Dirichlet $p$-Laplacian eigenvalue equation is \[ -\operatorname{div}(|\nabla u|^{p-2}\nabla u)=\lambda |u|^{p-2}u, \qquad u\in W^{1,p}_0(\Omega)\setminus\{0\}. \] The equation is understood weakly: for every $\varphi\in W^{1,p}_0(\Omega)$, \[ \int_\Omega |\nabla u|^{p-2}\nabla u\cdot\nabla\varphi\,{\,\mathrm{d}} x =\lambda\int_\Omega |u|^{p-2}u\varphi\,{\,\mathrm{d}} x. \] Define the full eigenvalue set by \[ \Sigma_p(\Omega)=\{\lambda\in{\mathbb{R}}:\text{there exists a nonzero weak solution of the displayed equation}\}. \] This definition includes all weak eigenvalues, without assuming that a variational sequence exhausts them.

Discreteness question. In the conventional framework above, determine whether, for every admissible $\Omega$ and $p$, the full set $\Sigma_p(\Omega)$ has no finite accumulation point. An explicit formulation of this interpretation is \[ \forall M>0,\qquad \#\left(\Sigma_p(\Omega)\cap[0,M]\right)<\infty. \] The record does not define "discrete." If only isolation of each eigenvalue is intended, the corresponding assertion is instead \[ \forall\lambda\in\Sigma_p(\Omega)\ \exists\delta>0:\quad \Sigma_p(\Omega)\cap(\lambda-\delta,\lambda+\delta)=\{\lambda\}. \] The intended convention should be checked against the report.

Further questions recorded by the source. Determine whether higher eigenvalues have finite multiplicity, and whether there exists \[ \mu>\lambda_2\quad\text{such that}\quad\mu\notin\Sigma_p(\Omega). \] For an explicit conventional meaning of $\lambda_2$, put \[ S=\left\{u\in W^{1,p}_0(\Omega):\int_\Omega |u|^p\,{\,\mathrm{d}} x=1\right\}, \qquad E(u)=\int_\Omega |\nabla u|^p\,{\,\mathrm{d}} x, \] choose a positive minimizer $u_1\in S$ of $E$, and set \[ \lambda_2=\inf_{\gamma\in\Gamma}\ \max_{t\in[0,1]}E(\gamma(t)),\qquad \Gamma=\{\gamma\in C([0,1],S):\gamma(0)=u_1,\ \gamma(1)=-u_1\}, \] where continuity uses the $W^{1,p}_0(\Omega)$ topology. This supplies a conventional second variational eigenvalue; the supplied record does not state its convention explicitly. The meaning of "multiplicity" remains unresolved: for $p\neq2$, the solutions associated with a fixed eigenvalue need not form a vector space, so ordinary eigenspace dimension cannot be adopted without justification. Accordingly, the finite-multiplicity question is retained as a source question requiring a specified nonlinear multiplicity notion, rather than asserted to follow from discreteness of the eigenvalue set.

The standard equation above uses the same exponent $p$ in the operator and in $|u|^{p-2}u$. The supplied assessment distinguishes it from a $(p,q)$-problem with $q<p$; the reported non-discrete example for that different problem is not presented as an answer to this question.

Short English statement

The problem asks whether the full Dirichlet $p$-Laplacian eigenvalue set on a bounded domain is discrete. It also asks whether higher eigenvalues have finite multiplicity and whether at least one real number above the second eigenvalue fails to be an eigenvalue. The precise domain hypotheses, meaning of discreteness, and nonlinear multiplicity convention need confirmation. The supplied registry labels the problem open; this is dated curation, not an independently verified status determination.
