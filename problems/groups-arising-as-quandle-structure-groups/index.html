Groups Arising as Quandle Structure Groups

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Use the following explicit right-quandle convention. A quandle is a set $Q$ with a binary operation $\triangleright:Q\times Q\to Q$ such that, for all $x,y,z\in Q$, \[ x\triangleright x=x,\qquad (x\triangleright y)\triangleright z=(x\triangleright z)\triangleright(y\triangleright z), \] and, for each $y\in Q$, the map $R_y:Q\to Q$, defined by $R_y(x)=x\triangleright y$, is bijective. With this convention, define its structure group by \[ \operatorname{Grp}(Q)=\left\langle e_x\ (x\in Q)\ \middle|\ e_{x\triangleright y}=e_y^{-1}e_xe_y\quad(x,y\in Q)\right\rangle. \] The supplied record does not specify the operation convention or the defining presentation of $\operatorname{Grp}(Q)$; this standard interpretation requires confirmation against the source. It also does not specify whether empty quandles are admitted, so that boundary convention remains unresolved.

The problem is to characterize the class of abstract groups \[ \mathcal C=\left\{G\ \middle|\ G\text{ is a group and there exists a quandle }Q\text{ with }G\cong\operatorname{Grp}(Q)\right\}, \] by giving necessary and sufficient conditions for membership, subject to the convention qualifications above, and to further analyze the groups in this class. No finiteness, cardinality, or connectedness restriction on $Q$, and no finiteness restriction on $G$, is supplied. The phrase "further analyze" specifies no additional mathematical target.

Short English statement

Characterize exactly which abstract groups occur as structure groups of quandles, and investigate their properties. The displayed definition uses an explicit right-quandle convention requiring source confirmation; the empty-quandle boundary and the intended scope of further analysis remain unspecified. The supplied record labels the problem open, without independent verification here.
