Homogeneous Factorizations Producing Type-II Arveson Systems

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$; the standard number fields have their usual meanings. All additional conventions are stated locally.
Definitions and conventions.
A factor is a von Neumann algebra with center $\mathbb C I$; type $\mathrm{II}_1$ is finite with a normalized trace and type $\mathrm{III}$ has no nonzero finite projections. The source uses a separable predual and a faithful normal state $\phi$. A noncommutative factorization assigns $\phi$-conditioned subalgebras $A_B$ to measurable subsets $B\subseteq\mathbb R$, respecting intersections, generated unions, independence of disjoint sets, and exhaustion. Homogeneity supplies state-preserving translations sending $A_B$ to $A_{B+t}$. An Arveson system is a measurable family of Hilbert spaces $E_t$, $t>0$, with associative unitaries $E_s\otimes E_t\cong E_{s+t}$. Type $\mathrm{II}$ means that units exist but do not generate the whole system.
Source scope and qualifications.
The report's factorization axioms, state-preserving conditional expectations, and continuity/measurability conditions are part of the construction; a family of arbitrary independent subalgebras is insufficient. The existence question concerns the given probability algebra, not simply existence of an unrelated type II system.
Catalogue mathematical target.
Catalogue wording retained for traceability.
If $A$ is a type $\mathrm{II}_1$ or type $\mathrm{III}$ factor with state $\phi$, does there exist a homogeneous noncommutative factorization of $(A,\phi)$ over $\mathbb R$ that leads to an Arveson system of type $\mathrm{II}$? Here homogeneity means a $\phi$-preserving translation action on the factorization over measurable subsets of $\mathbb R$.
Saved literature context.
The supplied catalogue's assessment dated 2026-08-21 records: The report poses existence of a homogeneous noncommutative factorization producing a type II Arveson system; no later construction resolving this general existence question was located. The assessment is retained as dated provenance; it is not a new comprehensive literature or open-status certification.

Short English statement

Construct a translation-invariant noncommutative factorization of the prescribed factor and state whose associated product system has type II.

Why the ordinary Gaussian construction gives the wrong type.
Let $K_t=L^2((0,t);\mathbb C)$ and $E_t=\bigoplus_{n\geq0}K_t^{\otimes_s n}$ be symmetric Fock space. For $f\in K_t$ define the exponential vector $e(f)=\bigoplus_{n\geq0}f^{\otimes n}/\sqrt{n!}$. Its squared norm is $e^{\|f\|^2}$, so it belongs to $E_t$. The orthogonal time decomposition identifies $e(f\oplus g)$ with $e(f)\otimes e(g)$.
Units already generate everything.
For each $z\in\mathbb C$, $u_t^z=e(z1_{(0,t)})$ is a measurable multiplicative section. Products of these units over finite time partitions give $e(f)$ for step functions $f$. Those vectors are total: if $v=(v_n)$ is orthogonal to every $e(f)$, then for any fixed finite collection of step functions the entire function $\langle v,e(\sum_jz_jf_j)\rangle$ is zero. Its Taylor coefficients imply orthogonality of each $v_n$ to all symmetric products of step functions. Step functions are dense in $K_t$, hence these products are dense in each symmetric tensor power, and every $v_n=0$.
Where the construction fails.
Therefore the ordinary Gaussian/Fock factorization is type I, not the requested type II. Adding more ordinary independent Gaussian channels repeats the same density argument. The source additionally prescribes a particular factor $(A,\phi)$; this Hilbert-space construction does not realize its state or conditional expectations. The first gap is a homogeneous factorization on that prescribed probability algebra with a nonzero component orthogonal to the subsystem generated by all units, while retaining at least one unit and all continuity axioms.
