Verbatim supplied catalogue question

Does PLANAR MIN-BISECTION admit a PTAS? For constrained bicriteria minimum spanning tree, does an FPAS exist, and can all Pareto-optimal solutions be enumerated in time polynomial in their number?

The overlapping source scope

This catalogue record spans three questions on printed page 1533: planar minimum-bisection approximation, a constrained spanning-tree scheme, and Pareto enumeration. It duplicates records 30000061, 30000063 and 30000064 and is not an additional independent conjecture. We preserve the composite text and test the report's proposed link between enumeration and approximation, making the output convention explicit. Nothing below settles the separate planar-bisection question.
Conditional implication under a precise output model.
Assume an algorithm lists all distinct Pareto cost pairs of any bicriteria spanning-tree instance, with one representative tree per pair, in time polynomial in input plus output length. Suppose edge cost and objective weight are nonnegative rationals. Under this assumption, the constrained problem has a fully polynomial approximation scheme with no budget violation. Here is the reduction.

Let the graph have $n\ge2$ vertices, budget $B$, and accuracy $0<\varepsilon\le1$; for larger requested accuracy parameter, run with one, which only strengthens the guarantee. A zero-weight optimum, if it exists, uses only zero-weight edges. Apply the assumed enumeration algorithm to that subgraph, with the original costs and zero weights. There is at most one distinct Pareto pair, its minimum cost paired with zero. This detects feasibility at zero objective and returns an exact answer if the cost is at most $B$. It also handles the case that all edges have zero weight. Disconnected subgraphs have no spanning tree and empty output. The one-vertex graph is trivial.

Otherwise any positive optimum is at least the minimum positive edge weight $w_{\min}$ and at most $(n-1)w_{\max}$ whenever a feasible tree exists. Consider powers-of-two guesses $W$ starting at $w_{\min}$ through this upper bound; their number is polynomial in the rational input bit lengths, because the logarithm of the ratio is. One guess satisfies $W\le\operatorname{OPT}<2W$. For each guess delete edges of weight greater than $2W$, and set $K=\varepsilon W/(n-1)$ and $\widetilde w_e=\lfloor w_e/K\rfloor$. Every remaining edge has rounded weight at most $2(n-1)/\varepsilon$, so every tree has rounded total at most $R=\lfloor2(n-1)^2/\varepsilon\rfloor$.

There are at most $R+1$ distinct Pareto pairs for original cost versus rounded weight: for each possible integer rounded weight, only its least achievable cost can be nondominated. Rational cost sums and representative trees have polynomial encoding length. Thus the assumed output-polynomial algorithm runs in fully polynomial time on each rounded instance. Among its budget-feasible pairs choose the least rounded weight and its tree. If any feasible tree exists in that instance, some Pareto pair dominates it: repeatedly replace a dominated pair by a dominating one in the finite pair set, which must terminate. The chosen tree is therefore optimal for the rounded objective under the exact original budget.

For the good guess the original optimum tree survives edge deletion. Writing it as $T^*$ and the selected tree as $T$, we have \[ w(T)<K\widetilde w(T)+(n-1)K \le K\widetilde w(T^*)+\varepsilon W \le\operatorname{OPT}+\varepsilon W \le(1+\varepsilon)\operatorname{OPT}. \] These inequalities sum the per-edge rounding error, use rounded optimality, and then $W\le\operatorname{OPT}$. All returned trees respect the original budget. Choose the smallest original weight among the returned feasible trees over all guesses; it is at least as good as the good-guess tree. If no feasible tree is ever returned, none existed: every possible feasible optimum would have supplied a good guess. This proves the conditional claim.

The output convention is essential.
If the enumeration algorithm must output every Pareto tree rather than one representative per distinct pair, a rounded instance may still have exponentially many outputs. For example a chain of $k$ triangles with all edge pairs $(1,1)$ has $3^k$ spanning trees, all with the same pair $(2k,2k)$ and all Pareto optimal. Each triangle independently contributes any two of its three edges; articulation attachment proves the count and connectivity. The bound $R+1$ controls pairs, not tree multiplicity. Therefore the preceding conditional fully polynomial running-time argument cannot silently use a tree-enumeration oracle instead.

Audit and remaining composite target

The two adjacent source sections were inspected. The audit checked zero optimum, binary rational weights, the geometric guess count, and exact feasibility. The reduction is conditional and does not construct the assumed Pareto algorithm. It establishes no planar bisection scheme either. In particular permitting an imbalance is a different target: two disjoint paths of orders $m-1,m+1$ have a zero cut with that imbalance, while every exact bisection must split a connected component and has cut at least one. Taking all of the smaller path and one endpoint of the larger attains one. Thus vanishing relative imbalance as $m$ grows does not make the zero-cut partition exactly feasible. No experiments were run, and all three original tasks remain unresolved here.
