Math-1084

Higher-Dimensional Enumeration and Tensor-Rank Problems

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For $n\geq1$, a labelled Latin square of order $n$ is a map $A:\{1,\ldots,n\}^2\to\{1,\ldots,n\}$ whose restriction to every row and every column is a permutation. Let $L_n$ count these arrays, without quotienting by row, column, or symbol permutations. The first request is to improve asymptotic bounds for $L_n$ as $n\to\infty$. The source supplies no baseline estimate or precise target error term, so none is declared the requested improvement.

The second request is to formulate and solve higher-dimensional analogues of that enumeration. One natural candidate, illustrating rather than fixing the unspecified choice, is to count arrays $A:\{1,\ldots,n\}^m\to\{1,\ldots,n\}$ for fixed $m\geq3$, with each axis-parallel line a permutation. The record does not select this definition, dimension regime, labelling convention, or other possible higher-dimensional combinatorial objects.

The third request asks for higher-dimensional analogues of the gamma function in this enumerative setting. The ordinary gamma function interpolates factorials, $\Gamma(n+1)=n!$, with recurrence $\Gamma(z+1)=z\Gamma(z)$. The source gives no recurrence, interpolation values, domain, dimensional parameter, or required relation to its higher-dimensional counts. Thus this part is a request to formulate a useful theory, not a definite existence/uniqueness theorem about a specified function. No existing special-function family is identified as a solution without such criteria.

Finally, for $T\in{\mathbb{R}}^n\otimes{\mathbb{R}}^n\otimes{\mathbb{R}}^n$, define its real tensor rank by \[ \operatorname{rank}_{{\mathbb{R}}}(T)=\min\left\{r:T=\sum_{i=1}^r a_i\otimes b_i\otimes c_i, \ a_i,b_i,c_i\in{\mathbb{R}}^n\right\}. \] Let $R_n=\max_T\operatorname{rank}_{{\mathbb{R}}}(T)$. This maximum concerns all real three-way tensors, with no symmetry restriction; it is not generic rank, border rank, or multilinear rank. The question asks to determine $R_n$, and specifically conjectures \[ R_n=(1+o(1))\frac{n^2}{2}\quad(n\to\infty), \qquad\text{equivalently}\qquad \lim_{n\to\infty}\frac{R_n}{n^2}=\frac12. \] The existence of a finite maximum is unproblematic under this definition since every tensor has a decomposition with at most $n^2$ simple tensors. No sharper bound or proof of the conjectured asymptotic is supplied.

The assessment dated 2026-08-21 discusses only the gamma-analogue challenge and says the report gives no general theory or resolution for it. It does not independently establish the status of all the separate Latin-square and tensor-rank questions grouped into this record.

Short English statement

The record bundles Latin-square asymptotics, unspecified higher-dimensional counting and gamma-function analogues, and a precise maximum-real-tensor-rank conjecture with leading term $n^2/2$. The last statement has a clear rank definition; the broader enumeration and function requests need additional targets.
