Several Complex Variables Problem List — Problem 70

Statement

Definitions and mathematical statement

For each positive integer $k$, let ${\mathbb{P}}^k({\mathbb{C}})$ denote complex projective $k$-space. If $F:{\mathbb{P}}^k({\mathbb{C}})\to{\mathbb{P}}^k({\mathbb{C}})$ is holomorphic, write $F^0=\operatorname{id}$ and $F^{n+1}=F\circ F^n$ for integers $n\geq 0$. The Fatou set $\mathcal F(F)$ consists of points having an open neighborhood on which the family $\{F^n:n\geq 0\}$ is normal: every sequence from this family has a subsequence converging uniformly on compact subsets, in the projective target, to a holomorphic map. A Fatou component is a nonempty connected component of $\mathcal F(F)$.

For a given $k$, the existence question is whether there are such a holomorphic map $F$ and a Fatou component $U$ satisfying \[ F^n(U)\cap F^m(U)=\varnothing \qquad\text{for all distinct integers }n,m\geq 0. \] Such a component is called wandering in the supplied statement.

The source leaves $k$ unquantified, so it does not specify whether existence is requested in some positive dimension, in every positive dimension, or in a particular intended dimension. The question above is therefore presented as a family of questions indexed by $k$, pending clarification. No restriction on the degree of $F$ is supplied, and none is added here. Nonnegative iterate indices are the convention used in this draft; their range is not explicit in the supplied formula.

Short English statement

For complex projective space of dimension $k$, ask whether a holomorphic self-map can have a Fatou component whose forward images are pairwise disjoint. The intended quantifier or restriction on $k$ is unspecified, and no degree hypothesis is supplied. The registry labels the problem open; that label is supplied metadata, not an independently verified assessment.
