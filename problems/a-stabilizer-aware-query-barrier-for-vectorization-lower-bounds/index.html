Verbatim supplied catalogue question

Quantum lower bounds for group-theoretic problems in the generic group model

We would like to solidify the credentials of group-theoretic cryptography as post-quantum by developing lower bounds for the quantum complexity of problems arising in group theory. It would be especially nice to develop such a bound for the vectorisation problem, since this underpins many hardness problems in the area.

Attempt and results

We attempt a quantum lower bound through equality tests of candidate transporters. The resulting theorem is correct for a restricted oracle, but the reduction needed to apply it to a full group-action oracle fails. Keeping that distinction is essential to the source's broad lower-bound question.
The relation differs from recovery of a sampled representative.
Let a finite group $G$ act on $X$, fix $x$, and put $K=\operatorname{Stab}(x)$. If $y=s\cdot x$, then $g\cdot x=y$ exactly when $g\in sK$: apply $s^{-1}$ and use the definition of $K$. If $s$ is uniform on $G$, conditional on $y$ it is uniform on the fiber $sK$, because all its elements had equal prior probability. An estimator using only $y$ and randomness independent of $s$ therefore guesses that particular sampled $s$ with probability at most $1/|K|$. Vectorization instead accepts any element of the fiber, so this information bound is not a lower bound on success in the actual relation problem.
A self-contained quantum lower bound for a candidate-test oracle.
Partition a finite candidate set into $L$ equal fibers $C_1,\ldots,C_L$. An unknown fiber $C_i$ is chosen uniformly. The only input-dependent oracle is the reversible membership test $O_i|g,b\rangle=|g,b\mathbin\oplus\mathbf1_{g\in C_i}\rangle$; all other gates and initial states are independent of $i$. The algorithm makes $q$ queries and outputs one candidate. Purify intermediate randomness and measurements into registers, so it suffices to use unit vectors and a final projective measurement after adding an output register. Let $\psi_i$ be the final state on $O_i$, and $\psi_0$ the final state on the all-zero oracle. Just before query $t$ on the all-zero run, let $P_i$ project onto query candidates in $C_i$. The projectors partition the query register, so $\sum_i\|P_i\phi_t\|^2=1$. A telescoping hybrid, replacing one oracle call at a time while keeping all remaining transformations unitary, gives \[ \|\psi_i-\psi_0\|\le2\sum_{t=1}^q\|P_i\phi_t\|. \] One can obtain this directly by subtracting the two time recurrences: insert $O_i\phi_t$ between $O_i\psi_{i,t}$ and $O_0\phi_t$; the previous-state difference retains its norm and $O_i-O_0$ has norm at most two on $P_i$ and vanishes on its complement. Cauchy--Schwarz now gives $\sum_i\|\psi_i-\psi_0\|^2\le4q^2$. Let $Q_i$ project onto outputs in $C_i$. For each $i$, $\|Q_i\psi_i\|\le\|Q_i\psi_0\|+\|\psi_i-\psi_0\|$. Applying the Euclidean triangle inequality across the index $i$ and using $\sum_i\|Q_i\psi_0\|^2\le1$ yields \[ \frac1L\sum_i\Pr_i(\hbox{output in }C_i) \le\frac{(2q+1)^2}{L}. \] Thus a fixed positive average success probability requires $q=\Omega(\sqrt L)$ as $L\to\infty$. The proof includes output without a final verification query and does not assume all candidate labels are distinct as group witnesses; fibers explicitly account for stabilizers.
The first gap in promoting the bound.
For group-action vectorization, one can implement the candidate test by evaluating $g\cdot x$ and comparing with $y$. This simulates the weaker membership oracle using the stronger action oracle. A lower bound for the weaker oracle does not therefore lower-bound algorithms using the stronger one; the simulation goes in the wrong direction for that inference. For an extreme representation example, let $G=X=\mathbb Z/L\mathbb Z$ act by translation on canonical residue encodings. From $x,y$, the transporter $y-x$ is obtained immediately by subtraction, even though a model exposing only yes/no tests of unknown candidates has the proved search lower bound. This is not a generic-encoding lower-bound counterexample: it shows why the source must fix which representation and operations are available.
