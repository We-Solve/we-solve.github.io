Linear Optimization over Mixed-Integer Bipartite Systems

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

A linear program optimizes $c^Tx$ over a polyhedron $\{x:Ax\leq b\}$. In the simplex method a pivot moves between adjacent basic feasible solutions; a pivot rule chooses the next such move.

An integer program imposes integral coordinates on a system of constraints. A mixed-integer program allows both integral and real coordinates; $\operatorname{conv}(S)$ denotes the set of finite convex combinations of feasible points of $S$.

Statement recorded in the supplied source.
For a bipartite graph $G=(U\cup V,E)$, an integral-coordinate set $I$, and $S(G,I)=\{x\in\mathbb{R}^{U\cup V}:x_i+x_j\geq b_{ij}\text{ for }ij\in E,\ x_i\in\mathbb{Z}\text{ for }i\in I\}$, determine the complexity of optimizing a linear function over $S(G,I)$, equivalently deciding whether a given $\bar{x}$ belongs to $\operatorname{conv}(S(G,I))$. [S2]
