Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

A linear program optimizes $c^Tx$ over a polyhedron $\{x:Ax\leq b\}$. In the simplex method a pivot moves between adjacent basic feasible solutions; a pivot rule chooses the next such move.

An integer program imposes integral coordinates on a system of constraints. A mixed-integer program allows both integral and real coordinates; $\operatorname{conv}(S)$ denotes the set of finite convex combinations of feasible points of $S$.

Statement recorded in the supplied source.

Verbatim supplied catalogue question

For a bipartite graph $G=(U\cup V,E)$, an integral-coordinate set $I$, and $S(G,I)=\{x\in\mathbb{R}^{U\cup V}:x_i+x_j\geq b_{ij}\text{ for }ij\in E,\ x_i\in\mathbb{Z}\text{ for }i\in I\}$, determine the complexity of optimizing a linear function over $S(G,I)$, equivalently deciding whether a given $\bar{x}$ belongs to $\operatorname{conv}(S(G,I))$.

Attempted reduction to ordinary linear programming

The source's $b_{ij}$ are rational, $k$ is their least common denominator, and variables have no nonnegativity constraints unless separately stated. We try to recover an exact ordinary linear relaxation by bipartite rounding. It succeeds in two boundary regimes and fails on a small mixed example.
Integral right-hand sides and fully integral variable sets.
For integer $b_{uv}$, any relaxed feasible $x$ can be decomposed as a finite convex combination of fully integral feasible points. To prove it, put $y_u=x_u$ on $U$ and $y_v=-x_v$ on $V$, so $y_u-y_v\ge b_{uv}$. Round all $y_i$ to $z_i(\theta)=\lfloor y_i+\theta\rfloor$ using one uniform $\theta\in[0,1)$. Integer translation of floors implies $z_u-z_v\ge b_{uv}$ on every edge. Undoing the sign change gives an integer feasible point for every $\theta$. For $y_i=m+r$ with $m\in\mathbb Z$ and $0\le r<1$, the rounded value is $m$ for a set of parameters of length $1-r$ and $m+1$ for length $r$, hence has mean $y_i$. Partitioning $[0,1)$ at the finitely many coordinate thresholds makes this a finite convex combination with mean $x$. Thus for every $I$ and integer right-hand sides, \[ \operatorname{conv}(S(G,I))=\{x:x_u+x_v\ge b_{uv}\ \forall uv\in E\}. \] If instead $I=U\cup V$ and the right-hand sides are rational, replace every $b_{uv}$ by $\lceil b_{uv}\rceil$: an integer sum satisfies the original inequality exactly when it satisfies the rounded one. The preceding proof then gives the hull for that regime as well. If $I$ is empty, the original set is already convex. Membership in these displayed hulls is checked by their edge inequalities. Optimization reduces to ordinary rational linear programming, with its standard polynomial-time algorithms as an external computational dependency; no new LP algorithm is claimed.
A three-vertex mixed example blocks the same relaxation.
Use a path with integral endpoints $x_1,x_2\in\mathbb Z$ and continuous center $z\in\mathbb R$, with \[ x_1+z\ge1/3,\qquad x_2+z\ge2/3. \] The denominator parameter is three. Every mixed feasible point satisfies \[ x_1+x_2+2z\ge4/3. \] Indeed put $m=x_2-x_1\in\mathbb Z$ and $w=x_1+z$. The constraints say $w\ge\max(1/3,2/3-m)$, so the objective is $m+2w$. If $m\le0$, this is at least $4/3-m\ge4/3$. If $m\ge1$, it is at least $m+2/3\ge5/3$. Equality $4/3$ is attained by $x_1=x_2=0,z=2/3$. In contrast $(x_1,x_2,z)=(1/3,2/3,0)$ is feasible for the ordinary continuous relaxation and has objective one. Since the stronger inequality is preserved by convex combinations, this point is outside the mixed hull. The objective is bounded below despite unrestricted variable signs, as the calculation shows; no unmentioned nonnegativity assumption creates the gap.
Denominator enumeration is not a bit-polynomial conclusion.
The report studies extended formulations whose size grows with $k$. Even one right-hand side $b=1/2^L$ has a binary encoding of length $O(L)$ while its least denominator is $k=2^L$. Therefore an algorithm that explicitly creates $k$ states or variables may take exponential time in the original binary input length. Calling it polynomial in $k$ does not classify the source's general encoded-input problem. This numerical example is exact and requires no asymptotic number-theoretic assumption.

Adversarial audit and unresolved complexity

The audit checked unrestricted-sign variables, use of the common random threshold, finite rather than merely limiting mixtures, and the denominator encoding. The supplied optimization/membership equivalence requires a precise oracle/encoding formulation; it is not proved by the edge-wise argument. The small path demonstrates why a plain-LP proposal fails, but does not show NP-hardness or prevent another polynomial method. The general rational mixed case and its complexity remain unresolved by this attempt. No numerical experiment was performed.
