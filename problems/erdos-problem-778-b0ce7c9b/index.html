Status Open · erdosproblems.comLLM status Open unverified

Statement

Fix $n\in\mathbb{N}$ and let $K_n$ be the complete graph on vertex set $[n]=\{1,\dots,n\}$. Two players, Alice (red) and Bob (blue), play until every edge of $K_n$ is colored.

Game 1 (unbiased clique game $\mathrm{Clique}(n)$). Alice moves first. On each move, the player colors one previously uncolored edge with their color. At the end, let $G_R$ be the red graph and $G_B$ the blue graph. Alice wins iff \[ \omega(G_R) > \omega(G_B), \] otherwise Bob wins (so a tie counts as a Bob win).

Question 1. Does Bob have a winning strategy for every $n\ge 3$?

Game 2 (biased clique game $\mathrm{Clique}^{(1,2)}(n)$). Alice colors one new edge; then Bob colors two new edges; repeat until all edges are colored. At the end Alice wins iff $\omega(G_R) \ge \omega(G_B)$ (equivalently Bob wins iff $\omega(G_B) > \omega(G_R)$).

Question 2. For $n>3$, does Bob have a winning strategy?

Game 3 (maximum-degree / "star" game $\mathrm{Star}(n)$). This is the unbiased game as in Game 1 (one edge per move, Alice first), but Alice wins iff \[ \Delta(G_R) > \Delta(G_B), \] otherwise Bob wins.

Question 3. Who wins $\mathrm{Star}(n)$?

Useful reformulations. Because every edge is colored exactly once, $G_B$ is the complement of $G_R$ in $K_n$. Hence \[ \omega(G_B)=\omega(\overline{G_R})=\alpha(G_R), \] so in Game 1 Alice wins iff $\omega(G_R) > \alpha(G_R)$. Similarly in Game 3, \[ \Delta(G_B)=\Delta(\overline{G_R}) = (n-1) - \delta(G_R), \] so Alice wins iff \[ \Delta(G_R) + \delta(G_R) > n-1. \] The game is still genuinely two-player: Bob does not control $G_R$ directly, but he controls which edges remain available.

Restatement from Math-5888-A2 r1, with the source manuscript’s qualifications.

Problem #778

1. ROUND-2 OBJECTIVE

I invoke the fail-safe "strict advance" clause rather than claiming a full proof or disproof. Relative to Round 1, the most promising gap to close is the finite verified range for the symmetric games. The new goal is to extend the exact solved range for Clique$(n)$ and Star$(n)$ from $n \leq 6$ to the largest range currently justified by the later literature, and to separate that from the still-open biased game Clique$^{(1,2)}(n)$.

2. Round-1 FOUNDATION USED

I use the following Round-1 results without re-proving them.

  1. The reformulation of Clique$(n)$ at game end as \[ \omega(G_R) > \omega(G_B) = \alpha(G_R), \] so Bob wins iff $\alpha(G_R)\geq \omega(G_R)$.
  2. The reformulation of Star$(n)$ at game end as \[ \Delta(G_B)=n-1-\delta(G_R), \] so Alice wins iff $\Delta(G_R)+\delta(G_R)>n-1$.
  3. The exact computations from Round 1: Bob wins Clique$(n)$ for $n=3,4,5,6$; Bob wins Clique$^{(1,2)}(n)$ for $n=4,5,6$; Alice wins Star$(3)$ and Bob wins Star$(n)$ for $n=4,5,6$.

3. NEW INSIGHT / TOOL (ROUND 2)

The substantive new input is the 2025 paper of Cambie--Provoost [CaPr25], which contains two pieces of information not used in Round 1:

  1. Proposition 9 of [CaPr25] proves: \[ \mbox{Bob wins Clique}(n)\ \mbox{for every } 3 \leq n \leq 8. \]
  2. Table 1 of [CaPr25] gives the exact Star-game outcomes on complete graphs up to $K_8$, namely \[ \mathrm{out}_{\Delta}(K_7)=(4,4), \qquad \mathrm{out}_{\Delta}(K_8)=(5,5), \] together with the previously known values for $K_3,\dots,K_6$.

The same paper also explains the computer verification method: two independent implementations were used, and the C implementation works by generating all non-isomorphic terminal states and then solving the game backwards using canonical labellings from nauty; see Section 6 of [CaPr25].

4. ATTACK PLAN (ROUND 2)

Round 1 left two concrete finite-range gaps:

  1. Clique$(n)$ was only verified up to $n=6$.
  2. Star$(n)$ was only verified up to $n=6$.

The Round-2 plan is therefore to import the strongest later exact results for these ranges, check carefully that the quoted statements really concern the original clique and star games on complete graphs (not just the colex variant), and update the strongest verified finite range.

No genuinely new theorem for the biased game Clique$^{(1,2)}(n)$ was found in the sources checked, so for that part I only report that the Round-1 state of knowledge remains the best verified information in this write-up.

5. WORK (ROUND 2)

5.1 Clique$(n)$: exact range extended to $n \leq 8$.

Cambie--Provoost state in Proposition 9 that:

If Alice wins Clique$(n)$ for some $n \geq 8$, then Bob wins Clique$(n+3)$. Bob wins Clique$(n)$ for $3 \leq n \leq 8$.

Therefore the exact solved range from Round 1 extends immediately to \[ \mbox{Bob wins Clique}(n)\ \mbox{for every } 3 \leq n \leq 8. \]

This is a strict advance over Round 1, which only verified $3 \leq n \leq 6$.

5.2 Star$(n)$: exact range extended to $n \leq 8$.

Table 1 of [CaPr25] records the Star-game outcome $\mathrm{out}_{\Delta}(G)$ for the colex graphs $C(m)$ with small $m$. For the complete graphs, the relevant rows are \[ K_3,\ K_4,\ K_5,\ K_6,\ K_7,\ K_8, \] corresponding to \[ m=3,6,10,15,21,28. \] From the table one reads: \[ \mathrm{out}_{\Delta}(K_3)=(2,1),\quad \mathrm{out}_{\Delta}(K_4)=(2,2),\quad \mathrm{out}_{\Delta}(K_5)=(3,3), \] \[ \mathrm{out}_{\Delta}(K_6)=(4,4),\quad \mathrm{out}_{\Delta}(K_7)=(4,4),\quad \mathrm{out}_{\Delta}(K_8)=(5,5). \]

Hence: \[ \mbox{Alice wins Star}(3), \] and \[ \mbox{Bob wins Star}(n)\ \mbox{for every } 4 \leq n \leq 8. \]

Again this strictly strengthens Round 1, which only established the cases up to $n=6$.

5.3 The biased game Clique$^{(1,2)}(n)$.

No later theorem in the checked sources resolves Erdős's original biased question with bias $(1,2)$. The later paper [CaPr25] proves the stronger-bias statement Clique$^{(1,3)}(n)$ is a Bob win for every $n \geq 4$, and explicitly remarks that the $(1,2)$ case remains difficult. Thus the only concrete verified information retained from Round 1 in this write-up is: \[ \mbox{Bob wins Clique}^{(1,2)}(n)\ \mbox{for } n=4,5,6. \]

6. ADVERSARIAL VERIFICATION

I checked the main possible failure modes.

  1. Was Table 1 about the wrong game? No. The table has separate columns. The Star-game information is in the column $\mathrm{out}_{\Delta}(G)$, so the entries quoted above really are Star-game outcomes.

  2. Was Proposition 9 only about the colex game? No. Proposition 9 explicitly names Clique$(n)$, i.e. the original clique game on $K_n$.

  3. Could the computation be fragile? The same paper states that two independent implementations were used for the computer-aided verifications, and Section 6 explains the reverse dynamic-programming method over non-isomorphic states using canonical labellings. This does not turn the result into a hand proof, but it addresses the main concern about transcription or implementation error.

  4. Did Round 2 accidentally overclaim something about the biased $(1,2)$ game? No. I make no new theorem there; I only preserve the Round-1 exact computations for $n \leq 6$ and record that the literature checked still leaves the full question open.

7. FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

The strict Round-2 advance is the extension of the exactly verified finite range: \[ \mbox{Bob wins Clique}(n)\ \mbox{for } 3 \leq n \leq 8, \] and \[ \mbox{Alice wins Star}(3),\ \mbox{Bob wins Star}(n)\ \mbox{for } 4 \leq n \leq 8. \]

The full conjectures for Clique$(n)$ and Star$(n)$ remain open, and no new rigorous progress was found here on Clique$^{(1,2)}(n)$ beyond the Round-1 range $n \leq 6$.

Erdős Problem #778: independent continuation

Date: 2026-09-23. Research attempt; no claim of a new published result.

1) TARGET AND SOURCE AUDIT

In the complete-graph edge claiming games, Alice claims one red edge per move and Bob claims blue edges, with ties awarded to Bob. Compare their largest cliques, also considering the maximum-degree (star) variant and Bob bias two.

All supplied versions considered: 778.tex. The source imports the symmetric outcomes through $n=8$ and retains biased Clique$^{(1,2)}(n)$ only through $n=6$. I independently implement exact minimax and extend the checked biased range to $n=7$. This is a finite computational result, with no claim of a general strategy.

2) WORK

Exact recursion.
Index the edges of $K_n$ by bit positions. A state is $(R,B,t)$, the disjoint red and blue masks and the player to move. At terminal states return true precisely when Alice has the strictly larger score. For a clique score, test all vertex subsets for completeness; for a star score, take maximum degree. The recursion is \[ W(R,B,A)=\bigvee_{e\ \mathrm{free}}W(R\cup\{e\},B,B\mathrm{ob}), \] \[ W(R,B,B\mathrm{ob})=\bigwedge_{S\subseteq E_{\rm free},\ |S|=\min(b,|E_{\rm free}|)}W(R,B\cup S,A), \] where $b$ is Bob's bias. An induction on the number of unclaimed edges proves the recursion exactly represents optimal play. Bob's consecutive selections form an unordered batch, since Alice does not move between them.

The executable verification/batch_2_games.py evaluates this recursion with memoization and short-circuit logical operations. Actual results: Bob wins both clique biases for $3\le n\le5$, Alice wins the star game at $n=3$, and Bob wins it at $n=4,5$. For bias two, Bob also wins at $n=6$ and $n=7$. The $n=6$ run visits 5,947 memoized states; the $n=7$ run visits 199,911. Thus the source's independently checked biased range extends to \[ \boxed{\text{Bob wins Clique}^{(1,2)}(n)\quad(3\le n\le7).} \] This is a reproducible finite certificate by exhaustive recursive evaluation, not an assertion that all ternary colorings were explicitly visited. Unvisited branches are skipped only when the Boolean recurrence already determines the value.

3) ADVERSARIAL VERIFICATION

Ties go to Bob, Alice moves first, and a final incomplete Bob move takes every remaining edge. These conventions are implemented explicitly. There is no symmetry reduction or heuristic pruning. A single implementation is evidence with an inspectable exhaustive algorithm, not a formally verified game proof; the source's symmetric $n=7,8$ computations were not reproduced here.

4) FINAL

UNRESOLVED. No winning strategy for arbitrary $n$ is obtained for either bias or for the star variant. The new bounded computation cannot justify extrapolation.

5) SOURCES CHECKED

Full source read. Checked Cambie--Provoost, https://arxiv.org/html/2505.03497v2, Proposition 9, on 2026-09-23, confirming the symmetric $3\le n\le8$ range. The biased $n=7$ result above comes from the local executable computation.

6) COMPLETION ESTIMATE

This is a conservative subjective measure of progress toward the original question, not a probability of correctness or a claim that the remaining work is routine. COMPLETION: 12%

Problem #778 (Clique-building game and variants)

1) FORMAL RESTATEMENT

Fix $n\in\mathbb{N}$ and let $K_n$ be the complete graph on vertex set $[n]=\{1,\dots,n\}$. Two players, Alice (red) and Bob (blue), play until every edge of $K_n$ is colored.

Game 1 (unbiased clique game $\mathrm{Clique}(n)$). Alice moves first. On each move, the player colors one previously uncolored edge with their color. At the end, let $G_R$ be the red graph and $G_B$ the blue graph. Alice wins iff \[ \omega(G_R) > \omega(G_B), \] otherwise Bob wins (so a tie counts as a Bob win).

Question 1. Does Bob have a winning strategy for every $n\ge 3$?

Game 2 (biased clique game $\mathrm{Clique}^{(1,2)}(n)$). Alice colors one new edge; then Bob colors two new edges; repeat until all edges are colored. At the end Alice wins iff $\omega(G_R) \ge \omega(G_B)$ (equivalently Bob wins iff $\omega(G_B) > \omega(G_R)$).

Question 2. For $n>3$, does Bob have a winning strategy?

Game 3 (maximum-degree / "star" game $\mathrm{Star}(n)$). This is the unbiased game as in Game 1 (one edge per move, Alice first), but Alice wins iff \[ \Delta(G_R) > \Delta(G_B), \] otherwise Bob wins.

Question 3. Who wins $\mathrm{Star}(n)$?

Useful reformulations. Because every edge is colored exactly once, $G_B$ is the complement of $G_R$ in $K_n$. Hence \[ \omega(G_B)=\omega(\overline{G_R})=\alpha(G_R), \] so in Game 1 Alice wins iff $\omega(G_R) > \alpha(G_R)$. Similarly in Game 3, \[ \Delta(G_B)=\Delta(\overline{G_R}) = (n-1) - \delta(G_R), \] so Alice wins iff \[ \Delta(G_R) + \delta(G_R) > n-1. \] The game is still genuinely two-player: Bob does not control $G_R$ directly, but he controls which edges remain available.

2) QUICK LITERATURE/CONTEXT CHECK

These games were asked by Erdős and have been studied recently.

  • Malekshahian--Spiro $2024$ study $\mathrm{Clique}(n)$, biased variants $\mathrm{Clique}^{(p,q)}(n)$, and the star game. They prove that Bob wins $\mathrm{Clique}(n)$ for a set of $n$ of natural density at least $3/4$, via the propagation statement: if Alice wins $\mathrm{Clique}(n)$ then Bob wins $\mathrm{Clique}(n+1)$, $\mathrm{Clique}(n+2)$, and $\mathrm{Clique}(n+3)$. They also prove a biased result of the form: if $q\ge 2p+1$ then for all sufficiently large $n$, Bob wins $\mathrm{Clique}^{(p,q)}(n)$ (in particular, $\mathrm{Clique}^{(1,3)}(n)$ is eventually a Bob win). For the star game, they show Bob wins on a set of $n$ of density at least $2/3$, with an analogous "if Alice wins at $n$ then Bob wins at $n+1,n+2$" propagation.
  • Cambie--Provoost (arXiv v2 posted Oct 28, 2025) revisit Erdős's edge-claiming games. They explicitly conjecture that Bob wins $\mathrm{Clique}(n)$ for every $n\ne 2$ (so in particular for all $n\ge 3$), and they prove (for all $n\ge 4$) the biased case $\mathrm{Clique}^{(1,3)}(n)$ as a Bob win.

So as of these references, the exact winner of $\mathrm{Clique}(n)$ for every $n$ (Question 1), the winner of $\mathrm{Clique}^{(1,2)}(n)$ for all $n>3$ (Question 2), and the winner of $\mathrm{Star}(n)$ for all $n$ (Question 3) remain open.

3) ATTACK PLAN

I try two complementary approaches.

(A) "Structure/strategy" approach. Try to find an invariant Bob can maintain (or a pairing strategy) forcing $\alpha(G_R)\ge \omega(G_R)$ at the end. Natural candidates:

  • Maintain a vertex partition or a graph homomorphism $\varphi$ such that every red clique maps to a blue clique (or to a red independent set), implying $\omega(G_R)\le \alpha(G_R)$.
  • Maintain a degree-balance condition to force $\Delta(G_R)+\delta(G_R)\le n-1$ in $\mathrm{Star}(n)$.

(B) "Counterexample search" approach. Compute winners for small $n$ exactly by minimax search. If Alice ever wins at some small $n$, that gives immediate disproof of "Bob wins for all $n$". If Bob wins all small cases, that is evidence (but not proof) for the conjecture.

4) WORK

4.1 Tiny cases by hand

Clique game $\mathrm{Clique}(3)$.
$K_3$ has $3$ edges. Alice moves first and hence gets $2$ edges total; Bob gets $1$. Any nonempty edge set in $K_3$ has clique number $2$, so $\omega(G_R)=\omega(G_B)=2$ and Bob wins (tie goes to Bob).
Star game $\mathrm{Star}(3)$.
Again Alice gets $2$ edges and Bob gets $1$. Any $2$-edge subgraph of $K_3$ has maximum degree $2$, while any $1$-edge subgraph has maximum degree $1$. Hence Alice wins $\mathrm{Star}(3)$.

4.2 Exact computation for $n\le 6$

I ran an exact minimax search (full game tree with memoization) for the three games for $n\le 6$. The outcomes are:
$n$$\mathrm{Clique}(n)$ $Q1$$\mathrm{Clique}^{(1,2)}(n)$ $Q2$$\mathrm{Star}(n)$ $Q3$
3Bob(not asked)Alice
4BobBobBob
5BobBobBob
6BobBobBob

So Bob wins all computed cases of $\mathrm{Clique}(n)$ for $3\le n\le 6$, and Bob wins all computed cases of $\mathrm{Clique}^{(1,2)}(n)$ for $4\le n\le 6$. For the star game, Alice wins only at $n=3$ among these values.

Remark. These computations do not resolve the questions, but they are consistent with the conjecture that Bob wins $\mathrm{Clique}(n)$ for all $n\ge 3$ and that Bob wins $\mathrm{Clique}^{(1,2)}(n)$ for all $n\ge 4$.

5) VERIFICATION

  • The hand checks for $n=3$ agree with the minimax output.
  • The minimax computation is feasible for $n\le 6$ because the total number of edges is $\binom{6}{2}=15$ and the total number of edge-coloring states is $3^{15}\approx 1.43\times 10^7$.
  • The computed outcomes are consistent with the published conjectures and partial density theorems quoted above.

6) FINAL

LABEL: UNRESOLVED.
What I can prove/confirm here.
  • Exact game-tree computation shows Bob wins $\mathrm{Clique}(n)$ for $3\le n\le 6$.
  • Exact game-tree computation shows Bob wins $\mathrm{Clique}^{(1,2)}(n)$ for $4\le n\le 6$.
  • Exact game-tree computation shows Bob wins $\mathrm{Star}(n)$ for $4\le n\le 6$ (and Alice wins $\mathrm{Star}(3)$).
  • Published results imply Bob wins $\mathrm{Clique}(n)$ for a set of $n$ of density at least $3/4$, and Bob wins $\mathrm{Star}(n)$ for a set of $n$ of density at least $2/3$, but do not settle all $n$.
Strongest heuristic.
The complement reformulation "Alice wins iff $\omega(G_R) > \alpha(G_R)$" suggests Bob can try to keep $G_R$ in a regime where independence is at least as large as clique number. The propagation phenomena (Alice-win at $n$ forces Bob-win at the next several $n$) also strongly point to "Alice-win" being rare, hence a plausible conjecture that Bob always wins.
Main obstacle.
A universal Bob strategy for all $n$ (even in the unbiased game) seems to require a global invariant that survives Alice's adaptive choices. Simple mirroring via a graph automorphism cannot work directly because any involution of $K_n$ induced by vertex permutations fixes some edges, preventing a clean pairing of edges.
Next concrete steps.
  1. Try to formalize a Bob strategy that maintains a "certificate" independent set of size equal to the current largest red clique (or larger), updating it after each Alice move.
  2. Push exact computation to $n=7$ with symmetry reduction / canonical labeling (the naive state space $3^{21}$ is too large, but automorphism pruning may help).
  3. For $\mathrm{Star}(n)$, attempt to maintain a tight two-sided bound on all red degrees to force $\Delta+\delta\le n-1$.
