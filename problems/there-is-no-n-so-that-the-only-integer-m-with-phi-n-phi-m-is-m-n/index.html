Math-11208

There is no n so that the only integer m with phi(n) = phi(m) is m=n

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.

For $n\in\mathbb N$, Euler's totient is \[\varphi(n)=\#\{a\in\mathbb N:1\le a\le n,\ \gcd(a,n)=1\},\] so $\varphi(1)=1$.

Statement recorded in the supplied source.
For every $n\in\mathbb N$, does there exist $m\in\mathbb N\setminus\{n\}$ with $\varphi(m)=\varphi(n)$? Equivalently, can any value attained by the totient function have exactly one positive-integer preimage? [S2]

Short English statement

Does every positive integer share its totient value with another positive integer?
