Math-3913

Convex Hulls of Selected Barycenters

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $n,d,k$ be integers with $n\geq 1$, $d\geq 1$, and $1\leq k\leq n$. These are the conventional nondegenerate parameter ranges; the supplied statement does not explicitly specify them. Let $[n]=\{1,\ldots,n\}$, and let $P=\{p_1,\ldots,p_n\}\subset{\mathbb{R}}^d$ be a set of $n$ distinct points. For each $I\subseteq[n]$ with $|I|=k$, define its $k$-point barycenter by \[ b_I=\frac{1}{k}\sum_{i\in I}p_i, \qquad B_k(P)=\{b_I:I\subseteq[n],\ |I|=k\}. \] Thus each barycenter uses $k$ distinct points; coincident barycenters arising from different index sets represent the same point of $B_k(P)$. No general-position or full-dimensionality assumption is supplied.

For a nonempty subset $S\subseteq B_k(P)$, let $Q_S=\operatorname{conv}(S)$. Write $\operatorname{vert}(Q_S)$ for its set of extreme points, where $x\in Q_S$ is extreme if $x=ty+(1-t)z$, with $y,z\in Q_S$ and $0<t<1$, implies $y=z=x$.

Determine, as a function of $n,d,k$, the extremal quantity \[ M_d(n,k)= \max_{\substack{P\subset{\mathbb{R}}^d\\ |P|=n}} \ \max_{\varnothing\ne S\subseteq B_k(P)} \left|\operatorname{vert}(\operatorname{conv}(S))\right|. \] The selected subset $S$ is arbitrary and need not contain every $k$-point barycenter. Restricting to nonempty selections avoids a convention for the convex hull of the empty set and does not change the maximum if an empty selection is assigned zero vertices.

Short English statement

Choose $n$ distinct points in ${\mathbb{R}}^d$, form the averages of all $k$-element subsets, and select any nonempty collection of these averages. Determine the largest possible number of vertices of the selected collection's convex hull, maximizing over both the original points and the selection. The parameter ranges and extraction boundaries stated above require human review; the supplied open-status label has not been independently verified.
