Statement

Definitions and mathematical statement

The supplied record uses a space of maps $\mathscr{H}$, a translation operator on $\mathscr{H}$, and a subset $\mathscr{U}\subseteq\mathscr{H}$ without defining them. Consequently, the following formulation is conditional on specifying these objects and their measurable structure.

Write $T:\mathscr{H}\to\mathscr{H}$ for the translation operator referred to in the source, and let $\Sigma$ denote the intended sigma-algebra on $\mathscr{H}$. Assuming $T$ is measurable, a probability measure $\mu$ on $(\mathscr{H},\Sigma)$ is invariant if \[ \mu(T^{-1}A)=\mu(A)\qquad\text{for every }A\in\Sigma. \] Let $\mathscr{C}\subseteq\mathscr{H}$ denote the set of constant maps. Assuming $\mathscr{C}\in\Sigma$, the source calls $\mu$ non-trivial when $\mu(\mathscr{C})=0$. An invariant probability measure is ergodic if every invariant measurable set has measure zero or one; the precise convention for invariance must agree with the intended translation action.

Problem (Dinh--Sibony, 2018, Problem 12). Given a non-trivial invariant probability measure $\mu$ on $\mathscr{H}$ as in the source, what can be said about \[ \mu(\mathscr{U})? \] This expression requires $\mathscr{U}$ to be measurable for the intended measure. The record does not define $\mathscr{U}$ or specify a proposed value or bound. It also does not make clear whether the question concerns all such invariant measures or specifically the ergodic measures discussed immediately before it. These missing qualifications prevent a fully specified mathematical statement.

Short English statement

Dinh and Sibony ask what can be said about the measure of $\mathscr{U}$ under a non-trivial translation-invariant probability measure on $\mathscr{H}$. The supplied excerpt omits the definitions of the space, the translation operator, and the subset, and leaves the intended ergodicity assumption unclear.
