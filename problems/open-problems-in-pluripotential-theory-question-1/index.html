Open Problems in Pluripotential Theory — Question 1

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $n\geq 1$ and let $\Omega\subset{\mathbb{C}}^n$ be a domain, meaning a nonempty connected open set. A function $u:\Omega\to[-\infty,\infty)$ is plurisubharmonic if it is upper semicontinuous and its restriction to each connected component of the intersection with a complex affine line is subharmonic or identically $-\infty$. The source does not specify whether the globally identically $-\infty$ function is admitted.

Let $\varphi$ be an arbitrary plurisubharmonic function on $\Omega$, and let $(\varphi_j)_{j\geq1}$ be bounded plurisubharmonic functions on $\Omega$ satisfying \[ \varphi_{j+1}(z)\leq\varphi_j(z),\qquad \lim_{j\to\infty}\varphi_j(z)=\varphi(z)\quad(z\in\Omega). \] Here bounded means bounded on $\Omega$ for each individual $j$; no bound uniform in $j$ is imposed. Write \[ \mu_j=(dd^c\varphi_j)^n \] for the Bedford--Taylor complex Monge--Ampère measure of the bounded potential $\varphi_j$. Fix one normalization of $d^c$ throughout; the source does not specify that normalization.

For an explicit working interpretation of cluster points, use local weak convergence of positive Radon measures: $\mu_{j_k}\to\mu$ if \[ \lim_{k\to\infty}\int_\Omega f\,{\,\mathrm{d}}\mu_{j_k}=\int_\Omega f\,{\,\mathrm{d}}\mu \quad\text{for every }f\in C_c(\Omega;{\mathbb{R}}). \] Thus, for a fixed approximating sequence, define \[ \mathcal C((\varphi_j))=\left\{\mu\text{ a positive Radon measure on }\Omega:\ \mu_{j_k}\to\mu\text{ locally weakly for some }j_k\uparrow\infty\right\}. \] Question (Bedford, as reported by Dinew, Guedj, and Zeriahi). What can be said about the set of cluster points of $(dd^c\varphi_j)^n$ under these hypotheses?

The local weak topology above is an explicit working convention, not a topology specified in the supplied statement. The source also leaves unresolved whether the intended object is $\mathcal C((\varphi_j))$ for a given approximating sequence or the union of these sets over all bounded decreasing approximations of a fixed $\varphi$. No existence of cluster points or independence from the approximation is asserted.

Short English statement

For an arbitrary plurisubharmonic function, investigate the possible limiting complex Monge--Ampère measures of bounded plurisubharmonic approximations decreasing pointwise to it. The source leaves the convergence topology and the role of the choice of approximation unspecified.
