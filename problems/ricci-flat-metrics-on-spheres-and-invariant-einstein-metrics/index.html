Ricci-Flat Metrics on Spheres and Invariant Einstein Metrics

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $S^n$ denote the smooth $n$-sphere. A smooth Riemannian metric $g$ is Ricci-flat if $\operatorname{Ric}_g=0$, and Einstein if $\operatorname{Ric}_g=\lambda g$ for some constant $\lambda\in{\mathbb{R}}$. A metric is called non-round here if it does not have constant sectional curvature.

The first question is: \[ \text{Does there exist a smooth Riemannian metric }g\text{ on }S^4 \text{ such that }\operatorname{Ric}_g=0? \]

For the second question, put \[ D=\{(2,7),(3,6),(4,5)\},\qquad G_{d_1,d_2}=\operatorname{SO}(d_1+1)\times\operatorname{SO}(d_2+1). \] For a specified smooth action $\rho:G_{d_1,d_2}\to\operatorname{Diff}(S^{10})$, define \[ \mathcal E_{\mathrm{nr}}(\rho)= \left\{g:\begin{array}{l} g\text{ is a smooth Riemannian metric on }S^{10},\\ \rho(h)^*g=g\text{ for every }h\in G_{d_1,d_2},\\ \operatorname{Ric}_g=\lambda g\text{ for some }\lambda\in{\mathbb{R}},\\ g\text{ does not have constant sectional curvature} \end{array}\right\}. \] The supplied clean statement asks, for every $(d_1,d_2)\in D$, whether the three constructed metrics exhaust this class. The supplied background describes the constructed metrics as Einstein metrics with positive scalar curvature; the clean uniqueness question imposes no positive-scalar-curvature restriction on competing metrics.

A precise uniqueness assertion requires the intended action $\rho_{d_1,d_2}$, the three reference metrics $g_{d_1,d_2,j}$, and an equivalence relation $\sim$ on metrics. With those data fixed, the proposed assertion has the form \[ \forall(d_1,d_2)\in D,\qquad \mathcal E_{\mathrm{nr}}(\rho_{d_1,d_2})/\!\sim = \{[g_{d_1,d_2,1}]_{\sim},[g_{d_1,d_2,2}]_{\sim}, [g_{d_1,d_2,3}]_{\sim}\}. \] This display is a schematic formulation, not a fully specified conjecture: the supplied record does not identify those metrics, explicitly specify the group action, or state whether uniqueness is taken up to scaling, arbitrary diffeomorphisms, or equivariant diffeomorphisms. In particular, positive rescaling preserves the Einstein and invariance conditions, so literal equality with only three metric tensors would require an additional normalization or another qualification. The standard block action on $S^{10}\subset{\mathbb{R}}^{d_1+1}\oplus{\mathbb{R}}^{d_2+1}$ is a possible intended action, but is not explicitly specified in the supplied text.

The original excerpt calls these the only invariant "metrics," whereas the clean statement restricts the target to non-round invariant Einstein metrics. The latter restriction is used above as supplied curation. The excerpt attributes the uniqueness conjecture to numerical investigations. The two questions are recorded together; no implication between them is asserted.

Short English statement

The record asks whether $S^4$ carries a smooth Ricci-flat Riemannian metric, and whether the three cited constructions exhaust the non-round invariant Einstein metrics on $S^{10}$ for each listed pair. The second question requires clarification of the action, reference metrics, normalization, and equivalence relation. Its numerical motivation and supplied open status are retained without independent verification.
