Composite Duplicate of Two Rainbow-Matching Conjectures

Let $n\in{\mathbb{Z}}_{\geq 1}$, and write $[n]=\{1,\ldots,n\}$. A Latin square of order $n$ is a function $L:[n]\times[n]\to[n]$ such that each symbol occurs exactly once in each row and exactly once in each column. A partial transversal is a set $T\subseteq[n]\times[n]$ such that, for any distinct $(i,j),(i',j')\in T$, one has $i\ne i'$, $j\ne j'$, and $L(i,j)\ne L(i',j')$. A transversal is a partial transversal of cardinality $n$.

  1. Retained Latin-square conjectures. For every positive integer $n$ and every Latin square $L$ of order $n$, there exists a partial transversal of cardinality $n-1$. If $n$ is odd, there exists a transversal of cardinality $n$. For $n=1$, the first assertion permits the empty partial transversal.
  2. Retained rainbow-matching conjecture. Let $G$ be a bipartite multigraph with vertex classes $A$ and $B$; parallel edges are allowed, and each edge joins a vertex of $A$ to a vertex of $B$. A proper edge-colouring with colour set $[n]$ is a function $c:E(G)\to[n]$ for which distinct edges sharing a vertex have different colours. A matching is a set of edges no two of which share a vertex, and it is rainbow if its edges have pairwise distinct colours. For every positive integer $n$, every such properly edge-coloured bipartite multigraph satisfying \[ \lvert c^{-1}(i)\rvert\geq n+1\qquad\text{for every }i\in[n] \] has a matching $M\subseteq E(G)$ satisfying \[ \lvert M\cap c^{-1}(i)\rvert=1\qquad\text{for every }i\in[n]. \] Thus $M$ has $n$ edges and uses every colour.

The source does not explicitly specify finiteness of the multigraph. The displayed formulation imposes no additional finiteness restriction; its finite and unrestricted versions are equivalent, since one can retain exactly $n+1$ edges of each of the finitely many colours before seeking the required matching. The supplied literature assessment concerns the second clause and does not provide a separate assessment of the Latin-square clauses.

Short English statement

The retained composite record asks whether every Latin square has a partial transversal missing only one row and, at odd order, a full transversal; it also asks whether $n$ sufficiently large colour classes in a properly edge-coloured bipartite multigraph guarantee a matching using all $n$ colours. The registry identifies both clauses as duplicates of other source records. Its supplied partially solved label and literature assessment require independent review.
