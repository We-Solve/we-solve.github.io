Consistency Patterns Among Cardinal Characteristics

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Write $\omega$ for the natural numbers and $\omega_1$ for the first uncountable ordinal. For $f,g\in\omega^\omega$, put $f\leq^*g$ if $\{n\in\omega:f(n)>g(n)\}$ is finite. The bounding and dominating numbers are \[ \mathfrak b=\min\{|B|:B\subseteq\omega^\omega\text{ and }(\forall g\in\omega^\omega)(\exists f\in B)\ f\not\leq^*g\}, \] \[ \mathfrak d=\min\{|D|:D\subseteq\omega^\omega\text{ and }(\forall f\in\omega^\omega)(\exists g\in D)\ f\leq^*g\}. \] Let $[\omega]^\omega$ denote the infinite subsets of $\omega$. A set $S\subseteq\omega$ splits $X\in[\omega]^\omega$ if both $X\cap S$ and $X\setminus S$ are infinite. Define \[ \mathfrak s=\min\{|\mathcal S|:\mathcal S\subseteq[\omega]^\omega\text{ and }(\forall X\in[\omega]^\omega)(\exists S\in\mathcal S)\ S\text{ splits }X\}. \] A family $\mathcal A\subseteq[\omega]^\omega$ is almost disjoint if distinct members have finite intersection. It is maximal almost disjoint if every $X\in[\omega]^\omega$ has infinite intersection with some member of $\mathcal A$. Define \[ \mathfrak a=\min\{|\mathcal A|:\mathcal A\text{ is an infinite maximal almost disjoint family on }\omega\}. \] The requirement that $\mathcal A$ be infinite excludes finite maximal almost disjoint families.

For an infinite cardinal $\kappa$, a proper ultrafilter $U$ on $\kappa$ is uniform if every member of $U$ has cardinality $\kappa$. A base for $U$ is a family $\mathcal B\subseteq U$ such that \[ (\forall A\in U)(\exists B\in\mathcal B)\ B\subseteq A. \] Under the uniform-ultrafilter convention, define \[ \mathfrak u(\kappa)=\min\{|\mathcal B|:\mathcal B\text{ is a base for a uniform ultrafilter on }\kappa\}. \] Here $2^{\aleph_1}=|\mathcal P(\omega_1)|$.

Using these standard interpretations, the supplied record asks the following three consistency questions, with all characteristics computed inside the model in question:

  1. Can a model of $\mathrm{ZFC}$ satisfy $\mathfrak b<\mathfrak s<\mathfrak d$?
  2. Can a model of $\mathrm{ZFC}$ satisfy $\mathfrak b<\mathfrak a<\mathfrak s$?
  3. Can a model of $\mathrm{ZFC}$ satisfy $\mathfrak u(\omega_1)<2^{\aleph_1}$?
The record supplies no definitions of these characteristics. In particular, the third question above is conditional on the intended meaning of $\mathfrak u(\omega_1)$ being the uniform-ultrafilter number with the stated base convention. The record also does not specify a relative-consistency hypothesis, permissible additional axioms, or large-cardinal assumptions. Taking $\mathrm{ZFC}$ as the ambient theory is an explicit conventional interpretation, not a supplied consistency-strength assertion. The questions are presented separately; the record does not explicitly ask for one model satisfying all three inequalities simultaneously.

Short English statement

The record asks whether three strict inequality patterns among cardinal characteristics can occur in models of set theory. The first two concern bounding, splitting, dominating, and almost disjointness on $\omega$; the third concerns the size of an ultrafilter base on $\omega_1$, interpreted here using uniform ultrafilters. The exact higher-cardinal convention and consistency assumptions require source confirmation. The supplied status is partially solved; this draft does not independently establish that assessment.
