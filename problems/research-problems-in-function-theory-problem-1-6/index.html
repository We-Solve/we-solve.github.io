Research Problems in Function Theory — Problem 1.6

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $f$ be a nonconstant entire function. Its Nevanlinna characteristic is $T(r,f)$, and its order is $\rho(f)=\limsup_{r\to\infty}\log T(r,f)/\log r$. For a finite value $a\in{\mathbb{C}}$, let $N(r,a;f)$ be the integrated counting function of zeros of $f-a$, counted with multiplicity. Its deficiency is \[ \delta(a,f)=1-\limsup_{r\to\infty}\frac{N(r,a;f)}{T(r,f)}\in[0,1], \] and $a$ is deficient if $\delta(a,f)>0$. Write $D(f)=\{a\in{\mathbb{C}}:\delta(a,f)>0\}$ for the set of finite deficient values. The value $\infty$ is automatically deficient for an entire function, so whether it is included in the source's sets must be checked.

Exact deficient-value problem (N. U. Arakelyan). The source reports that, given $\rho>\tfrac12$ and a countable set $E$, Arakelyan constructed an entire function of order exactly $\rho$ for which every point of $E$ is deficient. It asks whether there can be no additional deficient values. With $E\subset{\mathbb{C}}$ and finite deficient values intended, the quantified question is \[ \forall\rho>\tfrac12\ \forall E\subset{\mathbb{C}}\text{ countable}\quad \exists f\text{ entire}:\rho(f)=\rho\text{ and }D(f)=E. \] No prescribed numerical deficiencies are requested.

Summability conjecture. For an entire function of finite order with deficient values $a_n$, the source conjectures \[ \sum_n\left(\log[1/\delta(a_n,f)]\right)^{-1}<+\infty. \] The natural summability interpretation lists distinct finite deficient values without repetition. The displayed summands are positive and finite only for $0<\delta(a_n,f)<1$; at $\delta=1$ the denominator is zero. Such deficiencies are not excluded by the source, so their treatment is unresolved. A modified logarithm, deletion of exceptional terms, or an extra hypothesis would change the literal formula and is not imposed here.

The supplied summary labels both parts OPEN-TRIAGE, says they were open in Hayman's 2018 edition, relates the first to the Drasin--Weitsman program and Problem 1.26, and mentions the partial/related bound $\sum\delta^{1/3}<\infty$ attributed to Weitsman. It reports no recent resolution found. These are supplied status and progress claims, not independently verified results.

Short English statement

Can any countable set be exactly the finite deficient-value set of an entire function of prescribed order $\rho>1/2$? The second conjecture asks for logarithmic summability of deficiencies of finite-order entire functions, but its formula requires clarification at deficiency $1$ and about whether infinity is included.
