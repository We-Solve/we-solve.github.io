Math-3808

Weak-Arithmetic Pigeonhole Principles

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

In the usual first-order arithmetic language with addition, multiplication, and order, $\Delta_0$ formulas have only bounded quantifiers. The theory $\mathrm I\Delta_0$ permits induction for these formulas, with parameters. The expanded theory $\mathrm I\Delta_0(f)$ ordinarily allows the additional function symbol $f$ in the bounded-induction scheme; this convention requires source confirmation.

For positive integers $m,n$, write $\mathrm{PHP}_n^m(f)$ for \[ \left(\forall i\le m\ (i\ge1\Rightarrow1\le f(i)\le n)\right) \ \Longrightarrow\ \exists i,j\ (1\le i<j\le m\ \text{and }f(i)=f(j)). \] Thus no function mapping the $m$ pigeons into the $n$ holes can be injective. The notation $\mathrm{PHP}_n^m(\Delta_0)$ denotes the schema for graphs defined by bounded formulas, with parameters: whenever such a graph defines a total single-valued map from $\{1,\ldots,m\}$ to $\{1,\ldots,n\}$, it has a collision. This is a definability schema, not quantification over arbitrary set-coded functions unless the report supplies such coding.

The restored statement asks four provability questions: \[ \mathrm I\Delta_0\ \vdash\ \mathrm{PHP}_n^{n+1}(\Delta_0)\ ? \qquad \mathrm I\Delta_0\ \vdash\ \mathrm{PHP}_n^{n^2}(\Delta_0)\ ? \] \[ \mathrm I\Delta_0(f)\ \vdash\ \mathrm{PHP}_n^{2n}(f)\ ? \qquad \mathrm I\Delta_0(f)\ \vdash\ \mathrm{PHP}_n^{n^2}(f)\ ? \] Provability is intended uniformly in the size parameter and any allowed formula parameters. For $n+1$ and $2n$, the nontrivial domain has $n\ge1$. For $n^2$, one must at least specify $n\ge2$ so that the number of pigeons exceeds the number of holes; the source omits this small-parameter qualification. These are proof-strength questions, not a denial of the ordinary finite pigeonhole principle.

The retained original has different superscripts: it writes $n$ in both "or even" clauses and $n^2$ in the first expanded-language clause, whereas the restored statement uses $n^2$ in the former and $2n$ in the latter. The original $m=n$ clauses do not express a no-injection pigeonhole assertion. This substantive restoration must be checked against the report; it is not merely delimiter normalization. No version is silently identified with another.

Short English statement

The question asks whether bounded-induction arithmetic proves four pigeonhole schemes for definable maps or an added function symbol. The restored pigeon counts are retained, while conflicting original superscripts, small values of $n$, and the expanded induction convention are flagged.
