Math-13016

Polygonal Curve Simplification

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

An $n$-vertex polygonal curve is a piecewise-linear path through an ordered list $p_1,\ldots,p_n$ in an ambient Euclidean space. A simplification is a path represented by fewer segments or vertices, subject to a specified approximation or preservation requirement. The source does not state the ambient dimension or that requirement.

Problem. Can an $n$-vertex polygonal curve be simplified in time nearly linear in $n$?

A standard precise version would supply an error tolerance $\varepsilon$, a curve-distance measure $\operatorname{dist}$, and an admissible output class, then minimize the number of vertices of $Q$ subject to $\operatorname{dist}(P,Q)\leq\varepsilon$. If vertex-restricted output is intended, one would require \[ Q=(p_{i_1},\ldots,p_{i_k}),\qquad1=i_1<\cdots<i_k=n. \] Other versions allow new vertices, fix $k$ and minimize error, or request approximation rather than exact optimization. These are distinct problems; none is selected on behalf of the source. Without a quality condition the path can simply be replaced by a chord, so the omitted condition is essential.

The term nearly linear also needs a bound, for example $O(n\log^c n)$ for a fixed $c$, or $n^{1+o(1)}$, together with a cost model and parameter dependence. The source supplies no such definition, no bit/arithmetic model, and no deterministic or randomized requirement.

The supplied summary reports quadratic classic methods, naming Douglas--Peucker and Imai--Iri, and near-linear algorithms in restricted settings such as 1.5-dimensional terrains or in approximation models. It says the general exact problem under standard metrics remains open, without defining those metrics or giving precise algorithm/optimality guarantees. The quadratic-method statement is not an unconditional quadratic lower bound and does not identify all those methods with one exact optimization task.

Short English statement

Seek a nearly linear-time algorithm for simplifying a polygonal curve. The distance measure, error budget, optimization objective, allowed output vertices, dimension, and meaning of nearly linear are missing, so the exact task must be recovered. Reported fast restricted or approximate algorithms do not specify a solution to the general version.
