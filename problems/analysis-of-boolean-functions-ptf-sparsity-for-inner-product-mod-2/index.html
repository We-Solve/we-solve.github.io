Analysis of Boolean Functions — PTF Sparsity for Inner Product Mod 2

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $n\geq 1$ be an integer and let ${\mathbb{F}}_2=\{0,1\}$ be the field with two elements. For $x,y\in{\mathbb{F}}_2^n$, define the inner product modulo $2$ function by \[ \operatorname{IP}_{2n}(x,y)=(-1)^{\sum_{i=1}^{n}x_i y_i}, \] where the exponent is interpreted modulo $2$.

The supplied extract does not explicitly specify the monomial basis used to measure PTF sparsity. The following formulation uses signed coordinates: encode a bit $u_j\in{\mathbb{F}}_2$ by $z_j=(-1)^{u_j}\in\{-1,1\}$. For a Boolean function $F\colon\{-1,1\}^m\to\{-1,1\}$, a polynomial threshold function (PTF) representation means a real multilinear polynomial \[ p(z)=\sum_{S\subseteq\{1,\ldots,m\}}a_S\prod_{j\in S}z_j \quad\text{such that}\quad F(z)p(z)>0\quad\text{for every }z\in\{-1,1\}^m. \] The empty product is $1$, so a nonzero constant coefficient counts as one monomial. There is no degree restriction. Define \[ \operatorname{sp}_{\mathrm{PTF}}(F) =\min_p\left|\{S:a_S\ne0\}\right|, \] where the minimum is over these representations. This convention requires nonzero polynomial values at every input.

Define the signed-coordinate version of the inner product function by \[ \widetilde{\operatorname{IP}}_{2n} \left((-1)^{x_1},\ldots,(-1)^{x_n}, (-1)^{y_1},\ldots,(-1)^{y_n}\right) =\operatorname{IP}_{2n}(x,y). \] Under the stated convention, the source question is whether \[ \operatorname{sp}_{\mathrm{PTF}} \left(\widetilde{\operatorname{IP}}_{2n}\right)\geq 3^n \qquad\text{for every integer }n\geq1. \] Equivalently, must every such PTF representation have at least $3^n$ nonzero monomials? Ordinary monomials in the original $0,1$ coordinates give a different sparsity notion; the intended basis must therefore be confirmed against the source before this conditional formulation is accepted.

The source additionally records a much stronger question independently asked by Rocco Servedio. With the same PTF convention, for every integer $n\geq1$, every pair of functions $f,g\colon\{-1,1\}^n\to\{-1,1\}$, and all positive integers $s,t$, does \[ \operatorname{sp}_{\mathrm{PTF}}(f)\geq s, \qquad \operatorname{sp}_{\mathrm{PTF}}(g)\geq t \quad\Longrightarrow\quad \operatorname{sp}_{\mathrm{PTF}}(f\oplus g)\geq st \] hold, where $f\oplus g\colon\{-1,1\}^{2n}\to\{-1,1\}$ is defined on disjoint inputs by $(f\oplus g)(z,w)=f(z)g(w)$?

Short English statement

The question asks whether every polynomial threshold representation of inner product modulo $2$ on $2n$ bits needs at least $3^n$ monomials. The formulation above measures monomials in signed coordinates; the supplied extract leaves this basis convention unresolved. A stronger question attributed to Rocco Servedio asks whether PTF sparsity lower bounds multiply when two Boolean functions on disjoint inputs are multiplied.
