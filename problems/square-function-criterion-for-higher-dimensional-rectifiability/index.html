Square-Function Criterion for Higher-Dimensional Rectifiability

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For the conventional geometric interpretation, let $d,n$ be integers with $1\leq n\leq d$, and let $\mu$ be a nonnegative Radon measure on ${\mathbb{R}}^d$. The source does not explicitly specify the parameter range; in particular, whether it intends the restriction $n<d$ requires verification. Write $B(x,r)=\{y\in{\mathbb{R}}^d:|y-x|<r\}$, and let $\omega_n$ be the volume of the unit ball in ${\mathbb{R}}^n$. Use the lower density convention \[ \Theta_{n,*}(x,\mu)=\liminf_{r\downarrow0}\frac{\mu(B(x,r))}{\omega_n r^n}. \] The source does not specify the normalization of this density; omitting $\omega_n$ does not change its strict positivity and finiteness.

A set $E\subseteq{\mathbb{R}}^d$ is countably $n$-rectifiable if there are Lipschitz maps $f_j:{\mathbb{R}}^n\to{\mathbb{R}}^d$, $j\in{\mathbb{N}}$, such that \[ \mathcal H^n\!\left(E\setminus\bigcup_{j=1}^{\infty}f_j({\mathbb{R}}^n)\right)=0. \] Here an $n$-rectifiable measure means a measure $\mu$ satisfying $\mu\ll\mathcal H^n$ and \[ \mu\!\left({\mathbb{R}}^d\setminus\bigcup_{j=1}^{\infty}f_j({\mathbb{R}}^n)\right)=0 \] for such a sequence of Lipschitz maps. These standard conventions make the target explicit; the supplied record does not itself define rectifiability.

Question, with the unresolved quantifier made explicit. Interpret the displayed square-function hypothesis as holding for $\mu$-almost every $x$, a quantifier omitted from that hypothesis in the supplied record. Suppose that, for $\mu$-almost every $x\in{\mathbb{R}}^d$, \[ 0<\Theta_{n,*}(x,\mu)<\infty \quad\text{and}\quad \int_0^1\left(\frac{\mu(B(x,r))}{r^n}-\frac{\mu(B(x,2r))}{(2r)^n}\right)^2\frac{{\,\mathrm{d}} r}{r}<\infty. \] Must $\mu$ be $n$-rectifiable? In particular, when $\mu=\mathcal H^n\!\restriction E$, must $E$ be countably $n$-rectifiable? In this specialization the same hypotheses on $\mu$ remain in force. The record does not state measurability assumptions on $E$; the conventional reading takes $E$ to be $\mathcal H^n$-measurable and requires its restricted measure to be Radon, as in the general question.

The supplied dated assessment labels the problem partially solved: it attributes the affirmative implication for $n=1$ to existing work and says that the report leaves the analogous question for $n>1$ unresolved. This is supplied curation, not an independently verified theorem attribution or present-day status determination.

Short English statement

Does a Radon measure with positive finite lower $n$-dimensional density and finite square integral of its density differences between radii $r$ and $2r$, almost everywhere, have to be $n$-rectifiable? The same question is asked for $\mathcal H^n\!\restriction E$. The parameter range, the square-function quantifier, and the set measurability convention require source confirmation. Supplied dated curation reports an affirmative result in dimension one and an unresolved higher-dimensional question.
