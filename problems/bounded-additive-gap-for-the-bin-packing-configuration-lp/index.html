Bounded additive gap for the bin-packing configuration LP

OpenAI's claim

OpenAI presents the following claims relevant to this question, with manuscript numbers following paper order in Sources. In manuscript 1 (family 118; 2026-09-24), the asserted result is that bin-packing configuration relaxations have arbitrarily large additive gaps, and distinguishing $B$ bins from more than $B+c$ is NP-hard for each fixed $c$, even with all items larger than $1/6$.

Mathematical statement of the claimed result

Manuscript 1.
Let $\operatorname{LP}(I)$ be the fractional configuration-LP optimum for unit-capacity bin packing and $\operatorname{OPT}(I)$ the minimum integer bin count. For each integer $c\ge0$, the manuscript claims a finite rational instance $I$ and integer $B$ with every item larger than $1/6$ and \[ \operatorname{LP}(I)=B,\qquad\operatorname{OPT}(I)>B+c. \] The same fractional value holds if each pattern is required to be a subset of the individual item copies. Hence the additive configuration gap is unbounded.

Outline of the argument

For manuscript 1 (family 118; 2026-09-24), a vertex-cover instance is encoded by rational item labels whose feasible tuples are explicitly controlled. Fractional patterns have value $B$, but extracting any integral packing gives a small vertex cover; a separate finite witness yields the unconditional unbounded gap.
