Coincidence of Detected Slopes for Knot Manifolds

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a torus $T$, a rational slope is an unoriented isotopy class of essential simple closed curves in $T$, equivalently a primitive element of $H_1(T;{\mathbb{Z}})$ modulo sign. The space ${\mathbb{P}}(H_1(T;{\mathbb{R}}))$ also contains irrational slope directions. The supplied record does not specify which slope domain is intended.

Let $\mathcal K$ denote the intended class of knot manifolds. For $M\in\mathcal K$, write $\mathcal S(M)$ for the intended boundary-slope domain, and write \[ \mathcal D_{\mathrm{LO}}(M),\quad \mathcal D_{\mathrm{CTF}}(M),\quad \mathcal D_{\mathrm{NLS}}(M)\subseteq\mathcal S(M) \] for, respectively, the left-orderability-detected, cooriented-taut-foliation-detected, and non-L-space-detected slopes in the intended source conventions.

The question in the supplied corrected statement is whether \[ \forall M\in\mathcal K,\qquad \mathcal D_{\mathrm{LO}}(M) = \mathcal D_{\mathrm{CTF}}(M) = \mathcal D_{\mathrm{NLS}}(M). \] Unresolved qualifications. This is a schematic formulation: the record supplies neither the definition of a knot manifold nor the three detection predicates. In particular, it does not specify the manifold hypotheses, the slope domain, or any conventions concerning limiting slopes or exceptional fillings. No definition of detection solely through Dehn filling is assumed here. These omissions prevent a fully self-contained mathematical statement.

The original extracted passage states only that a following conjecture is closely related to the L-space conjecture for toroidal manifolds; it does not include that conjecture. The supplied corrected statement gives the equality question above, but its equivalence to the omitted conjecture cannot be established from the supplied material.

Short English statement

The supplied corrected question asks whether every knot manifold has exactly the same boundary slopes detected by left orderability, cooriented taut foliations, and the non-L-space condition. The manifold class and detection conventions are missing, so the displayed equality requires clarification and human mathematical review. The registry labels the problem open; that status is supplied curation, not an independently verified conclusion.
