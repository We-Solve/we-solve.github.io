FPRAS for cell-bounded contingency tables

OpenAI's claim

OpenAI presents the following claims relevant to this question, with manuscript numbers following paper order in Sources. In manuscript 1 (family 115; 2026-09-24), the asserted result is that binary-encoded contingency tables with individual cell bounds admit approximate counting with relative-error confidence guarantees and polynomial work on every random execution.

Mathematical statement of the claimed result

Manuscript 1.
Given nonnegative integer row margins $r_i$, column margins $c_j$ with equal total, and cell capacities $b_{ij}$, all in binary, define \[ \Omega=\{A\in\mathbb Z_{\ge0}^{m\times n}:\ \sum_jA_{ij}=r_i,\ \sum_iA_{ij}=c_j,\ A_{ij}\le b_{ij}\},\quad Z=|\Omega|. \] For rational $0<\varepsilon,\delta<1$, the claimed randomized algorithm uses only unbiased bits and returns $\widehat Z\in\mathbb Q_{\ge0}$ with \[ \Pr[(1-\varepsilon)Z\le\widehat Z\le(1+\varepsilon)Z]\ge1-\delta. \] If $Z=0$ the output is always zero. Every execution has bit cost bounded by one polynomial in total binary input length $L$, $\varepsilon^{-1}$ and $\log\delta^{-1}$; no sampling or counting oracle is assumed.

Outline of the argument

For manuscript 1 (family 115; 2026-09-24), softened integral signatures and balanced summation extend weights to defect states. A transport inequality controls the annealing chain, and bin-based rational weight estimation with bounded fair-bit simulation provides a finite implementation.
