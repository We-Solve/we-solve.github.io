Infinite Rank and Torsion in Integral Homology Cobordism

Statement

Definitions and mathematical statement

The source does not specify the manifold category. The following gives a precise formulation for each fixed choice $\mathcal C\in\{\text{smooth},\text{topological}\}$; the intended choice requires confirmation from the source. In the topological category, boundaries are required to be collared. These are conditional formulations, not an assertion that both categories are intended.

An integral homology $3$-sphere is a closed, connected, oriented $3$-manifold $Y$ satisfying \[ H_k(Y;{\mathbb{Z}})\cong H_k(S^3;{\mathbb{Z}})\qquad\text{for every }k\geq 0. \] Two such manifolds $Y_0,Y_1$ are integrally homology cobordant in category $\mathcal C$ if there is a compact, connected, oriented $4$-manifold $W$ in that category with oriented boundary \[ \partial W\cong (-Y_0)\sqcup Y_1, \] such that both boundary inclusions induce isomorphisms \[ H_k(Y_i;{\mathbb{Z}})\xrightarrow{\ \cong\ }H_k(W;{\mathbb{Z}}) \qquad(i\in\{0,1\},\ k\geq0). \] Let $\Theta^3_{{\mathbb{Z}},\mathcal C}$ denote the abelian group of these cobordism classes, with addition induced by oriented connected sum, identity $[S^3]$, and inverse $-[Y]=[-Y]$. This makes explicit the category suppressed in the source notation $\Theta^3_{{\mathbb{Z}}}$.

For the category intended by the source, the two questions are:

  1. Does there exist an injective group homomorphism \[ \bigoplus_{j=1}^{\infty}{\mathbb{Z}}\longrightarrow\Theta^3_{{\mathbb{Z}},\mathcal C}? \] Here the direct sum consists of integer sequences with finite support. Equivalently, do there exist classes $x_1,x_2,\ldots$ such that, for every $m\geq1$ and every $(a_1,\ldots,a_m)\in{\mathbb{Z}}^m$, \[ \sum_{j=1}^{m}a_jx_j=0\quad\Longrightarrow\quad a_1=\cdots=a_m=0? \]
  2. Does there exist $x\in\Theta^3_{{\mathbb{Z}},\mathcal C}\setminus\{0\}$ and an integer $n\geq2$ such that $nx=0$?
The first question follows the explicit statements, which ask for a subgroup isomorphic to the displayed direct sum. The background assessment also uses the word "summands." If a direct summand is intended, the stronger requirement is an isomorphism \[ \Theta^3_{{\mathbb{Z}},\mathcal C}\cong\left(\bigoplus_{j=1}^{\infty}{\mathbb{Z}}\right)\oplus B \] for some abelian group $B$. The supplied record does not resolve this distinction.

The original statement describes these questions as open, while the supplied registry status is partially_solved. Neither description is independently verified here.

Short English statement

For the intended category of integral homology cobordism, ask whether the group contains countably infinitely many independent elements of infinite order, and whether it contains a nonzero element of finite order. The category is unspecified, and the background leaves unclear whether the first question asks for a subgroup or a direct summand.
