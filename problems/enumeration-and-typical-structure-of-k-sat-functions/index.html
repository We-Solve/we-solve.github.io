Enumeration and Typical Structure of $k$-SAT Functions

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

A Boolean function maps $\{0,1\}^n$ to $\{0,1\}$. A $k$-SAT function is represented by a conjunction of clauses of width at most $k$, each clause a disjunction of literals $x_i$ or $\neg x_i$; distinct formulas computing the same function count once. Uniformly choosing a function means choosing from this finite set of distinct functions. A function is unate if complementing an appropriate subset of input coordinates makes it monotone in every coordinate. As $n\to\infty$, $o(1)$ tends to zero.

Statement recorded in the supplied source.
How many $k$-SAT functions on $n$ Boolean variables are there, and what does a typical such function look like? In particular, for fixed $k\geq 2$, is a $1-o(1)$ fraction of all such functions unate? [S2]
Scope qualification.
Here functions, not syntactic formulas, are counted. The asymptotic question fixes the clause width before letting the number of variables grow.
Source status.

Short English statement

Count distinct bounded-clause-width Boolean functions and determine whether almost all are monotone after suitable input-coordinate flips.
