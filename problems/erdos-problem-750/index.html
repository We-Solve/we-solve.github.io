Statement

Let $f:\mathbb{N}\to\mathbb{N}$ be a function with $f(m)\to\infty$ as $m\to\infty$. Does there exist a graph $G$ with infinite chromatic number $\chi(G)=\infty$ such that every (induced) subgraph $H$ of $G$ on $m$ vertices satisfies \[ \alpha(H)\ \ge\ \frac{m}{2} - f(m), \] where $\alpha(H)$ denotes the independence number?

(As usual, it suffices to consider induced subgraphs: deleting edges can only increase $\alpha$.)

Erdős Problem 750: an arbitrary diverging independence error

1. Statement and outcome

Given $f:\mathbb N\to[0,\infty)$ with $f(m)\to\infty$, construct a graph of infinite chromatic number such that every $m$-vertex subgraph $F$ has \[ \alpha(F)\ge m/2-f(m). \] We reconstruct the affirmative May 2026 proof of Chojecki and GPT-5.5 Pro. In fact we establish the stronger conclusion that prescribed, arbitrarily slowly diverging numbers of vertex deletions make all finite subgraphs bipartite. The earlier local attempts prove a fixed proportional error, or one unspecified sublinear error; neither implication alone permits a prescribed $f$. The finite profile induction below supplies that missing quantifier.

2. Construction and the external chromatic input

For a finite graph $H$ and $s\ge1$, define $M_s(H)$ on $\{0,\ldots,s-1\}\times V(H)$ and one apex $z$. Put a copy of $H$ on level zero; for every $uv\in E(H)$ put edges $(i,u)(i+1,v)$ and $(i,v)(i+1,u)$ between consecutive levels; join $z$ to every vertex on level $s-1$. There are no further edges. Let $\mathcal M_2=\{K_2\}$ and $\mathcal M_{r+1}=\{M_s(H):H\in\mathcal M_r, s\ge1\}$. We use Stiebitz's theorem, in precisely this recursive form: \[ H\in\mathcal M_r\quad\Longrightarrow\quad\chi(H)\ge r. \tag{1} \] The opposite bound follows inductively by giving all copies of a base vertex its base color and using one new color for the apex. The nontrivial lower bound $1$, stated as Theorem 1.1 by Müller and Stehlík, is our sole external graph-theoretic input. No assertion about arbitrary base graphs is substituted for it. Write $\operatorname{oct}(H)$ for the minimum number of vertices whose deletion makes $H$ bipartite.

3. Two local facts

For $X\subseteq V(M_s(H))$, let $P$ be the set of base vertices having a copy in $X$, ignoring the apex. Then \[ \operatorname{oct}(M_s(H)[X])\le s\operatorname{oct}(H[P])+\mathbf1_{z\in X}. \tag{2} \] Indeed, delete all copies of a minimum odd-cycle transversal of $H[P]$ and also the apex if present. Color each remaining copy by the side of its base vertex in the surviving bipartite graph. All remaining edges join opposite sides. If $H[P]$ is already bipartite, any odd cycle of $M_s(H[P])$ must contain the apex. Removing that apex leaves an odd-length path between two vertices in level $s-1$. Every edge outside level zero changes the level by one, so a returning path with no level-zero edge has even length. An odd returning path must descend to zero, use an edge there, and return, requiring at least $2s-1$ edges. The original odd cycle therefore has length at least $2s+1$.

4. Finite profiles by induction

We prove that for every nondecreasing unbounded $g:\mathbb N\to\mathbb N_0$ and every $r\ge2$ there is $H\in\mathcal M_r$ satisfying \[ \operatorname{oct}(H[X])\le g(|X|)\qquad(\varnothing\ne X\subseteq V(H)). \tag{3} \] The base $r=2$ uses $K_2$. Suppose the assertion holds for $r$. The zeros of $g$ form a finite initial segment; let its last index be $m_0$, or put $m_0=0$ if there are no zeros. Choose $s\ge2$ with $2s+1>m_0$ and set \[ h(t)=\max\left(0,\left\lfloor\frac{g(t)-1}{s}\right\rfloor\right). \] This function is again nondecreasing and unbounded. Apply the inductive hypothesis to obtain $H_0\in\mathcal M_r$ with profile $h$, and set $H=M_s(H_0)$. Take nonempty $X$, put $m=|X|$, and let $P$ be its projection. If $P=\varnothing$, $X$ consists only of the apex and $3$ holds. Otherwise $|P|\le m$. If $g(m)\ge1$, $2$ gives \[ \operatorname{oct}(H[X])\le s h(|P|)+1\le s h(m)+1\le g(m). \] If $g(m)=0$, then $h(|P|)=0$, so $H_0[P]$ is bipartite. An odd cycle in $H[X]$ would have to contain the apex and have at least $2s+1>m_0\ge m$ vertices, impossible. Thus $3$ holds also in the zero-budget case. The chromatic number is $r+1$ by $1$, completing the induction.

5. Combining all chromatic numbers

Given $g$ as above, apply $3$ for each $r\ge2$ to the profile \[ g_r(t)=\lfloor 2^{-r}g(t)\rfloor \] and obtain a finite graph $H_r$ of chromatic number $r$. Let $G$ be their disjoint union. It is countable and not colorable with any finite number of colors. For a finite vertex set $X$ of size $m$, put $X_r=X\cap V(H_r)$. Choosing the transversals separately gives \[ \operatorname{oct}(G[X]) \le\sum_{r:X_r\ne\varnothing}g_r(|X_r|) \le\sum_{r\ge2}2^{-r}g(m)\le g(m). \] The monotonicity of $g$ is used here; there is no unwarranted additivity assumption on its values. Finally, for the prescribed possibly nonmonotone $f$, define \[ g(m)=\left\lfloor\inf_{t\ge m}2f(t)\right\rfloor. \] This is nonnegative, nondecreasing, unbounded, and at most $2f(m)$. Deleting at most $g(m)$ vertices from any induced $m$-vertex subgraph leaves a bipartite graph. Its larger color class has size at least $(m-g(m))/2\ge m/2-f(m)$. Deleting edges only increases independence number, so the same conclusion holds for every subgraph on those vertices.

Müller and M. Stehlík, Generalised Mycielski graphs and the Borsuk--Ulam theorem, https://arxiv.org/abs/1710.01072. Nonnegativity of $f$ is the natural convention and is necessary to avoid trivial finite-size obstructions. The proof treats every finite size, including zero deletion budgets. This is a full reconstruction of the known affirmative argument relative to $1$, not a new result or a claim to reprove Stiebitz's theorem. Can the EHS input do anything beyond a fixed proportional error?

Theorem 750.1. There exists a graph $G$ with $\chi(G)=\infty$ and a function $g:\mathbb N\to[0,\infty)$ with $g(m)=o(m)$ such that every subgraph $H$ of $G$ on $m$ vertices satisfies \[ \alpha(H)\ge \frac m2-g(m). \] Equivalently, there exists a function $\eta:\mathbb N\to(0,\infty)$ with $\eta(m)\to 0$ such that every $m$-vertex subgraph $H$ of $G$ satisfies \[ \alpha(H)\ge \left(\frac12-\eta(m)\right)m. \]

5) WORK (ROUND-2)

For each integer $j\ge 1$, set \[ \lambda_j:=\frac{1}{(j+1)^2}. \] By the EHS theorem, for each $j$ there exists a graph $X_j$ with \[ \chi(X_j)>j \] such that every induced subgraph $K\subseteq X_j$ on $t$ vertices contains an induced bipartite subgraph on more than $(1-2\lambda_j)t$ vertices.

Because $j$ is finite, the de Bruijn--Erdős theorem implies that $X_j$ has a finite subgraph of chromatic number $>j$; replacing that finite subgraph by the induced subgraph on the same vertex set, we obtain a finite induced subgraph $F_j\subseteq X_j$ with \[ \chi(F_j)>j. \] Since the EHS property is hereditary under taking induced subgraphs, every induced subgraph $K\subseteq F_j$ on $t$ vertices still contains an induced bipartite subgraph on more than $(1-2\lambda_j)t$ vertices. Therefore \[ \alpha(K)\ge \left(\frac12-\lambda_j\right)t \qquad\text{for every induced }K\subseteq F_j. \] Let $v_j:=|V(F_j)|$.

For each $j$, let $n_j$ be a positive integer to be chosen recursively, and let $G_j$ be the disjoint union of $n_j$ copies of $F_j$. Then \[ s_j:=|V(G_j)|=n_jv_j, \qquad \chi(G_j)>j, \] and the same local estimate holds on $G_j$: every induced subgraph $K\subseteq G_j$ on $t$ vertices satisfies \[ \alpha(K)\ge \left(\frac12-\lambda_j\right)t. \] Indeed, $K$ splits across the copies of $F_j$, and independence numbers add over disjoint components.

Now define \[ T_j:=\sum_{i=1}^j s_i, \qquad D_j:=\sum_{i=1}^j \lambda_i s_i. \] I claim that we can choose the integers $n_j$ (equivalently, the multiples $s_j$ of $v_j$) so that \[ D_j\le \frac{T_j}{j+1} \qquad\text{for all }j\ge 1. \]

Feasibility of the recursion. Assume $s_1,\dots,s_{j-1}$ have already been chosen. Then $T_{j-1}$ and $D_{j-1}$ are fixed. We need \[ D_{j-1}+\lambda_js_j\le \frac{T_{j-1}+s_j}{j+1}. \] Since $\lambda_j=1/(j+1)^2$, this is equivalent to \[ D_{j-1}-\frac{T_{j-1}}{j+1} \le s_j\left(\frac{1}{j+1}-\frac{1}{(j+1)^2}\right) = s_j\frac{j}{(j+1)^2}. \] The coefficient on the right is positive, so the inequality holds for every sufficiently large $s_j$. Because $s_j$ may be any sufficiently large multiple of $v_j$, the recursive choice is possible.

Now let \[ G:=\bigsqcup_{j\ge 1}G_j. \] Since $\chi(G_j)>j$ for every $j$, we have \[ \chi(G)=\sup_j\chi(G_j)=\infty. \]

Let $H$ be any induced subgraph of $G$ on $m$ vertices. Write \[ m_j:=|V(H)\cap V(G_j)|, \qquad \sum_{j\ge 1}m_j=m. \] Applying the local estimate inside each component and summing gives \[ \alpha(H)\ge \sum_{j\ge 1}\left(\frac12-\lambda_j\right)m_j = \frac m2-\sum_{j\ge 1}\lambda_jm_j. \] So it remains to bound the weighted deficit \[ \Delta(H):=\sum_{j\ge 1}\lambda_jm_j. \]

Weighted majorization lemma. Because $(\lambda_j)$ is strictly decreasing, the maximum possible value of $\Delta(H)$ under the constraints \[ 0\le m_j\le s_j, \qquad \sum_{j\ge 1}m_j=m, \] is attained by filling the early components first.

Indeed, suppose $(m_j)$ maximizes $\Delta(H)$. If there exist indices $i<j$ with $m_i<s_i$ and $m_j>0$, then replacing \[ m_i\mapsto m_i+1, \qquad m_j\mapsto m_j-1 \] increases $\Delta(H)$ by $\lambda_i-\lambda_j>0$, a contradiction. Hence in a maximizing configuration, all components before some index $k$ are full, all components after $k$ are empty, and the $k$-th component may be partially filled.

Therefore, if \[ T_{k-1}<m\le T_k, \] then \[ \Delta(H)\le D_{k-1}+\lambda_k(m-T_{k-1}). \] Using the recursive bound on $D_{k-1}$, \[ \Delta(H)\le \frac{T_{k-1}}{k}+\frac{m-T_{k-1}}{(k+1)^2}. \] Since $T_{k-1}\le m$ and $(k+1)^{-2}\le k^{-1}$, \[ \Delta(H)\le \frac{m}{k}. \] Thus every induced subgraph $H$ with \[ T_{k-1}<|V(H)|\le T_k \] satisfies \[ \alpha(H)\ge \frac{|V(H)|}{2}-\frac{|V(H)|}{k}. \]

Define \[ \eta(m):=\frac1k\qquad\text{whenever }T_{k-1}<m\le T_k, \] and set \[ g(m):=\eta(m)m. \] Because each $s_j\ge 1$, the partial sums $T_k$ are strictly increasing and tend to infinity. Hence the interval index $k=k(m)$ also tends to infinity with $m$, so \[ \eta(m)\to 0. \] Consequently \[ g(m)=\eta(m)m=o(m), \] and every induced $m$-vertex subgraph $H$ of $G$ satisfies \[ \alpha(H)\ge \frac m2-g(m). \] As noted earlier, the same inequality then holds for every $m$-vertex subgraph of $G$, because passing from an induced subgraph to an arbitrary subgraph on the same vertex set can only increase the independence number. This proves Theorem 750.1. $\square$

6) ADVERSARIAL VERIFICATION

  • Induced versus arbitrary subgraphs. The problem is stated for all subgraphs, but induced subgraphs are the worst case on a fixed vertex set: deleting edges cannot decrease $\alpha$.
  • Heredity of the local EHS property. This is why it is legitimate to replace $X_j$ by a finite induced subgraph $F_j$.
  • Preservation under disjoint union. If a subgraph meets different copies in sets of sizes $t_1,\dots,t_r$, then the corresponding independent sets add, giving \[ \alpha\ge \sum_{\ell=1}^r\left(\frac12-\lambda_j\right)t_\ell =\left(\frac12-\lambda_j\right)\sum_{\ell=1}^r t_\ell. \]
  • Greedy filling really is extremal. The exchange argument excludes any maximizing configuration with a later component occupied while an earlier component is not yet full.
  • Why does $\eta(m)\to 0$? Because $T_k\to\infty$, so the interval index $k(m)$ tends to infinity.
  • What exactly was wrong in Round-1? There was no proof error there; the issue was a factual underclaim. The EHS input already yields a sublinear $o(m)$ error term, not merely a fixed positive proportion of $m$.
  • Why does this not yet settle the full problem? The construction only uses arbitrarily small relative defects inside finite high-chromatic components. It gives no quantitative control on the absolute defects $\lambda_j|F_j|$, so it does not by itself realize an arbitrary prescribed additive error $f(m)\to\infty$.
