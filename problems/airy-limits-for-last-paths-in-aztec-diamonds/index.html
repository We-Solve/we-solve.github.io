Airy Limits for Last Paths in Aztec Diamonds

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Consider the random lattice paths constructed from the height function of the two-periodic Aztec diamond, as referred to in the supplied source record. The record does not specify the tiling probability measure, periodic weights, boundary and height conventions, path construction, or ordering that defines a last path. Consequently, the following is a formulation template whose unresolved data must be supplied before it becomes a precise conjecture.

Let $n$ denote the size of the diamond along admissible sizes, and let $\theta_n$ denote its model parameters, possibly depending on $n$. Once a path construction and ordering have been fixed, write $\mathcal P_{n,\theta_n}$ for the resulting random path collection. A last path means an extremal member of this collection with respect to that ordering; the ordering and the sense in which such a path is required to exist are not specified in the record. If this path admits a transverse-coordinate representation, denote that representation by $L_{n,\theta_n}(u)$.

Source question. Can one establish the existence of a last path in this construction and prove that, after suitable centering and scaling, it converges to the Airy process? The supplied edited statement additionally asks for the parameter regimes in which this convergence holds.

Schematically, the requested convergence would have the form \[ \left( \frac{L_{n,\theta_n}(u_n+r_n t)-m_n(t)}{s_n} \right)_{t\in I} \ \Longrightarrow\ \left(\mathcal A(t)\right)_{t\in I}, \qquad n\to\infty, \] where $u_n$ is an observation location, $r_n>0$ and $s_n>0$ are longitudinal and transverse scales, $m_n$ is a centering function, $I\subseteq{\mathbb{R}}$ is an observation interval, and $\mathcal A$ denotes the intended Airy process. These are placeholders, not normalization data supplied by the source. A complete statement must specify the admissible parameter sequences $(\theta_n)$, observation region, deterministic or random nature of the normalization, interpolation or discrete evaluation convention, Airy-process variant, and meaning of convergence. In particular, the record does not determine whether convergence is meant only for finite-dimensional distributions or in a specified function-space topology.

The supplied dated assessment describes an original expectation covering all parameters, together with a later result for a last path in a thin rough--smooth regime. Neither the full parameter range nor the hypotheses and normalization of that restricted result are provided. No universal parameter quantifier or precise restricted theorem can therefore be extracted from this record alone.

Short English statement

The question asks whether the height-function paths of a two-periodic Aztec diamond have a well-defined last path whose centered and scaled fluctuations converge to an Airy process, and which parameter regimes permit this limit. The model, path ordering, normalization, and type of convergence need specification. The supplied status is partially solved, based on dated curation reporting a result in a thin rough--smooth regime; this draft does not independently verify that assessment.
