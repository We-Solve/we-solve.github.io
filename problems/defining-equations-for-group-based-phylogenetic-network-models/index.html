Math-4272

Defining Equations for Group-Based Phylogenetic Network Models

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $\mathcal M=\{\mathrm{CFN},\text{Jukes--Cantor},\mathrm{K2P},\mathrm{K3P}\}$ be the four model labels in the source. Write $V_N^{(M)}$ for the variety denoted by $V_N$ in the source when model $M\in\mathcal M$ is used on a phylogenetic network $N$.

Requested statement. For every $M\in\mathcal M$ and every phylogenetic network $N$ in the intended network class, determine defining polynomials for $V_N^{(M)}$.

Definitions needed to make the target precise. The supplied record does not specify the network class, the model parameterizations, the ground field, the ambient coordinates, or whether the varieties are affine or projective. Consequently, it does not uniquely define $V_N^{(M)}$. An affine formulation, conditional on supplying those choices, is as follows. Let $k$ be the chosen algebraically closed field, let $\Theta_{N,M}$ be the chosen parameter space, and let \[ \phi_{N,M}:\Theta_{N,M}\longrightarrow k^{r_{N,M}} \] be the model parameterization in the chosen coordinates. Define \[ V_N^{(M)}=\overline{\phi_{N,M}(\Theta_{N,M})}^{\mathrm{Zar}},\qquad I(V_N^{(M)})=\{f\in k[x_1,\ldots,x_{r_{N,M}}]:f(p)=0\text{ for every }p\in V_N^{(M)}\}. \] Under these conventions, the requested equations would be a finite set $F_{N,M}\subseteq k[x_1,\ldots,x_{r_{N,M}}]$ satisfying \[ Z_k(F_{N,M})=V_N^{(M)}, \] where $Z_k(F)$ denotes the common zero set of the polynomials in $F$. If the intended request is for generators of the full defining ideal, the requirement is instead \[ \langle F_{N,M}\rangle=I(V_N^{(M)}). \] These requirements are distinct: equations defining the variety as a set need not generate its vanishing ideal. A projective interpretation would require a specified projective ambient space and homogeneous equations. The affine template above is conditional and does not resolve which conventions or which equation-generation target the source intends.

Short English statement

For each of the CFN, Jukes--Cantor, K2P, and K3P models, find polynomial equations describing the associated variety for every phylogenetic network. The supplied record leaves the network conventions, parameterizations, ambient space, and meaning of defining equations unspecified; these choices require clarification before there is a unique precise target.
