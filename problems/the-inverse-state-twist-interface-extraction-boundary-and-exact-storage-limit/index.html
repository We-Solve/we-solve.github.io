Attempt and results

The requested ring, blind, and threshold signatures require security definitions and constructions that the source does not fix. We try a basic identification layer and a signed-challenge modification to expose what a twist would have to supply. No signature scheme or security reduction is completed here.
The ordinary two-challenge action protocol.
Let a finite abelian group $A$, written additively, act freely and transitively on $X$. Fix $x\in X$, secret $s\in A$, and public $y=s\cdot x$. The prover samples uniform $r\in A$ and sends $t=r\cdot x$. On challenge $c\in\{0,1\}$ it returns $z=r-cs$. The verifier accepts exactly when $z\cdot(c s\cdot x)=t$, where it uses $x$ for $c=0$ and the public $y$ for $c=1$; it need not know $s$. Completeness follows from $z+cs=r$. Two accepting transcripts for the same $t$ with responses $z_0,z_1$ obey $z_0\cdot x=z_1\cdot y$. Freeness implies $z_0=z_1+s$, hence $s=z_0-z_1$. For each fixed challenge, one can simulate its transcript without $s$ by sampling uniform $z$ and defining $t=z\cdot x$ or $t=z\cdot y$ as appropriate. Translation by $cs$ is a bijection on $A$, so this has exactly the honest transcript distribution. This proves perfect special honest-verifier simulation for the specified identification protocol. It does not prove unforgeability of any derived signature, anonymity, blindness, or security against quantum rewinding.
The signed-challenge attempt extracts only a double.
A basepoint-fixing inverse-state map, if available, must have $\iota(a\cdot x)=(-a)\cdot x$. Freeness and transitivity make this a well-defined involution, and it satisfies $\iota(b\cdot u)=(-b)\cdot\iota(u)$. Existence as a set map does not make evaluation efficient: recovering $a$ and negating it would already solve vectorization. Assume efficient evaluation of $\iota$, so both $y_+=y$ and $y_-=\iota(y)$ are available. For challenges $c\in\{+1,-1\}$, let the response again be $z_c=r-cs$, verified by $z_c\cdot y_c=t$. Two accepting responses yield $z_- - z_+=2s$, by freeness. The solutions of this doubling equation are precisely $s+A[2]$, where $A[2]=\{a:2a=0\}$: subtraction reduces it to the kernel of doubling. If $A$ has exponent two, the two public states and verification equations coincide. A prover can choose any $z$ and set $t=z\cdot y$; that same response answers either challenge without knowing a transporter from $x$ to $y$. Thus the ordinary extraction argument fails completely in this case. It does not prove all protocols using twists fail; it identifies the missing inversion-of-doubling or disambiguation step in this specific proposal.
A literal storage limit.
For $q$ independently chosen states in an $M$-element set, there are $M^q$ possible arrays. Any fixed-length binary encoding from which every array is recovered exactly must be injective, so length $b$ requires $2^b\ge M^q$, or $b\ge q\log_2 M$. In contrast, arrays of deterministic pairs $(u,\iota(u))$ have only $M$ possibilities per pair and can store just $u$ when $\iota$ is efficiently recomputed. Therefore halving such paired storage does not prove a compression of independent commitments or a complete signature memory improvement.
