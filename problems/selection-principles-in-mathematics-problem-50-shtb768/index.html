Statement

Definitions and mathematical statement

For purposes of interpreting the displayed formulas, let ${\mathbb{N}}^{{\mathbb{N}}}$ denote the set of functions from ${\mathbb{N}}$ to ${\mathbb{N}}$. The supplied record instead writes $Y\subseteq{\mathbb{N}}$ and $g\in{\mathbb{N}}$; the function-space interpretation used here is an inferred correction that requires source verification.

For $f,g\in{\mathbb{N}}^{{\mathbb{N}}}$, define eventual domination by \[ f\leq^{*}g\quad\Longleftrightarrow\quad \{n\in{\mathbb{N}}:f(n)>g(n)\}\text{ is finite}. \] A family $Y\subseteq{\mathbb{N}}^{{\mathbb{N}}}$ is dominating if \[ (\forall u\in{\mathbb{N}}^{{\mathbb{N}}})(\exists f\in Y)\;u\leq^{*}f. \] For $A\subseteq{\mathbb{N}}^{{\mathbb{N}}}$, say that $g\in{\mathbb{N}}^{{\mathbb{N}}}$ avoids middles in $A$ if both of the following hold:

  1. For every $f\in A$, $g\not\leq^{*}f$.
  2. For every $f,h\in A$, at least one of \[ \{n\in{\mathbb{N}}:f(n)<g(n)\leq h(n)\},\qquad \{n\in{\mathbb{N}}:h(n)<g(n)\leq f(n)\} \] is finite.
Using the conventional interpretation of the other invariant, let $\mathcal M$ be the ideal of meager subsets of ${\mathbb{R}}$, where a meager set is a countable union of nowhere dense sets, and put \[ \operatorname{cov}(\mathcal M) =\min\left\{|\mathcal A|:\mathcal A\subseteq\mathcal M, \ \bigcup\mathcal A={\mathbb{R}}\right\}. \] The record does not itself specify this convention.

The supplied question asks whether \[ \operatorname{cov}(\mathcal M) \leq \operatorname{add}(\mathfrak X,\mathfrak D). \] However, its definition of the right-hand side is unresolved. It describes it as the least cardinal $\kappa$ for which there is a dominating family $Y$ of cardinality $\kappa$ such that every partition of $Y$ into $\kappa$ pieces has a piece in which no function avoids middles. Under the function-space interpretation above, this requirement cannot hold: the partition into singleton sets is permitted, and for each singleton $\{f\}$, the function $g(n)=f(n)+1$ avoids middles in $\{f\}$. Thus the supplied wording does not define the claimed cardinal. The intended definition of $\operatorname{add}(\mathfrak X,\mathfrak D)$ must be recovered from the cited source before the displayed question can be treated as a precise mathematical assertion; no replacement definition is asserted here.

Short English statement

The supplied problem asks whether the covering number of the meager ideal is at most a cardinal defined using dominating families and functions that avoid middles. The function domains appear to have lost an exponent, and the stated partition requirement conflicts with the partition into singletons. The intended cardinal therefore requires source clarification. The registry labels the problem open; that label is supplied metadata, not an independently verified status assessment.
