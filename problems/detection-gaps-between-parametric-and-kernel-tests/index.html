Detection Gaps Between Parametric and Kernel Tests

Statement

Definitions and mathematical statement

For a measurable space $\mathcal X$ and a positive-definite kernel $k$ with reproducing kernel Hilbert space $\mathcal H_k$, suppose the kernel mean embeddings $\mu_P=\int k(x,\cdot)\,{\,\mathrm{d}} P(x)$ and $\mu_Q$ exist. The maximum mean discrepancy is \[ \operatorname{MMD}_k(P,Q)=\|\mu_P-\mu_Q\|_{\mathcal H_k}. \] This definition does not specify the kernel, the sampling experiment, or the distribution classes intended by the source. In particular, the record does not state conditions ensuring that this discrepancy distinguishes all distributions under consideration.

To describe the requested comparison abstractly, let $\mathcal E_n=\{\mathbb P_{P,n}:P\in\mathcal P\}$ be a statistical experiment indexed by distributions $P$, with sample-size index $n\in{\mathbb{N}}$. For a specified null class $\mathcal P_0\subseteq\mathcal P$, separation functional $\Delta(P,\mathcal P_0)$, and alternative class $\mathcal P_1\subseteq\mathcal P$, set \[ \mathcal A(r)=\{P\in\mathcal P_1:\Delta(P,\mathcal P_0)\ge r\}. \] A randomized test is a measurable function $\varphi_n$ into $[0,1]$, representing rejection probability. For fixed $\alpha,\beta\in(0,1)$ with $\alpha+\beta<1$, define the minimax separation threshold by \[ r_n^*(\alpha,\beta)=\inf\left\{r>0:\exists\varphi_n\ \text{such that}\quad \sup_{P\in\mathcal P_0}\mathbb E_{P,n}\varphi_n\le\alpha, \quad \sup_{P\in\mathcal A(r)}\mathbb E_{P,n}(1-\varphi_n)\le\beta \right\}. \] The corresponding threshold for a specified standard MMD test is defined by restricting the test in this expression to that procedure. This is a framework for making the question precise, not a claim that the source specifies these choices.

Source question. Determine to what extent the reported gap between an $n^{-1/2}$ detection boundary for the standard MMD goodness-of-fit test and an $n^{-1}$ boundary described as typical of parametric tests reflects intrinsic difficulty of nonparametric testing, and to what extent it reflects suboptimality of the standard MMD statistic. For a fixed nonparametric experiment and separation convention, this requires comparing the standard procedure's threshold with the minimax threshold over all tests; comparison with a parametric experiment additionally requires explicitly specified, comparable alternatives and separation measures.

Unresolved qualification. The record supplies neither the experiments and distribution classes nor the separation measure, kernel, standard statistic, calibration, or error criterion underlying the quoted rates. It does not say whether those rates measure MMD, squared MMD, or another discrepancy. Squaring a discrepancy changes its rate exponent, so the two quoted powers cannot by themselves establish a statistical efficiency gap. Consequently, the supplied question does not determine a unique quantitative theorem or conjecture; the abstract framework above leaves its missing specifications unresolved.

Short English statement

The question asks how much of the reported $n^{-1/2}$ versus $n^{-1}$ detection gap comes from the difficulty of nonparametric testing and how much comes from the standard MMD test. A precise comparison requires specified models, alternatives, error bounds, and a common separation convention. These details are absent from the supplied record, so the quoted rates are retained as source claims requiring clarification.
