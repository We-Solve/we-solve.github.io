Visibility Graphs of Points, Segments and Polygons — Conjecture 4

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let ${\mathbb{R}}^2$ denote the real Euclidean plane. For distinct points $p,q\in{\mathbb{R}}^2$, define their open line segment by \[ (p,q)=\{(1-t)p+tq:0<t<1\}. \] For a point set $P\subseteq{\mathbb{R}}^2$, two distinct points $p,q\in P$ are visible relative to $P$ if $(p,q)\cap P=\varnothing$. A subset $S\subseteq P$ is mutually visible relative to $P$ if every two distinct points of $S$ are visible relative to $P$. Points are collinear if they lie on a common affine line.

With this standard interpretation of visibility, the supplied conjecture asserts that for every pair of integers $k\geq2$ and $\ell\geq2$, there exists a positive integer $h(k,\ell)$ such that every point set $P\subseteq{\mathbb{R}}^2$ with $|P|\geq h(k,\ell)$ satisfies at least one of the following:

  1. There exist $\ell$ distinct points of $P$ lying on a common affine line.
  2. There exists a subset $S\subseteq P$ with $|S|=k$ such that \[ \forall p,q\in S,\qquad p\ne q\ \Longrightarrow\ (p,q)\cap P=\varnothing. \]
The threshold depends only on $k$ and $\ell$, and visibility is tested against the entire set $P$.

Unresolved scope qualification. The supplied statement does not explicitly restrict $P$ to be finite. The quantifier above retains its literal unrestricted wording, which includes infinite point sets. Whether the intended source formulation instead quantifies only over finite point sets requires confirmation. The supplied excerpt also does not explicitly define visibility or specify the underlying plane; the definitions above state the standard real Euclidean interpretation used in this draft.

Short English statement

For each $k,\ell\geq2$, the conjecture asks for a threshold beyond which every planar point set contains either $\ell$ collinear points or $k$ points whose connecting open segments contain no point of the whole set. The intended restriction to finite sets, if any, remains unresolved. The registry labels the problem open; this is supplied status information, not an independently verified assessment.
