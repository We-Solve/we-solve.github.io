Smale's 5th Problem: Height Bounds for Diophantine Curves

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A height bound for rational points requires a specified ground field and height. For example, for a chosen projective embedding $C\subset{\mathbb{P}}^r_{{\mathbb{Q}}}$, a point $P=[x_0:\cdots:x_r]\in C({\mathbb{Q}})$ has logarithmic projective height \[ h(P)=\log\max_{0\leq i\leq r}|x_i|, \] when the $x_i$ are relatively prime integer homogeneous coordinates. This example fixes neither the ground field nor the embedding for the original question; both are missing from its wording.

The supplied problem attributed to Stephen Smale (1998) asks for effective uniform bounds for heights of rational points on algebraic curves. In a chosen class of encoded curves and for a specified list $I(C)$ of permitted invariants or presentation data, a precise version would require a computable function $B$ satisfying \[ \forall C\text{ in the chosen class}\ \forall P\in C({\mathbb{Q}}),\qquad h(P)\leq B(I(C)). \] Here effective means that the bound can be obtained by an algorithm from the permitted finite input, and uniform means that the same function works over the stated class with only the declared input dependencies. The class of curves, height, input invariants and dependencies are not fixed by the source, so the displayed implication is a framework for the intended problem rather than a completed replacement theorem.

The background invokes Faltings's finiteness result for curves of genus greater than one, suggesting the smooth projective high-genus setting; the displayed source question itself says arbitrary algebraic curves and does not impose that restriction. A finite bound for all rational points of an unrestricted curve cannot be assumed when the selected height is unbounded on those points. The source also moves between integer solutions in its motivation and rational points in its actual question; these are not silently identified.

The supplied literature triage dated 2026-08-17 labels the problem open, reports effective methods in specified classes or under additional hypotheses, and reports no verified uniform effective theorem in the requested generality. This is a dated source assessment rather than a newly verified current literature claim.

Short English statement

Make finiteness of rational points on suitable high-genus curves effective by giving a computable height bound with explicit uniform dependencies. The imported statement must specify the ground field, curve class, height, and permitted input data before that aim becomes one precise theorem.
