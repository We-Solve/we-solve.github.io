Math-922

Equality Cases for Gerzon’s Equiangular-Line Bound

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For an integer $r\geq 1$, a line in ${\mathbb{R}}^r$ means a one-dimensional linear subspace. A finite set $\mathcal L$ of distinct lines is equiangular if there exists $c\in[0,1)$ such that, for unit vectors $u_L\in L$ chosen for each $L\in\mathcal L$, \[ \lvert\langle u_L,u_{L'}\rangle\rvert=c \qquad\text{whenever }L,L'\in\mathcal L,\ L\ne L'. \] The absolute value makes this condition independent of the choices of signs of the unit vectors. The common value $c$ may depend on the configuration; it is not prescribed in advance. Define \[ N(r)=\max\{\lvert\mathcal L\rvert:\mathcal L\text{ is an equiangular set of lines in }{\mathbb{R}}^r\}. \] The supplied source states Gerzon's absolute bound \[ N(r)\leq\binom{r+1}{2}=\frac{r(r+1)}2. \] The problem is to determine whether \[ \left\{r\in{\mathbb{Z}}:r\geq1,\ N(r)=\tfrac{r(r+1)}2\right\} \quad\text{is infinite}. \] Equivalently, does every integer $R\geq1$ admit an integer $r\geq R$ with an equiangular set of exactly $r(r+1)/2$ lines in ${\mathbb{R}}^r$?

The original excerpt additionally describes the bound as tight up to a multiplicative constant; this is supplied background, distinct from the exact equality question. The supplied dated literature assessment reports equality in dimensions $2,3,7,23$, nonattainment in infinitely many dimensions, and that the infinitude of equality dimensions remains open. These are supplied curation claims, not independently verified conclusions of this draft.

Short English statement

Are there arbitrarily large positive integer dimensions $r$ in which one can find exactly $r(r+1)/2$ distinct lines through the origin in ${\mathbb{R}}^r$, all making the same angle with one another? The common angle may vary between configurations. The registry labels the problem partially solved; this draft preserves that supplied assessment without independently verifying it.
