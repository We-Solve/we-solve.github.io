Math-14712

Inversion Monotonicity in the Domino Subclass

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For an integer $n\geq 1$, let $S_n$ be the set of permutations of $\{1,\ldots,n\}$. A permutation $\pi\in S_n$ contains a pattern $\tau\in S_m$ if there exist indices $1\leq i_1<\cdots<i_m\leq n$ such that $\pi(i_a)<\pi(i_b)$ if and only if $\tau(a)<\tau(b)$ for all $a,b$. Otherwise, $\pi$ avoids $\tau$. For a set $B$ of patterns, let $\operatorname{Av}(B)$ denote the family of permutations avoiding every member of $B$. Define \[ \operatorname{inv}(\pi)=\left|\{(i,j):1\leq i<j\leq n,\ \pi(i)>\pi(j)\}\right|. \] For a specified family $\mathcal D$ of permutations, put \[ d_{n,k}(\mathcal D)=\left|\{\pi\in\mathcal D\cap S_n:\operatorname{inv}(\pi)=k\}\right|. \] The supplied record asks for inversion monotonicity on the domino subclass, denoted there by \[ \mathcal D=[\operatorname{Av}(132)\mid\operatorname{Av}(231)] \] and described as a subclass of $\operatorname{Av}(1324)$. Interpreting inversion monotonicity as monotonicity in length at each fixed inversion number, the intended assertion is \[ \forall n\geq 1\ \forall k\geq 0,\qquad d_{n,k}(\mathcal D)\leq d_{n+1,k}(\mathcal D), \] where $n,k$ are integers. This is a conditional reconstruction: the supplied record does not define the domino family, its counting convention, or the exact parameter range.

In particular, the displayed bracket notation cannot be identified without qualification with ordinary horizontal juxtaposition. Such juxtaposition would allow a permutation to be split into a left block avoiding $132$ and a right block avoiding $231$; it contains $1324$, as witnessed by the split $13\mid24$. Consequently, that interpretation does not produce a subclass of $\operatorname{Av}(1324)$. Additional global avoidance conditions or a different interpretation of the notation are required. The record does not determine whether to count underlying permutations or permutations equipped with a specified division into cells.

The adjacent source excerpt attributes to Claesson--Ulfarsson an inequality written using $\operatorname{Av}_n^k(1324,231,4321)$ and $\operatorname{Av}_{n+1}^k(1324,231,4321)$. Under the fixed-inversion interpretation above, this is a related reported result for avoidance of three patterns; it does not itself specify the intended domino family or settle the requested assertion.

Short English statement

The intended question asks whether, for each fixed inversion number, the number of domino permutations is nondecreasing as their length increases. The supplied description leaves the domino family and counting convention unresolved, so the displayed inequality requires clarification before it becomes a fully specified conjecture.
