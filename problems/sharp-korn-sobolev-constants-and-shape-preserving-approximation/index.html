Sharp Korn–Sobolev Constants and Shape-Preserving Approximation

Definitions and mathematical statement

Endpoint Korn--Sobolev question. The supplied record asks for the optimal constant in \[ \left(\int_{{\mathbb{R}}^n}|u(x)|^{n/(n-1)}\,{\,\mathrm{d}} x\right)^{(n-1)/n} \leq C\int_{{\mathbb{R}}^n}|\varepsilon(u)(x)|\,{\,\mathrm{d}} x \] for compactly supported vector fields, and for an isoperimetric interpretation of this optimal inequality. Here ${\,\mathrm{d}} x$ denotes Lebesgue measure. The displayed exponent requires an integer dimension $n\geq2$; the record does not specify a particular dimension or its dimension quantifier.

The conventional meaning of the symmetric gradient is \[ \varepsilon(u)=\frac{Du+(Du)^{\mathsf T}}2, \qquad \varepsilon(u)_{ij}=\frac{\partial_j u_i+\partial_i u_j}{2} \] for a differentiable field $u:{\mathbb{R}}^n\to{\mathbb{R}}^n$. This convention, the vector and matrix norms denoted by $|\cdot|$, and the precise admissible regularity class require confirmation from the source; compact support alone does not specify these choices.

More precisely, once a dimension, norms, and an admissible class $\mathcal A$ of compactly supported vector fields have been fixed, the requested constant is \[ C_*(n;\mathcal A) =\inf\left\{C\geq0: \|u\|_{L^{n/(n-1)}({\mathbb{R}}^n)} \leq C\int_{{\mathbb{R}}^n}|\varepsilon(u)|\,{\,\mathrm{d}} x \text{ for every }u\in\mathcal A\right\}, \] with value $+\infty$ if no finite constant works. The task is to determine this constant and an associated isoperimetric interpretation. This is a conditional formulation: the record does not identify the geometric objects, perimeter or energy, or equality correspondence intended by that interpretation.

Shape-preserving approximation questions. The record also asks whether a $C^2$ approximant to a convex function can be chosen convex, and whether a $C^2$ approximant to a subharmonic function can be chosen subharmonic.

For clarity, a real-valued function $f$ on a convex set $D\subseteq{\mathbb{R}}^d$ is convex if \[ f((1-t)x+ty)\leq(1-t)f(x)+tf(y) \quad(x,y\in D,\ 0\leq t\leq1). \] For the real-valued, locally integrable version on an open set $\Omega\subseteq{\mathbb{R}}^d$, subharmonicity means upper semicontinuity together with \[ f(x)\leq\frac{1}{|B(x,r)|}\int_{B(x,r)}f(y)\,{\,\mathrm{d}} y \quad\text{whenever }\overline{B(x,r)}\subset\Omega, \] where $B(x,r)$ is the Euclidean ball and $|B(x,r)|$ its Lebesgue measure. These definitions explain the shape conditions; they do not resolve the intended domains or whether extended-valued functions are allowed.

The approximation questions cannot be given complete quantifiers from this record: it supplies neither the approximation relation or error criterion, nor the admissible input class, domains, boundary requirements, or any exceptional-set conditions. In particular, the phrase "the $C^2$ approximant" does not identify an underlying approximation theorem. These data must be recovered before a precise existence assertion for the approximants can be stated.

Short English statement

Determine the sharp endpoint Korn--Sobolev constant for compactly supported vector fields and its isoperimetric meaning. Also ask whether the intended $C^2$ approximations preserve convexity or subharmonicity. The norm conventions, admissible field class, and especially the approximation criterion are missing, so the supplied record supports only the qualified formulation above. Its partially solved status is supplied dated curation.
