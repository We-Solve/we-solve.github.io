Randomized k-server with squared-logarithmic ratio

Randomized k-server with squared-logarithmic ratio

Claim type: **Partial result**.

Exact scope: On a unit uniform metric with k initially distinct server sites, randomized marking has E[cost]≤2H_k·OPT with additive constant zero for every fixed finite request sequence.

Paging as the uniform-metric subclass

When every distinct pair of points has distance one, a configuration of k distinct server positions is a cache of k pages; a miss costs one and a hit costs zero. Use the classical randomized marking algorithm [F]. A phase is a maximal consecutive block of requests to at most k distinct pages. At a phase start clear marks. Mark a requested page; on a miss evict a uniformly random unmarked resident page. Marked pages are never evicted within that phase. There is always an unmarked victim on a miss, since fewer than k distinct pages have previously been marked. The policy is fixed for all horizons and needs no future requests.

Let l_i be the number of pages requested in phase i that were absent from the preceding phase's k-page set; for phase one use the initial cache C as that set. All phases except possibly the last contain k distinct pages, and after any full phase the cache is precisely those k pages. The l_i clean pages each cause at most one fault. For old pages, after s distinct old pages and c clean pages have been requested, the unmarked cache is a uniform (k−s−c)-subset of the k−s old pages not yet requested. This invariant follows by induction from uniform victim selection, on both hits and misses; previously marked pages are fixed. Thus the next distinct old request misses with probability c/(k−s)≤l_i/(k−s). There are at most k−l_i such requests. Consequently
E[faults in phase i] ≤ l_i + l_i Σ_{j=l_i+1}^k 1/j ≤ l_i H_k,
with value zero when l_i=0. The inequality uses H_{l_i}≥1 for l_i≥1. Repeated requests to marked pages cause no further fault.

Comparing every finite horizon to OPT

Let f_i be the number of faults of an optimal offline cache during phase i, starting with the same C. Every clean page of the first phase requires a first load, so l₁≤f₁. For i≥2 the preceding full phase requests k distinct pages and phase i requests l_i additional distinct pages. Any cache starting that two-phase interval contains at most k of their union, so at least l_i distinct requested pages must be loaded during those two phases: l_i≤f_{i−1}+f_i. Summing yields Σ_i l_i≤2Σ_i f_i, including a single incomplete phase. Combining gives E[cost]≤2H_k OPT with no horizon-dependent or initial additive term. Initial sites being distinct supplies exactly the initial full cache used in the first inequality. The sequence is fixed independently of victim choices, as required by an oblivious adversary.

Since H_k≤1+ln k and k≥2, this implies the requested O(log²(k+1)) ratio on this metric subclass, in fact O(log k), with B=0. It does not extend the phase argument to unequal distances. The policy's computational efficiency is not part of the literal existence assertion; exact uniform finite choices can be generated by rejection from unbiased bits, almost surely terminating with finite expected bit cost.

[F] Fiat, Karp, Luby, McGeoch, Sleator and Young (1991), Competitive Paging Algorithms. Marking and the 2H_k guarantee are classical; the explicit shared-initial-cache/finite-horizon accounting above states the zero-additive-constant version used here.

Mathematical statement of the claimed result

Manuscript 1.
For each $k\ge2$, arbitrary metric $(X,d)$ with at least $k+1$ points, and initial server tuple $s\in X^k$, the claim provides one randomized online $k$-server policy $A$ and finite $B\ge0$ such that every fixed finite request sequence $\sigma$ satisfies \[ \mathbb E\operatorname{cost}_{A,s}(\sigma) \le C(\log(k+1))^2\operatorname{OPT}_{X,d,k,s}(\sigma)+B, \] with absolute $C$. The adversary is oblivious to policy randomness. Additive $B$ may depend on the metric, $k,s$ but not on the sequence or horizon; distinct initial positions allow $B=0$. No computational-efficiency bound is asserted by this existence statement.
