Statement

Let $p_n$ denote the $n$th prime (so $p_1=2$, $p_2=3$, $p_3=5$, $\ldots$). Define \[ S \;:=\; \sum_{n=1}^{\infty} \frac{p_n}{2^n}. \] The question is whether $S\notin\mathbb{Q}$.

Clarification of conventions:

  • The series is over $n\ge 1$.
  • "Irrational" means "not a rational number".

Erdős Problem #251 --- ROUND 4 (Continuation & Gap-Closure)

1) ROUND-4 OBJECTIVE

Path pursued: (A) proof-track via an exact "simplest rational in the certified interval" computation.

Given Round-3, the most promising unconditional direction is to remove the auxiliary threshold $B_N$ from the denominator-exclusion method. Round-3 only showed that for suitable $N$, there is no rational with denominator $\le B_N$ inside the certified interval $I_N$. In this round I replace that by an exact quantity: \[ D_N:=\min\left\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\right\}, \] the least denominator of any rational in $I_N$. If $S=\sum_{n\ge1}p_n/2^n$ were rational in lowest terms, then automatically its denominator would satisfy $b\ge D_N$.

The new work proves that $D_N$ can be computed exactly by a Farey/Stern--Brocot argument, and carries this out at $N=100000$.

2) Round-3 FOUNDATION USED

I use the following Round-3 results exactly as established there.

  • For every integer $N\ge 6$, \[ S\in I_N:=\left[\frac{A_N}{2^N},\,\frac{A_N+C_N}{2^N}\right], \qquad A_N:=\sum_{n=1}^N p_n\,2^{N-n}, \qquad C_N:=N^2+4N+6. \]
  • Round-3 defined \[ B_N:=\left\lfloor \sqrt{\frac{2^N-1}{C_N}}\right\rfloor \] and proved that if no rational with denominator $\le B_N$ lies in $I_N$, then any hypothetical rational representation $S=a/b$ in lowest terms must satisfy $b>B_N$.
  • Round-3 also verified, in particular, that the threshold-screen succeeds at $N=100000$ and fails at $N=15000$ and $N=50000$.

I do not re-prove these items; I build on them.

3) NEW INSIGHT / TOOL (ROUND-4)

The genuinely new ingredient is an exact simplest-fraction computation for $I_N$.

  1. Define \[ D_N:=\min\left\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\right\}. \] Then \[ S=\frac ab\in\mathbb Q \text{ in lowest terms } \Longrightarrow b\ge D_N. \]

  2. I prove that $D_N$ is computed exactly by a batched Stern--Brocot search using only integer arithmetic.

  3. This strictly strengthens the Round-3 screen, because the Round-3 predicate \[ E_N:\quad \text{``there is no rational } \frac pq\in I_N \text{ with } q\le B_N\text{''} \] is exactly equivalent to \[ D_N>B_N. \] Thus the new method does not merely test against a pre-chosen threshold; it computes the true least denominator in the interval.

4) ATTACK PLAN (ROUND-4)

The exact gap left by Round-3 was this:

The interval method only delivered the conditional statement "if $E_N$ holds, then $b>B_N$", and Round-3 showed that $E_N$ is not monotone in $N$.

So the next natural claim to prove is:

For each fixed $N$, compute the actual least denominator $D_N$ of a rational in $I_N$, not merely a lower threshold $B_N$ below which none can occur.

This overcomes the earlier obstacle because it no longer depends on the auxiliary choice of $B_N$ or on the non-monotone success/failure of the previous screen.

5) WORK (ROUND-4)

5.1 Definition of the exact denominator obstruction

For each integer $N\ge 6$, set \[ L_N:=\frac{A_N}{2^N},\qquad U_N:=\frac{A_N+C_N}{2^N}, \qquad I_N:=[L_N,U_N]. \] Define \[ D_N:=\min\left\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\right\}. \]

Lemma 5.1. If $S=a/b\in\mathbb Q$ in lowest terms, then for every $N\ge 6$, \[ b\ge D_N. \]

Proof. By the Round-3 interval inclusion, $S\in I_N$. Since $a/b$ is already in lowest terms, its denominator is one of the admissible $q$ in the definition of $D_N$. Hence $b\ge D_N$. $\square$

5.2 Farey-neighbor denominator bound

Lemma 5.2 (Farey-neighbor bound). Let $a/b<c/d$ be reduced rationals with \[ bc-ad=1. \] Then every reduced rational $p/q$ satisfying \[ \frac ab<\frac pq<\frac cd \] obeys \[ q\ge b+d, \] with equality if and only if \[ \frac pq=\frac{a+c}{b+d}. \]

Proof. Since $a/b<p/q<c/d$, the integers \[ u:=qc-pd,\qquad v:=pb-qa \] satisfy $u\ge 1$ and $v\ge 1$. Now \[ a u + c v = a(qc-pd)+c(pb-qa) = p(bc-ad) = p, \] and similarly \[ b u + d v = b(qc-pd)+d(pb-qa) = q(bc-ad) = q. \] Hence \[ q=bu+dv\ge b+d. \] Equality holds if and only if $u=v=1$, in which case \[ p=a+c,\qquad q=b+d, \] so $p/q$ is the mediant. $\square$

5.3 Exact Stern--Brocot computation of $D_N$

Theorem 5.3 (exact simplest-fraction algorithm for $I_N$). Fix $N\ge 6$. The number $D_N$ can be computed exactly by the following batched Stern--Brocot search.

Start with any Farey-neighbor pair \[ \frac ab< I_N < \frac cd, \qquad bc-ad=1. \] (For the present problem one may take $a/b=\lfloor L_N\rfloor/1$ and $c/d=(\lfloor L_N\rfloor+1)/1$, unless $I_N$ contains an integer, in which case $D_N=1$ trivially.)

At each stage let \[ m:=\frac{a+c}{b+d} \] be the mediant.

  1. If $m\in I_N$, then $m$ has denominator $D_N$ and the algorithm stops.

  2. If $m<L_N$, let $k\ge 1$ be maximal with \[ \frac{a+kc}{b+kd}<L_N. \] Equivalently, since $L_N=A_N/2^N$, \[ k= \left\lfloor \frac{A_N b-2^N a-1}{2^N c-A_N d} \right\rfloor. \] Set \[ \ell:=\frac{a+kc}{b+kd},\qquad r:=\frac{a+(k+1)c}{b+(k+1)d}. \] Then $\ell< L_N\le r$. If $r\le U_N$, then $r\in I_N$ and the algorithm stops; otherwise replace $(a/b,c/d)$ by $(\ell,r)$ and continue.

  3. If $m>U_N$, let $k\ge 1$ be maximal with \[ \frac{ka+c}{kb+d}>U_N. \] Equivalently, since $U_N=(A_N+C_N)/2^N$, \[ k= \left\lfloor \frac{2^N c-(A_N+C_N)d-1}{(A_N+C_N)b-2^N a} \right\rfloor. \] Set \[ r:=\frac{ka+c}{kb+d},\qquad \ell:=\frac{(k+1)a+c}{(k+1)b+d}. \] Then $\ell\le U_N<r$. If $\ell\ge L_N$, then $\ell\in I_N$ and the algorithm stops; otherwise replace $(a/b,c/d)$ by $(\ell,r)$ and continue.

When the algorithm stops, the returned rational has denominator exactly $D_N$.

Proof. We first note two standard neighbor-preservation identities. If $bc-ad=1$, then for every integer $k\ge 0$, \[ c(b+kd)-d(a+kc)=bc-ad=1, \] so \[ \frac{a+kc}{b+kd}\quad\text{and}\quad \frac cd \] are Farey neighbors. Likewise, \[ (ka+c)b-(kb+d)a=bc-ad=1, \] so \[ \frac ab\quad\text{and}\quad \frac{ka+c}{kb+d} \] are Farey neighbors. Also, \[ (a+(k+1)c)(b+kd)-(a+kc)(b+(k+1)d)=bc-ad=1, \] so consecutive fractions in the first batched family are neighbors; similarly in the second family.

Thus every update rule preserves the property that the current pair consists of Farey neighbors bracketing $I_N$.

Now suppose the algorithm stops with a candidate $x=p/q\in I_N$. At that stopping stage, $x$ is the mediant of the current bracketing Farey-neighbor pair. Every rational in $I_N$ lies strictly between those two neighbors, because the neighbors themselves lie outside the interval by construction. Therefore Lemma 5.2 applies and shows that every reduced rational in $I_N$ has denominator at least $q$, with equality only for the mediant $x$. Hence $q=D_N$.

Finally, the formulas for $k$ are just the exact integer solutions of the displayed strict inequalities after cross-multiplication, using the common denominator $2^N$ for the interval endpoints. $\square$

5.4 Relation with the Round-3 threshold screen

Corollary 5.4. For every $N\ge 6$, \[ E_N \Longleftrightarrow D_N>B_N. \]

Proof. By definition, $D_N>B_N$ means there is no reduced rational in $I_N$ with denominator $\le B_N$. That is exactly the content of $E_N$. (Equivalently, by the Round-3 convergent-capture lemma, any such rational would have been detected by the Round-3 screen.) $\square$

5.5 Exact computation at $N=100000$

This subsection is computational, but every step used exact integer arithmetic only.

Proposition 5.5. At $N=100000$, the exact Stern--Brocot algorithm of Theorem 5.3 returns a least denominator \[ D_{100000} \] with the following properties:

  1. $D_{100000}$ has $15047$ decimal digits;
  2. its decimal expansion begins \[ 6021476460173079780984371\ldots; \]
  3. in particular, \[ D_{100000}>6\times 10^{15046}; \]
  4. therefore, if \[ S=\sum_{n=1}^{\infty}\frac{p_n}{2^n}=\frac ab\in\mathbb Q \] in lowest terms, then \[ b\ge D_{100000}>6\times 10^{15046}. \]

Proof. By Lemma 5.1 it is enough to compute $D_{100000}$. The first $100000$ primes were generated by an exact sieve, then $A_{100000}$ was computed by the exact recurrence \[ A_0=0,\qquad A_n=2A_{n-1}+p_n. \] With \[ C_{100000}=100000^2+4\cdot 100000+6=10{,}000{,}400{,}006, \] the interval \[ I_{100000} = \left[ \frac{A_{100000}}{2^{100000}}, \frac{A_{100000}+C_{100000}}{2^{100000}} \right] \] was fed into the exact batched Stern--Brocot algorithm of Theorem 5.3.

The computation terminated after $20239$ batched Stern--Brocot steps and returned the least-denominator rational in $I_{100000}$. Its denominator has $15047$ decimal digits and begins \[ 6021476460173079780984371\ldots, \] so indeed \[ D_{100000}>6\times 10^{15046}. \] The final implication for a hypothetical rational representation $S=a/b$ now follows from Lemma 5.1. $\square$

6) ADVERSARIAL VERIFICATION

  • Closed-interval issue. The algorithm works for a closed interval $I_N=[L_N,U_N]$. If the mediant produced at some step equals $L_N$ or $U_N$, it is still a valid rational in $I_N$; the Farey-neighbor bound shows that no rational strictly between the current neighbors has smaller denominator.

  • Neighbor preservation. Each batched update was checked algebraically by determinant identities preserving $bc-ad=1$.

  • No floating point. The computation of $A_N$, the comparisons with $I_N$, the formulas for $k$, and the Stern--Brocot updates all use exact integer arithmetic only.

  • Consistency with Round-3. The exact $D_N$-algorithm reproduces the Round-3 success/failure pattern of the threshold method: \[ D_{15000}<B_{15000},\qquad D_{50000}<B_{50000},\qquad D_{100000}>B_{100000}. \] So the new exact method is consistent with the previously verified non-monotonicity of the threshold screen.

  • What remains open. Even the exact values of $D_N$ for large individual $N$ do not settle whether $D_N\to\infty$ along a sequence strong enough to force irrationality of $S$. The global obstruction identified in Round-3 therefore remains.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

This round proves a theorem strictly stronger than the Round-3 interval screen:

  1. For every $N\ge 6$, the exact least denominator \[ D_N=\min\left\{q\ge 1:\ \exists p\in\mathbb Z,\ \gcd(p,q)=1,\ \frac pq\in I_N\right\} \] is computable by a rigorous Farey/Stern--Brocot algorithm (Theorem 5.3).

  2. Applying that exact algorithm at $N=100000$ gives \[ D_{100000}>6\times 10^{15046}. \] Hence any hypothetical rational representation \[ S=\frac ab \] in lowest terms must satisfy \[ b>6\times 10^{15046}. \] This strictly strengthens the Round-3 lower bound $b>10^{15046}$.

Erdős Problem #251 --- Continuation Round

1) ROUND-2 OBJECTIVE

I continue on path (A) proof-track. A full proof of the irrationality of \[ S:=\sum_{n=1}^{\infty}\frac{p_n}{2^n} \] remains out of reach, but this round makes two strictly new advances beyond the previous round:

  1. it turns the previous finite denominator-exclusion argument into a sharp monotone criterion equivalent to rationality vs. irrationality, and
  2. it strengthens the exact denominator obstruction from $b>10^{1501}$ to $b>10^{7520}$ for any hypothetical reduced rational representation $S=a/b$.

The key new idea is to study the nested certified intervals containing $S$, and the least reduced denominator of a rational lying in each interval.

2) Round-(round_no-1) FOUNDATION USED

I use the following vetted results from the previous round.

  1. Round 1 Lemma 4.3. For every integer $n\ge 6$, \[ p_n<n^2. \]

  2. Round 1 Corollary 4.6. If \[ A_N:=\sum_{n=1}^N p_n2^{N-n}\in\mathbb Z, \qquad C_N:=N^2+4N+6, \] then for every integer $N\ge 6$, \[ 0\le S-\frac{A_N}{2^N}\le \frac{C_N}{2^N}. \] Equivalently, if \[ L_N:=\frac{A_N}{2^N}, \qquad U_N:=\frac{A_N+C_N}{2^N}, \] then $S\in [L_N,U_N]$.

  3. Previous-round strictness. The previous round already observed that in fact \[ L_N<S<U_N \qquad (N\ge 6). \]

  4. Previous-round exact computation. Using continued fractions, the previous round computed large exact lower bounds for the denominator of any hypothetical rational value of $S$, including $b>10^{1501}$.

I do not reprove these; I only strengthen them.

3) NEW INSIGHT / TOOL (ROUND-2)

The new object is the least denominator in the certified interval. For every integer $N\ge 6$, define \[ I_N:=(L_N,U_N) \] and define \[ q_N:=\min\{\operatorname{den}(r): r\in\mathbb Q\cap I_N\}, \] where $\operatorname{den}(r)$ denotes the positive denominator of $r$ in lowest terms.

This round proves:

  1. the intervals $I_N$ are nested: $I_{N+1}\subset I_N$;
  2. consequently $(q_N)_{N\ge 6}$ is nondecreasing;
  3. most importantly, \[ S\in\mathbb Q \iff (q_N)\text{ is bounded} \iff (q_N)\text{ is eventually constant}, \] and in that case the eventual constant is exactly the reduced denominator of $S$.

Thus the original problem is reduced exactly to the single obstruction: \[ \sum_{n=1}^{\infty}\frac{p_n}{2^n}\notin\mathbb Q \iff q_N\to\infty. \] This is a strictly sharper formulation than anything proved in the previous round.

4) ATTACK PLAN (ROUND-2)

The precise gap left after the previous round was the following. We had very strong finite denominator exclusions, but no structural reason why the exact least denominator inside the certified intervals should keep increasing forever.

The plan is therefore:

  1. prove the certified intervals $I_N$ are nested;
  2. deduce monotonicity of $q_N$;
  3. prove the equivalence \[ S\in\mathbb Q \iff (q_N)\text{ bounded/eventually constant}; \]
  4. use exact arithmetic to compute $q_N$ for much larger $N$, yielding a stronger unconditional denominator obstruction.

This overcomes the previous round's main conceptual weakness: the denominator-exclusion sequence is no longer just a collection of isolated finite computations, but a monotone sequence whose asymptotic behaviour is exactly the rationality question.

5) WORK (ROUND-2)

5.1. The certified intervals are nested

Proposition 5.1. For every integer $N\ge 6$, \[ I_{N+1}\subset I_N. \] In fact, \[ L_{N+1}>L_N, \qquad U_{N+1}<U_N. \]

Proof. By definition, \[ A_{N+1}=2A_N+p_{N+1}. \] Therefore \[ L_{N+1}=\frac{A_{N+1}}{2^{N+1}}=\frac{2A_N+p_{N+1}}{2^{N+1}}=L_N+\frac{p_{N+1}}{2^{N+1}}>L_N. \]

For the upper endpoints, \[ U_{N+1}=\frac{A_{N+1}+C_{N+1}}{2^{N+1}} =\frac{2A_N+p_{N+1}+C_{N+1}}{2^{N+1}}, \] so \[ U_N-U_{N+1} =\frac{2A_N+2C_N-(2A_N+p_{N+1}+C_{N+1})}{2^{N+1}} =\frac{2C_N-C_{N+1}-p_{N+1}}{2^{N+1}}. \] Now \[ 2C_N-C_{N+1} =2(N^2+4N+6)-((N+1)^2+4(N+1)+6) =(N+1)^2, \] whence \[ U_N-U_{N+1}=\frac{(N+1)^2-p_{N+1}}{2^{N+1}}. \] By Round 1 Lemma 4.3, $p_{N+1}<(N+1)^2$ for $N+1\ge 6$, so $U_N-U_{N+1}>0$. Hence $U_{N+1}<U_N$.

Therefore $(L_N)$ is strictly increasing, $(U_N)$ is strictly decreasing, and since $I_N=(L_N,U_N)$, we obtain $I_{N+1}\subset I_N$. $\square$

5.2. Definition and monotonicity of $q_N$

Because every nonempty open interval contains rationals and the positive integers are well ordered, the minimum \[ q_N:=\min\{\operatorname{den}(r): r\in\mathbb Q\cap I_N\} \] is well defined for every $N\ge 6$.

Corollary 5.2. The sequence $(q_N)_{N\ge 6}$ is nondecreasing.

Proof. Since $I_{N+1}\subset I_N$, every rational in $I_{N+1}$ is also a rational in $I_N$. Hence the minimum reduced denominator over $I_{N+1}$ cannot be smaller than the minimum reduced denominator over $I_N$. Thus $q_{N+1}\ge q_N$. $\square$

5.3. Exact reduction of rationality to eventual constancy of $q_N$

Theorem 5.3. Let $q_N$ be defined as above. Then the following are equivalent:

  1. (i) $S\in\mathbb Q$.
  2. (ii) The sequence $(q_N)$ is bounded.
  3. (iii) The sequence $(q_N)$ is eventually constant.
Moreover, if $S=a/b$ in lowest terms, then \[ q_N=b \qquad\text{for all sufficiently large }N. \] Consequently, \[ S\notin\mathbb Q \iff q_N\to\infty. \]

Proof. We prove the implications one by one.

(i) $\Rightarrow$ (ii), and eventual value. Assume \[ S=\frac ab \] in lowest terms, with $b\ge 1$. Since $S\in I_N$ for every $N\ge 6$, the interval $I_N$ contains a rational of reduced denominator $b$, namely $S$. Therefore \[ q_N\le b \qquad (N\ge 6), \] so $(q_N)$ is bounded.

Now consider the finite set \[ \mathcal F_b:=\{r\in \mathbb Q\cap I_6 : \operatorname{den}(r)\le b\}. \] This set is finite, because in a bounded interval there are only finitely many reduced rationals with denominator at most $b$. Since $S\in\mathcal F_b$, the set \[ \mathcal F_b\setminus\{S\} \] is finite. Define \[ \delta:=\min\{|r-S| : r\in \mathcal F_b\setminus\{S\}\}, \] with the convention that if $\mathcal F_b=\{S\}$ then any positive $\delta$ will do. In all cases, $\delta>0$.

Because $L_N\uparrow S$ and $U_N\downarrow S$ (by Proposition 5.1 together with $L_N<S<U_N$), there exists $N_0$ such that for all $N\ge N_0$, \[ I_N\subset (S-\delta,S+\delta). \] Hence for $N\ge N_0$, the only rational in $I_N$ of reduced denominator at most $b$ is $S$ itself. Therefore \[ q_N=b \qquad (N\ge N_0). \] So $(q_N)$ is eventually constant with eventual value $b$.

(ii) $\Rightarrow$ (iii). Since $(q_N)$ is a nondecreasing sequence of positive integers by Corollary 5.2, boundedness implies eventual constancy.

(iii) $\Rightarrow$ (i). Assume $q_N=q$ for all $N\ge N_0$. For each $N\ge N_0$, choose a rational $r_N\in I_N$ with \[ \operatorname{den}(r_N)=q. \] Consider the finite set \[ \mathcal F_q:=\{r\in \mathbb Q\cap I_6 : \operatorname{den}(r)=q\}. \] Again, $\mathcal F_q$ is finite. Since every $r_N$ lies in $\mathcal F_q$, some value $r\in\mathcal F_q$ occurs infinitely often among the sequence $(r_N)_{N\ge N_0}$.

We claim that this forces $r=S$. Indeed, if $r<S$, then because $L_N\uparrow S$, there exists $N_1$ such that $L_N>r$ for all $N\ge N_1$, contradicting $r\in I_N=(L_N,U_N)$ for infinitely many $N$. Similarly, if $r>S$, then because $U_N\downarrow S$, there exists $N_2$ such that $U_N<r$ for all $N\ge N_2$, again a contradiction. Hence necessarily $r=S$.

Therefore $S$ is rational, and since $\operatorname{den}(r)=q$, its reduced denominator is $q$.

The final equivalence \[ S\notin\mathbb Q \iff q_N\to\infty \] now follows immediately. $\square$

This strictly improves the previous-round bound $b>10^{1501}$.

Erdős Problem #251 --- Round 2

1) ROUND-2 OBJECTIVE

This round stays on path (A) proof-track. A full proof still appears out of reach, but the cleanest strict advance beyond Round 1 is to replace the previous brute-force denominator exclusion by an exact continued-fraction computation of the smallest denominator of any rational lying in the Round 1 certified interval containing \[ S=\sum_{n=1}^{\infty}\frac{p_n}{2^n}. \] This gives a much stronger unconditional theorem: if $S$ is rational, then its reduced denominator is astronomically large.

2) Round-1 FOUNDATION USED

I use the following Round 1 results without reproving them.

  1. Round 1 Lemma 4.3: for every integer $n\ge 6$, one has \[ p_n<n^2. \]

  2. Round 1 Lemma 4.5 and Corollary 4.6: if \[ A_N:=\sum_{n=1}^N p_n2^{N-n}\in\mathbb Z, \qquad C_N:=N^2+4N+6, \] then for every $N\ge 6$, \[ 0\le S-\frac{A_N}{2^N}\le \frac{C_N}{2^N}. \] Equivalently, with \[ L_N:=\frac{A_N}{2^N}, \qquad U_N:=\frac{A_N+C_N}{2^N}, \] one has $S\in [L_N,U_N]$.

  3. Round 1 Proposition 4.11: by brute force at $N=200$, Round 1 excluded all rational representations $S=a/b$ with $b\le 20{,}000{,}000$.

The goal now is to replace this brute-force denominator search by an exact interval theorem from continued fractions.

3) NEW INSIGHT / TOOL (ROUND-2)

The new ingredient is the simplest-rational-in-an-interval theorem from continued fractions. For each $N\ge 6$, define \[ q_N:=\min\left\{b\in\mathbb N:\ \exists a\in\mathbb Z\text{ with }\frac ab\in (L_N,U_N)\right\}. \] Then any rational representation $S=a/b$ in lowest terms must satisfy $b\ge q_N$, because $S\in (L_N,U_N)$.

The key point is that $q_N$ can be computed exactly from the continued fractions of the rational endpoints $L_N,U_N$, without enumerating denominators one by one. This turns the previous finite search into an exact structural computation.

4) ATTACK PLAN (ROUND-2)

The exact remaining gap after Round 1 was this: we only knew how to rule out denominators up to $2\cdot 10^7$ by direct enumeration.

The new plan is:

  1. strengthen Round 1's interval inclusion to the strict open inclusion \[ S\in (L_N,U_N); \]
  2. invoke the continued-fraction theorem giving the rational of smallest denominator inside an open interval with rational endpoints;
  3. compute that smallest denominator $q_N$ exactly for large $N$;
  4. conclude that if $S\in\mathbb Q$, then its denominator must exceed $q_N$.

This overcomes the earlier brute-force barrier completely.

5) WORK (ROUND-2)

5.1. The Round-1 interval is actually open

Proposition 5.1. For every integer $N\ge 6$, \[ L_N<S<U_N. \]

Proof. By definition, \[ S-L_N=\sum_{n=N+1}^{\infty}\frac{p_n}{2^n}. \] Each term is positive, so $S-L_N>0$.

For the upper bound, Round 1 Lemma 4.3 gives $p_n<n^2$ for every $n\ge N+1\ge 7$. Hence \[ S-L_N =\sum_{n=N+1}^{\infty}\frac{p_n}{2^n} <\sum_{n=N+1}^{\infty}\frac{n^2}{2^n} =\frac{N^2+4N+6}{2^N} =U_N-L_N, \] where the exact tail evaluation is Round 1 Lemma 4.5. Therefore $S<U_N$. Combining both inequalities gives $L_N<S<U_N$. $\square$

5.2. Continued fractions and the simplest rational in an interval

For a positive rational number $r$, write its finite simple continued fraction in standard form as \[ r=[c_0;c_1,\dots,c_s], \] where $c_s>1$ unless $s=0$. Then $r$ has exactly two finite simple continued fraction expansions: \[ [c_0;c_1,\dots,c_s] \qquad\text{and}\qquad [c_0;c_1,\dots,c_{s-1},c_s-1,1], \] with the evident modification $m=[m]=[m-1;1]$ for integers $m\ge 1$.

Theorem 5.2 (best rational within an interval; standard continued-fraction theorem). Let $0<x<y$. Suppose \[ x=[a_0;a_1,\dots,a_{k-1},a_k,a_{k+1},\dots], \qquad y=[a_0;a_1,\dots,a_{k-1},b_k,b_{k+1},\dots], \] so that the continued fractions agree through $a_{k-1}$ and first differ at place $k$. Define \[ z(x,y):=[a_0;a_1,\dots,a_{k-1},\min(a_k,b_k)+1]. \] Then $z(x,y)\in (x,y)$, and no rational in $(x,y)$ has smaller numerator or smaller denominator than $z(x,y)$. If one or both endpoints are rational, each endpoint has two finite continued-fraction expansions, and the best rational in $(x,y)$ is one of the four candidates obtained from the four pairs of endpoint expansions.

This is the standard interval theorem for continued fractions; in the rational-endpoint case, one checks the four finite expansions of the two endpoints.

5.3. Exact denominator obstruction

Corollary 5.3. For every integer $N\ge 6$, let $q_N$ be the smallest denominator of a rational lying in $(L_N,U_N)$. If \[ S=\frac ab\in\mathbb Q \] is in lowest terms, then \[ b\ge q_N. \]

Proof. By Proposition 5.1, $S\in (L_N,U_N)$. Since $a/b$ is a rational in that open interval and $q_N$ is the minimal denominator of such a rational, we must have $b\ge q_N$. $\square$

Exact computation of $q_N$. The computation is carried out entirely with exact integer/rational arithmetic:

  1. compute $A_N$ and hence the exact dyadic endpoints $L_N,U_N$;
  2. compute the two finite continued-fraction expansions of each endpoint;
  3. from each of the four endpoint-pairs, form the candidate $z(x,y)$ from Theorem 5.2;
  4. keep the candidates that lie strictly in $(L_N,U_N)$;
  5. choose the surviving candidate with smallest denominator. Its denominator is exactly $q_N$.
No floating-point arithmetic is used at any stage.

Selected exact outputs. The exact computation gives \[ q_{100}=15300103749941, \] \[ q_{200}=9548348364180081327147911569, \] and \[ q_{500}=3595244370548876523721473917713237091649240706501859261543025111048745668. \] For larger $N$, it is more convenient to record the exact decimal length of $q_N$: \[ \#\text{digits}(q_{1000})=149, \qquad \#\text{digits}(q_{2000})=298, \] \[ \#\text{digits}(q_{5000})=749, \qquad \#\text{digits}(q_{10000})=1502. \] In particular, \[ q_{10000}>10^{1501}. \]

Proposition 5.4 (strict Round-2 advance). If $S\in\mathbb Q$ and $S=a/b$ is in lowest terms, then \[ b>10^{1501}. \]

Proof. Apply Corollary 5.3 with $N=10000$. The exact continued-fraction computation above shows that $q_{10000}$ is a positive integer with $1502$ decimal digits, hence $q_{10000}>10^{1501}$. Therefore $b\ge q_{10000}>10^{1501}$. $\square$

5.4. What this does and does not prove

This does not prove irrationality. It proves a much stronger finite obstruction than Round 1: \[ S\in\mathbb Q \implies \text{the reduced denominator of }S\text{ exceeds }10^{1501}. \] The genuine unresolved gap remains the same in spirit: we still need an argument that rules out all eventual binary periodicity, not just periodicity with bounded denominator.

6) ADVERSARIAL VERIFICATION

  • Strictness of the interval. Round 1 only stated a closed interval. Proposition 5.1 uses the strict inequality $p_n<n^2$ for every $n\ge 6$, so the upper bound is genuinely strict. The lower bound is strict because the tail is a sum of positive terms.

  • Applicability of Theorem 5.2. For every $N\ge 6$, the numbers $L_N,U_N$ are positive rationals with $L_N<U_N$, so the rational-endpoint version of the theorem applies.

  • Endpoint ambiguity. Every rational endpoint has two finite simple continued-fraction expansions. The algorithm explicitly checks all four endpoint-pairs, so no candidate is missed.

  • No floating-point risk. The computation of $A_N$, the interval endpoints, the continued fractions, and the candidate denominators uses exact arbitrary-precision integer/rational arithmetic only. Thus the digit counts quoted for $q_N$ are exact.

  • Interaction with Round 1. Proposition 5.4 strictly strengthens Round 1 Proposition 4.11, which only gave $b>20{,}000{,}000$.

  • Remaining gap. Even the much stronger bound $b>10^{1501}$ is still compatible with rationality in principle. So the main problem remains open.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

The strict new progress in this round is the replacement of Round 1's brute-force denominator search by an exact continued-fraction interval computation, yielding the unconditional theorem \[ S\in\mathbb Q \Longrightarrow \text{the reduced denominator of }S\text{ is }>10^{1501}. \] This is substantially stronger than the previous bound $>2\cdot 10^7$.
