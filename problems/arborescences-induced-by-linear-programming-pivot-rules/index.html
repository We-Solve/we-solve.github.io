Arborescences Induced by Linear-Programming Pivot Rules

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

For a nondegenerate linear program on a polytope and a generic linear objective, orient each edge toward decreasing objective value. A memoryless pivot rule chooses an improving outgoing edge using the current basis and fixed problem data, without a history of previous pivots. Choosing one such edge at every nonoptimal vertex yields a directed spanning tree toward the unique optimum, called an arborescence.

Scope qualification.

Verbatim supplied catalogue question

For a fixed linear-programming objective, how do the induced arborescences vary with the memoryless pivot rule, and for a fixed memoryless pivot rule, how do they vary with the objective?

A precise subclass of the broad question

The source studies normalized-weight rules as a controlled subclass of memoryless rules. We rederive its elementary polyhedral mechanism for a fixed objective and state exactly what changes when the objective varies. This is a proof within that subclass, not a classification of every unrestricted memoryless rule.
Independent choices on an acyclic oriented graph.
Let a finite directed graph be acyclic and have a unique sink $z$. At every other vertex $v$ choose one outgoing arc. Following chosen arcs cannot cycle, so it terminates at a sink, necessarily $z$. The chosen graph is connected after forgetting directions, and it has exactly one arc for each of the $N-1$ nonsink vertices. A connected undirected graph on $N$ vertices with $N-1$ edges is a tree: if it had a cycle, deleting one cycle edge would preserve connectivity, while a connected graph has at least $N-1$ edges by growing a spanning tree. Therefore each choice gives a rooted arborescence. Conversely such an arborescence chooses exactly one outgoing arc at each nonsink. If $d^+(v)$ denotes outdegree, their number is $\prod_{v\ne z}d^+(v)$. This concerns local choices with no shared rule-parameter restriction. It does not imply that one normalized-weight vector realizes every such combination.
A complete fixed-objective Minkowski-sum construction.
Fix an edge orientation on a polytope with strictly improving directions and the unique-sink property just described. At each nonsink $v$, let $D_v$ contain the vectors $(u-v)/\eta(u-v)$ for improving neighbors $u$, where the normalization values are fixed and positive. Distinct neighboring edges have distinct positive rays, so these normalized vectors are distinct: otherwise one neighbor would lie in the segment from $v$ to another, contrary to being an edge endpoint/vertex. Put $Q_v=\operatorname{conv}D_v$ and \[ \Pi=\sum_{v\ne z}Q_v, \] where the sum consists of all sums of one point from each polytope. For a weight vector $w$ giving a unique maximum in each finite $D_v$, the rule selects its maximizing neighbor at each vertex. The unique point maximizing $w\cdot x$ on $\Pi$ is the sum of those selected directions: each summand is bounded by its own maximum, and equality in the sum forces equality in every summand. This proves both existence and uniqueness of that maximizer.

Moreover two such generic weights give the same maximizing point of $\Pi$ if and only if they give the same selected neighbor at every vertex. The reverse implication is immediate. For the forward direction write the common point as the sum of the choices for the second weight and evaluate the first weight on it. The sum attains the first weight's sum of individual maxima. Each individual summand is no larger than its maximum, so every summand attains it; uniqueness forces every selected direction to agree. Distinctness of directions forces the same neighbor. Thus the maximizing-vertex regions of this explicit polytope encode exactly the coherent arborescences in this fixed-normalization subclass.

Varying the objective and a finite comparison arrangement.
For a rule with $w=c$ and normalization independent of $c$, the orientation of each edge changes only when $c\cdot(u-v)=0$. For fixed $v$, two candidate scores exchange order only when \[ c\cdot\left(\frac{u-v}{\eta(u-v)}- \frac{u'-v}{\eta(u'-v)}\right)=0. \] On each connected open region avoiding all these finitely many hyperplanes, every edge sign and every score comparison remains constant. Therefore the whole chosen arborescence remains constant. This proves an exact finite structural description for this rule class, including the inequalities to test a proposed region. It does not bound the number of regions polynomially in a general input description, and it requires the vertices, adjacency data and normalization values. Enumerating that data can itself be expensive.
