Math-6766

Three-Dimensional Coloring Number of the Sphere

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Use the following provisional interpretation of the supplied question: a triangulation is a finite simplicial complex whose geometric realization is homeomorphic to the sphere \[ S^3=\{x\in{\mathbb{R}}^4:\|x\|=1\}. \] Let $\mathcal T(S^3)$ denote the class of these triangulations. The supplied record does not explicitly specify finiteness or whether more general triangulations with face identifications are admitted; the intended class requires confirmation.

For $T\in\mathcal T(S^3)$, write $V(T)$ for its vertex set and define \[ \chi_3(T)=\min\left\{k\in{\mathbb{Z}}_{\geq 1}:\exists c:V(T)\to\{1,\ldots,k\}\ \text{such that}\ \forall\sigma\in T,\ \dim\sigma=3\Longrightarrow |c(V(\sigma))|\geq 2\right\}. \] Thus the coloring is a vertex coloring: every tetrahedron must contain vertices of at least two colors, while monochromatic triangles are permitted. No proper-coloring requirement is imposed on edges. Define the uniform coloring number by \[ \chi_3(S^3)=\sup_{T\in\mathcal T(S^3)}\chi_3(T)\in{\mathbb{Z}}_{\geq1}\cup\{\infty\}. \] The vertex-coloring convention and this supremum definition make explicit the natural interpretation of the notation in the record, but are not explicitly defined there.

Problem. Determine $\chi_3(S^3)$. In particular, does there exist an integer $k\geq1$ such that every $T\in\mathcal T(S^3)$ has a vertex coloring with at most $k$ colors and no monochromatic tetrahedron? If such a uniform bound exists, determine the least possible bound or establish an upper bound. The bound is required to be independent of the triangulation; each individual finite triangulation already admits a coloring using a distinct color at every vertex.

The supplied record labels this problem open. Its dated literature assessment instead concerns knot complexity and the treewidth of minimal triangulations of knot complements, so that assessment does not substantiate the status of this coloring question. The correspondence between the question and the cited report requires human verification.

Short English statement

For every finite simplicial triangulation of the $3$-sphere, color its vertices so that no tetrahedron is monochromatic; monochromatic triangles are allowed. Determine whether one fixed finite number of colors works for every triangulation, and determine the optimal number or an upper bound. This formulation uses a provisional interpretation of the triangulation class and coloring-number notation. The supplied open-status label has not been independently verified.
