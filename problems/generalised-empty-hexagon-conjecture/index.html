Generalised Empty Hexagon Conjecture

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Shared notation.
$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.

For a finite set $P\subset\mathbb R^2$, an empty hexagon consists of six points $S\subseteq P$ in strictly convex position such that \[\operatorname{conv}(S)\cap P=S.\] Thus no additional point lies either inside or on the boundary of the hexagon.

Statement recorded in the supplied source.
For every integer $\ell\geq3$, does there exist an integer $f(\ell)$ such that every finite $P\subset\mathbb R^2$ with $|P|\geq f(\ell)$ contains $\ell$ collinear points or an empty hexagon? [S2]

Short English statement

If collinear subsets have a fixed bounded size, must every sufficiently large planar point set contain a convex hexagon with no other point in its closed hull?
