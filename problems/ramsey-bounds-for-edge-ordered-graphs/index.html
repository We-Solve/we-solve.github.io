Math-4443

Ramsey Bounds for Edge-Ordered Graphs

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

An edge-ordered graph is a graph $H$ together with a total order $\prec_H$ on its edge set. The supplied record does not explicitly define the graph domain, the number of colours, or the host-order quantifier in $r_{\mathrm{edge}}$. The following gives a precise conditional formulation using finite simple undirected graphs, two colours, and an existentially chosen host edge order; these conventions require confirmation against the source.

An order-preserving copy of $(H,\prec_H)$ in an edge-ordered graph $(G,\prec_G)$ is an injection $f:V(H)\to V(G)$ such that every edge $uv\in E(H)$ maps to an edge $f(u)f(v)\in E(G)$, and, for all $e,e'\in E(H)$, \[ e\prec_H e'\quad\Longleftrightarrow\quad f(e)\prec_G f(e'). \] The copy need not be induced. Under the stated conventions, define $r_{\mathrm{edge}}(H,\prec_H)$ to be the least positive integer $N$ for which there exists a total order $\prec$ on $E(K_N)$ such that every colouring $\chi:E(K_N)\to\{1,2\}$ contains an order-preserving copy of $(H,\prec_H)$ whose edges all have the same colour. Set this value to $\infty$ if no such $N$ exists. An underlying graph is $d$-degenerate if every nonempty subgraph has a vertex of degree at most $d$.

Under these conventions, the two questions are:

  1. Does there exist an absolute constant $A>0$ such that, for every integer $n\geq1$, every graph $H$ with $|V(H)|=n$, and every total order $\prec_H$ on $E(H)$, \[ r_{\mathrm{edge}}(H,\prec_H)\leq 2^{An}? \]
  2. Does there exist a function $C:{\mathbb{Z}}_{\geq0}\to(0,\infty)$ such that, for every integer $d\geq0$, every integer $n\geq1$, every $d$-degenerate graph $H$ with $|V(H)|=n$, and every total order $\prec_H$ on $E(H)$, \[ r_{\mathrm{edge}}(H,\prec_H)\leq C(d)n? \]
Here the source notation $2^{O(n)}$ is interpreted as a uniform exponential upper bound, and the absolute implied factor in $O(C(d)n)$ is absorbed into $C(d)$. The graph, colouring, copy, and host-order conventions above are explicit provisional interpretations, not definitions verified from the report.

Short English statement

The questions ask whether every $n$-vertex edge-ordered graph has an edge-ordered Ramsey number bounded exponentially in $n$, and whether bounded degeneracy improves this to a bound linear in $n$, with a constant depending only on the degeneracy. The precise formulation above is conditional on conventions missing from the supplied record. The supplied open status requires independent review.
