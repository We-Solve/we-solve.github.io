Kourovka Notebook Problem 20.89

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Let $K$ be a field, let $d\geq 1$ be an integer, and let $G\leq \operatorname{GL}_d(K)$. This uses the usual finite-dimensional meaning of a linear group; the supplied source specifies no restriction on the field or its characteristic. Use the commutator convention $[x,g]=x^{-1}g^{-1}xg$, and define the left-normed iterated commutators by \[ c_1(x,g)=[x,g],\qquad c_{n+1}(x,g)=[c_n(x,g),g]\quad(n\geq 1). \] An element $g\in G$ is almost Engel if \[ \exists E_g\subseteq G\text{ finite}\quad \forall x\in G\quad \exists N=N(x,g)\in{\mathbb{Z}}_{\geq 1}\quad \forall n\geq N,\qquad c_n(x,g)\in E_g. \] Thus the finite set $E_g$ may depend on $g$, but must work for every $x$; the threshold may depend on both $x$ and $g$. An element is Engel if the same condition holds with $E_g=\{1_G\}$. Put \[ \operatorname{AE}(G)=\{g\in G:g\text{ is almost Engel}\}. \] Question (P. Shumyatsky, Kourovka Notebook Problem 20.89). For every field $K$, every integer $d\geq 1$, and every subgroup $G\leq\operatorname{GL}_d(K)$, is $\operatorname{AE}(G)$ a subgroup of $G$?

The supplied record gives two background results: Gruenberg's result that the Engel elements of a linear group form a subgroup, and Shumyatsky's result that a linear group all of whose elements are almost Engel is finite-by-hypercentral. Here finite-by-hypercentral means that there is a finite normal subgroup with hypercentral quotient, that is, a quotient equal to its transfinite upper center. These are supplied contextual assertions, not additional hypotheses or independently verified results.

Short English statement

Does the set of almost Engel elements form a subgroup in every linear group? For each such element $g$, one finite set must eventually contain all sufficiently long iterated commutators with $g$, for every starting element $x$, with the threshold allowed to depend on $x$ and $g$. The supplied registry labels the question open; this draft does not independently verify that status.
