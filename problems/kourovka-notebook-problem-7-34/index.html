Math-3238

Kourovka Notebook Problem 7.34

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a finite group $H$, define its $2$-rank by \[ m_2(H)=\max\{d\in{\mathbb{Z}}_{\geq 0}: H\text{ contains a subgroup isomorphic to }({\mathbb{Z}}/2{\mathbb{Z}})^d\}. \] For $x\in G$, let \[ C_G(x)=\{g\in G:gx=xg\} \] be its centralizer. Interpreting the source's term "$3$-element" as a nonidentity element of order a power of $3$, the problem is to describe, up to isomorphism, all finite groups $G$ such that \[ \forall x\in G,\qquad \left(|x|=3^k\text{ for some integer }k\geq1\right) \Longrightarrow m_2(C_G(x))\leq2. \] Equivalently, it suffices to require this inequality for every element of order exactly $3$: if $|x|=3^k$, then $x^{3^{k-1}}$ has order $3$ and $C_G(x)\subseteq C_G(x^{3^{k-1}})$. Groups with no nonidentity $3$-elements satisfy the condition vacuously. No simplicity or solvability hypothesis is imposed.

The source does not explicitly exclude the identity from "$3$-elements." This draft excludes it; if the identity were included, the condition would instead be equivalent to $m_2(G)\leq2$, since $C_G(1)=G$.

Short English statement

Describe all finite groups in which the centralizer of every nonidentity element of $3$-power order has $2$-rank at most $2$, equivalently contains no elementary abelian subgroup of order $8$. The supplied motivation is that many sporadic finite simple groups have this property; the requested classification concerns all finite groups.
