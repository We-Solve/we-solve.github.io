Assumptions and Function Classes for Function Secret Sharing

Statement

Definitions and mathematical statement

Shared notation.
Standard number systems are denoted by $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$; index ranges, computational models and specialized notation follow the cited problem source and the definitions below.

Function secret sharing distributes keys whose local evaluations combine to the output of a function while hiding that function from the prescribed coalitions. A point function is nonzero at one designated input and zero elsewhere.

A cryptographic security requirement compares an efficient adversary's advantage with a negligible function of the security parameter. A negligible function is smaller than every inverse polynomial eventually; computational and information-theoretic security are different requirements.

Statement recorded in the supplied source.
Characterize the function classes for which efficient function secret-sharing schemes follow from one-way functions, and determine the necessary and sufficient cryptographic assumptions for useful FSS instances; in particular, improve one-way-function-based FSS for point functions with at least three parties. [S2]
Scope qualification.
The coalition threshold, leakage, output group, and efficiency parameters are source-specific.

Short English statement

Characterize which functions admit efficient secret sharing from one-way functions and improve the stated multiparty point-function case.
