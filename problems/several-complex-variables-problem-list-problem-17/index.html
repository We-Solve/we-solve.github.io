Several Complex Variables Problem List — Problem 17

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

For a positive integer $n$, define the unit ball and unit polydisc by \[ B_n=\left\{z\in{\mathbb{C}}^n:\sum_{j=1}^{n}|z_j|^2<1\right\},\qquad \Delta^n=\left\{z\in{\mathbb{C}}^n:|z_j|<1\text{ for every }1\le j\le n\right\}. \] For a domain $\Omega\subseteq{\mathbb{C}}^n$, let \[ H^\infty(\Omega)=\left\{f:\Omega\to{\mathbb{C}}:f\text{ is holomorphic and }\sup_{z\in\Omega}|f(z)|<\infty\right\}. \] The corona assertion for $\Omega$ is the following statement: for every positive integer $k$ and every $f_1,\ldots,f_k\in H^\infty(\Omega)$ satisfying \[ \exists c>0\quad\forall z\in\Omega,\qquad \sum_{i=1}^{k}|f_i(z)|>c, \] there exist $g_1,\ldots,g_k\in H^\infty(\Omega)$ such that \[ \forall z\in\Omega,\qquad \sum_{i=1}^{k}f_i(z)g_i(z)=1. \] The supplied problem asks whether this assertion holds when $\Omega=B_n$, and whether it holds when $\Omega=\Delta^n$. The source does not specify $n$ or explicitly state whether it asks about a particular dimension or all dimensions; the formulation above consequently retains $n$ as a parameter. No quantitative bound on the norms of the $g_i$ is requested in the supplied statement.

Short English statement

Can every finite collection of bounded holomorphic functions on the unit ball or unit polydisc whose summed absolute values have a uniform positive lower bound admit bounded holomorphic coefficients giving an identically constant combination equal to $1$? The supplied source leaves the complex dimension unspecified.
