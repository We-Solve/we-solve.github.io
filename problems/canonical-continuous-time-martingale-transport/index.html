Canonical Continuous-Time Martingale Transport

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

The supplied problem asks for a natural or canonical continuous Markov martingale connecting two probability measures in convex order, and for a natural continuous-time formulation of martingale transport. Neither naturality nor canonicity is defined in the record. The state space, moment hypotheses, time interval, meaning of continuity, and transport objective are also unspecified, so a unique fully quantified formulation cannot be recovered.

The following gives an explicitly conditional Euclidean interpretation, rather than supplying missing hypotheses as facts about the source. Fix a dimension $d\geq 1$ and a finite horizon $T>0$. Let $\mathcal P_1({\mathbb{R}}^d)$ be the Borel probability measures $\lambda$ satisfying $\int_{{\mathbb{R}}^d}|x|\,\lambda({\,\mathrm{d}} x)<\infty$. For $\mu,\nu\in\mathcal P_1({\mathbb{R}}^d)$, write $\mu\preceq_{\mathrm{cx}}\nu$ if \[ \int_{{\mathbb{R}}^d}\varphi(x)\,\mu({\,\mathrm{d}} x)\leq\int_{{\mathbb{R}}^d}\varphi(x)\,\nu({\,\mathrm{d}} x) \] for every finite convex function $\varphi:{\mathbb{R}}^d\to{\mathbb{R}}$, allowing integrals with value $+\infty$. The first-moment assumption and an affine lower bound for $\varphi$ make these integrals well-defined. This is the non-strict convex-order interpretation of the source notation $\mu\prec_c\nu$; the record does not explicitly define that notation.

Let $\Omega=C([0,T],{\mathbb{R}}^d)$, let $X_t(\omega)=\omega(t)$, and let $\mathcal F_t=\sigma(X_r:0\leq r\leq t)$. Define $\mathcal M^{\mathrm{cont,Markov}}_T(\mu,\nu)$ to consist of probability laws $P$ on $\Omega$ such that \[ P\circ X_0^{-1}=\mu,\qquad P\circ X_T^{-1}=\nu, \] \[ {\mathbb{E}}_P[|X_t|]<\infty,\qquad {\mathbb{E}}_P[X_t\mid\mathcal F_s]=X_s \quad(0\leq s\leq t\leq T), \] and, for every bounded Borel function $f:{\mathbb{R}}^d\to{\mathbb{R}}$, \[ {\mathbb{E}}_P[f(X_t)\mid\mathcal F_s] ={\mathbb{E}}_P[f(X_t)\mid\sigma(X_s)] \quad P\text{-almost surely},\qquad 0\leq s\leq t\leq T. \] Here continuity means continuity of sample paths, and the Markov property is allowed to depend on both times $s,t$. These are conditional interpretations, not specified source requirements.

Within an intended framework of this kind, the first question is whether, for every admissible pair $\mu\preceq_{\mathrm{cx}}\nu$, there is a law \[ P_{\mu,\nu}\in\mathcal M^{\mathrm{cont,Markov}}_T(\mu,\nu) \] selected by a mathematically specified natural or canonical construction. Membership in this set expresses only the endpoint, continuity, Markov, and martingale requirements; it does not express canonicity. The source supplies neither a selection criterion nor conditions under which such a criterion should give uniqueness.

For context, in this conditional Euclidean framework a static martingale coupling is a probability measure $\pi$ on ${\mathbb{R}}^d\times{\mathbb{R}}^d$ with marginals $\mu,\nu$ such that, for the coordinate variables $(U,V)$, ${\mathbb{E}}_\pi[V\mid U]=U$. The source's second question asks for a natural continuous-time version of the martingale transport problem. It does not specify a cost functional, optimization direction, admissible path laws, intermediate marginal constraints, or the relation required between static and continuous-time problems. Consequently this second question remains a request to formulate a theory, rather than a specified variational problem.

Short English statement

Given probability measures in convex order, the source asks for a natural or canonical continuous Markov martingale with those endpoint laws, and for a natural continuous-time martingale transport formulation. The displayed framework is conditional: the source leaves the state space, regularity assumptions, meaning of canonicity, and transport objective unresolved. Its supplied status is partially solved; this draft does not independently verify that assessment.
