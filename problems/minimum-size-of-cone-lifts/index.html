Math-14003

Minimum Size of Cone Lifts

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

A convex cone in ${\mathbb{R}}^m$ is a convex set closed under multiplication by nonnegative real scalars. It is full-dimensional if its interior in ${\mathbb{R}}^m$ is nonempty. Given a cone $K\subseteq{\mathbb{R}}^m$ and a set $C\subseteq{\mathbb{R}}^n$, a $K$-lift of $C$ consists of an affine subspace $L\subseteq{\mathbb{R}}^m$ and a linear map $\pi:{\mathbb{R}}^m\to{\mathbb{R}}^n$ such that \[ C=\pi(K\cap L). \] The affine subspace is not required to pass through the origin. Equality here means exact equality of sets; no closure operation or approximation is included.

The original formulation takes $K$ to be a full-dimensional closed convex cone and $C$ to be an arbitrary convex set, and asks when such a lift exists. The supplied corrected formulation focuses on the minimum-size question and calls $C$ a cone. The supplied verification note asserts that the report proves the preceding general characterization and leaves the minimum-size question open; this assertion has not been independently verified here.

For a specified nested family $(K_k)_{k\in I}$, with each $K_k\subseteq{\mathbb{R}}^{m_k}$, and a specified target cone $C\subseteq{\mathbb{R}}^n$, define the set of feasible indices by \[ \mathcal F(C;(K_k))= \left\{k\in I:\begin{array}{l} \text{there exist an affine subspace }L\subseteq{\mathbb{R}}^{m_k}\\ \text{and a linear map }\pi:{\mathbb{R}}^{m_k}\to{\mathbb{R}}^n\\ \text{such that }C=\pi(K_k\cap L) \end{array}\right\}. \] The minimum-size question is to determine, in terms of the specified family and target, \[ \min\mathcal F(C;(K_k)), \] whenever this minimum exists, and to determine whether a feasible index exists at all. If the feasible set is empty, no member of the family provides such a lift. If the index order does not ensure existence of a least feasible index, that issue must also be resolved.

Unresolved scope. The record supplies neither a particular family nor a particular target cone. It does not specify the index set and its order, the meaning of nesting when ambient dimensions vary, or whether every $K_k$ must satisfy the full-dimensionality, closedness, and convexity hypotheses imposed on $K$ in the original formulation. It also does not explicitly specify convexity, closedness, or full-dimensionality of the target cone in the corrected formulation. These qualifications must be settled before this general problem schema becomes a fully specified minimum-size problem.

Short English statement

For a chosen family of cones and a chosen target cone, find the least index for which an affine slice of the indexed cone maps linearly onto the target. The source leaves the family, target, and several conventions unspecified. Its original formulation allows arbitrary convex target sets, whereas its corrected formulation asks about target cones. This is a statement-only draft requiring human mathematical review.
