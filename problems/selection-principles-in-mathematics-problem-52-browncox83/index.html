Math-6021

Selection Principles in Mathematics — Problem 52 ([BrownCox83])

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Equip every subset of ${\mathbb{R}}$ with its usual subspace topology. A subset $A$ of a space $T$ is nowhere dense in $T$ if $\operatorname{int}_T(\overline{A}^{\,T})=\varnothing$. A set $V\subseteq{\mathbb{R}}$ is a $\nu$-set if every subset of $V$ that is nowhere dense in $V$ is countable; the source describes this as being Luzin relative to itself.

Use the standard meaning of concentration: a space $Y$ is concentrated on $D\subseteq Y$ if, for every open set $U\subseteq Y$ containing $D$, the set $Y\setminus U$ is countable. Here countable includes finite and empty sets. The supplied record does not explicitly define concentration, so this interpretation requires source confirmation.

The question is whether the following implication holds for every $X\subseteq{\mathbb{R}}$: \[ \begin{gathered} \forall Y\subseteq X\ \exists D\subseteq Y\quad \left[ D\text{ is countable and } \forall U\subseteq Y\text{ open in }Y, \quad D\subseteq U\Longrightarrow Y\setminus U\text{ is countable}\right] \\[2pt] \Longrightarrow \exists V\subseteq{\mathbb{R}}\ \exists f:V\to X\quad \left[V\text{ is a }\nu\text{-set and }f\text{ is continuous and surjective}\right]. \end{gathered} \] The supplied source states that every continuous image of a $\nu$-set satisfies the hypothesis; the question asks for the converse.

Short English statement

Suppose every subset $Y$ of a set of reals $X$ has a countable subset $D$ such that every open neighborhood of $D$ in $Y$ leaves only countably many points of $Y$ outside it. Must $X$ be a continuous image of a set of reals whose every relatively nowhere dense subset is countable?
