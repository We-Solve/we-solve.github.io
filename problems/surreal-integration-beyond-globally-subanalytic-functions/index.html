Surreal Integration Beyond Globally Subanalytic Functions

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $\mathrm{No}$ denote the ordered field of surreal numbers, whose underlying collection is a proper class. For an ordered field $K$, a semialgebraic subset of $K^n$ is a finite Boolean combination of polynomial equalities and inequalities with coefficients in $K$; a function is semialgebraic if its graph is semialgebraic.

For terminology only, in the usual real setting a restricted analytic function is a function $f\colon{\mathbb{R}}^n\to{\mathbb{R}}$ obtained from a real analytic function $g$ defined on an open neighbourhood of $[-1,1]^n$ by setting \[ f(x)=\begin{cases}g(x),&x\in[-1,1]^n,\\0,&x\notin[-1,1]^n.\end{cases} \] The structure ${\mathbb{R}}_{\mathrm{an}}$ is the real ordered field expanded by all such functions. Globally subanalytic sets are the sets definable in this structure, and globally subanalytic functions are those with globally subanalytic graphs. These real definitions do not specify interpretations of the functions on surreal arguments.

Source research question. Can the surreal-number measure and integration theory referred to in the source be extended beyond semialgebraic and globally subanalytic sets and functions, in particular to restricted analytic functions and exponentiation?

Unresolved formulation. This is an extension programme rather than a fully specified existence proposition. The supplied record does not define the starting measure and integral, their domains and value spaces, the axioms an extension must satisfy, or the required agreement with the starting theory. It also does not specify which surreal interpretations of restricted analytic functions are intended, which exponential function is intended, or which sets, functions, dimensions, and integration bounds must be covered. Consequently, no precise universal quantifiers over these objects, or definitive existence assertion for an extension, can be extracted without additional source information. Under the conventional real definitions above, restricted analytic functions are already globally subanalytic; the intended additional surreal coverage therefore needs clarification.

Short English statement

The question asks for a broader measure and integration theory on surreal numbers, especially involving restricted analytic functions and exponentiation. The source leaves the starting theory and the requirements for an extension unspecified. Its supplied status is partially solved; this is a dated curation label, not an independently verified mathematical conclusion.
