Gasca–Maeztu Maximal-Line Conjecture

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

For an integer $n\geq 1$, let \[ \Pi_n=\{p\in{\mathbb{R}}[x,y]:\deg p\leq n\},\qquad N=\binom{n+2}{2}. \] A set $X=\{p_1,\ldots,p_N\}\subset{\mathbb{R}}^2$ of distinct points is a $GC_n$ set if, for every $i\in\{1,\ldots,N\}$, there are nonconstant affine linear polynomials $\ell_{i1},\ldots,\ell_{in}\in{\mathbb{R}}[x,y]$ such that \[ Q_i=\prod_{k=1}^{n}\ell_{ik},\qquad Q_i(p_j)=\delta_{ij}\quad(1\leq j\leq N), \] where $\delta_{ij}=1$ for $i=j$ and $0$ otherwise. These are the fundamental interpolation polynomials. Here an affine linear polynomial has the form $ax+by+c$, with $(a,b)\ne(0,0)$. For such a polynomial $\ell$, write \[ V(\ell)=\{(x,y)\in{\mathbb{R}}^2:\ell(x,y)=0\}. \] A maximal line for $X$ means a line containing exactly $n+1$ points of $X$.

Gasca--Maeztu maximal-line conjecture. For every integer $n\geq1$ and every $GC_n$ set $X\subset{\mathbb{R}}^2$, there exist an index $i\in\{1,\ldots,N\}$ and a nonconstant affine linear polynomial $\ell$ such that \[ \ell\mid Q_i\quad\text{in }{\mathbb{R}}[x,y],\qquad \lvert X\cap V(\ell)\rvert=n+1. \] In particular, every such set contains a maximal line. The supplied excerpt attributes this conjecture to Gasca and Maeztu in 1982.

Qualifications requiring review. The extracted cardinality is typographically damaged; $\binom{n+2}{2}$ is its intended binomial reading. The phrase "linear forms" is interpreted as affine linear polynomials defining lines in ${\mathbb{R}}^2$. The source does not explicitly give the lower bound on $n$; the displayed conjecture uses positive degrees. If degree zero is included, the empty-product definition gives a singleton with fundamental polynomial $1$: the maximal-line question still has an affirmative interpretation, but the additional divisibility condition cannot hold. The accompanying inductive discussion says to adjoin $n$ points when passing from degree $n-1$ to degree $n$; this conflicts with the cardinality difference $\binom{n+2}{2}-\binom{n+1}{2}=n+1$ and is not used as a hypothesis.

Short English statement

The conjecture asks whether every planar interpolation set whose fundamental polynomials each factor into $n$ affine linear factors has a line through $n+1$ of its points. The supplied report also requires that this line divide some fundamental polynomial. Positive degrees are used here; the source's degree-zero boundary and damaged extraction require review.
