Statement

For $A\subseteq\mathbb N$ let $1_A$ be its indicator function and define the additive convolution \[ (1_A*1_A)(n):=\sum_{k\in\mathbb Z}1_A(k)\,1_A(n-k), \] which counts ordered representations $n=a+b$ with $a,b\in A$.

Given a function $g:\mathbb N\to(0,\infty)$ with $g(N)\to\infty$, determine for which $g$ the following implication holds: \[ \left(\exists c>0\ \forall N\ge N_0:\ |A\cap[1,N]|\ge c\,\frac{N^{1/2}}{g(N)}\right)\ \Longrightarrow\ \limsup_{n\to\infty}(1_A*1_A)(n)=\infty. \]

Erdős Problem #40 --- Round 5

1) ROUND-5 OBJECTIVE

Path (C): obstruction / correction by ruling out the natural reduction from the remaining $B_2[\lambda]$-core to the Sidon problem.

Round 4 reduced the unresolved subpolynomial sector of Problem #40 to the existence of an infinite $B_2[\lambda]$ set whose counting function is $N^{1/2-o(1)}$ in the strong "for all sufficiently large $N$" sense. The most promising next step is therefore to test whether this remaining $B_2[\lambda]$-problem can be collapsed to the Sidon problem (Problem #39) by a structural theorem.

In this round I show that two of the most natural reduction principles are false:

  • bounded-representation sets need not be finite unions of Sidon sets;
  • even a strong local Sidon-richness property (every finite subset contains a large Sidon subset) still does not force such a decomposition.
Thus the Round 4 exact core is genuinely broader than the Sidon case, and any eventual reduction to Problem #39 would require a new global density-preserving theorem of a different kind.

2) ROUND-4 FOUNDATION USED

I rely on the following Round 4 results without re-proving them.
  • Round 4 exact subpolynomial reformulation: Problem #40 fails for some subpolynomial $g(N)\to\infty$ if and only if there exists an integer $\lambda\ge 1$ and an infinite set $A\subset\mathbb N$ with $A\in B_2[\lambda]$ and \[ |A\cap[1,N]|\gg_{\varepsilon} N^{1/2-\varepsilon} \qquad\text{for every }\varepsilon>0. \]
  • Round 4 one-way link: a positive answer to Problem #39 implies a negative answer to Problem #40 for some subpolynomial $g$.
  • Round 4 gap: the converse direction remained open; in particular, it was unclear whether the Round 4 $B_2[\lambda]$-core was essentially equivalent to the Sidon problem.

3) NEW INSIGHT / TOOL (ROUND-5)

The new ingredient is a recent theorem of Reiher--Rödl--Schacht on Ramsey-type generalised Sidon sets. Specialised to $k=2$, it yields the following.
Theorem (External theorem, $k=2$ case): For every integer $\ell\ge 2$ there exists an infinite set $X\subset\mathbb N$ such that:
  1. (i) $X$ is a $B_2[\ell]$ set, i.e. every integer has at most $\ell$ nondecreasing representations $n=x_1+x_2$ with $x_1\le x_2$ and $x_1,x_2\in X$;
  2. (ii) for every finite colouring $X=X_1\cup\cdots\cup X_r$ there exists a colour class $X_q$ for which some integer has exactly $\ell$ nondecreasing representations as a sum of two members of $X_q$;
  3. (iii) every finite subset $Y\subset X$ contains a Sidon subset $Z\subset Y$ with \[ |Z|\ge \frac14 |Y|. \]

Theorem thm:RRS is new relative to the previous rounds. It gives a bounded-representation set that is locally very Sidon-rich, yet whose finite colourings always contain a colour class with repeated two-sums.

4) ATTACK PLAN (ROUND-5)

The exact gap left after Round 4 was:
Can the remaining $B_2[\lambda]$-core be reduced to Problem #39 by converting bounded-representation sets into Sidon sets?

Round 5 attacks this by testing two precise reduction principles.

  1. $P1$ For each fixed $\lambda\ge 2$, every $B_2[\lambda]$ set is a finite union of Sidon sets.
  2. $P2$ There exists $\delta>0$ such that every set $X\subset\mathbb N$ with the local property \[ \forall\text{ finite }Y\subset X\ \exists\text{ Sidon }Z\subset Y\text{ with }|Z|\ge \delta |Y| \] is a finite union of Sidon sets.

If either principle were true, then the Round 4 $B_2[\lambda]$-core would be much closer to Problem #39. I will prove that both are false, with $P2$ already false for $\delta=1/4$. This rules out an entire class of natural local-to-global reduction strategies.

5) WORK (ROUND-5)

5.1. Notation.
For $S\subset\mathbb N$ let \[ \rho_{S,2}(n):=|\{(a,b)\in S^2:a\le b,\ a+b=n\}|. \] Thus $S$ is Sidon exactly when $\sup_n \rho_{S,2}(n)\le 1$, and $S\in B_2[\ell]$ exactly when $\sup_n \rho_{S,2}(n)\le \ell$.
5.2. A structural obstruction.
Proposition: For every integer $\ell\ge 2$ there exists an infinite set $X\subset\mathbb N$ such that:
  1. (a) $X\in B_2[\ell]$;
  2. (b) $X$ is not a finite union of Sidon sets;
  3. (c) every finite subset $Y\subset X$ contains a Sidon subset $Z\subset Y$ with $|Z|\ge |Y|/4$.
Proof: Fix $\ell\ge 2$, and let $X$ be as in Theorem thm:RRS. Property (a) is exactly part (i) of Theorem thm:RRS, while property (c) is exactly part (iii).

It remains to prove (b). Suppose for contradiction that \[ X=S_1\cup\cdots\cup S_r \] for some finite family of Sidon sets $S_1,\dots,S_r$. Since this is only a covering, not necessarily a partition, define a colouring $c:X\to [r]$ by choosing for each $x\in X$ one index $c(x)$ with $x\in S_{c(x)}$. Let \[ X_i:=\{x\in X:c(x)=i\}\subset S_i \qquad (1\le i\le r). \] Each colour class $X_i$ is a subset of the Sidon set $S_i$, hence itself Sidon. Therefore \[ \sup_n \rho_{X_i,2}(n)\le 1 \qquad\text{for every }i=1,\dots,r. \] But Theorem thm:RRS(ii) says that for every finite colouring of $X$ there is a colour class, say $X_q$, for which some integer has exactly $\ell$ nondecreasing two-term representations inside $X_q$. Equivalently, \[ \sup_n \rho_{X_q,2}(n)\ge \ell\ge 2, \] contradicting that $X_q$ is Sidon. This contradiction proves (b). ∎

5.3. Two false reduction principles.
Proposition Proposition immediately yields the following.
Corollary (Failure of finite Sidon decomposition): For every integer $\lambda\ge 2$, the following statement is false:
Every $B_2[\lambda]$ set is a finite union of Sidon sets.
Proof: Take $\ell=\lambda$ in Proposition Proposition. Then $X\in B_2[\lambda]$ but $X$ is not a finite union of Sidon sets. ∎
Corollary (Failure of the Alon--Erdős local-to-global principle): The following statement is false, already with $\delta=1/4$:
If $X\subset\mathbb N$ is such that every finite subset $Y\subset X$ contains a Sidon subset $Z\subset Y$ with $|Z|\ge \delta |Y|$, then $X$ is a finite union of Sidon sets.
Proof: Again use Proposition Proposition. The set $X$ there satisfies the stated local property with $\delta=1/4$, but is not a finite union of Sidon sets. ∎
5.4. Consequence for Problem #40.
Round 4 identified the unresolved core of Problem #40 as the possible existence of a dense $B_2[\lambda]$ set with counting function $N^{1/2-o(1)}$. Corollaries Corollary (Failure of finite Sidon decomposition) and Corollary (Failure of the Alon--Erdős local-to-global principle) show that this core cannot be collapsed to Problem #39 by either of the two most obvious mechanisms:
  1. (i) decomposing bounded-representation sets into finitely many Sidon pieces;
  2. (ii) proving only a local positive-density Sidon extraction statement for finite subsets.

This yields the following corrected structural formulation.

Corollary (Minimal corrected obstruction statement): The remaining open sector of Problem #40 is a genuinely generalised Sidon problem. More precisely, any reduction of the Round 4 exact core to Problem #39 must use a theorem strictly stronger than both false principles above.
Proof: By Corollary Corollary (Failure of finite Sidon decomposition), finite Sidon decomposition fails even inside the class $B_2[\lambda]$. By Corollary Corollary (Failure of the Alon--Erdős local-to-global principle), even strong local Sidon-richness does not force such a global decomposition. Therefore neither principle can justify replacing the $B_2[\lambda]$-core from Round 4 by the Sidon problem. ∎

6) ADVERSARIAL VERIFICATION

  • Compatibility of notation: The external theorem uses $\rho_{X,2}(n)$ to count nondecreasing representations, which is exactly the standard $B_2[\ell]$ convention used in the previous rounds after converting from ordered counts.

  • Colouring vs covering: In Proposition Proposition(b), the sets $S_1,\dots,S_r$ may overlap. Choosing for each $x\in X$ a single colour $c(x)$ produces colour classes $X_i\subset S_i$, which is enough because subsets of Sidon sets are Sidon.

  • Local property is genuinely strong: Corollary Corollary (Failure of the Alon--Erdős local-to-global principle) does not merely say that some finite subsets of $X$ contain large Sidon subsets; it says every finite subset does, with a fixed proportion $1/4$.

  • No density conclusion is being smuggled in: Theorem thm:RRS says nothing about $|X\cap[1,N]|$, so Round 5 does not solve the remaining density question of Problem #40. It only rules out two natural ways of reducing that density question to the Sidon case.

  • Could there still be some deeper equivalence with Problem #39? Yes. Round 5 does not exclude all possible future reductions. It excludes only reductions based on finite Sidon decomposition or on the local positive-density extraction principle above.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 5 gives a substantive structural advance beyond Round 4:

The unresolved subpolynomial sector of Problem #40 is not presently reducible to the Sidon problem by the two most natural local-to-global mechanisms. In fact, for every $\ell\ge 2$ there exists an infinite $B_2[\ell]$ set that is locally Sidon-rich (every finite subset contains a Sidon subset of size at least one quarter) but is nevertheless not a finite union of Sidon sets.
Thus the remaining core of Problem #40 must be treated as a genuinely generalised Sidon problem, not merely as Problem #39 in disguise.

WORK: A FINITE ALTERATION BOUND

Let $S$ contain $n$ integers and have at most $\lambda$ unordered representations of any sum, with repetitions allowed. For $n\ge8\lambda$, $S$ contains a Sidon subset of size at least \[ \frac{n^{2/3}}{4\lambda^{1/3}}. \] For each sum, join every two distinct unordered representations to form a forbidden configuration. Two distinct representations cannot share an element unless they are identical. Hence configurations have either four distinct elements or three distinct elements of the form $a+c=2b$. The total number of representation pairs is at most \[ \sum_s\binom{r(s)}2\le\frac{\lambda-1}2\sum_s r(s) \le\frac{\lambda n^2}{2}. \] The three-element configurations number at most $\lambda n$, since their middle element determines a diagonal representation and there are at most $\lambda-1$ alternatives. Select each element independently with probability $p=(8\lambda n)^{-1/3}$. Then delete one vertex from each retained forbidden configuration. The expected size left is at least \[ pn-\frac{\lambda n^2p^4}{2}-\lambda np^3 =\frac{15}{16}pn-\frac18\ge\frac12pn =\frac{n^{2/3}}{4\lambda^{1/3}}. \] The displayed inequality uses $pn\ge1$, which follows from $n\ge8\lambda$. Some realization therefore has the claimed size. Removing all configurations makes every unordered sum unique.

ADVERSARIAL VERIFICATION AND REMAINING GAP

Diagonal representations require three-vertex configurations and cannot be hidden in a four-uniform hypergraph. The separate $\lambda np^3$ term handles them. With $n=A(N)=N^{1/2-o(1)}$, this lemma gives only $N^{1/3-o(1)}$ points at each cutoff. Further, the extracted subsets at different cutoffs need not be nested. Thus this standard alteration argument neither constructs a single infinite dense Sidon set nor resolves the near-square-root $B_2[\lambda]$ problem. It identifies two separate missing requirements: density preservation and compatibility across scales.

Erdős Problem #40 --- Round 2

1) ROUND-2 OBJECTIVE

Path (B): counterexample / disproof for an infinite family of functions $g$.

Round 1 isolated that first-moment bounds are far too weak in the regime $|A\cap[1,N]|\asymp \sqrt N/g(N)$ with $g(N)\to\infty$, and suggested that any negative answer should come from building a set $A$ with uniformly bounded additive representation counts (a "$B_2[O(1)]$" construction) while keeping the required lower bound on $|A\cap[1,N]|$.

In this round I implement that disproof track for a large explicit class of growth functions $g$, using a theorem of Erdős--Rényi on infinite $B_2[g]$ sequences.

2) ROUND-1 FOUNDATION USED

I use the following vetted Round 1 items.
  • Lemma 40.1: For $m=|A\cap[1,N]|$, some $n\le 2N$ has at least $m^2/(2N-1)$ ordered representations using summands $\le N$.
  • Lemma 40.2: If $(1_A\!\ast\!1_A)(n)\le R$ for all $n$, then $|A\cap[1,N]|<\sqrt{2RN}$ for all $N$.
  • Round 1 gap: no construction was given that meets the hypothesis $|A\cap[1,N]|\gg \sqrt N/g(N)$ (for all large $N$) while keeping $(1_A\!\ast\!1_A)(n)$ bounded.

3) NEW INSIGHT / TOOL (ROUND-2)

The new tool is a classical probabilistic-existence theorem (quoted in a standard survey) constructing infinite sets with bounded two-term representation function and prescribed polynomial growth.

External Theorem (Erdős--Rényi, 1960; quoted as Theorem 8.2 in Sárközy--Sós). For every $\varepsilon>0$ there exists an integer $\lambda=\lambda(\varepsilon)$ and an infinite set $A\subset\mathbb N$ such that:

  1. (i) $A$ is a $B_2[\lambda]$ set: every $n\in\mathbb N$ has at most $\lambda$ solutions $a\le a'$ with $a,a'\in A$ to $a+a'=n$.
  2. (ii) (Polynomial density) There exists $N_0(\varepsilon)$ such that for all $N\ge N_0(\varepsilon)$, \[|A\cap[1,N]|>N^{\frac12-\varepsilon}.\]

4) ATTACK PLAN (ROUND-2)

  • Gap to close from Round 1: exhibit any divergent $g(N)$ for which the implication in Problem 40 fails.
  • Plan: Fix $\varepsilon>0$ and take $g(N)=N^{\varepsilon}$. Apply the external theorem above to obtain a set $A$ with $|A\cap[1,N]|\ge N^{1/2-\varepsilon}$ for all large $N$. Convert the $B_2[\lambda]$ property into a uniform bound on the ordered convolution $(1_A\ast 1_A)(n)$, showing $\limsup_n (1_A\ast 1_A)(n)<\infty$.
  • Extension: the same $A$ also disproves the implication for any $g$ that eventually dominates $N^{\varepsilon}$ (since the required lower bound $\sqrt N/g(N)$ is then even weaker).

5) WORK (ROUND-2)

5.1. From $B_2[\lambda]$ to bounded ordered convolution.
For a set $A\subset\mathbb N$, write \[r_A(n):=(1_A\ast 1_A)(n)=|\{(a,b)\in A\times A: a+b=n\}|\] for the ordered two-sum representation function. Also write \[R_A(n):=|\{(a,a')\in A\times A: a\le a',\ a+a'=n\}|\] for the nondecreasing (unordered) representation count.
Lemma: If $R_A(n)\le \lambda$ for all $n$ (i.e. $A\in B_2[\lambda]$), then $r_A(n)\le 2\lambda$ for all $n$.
Proof: Fix $n$. Map each ordered solution $(a,b)\in A\times A$ with $a+b=n$ to the nondecreasing pair $(\min\{a,b\},\max\{a,b\})$. This map lands in the set counted by $R_A(n)$. Moreover, every nondecreasing pair $(x,y)$ with $x+y=n$ has at most two preimages: $(x,y)$ and $(y,x)$, and only one if $x=y$. Hence $r_A(n)\le 2R_A(n)\le 2\lambda$. ∎
5.2. A disproof for $g(N)=N^{\varepsilon}$.
Fix any $\varepsilon>0$ and set \[g(N):=N^{\varepsilon},\qquad N\in\mathbb N. \] Then $g(N)\to\infty$. Let $A\subset\mathbb N$ be the set produced by the Erdős--Rényi theorem in §3, with the corresponding $\lambda=\lambda(\varepsilon)$.
Proposition: For $g(N)=N^{\varepsilon}$, the implication in Problem 40 is false. More precisely, there exists an infinite set $A\subset\mathbb N$ and a constant $c>0$ such that \[|A\cap[1,N]|\ge c\,\frac{\sqrt N}{g(N)}\quad\text{for all sufficiently large $N$},\] but $\sup_{n\in\mathbb N}(1_A\ast 1_A)(n)<\infty$.
Proof: By property (ii) of the Erdős--Rényi theorem, for all $N\ge N_0(\varepsilon)$ we have \[|A\cap[1,N]|>N^{\frac12-\varepsilon}=\frac{\sqrt N}{N^{\varepsilon}}=\frac{\sqrt N}{g(N)}. \] Thus the hypothesis of Problem 40 holds with $c=1$ (and $N_0=N_0(\varepsilon)$).

On the other hand, by property (i) the set $A$ satisfies $R_A(n)\le\lambda$ for all $n$. By Lemma 5.1, this implies \[(1_A\ast 1_A)(n)=r_A(n)\le 2\lambda\qquad\text{for all }n\in\mathbb N. \] Hence $\limsup_{n\to\infty}(1_A\ast 1_A)(n)\le 2\lambda<\infty$, contradicting the conclusion required in Problem 40. ∎

5.3. A necessary restriction on $g$.
The same argument yields an immediate corollary clarifying where a positive answer might still live.
Corollary: Fix $\varepsilon>0$ and let $A$ be as above. Then the implication in Problem 40 fails for every function $g$ satisfying $g(N)\ge N^{\varepsilon}$ for all sufficiently large $N$. Consequently, if the implication in Problem 40 holds for some $g(N)\to\infty$, then necessarily \[\forall\varepsilon>0:\quad g(N)=o(N^{\varepsilon})\quad (N\to\infty),\] i.e. $g$ must be subpolynomial ($g(N)=N^{o(1)}$).
Proof: If $g(N)\ge N^{\varepsilon}$ eventually, then for all large $N$, $\sqrt N/g(N)\le \sqrt N/N^{\varepsilon}=N^{1/2-\varepsilon}$. But $|A\cap[1,N]|>N^{1/2-\varepsilon}$ for all large $N$ by the theorem, so $|A\cap[1,N]|\ge \sqrt N/g(N)$ eventually as well. The boundedness of $(1_A\ast 1_A)(n)$ is unchanged. The final claim is just the contrapositive. ∎

6) ADVERSARIAL VERIFICATION

  • Ordered vs unordered counts: The only conversion step is Lemma 5.1. The map $(a,b)\mapsto(\min\{a,b\},\max\{a,b\})$ has fibers of size $\le 2$, so $r_A(n)\le 2R_A(n)$ is tight and correct.
  • Quantifiers in the hypothesis: The Erdős--Rényi theorem gives a lower bound $|A\cap[1,N]|>N^{1/2-\varepsilon}$ for all $N\ge N_0(\varepsilon)$, matching the "$\forall N\ge N_0$" hypothesis in Problem 40. Taking $c=1$ is valid.
  • $g(N)\to\infty$: For $g(N)=N^{\varepsilon}$ this is immediate.
  • Does boundedness hold for all $n$ or only large $n$? The $B_2[\lambda]$ property is for all $n\in\mathbb N$, so $\sup_n (1_A\ast 1_A)(n)\le 2\lambda$ holds globally. This certainly implies the failure of $\limsup_n(1_A\ast 1_A)(n)=\infty$.
  • Interaction with Round 1 Lemma 40.2: Lemma 40.2 gives $|A\cap[1,N]|\ll \sqrt N$ under bounded representation. Our constructed set has $|A\cap[1,N]|\asymp N^{1/2-\varepsilon}$, which is consistent.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 2 gives an explicit infinite family of divergent functions for which the implication in Problem 40 fails:

for every fixed $\varepsilon>0$, taking $g(N)=N^{\varepsilon}$ (or any $g$ eventually $\ge N^{\varepsilon}$) does not force $\limsup_n (1_A\ast 1_A)(n)=\infty$.
The remaining open regime is when $g(N)$ is subpolynomial ($g(N)=N^{o(1)}$), e.g. $g(N)=(\log N)^C$ or $g(N)=\log\log N$.

3) NEW INSIGHT / TOOL (ROUND-3)

The new ingredient is a reduction that turns Problem #40 into an existence/nonexistence statement about dense infinite $B_2[\lambda]$ sets, plus a monotonicity principle.
Definition (Ordered representation bound): For $A\subset\mathbb N$ define \[r_A(n):=(1_A\ast 1_A)(n)=|\{(a,b)\in A\times A: a+b=n\}|\in\mathbb N\cup\{0\}.\] We say that $A$ has bounded two-sum representations if $\sup_{n\ge 1} r_A(n)<\infty$.
Lemma (Reduction to $B_2[\lambda]$ sets): Fix $g:\mathbb N\to(0,\infty)$ with $g(N)\to\infty$. The implication in Problem #40 fails for this $g$ if and only if there exist constants $c>0$, $\lambda\in\mathbb N$, and an infinite set $A\subset\mathbb N$ such that
  1. (i) (Density) $|A\cap[1,N]|\ge c\,\dfrac{\sqrt N}{g(N)}$ for all sufficiently large $N$;
  2. (ii) ($B_2[\lambda]$) $A\in B_2[\lambda]$ (equivalently, $r_A(n)\le 2\lambda$ for all $n$).
Equivalently, failure for $g$ is the same as the existence of a bounded-representation set $A$ with \[\liminf_{N\to\infty}\ \frac{g(N)\,|A\cap[1,N]|}{\sqrt N}\ >\ 0.\]
Proof: ($\Leftarrow$) If such an $A$ exists, then by (ii) and Round 2 Lemma 5.1 we have $\sup_n r_A(n)\le 2\lambda<\infty$, hence $\limsup_n r_A(n)<\infty$. Together with (i), this is a direct counterexample to the conclusion of Problem #40.

($\Rightarrow$) If the implication in Problem #40 fails for $g$, then there exists an infinite $A\subset\mathbb N$ and $c>0$ such that the density lower bound in (i) holds, while $\limsup_n r_A(n)<\infty$. Set $R:=\sup_n r_A(n)<\infty$. Define $R_A(n)$ to be the number of unordered representations $n=a+a'$ with $a\le a'$ and $a,a'\in A$. Then $R_A(n)\le r_A(n)\le R$ for all $n$, so $A\in B_2[R]$. Taking $\lambda:=R$ gives (ii). The liminf reformulation is equivalent to (i) by unpacking the meaning of "$\gg$". ∎

Lemma (Monotonicity in $g$): Let $g_1,g_2:\mathbb N\to(0,\infty)$ with $g_i(N)\to\infty$ and assume $g_2(N)\ge g_1(N)$ for all sufficiently large $N$.
  1. (a) If Problem #40 fails for $g_1$, then it fails for $g_2$.
  2. (b) If Problem #40 holds for $g_2$, then it holds for $g_1$.
Proof: If $g_2\ge g_1$ eventually then $\sqrt N/g_2(N)\le \sqrt N/g_1(N)$ eventually. Thus any set $A$ meeting the stronger density requirement for $g_1$ also meets the weaker density requirement for $g_2$. Statement (a) follows by transporting a counterexample; (b) is the contrapositive of (a). ∎

4) ATTACK PLAN (ROUND-3)

  • Gap after Round 2: we had a family of counterexamples, but no structural characterisation of what a positive answer would have to exclude.
  • Round 3 goal: use Lemma lem:reduction and Lemma lem:mono to:
    1. reformulate Problem #40 as a question about how dense a bounded-representation ($B_2[\lambda]$) set can be while still satisfying a uniform lower bound at all large $N$;
    2. upgrade the Round 2 corollary into a clean "no polynomial $g$ can work" statement.
  • Why this helps: it isolates the remaining open regime as a single extremal question about dense infinite $B_2[\lambda]$ sets, clarifying what must be improved to settle the problem.

5) WORK (ROUND-3)

5.1. A clean necessary condition on $g$.
Define the (asymptotic) power-growth exponent of $g$ by \[\alpha(g):=\liminf_{N\to\infty} \frac{\log g(N)}{\log N}\in[0,\infty].\] Note that $\alpha(g)>0$ is equivalent to: there exists $\varepsilon>0$ such that $g(N)\ge N^{\varepsilon}$ for all sufficiently large $N$.
Theorem (Polynomially large $g$ never work): If $g(N)\to\infty$ and $\alpha(g)>0$, then the implication in Problem #40 fails for $g$. Equivalently, if Problem #40 holds for some $g$, then necessarily \[\alpha(g)=0\qquad\text{ i.e. }\qquad \forall\varepsilon>0:\ g(N)=o(N^{\varepsilon}).\] (In other words, $g$ must be subpolynomial: $g(N)=N^{o(1)}$.)
Proof: Assume $\alpha(g)>0$. Then choose $\varepsilon>0$ and $N_1$ such that $g(N)\ge N^{\varepsilon}$ for all $N\ge N_1$. By Round 2 Corollary 5.3, Problem #40 fails for every such $g$ (indeed for every $g$ with $g(N)\ge N^{\varepsilon}$ eventually), because an Erdős--Rényi $B_2[\lambda]$ set $A$ exists with $|A\cap[1,N]|\ge N^{1/2-\varepsilon}=\sqrt N/N^{\varepsilon}\ge \sqrt N/g(N)$ for all large $N$ while $\sup_n r_A(n)<\infty$.

The final statement is the contrapositive. ∎

5.2. Minimal corrected statement and remaining open regime.
Combining Lemma lem:mono, Lemma lem:reduction, and Theorem thm:polyfails yields the following sharp "frontier" formulation.
Corollary (Frontier formulation): Let $\mathcal G$ denote the class of functions $g(N)\to\infty$ for which Problem #40 holds. Then:
  1. (i) (Downward closure) If $g\in\mathcal G$ and $h(N)\le g(N)$ eventually, then $h\in\mathcal G$.
  2. (ii) (Polynomial exclusion) No $g$ with $\alpha(g)>0$ lies in $\mathcal G$.
  3. (iii) (Open core) The only possible elements of $\mathcal G$ are subpolynomial functions $g(N)=N^{o(1)}$ (e.g. $g(N)=(\log N)^C$, $g(N)=\log\log N$, etc.). Determining whether any such $g$ lies in $\mathcal G$ is equivalent (by Lemma lem:reduction) to ruling out the existence of bounded-representation $B_2[\lambda]$ sets with density $\gg \sqrt N/g(N)$ for all large $N$.

6) ADVERSARIAL VERIFICATION

  • Quantifiers in Lemma lem:reduction: Problem #40 assumes $|A\cap[1,N]|\gg \sqrt N/g(N)$ for all sufficiently large $N$. This is exactly the statement that the ratio $g(N)|A\cap[1,N]|/\sqrt N$ has positive liminf. Using limsup or limsup only would be incorrect; the proof uses the liminf version.

  • Bounded convolution $\Rightarrow B_2[\lambda]$: If $r_A(n)\le R$ for all $n$, then unordered representations satisfy $R_A(n)\le r_A(n)\le R$, so $A\in B_2[R]$ is valid.

  • Monotonicity direction: The direction in Lemma lem:mono(a) is the one actually used: weakening the hypothesis (larger $g$) cannot repair a counterexample. The contrapositive (b) is consistent.

  • No hidden dependence on $N$: In Theorem thm:polyfails we use a fixed $\varepsilon>0$ extracted from $\alpha(g)>0$; this matches the Round 2 construction which provides a single fixed $B_2[\lambda(\varepsilon)]$ set.

7) FINAL

UNRESOLVED (BUT STRICTLY ADVANCED).

Round 3 upgrades Round 2 from a family of counterexamples to a structural description:

Problem #40 is false for every $g(N)\to\infty$ with positive power-growth rate $\alpha(g)>0$ (in particular for every polynomially growing $g$), and the only remaining possible regime is subpolynomial $g(N)=N^{o(1)}$.
The remaining core question is equivalent to understanding how dense an infinite bounded-representation $B_2[\lambda]$ set can be while maintaining a uniform lower bound at all large $N$.
