Math-6667

Torsion-Freeness of Cluster Algebra Class Groups

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $\mathcal A=\mathcal A(\mathbf x,B)$ denote a cluster algebra with initial cluster $\mathbf x$ and exchange data $B$. A cluster algebra is generated over its coefficient ring by the cluster variables obtained through seed mutation. The supplied record does not specify the coefficient ring or coefficient system, the permitted exchange data, or the convention for frozen variables and their invertibility. These choices remain unresolved in the quantifier "every cluster algebra."

An abelian group $G$, written additively, is torsion-free if \[ \forall g\in G\;\forall m\in{\mathbb{Z}}_{>0},\qquad mg=0\Longrightarrow g=0. \] For a Krull domain $\mathcal A$ with fraction field $K$, its divisor class group has the standard description \[ \operatorname{Div}(\mathcal A) =\bigoplus_{\substack{\mathfrak p\in\operatorname{Spec}(\mathcal A)\\\operatorname{ht}(\mathfrak p)=1}}{\mathbb{Z}}[\mathfrak p], \qquad \operatorname{Cl}(\mathcal A) =\operatorname{Div}(\mathcal A)\big/\operatorname{Prin}(\mathcal A), \] where \[ \operatorname{Prin}(\mathcal A) =\{\operatorname{div}(f):f\in K^{\times}\}, \qquad \operatorname{div}(f) =\sum_{\operatorname{ht}(\mathfrak p)=1}v_{\mathfrak p}(f)[\mathfrak p]. \] Here $v_{\mathfrak p}$ is the normalized discrete valuation associated with the discrete valuation ring $\mathcal A_{\mathfrak p}$; the Krull-domain hypothesis ensures finite support of each principal divisor.

Conjecture as recorded. The divisor class group of every cluster algebra is torsion-free. Explicitly, the intended assertion is \[ \forall\mathcal A=\mathcal A(\mathbf x,B)\;\forall c\in\operatorname{Cl}(\mathcal A)\;\forall m\in{\mathbb{Z}}_{>0}, \qquad mc=0\Longrightarrow c=0, \] where the first quantifier is intended to range over all cluster algebras in the source's convention.

Unresolved scope. The displayed definition of $\operatorname{Cl}$ applies to Krull domains. The record neither imposes that hypothesis on every algebra in the conjecture nor defines a divisor class group for the remaining algebras. Thus it does not determine a fully specified unrestricted assertion. Restricting the quantifier to Krull cluster algebras would give a precise assertion under the displayed definition, but would narrow the recorded conjecture.

The supplied dated curation labels the problem partially solved and reports that torsion-freeness is proved for acyclic cluster algebras and, more generally, for cluster algebras that are Krull domains, while the unrestricted formulation is not fully settled. These are supplied literature assessments, not independently verified mathematical or current-status claims.

Short English statement

The recorded conjecture asks whether every element of finite order in the divisor class group of any cluster algebra is zero. The coefficient conventions and the meaning of the class group outside the Krull-domain setting are unspecified. Supplied dated curation reports results for acyclic and Krull cluster algebras and labels the unrestricted problem partially solved; this draft requires human mathematical review.
