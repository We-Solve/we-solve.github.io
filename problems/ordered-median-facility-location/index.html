Statement recorded in the supplied source.
Given $n$ sites, a nonnegative cost matrix $C=(c_{j\ell})$, and $p<n$ facilities, choose $X\subseteq\{1,\ldots,n\}$ with $|X|=p$ to minimize the ordered weighted cost $\sum_{k=1}^n\lambda_k c_{\sigma_X(k)}(X)$, where $c_j(X)=\min_{\ell\in X}c_{j\ell}$ and $\sigma_X$ sorts these costs. [S2]

Research attempt: Exact finite search and a conditional ordered-cost linearization

Finite exact algorithm with all order weights retained.
Assume $1\le p<n$ and rational nonnegative costs and weights. The minimum over an empty facility set is not defined by the source, so $p=0$ would need a separate convention. For each of the $\binom np$ subsets $X$, compute the $n$ minima $c_j(X)$ using $O(np)$ comparisons, sort them using $O(n\log n)$ comparisons, and evaluate their weighted sum. Return the least value and its set. This is exact because every admissible set is examined. Ties in sorted costs do not affect the sum: permuting equal values leaves every rank contribution unchanged. The total arithmetic/comparison count is \[ O\left(\binom np(np+n\log n)\right). \] It is polynomial for fixed $p$, in particular $O(n^2\log n)$ for $p=1$, but not a polynomial guarantee when $p$ is part of the input. Rational bit costs also depend on the supplied coefficient lengths.

Weights cannot be discarded. With $p=1$ and \[ C=\begin{pmatrix}0&3&9&9\\1&0&9&9\\1&3&0&9\\5&3&9&0\end{pmatrix}, \] the first two facility columns have sorted costs $(0,1,1,5)$ and $(0,3,3,3)$. Equal weights choose the first column, of total cost $7$ rather than $9$; weights $(0,0,0,1)$ choose the second, of maximum cost $3$ rather than $5$. The other columns have total cost $27$ and maximum $9$. Conversely, with free self-service and weights $(1,0,\ldots,0)$, every nonempty facility set has objective zero, since its smallest service cost is zero.

A convex sorting formula under an additional hypothesis.
For a vector $z$ let $z_{(1)}\le\cdots\le z_{(n)}$. If $0\le\lambda_1\le\cdots\le\lambda_n$, then \[ \sum_{i=1}^n\lambda_i z_{(i)} =\lambda_1\sum_jz_j+ \sum_{r=2}^n(\lambda_r-\lambda_{r-1})\sum_{i=r}^n z_{(i)}. \] This follows by collecting the coefficient of each sorted entry. The sum of the largest $L$ entries, for $1\le L\le n$, equals \[ \min_{t\in\mathbb R}\left(Lt+\sum_j(z_j-t)_+\right). \] For any $t$, the sum over the largest $L$ entries is at most the displayed expression, by bounding each $z_j$ in that set by $t+(z_j-t)_+$. Equality holds when $t$ lies between the largest excluded and smallest included values, with $t\le z_{(1)}$ when $L=n$. Hence epigraph variables $u_j\ge z_j-t$, $u_j\ge0$ give a linear formulation of each top-$L$ sum. Nonnegative weight differences allow the minima to be combined independently.

This can be combined with binary facility variables $x_\ell$, $\sum_\ell x_\ell=p$, and continuous assignment variables $a_{j\ell}\ge0$, $\sum_\ell a_{j\ell}=1$, $a_{j\ell}\le x_\ell$, setting $z_j=\sum_\ell c_{j\ell}a_{j\ell}$. For fixed open facilities every such $z_j$ is at least its nearest-facility cost. Every order statistic is coordinatewise nondecreasing: if $z\le z'$ coordinatewise, the number of entries below any threshold for $z'$ is at most the corresponding number for $z$, implying $z_{(i)}\le z'_{(i)}$. With nonnegative $\lambda$, replacing assignments by nearest facilities therefore cannot increase the objective. Thus this mixed-integer linear route is exact for the additional nondecreasing-weight case.

It does not make the original facility problem convex or eliminate its binary search. Moreover the source allows nonnegative weights without ordering them. For $\lambda=(1,0)$ the ordered objective is $\min(z_1,z_2)$, which is not convex: it is zero at $(0,2)$ and $(2,0)$ but one at their midpoint. Negative differences in the displayed decomposition invalidate the independent epigraph-minimization argument. This is the precise gap in extending that convenient formulation to arbitrary source weights.
