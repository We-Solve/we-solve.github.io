Math-5048

Finitary-Factor Characterization of Markov Random Fields

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

The supplied target is to characterize invariant Markov random fields that are finitary factors of i.i.d. processes. The underlying graph, invariance group, spin space, and admissible i.i.d. input spaces are not specified. The following gives a parameterized formulation; these parameters require confirmation before a single classification problem is determined.

Fix a countable connected locally finite graph $G=(V,E)$, a transitive subgroup $\Gamma\leq\operatorname{Aut}(G)$, and a standard Borel spin space $S$. These are framework parameters, not hypotheses explicitly supplied by the record. For $W\subseteq V$, write $X_W=(X_v)_{v\in W}$, and for finite $W$ define its external vertex boundary by \[ \partial W=\{u\in V\setminus W:\text{ some }v\in W\text{ satisfies }\{u,v\}\in E\}. \] A random field $X=(X_v)_{v\in V}$ with values in $S^V$ is $\Gamma$-invariant if $(X_{\gamma v})_{v\in V}$ has the same law as $X$ for every $\gamma\in\Gamma$. Under the finite-region Markov convention used here, it is a Markov random field if, for every finite $W\subseteq V$ and every measurable $A\subseteq S^W$, \[ \mathbb P\left(X_W\in A\mid\sigma(X_u:u\in V\setminus W)\right) = \mathbb P\left(X_W\in A\mid\sigma(X_u:u\in\partial W)\right) \quad\text{almost surely}. \] No positivity assumption or particular Gibbs specification is supplied.

Let $T$ be a standard Borel space, let $\lambda$ be a probability measure on $T$, and let $Y=(Y_v)_{v\in V}$ have product law $\lambda^V$. Write $(\gamma y)_v=y_{\gamma^{-1}v}$. A finitary factor representation of $X$ is a measurable map $\Phi:D\to S^V$, where $D\subseteq T^V$ is a $\Gamma$-invariant set of full product measure, such that \[ \Phi(\gamma y)=\gamma\Phi(y),\qquad \mathcal L(\Phi(Y))=\mathcal L(X), \] and, for almost every $y\in D$ and every $v\in V$, there is a finite radius $R_v(y)\in\{0,1,2,\ldots\}$ such that \[ y'\in D,\quad y'|_{B_G(v,R_v(y))}=y|_{B_G(v,R_v(y))} \quad\Longrightarrow\quad \Phi(y')_v=\Phi(y)_v. \] Here $B_G(v,r)$ is the graph-distance ball. Such a field is called a finitary factor of i.i.d., abbreviated ffiid. The target imposes neither a deterministic bound on the coding radius nor a finite-expectation requirement.

Classification problem, conditional on the framework. Give necessary and sufficient conditions on a $\Gamma$-invariant Markov random field law $\mu$ on $S^V$ for there to exist an admissible input space $(T,\lambda)$ and a finitary equivariant map $\Phi$ as above with $\mathcal L(\Phi(Y))=\mu$. The intended choices of $G,\Gamma,S$, the input restrictions, and the precise Markov convention remain unresolved from the supplied record.

The original extract also discusses a separate question about finite expected coding radius for finitely dependent invariant processes. That question is contextual and does not add an integrability hypothesis to the classification target.

Short English statement

Characterize the invariant Markov random fields that can be generated equivariantly from independent identically distributed vertex labels, with each output determined by labels within an almost surely finite radius. The source does not specify the graph, symmetry group, spin space, or input restrictions, so the displayed formulation is conditional on those choices. Finite expected coding radius is a separate contextual question. The supplied open label and verification claims are curation metadata, not independently verified conclusions.
