Pingree open problems — Petersen tail-field problem 1

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Let $d\geq1$ be an integer, $A=\{0,1,\ldots,d-1\}$, and $X=A^{{\mathbb{Z}}}$ with its product Borel $\sigma$-field. Use the left shift $(\sigma x)_j=x_{j+1}$. For $n\geq0$, define count vectors $v_n,w_n:X\to{\mathbb{Z}}_{\geq0}^d$ by \[ (v_n(x))_i=\#\{0\leq j\leq n:x_j=i\},\qquad (w_n(x))_i=\#\{0\leq j\leq n:x_{-j}=i\},\quad i\in A. \] Thus each vector counts $n+1$ symbols and includes $x_0$. Write $\mathcal B(v_n,v_{n+1},\ldots)$ for the $\sigma$-field generated by those count maps. The source defines \[ \mathcal F_n^+=\bigcap_{k\geq n}\mathcal B(v_n,v_{n+1},\ldots),\qquad \mathcal F^+=\bigcap_{n\geq0}\mathcal F_n^+, \] with analogous minus definitions using $w_n$, and asks whether $\mathcal F^+=\mathcal F^-$.

In the printed definition of $\mathcal F_n^+$, $k$ does not occur in the intersected expression, so literally $\mathcal F_n^+=\mathcal B(v_n,v_{n+1},\ldots)$ and \[ \mathcal F^+=\bigcap_{n\geq0}\sigma(v_m:m\geq n),\qquad \mathcal F^-=\bigcap_{n\geq0}\sigma(w_m:m\geq n). \] The analogous intended expression with $v_k,v_{k+1},\ldots$ in the inner intersection would change the intermediate fields but gives the same final tail field.

No probability measure is supplied. Literal equality of Borel sub-$\sigma$-fields on the full shift is different from equality modulo null sets under a specified shift-invariant measure. The research summary suggests a measure-theoretic tail-field question, but does not specify such a measure, a class of measures, or completion conventions. These must be checked before the supplied open-status interpretation can be adopted.

Short English statement

Do the tail $\sigma$-fields generated by forward and backward cumulative symbol counts coincide? The printed inner intersection has an unused index, and the source does not say whether equality is literal or modulo null sets for a chosen invariant measure.
