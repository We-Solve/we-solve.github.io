Math-314

A promise-to-total bridge for effective bounds on finite integral point sets

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

Rojas's Question 18 asks whether a computable function of a bivariate integer polynomial $f$ bounds the size of every integer solution when only finitely many exist. To fix "size", put \[ Z_f=\{(x,y)\in{\mathbb{Z}}^2:f(x,y)=0\},\qquad H(x,y)=\max(|x|,|y|). \] The source says genus-one curves are handled and that finiteness is decidable, but gives no precise class, theorem hypotheses, or proof for these statements. Its rational-point references are separate from the integral-point question.

The aid's equivalence fixes an effectively encoded class $\mathcal C\subseteq{\mathbb{Z}}[X,Y]$ and assumes a total algorithm deciding whether $Z_f$ is finite for every $f\in\mathcal C$. Under this assumption it reports computable equivalence, by terminating reductions, of the following tasks:

  1. A promise bound: on every input with finite $Z_f$, halt and return $B\ge0$ with $H(x,y)\le B$ for all solutions; no correctness or termination requirement is imposed on infinite inputs.
  2. A total conditional bound: halt on every input and return a bound that is valid whenever $Z_f$ is finite.
  3. A finite-case exact lister: halt on every finite input with the entire finite set $Z_f$, with no promise on infinite inputs.
  4. The total extended maximum: return $\infty$ for infinite $Z_f$, return $-1$ for the empty set, and otherwise return $\max_{Z_f}H$.
  5. The total extended cardinality: return $\infty$ for infinite $Z_f$ and $|Z_f|$ for finite $Z_f$, including zero for the empty set.
  6. Decide on all $(f,N)$, $N\ge0$, the predicate \[ \operatorname{OUT}(f,N)\quad\Longleftrightarrow\quad \exists(x,y)\in Z_f:\ H(x,y)>N. \]
The empty-set maximum convention is explicit and is not claimed as source notation. Infinite integral zero sets are unbounded in max norm because every integer ball is finite, so OUT is then true for every $N$. The finiteness decider is what permits the total procedures to distinguish those infinite inputs.

Without assuming a finiteness decider, the aid still reports mutual computability of promise bounds, finite-case exact listing, and finite-case exact cardinality. Exact cardinality in this latter statement is required to halt and be correct only on finite inputs. Enumeration of integer pairs and testing $f(x,y)=0$ supplies the search side; a promise must not silently be replaced by a guaranteed total algorithm.

These are conditional reductions between tasks, not an existence theorem for all procedures on arbitrary plane curves. The original does not specify irreducibility, smoothness, or genus conventions for a general $f$; the fixed-class formulation avoids inventing such a scope. Its printed claims about genus one and finiteness remain historical supplied assertions requiring their exact hypotheses to be checked.

Short English statement

The question asks for an effective bound on finite integral point sets. The aid shows that, given a finiteness decider for a fixed effective polynomial class, several bound, listing, maximum, cardinality, and outside-ball tasks are equivalent. It handles empty and infinite inputs explicitly and does not turn those reductions into a general existence proof.
