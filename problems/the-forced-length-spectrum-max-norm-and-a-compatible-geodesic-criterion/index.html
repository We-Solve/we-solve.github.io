Math-1729

The forced length-spectrum max norm and a compatible-geodesic criterion

Status Partially solved · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

A. Papadopoulos's source question asks whether the length-spectrum metric on Teichmüller space is Finsler and, if so, for its infinitesimal norm. The surface class, normalization of the metric, and smoothness required of "Finsler" are not specified. The supplied reduction uses the usual finite-type hyperbolic Teichmüller setting and a possibly nonsmooth continuous norm.

Fix such a surface $S$, and write $\ell_X(\lambda)$ for hyperbolic length of a nonzero measured lamination. In the normalization used by the aid, put \[ d_{\mathrm{Th}}(X,Y)=\log\sup_{\lambda\ne0}\frac{\ell_Y(\lambda)}{\ell_X(\lambda)},\qquad d_{\mathrm{ls}}(X,Y)=\max\{d_{\mathrm{Th}}(X,Y),d_{\mathrm{Th}}(Y,X)\}. \] A convention inserting an overall factor $1/2$ rescales all corresponding norms and path distances; it must not be mixed with these formulas. Thurston's asymmetric norm is \[ F_X(v)=\sup_{[\lambda]}{\,\mathrm{d}}_X\log\ell_\lambda(v). \] The aid states that the metric derivative of $d_{\mathrm{ls}}$ forces the reversible norm \[ N_X(v)=\max\{F_X(v),F_X(-v)\} =\sup_{[\lambda]}|{\,\mathrm{d}}_X\log\ell_\lambda(v)|. \] For a differentiable path $\gamma$ with $\gamma(0)=X$, $\dot\gamma(0)=v$, this is the stated limit of $d_{\mathrm{ls}}(X,\gamma(t))/|t|$.

Let \[ D_N(X,Y)=\inf_{\gamma:X\to Y}\int_0^1N_{\gamma(t)}(\dot\gamma(t))\,{\,\mathrm{d}} t, \] with the appropriate piecewise smooth or absolutely continuous admissible paths. The reported general inequality is $D_N(X,Y)\geq d_{\mathrm{ls}}(X,Y)$. A local norm formula alone does not establish equality of these global distances.

For the aid's minimizing-path criterion, suppose the $N$-distance between the pair is attained by an admissible path. Put $a=d_{\mathrm{Th}}(X,Y)$, $b=d_{\mathrm{Th}}(Y,X)$. It reports:

  • If $a>b$, equality $D_N(X,Y)=d_{\mathrm{ls}}(X,Y)$ is equivalent to a path $\gamma:X\to Y$ which is a forward Thurston geodesic up to reparametrization and satisfies $F_{\gamma(t)}(\dot\gamma(t))\geq F_{\gamma(t)}(-\dot\gamma(t))$ almost everywhere.
  • If $b>a$, the analogous condition uses a reverse Thurston geodesic, with $F(-\dot\gamma)\geq F(\dot\gamma)$ almost everywhere.
  • If $a=b$, equality requires one path geodesic in both directions, with $F(\dot\gamma)=F(-\dot\gamma)$ almost everywhere. Such a compatible bi-geodesic is also sufficient.
The directional geodesic condition means its corresponding asymmetric length equals the endpoint distance; a parametrization with unit speed is not an extra requirement. A compatible path is automatically an $N$-minimizer. Conversely, deduction of a single compatible path from equality uses attainment of the infimum; without attainment the formulation must use approximating paths instead. The record does not spell out the existence/properness argument for minimizers or the full surface hypotheses.

In the intended continuous, possibly nonsmooth Finsler sense, the forced local norm leaves the global question whether $D_N=d_{\mathrm{ls}}$ for every pair. Under the required minimizer-existence hypotheses this becomes existence of the compatible paths above for every pair. The aid describes that global existence question as still open; it does not establish that the length-spectrum metric is Finsler.

Short English statement

The supplied reduction determines the only possible reversible infinitesimal norm, but its intrinsic path metric may exceed the endpoint length-spectrum distance. Equality requires compatible directional geodesics; tied forward and reverse distances require a single equal-speed bi-geodesic. The global existence issue is left open.
