Math-7042

Proper Three-Colorings for Homothets of Convex Sets

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Under the standard convex-body interpretation of the supplied statement, a plane convex body is a compact convex set $D\subset{\mathbb{R}}^2$ with nonempty interior. A positive homothetic copy of $D$ is \[ t+\lambda D=\{t+\lambda x:x\in D\},\qquad t\in{\mathbb{R}}^2,\quad\lambda>0. \] For a finite set $P\subset{\mathbb{R}}^2$, a three-coloring is a map $c:P\to\{1,2,3\}$; it need not use all three colors. A subset of $P$ is nonmonochromatic if it contains two points with distinct colors.

Question under these conventions. Is it true that for every plane convex body $D$ there exists an integer $m=m(D)\ge2$ such that, for every finite set $P\subset{\mathbb{R}}^2$, there exists a coloring $c:P\to\{1,2,3\}$ satisfying \[ \forall t\in{\mathbb{R}}^2\ \forall\lambda>0,\qquad \left|P\cap(t+\lambda D)\right|\ge m \ \Longrightarrow\ \exists p,q\in P\cap(t+\lambda D)\quad c(p)\ne c(q)? \] Here $m$ depends only on $D$, and the same coloring must work simultaneously for every indicated copy. Because $D$ is closed under the stated convex-body convention, points on the boundary of a copy count toward its intersection with $P$.

Unresolved source qualifications. The supplied cleaned statement says "plane convex body," whereas the original statement says "plane convex set." The displayed question follows the cleaned wording with the standard definition above; the original wording does not expressly impose compactness, nonempty interior, or closedness. The supplied record also does not specify whether homothetic copies allow negative scale factors or how boundary points should be treated independently of the convex-body convention. These scope and convention choices require source review.

Short English statement

For each fixed plane convex body, ask whether a threshold exists such that every finite planar point set can be colored with three colors so that every positive homothetic copy containing at least that many points contains two different colors. The threshold must be independent of the point set. The original wording uses the broader term "convex set," so the intended domain and geometric conventions require review.
