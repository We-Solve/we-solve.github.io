Verbatim supplied catalogue question

Given a Boolean circuit $C$, can one construct a circuit $C'$ of comparable size that computes the same function even when an adversary replaces the output of some gates by one of their inputs?

What is already supplied by the source

The primary report, printed page2996, states an existing quasipolynomial-size construction for general circuits and a near-linear construction for formulas, tolerating a $1/51$ fraction of short-circuited gates on every root-to-leaf path. The cleaned question does not select a stronger remaining size bound. We preserve that ambiguity and attempt the elementary replication-and-voting route under the actual path fault model. The construction fails, as the exact examples below show. No improved compilation theorem is claimed.

What replication proves with a trusted voter

Run three disjoint copies of a Boolean circuit and feed their outputs $a,b,c$ to the majority function \[ M(a,b,c)=(a\wedge b)\vee\left((a\wedge c)\vee(b\wedge c)\right). \] If at most one copy outputs an incorrect bit and the voter is fault-free, the other two equal the correct bit, and the displayed formula returns it. For correct bit one their conjunction is one; for correct bit zero every pair has at least one zero. This proves the familiar conditional replication guarantee, with three copies and five voter gates. It says nothing about faults inside the voter or a pathwise corruption allowance.

A complete short-circuit attack on that route

Take the original circuit to be the single gate $x\wedge y$ and evaluate at $(x,y)=(0,1)$, whose correct output is zero. Short-circuit the first copy to its $y$ input. Then the three copy outputs are $(a,b,c)=(1,0,0)$. Short-circuit the voter's left gate $a\wedge b$ to its $a$ input, making that gate output one. Finally short-circuit the outermost voter OR gate to that left input. The whole circuit now outputs one, incorrectly. There are exactly three short-circuited gates. The right subtree's outputs do not affect the attacked output.

The unpadded construction may have paths too short for even one fault under the source's fraction rule; therefore this example alone is not an attack satisfying that rule. To test the natural attempt to cure this by harmless depth padding, append at least 153 identity gates $z\mapsto z\wedge z$ in series after the voter. Every root-to-leaf path now contains at least153 gates and at most the three corrupted gates. Thus every path's fault fraction is at most $3/153=1/51$, while the uncorrupted padding passes the erroneous one unchanged. This is an admissible counterexample to replication followed by such padding, not a counterexample to the source's more sophisticated construction.

More generally, arbitrary identity padding does not create resilience. For any finite AND/OR core with $s$ gates and a chosen input leaf, short-circuit every gate along a core output-to-leaf path towards that leaf, starting at the bottom. Induction along the path makes the core output equal that leaf. If an assignment makes this leaf differ from the intended function value, the core is corrupted. Appending $51s$ identity gates makes the at-most-$s$ faults a fraction at most $1/51$ on every full path, including paths meeting only part of the corrupted path. The identity gates neither change the function nor repair the chosen wrong value. This argument applies when such a disagreeing leaf/assignment exists; it is not asserted for constant functions or arbitrary gate bases without that explicit condition.

Why a global fault fraction is a different promise

Consider the balanced AND tree on $N=2^h$ inputs. It has $N-1$ gates and depth $h$. Choose an input assignment with at least one zero and one one, and choose a leaf carrying one. Short-circuit the $h$ ancestor gates towards this leaf. A bottom-up induction makes every selected ancestor output one, so the output is one instead of the correct zero. The fraction of all gates corrupted is only $h/(N-1)$, which tends to zero. But the chosen path has all its gates corrupted, so this attack does not satisfy the bounded-fraction-per-path promise. It demonstrates why a global gate-fraction guarantee cannot be substituted for the source's pathwise guarantee in either direction of a proof.

Audit and unresolved compilation gap

The audit checked the fault type at every gate, the majority formula, both bit values in the trusted-voter lemma, the minimum padded path length, and the difference between an example attacking one compiler and a lower bound for all compilers. The route fails at fault-tolerant aggregation and at the way padding changes the allowed adversarial budget. The source's existing result is not re-proved here, and a comparable-size improvement for arbitrary circuits is not obtained.
