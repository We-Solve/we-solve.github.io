Linear Systems and Eigenvalue Problems — Problem 26

Status Open · unsolvedmath.comLLM status Open unverified

Statement

Definitions and mathematical statement

For a specified scalar domain $K$ and an integer $n\geq 1$, a symmetric tridiagonal matrix is a matrix $T=(t_{ij})\in K^{n\times n}$ such that \[ t_{ij}=t_{ji},\qquad t_{ij}=0\quad\text{whenever }|i-j|>1. \] The supplied record does not explicitly specify $K$, the representation of input entries, or a floating-point arithmetic model. These must be stated in any precise theorem; the usual real symmetric interpretation is not an explicit hypothesis in the record.

$\mathrm{MR}^{3}$ denotes the eigenvalue algorithm named in the source. The record supplies neither a complete algorithm specification nor a particular floating-point implementation.

Requested analysis. Give a theoretical-computer-science-style analysis of a precisely specified floating-point implementation of $\mathrm{MR}^{3}$ that proves correctness and convergence under explicitly stated, easily verifiable conditions on the input symmetric tridiagonal matrix. The analysis must specify the arithmetic model, the input conditions, the intended output and its accuracy requirements, and the meaning of convergence. Its guarantees must apply to every input satisfying those conditions. The source does not supply these specifications or quantitative requirements, so this is a request to formulate and prove such guarantees, rather than a fully specified conjecture with fixed error bounds.

Supplied qualifications. The source reports that no rigorous theoretical-computer-science-style success proof was then available for a floating-point implementation on an arbitrary symmetric tridiagonal matrix. It attributes to Willems and Lang, under the reference label Willems_framework, a conditional correctness proof relying on several assumptions, some verifiable only after executing the algorithm on the given input. It also reports that insufficiently careful implementations can fail through roundoff when eigenvalues are too tightly clustered, citing Parlett:CSD-04-1367. These are supplied source assessments, not independently verified literature conclusions. In particular, the requested input conditions must address the distinction between conditions checkable from the input and assumptions ascertainable only during execution.

Short English statement

Develop a rigorous correctness and convergence analysis for a specified floating-point implementation of $\mathrm{MR}^{3}$, with guarantees under easily checkable conditions on a symmetric tridiagonal input matrix. The source leaves the implementation, arithmetic model, scalar domain, accuracy targets, and meaning of convergence unspecified. It reports a conditional correctness result and possible roundoff failures for tightly clustered eigenvalues; these qualifications must be retained.
