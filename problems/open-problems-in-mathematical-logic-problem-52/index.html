Statement

Definitions and mathematical statement

Let $X$ be a standard Borel space. A Borel equivalence relation on $X$ is an equivalence relation $E\subseteq X\times X$ that is Borel. It is countable if every equivalence class is countable. It is hyperfinite if there exists a sequence $(E_n)_{n\in{\mathbb{N}}}$ of Borel equivalence relations on $X$, each having only finite equivalence classes, such that \[ E_n\subseteq E_{n+1}\quad(n\in{\mathbb{N}}),\qquad E=\bigcup_{n\in{\mathbb{N}}}E_n. \] Here the finite classes need not have a common finite bound on their sizes.

Source question. Suppose that there is a counterexample to the problem called the hf/hf problem in the source. Must the set of all hyperfinite equivalence relations be $\boldsymbol{\Sigma}^{1}_{2}$-complete?

More explicitly, a coded formulation would require a Polish parameter space $P$, a specified subset $C\subseteq P$ of admissible codes, and an interpretation assigning to every $c\in C$ a Borel equivalence relation $E_c$ on a standard Borel space $X_c$. One could then define \[ \mathcal H=\{c\in C:E_c\text{ is hyperfinite}\}\subseteq P. \] For a Polish space $Y$, a set $A\subseteq Y$ belongs to $\boldsymbol{\Sigma}^{1}_{2}(Y)$ if there is a Borel set $B\subseteq Y\times{\mathbb{N}}^{{\mathbb{N}}}\times{\mathbb{N}}^{{\mathbb{N}}}$ such that \[ y\in A\iff (\exists u\in{\mathbb{N}}^{{\mathbb{N}}})(\forall v\in{\mathbb{N}}^{{\mathbb{N}}})\ (y,u,v)\in B. \] After specifying a class $\mathscr R$ of reduction maps from ${\mathbb{N}}^{{\mathbb{N}}}$ to $P$, the intended completeness assertion would require \[ \mathcal H\in\boldsymbol{\Sigma}^{1}_{2}(P) \quad\text{and}\quad (\forall A\in\boldsymbol{\Sigma}^{1}_{2}({\mathbb{N}}^{{\mathbb{N}}})) (\exists r\in\mathscr R)(\forall x\in{\mathbb{N}}^{{\mathbb{N}}})\, \left(x\in A\iff r(x)\in\mathcal H\right). \] This is a formulation schema only: neither the coding data nor the reduction class is supplied. In particular, continuous and Borel reductions are not silently identified. The definition of hyperfiniteness above supplies standard terminology, but the source's intended domain of equivalence relations still requires confirmation.

Short English statement

The source asks whether the existence of a counterexample to the hf/hf problem forces the collection of hyperfinite equivalence relations to be $\boldsymbol{\Sigma}^{1}_{2}$-complete. A precise formulation requires the definition of hf/hf, the intended coding of equivalence relations, and the reduction convention; these are absent from the supplied record.
