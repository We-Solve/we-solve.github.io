Math-3730

Commuting Billiard Maps and Confocal Ellipses

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $D_1,D_2\subset{\mathbb{R}}^2$ be smooth convex plane domains, labelled so that $D_1\subseteq D_2$. An oriented line is an affine line equipped with a unit direction vector. Write \[ \mathcal L=\{\ell:\ell\text{ is an oriented line meeting both }D_1\text{ and }D_2\}. \] For a line directed by $v$ that has a finite transverse forward exit point $x\in\partial D_i$, the usual billiard map $T_i$ sends that line to the oriented line through $x$ with direction \[ v'=v-2\langle v,n_i(x)\rangle n_i(x), \] where $n_i(x)$ is the outward unit normal. This defines the reflection convention wherever such an exit exists.

The supplied question asks whether, for every pair of nested smooth convex plane domains in the intended class, commutation of their billiard maps on the intended common space of oriented lines implies that their boundaries are confocal ellipses: \[ T_1\circ T_2=T_2\circ T_1 \quad\Longrightarrow\quad \exists f_1,f_2\in{\mathbb{R}}^2\ \exists a_1,a_2>\tfrac12\|f_1-f_2\|\ \forall i\in\{1,2\},\qquad \partial D_i=\{x\in{\mathbb{R}}^2:\|x-f_1\|+\|x-f_2\|=2a_i\}. \] The displayed conclusion expresses a common pair of foci; allowing $f_1=f_2$ includes concentric circles as the coincident-focus case.

Unresolved formulation qualifications. The source does not specify whether the domains must be bounded, distinct, strictly convex, or strictly nested, nor does it specify the precise smoothness class or treatment of tangencies. For the displayed composition equality, $T_1(T_2(\ell))$ requires $T_2(\ell)$ to lie in the domain of $T_1$, and conversely. The source does not establish that $\mathcal L$ is invariant under either map or specify whether equality means equality of partial maps, equality wherever both compositions exist, or equality on a designated invariant phase space. These interpretations are not silently identified here. The source also does not specify whether coincident foci are permitted. Consequently, the displayed implication records the intended question but requires these qualifications to be resolved before it is a fully determined conjecture.

Short English statement

The question asks whether two nested smooth convex planar billiard tables whose reflection maps commute must have elliptical boundaries with the same foci. The admissible tables and the domain of the composition identity need clarification. The supplied dated curation labels the problem partially solved and reports a result for piecewise-analytic domains; these claims have not been independently verified.
