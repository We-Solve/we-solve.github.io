Question 4.11 — Which 1-ended admissable word hyperbolic groups G inject in Γg (as purely pseudo-Anosov subgroups)?

Status Open · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedOpenOpen

Statement

Definitions and mathematical statement

Fix the closed genus-$g$ surface $\Sigma$ and its mapping class group $\Gamma_g$ in the source. The surrounding local record 11000255 defines a group $G$ to be admissible for $\Gamma_g$ when \[ \operatorname{vcd}(G)\le\operatorname{vcd}(\Gamma_g)=4g-5\qquad(g\ge2). \] Virtual cohomological dimension is the cohomological dimension of a torsion-free finite-index subgroup when such a subgroup exists; the intended group class must make this definition applicable. Admissibility is a necessary dimension constraint, not a claimed sufficient embedding criterion.

A finitely generated group is word hyperbolic if a Cayley graph has uniformly thin geodesic triangles. It is one-ended when removing any finite set of vertices leaves exactly one unbounded component. Write $\partial_\infty G$ for its Gromov boundary. In the usual purely-pseudo-Anosov convention, an injection $\iota:G\hookrightarrow\Gamma_g$ is purely pseudo-Anosov when every nonidentity element of its image is pseudo-Anosov; this convention in particular excludes nontrivial torsion in $G$.

Question 4.11.

  1. Which one-ended admissible word-hyperbolic groups admit an injection into $\Gamma_g$ with purely pseudo-Anosov image?
  2. For such an injection $\iota$, does there exist a continuous map \[ \xi:\partial_\infty G\longrightarrow\operatorname{PML}_0(\Sigma) \] that is $G$-equivariant, meaning \[ \xi(a\cdot\eta)=\iota(a)\cdot\xi(\eta) \qquad(a\in G,\ \eta\in\partial_\infty G)? \]
The genus and surface are fixed in this embedding problem. The source does not require the boundary map to be injective or a topological embedding. Its notation $\operatorname{PML}_0(\Sigma)$ is not defined in the excerpt; projective measured lamination space is the expected setting, but the subscript-zero convention and target topology must be recovered rather than replaced by an ending-lamination or uniquely-ergodic locus. If "purely" instead permits torsion while constraining all infinite-order elements, that differing convention also needs confirmation.

Short English statement

Classify the one-ended word-hyperbolic groups satisfying the virtual-dimension bound that embed purely pseudo-Anosovly in a fixed mapping class group, and ask whether each such embedding admits a continuous equivariant boundary map to the source's lamination space.
