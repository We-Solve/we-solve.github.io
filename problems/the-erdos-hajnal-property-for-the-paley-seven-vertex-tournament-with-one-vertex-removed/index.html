Math-1338

The Erdős-Hajnal property for the Paley seven-vertex tournament with one vertex removed

Status Solved · unsolvedmath.comLLM status Solved from source status

Definitions and mathematical statement

A tournament is a finite directed graph with exactly one of $u\to v$ or $v\to u$ for each pair of distinct vertices. A subtournament is the induced tournament on a vertex subset; it is transitive if its vertices admit a linear ordering with every edge directed forward. Write $\operatorname{tr}(T)$ for the largest number of vertices in a transitive subtournament.

The original extract does not describe $T^*$ by its edges. The attached aid identifies it with the exceptional six-vertex tournament called $K_6$ by Berger--Choromanski--Chudnovsky, namely the Paley tournament on ${\mathbb{Z}}/7{\mathbb{Z}}$ with vertex $0$ removed. Under that supplied identification, use vertex set $\{1,2,3,4,5,6\}$ and orient $i\to j$ when $j-i\in\{1,2,4\}\pmod7$. The symbol $K_6$ here names this tournament, not an undirected complete-graph problem.

The workshop question is whether \[ \exists\epsilon>0\ \forall n\geq1\ \forall\text{ $n$-vertex tournaments }T: \quad T^*\not\subseteq T\ \Longrightarrow\ \operatorname{tr}(T)\geq n^\epsilon. \] Thus $\epsilon$ depends only on the fixed forbidden tournament, not on $n$ or $T$. The source's historical remark calls this the smallest then-unresolved tournament case, attributed to Berger--Choromanski--Chudnovsky. Its universal version quantifies separately for each forbidden tournament $H$: $\forall H\,\exists\epsilon_H>0$ with the corresponding bound for all $H$-free tournaments. The source states that this universal property is equivalent to the Erdős--Hajnal conjecture; it does not ask for one exponent uniform over all $H$.

A tournament is two-colourable if its vertices partition into two transitive sets. For this $T^*$ the sets $\{1,2,3\}$ and $\{4,5,6\}$ are transitive. The supplied aid attributes to Nguyen, Scott, and Seymour (2025) the theorem that every two-colourable tournament has the stated Erdős--Hajnal property, and reports that it answers this workshop question affirmatively. This is a supplied literature conclusion requiring independent verification, not a proof or source check performed here.

The aid also records a quantitative restricted class. Start with the one-vertex tournament and close under substitution into tournament templates with at most five vertices: replace each template vertex by a nonempty previously constructed block and orient every interblock edge according to the corresponding template edge. For every tournament $G$ in this recursive class, it claims \[ T^*\not\subseteq G,\qquad \operatorname{tr}(G)\geq |V(G)|^{\log_5 2}. \] No balance assumption on block sizes is made. This explicit exponent applies to the substitution class, not to all $T^*$-free tournaments as a consequence of the supplied summary.

Short English statement

Ask whether excluding the six-vertex Paley subtournament forces a transitive subtournament of polynomial size. The supplied aid attributes an affirmative answer to a 2025 theorem for two-colourable tournaments and gives an explicit exponent only for a recursively defined substitution class.
