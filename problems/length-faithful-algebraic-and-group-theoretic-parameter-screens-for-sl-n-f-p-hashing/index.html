Parameter determination for post-quantum hash functions

Ramón Flores presented a Tillich-Zémor-style hash function using the Cayley graph of special linear groups in arbitrary dimension. Questions remain, however, about the optimal choice of parameters for use with this protocol.

In the design of the hash function one has control over two parameters; the dimension of the special linear group considered, and the characteristic of the underlying field. We would like to determine appropriate choices for both via two branches of cryptanalysis: first, by analysis of the multivariate system implied by long matrix products; and second by direct analysis of group-theoretic properties. We should also study the impact of the partial homomorphicity exhibited by the scheme. [S2]

Verbatim supplied catalogue question

Parameter determination for post-quantum hash functions

Ramón Flores presented a Tillich-Zémor-style hash function using the Cayley graph of special linear groups in arbitrary dimension. Questions remain, however, about the optimal choice of parameters for use with this protocol.

In the design of the hash function one has control over two parameters; the dimension of the special linear group considered, and the characteristic of the underlying field. We would like to determine appropriate choices for both via two branches of cryptanalysis: first, by analysis of the multivariate system implied by long matrix products; and second by direct analysis of group-theoretic properties. We should also study the impact of the partial homomorphicity exhibited by the scheme.

Attempt and results

The primary hash construction uses a state-dependent nonbacktracking encoding. We retain that distinction: a raw word in generator matrices is not automatically the same as concatenation of protocol message strings. The following are necessary screens and an attempted algebraic attack formulation, not secure parameter choices or a cryptanalysis of the complete published protocol.
A proved output-size screen.
An invertible $n$ by $n$ matrix over $\mathbb F_p$ is an ordered independent list of columns. The first has $p^n-1$ choices; after $i$ independent columns, their span has $p^i$ vectors, so the next has $p^n-p^i$ choices. Hence \[ |\operatorname{GL}_n(\mathbb F_p)|=\prod_{i=0}^{n-1}(p^n-p^i). \] The determinant map onto $\mathbb F_p^*$ is surjective, since $\operatorname{diag}(a,1,\ldots,1)$ realizes every nonzero $a$. Multiplication by one such matrix bijects any determinant fiber with any other. Consequently \[ |\operatorname{SL}_n(\mathbb F_p)|=\frac1{p-1}\prod_{i=0}^{n-1}(p^n-p^i) =p^{n^2-1}\prod_{j=2}^n(1-p^{-j}). \] If every string of length $L$ over an alphabet of size $b$ is admissible, then $b^L$ messages map into at most this many outputs. Once $b^L>|\operatorname{SL}_n(\mathbb F_p)|$, two messages collide by the pigeonhole principle. This is an existence threshold, not the work needed to find a collision; it does not justify equating output bit length with security.
An exact bounded-degree exponent model.
Let $U=I+N$, where $N^n=0$, and assume $p\ge n$. For every nonnegative integer $a$, the binomial theorem gives \[ U^a=\sum_{j=0}^{n-1}\binom aj N^j. \] The coefficients $\binom aj=a(a-1)\cdots(a-j+1)/j!$ are polynomials over $\mathbb F_p$, since $j!\ne0$ for $j<n\le p$. For $0\le a<p$ this evaluates the corresponding matrix power exactly. Also $U^p=I+N^p=I$, because binomial middle coefficients vanish modulo $p$ and $N^p=0$. Thus all integer powers depend only on $a\bmod p$. For a product of $t$ such blocks with separate exponents, each entry has individual degree at most $n-1$ and total degree at most $t(n-1)$: matrix multiplication sums products with one coefficient from each block. This derives an algebraic system for equality to a target matrix.
Where the length-faithfulness inference fails.
A solution with exponent $a\in\mathbb F_p$ corresponds to a representative $0\le a<p$, but writing $U^a$ as repeated letters may use as many as $p-1$ letters. A field element has only $O(\log p)$ bits, so an unconstrained exponent equation does not certify a short generator word. If only exponents $0,1,\ldots,L$ with $L<p$ are permitted, one exact scalar constraint is \[ \prod_{j=0}^{L}(a-j)=0. \] It has precisely those roots in the field. Any nonzero univariate polynomial vanishing on all $L+1$ distinct permitted values must have degree at least $L+1$: division by $a-j$ at each distinct root removes one degree, inductively. This lower bound is only for one nonzero univariate polynomial, not for systems using auxiliary variables. A total word-length bound requires further coupling of the exponent choices, and the source's nonbacktracking transducer imposes additional admissibility conditions. Solving the unconstrained low-degree system therefore does not complete the proposed short-message attack.
