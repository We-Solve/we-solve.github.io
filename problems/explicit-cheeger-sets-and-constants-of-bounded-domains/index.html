Math-4486

Explicit Cheeger Sets and Constants of Bounded Domains

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Let $n\geq 2$ be an integer and let $\Omega\subset{\mathbb{R}}^n$ be a nonempty bounded open domain. No regularity assumption on $\partial\Omega$ is supplied. For a Lebesgue-measurable set $E\subseteq\Omega$, let $|E|$ denote its $n$-dimensional Lebesgue measure. Under the conventional interpretation of perimeter in the whole ambient space, define \[ P(E):=\sup\left\{\int_E\operatorname{div}\varphi(x)\,{\,\mathrm{d}} x:\ \varphi\in C_c^1({\mathbb{R}}^n;{\mathbb{R}}^n),\ \sup_{x\in{\mathbb{R}}^n}|\varphi(x)|\leq 1\right\}\in[0,+\infty]. \] Thus $E$ has finite perimeter when $P(E)<\infty$. Define \[ h(\Omega):=\inf\left\{\frac{P(E)}{|E|}:E\subseteq\Omega\text{ is Lebesgue-measurable},\ |E|>0\right\}. \] A Cheeger set of $\Omega$ is an admissible set $E$ satisfying $P(E)/|E|=h(\Omega)$; measurable sets are regarded as equivalent when they differ by a null set.

Problem. For every such $n$ and $\Omega$, explicitly describe all Cheeger sets of $\Omega$, up to null sets, and compute $h(\Omega)$.

The supplied record does not define $P$. The definition above uses full ambient perimeter, which includes boundary contributions along $\partial\Omega$, rather than relative perimeter inside $\Omega$; this interpretation requires confirmation against the original source. The record also does not specify what constitutes an explicit description or computation, or how an arbitrary domain is to be represented.

Short English statement

For each bounded open domain in ${\mathbb{R}}^n$, $n\geq2$, describe every positive-volume subset minimizing perimeter divided by volume and determine the minimum value. This draft uses full ambient perimeter; the source does not explicitly specify that convention or the meaning of an explicit computation.
