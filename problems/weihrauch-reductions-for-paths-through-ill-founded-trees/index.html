Math-15797

Weihrauch Reductions for Paths Through Ill-Founded Trees

Status Partially solved · unsolvedmath.comLLM status Open unverified

Top Open Problems Not reported cataloguedPartially solvedOpen

Statement

Definitions and mathematical statement

Write ${\mathbb{N}}^{<{\mathbb{N}}}=\bigcup_{n\in{\mathbb{N}}}{\mathbb{N}}^n$. A tree on ${\mathbb{N}}$ is a set $T\subseteq{\mathbb{N}}^{<{\mathbb{N}}}$ closed under initial segments. Its set of infinite paths is \[ [T]=\{p\in{\mathbb{N}}^{{\mathbb{N}}}: (\forall n\in{\mathbb{N}})\ p\mathbin{\upharpoonright}n\in T\}. \] Call $T$ ill-founded when $[T]\ne\varnothing$. Under the usual finite-sequence interpretation of the source's phrase "an ill-founded subtree of ${\mathbb{N}}^{{\mathbb{N}}}$", the underlying multivalued path problem is \[ \operatorname{dom}(\mathrm{CNN})=\{T\subseteq{\mathbb{N}}^{<{\mathbb{N}}}:T\text{ is a tree and }[T]\ne\varnothing\}, \qquad \mathrm{CNN}(T)=[T]. \] This explicitly interprets the source wording; the record does not specify how input trees are represented, so it does not yet determine a represented multivalued problem.

For multivalued problems $P,Q$ on fixed represented spaces, ordinary Weihrauch reducibility $P\leq_{\mathrm W}Q$ means that there are computable transformations $K,H$ on names such that, for every name $p$ of any input in $\operatorname{dom}(P)$, $K(p)$ names an input in $\operatorname{dom}(Q)$, and for every name $q$ of any valid $Q$-output on that input, $H(p,q)$ names a valid $P$-output on the original input. The same transformations must work for all inputs and all valid oracle outputs.

The supplied question asks, separately, whether \[ \mathrm{CNN}\leq_{\mathrm W}\Sigma^0_1\text{-}\mathrm{RT} \qquad\text{and whether}\qquad \mathrm{CNN}\leq_{\mathrm W}\mathrm{wFindHS}\text{-}\Pi^0_1. \] Here the target names are retained exactly in mathematical content from the record. Their input domains, output requirements, promises, and representations are not defined there. Consequently these are provisional reduction questions in the source's intended conventions; a fully specified mathematical formulation requires those definitions and the representation of $\mathrm{CNN}$. No choice of such missing conventions is asserted in this draft.

Short English statement

Given an ill-founded tree, can one uniformly obtain an infinite path using a single application of either named target problem, with computable processing before and after that application? The two reductions are separate questions. The supplied record leaves the target problems and input representations unspecified, so this statement requires clarification and human mathematical review.
