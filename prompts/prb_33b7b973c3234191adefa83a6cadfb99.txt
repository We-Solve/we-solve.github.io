\section{Extremal problem on the number of tree endomorphism}\label{statement}

\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


A tree here is a finite simple connected graph with no cycles. Let $P_n$ be the path on $n$ vertices and $S_n=K_{1,n-1}$ the star (with $S_1=P_1$). An endomorphism of a graph $T$ is a map $\phi:V(T)\to V(T)$ such that $uv\in E(T)$ implies $\phi(u)\phi(v)\in E(T)$. Write $\operatorname{End}(T)$ for the set of these maps; they need not be bijections.
\paragraph{Statement recorded in the supplied source.}
The source conjecture asks whether, for every $n\geq1$ and every $n$-vertex tree $T$,\[ |\operatorname{End}(P_n)|\leq |\operatorname{End}(T)|\leq |\operatorname{End}(S_n)|. \] \sref{statement}{2}
\subsection{Short English statement}
Among all trees with the same number of vertices, are the path and the star respectively the minimum and maximum for the number of edge-preserving self-maps?
