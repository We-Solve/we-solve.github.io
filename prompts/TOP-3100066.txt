{\small\sffamily UnsolvedMath ID 3100066 · Number Theory}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


For $x=(x_1,x_2)$ and $y=(y_1,y_2)$ in $\mathbb R^2$, use Euclidean distance
\[|x-y|=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2}.\]
A subset $S\subset\mathbb R^2$ is dense if every nonempty Euclidean open disc meets $S$. It is a rational-distance set if $|x-y|\in\mathbb Q$ for every $x,y\in S$.

\paragraph{Statement recorded in the supplied source.}
Does there exist a dense rational-distance set $S\subset\mathbb R^2$? \sref{3100066}{2}

\subsection{Short English statement}
Can a set be dense throughout the real plane while every pair of its points is a rational distance apart?
