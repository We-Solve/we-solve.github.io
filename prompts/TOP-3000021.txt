\section*{Covering a crossing supermodular function with graph edges}\label{3000021}
{\small UnsolvedMath ID 3000021 · AMR-029-0021 · Combinatorics · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $V$ be a finite set and $p:2^V\to\mathbb Z$ satisfy
$p(\varnothing)=p(V)=0$. Two sets $X,Y$ cross when all four regions
$X\cap Y$, $X\setminus Y$, $Y\setminus X$, and $V\setminus(X\cup Y)$
are nonempty. The function is crossing supermodular when
\[
                     p(X)+p(Y)\le p(X\cap Y)+p(X\cup Y)
\]
for every crossing pair. No symmetry under complementation is assumed.

An undirected loopless multigraph $G$ on $V$ covers $p$ if the number
$d_G(X)$ of edges with exactly one endpoint in $X$ satisfies
$d_G(X)\ge p(X)$ for every subset $X$. Parallel edges count separately.
Determine the minimum
\[
             \gamma(p)=\min\{|E(G)|:G\text{ covers }p\},
\]
and obtain an effective characterization of this optimum and a
construction attaining it. The sought result should describe the
obstructions and optimal value in terms of the set function, beyond
restating the original graph minimization.

Negative values of $p$ impose no additional restriction, but replacing
$p$ by a symmetrized function need not preserve crossing supermodularity.
Although every undirected cut has the same size as its complement,
the input function is allowed to be asymmetric. Requiring a simple
graph would impose a different feasibility restriction and is not
the multigraph covering problem specified here.
\subsection{Short English statement}
Find the minimum number of undirected edges needed to satisfy
every cut demand of an arbitrary crossing-supermodular function.
