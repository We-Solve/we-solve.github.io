\section*{Exact matching in red-blue bipartite graphs}\label{3000034}
{\small UnsolvedMath ID 3000034 · AMR-029-0034 · Combinatorics · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $G=(U\sqcup W,E)$ be a finite bipartite graph with $|U|=|W|=n$.
Each edge is labelled red or blue, and an integer $k$ with
$0\le k\le n$ is specified. A perfect matching is a set $M\subseteq E$
in which each vertex belongs to exactly one edge. The exact matching
decision problem asks whether
\[
                        |M\cap E_{\rm red}|=k
\]
for some perfect matching $M$.

Find a deterministic polynomial-time algorithm for this decision problem,
and for constructing a matching when it exists, or a useful combinatorial
characterization leading to such an algorithm. The source already
records randomized polynomial algorithms, so the unresolved algorithmic
target must distinguish deterministic computation from those methods.

The prescribed number of red edges is exact. Merely finding the smallest
and largest attainable red counts does not justify that every intermediate
integer is attainable. The graph is not assumed complete, and neither
colour class need itself be a matching. There are exactly two colours;
allowing an arbitrary number of colours with individual exact quotas
would give a different problem. A feasibility certificate on a yes
instance consists simply of the matching, while the main challenge is
to recognize both yes and no instances efficiently and deterministically.
\subsection{Short English statement}
Can exact red-edge counts in bipartite perfect matchings be
decided and realized in deterministic polynomial time?
