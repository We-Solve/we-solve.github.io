## Problem statement (quoted material)
<<<
For every integer $k\ge3$, we seek a finite set $A\subset\mathbb R^2$ such that every red--blue colouring admits a line containing at least $k$ points of $A$, with \emph{all} points of $A$ on that line having the same colour.
The answer is affirmative. We reconstruct Zach Hunter's argument recorded at \url{https://www.erdosproblems.com/1090}. The external input is the finite Hales--Jewett theorem: for each alphabet size $k$ and number of colours $r$, there is an integer $N$ such that every $r$-colouring of $\{0,\ldots,k-1\}^N$ contains a monochromatic combinatorial line. Such a line fixes some coordinates and sets every remaining coordinate equal to the same variable $t\in\{0,\ldots,k-1\}$; the set of variable coordinates is nonempty.
>>>
