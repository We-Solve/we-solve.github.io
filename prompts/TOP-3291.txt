\section{PTAS for feedback arc set in tournaments}\label{3291}
{\small\sffamily UnsolvedMath ID 3291 · Graph Theory}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


A finite tournament is an orientation of a complete graph. A feedback arc set $F$ is a set of arcs such that deleting $F$ leaves no directed cycle. Define $\operatorname{OPT}(T)=\min\{|F|:F\text{ is a feedback arc set of }T\}$. A polynomial-time approximation scheme permits a running-time exponent depending on a fixed approximation parameter $\epsilon>0$.
\paragraph{Statement recorded in the supplied source.}
For each $\epsilon>0$, is there an algorithm that, on every $n$-vertex tournament $T$, runs in time polynomial in $n$ (for that fixed $\epsilon$) and returns a feedback arc set $F$ satisfying $|F|\leq(1+\epsilon)\operatorname{OPT}(T)$? \sref{3291}{2}
\subsection{Short English statement}
Does the tournament feedback-arc problem have a polynomial-time algorithm for every fixed desired relative accuracy?
